import Papers.PODC2018.PartialReplicationCausal.Model /-! # Theorem 1 (necessity): the class of algorithms and the notion of obliviousness Section 2 of the paper restricts attention to algorithms that "implement causal consistency by storing and attaching metadata (timestamps) with update messages … When to apply a received update at a replica is determined only using the replica's local metadata and the metadata attached with the update." We model these as *deterministic metadata algorithms* (`Alg`): * each replica `i` keeps metadata `m : M` (its "timestamp"), initially `init i`; * on a client write of `x`, the metadata becomes `write i m x` and the update message carries the new metadata (the update tuple `update(i, T, x, v)` carries the timestamp `T`); * a received update `(k, x, T)` may be applied at `i` iff `ready i m k x T`; applying it sets the metadata to `merge i m k x T`. Allowing the decision to see the sender and the register (not only `T`) and attaching the full metadata makes the class larger, hence the necessity result stronger. Updates carry a label `lab` (the written value, which the paper assumes unique); it is not visible to the algorithm and is only used to identify an update across two executions, as needed to compare causal dependency graphs of different executions (Section 3.1). -/ namespace Podc.PartialReplicationCausal.Necessity open Classical variable {ι Reg M : Type*} /-- A deterministic metadata algorithm. -/ structure Alg (ι Reg M : Type*) where /-- Initial metadata of each replica. -/ init : ι → M /-- Metadata of replica `i` after a client write on register `x`; it is attached to the update. -/ write replica `i` after applying the update from `k` on `x` with attached `T`. -/ merge : ι → M → ι → Reg → M → M /-- An update message; `lab` is the (unique) written value and `pre` is ghost data, as in `Podc.PartialReplicationCausal.Update`. -/ structure Upd (ι Reg M : Type*) where /-- The issuing replica. -/ src : ι /-- The register written. -/ reg : Reg /-- The value written (unique), invisible to the algorithm. -/ lab : ℕ /-- The attached metadata. -/ ts : M /-- Ghost: the updates applied at `src` before this update was issued. -/ pre : Set ℕ /-- Global state: issued updates `log 0, …, log (n-1)`, metadata and applied sets. -/ structure St (ι Reg M : Type*) where /-- Number of issued updates. -/ n : ℕ /-- The issued updates. -/ log : ℕ → Upd ι Reg M /-- Metadata of each replica. -/ md : n := s.n + 1 log := Function.update s.log s.n ⟨i, x, ℓ, A.write i (s.md i) x, s.app i⟩ md := Function.update s.md i (A.write i (s.md i) x) app := Function.update s.app i (insert s.n (s.app i)) } /-- by `j` on a register of `X_jk`, and (ii) the edges (`↪`) between common vertices coincide. -/ def DiffOnly (s₁ s₂ : St ι Reg M) (i j k : ι) : Prop := (∀ a ∈ CP s₁ i, (¬ ∃ b ∈ CP s₂ i, key s₂ b = key s₁ a) → (s₁.log a).src = j ∧ (s₁.log a).reg ∈ X j ∩ X k) ∧ (∀ b ∈ CP s₂ i, (¬ ∃ a ∈ CP s₁ i, key s₁ a = key s₂ b) → (s₂.log b).src = j ∧ (s₂.log b).reg ∈ X j ∩ X k) ∧ (∀ a ∈ CP s₁ i, ∀ a' ∈ CP s₁ i, ∀ (metadata `md`) is the same in any two later states whose causal dependency graphs of `i` differ only in updates on `e_jk`. (The paper quantifies over all later graphs `R₁, R₂` with `R₀ < R₁`, `R₀ < R₂`; we only quantify over extensions of the given state `s₀`, which makes obliviousness a weaker assumption and Theorem 1 a stronger statement.) -/ def Oblivious (s₀ : St ι Reg M) (i j k : ι) : Prop := ∀ s₁ s₂, Relation.ReflTransGen (Step X A) s₀ s₁ → Relation.ReflTransGen (Step X A) s₀ s₂ → DiffOnly X s₁ s₂ i j k → s₁.md i = s₂.md i /-- Quiescent state: every issued update has been applied at every replica storing its register. -/ def Quiescent (s : St ι Reg M) : Prop := ∀ a < s.n, ∀ r, (s.log a).reg ∈ X r → a ∈ s.app r end Podc.PartialReplicationCausal.Necessity
