But the lemma also fails when `e_ki ∈ E_j`. Five replicas `A, B, C, D, I` and five registers `f, e, b, a, g`: ``` X_A = {f, e, b} X_B = {e, a} X_C = {a, g} X_D = {g, b} X_I = {f, a, g} ``` Execution: `A` writes `f` (`u'`, sent to `I` only; delayed), `A` writes `e`, `B` applies it and writes `a`, `C` applies that and writes `g`, `D` applies that and writes `g` (`u`, sent to `I`).
