Its preservation is proved in `Preservation.lean`; the hard field is `safe`, whose preservation is the chain argument of `Chain.lean`. -/ namespace Podc.PartialReplicationCausal open Classical variable {ι Reg : Type*} (X : ι → Set Reg) /-- The inductive invariant. -/ structure Inv (s : State ι Reg) : Prop where /-- Applied updates have been issued. -/ app_lt : ∀ i, ∀ c ∈ s.app i, c < s.n /-- Replicas only apply updates of their own registers. -/ app_reg : ∀ i, ∀ c ∈ s.app i, (s.log c).reg ∈ X i /-- An update is applied at its issuer. -/ own : ∀ a < s.n, a ∈ s.app (s.log a).src /-- ∀ i k, Adj X i k → s.τ i i k = cnt X s i k s.n /-- The own entry of an update's timestamp is its position on the edge. -/ ts_own : ∀ a < s.n, ∀ k, Adj X (s.log a).src k → (s.log a).reg ∈ X k → (s.log a).ts (s.log a).src k = cnt X s (s.log a).src k (a + 1) /-- Lemma 3, strengthened: replica `i` has applied exactly the first `τ_i[e_ji]` updates of `e_ji`. -/ count : ∀ i j, j ≠ i → Adj X j i → ∀ c < s.n, (s.log c).src = j → (s.log c).reg ∈ X i → (c ∈ s.app i ↔ cnt X s j i (c + 1) ≤ s.τ i j i) /-- A positive entry `τ_r[e]` is witnessed by an update on `e` in the causal past of `r`. -/ τ_wit : ∀ r an update's timestamp is witnessed by an update on that edge that is the update itself or happened before it. -/ ts_wit : ∀ a < s.n, ∀ e₁ e₂, TsEdge X (s.log a).src e₁ e₂ → 0 < (s.log a).ts e₁ e₂ → ∃
