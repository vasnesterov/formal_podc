import Papers.PODC2018.AtomicCrossChainSwaps.Basic /-! # §3: outcomes, uniform and atomic protocols, Theorem 3.5 An *outcome* is the set `T` of triggered arcs (`T u v`: the transfer `u → v` happened). Payoff classes for a coalition `S` (a single party is `S = {v}`) are defined from the arcs entering and leaving `S`, exactly as in §3. A protocol is abstracted by its *game*: for every deviating coalition `S`, the set of outcomes that can result when the members of `S` deviate (in any way) and everybody else conforms. -/ namespace AtomicSwap variable {V : Type*} (D : Digraph V) /-- Arc `(u, v)` enters `S`. -/ def Enters (S : Set V) (u v : V) : Prop := D.Adj u v ∧ u ∉ S ∧ v ∈ S /-- Arc `(u, v)` leaves `S`. -/ def Leaves (S : Set V) (u v : V) : Prop := D.Adj u v ∧ u ∈ S ∧ v ∉ S variable (S : Set V) (T : V → V → Prop) /-- FreeRide: some entering arc is triggered, no leaving arc is triggered. -/ def FreeRide : Prop := (∃ u v, Enters D S u v ∧ T u v) ∧ ∀ u v, Leaves D S u v → ¬ T u v /-- Discount: all entering arcs are triggered, some leaving arc is not. -/ def Discount : Prop := (∀ u v, Enters D S u v → T u v) ∧ ∃ u v, Leaves D S u v ∧ ¬ T u v /-- Deal: all entering and leaving arcs are triggered. -/ def Deal : Prop := (∀ u v, Enters D S u v → T u v) ∧ ∀ u v, Leaves D S u v → T u v /-- NoDeal: no entering or leaving arc is triggered. -/ def NoDeal : Prop := (∀ u v, Enters D S u v → ¬ T u v) ∧ ∀ u v, Leaves D S u v → ¬ T u v /-- Underwater: some entering arc is not triggered and some leaving arc is triggered. -/ def Underwater : Prop := (∃ u v, Enters D S u v ∧ ¬ T u v) ∧ ∃ u v, Leaves D S u v ∧ T u v /-- The five classes cover all outcomes, and the acceptable ones (Deal, NoDeal, Discount, FreeRide) are exactly the non-Underwater ones. -/ theorem not_underwater_iff : ¬ Underwater D S T ↔ FreeRide D S T ∨ Discount D S T ∨ Deal D S T ∨ NoDeal D S T := by unfold Underwater FreeRide Discount Deal NoDeal constructor · intro h by_cases hin : ∀ u v, Enters D S u v → T u v · by_cases hout : ∀ u v, Leaves D S u v → T u v · exact Or.inr (Or.inr (Or.inl ⟨hin, hout⟩)) · push Not at hout exact Or.inr (Or.inl ⟨hin, hout⟩) · push Not at hin have hout : ∀ u v, Leaves D S u v → ¬ T u v := by intro u v hl ht; exact h ⟨hin, u, v, hl, ht⟩ by_cases hsome : ∃ u v, Enters D S u v ∧ T u v · exact Or.inl ⟨hsome, hout⟩ · push Not at hsome exact Or.inr (Or.inr (Or.inr ⟨hsome, hout⟩)) · rintro (⟨-, h2⟩ | ⟨h1, -⟩ | ⟨h1, -⟩ | ⟨-, h2⟩) ⟨⟨a, b, h3, h4⟩, ⟨c, d, h5, h6⟩⟩ · exact h2 c d h5 h6 · exact h4 (h1 a b h3) · exact h4 (h1 a b h3) · exact h2 c d h5 h6 /-- The abstract semantics of a swap protocol on `D`: `outcomes S` is the set of outcomes that can arise when exactly the coalition `S` deviates (cooperatively, in any way) and all other parties conform. -/ structure SwapGame (D : Digraph V) where outcomes : Set V → Set (V → V → Prop) variable {D} namespace SwapGame variable (G : SwapGame D) /-- Definition 3.1 (uniform): if all conform, everybody ends with Deal; whatever coalition deviates, no conforming party ends Underwater. -/ def Uniform : Prop := (∀ T ∈ G.outcomes ∅, ∀ v, Deal D {v} T) ∧ ∀ S, ∀ T ∈ G.outcomes S, ∀ v ∉ S, ¬ Underwater D {v} T /-- Strong Nash equilibrium (§3): no deviating coalition achieves a payoff better than Deal. As in the proof of Lemma 3.3, "better than Deal" means FreeRide or Discount (Fig. 3). -/ def StrongNash : Prop := ∀ S, ∀ T ∈ G.outcomes S, ¬ FreeRide D S T ∧ ¬ Discount D S T /-- Definition 3.2 (atomic). -/ def Atomic : Prop := G.Uniform ∧ G.StrongNash /-- The modelling assumption used by Lemma 3.4: a coalition can always refuse to give away its own assets, i.e. some deviation leaves every arc leaving the coalition untriggered. -/ def CanAbstain : Prop := ∀ S, ∃ T ∈ G.outcomes S, ∀ u v, Leaves D S u v → ¬ T u v end SwapGame /-! ### The combinatorial core of Lemma 3.3 -/ section core variable {S : Set V} {T : V → V → Prop} /-- Acceptability of a single party `v`, unfolded: if some arc leaving `v` is triggered then all arcs entering `v` are. -/ lemma all_in_of_out (h : ¬ Underwater D {v} T) {w : V} (hvw : D.Adj v w) (hvw' : w ≠ v) (ht : T v w) : ∀ u, D.Adj u v → u ≠ v → T u v := by intro u hu hu' by_contra hn exact h ⟨⟨u, v, ⟨hu, by simpa using hu', rfl⟩, hn⟩, ⟨v, w, ⟨hvw, rfl, by simpa using hvw'⟩, ht⟩⟩ lemma all_out_of_in (h : ¬ Underwater D {v} T) {u : V} (huv : D.Adj u v) (huv' : u ≠ v) (ht : ¬ T u v) : ∀ w, D.Adj v w → w ≠ v → ¬ T v w := by intro w hw hw' htw exact h ⟨⟨u, v, ⟨huv, by simpa using huv', rfl⟩, ht⟩, ⟨v, w, ⟨hw, rfl, by simpa using hw'⟩, htw⟩⟩ /-- Forward propagation of triggered arcs: a walk from `a ∈ S` to an outsider `b` all of whose entering arcs are triggered yields a triggered arc leaving `S`. -/ lemma exists_leaves_triggered (hacc : ∀ v ∉ S, ¬ Underwater D {v} T) {a b : V} (hab : Reach D a b) (ha : a ∈ S) : b ∉ S → (∀ u, D.Adj u b → u ≠ b → T u b) → ∃ u v, Leaves D S u v ∧ T u v := by induction hab with | refl => intro hb;
