Distributed Spanner Approximation — PODC 2018

Keren Censor-Hillel, Michal Dory. Distributed Spanner Approximation. PODC 2018. DOI 10.1145/3212734.3212758. Formalized version: arXiv 1802.03160 v1; numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The main hardness results hold: the Ω(n/(√α·log n)) deterministic and (given the randomized communication complexity of set disjointness) Ω(√n/(√α·log n)) randomized CONGEST lower bounds for α-approximate minimum directed k-spanner, k ≥ 5 (Thms 2.8, 1.1), with their supporting lemmas, including the cited gap-disjointness bound (Lemma 2.5), which we prove. The vertex-cover reduction (Claim 3.1) is correct, and Lemma 3.2's gap, that a node cannot compute its cover membership "without any communication", is closed by one extra round, which does not touch the asymptotic uses. The algorithms of §§4–6, the weighted k-spanner bounds and Thms 3.3, 3.4 were not checked.

Mistakes in the paper

No mistakes in the statements.

Typos

  • Proof of Lemma 2.4: "V_B = Y1, V_A = V \ V_A" should read V_A = V \ V_B.

  • Claim 3.1 / Lemma 3.2: the conversion H → H' gives w(H') ≤ w(H). It has "the same cost" only because H is a minimum spanner in Claim 3.1. Lemma 3.2 applies the conversion to an α-approximate H, so there only |C_H| ≤ w(H) holds, and that is all the proof needs.

  • Proof of Thm 2.8: the constants c₁, c₂ are handled loosely (β is defined from α(n'), the bound is used with α(n)). The argument is routine; our version has explicit constants and no monotonicity assumption.

Proof gaps in true statements (1)Lemma 3.2

🔧 Lemma 3.2 (from a 2-spanner algorithm to vertex cover)

The proof claims that after simulating the 2-spanner algorithm on G_S every node converts the spanner H into C_H "without any communication", but node v cannot know whether u₂ output the cross edge {v₁, u₂}, which decides whether v ∈ C_H (localRule_counterexample).

Impact. Repaired with one extra round: T + 1 rounds of 3B-bit messages, or 3(T + 1) rounds of B-bit messages, instead of 3T (lemma_3_2, lemma_3_2_congest). The +O(1) does not affect Thms 3.3/3.4.

Details

By §1.5, a node outputs some of its incident edges and the spanner is the union of the outputs. The natural local rule (apply C_H only to the edges that v's own copies output) fails. Take the triangle and the optimal 2-spanner of G_S made of all weight-0 edges plus the cross edge {0₁, 2₂}. Either 0₁ or 2₂ may be the node that outputs that cross edge. The rule then gives {0} or {2}, and neither is a vertex cover. The exact count 3T(3n) is neither proved nor refuted: we refuted only this rule, not every algorithm.

Repair

In one extra round each node tells each neighbour whether it output their shared cross edge.

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous CONGEST from CSLib (Cslib.Congest.Algorithm): deterministic nodes, IDs = vertex names, B-bit messages per edge, direction and round, no failures. Randomized algorithms (Thm 1.1) get private uniform random strings r v : ρ; they may fail with probability ≤ δ on each instance.

  • Directed k-spanner: a digraph is a loopless arc set E : Finset (V × V); the network is its underlying undirected graph (communication is bidirectional) and must be connected; node v knows the directions of its incident arcs. Each node selects some incident arcs; the output is the union. H is a k-spanner if H ⊆ E and every arc of E is joined by a directed walk of length ≤ k in H; α-approximate means |H| ≤ α·|H'| for every k-spanner H'.

  • Algorithms run on a fixed vertex set V, n = |V|, and must be correct on every such digraph on V. The lower-bound graph G(ℓ, β) is padded with pendant vertices to exactly n vertices (the paper uses monotonicity of α(n) instead). Bounds are stated concretely in n, α, B, T; B = O(log n) gives the paper's Ω-bounds.

  • Two-party communication: CSLib protocol trees. Lemma 2.5 (gap disjointness, deterministic) is proved; the randomized lower bound for set disjointness (Lemma 2.1) is the hypothesis RandDisjLB δ κ.

  • §3: undirected graphs G on V with a linear order (IDs). G_S lives on V × Fin 3, with weights in ℕ; the cross edge for v < u is {v₁, u₂}. A 2-spanner is H ≤ G_S covering every edge by a path of length ≤ 2, and its cost is the sum of the weights of its edges. The spanner algorithm's node input is its incident edges with weights; the MVC algorithm's node input is its neighbourhood; the MVC output is the out bit. Algorithms may be required to be correct only on a class P of graphs.
