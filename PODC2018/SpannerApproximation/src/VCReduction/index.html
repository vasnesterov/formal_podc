import Papers.PODC2018.SpannerApproximation.VertexCover import Cslib.Computability.Distributed.Congest.LowerBound import Mathlib.Logic.Equiv.Fin.Basic /-! # From distributed weighted 2-spanners to distributed vertex cover (Lemma 3.2 of [CD18]) Model: CSLib's deterministic synchronous CONGEST model `Cslib.Congest.Algorithm V I σ B` (vertex names are the IDs, `B`-bit messages per edge, direction and round, no failures). * **Spanner algorithms** run on `G_S` (vertex type `V × Fin 3`). The input of node `a` is the list of its incident edges with their weights, `inpS G a : V × Fin 3 → Option ℕ`. The output is given by a selector `pick : V' → σ → V' → V' → Bool`: node `x` in state `s` outputs the edge `{a, b}` iff `pick x s a b` (either orientation; only incident edges count). The output spanner is the union of the nodes' outputs, `spannerOut`. * **MVC algorithms** run on `G`; node input = its neighbourhood `V → Bool`; output `out v s = true` iff `v` is in the cover. `mvcAlg A pick T` simulates `A` on `G_S`: node `v` of `G` simulates `v₁, v₂, v₃`; the (at most three) `G_S`-messages that travel from copies of `v` to copies of a neighbour `u` in one round are bundled into one message of `3B` bits. After `T` simulated rounds, one extra round tells every neighbour `u` whether a copy of `v` picked the cross edge between `v` and `u`; then `v` decides whether `v ∈ C_H` (Claim 3.1). The extra round is needed: whether the cross edge `{v₁, u₂}` is in the union of the outputs may depend on the output of `u₂`, which `v` does not know (see `localRule_counterexample`). Main results: * `lemma_3_2`: `A_MVC = mvcAlg A pick T` uses `3B`-bit messages and `T + 1` rounds; * `lemma_3_2_congest`: `slow 3 (mvcAlg A pick T)` uses `B`-bit messages and `3(T + 1)` rounds (`slow k` is a generic CONGEST slowdown splitting `kB`-bit messages over `k` rounds); * `localRule_counterexample`: `C_H` cannot be computed from the nodes' own outputs only. -/ namespace
