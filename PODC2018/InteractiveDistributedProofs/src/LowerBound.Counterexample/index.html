import Papers.PODC2018.InteractiveDistributedProofs.LowerBound.Setup import Papers.PODC2018.InteractiveDistributedProofs.LowerBound.ColourRefinement /-! # Lemma 3.11 is false Lemma 3.11 of the paper claims: for every simple protocol deciding `Sym` on the dumbbell class `𝒢` and all distinct `F₁, F₂ ∈ 𝓕`, `‖μ_A(F₁) − μ_A(F₂)‖₁ ≥ 2/3`, where `μ_A(F)` is the law of the random set `𝓜_A(F, r)` under uniform challenges `r`. The paper's argument: by Corollary 3.10 the event "`𝓜_A(·, r)` intersects `𝓜_B(F₁, r)`" has probability `≥ 2/3` for `F₁` and `≤ 1/3` for `F₂`. But this "event" depends on `r` itself, so it is not an event on the domain of `μ_A`, which is only the *marginal* law of `𝓜_A(F, r)`. A correct simple protocol can make all `μ_A(F)` equal by masking the response with the challenges of the bridge nodes. ## The counterexample Challenges are bits, responses are pairs of bits. Fix `v_A = a 0` and a test vertex `j₀ = 1`; the bit `ι(F)` says whether `0 ∼ 1` in `F` (node `v_A` reads it off its view: is `a 1` among its neighbours?). In `cexProtocol`: * `x_A` (and `x_B`) accepts iff `M(x_A) = M(x_B)` and `m₁ ⊕ r_{x_A} = m₂ ⊕ r_{x_B}` for its response `m = (m₁, m₂)` — so the protocol is simple (`cexProtocol_isSimple`, Definition 6); * `v_A` accepts iff `M(x_A)₁ = ι(F_A) ⊕ r_{x_A}`, `v_B` accepts iff `M(x_B)₂ = ι(F_B) ⊕ r_{x_B}`; all other nodes accept. Then `𝓜_A(F, r) = {(ι(F) ⊕ r_{x_A}, ι(F) ⊕ r_{x_B})}` (`MA_eq`), whose law is uniform over the four singletons whatever `ι(F)` is (`μA_eq`, by flipping the two bridge challenges). On `G(F, F)` the honest prover is always accepted (`accProb_self`); on `G(F_A, F_B)` with `ι(F_A) ≠ ι(F_B)` all of `v_A, x_A, v_B` accepting forces `ι(F_A) = ι(F_B)`, so every prover is always rejected (`accProb_ne`). With the 6-vertex asymmetric graphs `F₁` (edges `02 03 05 12 14 23`) and `F₂ = F₁ + {01}` (so `ι(F₁) = 0`, `ι(F₂) = 1`), the family `𝓕 = {F₁, F₂}` satisfies the paper's requirements (`cexFamily_ok`), `G(F₁, F₂)` and `G(F₂, F₁)` are asymmetric while `G(F, F)` is symmetric, the protocol decides `Sym` on `𝒢` with perfect completeness and soundness (`cexPr_decides`), and `μ_A(F₁) = μ_A(F₂)` (`μA_F₁_eq_F₂`): `lemma_3_11_false`.
