import Mathlib /-! # Summing hash values "up the tree" In Protocols 1 and 2 every node `v` checks `a_v = c_v + ∑_{u ∈ C(v)} a_u`, where `C(v) = {u ∈ N(v) | t_u = v}` and `t_u` is the parent pointer the prover gave to `u`. * `treeSum_root`: a **global summation argument** (no tree structure needed). If every non-root node's pointer lies in its neighbourhood, summing all the checks gives `a_r = ∑_v c_v + [r is counted as somebody's child] · a_r`. So either the root is never counted as a child, and then `a_r = ∑_v c_v` (Lemma 3.3), or it is, and then `∑_v c_v = 0`. With the paper's literal `C(v)`, the root *is* counted as a child of `t_r` whenever `t_r ∈ N(r)` (e.g. `t_r = r`); excluding the root from `C(v)` (flag `excl`) restores Lemma 3.3. * `exists_treeSol`: if the "child" relation increases a bounded depth label by one, the checks have a solution (used for completeness: the honest prover's hash values). -/ open Finset namespace
