import Papers.PODC2018.InteractiveDistributedProofs.Model import Papers.PODC2018.InteractiveDistributedProofs.Hash import Papers.PODC2018.InteractiveDistributedProofs.TreeSum /-! # Protocol 1: the `O(log n)`-bit dMAM protocol for `Sym` (Section 3.1) Messages (one copy of every broadcast value per node; nodes compare copies with their neighbours): * first prover message to `v`: `(r, ρ_v, t_v, d_v) ∈ V × V × V × Fin n` (claimed root, image, parent, depth); * challenge of `v`: a hash index `i_v ∈ ZMod p` (the family `polyHash` of Theorem 3.2, `|H| = p`); * second prover message to `v`: `(i, a_v, b_v) ∈ (ZMod p)³` (claimed root index and hash values). The verification (`verify`) is the paper's, lines 1–4: 1. `v ≠ r` ⇒ `t_v ∈ N(v)` and `d_{t_v} = d_v - 1`; `v = r` ⇒ `d_v = 0`; 2. `C(v) = {u ∈ N(v) | t_u = v}`; 3. `a_v = h_i([v, N(v)]) + ∑_{u ∈ C(v)} a_u` and `b_v = h_i([ρ_v, ρ(N(v))]) + ∑_{u ∈ C(v)} b_u`; 4. `v = r` ⇒ `a_r = b_r`, `ρ_r ≠ r`, `i = i_r`; plus the implicit broadcast checks (`r` and `i` agree with all neighbours). In line 3 we read the paper's `N_ρ(v)` as `ρ(N(v))` = `{ρ_u | u ∈ N(v)}`, as in equation (1), in the proof of Lemma 3.3 and in Protocol 2 (the paper's footnote-style definition "the vector whose `v`-th coordinate is 1 iff there exists `c ∈ C(v)` with `ρ_c = v`" is a typo: with `C(v)` in place of `N(v)` the honest prover fails). The flag `excl` selects the version of line 2: `excl = false` is the paper's literal `C(v) = {u ∈ N(v) | t_u = v}`, `excl = true` the repaired `C(v) = {u ∈ N(v) | u ≠ r ∧ t_u = v}` (the tree `T` of the proof of Lemma 3.3 only uses the edges `{v, t_v}` for `v ≠ r`). ## Main results * `lemma_3_3` (repaired protocol) and `lemma_3_3_literal` (the general form for the literal protocol); `lemma_3_3_false`: the literal Lemma 3.3 fails (`K₂`, `t_r = r`, a hash index with `h_i(A) = 0`). * `soundness`: for both versions, on a connected non-symmetric graph every prover is accepted with probability `≤ 2(n² − 1)/p < 1/3` when `p ≥ 10 n³`. * `completeness`: an honest prover is accepted with probability `1` (repaired protocol; for the literal one, if some vertex moved by a non-trivial automorphism is not adjacent to all others). * `theorem_3_4`: the repaired Protocol 1 decides `Sym` on connected graphs; `theorem_3_4_literal_false`: the literal Protocol 1 rejects the complete graph `K_n` (`n ≥ 2`, a YES-instance) with probability `> 2/3`, for every prover. * `theorem_1_1`: `Sym ∈ dMAM[O(log n)]`. -/ open Finset Cslib.Probability namespace
