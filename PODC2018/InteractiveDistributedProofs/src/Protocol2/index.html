import Papers.PODC2018.InteractiveDistributedProofs.Protocol1 /-! # Protocol 2: the `O(n log n)`-bit dAM protocol for `Sym` (Section 3.2) Every node first sends a hash index `i_v ∈ ZMod p`; then the prover sends every node * broadcast part `(ρ, i, r) ∈ Perm V × ZMod p × V` (the whole permutation, the root's index, the root), compared with all neighbours, and * unicast part `(t_v, d_v, a_v, b_v) ∈ V × Fin n × ZMod p × ZMod p`. The verification is the one of Protocol 1 with `ρ_u := ρ(u)`: once the copies of `ρ` agree on the neighbourhood (`verify2`), `{ρ_u(u) | u ∈ N(v)} = ρ(N(v))`, which is the paper's line 3. We formalize the repaired line 2 (`excl = true`, root excluded from `C(v)`); the literal line 2 has the same defect as in Protocol 1 (`K_n` is rejected). ## The gap in the soundness proof and its repair The paper fixes a root `r₀` and union-bounds over the `n^n` maps `σ : V → V`, getting a failure probability `< 1/3` for that root. But in a dAM protocol the prover names the root (and the index `i = i_r` it must echo) *after* seeing all challenges, so it may pick any of the `n` nodes whose index happens to be bad; the union bound must also run over `r`, which costs a factor `n` and breaks the paper's arithmetic. The statement survives: `ρ` is broadcast as a permutation, so the union bound runs over `n · n!` pairs `(r, σ)` with `σ r ≠ r`, and `2 · n · n! · (n² - 1)/p < 1/3` for `p ≥ 10 n^{n+2}` because `n! ≤ n^{n-1}` (`soundness`, `theorem_3_5`). ## Main results * `theorem_3_5`: Protocol 2 decides `Sym` on connected graphs for every prime `p ≥ 10 n^{n+2}`. * `theorem_1_3`: `Sym ∈ dAM[O(n log n)]`. -/ open
