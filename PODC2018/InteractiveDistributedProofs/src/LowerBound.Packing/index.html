import Mathlib /-! # Lemma 3.12: packing of distributions in `ℓ₁` Lemma 3.12 of [KOS18] states: *if `U` is a set of distributions on `[d]` whose pairwise `ℓ₁` distances exceed `1/2`, then `|U| < 5^d`.* The statement is true, but the paper's volume argument is sloppy: it intersects the `ℓ₁` balls with `[0,1]^d` (after which balls around different centres no longer have equal volume) and uses the wrong volume formula `(4r)^d/(d+1)!` for an `ℓ₁` ball of radius `r`. We use the following repaired argument, which needs no explicit volume formula. Work in `E = PiLp 1 (Fin d → ℝ)` with an additive Haar measure `μ`. The open balls `B(x, 1/4)`, `x ∈ U`, are pairwise disjoint (triangle inequality) and, since `‖x‖₁ = 1`, contained in `B(0, 5/4) \ B(0, 3/4)`. By translation invariance and scaling, `μ B(x, r) = r^d · μ B(0, 1)` with `0 < μ B(0, 1) < ∞`. Hence `|U| (1/4)^d + (3/4)^d ≤ (5/4)^d`, i.e. `|U| + 3^d ≤ 5^d`, so `|U| < 5^d`. No case split on `d = 0` is needed (then no distribution exists and `U = ∅`). Separation `> 1/2` is only used as `≥ 1/2`.
