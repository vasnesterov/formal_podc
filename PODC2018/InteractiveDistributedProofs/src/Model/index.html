import Papers.PODC2018.InteractiveDistributedProofs.Basic import Cslib.Probability.Finite.Uniform /-! # Interactive distributed proofs: the dMAM and dAM models (Section 2.2) A fixed finite set `V` of nodes (identifiers known to everybody, as in the paper) runs on a network graph `G : SimpleGraph V`. A single prover sees all of `G`. * **dAM** (Definition 1): every node `v` draws a uniformly random challenge `c v ∈ R` and sends it to the prover; the prover answers every node with a response `M v ∈ M` that may depend on `G` and on all challenges; then every node decides. * **dMAM** (Section 2.2): the prover first sends every node a message `M₁ v`, then the nodes send challenges, then the prover answers with `M₂ v` (depending on all challenges). **Locality.** A node's decision function only receives its *local view*: `mask G v x` keeps the values `x u` for `u ∈ N(v)` (closed neighbourhood) and replaces all others by `none`. A node thus knows its own identifier, its neighbours' identifiers (the `some` entries) and their messages and challenges, as in Definition 1 (the lower-bound section gives nodes `r_{N(v)}`; the upper-bound protocols only use their own challenge). Locality is therefore built into the type of a protocol. **Provers** are deterministic functions of the challenges (they also depend on `G`, since the statement `∃ P` is made for each graph). A randomized prover is a mixture of deterministic ones, so its acceptance probability is an average of deterministic acceptance probabilities; restricting to deterministic provers changes neither `∃ P, Pr > 2/3` nor `∀ P, Pr < 1/3`. **Correctness** (Definition 2): `Decides Π 𝒢 L` — on every graph of the class `𝒢`, a YES-instance has a prover making all nodes accept with probability `> 2/3`, and on a NO-instance every prover makes all nodes accept with probability `< 1/3`. Probability is uniform over the challenge vector `c : V → R` (`Cslib.Probability.uprob`). **Cost.** `InDMAM L ℓ` / `InDAM L ℓ`: for every vertex set of size `n`, there is a protocol deciding `L` on connected graphs whose message and challenge alphabets have at most `2^{ℓ(n)}` elements (i.e. every node exchanges `O(ℓ(n))` bits with the prover). -/ open Finset Cslib.Probability namespace Podc.InteractiveDistributedProofs variable {V : Type*} [Fintype V] [DecidableEq V] open Classical in -- CSLib candidate /-- The local view of node `v` of a global assignment `x`: values on `N(v)`, `none` elsewhere. -/ noncomputable def mask (G : SimpleGraph V) (v : V) {α : Type*} (x : V → α) : V → Option α := fun u => if u ∈ cnbhd G v then some (x u) else none theorem mask_apply_of_mem {G : SimpleGraph V} {v u : V} {α : Type*} (x : V → α) (hu : u ∈ cnbhd G v) : mask G v x u = some (x u) := by simp [mask, hu] theorem mask_apply_of_notMem {G : SimpleGraph V} {v u : V} {α : Type*} (x : V → α) (hu : u ∉ cnbhd G v) : mask G v x u = none := by simp [mask, hu] open Classical in /-- The neighbourhood a node reads off its view: the positions holding a value. -/ noncomputable def viewNbhd {α : Type*} (w : V → Option α) : Finset V := univ.filter fun u => (w u).isSome theorem viewNbhd_mask (G : SimpleGraph V) (v : V) {α : Type*} (x : V → α) : viewNbhd (mask G v x) = cnbhd G v := by ext u by_cases hu : u ∈ cnbhd G v <;> simp [viewNbhd, mask, hu] /-!
