import Papers.PODC2018.LocallyIterativeColoring.AG /-! # Counterexamples to two claims of [BEG18] ## 1. The `2p + 1`-round claim of Section 1.2 Section 1.2 of [BEG18] (arXiv v2) says: start from a proper `(Δ+1)²`-colouring with `Δ + 1 = p` prime, run AG over `GF(p)`; "when all vertices run this simple iterative step for `2p + 1 = 2(Δ + 1) + 1` rounds, the ultimate coloring `ψ` is a proper `(Δ + 1)`-coloring". Section 3 itself (correctly) assumes `q > 2Δ`. `intro_claim_false`: a tree on 16 vertices with maximum degree `Δ = 4`, `p = 5`, and a proper colouring with values in `GF(5)²`; after `2p + 1 = 11` rounds vertex `0` is still working (colour `⟨1, 1⟩`) and six distinct colours are in use (`> Δ + 1 = 5`). (It finalizes after 13 rounds; `ag_final_of_lt` gives the correct general bound `(Δ + 1) p` rounds.) ## 2. The 3-dimensional AG algorithm of Section 7 does not terminate Algorithm 7 (3AG(p)) of [BEG18] on colours `⟨c, b, a⟩ ∈ Z_p³`: a vertex with `c ≠ 0` finalizes `c` (to `⟨0, b, a⟩`) iff no neighbour has the same `b`; otherwise it moves to `⟨c, b + c, a⟩`. Two adjacent vertices with colours `⟨1, 0, 0⟩` and `⟨1, 0, 1⟩` (a proper colouring) keep equal second coordinates forever, so `c` never becomes `0`: `threeAG_never_finalizes`. This refutes the termination claim ("Within the first `3Δ + 1` rounds, each vertex will have `c_v = 0`") and Corollaries 7.2, 7.3 for every `p ≥ 2` (in particular for `p ≥ 3Δ + 1 = 4` and `p ≥ 2Δ + 2`). The flaw: unlike in the 2-dimensional case, a proper colouring may contain adjacent vertices with the same `⟨c, b⟩` (differing only in `a`), and these conflict in every round. -/ namespace BEG18 open Cslib.LocallyIterative /-! ### 1.
