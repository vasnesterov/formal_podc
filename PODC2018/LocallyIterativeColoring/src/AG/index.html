Colours are pairs `⟨a, b⟩` over an additive group `R` (in the paper `R = GF(q)`, `q` prime). In every round a vertex `v` with colour `⟨a, b⟩` * *conflicts* if some neighbour has the same second coordinate `b`; then its new colour is `⟨a, b + a⟩`; * otherwise its new colour is `⟨0, b⟩` (*final*). ## Main results * `ag_isProper` (**Lemma 3.2**): proper colourings stay proper, over any additive group. * `run_of_working`, `run_of_final`: the trajectory of a vertex is `⟨a, b + t•a⟩` while it is working and constant once it is final. * `ag_final` (**Lemmas 3.3, 3.4 + Corollary 3.5**, generalized): over `ZMod q`, `q` prime, if all degrees are `≤ Δ` and `Δ (m + 1) < m q`, every vertex is final after `m q` rounds. `ag_final_of_two_mul_lt` is the paper's case `m = 1`, `2Δ < q`: final after `q` rounds. -/ namespace BEG18 open Cslib.LocallyIterative Finset variable {V R : Type*} {G : SimpleGraph V} section Group variable [AddCommGroup R] open Classical in /-- One step of the AG algorithm (Algorithm 1 of [BEG18], lines 4–10): a vertex with colour `x` whose neighbours have the set of colours `N`. -/ noncomputable def agStep (x : R × R) (N : Set (R × R)) : R × R := if ∃ y ∈ N, y.2 = x.2 then (x.1, x.2 + x.1) else (0, x.2) /-- The AG algorithm (Algorithm 1 of [BEG18]);
