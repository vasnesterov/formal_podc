import Cslib.Computability.Distributed.Local.Identifiers import Mathlib /-! # One-bit AG halving reduction (Section 3.2 of [BEG18]) Barenboim, Elkin, Goldenberg, *Locally-Iterative Distributed (Δ+1)-Coloring below Szegedy–Vishwanathan Barrier*, PODC 2018 (arXiv 1712.00285v2), Section 3.2, Algorithm 2. Colours are pairs `⟨a, b⟩` with `a ∈ {0, 1}` and `b ∈ ℤ_q`; here `q` is an arbitrary positive integer (no primality is needed). We encode `a` as a `Bool`: `true` stands for `a = 1` (a *working* vertex) and `false` for `a = 0` (a *final* vertex). In every round a working vertex `⟨1, b⟩` becomes final `⟨0, b⟩` if no neighbour has colour `⟨0, b⟩`, and moves to `⟨1, b + 1⟩` otherwise; final vertices keep their colour. ## Main results * `BEG18.Halving.isProper_run` — **Lemma 3.7**: a proper colouring stays proper in every round (for every `q`, with no assumption on `Δ` or on the number of colours). * `BEG18.Halving.run_final` — **Lemma 3.8**: if all degrees are `≤ Δ` and `Δ + 1 ≤ q`, then after `Δ + 1` rounds every vertex is final (from an arbitrary, not even proper, initial colouring). * `BEG18.Halving.halvingNat_run` — the halving step on `ℕ`-colours: a proper colouring with colours `< 2q` (encoded as `c ↦ ⟨⌊c/q⌋, c mod q⟩`) becomes a proper colouring with colours `< q` after `Δ + 1` rounds, provided `Δ + 1 ≤ q`. * `BEG18.Halving.iterHalving_run` — core of **Corollary 3.9**: iterating `s` halving phases (`q_i = max ⌈k_i/2⌉ (Δ + 1)`) turns a proper colouring with `k ≤ 2^s (Δ + 1)` colours into a proper `(Δ +
