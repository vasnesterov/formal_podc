Colours are triples `⟨a, b, c⟩` with `a, b ∈ ℤ_q` (`q` prime) and `c ∈ ℕ` (`c < k` throughout). A vertex with `a = 0` is *final* and keeps its colour. A *working* vertex `v` (`a_v ≠ 0`) looks for an index `j < k` which is *free*, i.e. 1. `b_v + j·a_v ≠ b_u + j·a_u` for every neighbour colour `⟨a_u, b_u, c_u⟩` with `a_u ≠ 0`, and 2. `⟨b_v + j·a_v, j⟩ ≠ ⟨b_u, c_u⟩` for every neighbour colour with `a_u = 0`; if there is one, it takes the least such `j` and becomes final with colour `⟨0, b_v + j·a_v, j⟩`; otherwise its colour becomes `⟨a_v, b_v + k·a_v, 0⟩`. Only the *set* of neighbour colours is used. ## Main results * `BEG18.RefineAG.isProper_run` — **Lemma 3.10**: a proper colouring satisfying the invariant `a ≠ 0 → c = 0` (e.g. `c = 0` everywhere initially) stays proper in every round. * `BEG18.RefineAG.lemma_3_11` — **Lemma 3.11**: two adjacent working vertices agree on `b + j·a` for at most one index `j < k` (when `k ≤ q`). * `BEG18.RefineAG.run_final` — **Lemma 3.12 / Corollary 3.13** (sharpened): if all degrees are at most `Δ`, `1 ≤ k` and `2Δ + k ≤ q`, then after `⌊2Δ/k⌋ + 1` rounds every vertex is final. *
