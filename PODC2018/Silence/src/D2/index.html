At time 2 a process with `¬ errSeen` commits. * Round 3: a process with `errSeen` sends to all the set of ids from which it got `'1'` in round 1 (including its own id if its value is `1`). * Participants of the consensus (time 3): `errSeen`, or received an id set in round 3. Initial bit `v̂`: committed (`¬ errSeen`), or every id is covered by a received id set (or its own). * Consensus (`B.1.Consensus`): max-floodset for `f` rounds (rounds 4 … f + 3): a participant holding `1` sends a message to all; it holds `1` if `v̂ = 1` or it received a consensus message. At time `f + 3` an uncommitted participant commits iff it holds `1`, and aborts otherwise.
