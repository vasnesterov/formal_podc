import Papers.PODC2018.Silence.Defs /-! # Silent information transfer: Lemmas 1, 2 and Corollary 2 of Goren–Moses (§3.1) The hypothesis "`P` guarantees that if `¬K_j φ` at time `m − 1` then `j` sends a message to `i` in round `m`" is formalized as `Prescribes`: in every admissible run in which `j` is alive at time `m − 1` and does not know `φ`, the protocol's message function prescribes a message to `i`. "`i` does not receive a round-`m` message from `j`" is `msg alg r j i (m - 1) = none`. **Correction.** As literally stated, Lemma 2 and Corollary 2 also apply when `i` itself has crashed by time `m` (a crashed process receives nothing). Then they are false: `i`'s local state is `⊥`, which carries no information (`corollary2_literal_false`). We add the hypothesis that `i` is alive at time `m` (`r.Alive i m`).
