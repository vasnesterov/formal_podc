import Papers.PODC2018.BeepingLeaderElection.Balanced import Papers.PODC2018.BeepingLeaderElection.Theorem2 import Podc.Computability.Distributed.Beeping.Basic /-! # Algorithm 1 in the beeping model: communication phases of 1664 rounds (Section 3.1.3), Theorem 3 Dufoulon, Burman, Beauquier. *Beeping a Deterministic Time-Optimal Leader Election.* DISC 2018, Sections 2.2, 3.1.2, 3.1.3 and Theorem 3. **Model** (`Cslib.Beeping`, Section 2.2): synchronous rounds with a synchronous start; deterministic algorithm; in every round a node beeps or listens; a beeping node learns nothing, a listening node learns one bit: whether at least one neighbour beeped (no collision detection, no sender identity, no multiplicity). Nodes know their own identifier (stored in the initial state as `α(id)`) and nothing else (uniform in `n`, `N`, `D`). No failures. **Implementation of a diffusion phase** (Section 3.1.3). The phase-level message of a node is its pair `(prefix, suspicious)`. It is encoded (`encode`) as one of `c = 13 · 64 · 2 = 1664` slots: `(|prefix| mod 13, the last min(|prefix|, 6) bits of prefix as a number < 64, suspicious)`. A communication phase consists of `c` rounds; in round `r` of the phase a node beeps iff `r` is its own slot, and otherwise listens and records `r` if it heard a beep. At the end of the phase it decodes every heard slot w.r.t. its own prefix `x` (`decode`: length `L = decodeNat 6 |x| (k mod 13)` by 6-balanced decoding, word `x[0, L-6) ‖ (last bits)`) and applies the rules of Algorithm 1 (`ruleStep`, with the repaired priority `Priority.maxDelete`) to the decoded set. * `decode_encode` — decoding is correct whenever the sender's prefix `y` and the receiver's prefix `x` satisfy the conclusion of Lemma 1; `encode_inj` — so the encoding is injective among such pairs; * `ruleStep_insert_self` / `ruleStep_erase_self` — the node's own pair never triggers a rule (needed because a beeping node cannot hear neighbours that use its own slot); * `beepRun_phase` (simulation) — at round `1664 · p` the beep-level state of every node carries exactly the phase-level state `run G .maxDelete ident p v`; `beepRun_s` for every round `t` (phase `t / 1664`); * `theorem_3` — **Theorem 3** in rounds: after `1664 · (|α(X)| + 2D)` rounds, every node has `prefix = α(X)`, `leaderId = X`, and the maximum-identifier node is the unique candidate and the unique leader; `theorem_3_log` — the same after `1664 · (2⌊log₂ X⌋ + 3 + 2D)` rounds, i.e. `O(D + log N)`. -/ namespace
