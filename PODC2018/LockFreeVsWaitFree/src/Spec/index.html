import Cslib.Computability.Distributed.SharedMemory.Objects.Iface import Mathlib.Analysis.SpecificLimits.Basic /-! # The `n`-process long-lived approximate agreement object (`n`-LLAA) Attiya, Castañeda, Hendler, Perrin, *Separating Lock-Freedom from Wait-Freedom*, PODC 2018 (cited as [ACHP18]), Definitions 1 and 2. Every process belongs to a *side* `0` or `1` and invokes the single operation `output()`, which returns a real number. In a sequential execution, the *current position* of side `i` is the output of the last operation of a process of side `i`, or `i` if there is none. The sequential specification contains the sequential executions every prefix of which satisfies the *convergence requirement*: the distance between the two current positions is at most `1/2^r`, where `r` is the number of operations of the prefix. ## Modelling * The operation invoked by a process of side `i` is `i : Fin 2` (the object "knows" the side of the invoking process, as in the paper); `llaaObj` is the interface (operations `Fin 2`, responses `ℝ`) and `llaaSpec` the nondeterministic sequential specification. Since the specification only depends on the sides, `n`-LLAA and 2-LLAA (Definition 1, one process per side) have the same specification. * `llaaSpec.Legal llaaSpec.init l` is "every prefix of `l` satisfies the convergence requirement" (Definition 2). ## Main statements * `legal_iff_forall` — legality as a bound at every prefix. * `close_of_legal` — the arithmetic core of Theorem 11: if only one operation of side `0` is linearized (with output `v`), every operation of side `1` linearized at position `≥ k + 2` (output `x`) satisfies `|x - v| < 1/2^(k+1)`. * `half_le_of_legal_zero`, `le_three_eighths_of_legal` — the two outputs used in Lemma 10. -/ namespace Podc.LockFreeVsWaitFree open Cslib SharedMemory /-- The interface of the LLAA object: the operation `output()` of a process of side `i` is `i`, responses are reals.
