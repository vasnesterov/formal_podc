import Podc.Computability.Distributed.PopulationProtocols.Phases import Mathlib.Data.Fintype.Sum import Mathlib.Data.Fintype.Option /-! # The model: population protocols with or without a leader, and the naming problem Burman, Beauquier, Sohier, *Space-Optimal Naming in Population Protocols* (PODC 2018 brief announcement; full version HAL hal-01790517v3 / DISC 2019), Section 2. * Protocols are CSLib's deterministic population protocols (`Cslib.PopulationProtocol.Protocol`) on labelled configurations `A → Q`; executions, weak fairness (every unordered pair of agents interacts infinitely often) and global fairness are CSLib's. * A protocol is *symmetric* (`IsSymmetric`) if `δ q p = (δ p q).swap`; in particular two homonyms stay homonyms. * Protocols with a leader (`LeaderProtocol L Q`): mobile agents have states `Q`, the unique leader has states `L` (any type: the leader may be "as powerful as needed"). Such a protocol is turned into a CSLib protocol on `L ⊕ Q` (`LeaderProtocol.toProtocol`) whose agents are `Option A` (`none` is the leader); configurations of the paper are `ofLM l c`. * **Naming** (`Execution.Stabilizes names Function.Injective`): the names of the mobile agents are eventually constant and pairwise distinct. The name of a mobile agent is a function `name` of its state (the paper's "variable called a name"). * `SolvesWeak P I names` / `SolvesGlobal P I names`: every weakly / globally fair execution starting in `I` (the allowed initial configurations) solves naming. -/ namespace Podc.PPNaming open Cslib.PopulationProtocol Cslib.PopulationProtocol.Protocol variable {S Ag A Q L N : Type*} /-- A protocol is *symmetric* if exchanging the roles of the two agents exchanges the results: `(p, q) → (p', q')` implies `(q, p) → (q', p')`. -/ def IsSymmetric (P : Protocol S) : Prop := ∀ p q, P.δ q p = (P.δ p q).swap lemma IsSymmetric.diag {P : Protocol S} (h : IsSymmetric P) (s : S) : (P.δ s s).2 = (P.δ s s).1 := by have := congrArg Prod.fst (h s s);
