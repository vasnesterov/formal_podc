When the leader (counter `c`) meets an agent in state `Fin.last k` and `c < Fin.last k`, the agent takes the name `c` and the counter is incremented; every other interaction is null (in particular all mobile-mobile ones). The rules do not depend on who initiates (`prop14_symmetric`). Invariant (`Inv14`): the agents not in `Fin.last k` hold pairwise distinct names `< c`, and there are exactly `c` of them. The counter increases at every non-null step, so the configuration is eventually constant; once it is constant, no agent in `Fin.last k` can be named any more, which by the invariant forces `c = Fin.last k` and then at most one agent can still be in `Fin.last k` (`n ≤ k + 1`). -/ namespace Podc.PPNaming open Cslib.PopulationProtocol Cslib.PopulationProtocol.Protocol variable {k : ℕ} /-- The
