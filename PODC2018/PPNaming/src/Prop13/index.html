States `Fin (P + 1)`; the state `P` (`Fin.last P`) is special. Rules (`s ≠ P`): 1. `(s, P) → (s, (s + 1) mod P)` and symmetrically `(P, s) → ((s + 1) mod P, s)`; 2. `(s, s) → (P, P)`; 3. `(P, P) → (1, 1)`; all other interactions are null. * `prop13_isSymmetric`: the protocol is symmetric. * `prop13_solvesGlobal`: for `3 ≤ n ≤ P`, from every configuration, every globally fair execution solves naming.
