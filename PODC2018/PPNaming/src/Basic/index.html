Both weak and global fairness correctness imply it (`SolvesWeak.reachNamed`, `SolvesGlobal.reachNamed`); all impossibility results of this file only use this consequence, hence hold under both fairness assumptions. * **Lemma 2** (`lemma2`, `lemma2_leader`): in a naming protocol with `P` states per mobile agent (and a population of `P` mobile agents), names are an injective function of the states and the only non-null rules between two mobile agents are between homonyms.
