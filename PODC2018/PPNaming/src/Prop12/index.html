import Papers.PODC2018.PPNaming.Model import Mathlib.Algebra.Order.BigOperators.Group.Finset import Mathlib.Data.ZMod.Defs /-! # Proposition 12: asymmetric self-stabilizing naming with `P` states, without leader Burman, Beauquier, Sohier, *Space-Optimal Naming in Population Protocols*, Proposition 12. The protocol has states `Fin P` and the single (asymmetric) rule `(s, s) → (s, s + 1 mod P)`. For every population of size `n ≤ P`, from any initial configuration, every weakly fair and every globally fair execution solves naming (`prop12_solvesWeak`, `prop12_solvesGlobal`). Proof: a natural-number potential strictly decreases at every non-null step (`prop12_pot_lt`). Instead of the paper's lexicographic pair (number of holes, hole distance) we use the single sum `∑_{holes h} ∑_{agents x} ((h - C x) mod P)`: the set of holes can only shrink, and for every remaining hole `h` the distance of the moving agent to `h` drops by one. Hence only finitely many non-null steps occur (`eventually_const_of_potential`); in the final constant configuration, a remaining pair of homonyms would make a non-null step when it interacts (weak fairness), and from every configuration a configuration without homonyms (which is silent) is reachable (global fairness). -/ namespace Podc.PPNaming open Cslib.PopulationProtocol Cslib.PopulationProtocol.Protocol -- CSLib candidate (general fact about executions;
