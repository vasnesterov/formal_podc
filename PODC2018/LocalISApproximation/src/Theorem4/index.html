import Papers.PODC2018.LocalISApproximation.Basic import Cslib.Computability.Distributed.PortNumbering.Basic /-! # Theorem 4: no 1-round algorithm beats ratio `(Δ+1)/2` **Model** (§2.4 of the paper). Synchronous message passing in the port-numbering model of CSLib (`Cslib.PortNumbering`): a node knows its degree, distinguishes its incident edges by port numbers, and has as local input its unique label `ℓ v ∈ Fin N` and its private random string `r v ∈ R`. The random strings are independent and identically distributed with an arbitrary distribution `μ` on a finite set `R` (finite-precision randomness). A 1-round randomized algorithm is a deterministic CSLib `Algorithm (Fin N × R) Bool` run for one round; the output is the set of nodes that output `true`. Bandwidth and local computation are unlimited (messages and states of arbitrary types); `n`, `Δ`, `N` are fixed, hence known to the algorithm. **The argument.** Instead of the paper's `G₁ = K_{Δ+1}` (which has a different number of nodes than any `Δ`-regular bipartite graph, and nodes know `n`), we use two graphs on the *same* node set `V = Fin k × ZMod (Δ+1) × Bool` with the *same* port numbers at both ends of every edge: port `i < Δ` of `(c, a, s)` leads to `(c, a+i+1, s)` in `G₁ = crown false` (`2k` disjoint copies of `K_{Δ+1}`) and to `(c, a+i+1, ¬s)` in `G₂ = crown true` (`k` copies of `K_{Δ+1,Δ+1}` minus a perfect matching, a `Δ`-regular bipartite graph). For each node `v` a permutation `flipOthers v` of the nodes fixing `v` maps the `G₁`-neighbourhood of `v` onto its `G₂`-neighbourhood port by port, so the 1-round view of `v` in `G₂` under `(ℓ, r)` is its view in `G₁` under `(ℓ, r) ∘ flipOthers v` (`eval_crown_true`). Averaging over all labelings and random strings (both invariant under permutations of the nodes) every node joins with the same probability in `G₁` and `G₂` (`sum_expectedSize_eq`); in `G₁` at most `2k` nodes join (one per clique), while `α(G₂) ≥ k(Δ+1)`. * `theorem4`: for every correct 1-round algorithm there are a `Δ`-regular bipartite port-numbered graph and a labeling with `(Δ+1) · E[|output|] ≤ 2 α(G)`. * `theorem4_ratio`: hence a 1-round algorithm with performance ratio `ρ` on simple `Δ`-regular graphs has `ρ ≥ (Δ+1)/2` (Theorem 4 as stated). * `boppanaAlg`, `boppanaAlg_correct`: non-vacuity — Boppana's rule with random ranks and labels as tie-breakers is a correct 1-round algorithm in this model. -/ open Finset SimpleGraph Cslib.PortNumbering namespace
