Simple and Local Independent Set Approximation — PODC 2018

Ravi B. Boppana, Magnús M. Halldórsson, Dror Rawitz. Brief Announcement: Simple and Local Independent Set Approximation. PODC 2018. DOI 10.1145/3212734.3212793. Formalized version: arXiv 1803.00786 v1 (full version; numbering follows it).

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. Boppana's algorithm / the Caro–Wei bound achieves a tight (Δ+1)/2 ratio (Theorem 1), and no 1-round randomized algorithm does better (Theorem 4, whose proof needed a different pair of graphs). Theorems 3, 6 and 7 and Lemmas 2–4 also hold, and everything else is a slip, such as the wrongly rounded constant of Theorem 2. Theorem 5 was not checked.

Mistakes in the paper

✏️ Slips

  • Theorem 2 (ratio (d̄+2)/1.657 in terms of the average degree) is false as printed: K_{24000,10000} has α = 24000 but (d̄+2)/1.657·CaroWei ≈ 23999.2 (theorem2_false). The theorem claims α(G) ≤ (d̄+2)/1.657 · CaroWei(G) for every graph. The proof ends with (d̄+2)/(4(√2−1)) ≤ (d̄+2)/1.657, but 4(√2−1) = 1.65685… < 1.657, so the inequality goes the wrong way. Because the bound is asymptotically tight on bipartite graphs with regular sides and τ ≈ 1/√2 (the paper's own extremal family), the rounded constant really fails. The smallest complete bipartite counterexample is K_{13721,5683}. The statement with the proof's own constant 4(√2−1) in place of 1.657 holds (theorem2_corrected).

  • Lemma 5 lacks Y > 0: as stated (a > b > 0, Z − Y ≥ X > 0) it is false, since a=2, b=1, X=1, Y=−100, Z=−50 gives a smaller value at t = 0 than at t = 1 (lemma5_false). The hypothesis holds at the only use, Y = w(opt) > 0; with it we prove the lemma (lemma5).

  • Theorem 1 at Δ = 0: a ratio (0+1)/2 < 1 is impossible on edgeless graphs (theorem1_false_zero), and Theorem 3's ratio is undefined there. The theorem holds for every Δ ≥ 1 (theorem1).

  • Theorem 6 takes the minimum over x ≤ 1, where the expression takes negative values (theorem6_min_unbounded). The minimum should be over 0 ≤ x ≤ 1, which we formalize.

  • "For Δ = 2, … ρ ∼ 1.657" should be ≈ 1.686 = 1/0.593 (rho_two_gt).

  • The arXiv abstract says Boppana's algorithm is "only a Δ-approximation" on weighted graphs. The correct ratio is Δ+1, as §3 and the PODC abstract state; it exceeds Δ on K_{Δ,Δ} with weights 1, Q > Δ (boppana_weighted_not_Delta).

  • §3 writes E[w(B)] = Σ_{v∈B} …, which should be Σ_{v∈V}.

  • Lemma 5 is applied with t = W/X, which is undefined when V′ = ∅.

Typos

  • Eqs. (8) and (11) write w(Max) for E[w(Max)].

Proof gaps in true statements (1)Theorem 4

🔧 Theorem 4 (1-round lower bound)

The proof says no 1-round algorithm can distinguish K_{Δ+1} from a Δ-regular bipartite graph, but in the paper's model nodes know n, the two graphs have different sizes, and the view also contains the port number at the neighbour's end.

Impact. The theorem is true, and the paper's argument stays with another pair of graphs (theorem4, theorem4_ratio).

Repair

We use 2k copies of K_{Δ+1} versus k copies of K_{Δ+1,Δ+1} minus a perfect matching, on the same nodes, with matching port numbers at both ends of every edge. For each node v, a permutation fixing v maps its view in one graph to its view in the other, so averaging over labelings gives every node the same join probability in both graphs.

Full list of differences (including modelling choices and minor imprecisions): differencies.md.

The formalizationmodel, Lean names of the results, trust

Model.

  • Finite simple graphs (Mathlib SimpleGraph, indepNum). "B has performance ratio ρ for Δ" (HasPerformanceRatio) means α(G) ≥ B(G) ≥ α(G)/ρ for all finite G with Δ(G) = Δ. HasTightPerformanceRatio adds that no smaller ratio holds.

  • Boppana's algorithm: a uniformly random ordering σ : V ≃ Fin n; the output is the set of vertices preceding all their neighbours. We prove its expected size is exactly CaroWei(G).

  • Theorem 4: synchronous message passing in CSLib's port-numbering model, one round. Nodes have unique labels from Fin N (any N ≥ n) and private i.i.d. random strings from an arbitrary distribution on a finite set. Messages and local computation are unbounded, and n, Δ, N are known. The algorithm must output an independent set with probability 1, but only on simple Δ-regular graphs with n = 2k(Δ+1) nodes. This is a weaker hypothesis than the paper's, so the theorem is stronger. Not covered: randomness with infinitely many outcomes (e.g. exact uniform reals).

  • Weighted section: positive real weights. In Max, node v draws x_v ∈ [0,1] uniformly (product Lebesgue measure) and joins iff x_v^{1/w_v} beats all its neighbours. Lemma 2 is proved measure-theoretically.
