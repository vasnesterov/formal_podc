To check that the two hypotheses `A.NRL OneShot` and `A.WaitFree OneShot` are not jointly unsatisfiable *in our model* (which would make Theorem 4 vacuous), we give a recoverable test&set `casTAS P` built from a single compare&swap object `W` (initially `none`), for any process type `P`: * `cas`: `W.cas(none, some p)` (the response is ignored); * `read`: `v ← W.read`; * `ret`: return `v ≠ some p` (`false` = 0 iff `p` is the winner).
