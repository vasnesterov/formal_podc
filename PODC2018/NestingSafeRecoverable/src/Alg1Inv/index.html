import Papers.PODC2018.NestingSafeRecoverable.Alg1Step /-! # The invariant of the correctness proof of Algorithm 1 The proof of Lemma 2 maintains, along every execution, a *ghost linearization* `L` of the history and the ghost set `G` of the values that `R` has held. Linearization points: * a `READ` is linearized when it reads `R` (lines 8/19); if it crashes before returning, the entry is retracted (`IsLinearization.erase_ro`); * a `WRITE` is linearized when it writes `R` (line 4); * a `WRITE` of `p` that may return without writing (the paper's case "`curr ≠ R`, a write by a different process `q` happened between the two reads of `R` by `p`") is linearized *speculatively* immediately before the write of `q` that disarms it ("phantom" entry). The phantom entry stays immediately followed by a write entry (`FW`), so it can be retracted (`IsLinearization.erase_absorbed`) if `p` writes `R` itself later or re-executes `WRITE`. The pending `WRITE(val)` of `p` is in `L` iff `LinW` holds: `p` has written `val` to `R` (`val ∈ G`), or `S_p = ⟨0, val⟩`, or `S_p = ⟨1, c⟩` with `R ≠ c`, or `p` is about to execute line 3 with `temp ≠ R`. The freshness of written values makes `R ≠ c` stable. -/ set_option linter.unusedSectionVars false namespace Podc.NestingSafeRecoverable.Alg1 open Cslib.SharedMemory Cslib.SharedMemory.NRL variable {P
