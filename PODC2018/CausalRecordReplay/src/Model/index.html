import Papers.PODC2018.CausalRecordReplay.Basic /-! # The shared-memory model of Sections 2–4 R. L. Jones, M. S. Khan, N. H. Vaidya. *Optimal Record and Replay under Causal Consistency.* PODC 2018 (brief announcement); full version arXiv:1805.08804v2. * `Program P Op X`: processes `P`, operations `Op`, shared variables `X`; every operation has a process, a kind (read/write) and a variable; the program order `po` is a strict total order on the operations of each process and relates no operations of different processes (Section 2). * An `Execution` is a writes-to map (Definition 2.1); `none` is the initial value. * A view of process `i` (Section 3) is a strict total order on `Obs i = (∗,i,∗,∗) ∪ (w,∗,∗,∗)` in which each read of `i` returns the last value written to its variable (`IsViewOf`). * Strong causal order `SCO` (Definition 3.3) and strong causal consistency (Definition 3.4). * Records, replays and good records for both RnR models (Section 4). The replay is any execution explained by views `V'` that respect the record. The values read in the replay are not constrained: every family of strict total orders explains some execution (`exists_explains`), so "there is a replay certified by `V'`" just means that `V'` is a family of strict total orders satisfying the consistency condition and respecting the record. -/ namespace Podc.CausalRecordReplay open Relation /-- A shared-memory program (Section 2): processes `P`, operations `Op`, variables `X`. -/ structure Program (P Op X : Type*) where /-- The process performing the operation. -/ proc : Op → P /-- The operation is a write (otherwise it is a read). -/ IsWrite : Op → Prop /-- The shared variable accessed. -/ var : Op → X /-- Program order. -/ po : Op → Op → Prop po_irrefl : ∀ a, ¬ po a a po_trans : ∀ {a b c}, po a b → po b c → po a c po_proc : ∀ {a b}, po a `(∗,i,∗,∗) ∪ (w,∗,∗,∗)`. -/ def Obs (i : P) (o : Op) : Prop := π.proc o = i ∨ π.IsWrite o /-- Program order restricted to `Obs i`, i.e. `PO | (∗,i,∗,∗) ∪ (w,∗,∗,∗)`. -/ def poOn (i : P) (a b : Op) : Prop := π.po a b ∧ π.Obs i a ∧ π.Obs i b /-- An execution: the writes-to relation (Definition 2.1), as the write read by each read (`none` = the initial value). -/ structure Execution (Op : Type*) each read of `S` returns the last value written to its variable. -/ def IsViewOf (ex : Execution Op) (S : Op → Prop) (r : Op → Op → Prop) : Prop := IsStrictTotalOn S r ∧ ∀ rd, S rd → ¬ π.IsWrite rd → match ex.rf rd with | some w => π.LastWriteBefore r rd w | none => ∀ w, π.IsWrite w → π.var w = π.var rd → ¬ r w rd /-- The per-process views `V` explain the execution `ex`: each `V i` is a view on `Obs i`. -/ def Explains (ex : Execution Op) (V : P → Op → Op → Prop) : Prop := ∀ i, π.IsViewOf ex (π.Obs i) (V i) /-- Definition 3.3 (strong causal order): `(w₁, w₂) ∈ SCO(V)` iff both are writes and `w₁ <_{V_j} w₂` where `j` is the process of `w₂`. -/ def SCO (V : P → Op → Op → Prop) (a b : Op) : Prop := π.IsWrite a ∧ π.IsWrite b ∧ V (π.proc b) a b /-- Definition 3.4 (strong causal consistency), def SCCExplains (ex : Execution Op) (V : P → Op → Op → Prop) : Prop := π.Explains ex V ∧ π.StronglyCausal V /-! ### Records and replays (Section 4) -/ /-- RnR Model 1: `R` is a record of `V` if `R i ⊆ V i` for all `i`. -/ def IsRecord1 (V R : P → Op → Op → Prop) : Prop := ∀ i a b, R i a b → V i a b /-- RnR Model 1: the record `R` of `V` is good if every set of views `V'` certifying a strongly causally consistent replay valid for `R` (views of some execution, strongly causal, respecting `R`) equals `V`. -/ def Good1 (V R : P → Op → Op → Prop) : Prop := ∀ (ex : Execution Op) (V' : P → Op →
