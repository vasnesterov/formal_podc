Theorem 6.7: for every good Model-2 record `R` of strongly causal views `V`, every cover `o₁ ⋖ o₂` of `A_i(V)` that is not in `PO`, `SWO_i(V)` or `B_i(V)` is recorded: `(o₁, o₂) ∈ R_i`. ## The paper's construction is broken The proof (Appendix C) swaps `e = (o₁, o₂)` using `U_i = (A_i(V) \ {e}) ∪ {(o₂, o₁)} ∪ C_i(V, o₁, o₂)`, `U_m = A_m(V) ∪ C_i(V, o₁, o₂)` and claims that `¬ B_i(V)` makes every `U_m` a partial order. This fails whenever `o₁` and `o₂` are writes and `o₂` is a write of `i`: then `e` itself is in `C¹_i(V, o₁, o₂)` (take `w₃ = o₁`, `w₄ = o₂`), so `U_i` contains both `e` and its reverse (`paper_U_has_cycle`). (`¬ B_i(V)` only excludes cycles of `(A_i \ {e}) ∪ C_i`, which does not contain `(o₂, o₁)`.) ## The repaired construction Write `A' = A_i(V) \ {e}` (transitive because `e` is a cover), `B_p = A_p(V)` for `p ≠ i` and `B_i = A'` (`Brel`). Let `F` (`Frel`) be the least relation such that * `(w₃, w₄) ∈ F` if `w₃ ≠ w₄` are writes, `w₄` a write of `i`, `w₃ ≤_{A'} o₂` and `o₁ ≤_{A'} w₄`; * `(w₃, w₄) ∈ F` if `w₃ ≠ w₄` are writes, `(w₅, w₆) ∈ F`, `w₃ ≤_{B_p ∪ F} w₅`, `w₆ ≤_{B_p} w₄` where `p` is the process of `w₄`. This is `C_i(V, o₁, o₂)` with `A_i` replaced by `A'` (in particular `F ⊆ C_i(V, o₁, o₂)`). Then `U_m = (B_m ∪ F ∪ {(o₂, o₁) | m = i})⁺` (`Urel`) works when `o₂` is a write; when `o₂` is a read we take `F = ∅` (as the paper does).
