The paper bounds this knowledge: "if process `i` is aware that `(o₁, o₂) ∈ V_j` (`j ≠ i`) then process `i` must have already observed some `o₃ ∈ (∗, j, ∗, ∗)` with `o₁ <_{V_j} o₂ ≤_{V_j} o₃`". We give process `i` the *maximal* knowledge allowed by this bound (`SameKnow`): its own view up to `o₂`, and for every write `w` of another process `m` that `i` has observed so far, the view `V_m` up to `w`.
