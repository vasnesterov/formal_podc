On Local Distributed Sampling and Counting — PODC 2018

Weiming Feng, Yitong Yin. On Local Distributed Sampling and Counting. PODC 2018. DOI 10.1145/3212734.3212757. Formalized version: arXiv 1802.06686 v1; numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The probabilistic and locality cores of the main results hold after local changes: Theorem 3.2 (sampling from inference), Theorem 3.4, the boosting Lemma 4.1, the correctness of the local JVV sampler (Claims 4.5–4.7, Lemma 4.8), and both directions of Theorem 5.1. Corollary 5.2 is false, since strong spatial mixing (SSM) with exponential decay in total variation does not imply SSM in multiplicative error, but it is a by-product that the paper lists under minor results and no main theorem uses. The composition into Theorem 4.2, the round counts and the applications were not checked.

Mistakes in the paper

❌ Corollary 5.2 (TV-SSM ⇒ multiplicative SSM)

Corollary 5.2 is false: the hardcore model on perfect matchings has SSM with exponential decay in total variation but no SSM in multiplicative error, whatever the rate (corollary_5_2_false).

Impact. The counterexample is the paper's own main application (the hardcore model in the uniqueness regime), but the paper lists the corollary under minor results and nothing depends on it. The easy direction (multiplicative ⇒ TV, same rate) holds (ssm_of_mssm).

Details

The multiplicative error (2) is err = max_x |ln μ(x) − ln μ̂(x)|, and the only convention is ln 0 − ln 0 = 0. In the hardcore model, let u be a neighbour of v. Pin u to occupied (σ) and to unoccupied (τ). Then μ^σ_v(occupied) = 0 while μ^τ_v(occupied) > 0, so err(μ^σ_v, μ^τ_v) = ∞. No rate δ_n(1) = poly(n)·α can bound it.

  • The class of hardcore models on perfect matchings (every even n) meets every hypothesis of the corollary. Its members are locally admissible, their constraints have diameter 1, and they have TV-SSM with δ_n(d) = 2·(1/2)^d.

  • On any graph with an edge the hardcore model has no multiplicative SSM (hardcore_err_infinite, hardcore_not_mssm).

  • The counterexample keeps v free and changes only a neighbour, so it does not rely on the trivial case v ∈ D, where err = ∞ for every distribution.

  • Large weights break it with soft constraints alone too, so the true statement can only bound err once poly(n)·α^d is small.

Repair

Only the true direction is proved: d_TV ≤ err, so multiplicative SSM implies TV-SSM with the same rate (ssm_of_mssm).

❌ Corollary 5.2, proof route (Theorem 5.1 ⇐, then Lemma 4.1, then Theorem 5.1 ⇒ for err)

The boosting lemma has locality 2t + ℓ, so the paper's route proves decay only at rate √α, not at the claimed rate α, even at large distances.

Impact. The stated rate is not reached by the paper's proof, and no route to it is formalized.

✏️ Slips

  • §4.2.1 and Lemma 4.8 swap acceptance and rejection: node vᵢ sets F'_{vᵢ} = 1 with probability q_{vᵢ} ≥ e^{−5/n²} and fails when F'_{vᵢ} = 1, so the algorithm fails almost surely. The proof uses Pr[success | Y = σ] = ∏ q_{vᵢ}(σ), so the intended reading is "accept with probability q_{vᵢ}, fail with probability O(1/n)"; we formalize this version (lemma_4_8_success, lemma_4_8). Lemma 4.8 says the algorithm "fails with probability at most ∑ E[F'_{vᵢ}] = 1 − O(1/n)", which matches neither reading.

  • Theorem 5.1 (⇒): the rate δ_n(t) = 2 min{δ | t(n, δ) ≤ t − 1} need not be attained, and for small t the set is empty. min should be inf, with inf ∅ = ∞. We prove the statement with the infimum, using [0, ∞]-valued rates (theorem_5_1_forward).

Typos

  • In the Claim of Lemma 4.1, "dist_G(v, v_{i−1}) > t" and "at node v_{i−1}" should read vᵢ.

  • In the proof of (3), "m = |Λ| ≤ n" should read m = |Γ|.

  • In Claim 4.6, Γ uses B_t(v) for B_t(vᵢ), and the pinnings τ₁, τ₂ are implicitly combined with τ.

The proof writes μ_{Λᵢ∪{v}}(τᵢᶜ) = μ_{Λᵢ₋₁∪{v}}(τᵢ₋₁ᶜ)·μ^{τᵢ₋₁ᶜ}_{vᵢ}(cᵢ) ≥ μ^{τᵢ₋₁ᶜ}_{vᵢ}(cᵢ), but the first factor is a probability, so the inequality goes the other way.

Repair

The formalizationmodel, Lean names of the results, trust

Model.

  • A joint distribution over Σ^V (V, Σ finite) is a nonnegative weight w : (V → Σ) → ℝ. A partial configuration τ ∈ Σ^Λ is a pinning τ : V → Option Σ. Conditional marginals μ^τ_v (marg), conditional distributions μ^τ (cond), TV distance (tv) and multiplicative error (MultClose) are all finite sums. Gibbs distributions are products of factors with finite scopes (Factor, gibbsW). Locality (Definition 2.4) is GibbsLocal G F ℓ, i.e. every scope has diameter ≤ ℓ in G. Local admissibility (Definition 2.5) is LocallyAdmissible.

  • LOCAL model, per instance. The instance (G, x) is fixed. An inference algorithm is a function from pinnings to answers at each node. It is r-local (IsLocalAlg) if its answer at v depends only on the pinning within distance r of v; the rest of (G, x) is fixed and known. Randomness is removed as in Proposition 3.3. Where we assume an algorithm (Theorem 5.1 ⇒, Lemma 4.1), this hypothesis is weaker than true LOCAL locality, so the results are stronger. Where we build an algorithm (Theorem 5.1 ⇐, Lemma 4.1), it is local in the pinning, and its output is given by an explicit formula that uses only the factors inside the ball (marg_eq_local, Proposition 2.1).

  • Sampling. The SLOCAL samplers are modelled through their output distributions, for an arbitrary scan order. seqProb A l τ σ is the probability that the sequential sampler outputs σ (product formula (10)). The JVV rejection step (§4.2.3) is modelled abstractly: we take μ̂ with multiplicative error δ (Claim 4.5), the ground state, the feasible path σ₀, …, σₙ = σ (Claim 4.6), and the acceptance probabilities (9).

  • SLOCAL→LOCAL simulation via network decomposition (Lemmas 3.1, 4.4, cited from Ghaffari–Kuhn–Maus) is not formalized. Round counts are therefore formalized only as localities.
