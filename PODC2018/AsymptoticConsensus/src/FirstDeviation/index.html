import Papers.PODC2018.AsymptoticConsensus.LowerBounds /-! # The "first deviation parity" algorithm (counterexample to Theorem 4 (⇐) of FNS'18) For two agents in the network model `{H0, H1, H2}` we define an asymptotic consensus algorithm `fd` whose limits are always initial values (`fd_limit`), although exact consensus is not solvable in this model. **Algorithm.** Each agent stores its own initial value, the initial values it knows, a round counter and a decision variable `dec` (initially `none`). In round `t` (1-indexed), agent `i` * keeps `dec` if it is already set; * otherwise, if `i` does not hear the other agent `o` in round `t`, sets `dec := if t odd then x_i else x_o`; * otherwise copies the decision variable of `o` (possibly `none`). The output is `dec` if set, and agent `0`'s initial value (once known) otherwise. **Why it works.** If every round is `H0`, no decision is ever taken and both outputs equal `x 0` from time `1` on. Otherwise let `T + 1` be the first round in which some agent `k` is deaf and `D := if T + 1 odd then x_k else x_o`. In round `T + 1`, `k` decides `D` and `o` copies `none`; in round `T + 2`, `o` either is deaf and decides by parity of `T + 2` (which gives `D` again) or copies `D` from `k`. Decisions never change afterwards. ## Main results * `fd`: the algorithm. * `fd_eventually_const`: in every execution, both outputs are eventually equal to `x 0` or `x 1`. * `fd_solves`: `fd` solves asymptotic consensus in `{H0, H1, H2}`. * `fd_limit`: every limit of `fd` is an initial value. -/ namespace AsymptoticConsensus open Cslib.HeardOf Filter Topology Set variable {V : Type*} /-- The
