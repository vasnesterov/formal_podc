Here we prove that fact for every `t`: the number `σ` of grid points at `ℓ₁`-distance exactly `t` from `p = (x, y)` determines the parity of `x + y`. Explicitly, with `a = min x (2t - x)`, `b = min y (2t - y)` (both in `[0, t]`, `a + b ≡ x + y`): * `a, b < t`, `a + b < t`: `σ = t + 1 + (a + b)` (range `[t+1, 2t]`); * `a, b < t`, `a + b ≥ t`: `σ = 2 (a + b) + 2` (even, range `[2t+2, 4t-2]`); * exactly one of `a, b` (say `a`) equals `t`: `σ = 2t + 1 + 2b` (odd, `≥ 2t+1`), `a + b = t + b`; * `a = b = t`: `σ = 4t`.
