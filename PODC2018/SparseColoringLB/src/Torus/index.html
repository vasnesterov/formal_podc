import Papers.PODC2018.SparseColoringLB.Model /-! # A toroidal triangulation that is not 4-colourable (Fisk) The graph `torus w` (Figure 3 of the paper, up to drawing) has `n = 3w + 1` vertices: three rows `a_0 … a_{w-1}`, `b_0 … b_{w-1}`, `c_0 … c_{w-1}` (vertex `some (i, j)` is row `i`, column `j`) and one extra vertex `a_w` of the first row (`none`). It is the triangulation of the torus made of three triangulated bands between the cyclic rows `a` (length `w + 1`), `b`, `c` (length `w`): * column triangles `a_j b_j c_j`; * between columns `j` and `j + 1`: `a_j a_{j+1}`, `b_j b_{j+1}`, `c_j c_{j+1}`, `b_j a_{j+1}`, `c_j b_{j+1}`, `c_j a_{j+1}`; * around the torus: `b_{w-1} b_0`, `c_{w-1} c_0`, `c_{w-1} b_0`, and `a_w` is adjacent to `a_{w-1}, a_0, b_{w-1}, b_0, c_{w-1}, c_0`. All degrees are `6`, except `deg a_0 = 4` and `deg b_0 = deg c_0 = 7`: exactly two vertices of odd degree, and they are adjacent, so Fisk's theorem (cited by the paper) says that `torus w` is not 4-colourable. We prove this directly (`torus_not_colorable`) by Fisk's parity argument specialised to this "3-row" family, phrased as a transfer argument: the colours `(a_j, b_j, c_j)` of a column form one of 24 *states*; consecutive columns are related by a relation `R` that never leaves one of 6 classes (`stateClass`), while the passage through `a_w` from column `w - 1` to column `0` always changes the class. Both facts are finite checks (`decide`). -/ namespace Podc.SparseColoringLB open SimpleGraph /-- Vertices of `torus w`: `some (i, j)` is row `i ∈ {a, b, c}`, column `j`; `none` is `a_w`. -/ abbrev TV (w : ℕ) := Option (Fin 3 × Fin w) /-- The edges of `torus w`, each listed once (in one direction). -/ def torusRel (w : ℕ) : TV w → TV w → Prop | some (i, j), some (i', j') => (j = j' ∧ i ≠ i') ∨ ((j : ℕ) + 1 = j' ∧ (i' = i ∨ (i = 1 ∧ i' = 0) ∨ (i = 2 ∧ i' = 1) ∨ (i = 2 ∧ i' = 0))) ∨ ((j : ℕ) + 1 = w ∧ (j' : ℕ) = 0 ∧ ((i = 1 ∧ i' = 1) ∨ (i = 2 ∧ i' = 2) ∨ (i = 2 ∧ i' = 1))) | none, some (_, j) => (j : ℕ) + 1 = w ∨ (j : ℕ) = 0 | _, _ => False /-- The toroidal triangulation of Figure 3 with `3w + 1` vertices (two adjacent vertices `b_0`, `c_0` of odd degree `7`, all others of even degree). -/ def torus (w : ℕ) : SimpleGraph (TV w) := SimpleGraph.fromRel (torusRel w) /-- Class of a column state `(a, b, c)` (colours of `a_j, b_j, c_j`);
