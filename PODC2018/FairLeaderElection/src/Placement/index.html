import Papers.PODC2018.FairLeaderElection.Rushing /-! # Placing a coalition with prescribed segment lengths Given `k ≥ 1` segment lengths `g 0, …, g (k-1)` with `∑ (g t + 1) = n` and `g (k-1) ≥ 1`, the coalition `place n k g` puts adversary `t` at position `pos g t = 1 + ∑_{s<t} (g s + 1)`; then the honest segment after adversary `t` has length `g t`, the origin `0` lies in the last segment, and the adversary before adversary `t+1` is adversary `t`. We also provide a "greedy from the end" choice of segment lengths below given caps (`fillGaps`), used for the equally spaced coalition of Theorem 4.2 and the cubic coalition of Theorem 4.3. -/ namespace Podc.FairLeaderElection open Cslib.UniRing open Fin.NatCast Fin.CommRing variable {n : ℕ} [NeZero n] theorem gap_eq_iff {C : Finset (Fin n)} {a : Fin n} (ha : a ∈ C) {g : ℕ} : gap C a = g ↔ a + ((g + 1 : ℕ) : Fin n) ∈ C ∧ ∀ s < g, a + ((s + 1 : ℕ) : Fin n) ∉ C := by constructor · rintro rfl;
