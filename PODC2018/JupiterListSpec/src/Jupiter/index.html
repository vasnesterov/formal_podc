import Papers.PODC2018.JupiterListSpec.System /-! # The Jupiter protocol (Section 4.1, Appendix C) The multi-client Jupiter protocol of Xu, Sun and Li as reviewed in Appendix C. * An operation (`JOp`, Definition 27) is a list operation with its identifier and its context. * A 2D state space (`DSS`, Definition 29) is represented by its set of edges and its current vertex. Every edge is labelled by an operation whose context is the source vertex, so an edge is just a `JOp` (from `op.ctx` to `op.ctx ∪ {op.oid}`). In the state space of client `c` (and in the server's state space for `c`) an edge is in the LOCAL dimension iff its operation was generated by `c`, and in the GLOBAL dimension otherwise. `edgeFrom` returns the (latest added) edge from a vertex in a given dimension. * `xLoop` / `xForm` are `xForm(op, d)` of Algorithm C.4: starting from the vertex matching `op.ctx`, transform `op` along dimension `d` until the current vertex is reached, adding the two transformed edges of every square (Figure 3). * Client (Algorithm C.5): local processing adds a LOCAL edge from the current vertex; remote processing calls `xForm(op, LOCAL)`. Server (Algorithm C.6): `xForm(op, GLOBAL)` in the state space of the sender, appends the transformed operation along the GLOBAL dimension of the state spaces of all other clients, and forwards the transformed operation. -/ namespace Podc.JupiterListSpec variable {n : ℕ} /-- An operation of Jupiter (Definition 27). -/ structure JOp (n : ℕ) where o : LOp (Oid n) oid : Oid n ctx : Finset (Oid n) deriving DecidableEq /-- `op⟨op'⟩` (Definition 27). -/ def JOp.xf (op op' : JOp n) : JOp n := ⟨JupiterListSpec.xf op.o op'.o, op.oid, insert op'.oid op.ctx⟩ /-- A 2D state space: its edges and its current vertex. -/ structure DSS (n : ℕ) where edges : List (JOp n) cur : Finset (Oid n) /-- The edge from vertex `u` along dimension `d` (`true` = LOCAL, i.e. generated by the owner `c`), in the state space owned by `c`. -/ def edgeFrom (c : Fin n) (E : List (JOp n)) (u : Finset (Oid n)) (d : Bool) : Option (JOp n) := E.find? fun e => decide (e.ctx = u) && (decide (e.oid.1 = c) == d) /-- The loop of `xForm(op, d)` (Algorithm C.4, lines 5–19);
