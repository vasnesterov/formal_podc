(PODC 2016) and by the paper: an abstract execution `A = (H, vis)` is a sequence `H` of `do` events with a visibility relation (here on positions in `H`). `Weak A` is the weak list specification `A_weak` (Definition 1) and `Conv A` the convergence property `A_cp`. `Weak.conv` shows that `A_weak ⊆ A_cp`: two `Read`s that see the same list updates return the same list (the paper derives the
