With `t` the resilience: 1. A node that receives a message containing `b` decides `b`. 2. A node `i ≤ t` (0-based) that has received nothing in rounds `1, …, i` decides its input at the beginning of round `i + 1` (i.e. after `i` rounds). 3. A node `i ≤ t` that decided after round `k - 1` (at the end of round `k - 1` or the beginning of round `k`) sends its value to all nodes `i + 1, …, n - 1`, in this order, in round `k`. Orderly crashes are taken with respect to this order (`rank p k q = q`): a crashing node delivers its messages to the nodes `q < m` for some `m`. -/ namespace Podc.EarlyDecidingExpensive.Orderly open
