import Cslib.Computability.Distributed.Byzantine.LockStep.Basic import Mathlib /-! # Synchronous message passing with per-round fault onset (Dolev–Lenzen, PODC 2013, Section 2) The model of *Early-Deciding Consensus is Expensive* (Dolev, Lenzen, PODC 2013): * `n` nodes `V` on a complete network, synchronous rounds `1, 2, …`, authenticated links (the receiver knows the sender), unbounded messages and local computation. * A deterministic algorithm is a CSLib lock-step protocol (`Cslib.Byzantine.LockStep.Protocol`): the message `p` sends to `q` in round `k` and the decision status of `p` are functions of the input of `p` and of its history (the inboxes of rounds `1, …, k - 1`). Decisions are *first* decisions (`DecidesAt`): later changes of the status are ignored, so a decision is final. * An execution (`Execution`) fixes the binary inputs, the set `F` of faulty nodes, for each faulty node the round `fr p` from which on it is faulty (the paper's sets `F_k = {p ∈ F | fr p ≤ k}`, `FaultyAt`), and the messages faulty nodes send (`adv`). Before its fault round a faulty node follows the algorithm. The number of faults is `F.card` (the paper's `f^E = max_k |F_k|`). * Fault classes are predicates on executions: Byzantine (`byzAdm t`: at most `t` faulty nodes), crash (`crashAdm`: in its fault round a node sends a subset of its algorithm messages, then nothing, Definition 4.1) and orderly crash (`orderlyAdm`: the subset is a prefix of an order fixed by the algorithm, Definition 4.4). * `Correct A Adm`: termination, agreement and validity in every admissible execution, for the nodes that are never faulty. `DecidingAt A Adm f D`: in admissible executions with exactly `f` faulty nodes, every never-faulty node decides within `D` rounds (Definition 3.1 with `d(f) = D`). * Message counts: `msgCount A E R` counts the messages sent in rounds `1, …, R` by nodes that are not faulty in the round of sending (the paper's convention: nodes of `F_k` are "faulty" only from round `k` on). The construction `addFaults E S k₀ γ` turns the (honest) nodes of `S` faulty from round `k₀` on, sending `γ`; it does not change anything before round `k₀` (`hist_addFaults_of_lt`). All executions of the lower-bound proofs are built with it. The model is a re-indexing of CSLib's lock-step model: `hist_toScenario` shows that our histories are those of the CSLib scenario in which `F` is the (static) Byzantine set and faulty nodes send the messages they send here. -/ namespace Podc.EarlyDecidingExpensive open Finset /-- A deterministic binary consensus algorithm on the nodes `V` with messages `M`: a CSLib lock-step protocol with binary inputs and outputs. -/ abbrev Algorithm (V M : Type*) := Cslib.Byzantine.LockStep.Protocol V Bool M Bool /-- Local histories: the inboxes of the rounds so far, oldest first. -/ abbrev History (V M : Type*) := Cslib.Byzantine.LockStep.History V M -- CSLib candidate (synchronous executions with per-round fault onset, `addFaults`, counts) /-- An execution: inputs, faulty nodes `F`, the round `fr p` from which on `p ∈ F` is faulty, and the messages `adv k p q` that a faulty `p` sends to `q` in round `k`. -/ structure Execution (V M : Type*) where /-- The binary inputs. -/ input : V → Bool /-- The nodes that are faulty at some point. -/ F : Finset V /-- The round from which on a node of `F` is faulty (irrelevant outside `F`). -/ fr : V → ℕ /-- The message a faulty `p` sends to `q` in round `k`. -/ adv : ℕ → V → V → Option M variable {V M : Type*} namespace Execution /-- `p ∈ F_k`: node `p` is faulty in round `k`. -/ def FaultyAt (E : Execution V M) (k : ℕ) (p : V) : Prop := p ∈ E.F ∧ E.fr p ≤ k instance [DecidableEq V] (E : Execution V M) (k : ℕ) (p : V) : Decidable (E.FaultyAt k p) := by unfold FaultyAt; infer_instance lemma FaultyAt.mono {E : Execution V M} {k k' : ℕ} {p : V} (h : E.FaultyAt k p) (hk : k ≤ k') : E.FaultyAt k' p := ⟨h.1, h.2.trans hk⟩ lemma not_faultyAt_of_not_mem {E : Execution V M} {k : ℕ} {p : V} (h : p ∉ E.F) : ¬ E.FaultyAt k p := fun h' => h h'.1 end Execution variable [DecidableEq V] (A : Algorithm V M) /-- The message `p` sends to `q` in round `k`, given the histories `h` after round `k -
