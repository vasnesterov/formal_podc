import Papers.PODC2013.CubicBitsBA.Correctness /-! # Agreement fails: `n = 7`, `t = 2` (refutes Lemma 5 and Theorem 2) Processes `0, …, 4` are correct, `b₁ = 5` and `b₂ = 6` are Byzantine (`n = 7 > 3t = 6`). Values are `Bool`; the construction is parametrized by `f : Bool` (all values are xor-ed with `f`) so that it works for both choices of the default value `v0 = !f`. With `f = false`: * inputs: `0, 1, 2 ↦ false`, `3, 4 ↦ true`; * round 1: `b₁` sends `false` to the group `A = {0, 1, 2}` and `true` to `3, 4`; `b₂` sends `true` to everybody; * round 2: both Byzantine processes echo the round-1 values "as the receiver saw them": to `i` they report `b₁`'s value as the one `i` received (`false` in `A`, `true` outside), and the correct inputs truthfully. So `b₂` tells `A` that `b₁` proposed `false` and tells `3, 4` that `b₁` proposed `true`; * round 3: both Byzantine processes report no suspicion and echo the round-2 arrays as the receiver saw them. `b₂`'s round-2 equivocation can only be detected at the end of round 3 = `t + 1`, so it is never reported; `b₂` is in the top set of the node `b₁` everywhere. At the node `b₁` the correct children's echoes are `false, false, false, true, true`, and `b₂`'s echo tips the strict majority to `false` in `A` but leaves a tie (→ `⊥`) at `3, 4`. At the root, `A` sees four `false` among seven children and decides `false`; `3, 4` see only three and fall back to `v0 = true`.
