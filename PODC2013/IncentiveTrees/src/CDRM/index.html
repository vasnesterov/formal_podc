import Papers.PODC2013.IncentiveTrees.Basic import Papers.PODC2013.IncentiveTrees.Geometric /-! # Theorem 5: contribution-deterministic reward mechanisms (CDRM) The reward of `p` is `R(x_p, y_p)` where `x_p = C(p)` and `y_p = C(T_p \ {p})`. A function `R` is *successfully contribution-deterministic* if, for `x > 0`, `y ≥ 0`, (i) `0 < ∂R/∂x < 1`, (ii) `0 < ∂R/∂y`, (iii) `φ x < R(x, y) < Φ x`, (iv) `R(x' + x'', y) ≥ R(x', x'' + y) + R(x'', y)`. The paper leaves `R(0, y)` unconstrained; we add right-continuity of `R(·, y)` at `0` (equivalently, by (iii), `R(0, y) = 0`). * `theorem_5`: such a mechanism satisfies nonnegative rewards, budget, CCI, CSI, `φ`-RPC, USA and UGSA; it violates URO **and PO** (the paper's statement "all properties except URO" includes PO, which fails since `R(x, y) < Φ x ≤ x`; Section 4.4 correctly says "except PO/URO"). * `example_i_cd`: the first CDRM example `R(x, y) = (Φ - θ / (1 + x + y)) x` (Algorithm 5) satisfies the hypotheses (non-vacuity). -/ namespace Podc.IncentiveTrees open Set /-- The mechanism
