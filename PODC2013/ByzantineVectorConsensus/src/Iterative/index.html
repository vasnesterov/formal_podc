In round `r + 1`, every correct process `i` obtains (by Component #1 of the Abraham–Amit–Dolev algorithm, used as a black box) a set `B_i[r+1]` of tuples `(p_k, w_k)` with at most one tuple per process (Property 2), with `w_k = v_k[r]` for correct `p_k` (Property 3), such that any two correct processes share at least `n - f` identical tuples (Property 1). It then sets `v_i[r+1]` to the average of one deterministically chosen point of `Γ(Φ(C))` for every `C ⊆ B_i[r+1]` with `|C| = n - f`. We formalize the algorithm on the level of these round exchanges, exactly as the paper's proof does: a `RoundExec` records the adversary's choices (faulty set, inputs, the sets `B`, and the values in the tuples of faulty processes, which may differ between receivers); the states are computed (`RoundExec.state`). Property 2 is built into the representation (`B` is a set of processes and the tuple values are a function of the sender), Property 3 into `recvWith` (tuples of correct senders carry their current state), and Properties 1 and "`|B_i| ≥ n - f`" are the hypotheses `RoundExec.Valid f s` with subset size `s`. **The implementation of Component #1 (reliable broadcast + witnesses, [AAD04]) is not formalized**: Theorem 5 is proved for every execution in which Component #1 delivers sets with Properties 1–3, as in the paper. The subset size `s` is a parameter: `s = n - f` is the paper's Section 3.2 algorithm; the restricted round structures of Section 4 are the instances `s = n - f` (synchronous, `B_i` = all processes) and `s = n - 3f` (asynchronous, `B_i` = the first `n - f` round messages); see `theorem_6_sync`, `theorem_6_async`.
