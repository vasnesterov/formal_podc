import Mathlib /-! # The asynchronous model: routes, walks chosen by the adversary, meetings Dieudonné, Pelc, Villain, *How to meet asynchronously at polynomial cost*, PODC 2013 (arXiv:1301.7119v2), Section 1 ("The model"). * The graph is embedded so that edges are pairwise disjoint segments (the paper uses an embedding in `ℝ³`; any such embedding gives the same meeting relation). We use the embedding of a graph on the node set `V` into `V → ℝ` that sends node `v` to the basis vector `emb v` and the edge `{u, w}` to the segment between `emb u` and `emb w`: two such segments meet only at a common endpoint. `point u w c` is the point at fraction `c ∈ [0, 1]` of the way from `u` to `w`. * A *route* is the sequence of nodes `r 0, r 1, …` visited by the agent (consecutive nodes adjacent, `IsRoute`). `posR r x` is the point at "progress" `x ≥ 0` along the route: `x = i + c` with `c ∈ [0, 1]` is the point at fraction `c` of the `i`-th edge `{r i, r (i+1)}`. * A *walk* (chosen by the adversary) is an increasing sequence of times `τ 0 = 0 < τ 1 < …` and a progress function `p` such that on `[τ i, τ (i+1)]` the progress `p` is continuous, stays in `[i, i+1]`, and `p (τ i) = i`. This is exactly the paper's walk `f` on the route (the paper's `f_i : [t_i, t_{i+1}] → [v_i, v_{i+1}]` is `t ↦ point (r i) (r (i+1)) (p t - i)`): the adversary may stop the agent, move it back and forth inside an edge, and speed it up arbitrarily. The times may accumulate (we do not require `τ i → ∞`); positions are only considered at times `t ≤ τ i`. `τ i` is the time at which the agent completes its `i`-th edge traversal. * Agents with routes `ra`, `rb` and walks `Wa`, `Wb` *meet* at time `t` (`Meet`) if both positions are defined at `t` and equal (a meeting at a node or inside an edge). -/ namespace Podc.AsyncRendezvousPoly open Set /-!
