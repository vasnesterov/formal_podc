import Papers.PODC2013.AsyncRendezvousPoly.Trajectories /-! # Algorithm RV-asynch-poly and the structure of its route Dieudonné, Pelc, Villain, *How to meet asynchronously at polynomial cost*, PODC 2013 (arXiv:1301.7119v2), §3.1–3.2. The agent with modified label `M(x) = (b₁ … b_s)` and start node `v` follows, for `k = 1, 2, …` (iteration `k` of the `repeat` loop), for `i = 1, …, min(k, s)`: the segment `S_i(k)` (two atoms `B(2k, v)` if `bᵢ = 1`, `A(4k, v)` if `bᵢ = 0`), followed by the border `K(k, v)` if `i < min(k, s)` and by the fence `Ω(k, v)` otherwise. Its route is the infinite concatenation of these iterations (`route`). Before the meeting the route of an agent depends only on the graph, its start node and its label (the agent learns nothing else), so it is a fixed sequence of nodes. In Lean, segments are indexed from `0` (`i = 0, …, min(k, s) - 1` is the paper's `i + 1`), and iterations (= pieces/fences) from `1` as in the paper. Index functions (positions in the route, in edge traversals from the start): `iS k` (start of the `k`-th piece `T(k)`), `segS k i` (start of segment `S_{i+1}(k)`), `fS k` (start of the `k`-th fence `Ω(k)` = end of `T(k)`), and `iS (k+1)` (end of `Ω(k)`). -/ namespace Podc.AsyncRendezvousPoly open Traj Finset /-! ### Modified labels -/ /-- The length `|L|` of the binary representation of `L`. -/ def binLen (L : ℕ) : ℕ := (Nat.digits 2 L).length /-- The binary representation of `L`, most significant bit first (`true` = 1). -/ def binDigits (L : ℕ) : List Bool := ((Nat.digits 2 L).map (fun d => decide (d = 1))).reverse /-- The modified label `M(x) = (c₁c₁c₂c₂ … c_r c_r 0 1)` for `x = (c₁ … c_r)` the binary representation of `L`. -/ def modLabel (L : ℕ) : List Bool := (binDigits L).flatMap (fun c => [c, c]) ++ [false, true] /-! ### Infinite concatenation of closed trajectories -/ section InfConcat variable {V : Type*} /-- Offsets of an infinite sequence of blocks. -/ def offs (B : ℕ → Traj V) (t : ℕ) : ℕ := ∑ s ∈ range t, (B s).len /-- The infinite concatenation `B 0 B 1 B 2 …` (of blocks with at least one edge). -/ def infConcat (B : ℕ → Traj V) (i : ℕ) : V := (B (Nat.findGreatest (fun t => offs B t ≤ i) i)).f (i - offs B (Nat.findGreatest (fun t => offs B t ≤ i) i)) variable {B : ℕ → Traj V} theorem offs_succ (t : ℕ) : offs B (t + 1) = offs B t + (B t).len := by simp [offs, sum_range_succ] theorem le_offs (hpos : ∀ t, 1 ≤ (B t).len) (t : ℕ) : t ≤ offs B t := by induction t with | zero => simp [offs] | succ t ih => rw [offs_succ];
