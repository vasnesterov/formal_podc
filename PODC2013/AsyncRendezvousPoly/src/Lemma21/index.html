If the trajectory `S` of an exploration procedure that explores all graphs of size `≤ 2m` is *clean* (all its nodes have degree `≤ m - 1`) and has fewer than `m` nodes, then we build a graph `H` of size `< 2m` in which the procedure follows the same trajectory, but which has extra nodes attached to the *free* ports of `S` (ports never used by the trajectory). These extra nodes are not visited, a contradiction. The construction (`Lemma21.H`): node set `X ⊕ Fin d`, where `X` is the set of nodes of `S` and `d` the maximal number of free ports at a node of `X`. Occupied ports keep their connections from `G`; the `c`-th free port of `x ∈ X` (in an arbitrary fixed enumeration) leads to the extra node `c`, whose ports enumerate (arbitrarily) the nodes `x` with
