Every node holds at most `N` keys (pairwise distinct). The key of global rank `r` must end up at node `out r` (for Problem 4.1: the node with index `⌊r / n⌋`). The algorithm takes 32 rounds: * round 0 (Step 2): every node selects every `s`-th of its keys (Step 1) and sends its `i`-th selected key to member `i` of group 0; * rounds 1–6 (Step 3): group 0 sorts the samples with Algorithm 3; * round 7 (Step 4): every `N`-th sample (in sorted order) is a delimiter; its holder broadcasts it; * local (Step 5): every node splits its keys into `s` buckets by the delimiters; * rounds 8–22 (Step 6): the keys of bucket `j` are spread evenly over the members of group `j` using the routing algorithm (Theorem 3.7, as a subroutine on a virtual clique of `4N` nodes, since a node may receive up to `3N` keys); * rounds 23–28 (Step 7): every group sorts its keys with Algorithm 3; * round 29: every node announces how many keys it holds; * rounds 30–31 (Step 8): every
