For an undirected graph `G` this is `G.Adj` (`hd_adj_eq_edist` below identifies the hop distance with Mathlib's `SimpleGraph.edist`); for a directed graph it gives Section 4.4 of the paper. Node identifiers are the elements of `V`, which carries a linear order (the identifier order used for tie-breaking). `hd E s v` is the number of hops of a shortest `E`-walk from `s` to `v` (`⊤` if
