This is the set version of the paper's `top_k(L)` ("the list of the first `k` elements of `L`, or `L` if `|L| < k`") for a lexicographically sorted list `L` without duplicates; `sort_topk` says that sorting `topk k F` gives exactly the first `k` entries of the sorted list of `F`. -- CSLib candidate (generic order theory on finsets). -/ namespace Podc.SourceDetectionCongest open Finset variable {α : Type*} [LinearOrder α] /-- The `k` smallest elements of `F`. -/ def topk (k : ℕ) (F : Finset α) : Finset α := F.filter fun x => #(F.filter (· < x)) < k variable {k k' : ℕ} {F : Finset α} {x y : α} lemma mem_topk : x ∈ topk k F ↔ x ∈ F ∧ #(F.filter (· < x)) < k := mem_filter lemma topk_subset : topk k F ⊆ F := filter_subset _ _ @[simp] lemma topk_zero : topk 0 F = ∅ := by ext x;
