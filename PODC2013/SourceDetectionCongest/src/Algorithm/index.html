import Papers.PODC2013.SourceDetectionCongest.Basic /-! # Algorithm 1: pipelined Bellman–Ford Synchronous rounds on the communication relation `E` (`E u v`: `u` can send to `v`). In every round each node `v` * (Lines 7–10) sends the `β` lexicographically smallest entries `(h_s, s)` of its list `L_v` that are not yet marked as sent to all its out-neighbours, and marks them as sent (the paper's algorithm is `β = 1`: "the smallest unsent pair"); * (Lines 11–15) for every received pair `(h_s, s)` such that `L_v` has no entry `(h', s)` with `h' ≤ h_s + 1`, replaces the entry for `s` by `(h_s + 1, s)` and marks it unsent; * (Line 16, optional) deletes all entries with distance `> cap`. The journal pseudocode places Line 16 *after* the loop (`cap = ⊤` here, the deletion is done by `output`); a per-round deletion (as one may also read the pseudocode) is `cap = h`. Both variants are covered. `L_v` has at most one entry per source, so we store it as a function `est : V → ℕ∞` (`est s = ⊤`: no entry for `s`), together with the flags `sent : V → Bool`. Processing the received pairs one by one (Lines 11–15) gives the same result as taking, for every `s`, the minimum received distance (`recv`), which is what `step` does. -/ namespace Podc.SourceDetectionCongest open Finset variable {V : Type*} [Fintype V] [LinearOrder V] /-- Local state of a node: its list `L_v` (as `est`, `⊤` = no entry) and the `sent_v` flags. -/ structure State (V : Type*) where /-- `est s = h` iff `(h, s) ∈ L_v`; The flag of `s` is reset iff the entry of `s` improved; otherwise it is set if the entry of `s` was sent in this round. Entries with distance `> cap` are deleted (Line 16). -/ noncomputable def step (β : ℕ) (cap : ℕ∞) (st : State V) (inbox : V → Finset (ℕ ×ₗ V)) : State V where est s := if cap < min (st.est s) (recv inbox s) then ⊤ else min (st.est s) (recv inbox s) sent s := if recv inbox s < st.est s then false else st.sent s || decide (toLex ((st.est s).toNat, s) ∈ msg β st) /-- Initial state (Lines 1–5): `L_v = {(0, v)}` if `v ∈ S`, else `L_v = ∅`. -/ def init (S : Finset V) (v : V) : State V where est s := if s = v ∧ v ∈ S then 0 else ⊤ sent _ := false variable (E : V → V → Prop) [DecidableRel E] (S : Finset V) (β : ℕ) (cap : ℕ∞) /-- The state of every node after `t` rounds (`L_v^t` of Definition 4.2 is `(run … t v).entries`).
