import Papers.PODC2013.MessageAdversariesVsFD.Model /-! # Block simulation of synchronous rounds A generic simulation theorem used for Theorem 6 of Raynal–Stainer (Appendix A.3): every round `R` of an algorithm `A` designed for a "target" adversary is simulated by a block of `k ≥ 1` rounds of the "host" adversary (rounds `k R, …, k R + k - 1`, in our `0`-based numbering). During a block the processes flood (full information) the states they had at the beginning of the block; at the end of the block process `i` applies `A`'s transition to the states it knows of the processes `j` allowed by a filter `allow R j i` known to everybody (`allow = ⊤`: plain flooding; the PAIRS simulation of Part 4 discards the messages not exchanged by the pair of the round). The simulated (induced) pattern is `blockPat k allow p`: `j → i` in simulated round `R` iff `allow R j i` and there is a journey from `j` to `i` inside block `R`. The main result `solvable_of_blockPat`: if the induced pattern of every host pattern is in the target adversary, then every task solvable under the target adversary is solvable under the host adversary (with the strong semantics `Solvable`: every process outputs). -/ namespace Podc.MessageAdversariesVsFD open Cslib.HeardOf (Graph Hears StepFn conf next msgs) open Cslib.DynNet (Journey) variable {P X Y : Type} /-- The pattern induced by blocks of `k` rounds of `p` with filter `allow`: in simulated round `R` (`0`-based), `i` receives the message of `j` iff `allow R j i` and some journey of `p` leads from `j` at time `k R` to `i` at time `k R + k`. -/ def blockPat (k : ℕ) (allow : ℕ → Graph P) (p : ℕ → Graph P) : ℕ → Graph P := fun R j i => allow R j i ∧ Journey p (k * R) j (k * R + k) i namespace BlockSim variable {σ : Type} /-- Local state of the simulating (host) algorithm: the current host round, the identity of the process, and the simulated states (at the beginning of the current block) it knows. -/ structure St (P σ : Type) where /-- Number of host rounds executed so far. -/ time : ℕ /-- The identity of the process. -/ me : P /-- The known simulated states of the current block (`none`: unknown). -/ known : P → Option σ open Classical in /-- Union of the knowledge carried by the received messages. -/ noncomputable def merge (M : P → Option (St P σ)) (j : P) : Option σ := if h : ∃ v, ∃ l m, M l = some m ∧ m.known j = some v then some (Classical.choose h) else none open Classical in /-- One host round of process `i` receiving the host states `M` (`M i` is its own state): merge the received knowledge;
