import Papers.PODC2013.MessageAdversariesVsFD.Async import Papers.PODC2015.WeakestFDEventualConsistency.RunTools /-! # Theorem 1, asynchronous side: `AMP_{n,n-1}[fd : ∅]` solves exactly the local tasks Raynal–Stainer (PODC 2013), Theorem 1 states that `SMP_n[adv : ∞]` and `AMP_{n,n-1}[fd : ∅]` solve the same tasks. Both sides are characterized by locality (`Task.IsLocal`: every process can compute its output from its own input). This file proves the asynchronous side, `amp_solvable_iff_local`. * `←`: every process outputs `f i (x i)` at each of its steps. * `→` (the paper's argument "a process cannot distinguish a run where the others crashed initially from one where their messages are delayed", made precise): we use explicit schedules where process `i` steps at the global times `slot i u = n * u + idx i`. At its odd local times `2a + 1` it receives its own message sent at its local time `a`; at local times `4v` it takes a time-out; in the failure-free run with parameter `N` it receives at local time `4(s + N) + 2` the message of another process sent at global time `s`. - `soloRun x i`: all processes but `i` crash at time `0`. By solvability, `i` outputs; by indistinguishability (`sim2`), its output only depends on `x i`; this defines `f`. - `mergedRun x N`: failure-free; up to time `N` every process `i` behaves exactly as in its solo run (messages of other processes are only received after time `N`). With `N` beyond all solo decision times, every process outputs its solo value, and validity of this run gives an output vector `O ∈ Δ x` with `O i = f i (x i)`. -/ namespace
