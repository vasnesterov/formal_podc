import Papers.PODC2013.MessageAdversariesVsFD.Model /-! # Tasks in `ARW_{n,n-1}[fd : Ω]` Raynal–Stainer (PODC 2013), Sections 2.3 and 2.4: asynchronous processes communicating through single-writer multi-reader atomic registers, where up to `n - 1` processes may crash, enriched with the eventual leader failure detector `Ω`. * Every process `p` owns a bank of atomic registers indexed by `K` (register `k` holds values of type `V k`, initially `Alg.v₀ k`); only `p` writes them, everybody reads them. * A process is a deterministic state machine (`Alg.next`); one atomic step (`Act`) is a write to one of its own registers, a read of one register of any process, a query of its `Ω` module, or a decision `decide y` (the *first* decision is the value computed by the process; it may keep taking steps afterwards, e.g. to help others). * An execution is given by the input vector, an infinite schedule `σ : ℕ → P` (`σ t` takes the atomic step number `t`) and an `Ω` history `H : P → ℕ → P` (`H p t` is the output of `p`'s `Ω` module if `p` queries it at time `t`). A process is correct iff it takes infinitely many steps; with finitely many processes some process is correct, so any number `≤ n - 1` of crashes is allowed (wait-freedom). * `Ω` (`OmegaValid`): there are a correct process `ℓ` and a time after which the `Ω` modules of all correct processes output `ℓ`; before that time, and for faulty processes, outputs are arbitrary. * `Alg.Solves T` (Section 2.4 semantics): for every valid input vector, schedule and valid `Ω` history, every correct process decides, and at every time the decided values are valid (`Task.Valid`; decisions are irrevocable, so
