import Mathlib /-! # The multi-agent rotor-router with delayed deployments Klasing, Kosowski, Pająk, Sauerwald, *The Multi-Agent Rotor-Router on the Ring: A Deterministic Alternative to Parallel Random Walks*, PODC 2013 (full version hal-00735113v2), Sections 1.3 and 2.1. * A `RotorGraph` is a finite set of nodes; node `v` has `deg v ≥ 1` outgoing arcs arranged in the fixed cyclic order `port v 0, …, port v (deg v - 1)` (the paper's `ρ_v`). Multi-arcs and loops are allowed; the paper's setting (the directed symmetric version of an undirected graph) is a special case. * A configuration (`Config`) is the number of (indistinguishable) agents on each node and the port pointer of each node (a cyclic position, read modulo `deg v`). * Rounds are synchronous. In a round with delays `d`, node `v` keeps `min (pos v) (d v)` agents (the stopped ones) and releases the others one by one: the `j`-th released agent leaves along the arc at cyclic position `ptr v + j`, and the pointer advances by the number of released agents (`step`). A delayed deployment `D` gives the delays `D t` of every round `t ≥ 1`; the undelayed system `R[k]` is `D = 0` (`undelayed`). * `visits c₀ D t v` is the paper's `n_v^D(t)`: the agents placed on `v` initially plus the number of arrivals at `v` in rounds `1, …, t` (equation (4) of the paper). The main technical fact (`visits_eq_visitsOf`) is the paper's description of the system by cumulative exit counts: the `j`-th exit from `v` uses the arc at position `ptr₀ v + j`, so the visits are a monotone function of the vector of cumulative exits. -/ open Finset namespace Podc.RotorRouterRing /-- A directed graph with a fixed cyclic order of the outgoing arcs of every node. -/ structure
