The following invariant of the undelayed system holds for every initialization and needs no agent identities: between two consecutive occupied nodes, the empty nodes read `R…R U…U L…L`, where `R` (`L`) is a visited node whose pointer points clockwise (counter-clockwise) and `U` is an unvisited node. Equivalently (`pattern_invariant`), for two adjacent empty nodes `u, u + 1` the patterns `(L, R)`, `(L, U)` and `(U, R)` never occur.
