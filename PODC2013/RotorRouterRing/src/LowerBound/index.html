import Papers.PODC2013.RotorRouterRing.Ring /-! # Theorem 3.7: a lower bound `Ω((n/k)²)` on the cover time for every initial placement Klasing, Kosowski, Pająk, Sauerwald, PODC 2013, Theorem 3.7: for any initial locations of the `k` agents there is a pointer initialization of the ring for which the cover time is `Ω((n/k)²)`. The paper's proof relies on the agent-domain Lemmas 2.5/2.6, whose proofs are sketchy. We give a different, self-contained proof with explicit constants, based on the potential identity `potential_run` (a rotor-router analogue of the optional stopping argument for random walks): * all pointers point **away from a node `v`** (`awayPtr v`), so the pointer part of the potential of any radially non-increasing `h` can only grow; * *hit lemma* (`hit_lemma`, parabola `(R - d)²`): if no agent starts within distance `R` of `v`, then before `v` is reached the agents must spend at least `R²` agent-rounds within distance `R` of `v`; * *scale step* (`scale_step`, a smooth bump of radius `2R`): the number of agents within distance `R` of `v` at time `s` is at most `2 N_{2R}(0) + (1/R²) Σ_{s' < s} N_{2R}(s')`; * iterating the scale step over the radii `2^m R₀` (`multiscale`) and choosing `v` by counting (`exists_good_center`) so that few agents start near `v` at every scale gives `n² < 8192 k² T` for every `T` at which the ring is covered (`theorem_3_7`).
