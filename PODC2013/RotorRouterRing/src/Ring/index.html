A pointer `p` points to `v + 1` iff `p` is even. This file provides * the ring distance `ringDist v x` and its behaviour on neighbours; * the **potential identity** (`potential_run`): for any `h : ZMod n → ℤ`, `Φ_h(c) = 2 Σ_u pos(u) h(u) + Σ_v h(pointer target of v)` changes in every round by `Σ_v (agents released from v) · (h(v+1) + h(v-1) - 2 h(v))`, so `Φ_h(run t) = Φ_h(c₀) + Σ_v e_v(t) · Δh(v)`.
