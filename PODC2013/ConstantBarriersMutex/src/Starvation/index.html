Proof (following the paper). Suppose `p` is starved. Let `S` be the set of processes that stay in their entry section forever. For `q ∈ S`, the nodes on `q`'s path that hold `q` only disappear after `q`'s barrier (`q` writes no more), and its leaf holds `q` forever; so the highest level `levF q t` holding `q` is non-decreasing and eventually constant (Claim 1). Take a time `T*` after which all these levels are constant, and `p₀ ∈ S` with the smallest level `k`. * `k = 0`: the root holds `p₀` from `p₀`'s barrier on. By the waiting section (statement 25, `waiting_entry`), some process `g` enters the critical section after `p₀`'s barrier; its exit section reads the root and promotes `p₀` (`enters_of_read`) — a contradiction. * `k ≥ 1`: the parent of `p₀`'s level-`k` node holds some `q ≠ p₀` at `T*`; let `t₀` be the last write to it before `T*`, by `q`. By TSO (writes are performed in program order), `p₀`'s write to its level-`k` node was performed before `t₀`, and that node holds `p₀` from then on. `q ∉ S` (its level would be `≤ k − 1`), so `q` enters the critical section after `t₀`, reads `p₀`'s level-`k` node (a child of `q`'s level-`(k−1)` node) in its exit section and promotes `p₀` — a contradiction (Claim 2). -/ namespace Podc.ConstantBarriersMutex variable {h : ℕ} open Classical namespace Run variable (r : Run h) /-- `q` stays in its entry section from some time on. -/ def Stuck (q : Proc h) : Prop := ∃ T, ∀ t ≥ T, ((r.s t).pc q).Entry /-- The node at level `l` on `q`'s path holds `q` at time `t`. -/ def hold (q : Proc h) (t l : ℕ) : Prop := (r.s t).mem.node (anc q l) = some q /-- The highest level (smallest number) holding `q`, `h + 1` if none. -/ noncomputable def levF (q : Proc h) (t : ℕ) : ℕ := if hx : ∃ l, l ≤ h ∧ r.hold q t l then Nat.find hx else h + 1 lemma levF_le {q : Proc h} {t l : ℕ} (hl : l ≤ h) (hh : r.hold q t l) : r.levF q t ≤ l := by unfold levF;
