import Mathlib /-! # Attiya, Hendler, Levy (PODC 2013): Algorithm 1 under Total Store Ordering — the model Hagit Attiya, Danny Hendler, Smadar Levy. *An O(1)-Barriers Optimal RMRs Mutual Exclusion Algorithm.* PODC 2013 (extended abstract). ``` 1 shared T : binary tree with leaves L_0 … L_{n−1}, nodes init −1 3 shared promQ : queue of int, init ∅ 5 shared apply : array [0..n−1] of boolean init false 7 shared signal : array [0..n−1] of boolean 9 shared inPromQ: array [0..n−1] of boolean init false 11 shared lock : int init −1 13 shared exits : int init 0 16 Entry(): 17 signal[p] ← false 18 apply[p] ← true 19 foreach node n on the path from L_p to the root do n ← p 22 Barrier 23 if CAS(lock, −1, p) ≠ −1 then 24 e ← exits 25 await (exits − e ≥ 2) ∨ lock ∈ {p, −1} 26 if CAS(lock, −1, p) ≠ −1 then 27 await signal[p] 30 Exit(): 31 apply[p] ← false 32 exits ← exits + 1 33 foreach node n on the path from the root to L_p's parent do 34 q1 ← n, q2 ← n.left, q3 ← n.right 35 foreach q ∈ {q1, q2, q3} \ {−1, p} do 36 if apply[q] ∧ ¬inPromQ[q] then 37 promQ.enqueue(q) 38 inPromQ[q] ← true 42 if promQ.isEmpty() then 43 lock ← −1 44 else 45 next ← promQ.dequeue() 46 inPromQ[next] ← false 47 lock ← next 48 signal[next] ← true 50 Barrier ``` ## Model (Section 3 of the paper) * `n = 2^h` processes `Fin (2^h)`; the tree is the complete binary tree in heap numbering (root `1`, children of `v` are `2v`, `2v+1`, leaf of `p` is `2^h + p`); `anc p l` is the node at level `l` (root = level 0, leaves = level `h`) on the path of `p`. A node holds `none` (= `−1`) or a process id; only process `p` ever writes `p`. * **TSO** (the paper's Section 3, after Park and Dill): every process has a FIFO store buffer `buf p`. A write is *issued* by appending it to the buffer and *performed* when it leaves the buffer (event `flush p`, chosen by the adversary at any time). A read returns the value of the most recent write to that variable in the reader's own buffer, if any, and the memory value otherwise (`Mem.view`). A barrier step with a non-empty buffer performs the oldest buffered write (so a barrier completes after the buffer is drained). A CAS first performs all buffered writes and then compares-and-swaps atomically on memory. * Each step of a process performs one shared-memory access (or a local step). The `foreach` of statement 35 visits the distinct values among `q1, q2, q3` (other than `−1, p`) in this order. The queue `promQ` is a single shared variable holding a list; `enqueue`/`dequeue` read it (in the process's view) and issue a write of the new list in one step, and `exits ← exits + 1` reads and issues the write in one step (in all three cases only the lock holder accesses the variable, so this does not restrict the behaviour of the algorithm; see `README.md`). * The critical section is one local step (`cs → x31`). The remainder section is `rem`; a step of a process in `rem` starts a passage by issuing statement 17. * `ent` is a ghost counter of critical-section entries (never read by the algorithm). -/
