No bound on the local variables is needed: the levels are ranked by `h − 1 − l` and the candidate lists by their length. * `rkE` ranks the program counters of the entry section; `μ rkE s p` drops at every step of `p` as long as `lock = p` (statement 25 then exits) and `signal[p]` is set (statement 27). -/ namespace Podc.ConstantBarriersMutex variable {h : ℕ} namespace Prog /-- Rank of the program counters of the critical and exit sections (and statement 50). -/ def rkX : PC h → ℕ | .cs => 17 * h + 10 | .x31 => 17 * h + 9 | .x32 => 17 * h + 8 | .x34 l j acc => 7 + 17 * (h - 1 - l) + 4 * acc.length + 5 * (3 - min j 2) + 1 | .x35 l cands => 7 + 17 * (h - 1 - l) + 4 * cands.length + 1 | .x36 l _ rest => 7 + 17 * (h - 1 - l) + 4 * rest.length + 4 | .x37 l _ rest => 7 + 17 * (h - 1 - l) + 4 * rest.length + 3 | .x38 l _ rest => 7 + 17 * (h - 1 - l) + 4 * rest.length + 2 | .x42 => 6 | .x43 => 5 | .x45 => 5 | .x46 _ => 4 | .x47 _ => 3 | .x48 _ => 2 | .x50 _ => 1 | _ => 0 /-- Rank of the program counters of the entry section. -/ def rkE : PC h → ℕ | .e18 => h + 9 | .e19 l => l + 8 | .e22 => 7 | .e23 => 6 | .e24 => 5 | .e25a _ => 4 | .e25b _ => 3 | .e26 => 2 | .e27 => 1 | _ => 0 /-- The measure of process `q`: twice the rank of its program counter plus the length of its store buffer. -/ def μ (rk : PC h → ℕ) (s : Cfg h) (q : Proc h) : ℕ := 2 * rk (s.pc q) + (s.buf q).length lemma addCand_length (p : Proc h) (acc : List (Proc h)) (o : Option (Proc h)) : (addCand p acc o).length ≤ acc.length + 1 := by cases o with | none => simp [addCand] | some q => simp only [addCand];
