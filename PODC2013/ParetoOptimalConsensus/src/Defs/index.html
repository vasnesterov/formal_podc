Consensus is the case `k = 1` of nonuniform `k`-set consensus (`SolvesSetConsensus 1 t bin`), with binary inputs `bin = {0, 1}`. This file adds: * `Knows`: knowledge `K_i φ` (Definition 2) in the system of a full-information protocol: `φ` holds in every admissible run in which `i` is alive with the same view (for
