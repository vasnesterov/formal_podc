import Papers.PODC2013.ParetoOptimalConsensus.Defs /-! # Unbeatable consensus: Lemma 2, Lemma 3, Theorem 2 (§3) * **Lemma 2** (`lemma2`): if `Q ⪰ P_a` solves consensus, every live process decides `a` in `Q` at the first time it knows `∃a`. * The run of a hidden path (`exists_run_of_hiddenPath`, Lemma 9 of the paper for `c = 1`): if there is a hidden path w.r.t. `⟨i, m⟩`, some run with the same view for `i` has a correct process that knows `∃a` at `m`, and `i` correct. * **Lemma 3** (`lemma3`): `K_i(never-known(∃a))` iff `¬K_i∃a` and there is no hidden path. * **Theorem 2** (`theorem2`): `Opt0` (more generally `Opt_a`, `a ∈ {0, 1}`) is an unbeatable consensus protocol. The paper states everything for `a = 0`; the case `a = 1` (the protocol `Opt1` of §3.1) is the same proof with the values swapped, and is used for majority consensus with `n = 2`. -/ namespace
