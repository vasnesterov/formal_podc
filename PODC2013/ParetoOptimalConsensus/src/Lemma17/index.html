import Papers.PODC2013.ParetoOptimalConsensus.Lemma17Runs /-! # Lemma 17 (no earlier decisions when `¬K_i ∃0`, Appendix C) Let `Q ⪰ U-P0` solve uniform consensus, `0 < t < n`. If there is a hidden path w.r.t. `⟨i, m⟩` and `¬K_i ∃0` at `m`, then `i` does not decide at `m`. Proof as in the paper, with the runs of `Lemma17Runs.lean` (`z = b M` is the hidden node at `m - 1 = M`, `j = b (M + 1)` the hidden node at `m`, which reached `⟨i, m⟩`): * `F⟨i, m⟩ < t`: in `r'`, `z` crashes in round `m` reaching everybody but `i`, and `i` crashes silently in round `m + 1`; `j` knows `∃correct(0)` at `m + 1`. In `r''` (indistinguishable to `j` at `m + 1`) `z` survives round `m`, and decides `0` by Lemma 15, Part 2 (Lemma 14, Part 2 if `m = 1`). So `j` decides `0`, and `i` cannot decide `1`. * `F⟨i, m⟩ = t`: four runs `r' ~_j r'' ~_z r''' ~_j r''''`. In `r'''` the node `⟨i, m - 1⟩` has seen `⟨b (m - 2), m - 2⟩` (or `i` has input `0` if `m = 1`); in `r''''`, where `i` is correct, `z` decides `0` by Lemma 15, Part 1 (Lemma 14, Part 1 if `m = 1`),
