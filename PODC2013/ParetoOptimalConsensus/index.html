Pareto-optimal (unbeatable) consensus — PODC 2013

Armando Castañeda, Yannai A. Gonczarowski, Yoram Moses. Brief announcement: Pareto optimal solutions to consensus and set consensus. PODC 2013, pp. 113–115. Formalized version: the full version, arXiv 1311.6902 v1, Good, Better, Best! — Unbeatable Protocols for Consensus and Set Consensus; numbering follows it.

arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. The main results hold: Opt0 is an unbeatable consensus protocol (Thm. 2), OptMaj is unbeatable for t > 0 (Thm. 3), Opt_min-k is unbeatable (Thm. 4), and U-Opt0 is an unbeatable uniform consensus protocol deciding by f + 1 / f + 2 (Thm. 5). Saving them takes a new inner induction for Lemma 15, the core of Theorem 5, and one added condition each for Lemma 10 (the core of the k-set part; the same lemma as Lemma 1 of the authors' PODC 2016 paper), Lemma 6 and Corollary 1 (HMW's P0opt is beatable, which needs t ≥ 2). The uniform k-set protocol U-PROT_min-k (Thm. 6) was not formalized, so this verdict does not cover it.

Mistakes in the paper

🔧 Lemma 10 (the core of the k-set part)

Lemma 10 is false as stated: with n = 6, k = 2, t = 1, V = {0, 1, 2}, a 2-set consensus protocol in which low processes decide at once can make process 0 decide 2 at time 1 even though all five conditions hold for it with v = 0 (lemma10_false).

Impact. Lemma 11 and Theorem 4 stand: the proof goes through with an extra hypothesis that holds wherever Lemma 10 is used (lemma11, theorem4).

Details

This is Lemma 1 of the authors' PODC 2016 paper, with the same five conditions. The "changes" in the proof suppress messages carrying v to j_b, which may need more than t crashes. The counterexample and the repair are in UnbeatableSetConsensus. (lemma10_false, theorem4)

Repair

Add the hypothesis "every process alive and low at m − 1 crashes in round m". (Podc.UnbeatableSetConsensus.lemma1)

🔧 Lemma 6 when d = t (missing hypothesis)

Condition (b), "K_i(K_j ∃v held at m − 1) for at least t − d processes j", holds vacuously when i knows of d = t failures, even if v occurs nowhere, so Lemma 6 is false then (lemma6_literal_false).

Impact. Recoverable from its proof: the proof sketch counts "processes knowing ∃0, including i itself", so it assumes K_i ∃v. We prove Lemma 6 with "K_i ∃v and ((a) or (b))" (lemma6). All uses in the paper are consistent with this version.

Details

Example: n = 3, t = 1, all inputs 1, process 2 crashes in round 1 sending nothing. At time 1, process 0 knows of one failure, so (b) holds for v = 0, but K_0 ∃correct(0) is false. The remark on time t + 1 after the lemma repeats the error. (lemma6_literal_false; repaired: lemma6)

🔧 Corollary 1 ("P0opt of [HMW] is not unbeatable") for t ≤ 1

Corollary 1 holds only for t ≥ 2 (or n ≤ t + 1): for t ≤ 1 (and n ≥ 3), P0opt makes exactly the same decisions as Opt0, so it is unbeatable by Theorem 2 (p0opt_sameDecisions, p0opt_unbeatable).

Impact. One condition on t saves it: the paper's own example ("one failure seen in each of the first two rounds") needs t ≥ 2. As a refutation of HMW's general claim, the corollary is correct (corollary1).

Details

We read P0opt as the paper describes it: decide 0 on K_i ∃0; decide 1 after a round in which no new failure became known. (corollary1; for t ≤ 1: p0opt_sameDecisions, p0opt_unbeatable)

✏️ Slips

  • Lemma 15, last case: "j fails at (r', m) before sending any messages" must mean that j's round-m + 1 message reaches only i, and "known by ⟨i, m⟩ to fail" should read ⟨i, m + 1⟩.

  • Contribution 3 (§1) says "P0opt, which was claimed to be beatable is not unbeatable"; it should say "claimed to be unbeatable".

Typos

  • Two different results are numbered "Corollary 1" (§3 and Appendix C).

Proof gaps in true statements (2)Lemma 15 · Theorem 2

🛠️ Lemma 15 (inner induction)

The inner induction on |C_i \ Z_i| does not decrease in Case II: the new process j does not see ⟨k, m⟩ and may consider more processes possibly alive, so C_j can be larger than C_i.

Impact. Statement true; proved with a different induction (lemma15_part1, lemma15_part2).

Details

The induction hypothesis is also applied to j without checking that j knows ∃0 for the first time at m and does not know ∃correct(0) at m. The base case needs z ∈ C_i argued. The counting argument for Part 1 ("fewer Case II than Case I invocations") is not needed.

Repair

We prove Lemma 15 by an induction on n − |Z_i|. Case II followed by Case I becomes one step x ~_i x' ~_j x'': in x'', k has received z's message, Z_i has grown by k, and the induction hypothesis is applied to i itself. The number of failures in these runs never exceeds F⟨i, m+1⟩ + 1 ≤ t. The base case becomes "⟨z, m⟩ hidden" (Case C). (lemma15_part1, lemma15_part2, ic, ic_caseII)

🔧 Theorem 2 (derivation in §3)

Theorem 2's proof says a process deciding 1 must know never-known(∃0), but by Agreement this is only a precondition for correct deciders.

Impact. Statement true (theorem2).

Repair

The proof works by making i correct in the run that contains the hidden path (exists_run_of_hiddenPath).

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous message passing, crash failures, at most t crashes. Theorem 5 and the uniform lemmas assume t < n, as in the paper's model. A run (adversary) is CSLib's SyncCrash.Run: inputs, crash round, and the set reached in the crashing round. The model, views and hidden nodes are those of the companion formalization Papers/PODC2016/UnbeatableSetConsensus (same authors, same model), which this folder imports.

  • Full-information protocols: a protocol is a decision rule that depends only on the view (SameView, i.e. CSLib's FIIndist). A process decides at the first time its rule fires while it is alive. The companion's theorem1_lockStep shows that this covers all deterministic protocols (Coan).

  • Consensus is nonuniform 1-set consensus with inputs {0, 1}. Uniform consensus requires that all deciders, faulty ones included, agree. Unbeatability (Def. 1): P solves the problem, and every solution Q with Q ⪰ P satisfies P ⪰ Q. Domination compares decision times per process and per adversary.

  • Knowledge K_i φ (Def. 2) is truth in all admissible runs where i is alive at m with the same view. K_i ∃v is "v has been seen" (Lemma 1/KoP via decided_mem_vals). K_i(Maj = v) is characterized explicitly (knows_maj_iff). ∃correct(v) means "some correct process knows ∃v at time m".

  • No randomness.

Lemma 17, case F⟨i, m⟩ = t: it suffices that only z carries 0. The paper makes every hidden process at m − 1 carry it.

Lemma 2: the proof needs P0 to decide at the first time K_i ∃0 holds, which is true because first knowledge happens by time f + 1 ≤ t + 1.

Trust. No sorry. All theorems in the table use only the axioms propext, Classical.choice and Quot.sound.
