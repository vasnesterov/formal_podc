import Papers.PODC2013.TMObservationalRefinement.Sufficiency /-! # Necessity of the opacity relation, for refinement with respect to traces (Section 7, repaired) Theorem 24 of the paper (observational refinement with respect to *states* implies the opacity relation) is false. Its repair, as in the journal version (JACM 2017, Section 7.1), is necessity from observational refinement with respect to *traces* (Definition 15). * `TraceNec.opac_of_rt`: two histories with the same per-thread projections, the second preserving the real-time order of the first (`RT`), are related by `⊑` (Definition 4). * `trace_necessity`: `H_C ⊑_trace H_A ⟹ H_C ⊑ H_A` (all histories, pending ones included); `trace_necessity_complete`: the version for complete histories. * `theorem_16_repaired`: for transactional systems, `H_C ⊑ H_A ⟺ H_C ⊑_trace H_A`. The proof follows Lemma 7.1 / Figure 15 of the journal version, simplified for trace observation: for `H ∈ H_C` we build a program `P_H` whose thread `t` executes, for each of its transactions in `H|t`, an atomic block with exactly the calls of that transaction (parameters taken from `H`), preceded and followed by non-transactional *marker* assignments `x := v` with values unique in the trace. A trace `τ` of `P_H` with `history τ = H` exists; refinement gives `τ' ∼ τ` with `history τ' ∈ H_A`. Per-thread equality gives the per-thread projections of `history τ'`, and the markers, being non-transactional, are ordered in `τ'` as in `τ`; this transfers the real-time order. -/ namespace Podc.TMObservationalRefinement open IKind Act Lang CmdClass TState namespace TraceNec variable {T LV GV O M BE IE C : Type} [Lang T LV GV BE IE C] /-!
