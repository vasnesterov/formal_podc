import Papers.PODC2013.TMObservationalRefinement.Theorem24 /-! # The Theorem 24 counterexample needs the literal Figure 2 `theorem_24_false` uses the trace sets of Figure 2 *as printed* (`Tr`). There, the trace of the body `C` goes on after an aborted method call, and the first rule for `x := atomic {C}` requires the whole trace of `C` to end with `aborted`. So if the body has, say, a local assignment after the call, an aborted call never lets the block finish with `x := aborted`, and the effect of that assignment can be reproduced by a successful call instead. Section 2 states the intended semantics: when the transactional system aborts a call, "the execution of C terminates" (and the trace set "contains traces in which C is aborted in the middle of its execution"); the journal version's Figure 4 formalizes this. `TrI` is Figure 2 with this repair: the body of an atomic block is cut at its first `aborted`. `theorem_24_cex_fails_intended`: with the repaired trace sets, the pair `H_C`, `H_A` of `theorem_24_false` is **not** in the state-observational-refinement relation, already for the minimal deterministic language. The witness program is `r := atomic { y := o.f(1); z := 1 }`: the trace in which the call is aborted ends with `r = aborted` and `z` unchanged, while every trace with a history in `H_A` that sets `r` to `aborted` runs `z := 1`.
