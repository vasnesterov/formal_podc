import Papers.PODC2012.CollaborativeSearchPlane.Geometry /-! # Theorem 5.1: the harmonic search algorithm Each agent (1) goes to a node `u` chosen with probability `p(u) = c / d(u)^(2+δ)`, (2) performs a spiral search of length `t(u) = d(u)^(2+δ)`, (3) returns. (For `u = s` the paper's `p(u)` divides by `0`; we put `p(s) = 0`.) With the spiral guarantee of `Phases.lean` (a spiral from `u` reaches every `v` with `σ d(u, v)² ≤ t` within `σ d(u, v)²` steps), an agent that picked `u` with `σ d(u, τ)² ≤ t(u)` finds the treasure by time `d(u) + σ d(u, τ)²` (`harmonicBound`); the running time of the `k` agents is at most the minimum of these bounds (`harmonicTime`). `theorem_5_1`: for every `δ > 0` and `ε ∈ (0, 1)` there are `α, C > 0` such that whenever `k > α D^δ`, with probability at least `1 - ε` the running time is at most `C (D + D^(2+δ)/k)`. (The paper states "with probability at least `1 - ε`, the *expected* running time is `O(D + D^(2+δ)/k)`" and assumes `δ ≤ 0.8`; the restriction on `δ` is not needed.) -/ namespace
