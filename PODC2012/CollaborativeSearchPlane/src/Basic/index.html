import Mathlib /-! # Collaborative search on the plane: the model (§2 of Feinerman–Korman–Lotker–Sereni) `k` identical probabilistic agents start at the source `s = (0,0)` of the grid `ℤ²` and search, without communication, for a treasure placed by an adversary at a node `τ`. The search is over once some agent visits `τ`. * An agent's behaviour is a probability law on *trajectories* `ℕ → ℤ × ℤ` (position at each time step). Agents do not communicate, so the `k` trajectories are independent: the joint law is the product measure `Measure.pi ν` (`ν a` is the law of agent `a`). Since the agents know nothing about `τ`, the trajectory up to the moment the treasure is found does not depend on `τ`; what an agent does afterwards is irrelevant, so a law independent of `τ` is no loss of generality. * A *uniform* algorithm is a single law `μ` used by all agents whatever `k` is (`ν = fun _ ↦ μ`); an algorithm with *advice* is a family `A : ℕ → Measure Traj`, an agent with estimate `k̃` using `A k̃`. * `findTime ω τ` is the first time some agent is at `τ` (`⊤` if never), and `expectedTime ν τ` its expectation — the paper's `T_A(D, k)` for `d(s, τ) = D`. We do *not* require the trajectories to be nearest-neighbour walks starting at `s`: the lower bounds only use that an agent occupies one node per time unit, so they hold for this larger class of "teleporting" agents, in particular for grid walks. The two probabilistic facts behind all lower bounds of §4 are proved here: * `sum_visit_le` — in `N` steps one agent visits at most `N + 1` nodes, hence the visit probabilities of any finite set of nodes sum to at most `N + 1`; * `half_le_sum_visit` — Markov's inequality plus a union bound: if the expected time to find `u` with agent laws `ν` is at most `T` and `2T ≤ N + 1`, then `∑ₐ Pr[agent a
