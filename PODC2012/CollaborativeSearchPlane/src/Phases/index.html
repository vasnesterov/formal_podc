import Papers.PODC2012.CollaborativeSearchPlane.Basic /-! # Phased search algorithms (the algorithms of §3 and of the appendix) All upper-bound algorithms of the paper are built from *phases*: "go to a node `u` chosen uniformly at random in the ball `B(R)`, perform a spiral search of length `t` starting at `u`, return to the source". Phases are grouped into *blocks* `b = 0, 1, 2, …` (stages, resp. big stages), block `b` consisting of the finitely many phases `P b`. As in the paper, the navigation procedures are atomic, with the guarantees the paper assumes (§2 and footnote 1): * walking to `u` takes `d(u) ≤ R` steps, a spiral search of length `t` takes `t` steps and ends within distance `t` of `u`, so returning takes `≤ R + t` steps: a phase lasts at most `2R + 2t` (`phaseDur`); * a spiral search of length `t` from `u` visits every node `v` with `σ · d(u, v)² ≤ t` (the paper takes `σ = 4`: "visits all nodes at distance at most `√x/2`"; we keep the constant `σ ≥ 1` as a parameter, any value gives the same asymptotics). Hence an agent whose node `u` in phase `x` satisfies `σ · d(u, τ)² ≤ t` has found the treasure by the end of phase `x`. We formalize the analysis at this level: the random choices of all agents in all phases are independent (`Measure.infinitePi`), `notFoundBefore S b` is the event that no agent has hit its success set in a block `< b`, and if every agent finishes block `b'` within time `∑_{b'' ≤ b'} dur b''`, then the search is over by time `timeBound S dur = ∑_b dur b · 1[notFoundBefore S b]`. `lintegral_timeBound` computes its expectation exactly: `E[timeBound] = ∑_b dur b · ∏_{a} ∏_{phases x before b} Pr[u_{a,x} ∉ S(a,x)]`. -/ namespace Podc.CollaborativeSearchPlane open MeasureTheory
