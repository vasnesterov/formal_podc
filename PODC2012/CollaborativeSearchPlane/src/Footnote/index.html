import Papers.PODC2012.CollaborativeSearchPlane.Theorem41 /-! # The trivial lower bound `Ω(D + D²/k)` (§2 and footnote 2) §2 states: "it is easy to see that the expected running time is `Ω(D + D²/k)`, even if the number of agents `k` is known to all agents" (footnote 2). The argument of footnote 2 (Markov plus counting) is `sq_div_le`: if every node within distance `D` is found in expected time `≤ T`, then `D²/(8k) ≤ T + 1`. It needs no assumption on the agents (they need not even be identical). The `Ω(D)` part needs that agents walk on the grid from the source (`IsWalk`): then no node at distance `D` is found before time `D`. Together (`footnote_2`): for every `k ≥ 1` agents walking on the grid and every `D ≥ 1`, some treasure at distance `≤ D` has expected finding time `≥ (D + D²/k)/20`. The bound is over treasures at distance *at most* `D`, as in the footnote's proof; for a fixed exact distance `D` it is false in general (agents that walk to distance `D` and then around the sphere of radius `D` find every treasure at distance exactly `D` in time `O(D)`), which is harmless because competitiveness is required for all `D`. -/ namespace Podc.CollaborativeSearchPlane open MeasureTheory
