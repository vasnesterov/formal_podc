import Papers.PODC2012.TMLiveness.Liveness /-! # The two schedules: Lemma 1 in crash-free and in parasitic-free systems * **Crash-free systems** (`lemma1_crashFree`): the processes are scheduled round-robin, so no process crashes. If `p₁` is parasitic, `p₂` is correct but makes no progress, so it does not run alone: another process is correct. Otherwise `p₁` is correct and never commits, so it does not run alone either. (The paper's sequential Strategy 2 is not admissible in a crash-free system with three or more processes, nor when an operation blocks until another process takes a step.) * **Parasitic-free systems** (`lemma1_parasiticFree`): the paper's sequential Strategy 1: `p₁` is scheduled until `T₁` has read a value, then `p₂` until `p₁` is ready, then `p₁` again. A process whose operation does not return runs alone; so does `p₂` if `p₁` crashes, and `p₁` if `p₂` crashes. Otherwise both are correct, and only `p₂` may make progress.
