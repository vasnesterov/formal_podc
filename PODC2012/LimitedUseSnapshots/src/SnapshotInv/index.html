import Papers.PODC2012.LimitedUseSnapshots.SnapshotSeq /-! # Algorithm 3: the invariant The invariant behind Theorem 4.2. The ghost state consists of * `R a`: the set of all states taken so far by the max array of the node `a` (a chain); * `L`: the linearization built so far; * `s₀`: the vector of leaf pointers represented by the current value of `root.mr` (the paper's `root.seq[root.mr]`). **Linearization points.** A `Scan` is linearized at its `ReadMax(root.mr)` (as in the paper). An `Update` of process `j` with counter value `m` is linearized at the first `WriteMax(root.mr, d)` after which `root.seq[root.mr]_j ≥ m`, i.e. as soon as the root pointer represents its leaf pointer. (The paper linearizes it at the first `WriteMax(root.mr, d')` with `d' ≥ d`, where `d` is the operation's own root pointer; that is too late, see `SnapshotCounterexample.lean`.) -/ namespace
