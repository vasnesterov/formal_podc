We record the recursion as a binary tree `Shape` whose leaves are the values (`m` = number of leaves of the left subtree). Nodes are addressed by paths `List Bool` from the root (`false` = left, `true` = right). * `Shape.size` — number of leaves (`k`), `Shape.subD t a` — the subtree at address `a` (`leaf` if `a` leaves the tree), `Shape.lo t a` — the offset of the subtree at `a` (the smallest value of its range), `Shape.addr t v` — the address of the leaf of value `v`. * `Shape.balanced k` — the paper's balanced tree (`m = ⌈k/2⌉`). * `LeftDom c σ` — every left step of the path `c` is at a node whose switch is off ("a traversal of `c` is consistent with switch states `≥ σ`"); `RightDom c σ` — every right step of `c` is at a node whose switch is on ("a traversal reading switches no later than `σ`").
