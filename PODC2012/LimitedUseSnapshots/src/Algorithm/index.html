import Papers.PODC2012.LimitedUseSnapshots.Spec import Papers.PODC2012.LimitedUseSnapshots.Tree /-! # Algorithm 2: the 2-component max array `MaxArray_{k×h}` Aspnes, Attiya, Censor-Hillel, Ellen, *Limited-Use Atomic Snapshots with Polylogarithmic Step Complexity*, Algorithm 2 (Section 3), and its correction from the authors' erratum (line 9.5: `MaxUpdate1` performs an embedded `MaxScan` after its `WriteMax`). The recursion of Algorithm 2 is unfolded over a tree `T : Shape` (leaves = values of the first component, `k = T.size`; the paper's split point `m` at a node is the size of its left subtree, so every choice of `m`, balanced or not, is covered). Base objects (`Obj`): * `sw a` — the 1-bit multi-writer register `switch` of the internal node at address `a`; * `sec a` — the `MaxReg_h` object `second` of the node at address `a` (`sec []` is the second component). These max registers are taken as **atomic** base objects (CSLib `maxRegObj`, over `ℕ`, so the range `h` plays no role for correctness); their `O(log h)` cost is a parameter of the step-complexity analysis. Local states (`Loc`), with the line numbers of Algorithm 2: * `d0 v a` — `MaxUpdate0(r, v)` has descended to node `a`; right steps (line 6) need no shared access and are skipped, a left step reads `switch` (line 3) and stops if it is `1`; * `up v a` — `MaxUpdate0(r, v)` returns from the recursion below node `a`: it writes `switch ← 1` (line 7) at the deepest right step strictly above `a`, then continues upwards; * `w1 v` — `MaxUpdate1(r, v)` about to perform `WriteMax(r.second, v)` (line 9); * `s1 e a … s5 e a x` — a `MaxScan` at node `a` (lines 11, 12, 13, 16, 17; at a leaf, `s1` is the final `ReadMax(r.second)` of the `MaxArray_{1×h}` case); `e = true` marks the scan embedded in `MaxUpdate1` by the erratum (line 9.5), whose result is discarded; * `rt r` — about to return `r`. `alg T fix` is Algorithm 2 for `fix = false` and the corrected algorithm for `fix = true`. `MaxUpdate0(v)` may only be invoked with `v < k` (`allowed`). -/ namespace Podc.LimitedUseSnapshots open
