import Papers.PODC2012.NonEquivocationLimits.Basic /-! # Claim 3.1: non-equivocation without transferable authentication does not help **Claim 3.1.** In an asynchronous system with `n < 3f + 1` processes, at most `f` Byzantine, where processes have no transferable authentication and faulty processes cannot equivocate, there is no r-broadcast protocol. We prove it (for `n ≥ 3`, see `SmallCases.lean` for `n ≤ 2`) against the weakest adversary we could think of: every faulty process *imitates* a correct process of another run (`Imitating`), so it never equivocates if the protocol does not (`claim_3_1`), and it never needs anybody else's authentication: links are authenticated point to point, and nothing in the model lets a receiver check a relayed statement (no transferable authentication). The admissible runs are even partially synchronous (`Run.Valid f δ` for any `δ`), which only strengthens the result; the asynchronous versions follow (`claim_3_1_async`). ## The four runs (groups `A = g⁻¹ 0 ∋ s`, `B = g⁻¹ 1`, `C = g⁻¹ 2`, each of size `≤ f`) 1. `run1`: `C` silent (crashed), sender input `m'`, synchronous: `A ∪ B` deliver `m'`; all of `B` by time `T₁`. 2. `run2 T₁`: `A` faulty, sends to `B` exactly what it sent in run 1 up to `T₁`, then nothing; `B ↔ C` messages sent before `T₁ + 1` arrive at `T₁ + 1`. `B` cannot distinguish it from run 1 up to `T₁ + 1`, delivers `m'`, so `C` delivers `m'` (L2, S2), by time `T₂`. 3. `run3 T₁ H` (`H > T₁, T₂`): no faults, input `m'`; `B ↔ C` as in run 2, `A ↔ C` messages and `A → B` messages sent after `T₁` arrive at time `H`. `A ∪ B` see run 1 up to `T₁ + 1`, hence `B ∪ C` see run 2 up to `H`: `C` delivers `m'` by `T₂`. 4. `run4 T₁ H`: sender input `m`, `B` faulty and imitates run 3 *exactly*, same delays as run 3. `C` sees run 3 up to `H` and delivers `m'`; the correct sender delivers `m` (L1): Agreement fails. **Repair of the paper's proof.** In the paper's Run 3, messages between `A` and `B` are "delivered in a timely fashion" throughout; then `B` hears from the (now correct, not crashed) processes of `A` after time `t`, and need not behave as in Run 2, so `C` need not deliver `m'`.
