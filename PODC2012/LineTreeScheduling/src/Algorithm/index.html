import Papers.PODC2012.LineTreeScheduling.Framework /-! # The distributed algorithm of Section 5 (epochs, stages, steps) and Lemma 5.1 The first phase of the algorithm of Figure 7, generic in the raising rule (so that it covers the unit-height algorithm of Section 5, the narrow-instance algorithm of Lemma 6.2 and the line-network algorithms of Section 7). The demand instances are partitioned into groups `grp d ∈ {0, …, ℓ-1}` (a layered decomposition; group `0` is the paper's `G₁`). The first phase has `ℓ` epochs; epoch `k` has `b` stages; stage `j` (0-based, the paper's stage `j+1`) consists of `K` steps. In step `t` of stage `j` of epoch `k`, let `U` be the set of instances of group `k` that are `(1 - ξ^{j+1})`-unsatisfied; an arbitrary maximal independent set `I ⊆ U` (supplied by an adversarial MIS oracle `mis`) is raised. The paper runs each stage "until `U = ∅`"; its distributed implementation runs a fixed number of iterations per stage. We run `K` steps per stage and prove (`lemma_5_1`, `stage_complete`) that `U = ∅` after `K` steps as soon as `p_max < 2^K p_min`, so the two versions coincide (once `U = ∅` the remaining steps raise nothing). Main results: * `claim_5_2`: if `d₁ ∈ I` kills `d₂` (conflicting, `d₂` still unsatisfied after the step), then `p(d₂) > 2 p(d₁)`. * `lemma_5_1`: if `U` is nonempty at the `L`-th step of a stage then `2^L p_min ≤ p_max`. * `alg_sat`: at the end of the first phase all dual constraints are `(1-ξ^b)`-satisfied. * `alg_validRun`, `alg_interference`: the run is a valid run of the framework with the
