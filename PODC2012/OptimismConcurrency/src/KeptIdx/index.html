import Papers.PODC2012.OptimismConcurrency.Basic /-! # Positions of the events kept by `complete` `lfIdx f H` lists the positions (in `H`) of the events kept by `lookFilter f H`; `kidx f H a` is the position of the `a`-th kept event. Lemmas: kept events are the events at these positions, positions are strictly increasing, and every position whose event passes the filter occurs. Then, for `complete`, a *window lemma*: between two kept events of an operation of `p` with no kept response of `p` in between, every event of `p` is kept. -/ namespace Podc.OptimismConcurrency section LF variable {α : Type*} (f : α → List α → Bool) /-- Positions of the events kept by `lookFilter f`. -/ def lfIdx : List α → List ℕ | [] => [] | e :: l => if f e l then 0 :: (lfIdx l).map (· + 1) else (lfIdx l).map (· + 1) /-- Position of the `a`-th kept event. -/ def kidx (H : List α) (a : ℕ) : ℕ := (lfIdx f H).getD a 0 lemma length_lfIdx (H : List α) : (lfIdx f H).length = (lookFilter f H).length := by induction H with | nil => rfl | cons e l ih => simp only [lfIdx, lookFilter];
