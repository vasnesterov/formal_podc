import Papers.PODC2012.OptimismConcurrency.Basic /-! # LS-linearizability is compositional (Theorem 5, Appendix B) A history `H` on several objects `x : X` (for the paper: `X = {O₁, O₂}`) is LS-linearizable w.r.t. the composed sequential implementation as soon as every `H|x` is LS-linearizable w.r.t. the sequential implementation of `x`. The composed implementation is represented by any set `SigIS` of sequential histories containing the histories of every component (`∀ x, SigX x ⊆ SigIS`: running only operations of `O_x` is an execution of `IS₁ × IS₂`). The composed type `τ₁ × τ₂` is represented, as usual for linearizability, by the multi-object Herlihy–Wing specification (one sequential specification per object). Well-formedness of the high-level history of `H` is assumed (all histories of the paper are well-formed). The local-serializability half is immediate, because every operation acts on one object, so `H|π = (H|x)|π`; the linearizability half is the locality of linearizability (Herlihy–Wing, `Cslib.SharedMemory.HerlihyWing.linearizable_of_restrictX`). The paper's proof reasons about interleaving witnesses `S¹_π`, `S²_π` of both components and "any completion"; neither is needed. -/ namespace Podc.OptimismConcurrency open Cslib.SharedMemory variable {P X Op Res Obj Val : Type} [DecidableEq P] [DecidableEq X] /-- `H|x`: the events on object `x`. -/ def restrictObj (H : Hist P X Op Res Obj Val) (x : X) : Hist P X Op Res Obj Val := H.filter (fun e => decide (e.obj = x)) lemma restrictPX_restrictObj (H : Hist P X Op Res Obj Val) (p : P) (x : X) : restrictPX (restrictObj H x) p x = restrictPX H p x := by unfold restrictPX restrictObj rw [List.filter_filter] congr 1;
