import Mathlib import Cslib.Computability.Distributed.SharedMemory.HerlihyWing.Locality /-! # Two-level histories, LS-linearizability, schedules Gramoli, Kuznetsov, Ravi, *Optimism for Boosting Concurrency* (arXiv 1203.4751v8; PODC 2012 brief announcement "From Sequential to Concurrent: Correctness and Relative Efficiency"), Sections 2–4. A history of a concurrent implementation of a sequential implementation `IS` has two levels: high-level operations (`inv`/`res`) of the implemented type and, inside them, the reads and writes of the base objects ("t-objects") of `IS` (`rinv`/`rres`, `winv`/`wres`). A read or a write may abort: its response is `⊥` (`rres p x none`, `wres p x false`), and then the enclosing high-level operation is aborted (the `⊥` event is also its response, §2). * `Ev`, `Hist`: events and histories (every event carries the process and the high-level object). * `localView H p x k` = `H|π` for the `k`-th operation `π` of `p` on `x`, without its last aborted read or write (§3). * `LocSer SigIS H` (local serializability w.r.t. the set `Σ` of histories of `IS`), `hl H` (the high-level history `H̃`: invocations and responses of non-aborted operations), `LSL SigIS spec H` (**Definition 1**, LS-linearizability, with Herlihy–Wing linearizability from CSLib). * `complete H` (events of the operations that returned a matching response), schedules `SEv`, `sched`, `Exports`, `Accepts` (§4). Histories are only meaningful when well-formed; as in the paper, the definitions are applied to the histories produced by implementations, which are well-formed. -/ namespace Podc.OptimismConcurrency Since histories of a sequential implementation are sequential and prefix-closed, we take `S` ending with `π`. -/ def LocSer (SigIS : Set (Hist P X Op Res Obj Val)) (H : Hist P X Op Res Obj Val) : Prop := ∀ p x k, k < numOps H p x → ∃ S₀, S₀ ++ localView H p x k ∈ SigIS /-- Keep a high-level invocation unless its operation aborted; keep every high-level response. -/ def keepHL (e : Ev P X Op Res Obj Val) (later : Hist P X Op Res Obj Val) : Bool := match e with | .inv p x _ => !((termOf p x later).any Ev.isAbort) | .res .. => true | _ => false /-- High-level events as Herlihy–Wing events. -/ def toHW : Ev P X Op Res Obj Val → Option (Cslib.SharedMemory.HerlihyWing.Event P X Op Res) | .inv p x o => some (.inv p x o) | .res p x r => some (.res p x r) | _ => none /-- The high-level history `H̃` of `H`: invocations and responses of the non-aborted operations. -/ def hl (H : Hist P X Op Res Obj Val) : Cslib.SharedMemory.HerlihyWing.History P X Op Res := (lookFilter keepHL H).filterMap toHW /-- **Definition 1** (LS-linearizability): `H` is locally serializable w.r.t. `Σ` (the histories of `IS`) and its high-level history is linearizable w.r.t. `spec` (the type `τ`). -/ def LSL (SigIS : Set (Hist P X Op Res Obj Val)) (spec : Cslib.SharedMemory.HerlihyWing.SeqSpec P X Op Res) (H : Hist P X Op Res Obj Val) : Prop := LocSer SigIS H ∧ Cslib.SharedMemory.HerlihyWing.Linearizable spec (hl H) /-! ## Schedules and acceptance (§4) -/ /-- Keep the events of the operations that returned a matching response. -/ def keepC (e : Ev P X Op Res Obj Val) (later : Hist P X Op Res Obj Val) : Bool := (termOf e.proc e.obj (e :: later)).any Ev.isRes /-- `complete(H)`: the events of the complete operations that returned a matching response. -/ def complete (H : Hist P X Op Res Obj Val) : Hist P X Op Res Obj Val := lookFilter keepC H /-- Schedule events: events without read values and high-level responses. -/ inductive SEv (P X Op Obj Val : Type) where | inv (p : P) (x : X) (o : Op) | res (p : P) (x : X) | rinv (p : P) (x : X) (y : Obj) | rres (p : P) (x : X) | winv (p : P) (x : X) (y : Obj) (v : Val) | wres (p : P) (x : X) deriving DecidableEq /-- Forget values (read values, high-level responses, success flags). -/ def Ev.erase : Ev P X Op Res Obj Val → SEv P X Op Obj Val | .inv p x o => .inv p x o | .res p x _ => .res p x | .rinv p x y => .rinv p x y | .rres p x _ => .rres p x | .winv p x y v => .winv p x y v | .wres p x _ => .wres p x /-- The schedule exhibited by `complete(H)`. -/ def sched (H : Hist P X Op Res Obj Val) : List (SEv P X Op Obj Val) := (complete H).map Ev.erase /-- `H` exports the schedule `σ`: `complete(H)` exhibits the order of `σ`. -/ def Exports (H : Hist P X Op Res Obj Val) (σ : List (SEv P X Op Obj Val)) : Prop := sched H = σ /-- An implementation, given by the set of histories it exports, accepts `σ`. -/ def Accepts (I : Set (Hist P X Op Res Obj Val)) (σ : List (SEv P X Op Obj Val)) : Prop := ∃ H ∈ I, Exports H σ /-- `σ` is an `(IS, τ)`-LSL schedule: some LSL history exports it. -/ def LSLSched (SigIS : Set (Hist P X Op Res Obj Val)) (spec : Cslib.SharedMemory.HerlihyWing.SeqSpec P X Op Res) (σ : List (SEv P X Op Obj Val)) : Prop := ∃ H, LSL SigIS spec H ∧ Exports H σ end Podc.OptimismConcurrency
