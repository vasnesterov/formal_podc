import Papers.PODC2012.OptimismConcurrency.ListSet /-! # Sequential correctness of `LL` (Algorithm 2) The memory `m : Mem` *represents* the set `q` (`Rep m q`) if, starting from `head`, the `next` pointers lead through nodes with keys `-∞, z₁, …, zₖ` to a `+∞` node, where `z₁ < ⋯ < zₖ` and `q = {z₁, …, zₖ}` (`Chain m [z₁, …, zₖ]`). Unreachable garbage is allowed. `LLI zs o m s` is the invariant of a solo run of the operation `o` of `LL` started from a memory representing the sorted list `zs`: `s` is the control state, `m` the current memory. We show * `LLI.start`: it holds initially; * `LLI.read`, `LLI.write`, `LLI.alloc`: it is preserved by every action of `LL` (a read of an allocated location; a write; a write of a new node to an unallocated location), and every action strictly decreases `rank`; * `LLI.done`: when the operation returns `r`, the memory represents `(setδ q o).1` and `r = (setδ q o).2` (`q = zs.toFinset`); * `LLI.act_read`, `LLI.act_write`: reads and writes only access allocated locations; * `LLI.readOnly`: if the set is not modified by `o` (`(setδ q o).1 = q`), `LL` performs no write; * `soloStep_correct`: a solo run from a chain representing `q` returning `r` leaves a chain representing `(setδ q o).1` and `r = (setδ q o).2`;
