import Mathlib /-! # Static scheduling instances and Algorithm 1 (Section 3 of Kesselheim, PODC 2012) A *static single-hop instance* (Section 2) consists of links `E`, packets `P` (each packet has to cross one link `link p`) and the interference matrix `W : E → E → ℝ` with entries in `[0, 1]` and `W e e = 1`. For a packet set `S`, `R_S(e')` is the number of packets of `S` on `e'`, and the interference measure is `‖W · R_S‖∞ = max_e ∑_{e'} W e e' · R_S(e')`. A static algorithm `𝒜(I', n')` is a black box: run (for its `f(n') · I'` time steps) on a packet set `S`, it returns the random set of packets it did **not** deliver. The hypothesis of Theorem 1 is that `𝒜(I', n')` delivers everything with probability at least `1 - 1/n'` whenever `‖W · R_S‖∞ ≤ I'` and `|S| ≤ n'`. Algorithm 1 (verbatim): ``` for i := 1 to ξ = ⌈log(I / 2φχ log n)⌉ do Assign each remaining packet a delay of at most ⌈2^{-i+1} · I / χ⌉; Execute 𝒜(χ, m·χ) for f(mχ)·χ steps on all packets that received the same delay; for i := 1 to ⌈φ⌉ + 1 do Execute 𝒜(2φχ log n, n) on the remaining packets; ``` with `χ = 6 (ln m + 9)`. The delays are independent and uniform in `[ψ]`, `ψ = ⌈2^{-i+1} I/χ⌉` (proof of Claim 2). The base `b` of `log` is not fixed by the paper; we keep it as a parameter. Here everything is a `PMF` over the final set of undelivered packets; "Algorithm 1 succeeds" means this set is empty. The running time of Algorithm 1 is a deterministic quantity, treated in `Time.lean`. -/ namespace Podc.WirelessPacketScheduling open Finset /-- A static single-hop instance (Section 2): every packet `p` has to be sent over the link `link p`;
