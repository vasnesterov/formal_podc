import Papers.PODC2012.WirelessPacketScheduling.Counting import Papers.PODC2012.WirelessPacketScheduling.Numerics /-! # Theorem 1 is false Instance: packet routing (`W` = identity) on `m = 200` links with `5100` packets on every link, so `n = 1 020 000` and `I = ‖W · R‖∞ = 5100`; `φ = 1`. The static algorithm is "all or nothing": if `‖W · R_S‖∞ ≤ I'` it delivers all of `S` (one packet per link and step, `f ≡ 1`), otherwise it delivers nothing. It satisfies the hypothesis of Theorem 1 with success probability `1`. Then `85 < χ < 86`, `ξ = 1` and `ψ₁ = 60`. In iteration 1 each packet gets a uniform delay in `[60]`, so on every link a delay class receives `Bin(5100, 1/60)` packets, mean `85 < χ`. A class is served only if *no* link carries more than `χ` (i.e. `≥ 86`) of its packets. On each link this fails with probability `P(Bin(5100, 1/60) ≥ 86) ≥ P(= 86) ≥ 1/25`, independently over the 200 links. So with probability `≥ 1 - 60 · (24/25)^200 > 0.98` every class fails, nothing is delivered, and the clean-up executions `𝒜(2φχ log n, n)` are run on an instance of interference `5100 > 2φχ log n` and deliver nothing either. Hence Algorithm 1 fails with probability `> 0.98 > 1/n^φ`. The paper's proof breaks in Claim 2: with `ψ = ⌈2^{-i+1} I/χ⌉` delay values the expected load of a delay class is up to `χ`, not `χ/2` as claimed, so a constant fraction of the classes is overloaded.
