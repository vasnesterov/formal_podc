import Mathlib /-! # Stability of simple discrete-time queues Two single-server discrete-time queues, modelled with Mathlib's `PMF`: * `slot a s`: in each slot a packet arrives with probability `a` and, independently, the link has a transmission opportunity with probability `s`; it then sends one packet if its queue (after the arrival) is nonempty. `slot_stable`: the queue is stable (bounded expected length) if `a < s`. * the TDMA frame `slot a 0` followed by `slot a 1` (a slot without and a slot with a sure transmission opportunity). `tdma_stable`: stable if `a < 1/2`. The proof is a Foster–Lyapunov argument with the exponential Lyapunov function `V j = z ^ j`, `z > 1` (`stable_of_drift`): a geometric drift `E[V(Q') | Q = j] ≤ ρ V j` for `j ≥ 1`, `ρ < 1`, bounds `E[V(Q_t)]` uniformly in `t`, and `j ≤ z ^ j / (z -
