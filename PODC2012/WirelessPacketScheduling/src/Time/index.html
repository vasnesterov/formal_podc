import Papers.PODC2012.WirelessPacketScheduling.Model /-! # The running time of Algorithm 1 (first part of the proof of Theorem 1) Algorithm 1 has a fixed schedule: iteration `i` of the first loop runs `ψ_i` executions of `𝒜(χ, mχ)` of `f(mχ)·χ` steps each, and the clean-up loop runs `⌈φ⌉ + 1` executions of `𝒜(2φχ log n, n)` of `f(n)·2φχ log n` steps each. We check the paper's estimate `∑_{i=1}^{ξ} ⌈2^{-i+1} I/χ⌉ f(mχ) χ + (⌈φ⌉+1) f(n) 2φχ log n ≤ 2 f(mχ) I + ξ f(mχ) χ + (⌈φ⌉+1) f(n) 2φχ log n`. The paper then writes the middle term as `O(log n · f(mχ))`; since `χ = Θ(log m)` it is really `O(log n · log m · f(mχ))` (this is the bound `O(log n · log² m)` stated in the introduction for `f = O(log)`).
