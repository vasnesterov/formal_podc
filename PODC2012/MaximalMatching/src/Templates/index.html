import Mathlib import Cslib.Computability.Distributed.ColourSystem.Algorithm /-! # Templates, realisations and extensions (§3.2–3.5 of Hirvonen–Suomela) An `h`-template `(T, τ)` is an `h`-regular colour system `T` with a forbidden colour `τ(t) ∉ C(T, t)` at each node. Its **realisation** (§3.5) adds at each node `t` a half-loop of every free colour `c ∉ C(T,t) + τ(t)` and unfolds: the view of `t` in this graph is the `d`-regular (`d = k - 1`) colour system `real T t` in which every node mapped to `t` sees the same thing (Corollary 10). We define the template output `out A T t := A (real T t) e` directly as the output of the root of the view from `t`; by Lemma 8 / Corollary 10 this is the output of every node of the realisation that is mapped to `t` (`out_eq_apply`). A 1-colour picker `P` chooses one free colour `P t` at each node; the **extension** `T.extend P` (§3.3) unfolds the half-loops `P t` only, keeping `τ`. Its realisation coincides with the realisation of `T` (Corollary 11, `real_extend`), so `out A (T.extend P) x = out A T (pos x)` (`Good.out_extend`). -/ namespace Papers.PODC2012.MaximalMatching open
