Distributed Maximal Matching: Greedy is Optimal — PODC 2012

Juho Hirvonen, Jukka Suomela. Distributed Maximal Matching: Greedy is Optimal. PODC 2012. DOI 10.1145/2332432.2332464. Formalized version: arXiv 1110.0367 v1 (the only version); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. On anonymous k-edge-coloured graphs, maximal matching needs exactly k - 1 deterministic rounds, so the greedy algorithm is optimal (Lemma 1, Theorem 2), and for k ≥ 3 the lower bound holds already on (k-1)-regular graphs (Theorem 6), which gives Ω(Δ) (Corollary 3). All of this is proved, and the template / extension / critical-pair argument of §3 goes through as written. One step is missing: the paper's formal model uses infinite trees, and passing to finite simple graphs needs an extra construction, which we supply.

Proof gaps in true statements (1)Theorem 2, Theorem 6 and Corollary 3

🔧 Theorem 2, Theorem 6 and Corollary 3 (from infinite trees to finite graphs)

The lower bounds are proved in the formal model of §2.3, whose instances are edge-coloured trees, all infinite in the proof, while Theorem 2 and Corollary 3 talk about k-edge-coloured graphs; the paper does not give the passage to finite graphs.

Impact. Statements true; we add the missing step, so all lower bounds hold for finite simple graphs (completion, findsMaximalMatching_of_finite, theorem2_lower_messagePassing, theorem6_messagePassing).

Details

The trees built in the proof (realisations, and the final U, V) are infinite. For finite graphs one more step is needed: every finite ball of a d-regular colour system must appear as the view of a node in a finite, simple, d-regular, k-edge-coloured graph.

Repair

A 2^k-copies construction (completion): 2^k copies of the ball; a boundary node lacking its colour-c edge is joined to its twin in the copy with coordinate c flipped.

Model.

  • View model (§2.3, used in the proofs). G_k is the free product of k copies of ℤ/2, implemented as reduced words (FreeCox k). A colour system is a prefix-closed V ⊆ G_k, i.e. a k-edge-coloured tree, possibly infinite. An algorithm is any function A : Set G_k → G_k → Option (Fin k); none means unmatched, some c means matched along colour c. It has running time r if (ūU)[r+1] = (v̄V)[r+1] implies A U u = A V v. Correctness is (M1)–(M3). The model is deterministic and anonymous; local computation and message size are unbounded.

  • Message-passing model (§1.2). A k-edge-coloured network is a ColouredGraph k α: each colour class is a partial involution, and IsSimple means a simple graph with a proper edge colouring. Nodes may be finite or infinite in number, and cycles are allowed. A node starts knowing its incident colours. In each synchronous round it sends one message per colour, then receives and updates. It outputs after r rounds.

  • Equivalence. We prove that the two models are equivalent (state_eq_of_view, hasRunningTime_toAlgorithm, out_ofView, isMaximalMatching_view). The lower bound needs correctness only on finite simple (regular) networks. The upper bound holds on all networks (on non-simple networks the maximal-matching spec lets a node be matched along a half-loop, so its usual meaning is for simple graphs).

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice and Quot.sound. The hypotheses of Theorem 6 are satisfiable: greedy satisfies them (good_greedy). In the message-passing model, lemma1_messagePassing gives an algorithm that is correct on all networks. The reusable infrastructure is in CSLib (Cslib/Computability/Distributed/ColourSystem/): the free Coxeter group, colour systems, coloured graphs and their views (universal covers), the view-based and message-passing models with bridges between them, and finite completions.
