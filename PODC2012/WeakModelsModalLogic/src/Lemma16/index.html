If `G` is `k`-regular for an odd `k` and some *consistent* port numbering makes all nodes bisimilar in `K_{+,+}(G, p)`, then `G` has a 1-factor (perfect matching). Proof (as in the paper): reading `p` on `V × Fin k` (`PortNumbering.onProd`), bisimilarity of all nodes forces the remote port number `f(i)` behind port `i` to be the same at every node; consistency makes `f` an involution of `Fin k`; since `k` is odd, `f` has a fixed point `i`, and the edges `{v, w}` with `p((v, i)) = (w, i)` form a perfect matching. -/ namespace Podc.WeakModelsModalLogic open Function -- CSLib candidate /-- An involution of a finite type of odd cardinality has a fixed point. -/ theorem Involutive.exists_fixed_of_odd_card {α : Type*} [Fintype α] {f : α → α} (hf : Involutive f) (hodd : Odd (Fintype.card α)) : ∃ x, f x = x := by classical by_contra hne push Not at hne let σ : Equiv.Perm α := hf.toPerm have h2 : σ ^ 2 = 1 := by ext x; simp [σ, sq, hf x] have hsupp : σ.support = Finset.univ := by ext x; simp [σ, Equiv.Perm.mem_support, hne x] have := Equiv.Perm.two_dvd_card_support h2 rw [hsupp, Finset.card_univ] at this exact (Nat.not_even_iff_odd.2 hodd) (even_iff_two_dvd.2 this) -- CSLib candidate /-- An involution `m` of `V` with `G.Adj v (m v)` for all `v` (hence fixed-point-free) gives a perfect matching. -/ theorem exists_perfectMatching_of_involutive {V : Type*} {G : SimpleGraph V} (m : V → V) (hm : Involutive m) (hadj : ∀ v, G.Adj v (m v)) : ∃ M : G.Subgraph, M.IsPerfectMatching := by let M : G.Subgraph := { verts := Set.univ Adj := fun u w => m u = w adj_sub := by rintro u w rfl; exact hadj u edge_vert := fun _ => Set.mem_univ _ symm := ⟨by rintro u w rfl; exact hm u⟩ } refine ⟨M, fun v _ => ⟨m v, rfl, fun w (hw : m v = w) => hw.symm⟩, fun v => Set.mem_univ v⟩ variable {V : Type*} /-- Lemma 16 of [Hella et al.].
