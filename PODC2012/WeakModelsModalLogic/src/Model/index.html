import Mathlib /-! # Weak models of distributed computing: the model (§1 of Hella et al.) We formalize §1 of Hella, Järvisalo, Kuusisto, Laurinharju, Lempiäinen, Luosto, Suomela, Virtema, *Weak models of distributed computing, with connections to modal logic* (PODC 2012; full version arXiv:1205.2051v3). * Graphs are finite simple graphs `G : SimpleGraph V` with `[Finite V]`; `deg G v` is the number of neighbours. * Ports: `Port G = Σ v, Fin (deg G v)` (the paper numbers ports `1, …, deg v`; we use `0, …, deg v - 1`). * A port numbering (§1.2) is a bijection `p : P(G) → P(G)` with `A(p) = A(G)` (`PortNumbering`); it is consistent if `p` is an involution. * A distributed state machine (§1.1) for degree bound `Δ` is `Machine Δ Y`: stopping states `Y`, intermediate states `Z`, messages `M` with the "no message" symbol `m0`, initial states `z0` (a function of the degree), message construction `μ : Z → ℕ → M` (port index `0 ≤ i < Δ`) and transition `δ : Z → (Fin Δ → M) → Y ⊕ Z`. * The execution (§1.3) is `Machine.state`, defined literally as in the paper (incoming vector ordered by in-port number, padded with `m0`; stopped nodes send `m0` and keep their state). * Algorithm classes (§1.5): `Machine.IsMultiset`, `Machine.IsSet`, `Machine.IsBroadcast`. * Problem classes (§1.6): `VVc`, `VV`, `MV`, `SV`, `VB`, `MB`, `SB` and the constant-time versions `VVc1`, …, `SB1`. -/ namespace Podc.WeakModelsModalLogic open Function section Graph variable {V : Type*} /-- The degree of a node: the number of its neighbours. -/ noncomputable def deg (G : SimpleGraph V) (v : V) : ℕ := Nat.card (G.neighborSet v) /-- The ports `P(G)` of a graph: pairs `(v, i)` with `i < deg v`. -/ abbrev Port (G : SimpleGraph V) := Σ v : V, Fin (deg G v) /-- `G ∈ F(Δ)`: the maximum degree of `G` is at most `Δ` (finiteness of `V` is a separate `[Finite V]` assumption). -/ def MaxDegLE (G : SimpleGraph V) (Δ : ℕ) : Prop := ∀ v, deg G v ≤ Δ /-- A port numbering of `G` (§1.2): a bijection `p` of the set of ports with `A(p) = A(G)`, i.e. `{(u, v) : p((u,i)) = (v,j) for some i, j} = {(u, v) : {u, v} ∈ E}` (the two inclusions are the fields `adj` and `cover`, see `PortNumbering.A_eq`).
