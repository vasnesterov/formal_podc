import Papers.PODC2012.ResilientRouting.Model import Cslib.Foundations.Combinatorics.SimpleGraph.BFSTree /-! # Theorem 3.1: every connected network has a 1-resilient forwarding pattern The paper's algorithm (Section 3.2.1) is not specified precisely enough to be formalized (see `differencies.md`). We prove Theorem 3.1 with a different, simple construction based on any rooted spanning tree `T` of `G` with root `d` (e.g. a BFS tree). For a vertex `v` let `Sub v` be its subtree. An *exit* of `Sub v` is a non-tree edge `zw` with `z ∈ Sub v`; its *value* is the depth of the lowest common ancestor of `z` and `w` (`cd z w`). The edge `zw` leaves `Sub u` (for an ancestor `u` of `z`) iff its value is `< depth u` (`desc_iff_le_cd`). Every vertex `v` fixes an exit `X v` of minimum value `low v`, and its *escape hop* `esc v`: the other endpoint of `X v` if `X v` starts at `v`, otherwise the child of `v` towards the start of `X v`. Forwarding at `v ≠ d` (`next`): * packet from the parent (*down mode*): to `esc v` if `v` has an exit and that link is up, else back to the parent; * any other packet (*up mode*): to the parent if that link is up; otherwise to `esc v` if `low v < depth v` (the parent link is not a bridge); otherwise drop it. With at most one failed link, up-mode packets climb to `d`; if the failed link is the parent link of `u`, a packet climbing into `u` follows escape hops down `Sub u` (all minimal exits have the same value `low u`, so the descent ends at an exit leaving `Sub u`) and then climbs to `d` on a path that avoids `Sub u`. If the parent link of `u` is a bridge, `Sub u` is cut off and packets there are dropped at `u`. Down-mode packets descend and then switch to up mode. All trajectories terminate, so there are no forwarding loops. -/ namespace Podc.ResilientRouting.OneResilient open SimpleGraph Classical variable {V : Type*} {G : SimpleGraph V} (T : G.RootedTree) /-!
