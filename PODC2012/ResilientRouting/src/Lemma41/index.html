import Papers.PODC2012.ResilientRouting.Model /-! # Lemma 4.1, repaired Lemma 4.1 of the paper: *"For any edge `e_uv`, if `v` has any working path to the destination which does not use the edge `e_vu`, then `v` must not send a packet traveling `u → v` back to `u`."* The proof fails all links of `u` other than `uv` and needs `v` to keep its path to `d` in that scenario; a path that merely avoids the *edge* `vu` may pass through `u` and be destroyed. As stated the lemma is false (`Counterexamples.lemma_4_1_false`); the correct hypothesis is that `v` reaches `d` after the other links of `u` fail (`lemma_4_1`). The core of the argument, for a node `u` whose only live link is `uv`, is `lemma_4_1_core`; with a node `v` that has exactly two live links it forces `v` to pass packets through (`pass_through`). -/
