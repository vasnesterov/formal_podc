The network is a simple graph `G` with a destination `d`. A *forwarding pattern* gives every node `i` a function that maps the link on which a packet arrived (represented by the neighbour `u` it came from) and the set of live incident links (represented by the set `A` of neighbours over live links) to an outgoing incident link (represented by a neighbour of `i`). If the chosen link is down the packet is lost. For a failure set `F` (a set of edges), a *forwarding path* is a walk `x₀ x₁ … x_k` (`k ≥ 1`) in `G \ F` such that every interior vertex `x_j` (`0 < j < k`) is not the destination and forwards `x_{j-1} → x_j` to `x_{j+1}`. The first hop is not constrained (the paper does not model the source's choice). The destination is a sink: a packet is not forwarded any further once it reaches `d` (the paper puts no constraint at `d`, which makes every pattern loop; see `literal_K2`). A pattern is *good* for `F` if (1) every node connected to `d` in `G \ F` has a forwarding path to `d`, and (2) no forwarding path repeats a directed edge (the paper's notion of a forwarding loop, Section 4). It is *t-resilient* if it is good for every `F ⊆ E` with `|F| ≤ t`, and *perfectly resilient* if it is good for every `F ⊆ E`. Besides the definitions, this file contains the trajectory semantics used in the proofs: a forwarding path is the beginning of the deterministic trajectory `δ, nxt δ, nxt² δ, …` of its first dart, so loop-freedom follows from termination of trajectories (`good_of`), and a "trap" (a set of darts closed under forwarding and avoiding `d`) refutes condition (1) (`not_reach_of_trap`). -/ namespace Podc.ResilientRouting open SimpleGraph variable {V : Type*} /-- A forwarding pattern on `G` (the paper's `f^d = (f^d_1, …, f^d_n)`): `next i A u` is the neighbour to which node `i` sends a packet that arrived from `u`, when `A` is the set of neighbours of `i` over live links.
