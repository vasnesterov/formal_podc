import Papers.PODC2012.ResilientRouting.Fig3 import Papers.PODC2012.ResilientRouting.Lemma41 /-! # Theorem 4.3: no perfectly resilient forwarding pattern for the network of Figure 3 The proof follows the paper's strategy, with the two gaps repaired. * **Node 1 routes cyclically** (the instance of Lemma 4.2 that is needed). Let `σ` be the forwarding function of node `1` when its four links are up. For `w ∈ {2,3,4,5}` consider the scenario in which only the four links of `1` and a path `w – m – d` survive. Every other neighbour of `1` is a dead end, so a packet from a node `x ≠ w` bounces between `1` and the dead ends along the `σ`-orbit of `x` until it reaches `w`; hence no proper non-empty subset of `{2,3,4,5}` avoiding `w` is closed under `σ` (`closed_false`). Therefore `σ` is a 4-cycle `5 ↦ a ↦ b ↦ c ↦ 5` (`exists_cycle`; a finite check). * **The failure scenario of Figure 3** (for the cycle `(5 a b c)`; the figure is the case `a, b, c = 2, 3, 4`): the surviving links are `1–2, 1–3, 1–4, 1–5`, `a – X – c` and `b – Y – d`, where `X` is the node of the pair `{a, c}` and `Y` the node of `{b, 5}`. The paper applies Lemma 4.1 to node `a` here, but every path from `a` to `d` passes through `1`, so Lemma 4.1 does not apply. Instead, three more scenarios with the same local views (`pass_through`) show that `a` forwards packets from `1` to `X`, `X` forwards packets from `a` to `c`, and `c` forwards packets from `X` to `1`. Then a packet of node `5` (whose only live link is to `1`) travels `5 → 1 → a → X → c → 1 → 5 → 1 → …` and never reaches `d` (`final_false`).
