Algorithm 1 sends a pebble `P` along a depth-first traversal of a BFS tree `T₁`; when `P` enters a node `v` for the first time it waits one time slot and then starts `BFS_v`. This file analyses the pebble *globally* (the distributed implementation in `Algorithm1.lean` is shown to follow it step by step): * `RTree V`: a rooted tree given by a parent function and a depth function. * `PState`, `PState.step`: the global state of the pebble (position, waiting/ready, the set of entered nodes, and for every node the set of children not yet visited) and one time slot. * `PState.done_all_entered`: after `3n - 1` slots the traversal is over and every node has been entered (Remark 3: the tree is traversed in `O(n)` time, here with the waiting slots counted). * `firstVisit`, `firstVisit_le`: the slot in which the pebble enters `v`, at most `3n - 1`. * `lemma1_sep`: if `u` is entered before `v` then `firstVisit u + 1 + d(u, v) ≤ firstVisit v` (the pebble
