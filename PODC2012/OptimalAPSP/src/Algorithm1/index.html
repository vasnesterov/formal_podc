import Papers.PODC2012.OptimalAPSP.Pebble import Podc.Computability.Distributed.Congest.Typed import Cslib.Foundations.Combinatorics.SimpleGraph.BFSTree /-! # Algorithm 1 of [HW12] as a CONGEST algorithm: APSP in `O(n)` rounds (Theorem 1) The algorithm `apsp r` (for a root `r`, "the node with ID 1"; `n = |V|` is known to all nodes) runs in three stages, switched by a round counter: 1. rounds `1 … n`: a BFS from `r` builds the tree `T₁` (every node learns its parent; in the last round every node learns its children from its neighbours' messages); 2. from round `n + 1` on: the pebble traverses `T₁` depth-first (`Pebble.lean`); when it enters a node `v` for the first time, it waits one slot and `v` starts `BFS_v`: a wave carrying the token `(v, distance)` that every node forwards to all neighbours once, in the round after it first receives it. By Lemma 1 a node never has to forward two tokens in the same round, so a message carries at most one token; 3. from round `5n` on: eccentricities are flooded (max and min) for `n` more rounds, giving the diameter and the radius (Lemmas 2–6). Messages: one tree-message (`Option (Option V)`), one pebble bit, one token (ID and a distance `< n + 1`), two numbers `< n + 1`; i.e. `O(log n)` bits (`msgBits_le`). -/ namespace Podc.OptimalAPSP
