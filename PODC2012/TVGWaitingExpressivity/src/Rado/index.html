import Mathlib.Order.WellQuasiOrder import Mathlib.Order.WellFoundedSet /-! # Lemma 4.10 is false for infinite subsets (Rado's example) Lemma 4.10 of the paper (attributed to Higman [20]) states: if `(Q, ≤)` is a well quasi-order, then `(𝒫(Q), ≤_P)` is a well quasi-order, where `A ≤_P B` iff there is an injective `φ : A → B` with `a ≤ φ a` for all `a ∈ A`. Higman's result is about *finite* subsets (or finite sequences); for arbitrary subsets it fails, by Rado's classical example `Q = {(i, j) | i < j}` with `(i, j) ≤ (k, l)` iff `(i = k ∧ j ≤ l) ∨ j < k`. The paper applies the lemma to infinite antichains `Xᵢ` in the proof of Theorem 4.12.
