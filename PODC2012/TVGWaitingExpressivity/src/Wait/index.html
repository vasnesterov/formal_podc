import Papers.PODC2012.TVGWaitingExpressivity.FromDFA import Podc.Computability.Languages.SubwordClosed /-! # Waiting allowed: `𝓛_wait` is the class of regular languages (Theorem 4.1) The paper's proof goes through a quasi-order `≺` on *words* (Lemma 4.2, Propositions 4.3–4.9, Theorem 4.12) and a theorem of Harju–Ilie (Theorem 4.7); several of those steps are broken (see `README.md`). We prove Theorem 4.1 by working on *walks* (words over the finite alphabet of edges) instead, which is the idea of the paper's Lemma 4.2 made exact: * `Sched.sublist` (Lemma 4.2, corrected): if an edge sequence can be scheduled with waiting, so can each of its subsequences — use, for each kept edge, the departure date it had in the original journey; the dropped edges become pauses. * Hence the set of schedulable edge sequences is closed under subwords and therefore regular (Haines' theorem, `Cslib.Language.IsRegular.of_sublist_closed`, from Higman's lemma). * Intersecting with the (regular) set of walks from an initial to an accepting node and projecting each edge to its label gives `L_wait(G)`; regular languages are closed under both operations. The argument never uses that time is discrete, nor any property of `ρ` and `ζ`. -/ namespace Podc.TVGWaitingExpressivity open TVG TVGAutomaton List variable {V α : Type*} /-- `IsWalk u l v`: the edge sequence `l` is a walk from `u` to `v` in the footprint. -/ def IsWalk : V → List (V × α × V) → V → Prop | u, [], v => u = v | u, e :: l, v => e.1 = u ∧ IsWalk e.2.2 l v namespace TVG variable (G : TVG V α) /-- `G.Sched t l`: the edge sequence `l` can be traversed, waiting allowed, by a journey that is at the start node of `l` at time `t`. -/ def Sched : ℕ → List (V × α × V) → Prop | _, [] => True | t, e :: l => ∃ t₁, t ≤ t₁ ∧ G.present e t₁ ∧ Sched (t₁ + G.latency e t₁) l variable {G} /-- Starting earlier never hurts when waiting is allowed. -/ theorem Sched.anti {t₀ t : ℕ} {l : List (V × α × V)} (h : t₀ ≤ t) (hs : G.Sched t l) : G.Sched t₀ l := by cases l with | nil => trivial | cons e l => obtain ⟨t₁, ht₁, hp, hl⟩ := hs exact ⟨t₁, h.trans ht₁, hp, hl⟩ /-- **Lemma 4.2** of [CFGSY'12], in the form used: with waiting allowed, every subsequence of a schedulable edge sequence is schedulable (from the same start date). -/ theorem Sched.sublist {l' l : List (V × α × V)} (hsub : l' <+ l) : ∀ {t}, G.Sched t l → G.Sched t l' := by induction hsub with | slnil => intro _ _;
