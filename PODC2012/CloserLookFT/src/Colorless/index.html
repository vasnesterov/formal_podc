import Podc.Computability.Distributed.SharedMemory.Resilience import Cslib.Computability.Distributed.SharedMemory.Consensus /-! # Lemma 6.1 of Taubenfeld (PODC 2012): the construction `A'` and its safety Model: CSLib's asynchronous shared-memory model (`Cslib.SharedMemory.Impl`), deterministic processes, atomic base objects; a task algorithm is an `Impl` of `taskObj In Out` (invocation = input, response = output), safety is `Impl.Solves` (the task relation holds in every finite one-shot execution, for the inputs/outputs given so far). Given an algorithm `A` (base objects `B i`, `i : ι`), the algorithm `A' = withOutput A` (proof of Lemma 6.1) has one extra register `output : Option Out`, initially `none` (= ⊥), base objects `OutB B Out : ι ⊕ Unit → ObjSpec`. A process of `A'` alternates * `check`: read `output`; if it contains `v`, go to `adopt v` (then return `v`), else go to * `exec`: take the next step of `A`; if `A` returns `r`, write `some r` into `output` (phase `fin r`) and then return `r`. The local state of `A'` records the local state of `A` and the operation that `A` considers pending (`OutL`), so that every configuration of `A'` *projects* (`projC`) to a configuration of `A`; a step of `A'` is simulated by the labels `projStep A C ℓ` of `A` (`sim_step`): reading `output` and returning are invisible, the write of `output` is the response of `A`. Processes that adopt simply stop in the projected execution of `A` (they look crashed there). * `wstep_cases` — classification of the steps of `A'`; `OutInv` — structural invariant; * `sim_step` — the simulation (for invocations in one-shot executions, `outInv_cond`); * `SafeInv`, `safeInv_of_run` — every finite one-shot execution of `A'` projects to one of `A` with the same inputs in which every value returned by `A'` (own decision or adopted) is the output of some process; * `Colorless` — colorless tasks: `Δ ins outs ↔ R (vals ins) (vals outs)` for a relation `R` on (input value set, output value set) that is downward closed in the output set (as for the colorless tasks of Herlihy–Kozlov–Rajsbaum, whose output complexes are closed under faces); `AdoptClosed` — the only consequence used: outputs may be replaced by `⊥` or by an output of another process (`Colorless.adoptClosed`); * `solves_withOutput` — **safety of `A'`**: `A.Solves T → (withOutput A).Solves T` for adopt-closed `T`. Colorlessness is needed exactly here (adopting).
