import Papers.PODC2012.CloserLookFT.ColorlessLiveness /-! # Section 6 of Taubenfeld (PODC 2012), shared memory: Lemma 6.1, Theorems 6.2 and 6.3 Model: asynchronous shared memory (CSLib), atomic read/write registers (`UsesRegisters`), deterministic processes, crash failures, one-shot task executions with **required participation** (`ReqPart`: every process invokes the task). A *register algorithm* for a task (`HasRegAlgorithm`) uses only registers, accepts every input in every process, solves the task (`Impl.Solves`) and has the given progress property (`WeaklyResilient`/`Resilient` of `Podc/Computability/Distributed/SharedMemory/Resilience.lean`). * `lemma_6_1` — **Lemma 6.1**: for colorless `T` and `t ≤ n - 2`, `T` has a weakly-`t`-resilient register algorithm iff it has a `t`-resilient one (`withOutput`, `solves_withOutput`, `resilient_withOutput`; the converse is `Resilient.weaklyResilient`). * `theorem_6_2` — **Theorem 6.2** (`n ≥ 3`: no weakly-1-resilient consensus), from the external impossibility `LAAImpossibility` (Loui–Abu-Amara), taken as a hypothesis. * `theorem_6_3` — **Theorem 6.3** (`k ≤ n - 2`: no weakly-`k`-resilient `k`-set consensus, `setConsensus`), from the external impossibility `SetConsensusImpossibility` (Borowsky–Gafni, Herlihy–Shavit, Saks–Zaharoglou), taken as a hypothesis. * Non-vacuity: `selfDecide` (return your own input) is resilient and solves `k`-set consensus for `k ≥ n` and consensus on `Unit`; hence `not_setConsensusImpossibility`, `not_LAAImpossibility_unit` (the external hypotheses are not tautologies) and `hasRegAlgorithm_setConsensus_of_le` (the conclusion of Theorem 6.3 fails for `k ≥ n`).
