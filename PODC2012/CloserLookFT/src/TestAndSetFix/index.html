import Papers.PODC2012.CloserLookFT.TestAndSet import Mathlib.Data.Finset.Card import Mathlib.Order.Interval.Finset.Nat /-! # Safety of the corrected test-and-set algorithm (Theorem 3.2, corrected) Taubenfeld, *A closer look at fault tolerance*, PODC 2012, Section 3.1. `TestAndSet.lean` shows that Theorem 3.2 (at most one winner) fails for the printed algorithm. Here we prove it for the corrected algorithm (`fixed = true`: line 10 also loses when `locked = 0`) for **every** number of processes `n ≥ 2` (`theorem_3_2_fixed`). ## Proof idea (an inductive invariant over global states, no ghost state) Call `p` *holding* if it is at line 10 (second read), line 14, a winner, or at line 1 of `reset` (`TLoc.hold`), and a *candidate* if `turn = p` and all locks `p` has checked so far held `p` (`TLoc.cand`; `TLoc.cert` are the checked indices). For a holding or candidate process `p`: * `lost p` — checked locks that no longer hold `p`; * `dest p` — other processes with a pending write (line 5 `lock[j] := q`, or a release `lock[j] := 0`) to a lock that currently holds `p`; * `live p` — other processes about to write `turn` (line 2), plus the competing process whose identifier is in `turn`. Invariant `Inv`: 1. (`ic`) `|lost p| + |dest p| + |live p| ≤ n − 1`. When `p` starts checking, `dest p` and `live p` are disjoint sets of other processes. Afterwards `p` writes no lock, so a lock of `p` is lost only through a pending write of `dest p` (which leaves `dest p`); and nobody joins `live p`, because `turn ≠ 0` (`h0`) and only the owner of `turn` and line-2 writers count. 2. (`il`) If `p` is holding and `r ≠ p` is a candidate owning `turn`, then no lock checked by `r` holds `p` (`p` writes no lock while holding). 3. (`h1`) At most one process is holding. A second process `r` entering the holding zone would, by (2), have taken all `n − 1` locks from the holder `p`, so `|lost p| = n − 1` and by (1) `live p = ∅`, although `r ∈ live p`. This is the paper's counting argument ("each other process can overwrite at most one lock already set by another process") made precise; it does not use the `winner` register. -/ namespace
