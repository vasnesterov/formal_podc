import Papers.PODC2012.LeaderElectionSpaceLB.Model /-! # Non-vacuity of the hypotheses of the space lower bound The space lower bound (Theorem 5.1 of Giakkoupis–Woelfel, PODC 2012) assumes an algorithm that is a leader election (`Alg.IsLeaderElection`) and nondeterministically solo-terminating (`Alg.SoloTerminating`). Here we show that these hypotheses are satisfiable for **every** finite set of processes `P`, by a deterministic obstruction-free algorithm `racing P` using one single-writer register per process (`Reg = P`, values `ℕ`, initial value `0`). ## The algorithm ("racing counters, lose if someone is ahead") Process `p` keeps a counter `c`, initially `1`. One iteration: 1. write `R_p := c`; 2. read the registers `R_q` of all other processes `q ≠ p`, one by one (in a fixed order); as soon as a value `o > c` is read, return `False` (lose); 3. if every value `o` read in this iteration satisfies `o + 2 ≤ c`, return `True` (win); otherwise set `c := c + 1` and start the next iteration. The local state (`St`) records the identity of the process, its phase, the counter `c`, the processes still to be read in the current iteration (`rem`) and the maximum `mx` of the values read so far in the current iteration. ## Proof idea * Per-process invariants (`Inv`): `R_q + 1 = c_q` in the write phase and `R_q = c_q` otherwise; a winner has `mx + 2 ≤ c`; a loser `p` has some `q` with `c_p < c_q`. * Pairwise invariant (`Jst p q`): if `p` has read `q` in its current iteration (or won) and `mx_p + 2 ≤ c_p`, then `c_q ≤ mx_p + 1`, and if `c_q = mx_p + 1` then `q` is in its write phase, or has not yet read `p` in its current iteration, or has lost. (After `p`'s read, `q` writes at most once more, and then reads `R_p = c_p > c_q` and loses.) Two winners would give `c_q < c_p < c_q`. * If all processes of `S` returned, the one with the largest counter cannot have lost (a loser is overtaken by some process with a larger counter, which must have taken steps, hence is in `S`). * Solo termination: in a solo run the other registers stay constant, so the counter cannot grow beyond their maximum `+ 2`. -/ namespace
