Method `elect()`: 1. if `flag.Read() = 1` return `False`; 2. `flag.Write(1)`; 3. choose `x ∈ {1, …, ℓ}` at random (`Pr(x = i) = 2^{-i}` for `i < ℓ`, `Pr(x = ℓ) = 2^{-(ℓ-1)}`); 4. `R[x].Write(1)`; 5. if `R[x+1].Read() = 0` return `True`; 6. return `False`. We model it in the nondeterministic model of `Model.lean`: the coin flip of line 3 is a nondeterministic choice (folded into the step of line 2); its distribution is irrelevant for the deterministic properties proved here. Registers are `Option (Fin (ℓ + 1))`: `none` is `flag`, `some j` is `R[j+1]`. A choice `x ∈ {1, …, ℓ}` is `j : Fin ℓ` with `x = j + 1`, so line 4 writes `some j.castSucc` (= `R[x]`) and line 5 reads `some j.succ` (= `R[x+1]`). ## Results * `GroupElect.steps_le_four` / `GroupElect.waitFree` / `GroupElect.soloTerminating` / `GroupElect.card_reg`: step complexity `O(1)` (at most 4 steps per process, wait-free) and space `ℓ + 2` registers (Lemma 2.2). * `GroupElect.isGroupElection`: in every crash-free execution some process is elected (Lemma 2.2, "at least one process gets elected"). * `GroupElect.not_groupElectLiteral`: the definition of `GroupElect` in Section 2.1 *read literally* ("If some processes call `elect()`, then at least one process must get elected", no crash-freedom qualifier) fails for Figure 1 if processes may crash. * `GroupElect.lemma_2_2_final_bound` (via `GroupElect.final_bound`, which gives `+ 4` for any `1 ≤ k ≤ 2^ℓ`): the last real-number estimate in the proof of Lemma 2.2 (`… ≤ 2 log k + 6`);
