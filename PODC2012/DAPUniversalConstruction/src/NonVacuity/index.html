`LL` is not `ObjSpec.ReadOnly`, whereas the paper calls `LL` trivial. LL/SC can equally be encoded with a version number that the caller keeps locally: `LL` returns the value and the version (a read-only primitive), `SC v ver` succeeds iff the version is still `ver` (no successful `SC` since the caller's `LL`) and then increments it.
