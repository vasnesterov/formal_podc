A fault-free receiver `b` checks `Y s = code c s (X b)` on every coded symbol of its incoming links (step 2 of Algorithm 1). `Correct` is the paper's property (EC): whenever no fault-free node detects a mismatch, all fault-free nodes hold the same value.
