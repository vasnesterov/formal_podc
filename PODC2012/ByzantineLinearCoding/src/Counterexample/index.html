import Papers.PODC2012.ByzantineLinearCoding.Examples /-! # Two small issues in Appendix C, with Lean witnesses 1. **Lemma 1 is false for small fields.** Lemma 1 claims, "for any `ρ_k ≤ U_k/2`", that `M̃_H` is invertible with probability `≥ (1 - (n-f-1)/2^{L/ρ_k})^{ρ_k}`. When `2^{L/ρ_k} < (n-f-1)/2` and `ρ_k` is even, the right-hand side is `> 1`; when it equals `1` the claim says `M̃_H` is *always* invertible, which fails for the all-zero coding. Instance: `n = 7`, `f = 2` (so `n - f - 1 = 4`), `H = K_5` with all link capacities `2` (`U_k = 16`), `ρ_k = 2`, `L = 2`, so the field is `GF(2^{L/ρ_k}) = GF(2)` and the bound is `(1 - 4/2)^2 = 1`. The induction in the paper multiplies inequalities whose factors `1 - (n-f-1)/2^{L/ρ_k}` may be negative. With `n - f - 1 ≤ |F|` the lemma holds (`TreePacking.lemma_1`). 2. **The argument of Appendix C.3 does not prove that `A_q` is invertible.** It only uses that some column has a single nonzero entry, that every row has a nonzero entry and that no two columns have the same support; these properties hold for the incidence matrix of the edges `(1,5), (2,3), (3,4), (4,2)` on the nodes `1..4` (root `5`), which is singular (a cycle, no tree).
