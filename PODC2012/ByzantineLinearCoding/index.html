Byzantine Broadcast with Local Linear Coding (NAB) — PODC 2012

Guanfeng Liang, Nitin Vaidya. Byzantine broadcast in point-to-point networks using local linear coding. PODC 2012. DOI 10.1145/2332432.2332492. Formalized version: arXiv 1106.1845 v3 ("Network-Aware Byzantine Broadcast in Point-to-Point Networks using Local Linear Coding"). Its numbering matches the proceedings version.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. Theorem 1 holds as stated: random coding matrices make the Equality Check correct with probability ≥ 1 − 2^{−L/ρ}·C(n, n−f)(n−f−1)ρ, proved for every finite field, given that each H ∈ Ω_k carries ρ edge-disjoint spanning trees, which the paper gets from the cited Nash-Williams–Tutte theorem. The proof that A_q is invertible (Appendix C.3) has a gap closed in a few lines, the claim itself being true, and everything else is a slip, including Lemma 1, which is false only for small fields outside the paper's large-L regime. NAB's capacity fraction was checked only as arithmetic: Theorem 3 is correct given Theorem 2 and the time bound (24), which enter as hypotheses and, like Phases 1 and 3, were not checked.

Mistakes in the paper

✏️ Slips

  • Lemma 1 (small fields). For 2^{L/ρ_k} < (n−f−1)/2 and even ρ_k the claimed bound (1 − (n−f−1)/2^{L/ρ_k})^{ρ_k} exceeds 1, and for n = 7, f = 2, H = K_5 with all capacities 2, ρ_k = 2, L = 2 (GF(2)) it equals 1 although the all-zero coding makes M̃_H singular (lemma_1_false_small_field). When the base 1 − (n−f−1)/2^{L/ρ_k} is exactly −1, the lemma claims that M̃_H is always invertible; when it is below −1 the bound exceeds 1. In the example (U_k = 16) the bound is (1 − 4/2)² = 1. The induction multiplies Pr[M_q invertible] ≥ (1−w/q)^q by the factor 1 − w/q, which may be negative. This is outside the paper's regime: NAB "is intended to be used for sufficiently large L", and Theorem 1, which only needs det M̃_H ≢ 0, is unaffected. Theorem 1 itself is only meaningful for 2^{L/ρ} > C(n,n−f)(n−f−1)ρ, and in that regime Lemma 1 holds. We prove the lemma under the hypothesis n−f−1 ≤ |F| (TreePacking.lemma_1).

  • Lemma 2 (field size). Lemma 2 and the text before it take the diagonal entries from GF(2^{ρ_k}) and give the bound 1 − w/2^{ρ_k}, but the field is GF(2^{L/ρ_k}), so the bound is 1 − w/2^{L/ρ_k}. (16) uses Lemma 2 with the right field; we prove it for any finite field (lemma_2).

  • The definition of U_k has Ω where it means Ω̄_k. Ω_k must consist of induced subgraphs, otherwise |Ω_1| = C(n, n−f) and U_k > 0 fail.

  • Section 5.1 sets ρ* = U_1/2, which can be a non-integer. ρ_k must be an integer dividing L. Rescaling the time unit (doubling all capacities) repairs this.

Typos

  • In (11) the first two blocks of P_q are both written A_{q+1}S_{q+1,1}. In (8) two blocks are written A_{ρ_k}C_{ρ_k,ρ_k} instead of A_{ρ_k}S_{ρ_k,p}. (12)–(13) write S_{1,k+1} and M_{k+1} for S_{1,q+1} and M_{q+1}.

  • Proof of Lemma 2: R for W, and det(S − R).

Proof gaps in true statements (1)Appendix C.3

🔧 Appendix C.3 (A_q is invertible)

The invertibility argument for A_q never uses that the edges form a tree, and the incidence matrix of the edges (1,5), (2,3), (3,4), (4,2) (root 5) satisfies all its premises yet is singular (c3_argument_insufficient).

Impact. Statement true; repaired over any field (TreePacking.det_A_ne_zero).

Details

The argument uses only three facts:

  1. some column of A_q has a single nonzero entry;

  2. every row has a nonzero entry;

  3. no two columns have the same support.

Repair

If D·A_q = 0, then D takes equal values at the two ends of every tree edge, and connectivity forces D = 0. Our proof uses exactly this, over any field (TreePacking.det_A_ne_zero).

The formalizationmodel, Lean names of the results, trust

Model.

  • One Equality Check (Algorithm 1) on the graph G_k. Nodes form a finite type V with |V| = n and 3f < n. z a b is the integer capacity of link (a, b) of G_k. A coded symbol (Sym z) is one unit of capacity of one link. The coding matrices are one function c : Sym z × Fin ρ → F over an arbitrary finite field F; theorem_1_galois instantiates F = GF(2^{L/ρ}).

  • Values and faults. Each node holds its Phase-1 value as X i : Fin ρ → F. Synchronous, one round, no forwarding. Byzantine faults: faulty senders send arbitrary symbols Y, while fault-free senders send X_i C_e and fault-free receivers check Y_e = X_j C_e.

  • Admissible faulty sets. At most f nodes, containing every node already removed from V_k and one node of every pair found in dispute. This is exactly what dispute control (Phase 3) guarantees.

  • Correctness. Correct is property (EC): if no fault-free node detects a mismatch, all fault-free nodes hold equal values. It is quantified over all admissible faulty sets, all values X and all faulty behaviour Y.

  • Randomness. The coding entries are i.i.d. uniform on F. Probability is counting (Cslib.Probability.uprob).

  • Hypothesis ρ_k ≤ U_k/2. We use it in the form the paper actually uses. Each H ∈ Ω_k carries ρ edge-disjoint unit-capacity undirected spanning trees (TreePacking). The paper gets these from the Nash-Williams–Tutte packing theorem [16], which is not formalized. TreePacking.star and theorem_1_complete show that the hypothesis is met, e.g., when all capacities are ≥ ρ.

Throughput.lean

Proof route for Theorem 1. We do not go through Lemma 1. To show det M̃_H ≢ 0, we evaluate it at an explicit coding: the symbol of tree q carries coordinate q only. There M̃_H is block-diagonal with blocks A_q. Then Schwartz–Zippel applies to ∏_{H∈Ω_k} det M̃_H, which has total degree ≤ |Ω_k|(n−f−1)ρ. This gives the paper's bound for every field size.

Not formalized.

  • Theorem 2, the information-theoretic capacity upper bound. It enters Theorem 3 as a hypothesis.

  • The Nash-Williams–Tutte packing theorem.

  • Phases 1 and 3 and the multi-instance protocol: unreliable broadcast via spanning trees, dispute control, 1-bit Byzantine broadcasts, and the time bound (24), which enters as a hypothesis.

  • det A_q = ±1: we prove only det A_q ≠ 0, which is all the paper uses.

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity: TreePacking.star builds packings and theorem_1_complete discharges the packing hypothesis. The shared Schwartz–Zippel wrapper is staged in Podc/Probability/Finite/SchwartzZippel.lean.
