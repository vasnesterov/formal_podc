import Mathlib /-! # Lemma 4: graphs all of whose bisections are crossed Jaffe, Moscibroda, Sen, *On the Price of Equivocation in Byzantine Agreement*, PODC 2012. Lemma 4 of the paper: *for a graph `G = (V, E)` on `n` vertices, if all bisections are crossed by at least one edge, then `|E| ≥ n/2`.* The paper defers the proof to the full version; we supply one. A graph on the vertex set `U : Finset V` is given by a family `F : Finset (Finset V)` of 2-element subsets of `U`. A *bisection* of `U` is a pair `(S, U \ S)` with `|S| = ⌊|U|/2⌋`; an edge `f` *crosses* it if it meets both `S` and `U \ S`. ## Proof If `2|F| < |U|`, the graph has more than `|U|/2` connected components (adding an edge decreases the number of components by at most one). A family of `c` positive integers with sum `m < 2c` realises every `k ∈ [0, m]` as a sub-sum (`exists_subsum_eq`), so some union of components has exactly `⌊|U|/2⌋` vertices; no edge crosses it. Instead of connected components we use any colouring `χ : V → V` constant on every edge with `|U| ≤ |F| + |χ(U)|` (`exists_coloring`), built by induction on `F` by merging colour classes. -/ namespace
