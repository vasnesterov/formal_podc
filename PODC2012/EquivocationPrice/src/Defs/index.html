import Mathlib /-! # Definitions: f-tolerance, h-disjointness, the numbers `Tₙ(h)` and `Uₙ(h)` Jaffe, Moscibroda, Sen, *On the Price of Equivocation in Byzantine Agreement*, PODC 2012. A system of `n` processors with 3-processor partial broadcast channels is a 3-uniform hypergraph on the processors. We represent a hypergraph on a finite vertex type `V` by its edge set `E : Finset (Finset V)`; it is 3-uniform (`Uniform3 E`) when every edge has three vertices. The paper writes a hyperedge as a triple `(x, y, z)`; here it is the set `{x, y, z}` (the vertices are always distinct where the paper uses it, since they come from disjoint sets). * `Rainbow E A B C`: some hyperedge has one vertex in each of `A`, `B`, `C` (trichromatic edge). * `FTolerant E f`: Definition 1 (`f`-tolerance). * `HDisjoint E h`: Definition 2 (`h`-disjointness), with `n = Fintype.card V`; the size condition `|A| + |B| + |C| ≥ (n + 3h)/2` is written `n + 3h ≤ 2(|A| + |B| + |C|)`. * `crossing A B C`: the triples `{x, y, z}` with `x ∈ A, y ∈ B, z ∈ C` (`|A||B||C|` of them when the sets are disjoint, `card_crossing`); `Rainbow E A B C ↔ ¬ Disjoint E (crossing A B C)`. * `T n h`, `U n h`: Definitions 3 and 7 (minimum number of hyperedges of an `h`-disjoint hypergraph; minimum number of hyperedges forcing `h`-disjointness), on the vertex type `Fin n`. -/ namespace Podc.EquivocationPrice variable {V : Type*} [DecidableEq V] /-- A hypergraph (given by its edge set) is 3-uniform if every edge has exactly three vertices. -/ def Uniform3 (E : Finset (Finset V)) : Prop := ∀ e ∈ E, e.card = 3 /-- Some hyperedge of `E` is trichromatic for the (partial) colouring `A, B, C`: `∃ x ∈ A, y ∈ B, z ∈ C, (x, y, z) ∈ E`. -/ def Rainbow (E : Finset (Finset V)) (A B C : Finset V) : Prop := ∃ x ∈ A, ∃ y ∈ B, ∃ z ∈ C, ({x, y, z} : Finset V) ∈ E variable [Fintype V] /-- **Definition 1** (`f`-tolerance). For all vertex sets `S ≠ T` and `Z` with `|Z| ≤ f`, `|S|, |T| ≥ n - f` and `S ∩ T ⊆ Z ⊂ S ∪ T` there are `x ∈ S \ Z`, `y ∈ T \ Z`, `z ∈ S ∩ T` with `(x, y, z) ∈ E`. (`Z ⊂ S ∪ T` is strict, as in the paper; `|S| ≥ n - f` is written `n ≤ |S| + f`.) -/ def FTolerant (E : Finset (Finset V)) (f : ℕ) : Prop := ∀ S T Z : Finset V, S ≠ T → Z.card ≤ f → Fintype.card V ≤ S.card + f → Fintype.card V ≤ T.card + f → S ∩ T ⊆ Z → Z ⊂ S ∪ T → ∃ x ∈ S \ Z, ∃ y ∈ T \ Z, ∃ z ∈ S ∩ T, ({x, y, z} : Finset V) ∈ E /-- The colourings quantified over in Definition 2: pairwise disjoint `A, B, C` with `|A|, |B|, |C| ≥ h` and `|A| + |B| + |C| ≥ (n + 3h)/2`. -/ def ValidColoring (h : ℕ) (A B C : Finset V) : Prop := Disjoint A B ∧ Disjoint A C ∧ Disjoint B C ∧ h ≤ A.card ∧ h ≤ B.card ∧ h ≤ C.card ∧ Fintype.card V + 3 * h ≤ 2 * (A.card + B.card + C.card) /-- **Definition 2** (`h`-disjointness). Every valid partial colouring `A, B, C` has a trichromatic hyperedge. -/ def HDisjoint (E : Finset (Finset V)) (h : ℕ) : Prop := ∀ A B C : Finset V, ValidColoring h A B C → Rainbow E A B C /-! ###
