import Papers.PODC2012.OrderPreservingByzRenaming.Alg5 /-! # The pseudocode of Rounds 2–3 of Algorithm 5 breaks Lemmas 29–30 Lines 10–11 of Algorithm 5 *add* the ids echoed `n - t` times to `Ids`, which still contains the Round-1 ids, and Lines 13–14 broadcast Ready for all of `Ids`. The text of §6.1.1 ("Only ids that have been echoed at least `n - t` times are considered for the following round") and the proof of Lemma 29 use only the echoed ids; `Alg5.step` follows the text. With the pseudocode, a correct process sends Ready for every id it received in Round 1, and with `n = 3t + 1` (so `n - 2t = t + 1`) one correct Ready plus `t` Byzantine ones get an id accepted. Concrete instance: `n = 4`, `t = 1`, Byzantine process `3` sends the fake ids `10, 11, 12` to the correct processes `0, 1, 2` in Round 1 and Ready for all of them in Round 3.
