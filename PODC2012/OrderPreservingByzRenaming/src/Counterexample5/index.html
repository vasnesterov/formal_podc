So `0, 1, 2` see 5 echoes of `x`, process `2` sees 5 echoes of `y`. * Round 3: both send Ready for `x` to `0` only and Ready for `y` to `2, 3, 4` only. Result: `timely₀ = {2, …, 7}`, `timely_i = {3, …, 7}` for `i ≥ 1`; `accepted₀ = accepted₁ = {2, …, 7}`, `accepted_i = {1, …, 7}` for `i ≥ 2`. Hence processes `0, 1` rank `x, 3` as `δ, 2δ`, processes `2, 3, 4` as `2δ, 3δ`. * Round 4: both send process `1` the vote `x ↦ 3δ, k ↦ (k - 1)δ (k = 3, …, 7)`. It is valid at `1` (`x ∉ timely₁`), and process `1` computes `ranks[x] = 2δ` and `ranks[3] ∈ {2δ, 2.5δ}` (both choices of `select_t`): the spacing `δ` between `x` and `3` is lost. * Round 5: process `0` (with `x ∈ timely₀`) rejects the vote of the correct process `1` (**Lemma 33 fails**); the Byzantine processes send nothing to `0`.
