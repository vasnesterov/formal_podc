import Papers.PODC2012.OrderPreservingByzRenaming.Spec /-! # The 2-round echo-counting algorithm (Algorithm 8, §6.3) Processes are `Fin n` on the complete network. A process receives its own messages through the self-loop (link `n` in the paper); in CSLib's `LockStep` there is no self-loop, so a process adds its own message to its inbox itself (`Function.update`). * Round 1: broadcast `⟨ID, my id⟩`; `linkid[lnk]` is the id received on link `lnk`, `timely` the set of ids received. * Round 2: broadcast `⟨MultiEcho, timely⟩`. An echo `ids` from link `lnk` is *valid* (`isValid`) iff `linkid[lnk] ≠ ⊥`, `|ids| ≤ n` and `|timely ∩ ids| ≥ n - t`. `counter[id]` = number of valid echoes containing `id`, `accepted` = union of the valid echoes. * New name: `newid[my id] = ∑_{id ∈ accepted, id ≤ my id} min(counter[id], n - t)` (Lines 17–22). -/ namespace Podc.OrderPreservingByzRenaming.TwoRound open Cslib.Byzantine.LockStep /--
