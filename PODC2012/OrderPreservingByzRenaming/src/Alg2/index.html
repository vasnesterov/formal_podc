For every `id ∈ V`, `proposedNewIds` collects `vᵢ[id]` (or `predecessorNewId(vᵢ, id)` if `id ∉ vᵢ`), and `newId := avg(proposedNewIds)` (Algorithm 5). The first vote epoch is Algorithm 6, which also recomputes `minOffset` from the offsets of the accepted votes. * `Skew` of vote epoch `k` is `3t² (2t/N)^(k-1)`. The output is `⌈newId[my id] / (N − t − Skew)⌉` with the final `Skew = 3t² (2t/N)^K`. arXiv v2 has `K = 4⌈log t⌉ + 2` vote epochs (epoch 2: Algorithm 6, epochs `3, …, 4⌈log t⌉ + 3`: Algorithm 5). arXiv v1 has a separate local epoch for the minimum offsets and one vote epoch less (`K = 4⌈log t⌉ + 1`).
