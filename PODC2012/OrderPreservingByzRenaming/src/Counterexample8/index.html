import Papers.PODC2012.OrderPreservingByzRenaming.TwoRound /-! # Algorithm 8 needs `n > 2t² + t`: a counterexample for `n = 9 > t² + 2t`, `t = 2` The heading of §6.3 (and the table of contents) announce Algorithm 8 for `n > t² + 2t`; the caption of Algorithm 8, the text and Theorem 45 say `n > 2t² + t`. The two bounds differ for `t ≥ 2`. We show that the stronger heading is false: for `n = 9`, `t = 2` (so `n > t² + 2t = 8`) Algorithm 8 violates order preservation. *Execution.* Correct processes `0, …, 6` with ids `10, …, 16`; Byzantine processes `7, 8`. In Round 1 the Byzantine processes send the ids `1` and `2` to process `0` only (nothing to the others). In Round 2 both send to process `0` the echo `{10, …, 14, 1, 2, 3, 4}` (9 ids, 7 of them timely at process `0`: valid), and nothing to the others. Then process `0` computes `newid[10] = 3 + 3 + 2 + 2 + 7 = 17`, while process `1` computes `newid[11] = 1 + 1 + 7 + 7 = 16`: the correct process with the smaller id gets the larger name. -/ namespace
