Simulated round `r ≥ 1` is *owned* by `p_{r mod n}` (line 1). Atomic steps of simulator `i` in round `r`: * `start`, owner (lines 2–3, one iteration of the repeat loop): `arw_view ← S[r].collect()`, `FD_VAL[i] ← C.read()`; if `PROP(arw_view, FD_VAL[i])` holds go to `write`, else iterate again; * `start`, non-owner (line 4): `FD_VAL[i] ← C.read()`, go to `write`; * `write` (lines 6–7): `iis_view ← S[r].arw_write_snapshot()`; this ends the simulation of `IS[r].write_snapshot()` by `q_i`, whose `C*.read()` returns `FD_VAL[i]`. The collect and the write-snapshot are taken atomic (a sequential execution of these objects is one of their legal executions), so `arw_write_snapshot` returns the set of simulators that have written `S[r]` so far. The failure-detector history is `H i t` (output of `C` at simulator `i` at time `t`); `sched t` is the simulator that moves at time `t`. ## Σ (Section 4.4, Theorem 4) Section 4.4 claims that Figure 3 with `PROP_{◇P}(arw_view) = ∀ j ∈ FD_VAL[i], j = i ∨ ⟨j,-⟩ ∈ arw_view` correctly simulates `IIS_n[Σ*]` in `ARW_n[Σ]` (and the same for `S, ◇S, S_x, ◇S_x`); Theorem 4 states it "for the failure detector classes studied in this paper" (with `t = n − 1` the extra conjunct `|arw_view| ≥ n − t − 1` is vacuous). `sigma_simulation_false` refutes it with two simulators: `p_0` always runs its round first, so it never sees `p_1` and `q_1` is weakly correct, while `p_0`'s Σ-quorum, read at the rounds it does not own, is `{p_0, p_1}`.
