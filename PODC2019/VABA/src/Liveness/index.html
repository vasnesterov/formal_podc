import Papers.PODC2019.VABA.LivenessInv /-! # VABA: views complete (Lemmas 7, 17–19) If honest parties keep delivering each other's messages, every view completes. We prove the constructive form: from every reachable state in which all honest parties are in view `≥ j`, honest steps alone (no corruption, no Byzantine signatures; any coin) lead to a state in which all honest parties are in view `> j` (`view_progress`). Combined with `ExpectedViews.lean` this shows that the probability bounds there are not vacuous: views do complete, and a view completes with everybody deciding as soon as its leader's broadcast completed (Lemma 22). Proof outline: if a skip certificate of view `j` exists (case A), every honest party in view `j` invokes `elect`, `elect` returns (the coin was revealed by the first invocation), every honest party receives the view-change messages of all honest parties and leaves the view.
