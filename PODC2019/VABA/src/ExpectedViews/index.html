The states contain everything (all local states, all signature shares, the corrupted set) except the coins that have not been revealed yet, so `σ` is an adaptive adversary that also schedules all messages and corruptions. With a coin sequence `c` this determines a run `run C σ c`. Let `good σ c j` be the set of proposers whose broadcast of view `j` has a stage-4 certificate at the moment the coin of view `j` is revealed (all of `P` if it is never revealed).
