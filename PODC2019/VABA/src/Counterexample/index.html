import Papers.PODC2019.VABA.Safety /-! # VABA: the thresholds `2f + 1` need `n = 3f + 1` The paper allows any `f < n/3` but hard-codes the threshold `2f + 1` for signatures and for the number of view-change messages. Its proof of PB-provability (Lemma 3) says: two sets of `2f + 1` signers each contain `f + 1` honest parties, "and thus there is an honest party in both". This needs `2(f + 1) > n - f`, i.e. `n = 3f + 1`. For `n = 5`, `f = 1` (so `f < n/3`) and threshold `2f + 1 = 3` we exhibit a reachable state of the protocol model with two stage-1 certificates on different values in the broadcast of the corrupted party `4` in view 1: honest parties `0, 1` deliver `true`, honest parties `2, 3` deliver `false`, and party `4` signs both. (If party `4` is elected, continuing the same equivocation through stages 2–4 lets `0, 1` decide `true` and `2, 3` decide `false`.) With the threshold `n - f = 4` instead, `n + f < 2Q` holds and `Safety.lean` applies. -/ namespace VABA.Counterexample open Finset /-- `n = 5` parties, `f = 1`, threshold `Q = 2f + 1 = 3`. -/ def C5 :
