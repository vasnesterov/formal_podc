A set `R` of not-yet-queried neighbours determines `X_v = Edges vol R`, the edges from `v` to `R`. A trial draws `s` edges of `X_v` uniformly and independently with replacement; `queried f` is the set of neighbours hit. The proof of Lemma 4.3 partitions the neighbours into `L = 2h` volume classes with ratio `b = n^ε`, takes the class `K` of maximum volume, cuts it into `q = ⌊|K|/β⌋` groups of `β = ⌈|K|/α⌉` nodes, and shows that each group is hit with probability `≥ 1 − (1 − θ)^s`, `θ = 1/(L α b)`. u⌋`, so that `b^x ≤ vol u < b^{x+1}` on class `x`. **The paper writes the class as `vol u ∈ (b^x, b^{x+1}]`, which excludes volume `1` (all neighbours in the simple graph `G_0`!); we use `[b^x,
