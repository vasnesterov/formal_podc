import Podc.Foundations.Combinatorics.SimpleGraph.ClusterSpanner /-! # The cluster hierarchy of algorithm `Sampler` (Section 3, Lemma 4.5, Theorem 4.6) Bitton, Emek, Izumi, Kutten. *Message Reduction in the LOCAL Model is a Free Lunch.* PODC 2019 (arXiv:1909.08369v1). `Sampler` runs `Cluster_j` for `j = 0, …, k` on graphs `G_0 = G, G_1, …, G_k`, where `G_{j+1}` is the cluster graph of `G_j` w.r.t. the clusters formed at level `j`. We model **an arbitrary outcome** of the random choices: the deterministic content of the stretch analysis is that *every* outcome satisfying the postconditions of the procedure (and the "whp" facts of Lemmas 4.2 and 4.3) gives a `(2·3^k − 1)`-spanner. ## Representation * A level-`j` node is identified with a vertex of `V` (its root: a level-`(j+1)` node is a level-`j` center, so inductively every node is an original vertex). `cl j x = some a` means that the original vertex `x` lies in the level-`j` cluster `C_j(a)`; `cl j x = none` means that `x` was in an unclustered node at some level `< j`. * `merge j a` is the outcome of the second step of `Cluster_j` for the level-`j` node `a`: `some a` if `a` is a center, `some b` if `a` joined the cluster of the center `b`, `none` if `a` is unclustered. * The edges of the multigraph `G_j` between level-`j` nodes `a` and `b` are the original edges of `G` between `C_j(a)` and `C_j(b)` (`cross j a b`); this is exactly the paper's `E_j(a, b)`, multiplicities included. * `F j a` is the edge set `F_a` produced by the first step of `Cluster_j` for node `a`.
