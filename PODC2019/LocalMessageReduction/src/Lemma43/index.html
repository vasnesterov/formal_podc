import Papers.PODC2019.LocalMessageReduction.Trial /-! # Lemma 4.3 for one node: all `2h` trials of the first step of `Cluster_j` We run the first step of `Cluster_j` (Pseudocode 2, lines 4–12) at a fixed node `v` whose neighbourhood in `G_j` is `N` with volumes `vol`. The state is the set `R` of neighbours not yet queried; the loop runs while fewer than `L` trials were made, `X_v ≠ ∅` (`R ≠ ∅`) and `|F_v| = |N \ R| < τ`. A trial draws `s` edges of `X_v` uniformly with replacement and removes the queried neighbours from `R`. **Randomness.** The trials are adaptive (`X_v` depends on the earlier trials). To keep a single finite uniform sample space we draw, for every trial `t < L` and sample `i < s`, a uniform number in `Fin M` with `M = (vol N)!`; it is decoded into a uniform edge of the current `X_v` (whose size divides `M`) by `decodeEdge`. The decoded samples of a trial are exactly uniform (`uprob_decode`), whatever the history, which is all the paper's conditioning ("we treat those events as if they necessarily occur") needs. **Result** (`lemma_4_3_node`). With `L` classes of ratio `b`, all volumes in `[1, b^L)`, `α ≥ 6`, `τ ≤ α/3` and `θ = 1/(L α b)`, after the loop `v` is light (`R = ∅`) or heavy (`|N \ R| ≥ τ`), except with probability at most `L · |N| · (1 − θ)^s`. With the paper's parameters (`L = 2h`, `b = n^ε`, `α = 3c n^{2^j δ} log² n / h`, `s = c² n^{2^j δ + ε} log³ n`, `τ = c n^{2^j δ} log n`) this is `≤ 2h · n · n^{−c/6}` (`theta_mul_samples`). -/
