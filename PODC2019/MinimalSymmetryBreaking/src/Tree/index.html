Distances are word lengths: `dist(v, w) = ‖v⁻¹ w‖`. The radius-`r` view of `v` of a field `x` is `shift v x = (h ↦ x (v * h))` restricted to the ball of radius `r` around the origin; so an algorithm is a function of the field around the origin, and translation invariance is built in.
