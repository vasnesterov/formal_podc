import Papers.PODC2019.MinimalSymmetryBreaking.Tree /-! # Anonymous randomized algorithms on the oriented tree; the speedup lemmas Section 5 (`Δ = 4`) and Section 7 (`Δ = 2k`) of the paper. Nodes have no identifiers; every node `v` has an independent random value `x v` from a finite probability space `(Ω, μ)`. * A `t`-round (node) algorithm with palette `α` is a function `out` of the field around the origin that only depends on the ball of radius `t`; node `v` outputs `out (shift v x)`. It *fails locally* at `v` if all `2k` neighbours of `v` output the same colour as `v` (no weak colouring). * A `t`-round edge algorithm assigns to the edge `{v, v gᵈ}` of dimension `d` the value `out d (shift v x)`, a function of the balls of radius `t` around both endpoints. It fails locally at `v` if, in every dimension, the two edges of `v` get the same value. Since all nodes of the tree look the same, the local failure probability does not depend on the node; we compute it at the origin (`failProb`). -/ namespace Podc.MinimalSymmetryBreaking open Finset
