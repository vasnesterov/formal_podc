import Mathlib /-! # Finite i.i.d. random fields with resampling (conditioning on a region) Randomness for anonymous randomized LOCAL algorithms: every node `i : ι` of a (possibly infinite) network gets an independent random value `x i` from a finite probability space `(Ω, μ)`. All events we consider depend on finitely many nodes, so probabilities are computed by summing over the configurations `y : F → Ω` on a finite set `F` of nodes (the field is `default` outside `F`); the result does not depend on `F` as long as `F` contains the nodes the event depends on (`expect_eq_of_dependsOn`). Conditioning on the values in a region `S` is expressed by *resampling* the field outside `S`: `condE μ F S h x` is the expectation of `h` when the values in `S` are those of `x` and the values outside `S` are fresh. The key facts are the tower property `expect_mul_condE`, the reduction `condE_eq_of_dependsOn` (an event that depends on `T ∪ D` with `T ⊆ S`, `D ∩ S = ∅` has the same conditional probability given `S` and given `T`), and conditional independence of events depending on pairwise disjoint regions outside `S` (`condE_prod`). All proofs are by finite sums and the measure-preserving involution `(y, y') ↦ (y|_S ∪ y'|_{Sᶜ}, y'|_S ∪ y|_{Sᶜ})`. -- CSLib candidate (`Cslib/Probability/Finite/Field.lean`). -/ -- CSLib candidate
