import Papers.PODC2019.MinimalSymmetryBreaking.Lemmas78 import Papers.PODC2019.MinimalSymmetryBreaking.FieldProd import Papers.PODC2019.MinimalSymmetryBreaking.Packing import Papers.PODC2019.MinimalSymmetryBreaking.Asymptotics /-! # Finite trees with identifiers: Claim 10, Lemma 9, Theorems 6 and 13 The instances are finite sets `V` of nodes of the oriented `2k`-regular tree containing a ball `B_K` around the origin; the network is the subgraph induced by `V` (with `V` connected, as in `exists_subtree`, it is a tree of maximum degree `2k` whose ball `B_K` is a complete `2k`-regular ball, with a consistent orientation). Every node has a unique identifier in `Fin n`, `n = |V|`, and an independent random value from `(Ω, μ)`. A `t`-round algorithm (`IdAlg`) maps what a node sees within distance `t` — which of the nodes exist, their identifiers and random values, with the orientation — to a colour `Bool`. (It sees the nodes of `V` within tree distance `t`; for a connected `V` these are exactly the nodes within distance `t` in the network. It also knows `n`.) Claim 10 (`succProb_le`): from a lower bound `q` on the local failure probability of anonymous algorithms (with randomness `Fin n × Ω`), every algorithm with identifiers succeeds with probability at most `(1-q)^|S| + |B_K|²/n` for some identifier assignment, where `S ⊆ B_{K-t-1}` is any set of nodes with pairwise disjoint `(t+1)`-balls. The paper takes nodes at pairwise distance `≥ 2t+1`; their failure events (which depend on the `(t+1)`-balls) need not be independent, so we use disjoint `(t+1)`-balls (distance `≥ 2t+3`). -/
