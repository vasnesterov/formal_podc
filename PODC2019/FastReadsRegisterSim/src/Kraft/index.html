import Mathlib /-! # Prefix-free families of binary strings A family `S : α → List Bool` is *prefix-free* if `S a <+: S b` implies `a = b` (in particular `S` is injective). If all strings have length `≤ n`, then `|α| ≤ 2 ^ n` (`card_le_two_pow_of_prefixFree`), and if moreover `|α| = 2 ^ n`, every string has length exactly `n` and every binary string of length `n` occurs (`complete_of_prefixFree`): the family is the set of leaves of the complete binary tree of depth `n`. These are the counting facts behind Lemma 3.3 of the paper (the decision tree of a read with at most `log₂ k` reads is a complete binary tree with `k` leaves at depth `log₂ k`). -- CSLib candidate
