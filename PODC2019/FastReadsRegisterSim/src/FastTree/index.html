*steps*, then every step of the first read is a read of a fresh register (the read is invisible), and the read is described by a complete binary decision tree of depth `m` (paper: Lemmas 3.3, 3.4 and the remark that the first read is invisible): * `node act l₀ u` — the local state after the reads returned the bits `u`; * for `|u| < m` the next step is a read (`node_read`); for `|u| = m` the read returns `val u` (`node_ret`), and `val` is a bijection from the strings of length `m` to `V` (`str_val`, `val_str`); * `path act l₀ M j` — the bits read in the first `j` steps when every read sees memory `M`. -/ set_option linter.unusedSectionVars false namespace Podc.FastReadsRegisterSim open Cslib.SharedMemory variable {V : Type} {v₀ : V} {ι L : Type} [DecidableEq ι] section Defs variable
