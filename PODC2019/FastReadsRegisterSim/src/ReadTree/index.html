Running it *solo* from local state `l` on memory `M` is a deterministic sequence of pairs `lrun act n (l, M)` (local state, memory). This file develops the combinatorics behind Lemmas 3.3 and 3.4 of the paper, abstractly: * `rr act s N` — the list of `(register, value)` pairs read in the first `N` steps; * **lockstep** (`lockstep`): two solo runs from the same local state on memories `M`, `M'` stay in the same local state as long as their reads return the same values, and they first differ at a read of a register that the process has not accessed before (`diverge`); * `SeqReads` — hypotheses describing the first read of a reader after a solo write of `v` (memory `M v`) for every `v`: the solo read returns, and it returns `v`. Its read-response strings `s v` are a prefix-free family (`prefixFree`), hence `|V| ≤ 2^(max |s v|)` (Theorem 3.1) and, if every read reads at most `m = log₂ |V|` registers, the strings are exactly all binary strings of length `m` (`complete`, Lemma 3.3) and each read accesses a register for the first time (`fresh`, Lemma 3.4). -/ set_option linter.unusedSectionVars false namespace
