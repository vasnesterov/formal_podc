import Mathlib /-! # Problems and the speedup operators (Brandt, PODC 2019, §3 and §4.1–4.2) A *problem* (§3) is given by a set of output labels `O`, and for every maximum degree `Δ` * `f Δ ⊆ O` (the labels allowed for degree `Δ`; finite in the paper), * `g Δ`, a set of 2-element multisets of labels (edge configurations), * `h Δ`, a set of multisets of at most `Δ` labels (node configurations). We keep `f`, `g`, `h` as arbitrary sets; the well-formedness conditions of the paper are collected in `Problem.WF` and are preserved by the operators (`WF.edgeStep`, `WF.nodeStep`), but none of the speedup theorems needs them. The derived problems of §4.1: * `P.edgeStep` is `Π_{1/2}`: labels are sets `Y ⊆ f Δ`, an edge `{Y, Z}` is good if *every* `{y, z}` with `y ∈ Y`, `z ∈ Z` is good (Property 1), a node is good if *some* choice of one label per set is good (Property 2); * `P.nodeStep` is the dual step (Properties 3 and 4): edges existential, nodes universal; * `P.speedup = P.edgeStep.nodeStep` is `Π_1`. The simplified problems of §4.2 (Properties 5 and 6) are `edgeStepMax`, `nodeStepMax` and `speedupMax = P.edgeStepMax.nodeStepMax` (`Π'_1`). -/ -- CSLib candidate (problems and round-elimination operators) namespace AutomaticSpeedup /-- A problem in the sense of §3 (for all maximum degrees `Δ` at once). -/ structure Problem (L : Type*) where /-- `f Δ`: the output labels usable in graphs of maximum degree `Δ`. -/ f : ℕ → Set L /-- `g Δ`: the allowed edge configurations (2-element multisets). -/ g : ℕ → Set (Multiset L) /-- `h Δ`: the allowed node configurations (multisets with at most `Δ` elements). -/ h : ℕ → Set (Multiset L) namespace Problem variable {L : Type*} /-- The well-formedness conditions of §3, items 2–4. -/ structure WF (P : Problem L) : Prop where f_finite : ∀ Δ, (P.f Δ).Finite g_card : ∀ Δ, ∀ m ∈ P.g Δ, Multiset.card m = 2 g_sub : ∀ Δ, ∀ m ∈ P.g Δ, ∀ x ∈ m, x ∈ P.f Δ h_card : ∀ Δ, ∀ m ∈ P.h Δ, Multiset.card m ≤ Δ h_sub : ∀ Δ, ∀ m ∈ P.h Δ, ∀ x ∈ m, x ∈ P.f Δ /-- Property 1 of §4.1 (universal edge condition) for a pair of sets of labels. -/ def EdgeAll (P : Problem L) (Δ : ℕ) (Y Z : Set L) : Prop := Y ⊆ P.f Δ ∧ Z ⊆ P.f Δ ∧ ∀ y ∈ Y, ∀ z ∈ Z, ({y, z} : Multiset L) ∈ P.g Δ /-- Property 3 of §4.1 (existential edge condition) for a pair of sets of labels. -/ def EdgeEx (P : Problem L) (Δ : ℕ) (Y Z : Set L) : Prop := Y ⊆ P.f Δ ∧ Z ⊆ P.f Δ ∧ ∃ y ∈ Y, ∃ z ∈ Z, ({y, z} : Multiset L) ∈ P.g Δ /-- Property 2 of §4.1 (existential node condition): the multiset `m` of sets of labels has at most `Δ` elements, all of them subsets of `f Δ`, and one can choose one element from each set so that the resulting multiset is in `h Δ`. A *choice* is a multiset `m'` related to `m` by `∈` elementwise (`Multiset.Rel`). -/ def NodeEx (P : Problem L) (Δ : ℕ) (m : Multiset (Set L)) : Prop := Multiset.card m ≤ Δ ∧ (∀ Y ∈ m, Y ⊆ P.f Δ) ∧ ∃ m', Multiset.Rel (· ∈ ·) m' m ∧ m' ∈ P.h Δ /-- Property 4 of §4.1 (universal node condition). -/ def NodeAll (P : Problem L) (Δ : ℕ) (m : Multiset (Set L)) : Prop := Multiset.card m ≤ Δ ∧ (∀ Y ∈ m, Y ⊆ P.f Δ) ∧ ∀ m', Multiset.Rel (· ∈ ·) m' m → m' ∈ P.h Δ /-- `Π_{1/2}` (§4.1, Properties 1 and 2). -/ def edgeStep (P : Problem L) : Problem (Set L) where f Δ := {Y | Y ⊆ P.f Δ} g Δ := {m | ∃ Y Z, m = {Y, Z} ∧ P.EdgeAll Δ Y Z} h Δ := {m | P.NodeEx Δ m} /-- The second half step `Π_{1/2} ↦ Π_1` (§4.1, Properties 3 and 4). -/ def nodeStep (P : Problem L) : Problem (Set L) where f Δ := {Y | Y ⊆ P.f Δ} g Δ := {m | ∃ Y Z, m = {Y, Z} ∧ P.EdgeEx Δ Y Z} h Δ := {m | P.NodeAll Δ m} /-- The speedup `Π ↦ Π_1` of §4.1. -/ def speedup (P : Problem L) : Problem (Set (Set L)) := P.edgeStep.nodeStep /-- Property 5 of §4.2: Property 1, and both sets are maximal with this property. -/ def EdgeAllMax (P : Problem L) (Δ : ℕ) (Y Z : Set L) : Prop := P.EdgeAll Δ Y Z ∧ (∀ Y', Y ⊂ Y' → ¬ P.EdgeAll Δ Y' Z) ∧ (∀ Z', Z ⊂ Z' → ¬ P.EdgeAll Δ Y Z') /-- Property 6 of §4.2: Property 4, and no set of the multiset can be enlarged. -/ def NodeAllMax (P : Problem L) (Δ : ℕ) (m : Multiset (Set L)) : Prop := P.NodeAll Δ m ∧ ∀ Y ∈ m, ∀ Y', Y ⊂ Y' → ¬ P.NodeAll Δ (Y' ::ₘ m.erase Y) /-- `Π'_{1/2}`: `Π_{1/2}` with Property 1 replaced by Property 5 (§4.2). -/ def edgeStepMax (P : Problem L) : Problem (Set L) where f Δ := {Y | Y Problem (Set (Set L)) := P.edgeStepMax.nodeStepMax /-- Iterated speedup `Π_k` (label type `Set (Set ⋯ L)`, `2k` times). -/ def IterLabel (L : Type*) : ℕ → Type _ | 0 => L | k + 1 => Set (Set
