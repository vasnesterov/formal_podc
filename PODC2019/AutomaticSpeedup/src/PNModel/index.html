import Papers.PODC2019.AutomaticSpeedup.Abstract import Cslib.Computability.Distributed.PortNumbering.Basic /-! # The port-numbering model with input labels (Brandt, PODC 2019, §3) * `LGraph I n`: a port-numbered graph on `n` nodes (CSLib's `PNGraph (Fin n)`) with an input label in `I` at every port, i.e. at every pair `(v, e) ∈ B(G)` (the paper's `Σ`-input-labelled graphs). * `ViewT I t`, `LGraph.view`: the radius-`t` neighbourhood `N^t(v)`, defined as the information a node can gather in `t` rounds of the port-numbering model (its full-information state): own input labels, and for each port the neighbour's radius-`(t-1)` view together with the port number at the neighbour. * `LGraph.eview`: the radius-`t` view `N^t(e)` of the edge behind port `i` of `v`, seen from `v`: the radius-`(t-1)` views of both endpoints and the port numbers of `e` at both endpoints. This is the information both endpoints have after `t` rounds. * `SolvableIn 𝒢 P Δ t`: some deterministic CSLib port-numbering algorithm solves `P` on every graph of the class `𝒢` within `t` rounds. * `IsIndependent 𝒢 t`: `t`-independence (§3), literally: clauses 1 and 2 with views as above. `solvableIn_iff_view`: a problem is solvable in `t` rounds iff some function of radius-`t` views solves it.
