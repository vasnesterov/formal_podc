import Papers.PODC2019.AutomaticSpeedup.Theorem1 /-! # Superweak `k`-colouring and its trit description (Brandt, PODC 2019, §5.1) * `superweak k`: each node outputs a colour from `Fin k` (the paper's `{1, …, k}`) and, at each port, a pointer kind: demanding `→` (`Ptr.demand`), accepting `⊸` (`Ptr.accept`) or none `•` (`Ptr.none`). Node configurations (regular graphs of degree `Δ`): exactly `Δ` labels, one colour, and `#⊸ < min (k + 1) #→`. Edge configurations: different colours, or both `•`, or some `⊸`. * `Trit k = Fin k → Fin 3`: trit sequences of length `k`. * `tritHalf k`: the paper's "equivalent description" of `Π'_{1/2}` (derived from superweak `k`-colouring): labels are trit sequences; an edge is good iff the tritwise sum is `22…2`; a node configuration (of `Δ` sequences) is good iff some position `j` has at most `k` zeros and strictly more twos than zeros. * `tritOne k = (tritHalf k).nodeStepMax`: the paper's description of `Π'_1` (Properties A and B). * `toTrit`: the paper's bijection between the usable `Π'_{1/2}` labels and trit sequences (`0` for `{⊸}`, `1` for `{⊸, •}`, `2` for `{→, ⊸, •}` in each colour). -/ namespace AutomaticSpeedup open Problem /-- Pointer kinds of superweak colouring: demanding (`→`), accepting (`⊸`), none (`•`). -/ inductive Ptr | demand | accept | none deriving DecidableEq, Repr instance : Fintype Ptr := ⟨{.demand, .accept, .none}, by intro x; nodes: Properties A (every choice is good for `tritHalf`) and B (maximality). -/ def tritOne (k : ℕ) : Problem (Set (Trit k)) := (tritHalf k).nodeStepMax /-- The map from `Π'_{1/2}` labels (sets of superweak labels) to trit sequences: in colour `c`, `2` if `(c, →)` is present, else `1` if `(c, •)` is present, else `0`. On the usable labels this is the paper's bijection. -/ noncomputable def toTrit {k : ℕ} (Y : Set (Fin k × Ptr)) : Trit k := by classical exact fun c => if (c, Ptr.demand) ∈ Y then 2 else if (c, Ptr.none) ∈ Y then 1 else 0 end AutomaticSpeedup
