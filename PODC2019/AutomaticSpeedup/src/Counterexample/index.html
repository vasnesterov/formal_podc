import Papers.PODC2019.AutomaticSpeedup.Theorem1 /-! # Theorem 1, (2) ⇒ (1), is false without edge symmetry breaking The paper's proof of (2) ⇒ (1) lets both endpoints `u, v` of an edge `e` pick a pair `(o, o')` from their two `Π_1`-outputs with `{o, o'} ∈ g_{1/2}`, `v` taking `o` and `u` taking `o'`, "by looking only at `N^t(e)`". This needs the two endpoints to agree on who is who. If `N^t(e)` looks the same from both sides, both endpoints make the same choice. Counterexample. `Π` = *edge orientation*: labels `{true, false}`, an edge is good iff its two half-edges carry different labels, every node configuration is good. Then the constant output `{{true}, {false}}` solves `Π_1` in `0` rounds (hence in `t - 1` rounds) on every graph, but in any graph where some edge has the same port number at both ends and both endpoints have the same view (for instance a single edge `K_2`, or any `d`-regular graph whose port numbering is a proper edge colouring, with no inputs), no algorithm solves `Π` at all. `theorem_1_backward_false`: for every `t ≥ 1`, the class consisting of `K_2` alone (`n = 2`, `Δ = 1`, simple, connected, acyclic, so of girth `∞ ≥ 2t + 2`) is `t`-independent, `Π_1` is solvable in `t - 1` rounds and `Π` is not solvable in `t` rounds. -/ namespace AutomaticSpeedup open Cslib.PortNumbering Problem /-- Edge orientation: the two half-edges of every edge carry different labels. -/ def orientation : Problem Bool where f _ := Set.univ g _ := {{true, false}} h Δ := {m | Multiset.card m ≤ Δ} theorem orientation_wf : orientation.WF where f_finite _ := Set.toFinite _ g_card _ m hm := by rw [Set.mem_singleton_iff.1 hm];
