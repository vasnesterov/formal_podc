We state this for an arbitrary well-formed history `α` of the CRDT object (CSLib `Label`s) together with a map `ls` assigning to each completed query operation the state it learned (`LearnedHistory`), and prove that `α` has a linearization in the sense of CSLib (`Cslib.SharedMemory.IsLinearization`). Update identifiers are assumed unique (as in the paper, "we assume updates to be unique"). Validity is split in two: every update in the causal history of a learned state has been invoked (`validity_invoked`), and none of them is invoked after the query returned (`validity_before`). -/ --
