import Papers.PODC2019.CRDTReplication.CRDT import Cslib.Computability.Distributed.MessagePassing.Async /-! # Algorithm 2: linearizable state machine replication of state-based CRDTs The protocol of Section III-B as a CSLib asynchronous message-passing protocol (`Cslib.AsyncMP.Protocol`): every process is both a proposer and an acceptor. **Acceptor** (lines 27–49). Local variables: payload `s` and round `r = (rnr, rid)`, initially `(s₀, (0, ⊥))`. * `apply_update(u)` (called by the local proposer): `s ← u(s)`, `rid ← ⊥`. * `MERGE(s')`: `s ← s ⊔ s'`, `rid ← ⊥`, reply `MERGED`. * `PREPARE(r', s')`: `s ← s ⊔ s'`; an incremental prepare (`r'nr = ⊥`) gets the number `rnr + 1`; if `r'nr > rnr` then `r ← r'` and reply `ACK(r, s)`. * `VOTE(r', s')`: `s ← s ⊔ s'`; if `r' = r` reply `VOTED(s')`. **Proposer** (lines 1–26). * Update `u`: apply it on the local acceptor, send `MERGE(s)` to the other acceptors, respond once `MERGED` has been received from a quorum (the local acceptor counts as merged). * Query `q`: `PREPARE((⊥, id), s₀)` to all acceptors. Once `ACK`s from (a superset of) a quorum are received, with `s'` the LUB of the received states: (a) if all received states are equal to `s'`, `s'` is *learned by consistent quorum*; (b) else if all received rounds are equal to `r`, send `VOTE(r, s')` to all acceptors; `s'` is *learned by vote* once `VOTED(s')` is received from a quorum (line 24); (c) else retry with the fixed prepare `PREPARE((max R + 1, new_id), s')`. The query returns `cmd_q` applied to the learned state. * Retries after a `NACK` (Section III-B, "Retrying Requests") are modelled by the internal action `retry n`: at any time, a pending query may abandon its current attempt and start a new one, incremental (`n = none`) or fixed (`n = some k`), carrying the LUB of the payloads received. Message ids: the attempt id `(p, k, j)` (proposer, index of the operation of `p`, attempt counter) plays the role of the round ID `rid` and of the request id of the paper; the round of an attempt is `(n, id)`. `VOTED` messages carry the round they answer. **Variants** (`Variant`): `cons` is the test of line 13 (`sᵢ ≡ s'`; equality in the paper's intended reading, `Variant.paper`), and `fix` adds our repair: an acceptor answers `VOTED` only if, in addition, its payload before the merge is `⊑ s'` (`Variant.fixed`). **Ghost state.** `learned k = some (s, v)`: the `k`-th operation of the process was a query that learned `s` (`v = true`: by vote).
