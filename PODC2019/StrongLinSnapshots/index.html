Strongly Linearizable Snapshots and ABA-Detecting Registers — PODC 2019

Sean Ovens, Philipp Woelfel. Strongly Linearizable Implementations of Snapshots and Other Types. PODC 2019. DOI 10.1145/3293611.3331632. Formalized version: arXiv 1908.10826 v1 (full version, 51 pp.); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The one mistake of substance is the specification of the first DRead, which wrongly forces every process's first DRead to report "no write"; for the natural specification, one condition away, Theorem 1 holds: Algorithm 2 is a lock-free strongly linearizable ABA-detecting register from n + 1 registers of O(log n + log |D|) bits. Observation 4 (Algorithm 1 is not strongly linearizable) holds, and Theorem 25 (Algorithm 3, the snapshot, is strongly linearizable) and its lock-freedom (Theorem 32) are proved with atomic S and R. The paper's main claim of a bounded-space snapshot, which needs a merely linearizable S, and Theorem 3 (simple types) were not checked.

Mistakes in the paper

🔧 Section 3 (specification of the first DRead) and Theorem 12

The specification makes a process's first DRead return "no write", but Algorithms 1 and 2 return true for it, so in the sequential execution DWrite_p(x); DRead_p() the read returns (x, true) and Algorithm 2 is not even linearizable for the literal specification, for every n ≥ 1 (not_linearizable_literal).

Impact. A mis-stated definition with evident intent: read literally, Theorem 12 is false, but with the natural specification Theorem 1 holds and is proved (theorem1). Algorithm 3 is unaffected: it only uses the flag of a DRead that follows a DRead of the same SLscan.

Details

Section 3 defines DRead_q() to return a = true iff "q performed an earlier DRead_q() and a DWrite was performed since q's last DRead_q()". So a first DRead must return false. In Algorithm 2 a first DRead after any DWrite reads A[q] = ⊥ ≠ (p, s), sets changed, and returns true. The proof misses it because Lemma 8 only compares two consecutive DReads and Theorem 10 never treats the first one.

Repair

The specification "a DWrite since q's last DRead_q() or since the beginning". This is the PODC'15 ABADetection formalization's abaObj, and Theorem 1 is proved for it.

✏️ Slips

  • Observation 6(b) reads "A[p] = s throughout [t, t']", while the intended statement, used in Lemma 7, is "A[q] = (p, s) throughout [t, t']". The intended statement is true. The paper takes it from a thesis without proof; we prove it as an invariant of GetSeq (protBy_getSeq, protBy_of_wInv).

Typos

  • Lemma 8 refers to "the loop-guard on line 53" (line 41 is meant).

  • Theorem 12's proof cites "Theorem 11" (Lemma 11 is meant).

  • Lemma 11's case (ii) cites Q-2 instead of Q-1.

  • Observation 6(a) says "at least n" GetSeq calls where the queue gives n + 1.

Model.

  • CSLib's asynchronous shared-memory model (Cslib.SharedMemory.Impl): n processes Fin n, deterministic programs, atomic base objects, arbitrary scheduler. Executions are label lists, and a response is a separate step after the operation's last access. Strong linearizability is CSLib's Impl.StronglyLinearizable (a prefix-preserving linearization function). Lock-freedom is Impl.LockFree (every infinite execution with infinitely many steps has infinitely many responses).

  • ABA-detecting register: abaObj (Fin n) V v₀ (value domain V with ⊥ = v₀; DRead carries the reader, and only q may invoke dread q). Algorithm 2 runs on n + 1 registers over V × Option (Fin n × Fin (2n+2)). The arbitrary choice on line 11 is any pick avoiding the excluded values (PickSpec); theorem1 uses pickMin.

  • Snapshot: CSLib's snapObj n over ℕ (0 = ⊥; update_p(x) only on component p, x ≠ 0). Algorithm 3's lock-freedom is proved with a lexicographic potential: pending update work, stale scanner views, R ≠ S, scanners heading for the line-51 write, and steps left in the current iteration. The paper instead derives it from the amortized bound of Section 4.4.

  • Algorithm 3 runs on an atomic snapshot S and an atomic ABA-detecting register R over vectors. The paper's S may be any linearizable snapshot (that gives bounded space), and R may be Algorithm 2 (by composability). Neither substitution is formalized: CSLib has no composition theorem. The linearization function R-1/R-2 is the paper's. It does not look at where S's operations take effect, so we expect the proof to transfer to a linearizable S, but this is not checked.
