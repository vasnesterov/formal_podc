import Papers.PODC2015.ABADetection.Defs import Cslib.Computability.Distributed.SharedMemory.StrongLin import Cslib.Computability.Distributed.SharedMemory.Potential import Cslib.Foundations.Data.Finset.SumUpdate /-! # The ABA-detecting register of Ovens–Woelfel (PODC 2019), Algorithm 2: definitions Sean Ovens, Philipp Woelfel. *Strongly Linearizable Implementations of Snapshots and Other Types.* PODC 2019 (arXiv:1908.10826), Section 3. `n` processes `Fin n` share * a register `X` (base object `none`) holding a triple `(x, p, s)`, initially `(⊥, ⊥, ⊥)` (here `(v₀, none)`), and * registers `A[q]`, `q : Fin n` (base object `some q`) holding a pair `(p, s)`, initially `(⊥, ⊥)` (here `none`; the value component of `A[q]` is unused and stays `v₀`). All registers have the value type `V × Option (Fin n × Seq n)` where `Seq n = Fin (2n+2)` (sequence numbers `{0, …, 2n+1}`), i.e. `O(log n + log |V|)` bits. * `DWrite_p(x)`: `s ← GetSeq()` (one read of `A[c]`, then local computation), `X.write(x,p,s)`. * `GetSeq_p()` (Algorithm 1, lines 3–14): read `A[c]`; record `(c, sr)` in `na` iff the pair read belongs to `p`; `c ← c + 1 mod n`; choose `s ∉ na ∪ usedQ`; push `s` into the queue `usedQ` of the last `n + 1` chosen sequence numbers. The "arbitrary" choice is a parameter `pick` (any function returning a value outside a list of fewer than `2n+2` excluded values). * `DRead_q()` (Algorithm 2): repeat { `(x,p,s) ← X.read`; `(r,sr) ← A[q].read`; `A[q].write(p,s)`; `(x',p',s') ← X.read`; if `(p,s) ≠ (r,sr)` or `(x,p,s) ≠ (x',p',s')` then `changed ← true` } until both equalities hold; return `(x', changed)`. The implemented object is `abaObj (Fin n) V v₀` of the ABADetection formalization (`Papers/PODC2015/ABADetection/Defs.lean`): `DRead` carries the reader (`dread q`), and only `q` may invoke `dread q` (`allowed`). The implementation is defined for an arbitrary sequential specification with the same operations and responses (`implG`), so that it can also be compared with the paper's literal specification
