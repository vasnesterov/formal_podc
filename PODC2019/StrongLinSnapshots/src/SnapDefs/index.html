import Papers.PODC2015.ABADetection.Defs import Cslib.Computability.Distributed.SharedMemory.StrongLin import Cslib.Computability.Distributed.SharedMemory.Objects.Snapshot /-! # The strongly linearizable snapshot of Ovens–Woelfel (PODC 2019), Algorithm 3: definitions Section 4.3 of the paper. The implemented object is CSLib's `n`-component single-writer snapshot `snapObj n` over `ℕ` (`0` plays the role of `⊥`; `update_p(x)` is only allowed for `x ≠ 0` and only on component `p`). The shared objects are * a snapshot object `S` (base object `.S`, type `snapObj n`), and * an ABA-detecting register `R` over vectors (base object `.R`, type `abaObj` of the ABADetection formalization, initially the all-`⊥` vector). **Model choice.** Both base objects are *atomic*. In the paper `S` is only a linearizable implementation (to get bounded space) and `R` is Algorithm 2; see `README.md`. * `SLupdate_p(x)`: 43 `S.update_p(x)`; 44 `s ← S.scan()`; 45 `R.DWrite_p(s)`. * `SLscan_p()`: repeat { 47 `(s₁, c₁) ← R.DRead_p()`; 48 `ℓ ← S.scan()`; 49 `(s₂, c₂) ← R.DRead_p()`; 50–51 if not `s₁ = ℓ = s₂` then `R.DWrite_p(ℓ)` } until `s₁ = ℓ = s₂` and `¬c₂`; return `s₂`. -/ namespace Podc.StrongLinSnapshots.Snap open Cslib.SharedMemory Cslib.SharedMemory.ABADetection variable (n : ℕ) /-- Vectors (views of the snapshot). -/ abbrev Vec := Fin n → ℕ /-- The base objects: the linearizable snapshot `S` and the ABA-detecting register `R`. -/ inductive Obj where | S | R deriving DecidableEq /-- The ABA-detecting register over vectors, initially all `⊥ = 0`. -/ abbrev RObj : ObjSpec := abaObj (Fin n) (Vec n) (fun _ => 0) /-- The base objects' specifications. -/ abbrev B : Obj → ObjSpec | .S => snapObj n | .R => RObj n /-- Program counters (the local state;
