import Papers.PODC2019.StrongLinSnapshots.ABADefs import Podc.Computability.Distributed.SharedMemory.WriteStrongLin /-! # Observation 4: Algorithm 1 is not strongly linearizable Sean Ovens, Philipp Woelfel. *Strongly Linearizable Implementations of Snapshots and Other Types.* PODC 2019 (arXiv:1908.10826), Section 3.1. Algorithm 1 is the linearizable ABA-detecting register of Aghazadeh–Woelfel. Its `DWrite` and `GetSeq` are those of Algorithm 2 (`ABADefs.lean`); its `DRead_q()` uses a persistent local Boolean `b` (initially `false`): ``` 15 (x,p,s) ← X.Read() 16 (r,sr) ← A[q].Read() 17 A[q].Write(p,s) 18 (x',p',s') ← X.Read() 19–24 ret ← if (p,s) = (r,sr) then (x, b) else (x, true) 25–30 b ← ((x,p,s) ≠ (x',p',s')) 31 return ret ``` `alg1 v₀ pick` models it (for any `n`, `V`, `v₀` and choice function `pick`) as an implementation of `abaObj (Fin n) V v₀`. ## The counterexample (Observation 4) We instantiate the paper's proof with `n = 2`, `V = Bool`, `v₀ = false`, `pick = pickMin` (choose the smallest admissible sequence number); reader `p = 0`, writer `q = 1`, written value `true`. While `A[0] = A[1] = ⊥`, the consecutive `DWrite`s of `q` choose sequence numbers `0, 1, 2, 3, 0`, so the paper's `dw_i` / `dw_{i+1}` / `dw_j` are `dw1` / `dw2` / `dw5`. * `S = dw1 ◦ (dr1 up to the end of line 16) ◦ dw2` (`dr1` reads `X = (x, q, 0)` on line 15); * `T1 = S ◦ dw3 ◦ dw4 ◦ dw5 ◦ (rest of dr1) ◦ dr2`: `dr1` sees `(x,q,0)` again on line 18 and clears `b`; `dr2` finds `A[p] = (q,0) = X`'s tag and returns `(x, false)`; * `T2 = S ◦ (rest of dr1) ◦ dr2`: `dr2` reads `X = (x,q,1) ≠ A[p] = (q,0)` and returns `(x, true)`. If `dr1` is linearized before `dw2` in `f S`, then in `f T1` the operation `dw2` lies between `dr1` and `dr2`, so `dr2` must return flag `true`. Otherwise `dw1, dw2` precede `dr1` in `f T2`, which precede `dr2` with no `DWrite` in between, so `dr2` must return flag `false`.
