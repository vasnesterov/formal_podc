Representation choices: * constants: `Acceptor` is a type `A`, `Value` a type `V`, `Quorum` a `QuorumSystem A` (an intersecting family of finite sets of acceptors, which is `QuorumAssumption`, L28–29); * `Ballot = Index = Nat` (L23–24); the "ballot" `-1` of empty log entries and of `logTail` is handled by using `ℤ` for those fields; `NoVal` (L25, a value outside `Value`) is `none`, so a log entry `⟨b, v⟩ ∈ (Ballot ∪ {-1}) × (Value ∪ {NoVal})` is a pair `ℤ × Option V`; * `CHOOSE` (in `Max`, L7, and `GetHighestBallotEntry`, L64–67) is Hilbert's `Classical.epsilon`: deterministic, unspecified when nothing satisfies the predicate, as in TLA+; * each action is a predicate on the pair (unprimed state `s`, primed state `s'`), listing every variable (the `UNCHANGED` clauses become equations); `TypeOK` (L136–145) holds by typing; * `S ∈ SUBSET 1bmsgs` in `Next` (L162) ranges over finite subsets (`Finset`); `1bmsgs` is finite in every reachable state anyway. In `Propose` (L118–123) the text "`⇒ v is safe at i, b`" after `logs[a][i][2] = NoVal` is a grey comment, not part of the formula. So `Propose(a, i, v)` is enabled whenever `a` is a leader and its log entry at `i` holds `v` or no value, and it records nothing in `logs`: a leader whose entry is empty may propose *several different values* at the same index and ballot. **Main result** (`tla_invariance_false`): with three acceptors, majority quorums and `Value = Bool`, a state reachable from `Init` by `Next` steps violates `OneValuePerBallot`, and both `true` and `false` are chosen at index `0`; hence `THEOREM Invariance` (L177) is false.
