import Papers.PODC2019.TopologicalConsensus.Distance /-! # Topological characterization of consensus (Lemmas 4.4, 4.5, Theorems 5.2, 5.3) A partition of `Σ` into decision sets `Σ_v` is encoded as a labelling `lab : Σ → V` (`Σ_v = lab⁻¹{v}`; parts may be empty). **Necessity (holds in the generic model of Section 3).** * `isOpen_fiber_τNU` (Lemma 4.5) and `theorem_5_3_necessary`: a non-uniform consensus algorithm yields a `d_nu`-clopen partition satisfying validity. * `isOpen_fiber_τU` (Lemma 4.4) and `theorem_5_2_necessary`: the same for uniform consensus and `d_u`. * `theorem_5_2c_necessary`: the same for uniform consensus and our corrected distance `d_uc`. **Sufficiency (the universal algorithms).** The paper's termination proof needs that a process's view determines the global time and the process's earlier views (`Model.LockstepRecall`); without it the theorems are false (`Counterexamples.lean`). Under this assumption: * `theorem_5_3` (Theorem 5.3): non-uniform consensus is solvable iff there is a `d_nu`-clopen partition with validity. * `theorem_5_2c` (corrected Theorem 5.2): uniform consensus is solvable iff there is a `d_uc`-clopen partition with validity, where `d_uc` only requires obedience in the first execution. The paper's Theorem 5.2 (with `d_u`) is false when disobedient processes can have the same view as obedient ones (`Counterexamples.theorem_5_2_false`). * `theorem_5_2_faultFree`: in fault-free models (e.g. dynamic networks under message adversaries, the setting of the PODC'19 paper), `d_uc = d_u`, so the paper's Theorem 5.2 holds as stated. -/ namespace TopoConsensus open Set Filter Topology
