`isClopen_fibers_iff_closure` is the same with closures, `isClopen_iff_separation` the paper's two-set version. * `theorem_6_4_nonUniform` / `theorem_6_4_uniform` (Theorem 6.4, under `LockstepRecall`): consensus is solvable iff there is a labelling with validity such that no decision set contains a limit point of another (w.r.t. `τNU`, resp. the corrected uniform topology `τUc`; `theorem_6_4_uniform_faultFree` gives the paper's `τU` version for fault-free models). * `SetDistZero d A B`: the set distance `d(A, B) = inf {d(α, β) | α ∈ A, β ∈ B}` (Definition 6.1) is `0`, in the junk-free form `∀ ε > 0, ∃ α ∈ A, β ∈ B, d(α, β) < ε` (for empty `A` or `B` it is false, matching `inf ∅ = +∞`); `setDistZero_iff_sInf` relates it to `sInf`. * `corollary_6_5_nonUniform` / `corollary_6_5_uniform` (Corollary 6.5, second sentence): if for a labelling with validity all decision sets have positive pairwise distance, consensus is solvable. * `theorem_6_4_setDist_nonUniform` / `..._uniform` (last sentence of Theorem 6.4): if consensus is not solvable, then for *every* labelling with validity there are `v ≠ w` with `d(Σ_v, Σ_w) = 0`. * `ClosureCounterexample.closure_not_setDistZero`: for a non-metric distance, a point in the closure of `B` can have positive distance to `B`, so the paper's sequence argument for the last sentence of Theorem 6.4 (via Lemma 6.2) does not apply;
