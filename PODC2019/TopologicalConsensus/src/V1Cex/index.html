The "if" directions are false. Counterexample (three processes `0, 1, 2`, binary inputs): `MA = {π_k | k ∈ ℕ} ∪ {σ_∞}` with * `σ_∞`: `1 → 0` and `1 → 2` in every round; * `π_k`: no edges before round `k + 1`, `2 → 0` in round `k + 1`, then `0 → 1`, `0 → 2` forever. Every execution `(x, π_k)` lies in the clopen set `S_{x₀,x₂,k}` (process 1 is never heard of; the `(k+2)`-round views determine `k`, `x₀`, `x₂`), broadcast by `0`, containing only `x₀`-valent valent executions. The component of `(x, σ_∞)` is `{(y, σ_∞) | y₁ = x₁}` (broadcast by `1`). Yet consensus is impossible: `((1,0,1), π_k)` must decide like `((1,1,1), π_k)` (process 0 never hears of process 1), i.e. `1`, while for large `k` process 1 cannot distinguish it from `((0,0,0), σ_∞)` before deciding. We also refute v1 Corollary 6.1 ("finitely many components" for compact adversaries) and Corollary 6.5 (`ε`-approximations equal components for small `ε`) on the limit-closed adversary
