A message adversary is an arbitrary set `MA` of communication patterns `σ : ℕ → Graph P` (no compactness/limit-closure assumed). Inputs are arbitrary: `Σ = {(x, σ) | x : P → V, σ ∈ MA}`. * `FIIndist x y σ τ t p`: process `p` has the same full-information view after `t` rounds in the executions `(x, σ)` and `(y, τ)` (defined by recursion on `t`, no view type needed): the library notion `Cslib.HeardOf.FIIndist` with initial views given by the inputs. * `dnModel MA`: the instance of the generic model; it is fault-free and satisfies `LockstepRecall`, so the characterization of Theorem 5.2/5.3 applies with the paper's `d_u` (`dn_theorem_5_2`, `dn_theorem_5_3`). * `dn_solvable_iff`: the same characterization without topology: consensus is solvable under `MA` iff there is a labelling `L` of the executions that respects validity and is *locally constant*: for every admissible `(x, σ)` there is a round `T` such that
