import Mathlib import Cslib.Computability.Distributed.Knowledge.Basic /-! # Generic system model (Section 3 of Nowak–Schmid–Winkler) T. Nowak, U. Schmid, K. Winkler. *Topological Characterization of Consensus under General Message Adversaries.* PODC 2019 (full version: *Topological Characterization of Consensus in Distributed Systems*, arXiv:1905.09590v3). The paper's generic model for full-information executions: * a type `C` of configurations and a finite set `P` of processes; * for every process `p` an equivalence relation `indist p` on configurations (`C ∼ₚ D`: `p` has the same view in `C` and `D`), i.e. an indistinguishability system (`Cslib.Knowledge.IndistSystem`) on configurations; * the obedient processes `Ob C ⊆ P` of a configuration; * weak clocks `clock p : C → ℕ`; * the input values `input C : P → V` (meaningful for initial configurations); * the set `adm ⊆ (ℕ → C)` of admissible executions `Σ`. The paper's restrictions are fields of `Model`: disobedient processes do not recover, all processes are obedient initially, every execution has an obedient process, weak-clock properties, inputs are locally accessible, and initial configurations are determined by the inputs. A *decision algorithm* (`DecisionAlg`) is a family `Δₚ : C → Option V` (`none` = `⊥`) that is constant on `∼ₚ`-classes and irrevocable along admissible executions (the paper's "`C'` reachable from `C`" is read as "`C'` occurs later than `C` in an admissible execution"). Consensus (Definition 3.1): `SolvesNonUniform` (Termination, Agreement among obedient processes, Validity) and `SolvesUniform` (Uniform Agreement among all processes). Validity is required for obedient processes; for uniform consensus this implies validity for all deciding processes (`SolvesUniform.validity_all`). -/ namespace TopoConsensus open Set Filter /-- The
