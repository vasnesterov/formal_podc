If `1 < ℓ ≤ n` and `g = gcd(ℓ, m) > 1`, pick `g` processes `p₀, …, p_{g-1}`, cut the ring of the `m` registers into `g` arcs of length `d = m / g`, and let `pᵢ` see the registers rotated by `i·d` (`π pᵢ = (finRotate m)^(i d)`). In the *lock-step* execution (each round: one step of every `pᵢ`, in order) the configuration stays symmetric: `pᵢ`'s local state is the renaming of `p₀`'s by `σⁱ` (`σ` the cyclic permutation of the identifiers of the `pᵢ`) and register `sh y` holds the `σ`-renaming of the value of register `y` (`sh` = rotation by `d`). In a round all processes access *different* physical registers, so the sequential round has the same effect as a simultaneous one. Hence either all `g ≥ 2` processes enter the critical section in the same round (mutual exclusion fails), or none ever does and the lock-step execution is a fair execution in which no `lock()` completes (deadlock-freedom fails). The argument covers arbitrary read-modify-write registers *and* atomic snapshots (all processes of a round perform the same kind of access), so it also gives the necessary condition of Taubenfeld (PODC 2017) for read/write registers and for the snapshot-based model of Algorithm 1.
