import Papers.PODC2019.AnonymousMutex.LowerBound import Mathlib.Data.Finset.Lattice.Fold /-! # Algorithm 2: read/modify/write (compare&swap) memory-anonymous mutex Aghazadeh, Imbs, Raynal, Taubenfeld, Woelfel, PODC 2019 (arXiv:1810.03723), Section 5. ``` operation lock() is (1) repeat (2) for each x ∈ {1..m} do R.compare&swap(x, ⊥, id) (3) for each x ∈ {1..m} do view[x] ← R.read(x) (4) most_present ← maximum number of times the same non-⊥ value appears in view (5) owned ← |{x : view[x] = id}| (6) if owned < most_present then (7) for each x ∈ {1..m} do if view[x] = id then R.write(x, ⊥) (8) repeat (9) for each x ∈ {1..m} do view[x] ← R.read(x) (10) until ∀ x : view[x] = ⊥ (11) end if (12) until owned > m/2 operation unlock() is (13) for each x ∈ {1..m} do R.compare&swap(x, id, ⊥) ``` Modelling choices (see `README.md`): registers hold `Option Id` (`none` = `⊥`); every loop iteration is one atomic access (iterations of line 7 with `view[x] ≠ id` do nothing and are skipped); loops run in the process's local order; the bookkeeping between accesses (lines 4–6, 10–12) is folded into the continuation of the preceding access; `owned > m/2` is `m < 2 owned`.
