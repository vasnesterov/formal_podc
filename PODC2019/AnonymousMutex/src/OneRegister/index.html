import Papers.PODC2019.AnonymousMutex.LowerBound import Cslib.Computability.Distributed.SharedMemory.Indist /-! # One read/write register does not suffice for deadlock-free mutual exclusion Classical fact (Burns–Lynch, reference [3] of Aghazadeh–Imbs–Raynal–Taubenfeld–Woelfel, PODC 2019), here for a single register: with `m = 1` anonymous register accessed by reads, writes (and snapshots, which for one register are just reads) there is no deadlock-free mutual exclusion algorithm for two or more processes. Symmetry is not needed. Covering argument: 1. by deadlock-freedom, every process `r` running `lock()` solo from the initial configuration returns (`solo_lock_returns`): otherwise the execution "`r` invokes `lock` and then takes internal steps forever" is fair and client-well-formed, `r` is pending, nobody is in the critical section, and no operation completes; 2. cut `p`'s solo `lock()` run before its first write (`split_at_write`): up to there the memory is still the initial one, so `q`'s solo `lock()` run can be inserted and returns; then `p`'s write overwrites the (only) register with the same value as in the solo run and leaves `p` in the same local state, so `p` completes its solo run too: both are in the critical section. -/ set_option linter.unusedSectionVars false open Cslib.SharedMemory namespace
