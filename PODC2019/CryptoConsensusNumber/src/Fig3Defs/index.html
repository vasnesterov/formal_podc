Processes are `Fin n` (process identifiers break ties in "the oldest transfer"). Base objects (index type `Idx n Acct`): * `.inl ()` — the atomic snapshot object `AS`; component `p` holds `hist_p`, a set of `(transfer tuple, result)` pairs; * `.inr (.inl (a, i))` — the register `R_a[i]` (initially `⊥ = none`); * `.inr (.inr (a, r))` — the `k`-consensus object `kC_a[r]`. A transfer tuple is `(a, b, x, p, r)`: source, destination, amount, originator and the originator's `round_a` when it invoked the transfer. Code for process `p` (local variables `hist`, `committed_a`, `round_a`; local computation is folded into the continuations of the base-object accesses, one access per atomic step): ``` transfer(a, b, x): 1 if p ∉ μ(a) then return false 3 tx = (a, b, x, p, round_a) 4 R_a[p].write(tx) 5 collected = collect(a) \ committed_a -- n register reads, one per step 6 while tx ∈ collected do 7 req = the oldest transfer in collected 8 prop = proposal(req, AS.snapshot()) 9 decision = kC_a[round_a].propose(prop) 10 hist = hist ∪ {decision} 11 AS.update(hist) 12 committed_a = committed_a ∪ {t : decision = (t, *)} 13 collected = collected \ committed_a 14 round_a = round_a + 1 15 return ((tx, success) ∈ hist) read(a): 19 return balance(a, AS.snapshot()) ``` Modelling choices (see the paper folder's `differencies.md`): * line 22–23 of `collect` reads `R_a[i]` twice ("if `R_a[i].read() ≠ ⊥` then add `R_a[i].read()`"); we read it once (the second read is a typo-level redundancy); * `kC.propose` returning `⊥` is never the case (proved from `KShared μ k`); in the code the `⊥` decision is simply ignored (`hist ∪ ∅`); * `balance` uses truncated subtraction on `ℕ` (the invariant shows no truncation happens). -/ set_option linter.unusedSectionVars false namespace CryptoCons.Fig3 open Cslib.SharedMemory set_option allowUnsafeReducibility true in attribute [local reducible] atSpec snapObj kConsObj /-- A transfer tuple `(a, b, x, p, r)`: source `a`, destination `b`, amount `x`, originator `p` and the originator's round number `r` for account `a` at invocation. -/ structure Tx (n : ℕ) (Acct : Type) where a : Acct b : Acct x : ℕ p : Fin n r : ℕ deriving DecidableEq /-- `hist`: a set of (transfer tuple, success flag) pairs. -/ abbrev Hist (n : ℕ) (Acct : Type) [DecidableEq Acct] := Finset (Tx n Acct × Bool) variable {n : ℕ} {Acct : Type} [DecidableEq Acct] /-- The age of a transfer tuple: its round, ties broken by the originator's identifier (lexicographic order).
