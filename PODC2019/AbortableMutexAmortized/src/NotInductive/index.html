import Papers.PODC2019.AbortableMutexAmortized.PaperInv /-! # The paper's invariant `I` is not inductive Appendix A proves Theorem 4.1 by induction on steps, assuming `I` before a step and showing it after. But `I = I1 ∧ … ∧ I12` is *not* preserved by every step from an arbitrary configuration satisfying `I`: with `n = 3`, queue `Q = [r, x, π]` (`r = 0`, `x = 1`, `π = 2`), `r` at line 3 with `*a_r = &go_x`, `x` aborted at line 11 (`*a_x = pred_x = a_r`), `π` at line 3, all of `I` holds; `π` executes line 3, splices `x` out and becomes `r`'s successor, but `*a_r = &go_x` is neither `nil` nor `&go_π`: `I7` fails. (The configuration is unreachable: an aborted process has erased `&go_x` from its predecessor node at line 9.) The proof's "the rest of the invariants continue to hold since they are unaffected" (line 3, case 3) misses exactly this; it needs the additional conjunct `Loc.x1` ("an aborted process's predecessor node does not hold its go-address"), with which the invariant is inductive (`inv_step`). -/ namespace Podc.AbortableMutexAmortized /-- The counterexample-to-induction configuration (`n = 3`). -/ def ctiState : State 3 where pc := ![.l3, .l11, .l3] mynode p := some p pred := ![none, some 0, some 1] v := ![.nil, .go 2, .nil] node a := match a with | none => .token | some p => ![.go 1, .addr (some 0), .nil] p go _ := false tail := some 2 /-- `ctiState` satisfies the paper's invariant `I`, with `A = [a₀, a_r, a_x, a_π]`, `Q = [r, x, π]`. -/ theorem ctiState_paperInv : PaperInv ctiState [none, some 0, some 1, some 2] [0, 1, 2] := by refine ⟨rfl, by decide, by decide, rfl, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_, ?_⟩ · intro i p h;
