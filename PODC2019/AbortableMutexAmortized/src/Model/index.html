Asynchronous shared memory, no crashes, deterministic algorithm; the scheduler (adversary) is arbitrary. * Node addresses `Node n = Option (Fin n)`: `none` is `&sentinel`, `some p` is `&node_p`. The contents of a node are `Val n`: `nil`, `token`, a node address, or the address `&go_q` of a busy-wait flag. * A step of a process performs one shared-memory operation (the numbered line `pc p`) together with all local actions that follow it, as in the paper ("in a single step of the execution, a process performs an operation on a single shared variable, but can perform any number of local actions"). Being at line 1 is being in the Remainder section; being at line 7 is being in the CS (the paper's convention in `I10` and Corollary 4.1.1). * A step is labelled by the process and a Boolean *abort* flag (the environment's abort signal). The flag only matters at lines 4, 5, 6 (the paper allows the jump to the Abort section "only after performing Line 3, or Line 4, or Line 5, or Line 6"): there an aborting step jumps to the Abort section and performs line 9 in the same step (the jump is a local action, merged into the next shared-memory operation). Everywhere else the flag is ignored. * Values that the invariant shows impossible (e.g. `*v_p ← true` with `v_p` not the address of a go-flag, or `v_p = &go_q` with `q ≠ p` at line 3) are given some harmless semantics. -/ namespace Podc.AbortableMutexAmortized /-- Node addresses: `none` is `&sentinel`, `some p` is `&node_p`. -/ abbrev Node (n : ℕ) := Option (Fin n) /-- Contents of a node (and values of the local variable `v_p`). -/ inductive Val (n : ℕ) where /-- `nil` -/ | nil /-- `token` -/ | token /-- the address of a node -/ | addr (a : Node n) /-- the address `&go_q` of process `q`'s busy-wait flag -/ | go (q : Fin n) deriving DecidableEq /-- Program counters: the next line (shared-memory operation) to execute. -/ inductive PC where | l1 | l2 | l3 | l4 | l5 | l6 | l7 | l8 | l9 | l10 | l11 deriving DecidableEq, Repr /-- Configurations: shared variables and local variables of all processes. -/ structure State (n : ℕ) where /-- program counters -/ pc : Fin n → PC /-- local `mynode_p` -/ mynode : Fin n → Node n /-- local `pred_p` -/ pred : Fin n → Node n /-- local `v_p` -/ v : Fin n → Val n /-- contents of the nodes (`sentinel` and `node_p`) -/ node : Node n → Val n /-- busy-wait flags `go_p` -/ go : Fin n → Bool /-- shared variable `tail` -/ tail : Node n variable {n : ℕ} /-- The initial configuration.
