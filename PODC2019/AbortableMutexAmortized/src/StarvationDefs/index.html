import Papers.PODC2019.AbortableMutexAmortized.Invariant /-! # Starvation freedom: the distance function `δ` and the promoters set `Ψ` (Section 4.1) The paper (Section 4.1) measures how far a process `p` in the Try section is from the CS by a decimal number `δ(p)` whose digits are read off the queue prefix `q₁ … q_i = p`: `d_j = 3` for `j < m`, `d_m = f(q_m)`, `d_j = 0` for `j > m`, where `q_m` is the first process of the prefix that is not at line 1, and `f` is the digit function of equation (1). We define: * `fDigit s r` — the function `f` of equation (1). The paper leaves `f` unspecified at line 11 (it only remarks that a queue member is never at lines 2, 8), but a queue member *can* be at line 11 (an aborted process that has marked its node and is about to wake its successor), and `q_m` may be such a process. We set `f = 4` at line 11: the transitions `10 → 11 → 1` must make the digit decrease (`5 > f(11) > 3`), so `4` is the only possible choice. * `decVal ds` — the value of the big-endian decimal digit list `ds`. * `qPrefix Q p` — the prefix `q₁ … q_i` of `Q` ending at `p = q_i`. * `deltaDigits s P` — the digit list of Definition 4.1 for the prefix `P`, and `delta s p = decVal (deltaDigits s (qPrefix (Qof s) p))`. * `leaderQm s P` — the process `q_m`, and `promoters s p` — the set `Ψ(p)`. -/ namespace Podc.AbortableMutexAmortized variable {n : ℕ} /-!
