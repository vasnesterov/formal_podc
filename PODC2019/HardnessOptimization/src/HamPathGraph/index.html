import Papers.PODC2019.HardnessOptimization.MDSGraph /-! # The directed Hamiltonian path lower-bound graphs (Section 2.2.1) Bachrach, Censor-Hillel, Dory, Efron, Leitersdorf, Paz. *Hardness of Distributed Optimization.* PODC 2019 (arXiv:1905.10284), Section 2.2.1. `k = 2 ^ L` (positions `Fin (2 ^ L)`), `2 log k = 2 L` boxes (`Fin (2 * L)`). A row index is a bit string `i : Fin L → Bool`. * `start`, `stop` (the paper's `end`), `sA1 = s¹₁`, `sA2 = s²₁`, `sB1 = s¹₂`, `sB2 = s²₂`. * Rows: `row s ℓ i` is `a^i_1` (`s = false`, `ℓ = false`), `a^i_2` (`s = false`, `ℓ = true`), `b^i_1`, `b^i_2` (`s = true`). * Box `c` (`0 ≤ c < 2L`): `g c`, `r c`, and per line `q : Bool` (`true = t`, `false = f`) and position `d`: launch `la c q d` (`ℓ^{c,d}_q`), skip `si c q d` (`σ`), burn `be c q d` (`β`). Box `c < L` handles bit `c` of the layer-1 rows, box `c ≥ L` bit `c - L` of the layer-2 rows (`layer c`, `bit c`). * The wheel vertex `wheel^{c,d}_q` is a row: `W c q d = (side, index)` and the row is `row side (layer c) index` (`wrow`). The construction is stated for an abstract wheel assignment `W`; the properties needed are stated as hypotheses in the claims and a concrete `W` is given in `HamPathWheel.lean`. Arcs (`baseArc`, listed by out-neighbourhood) are exactly those of the paper, **plus** `r c → ℓ^{c,k-1}_q` for both `q`, which are drawn in the paper's Figure 2 and used in the proof of Claim 2.1 but missing from the textual construction (without them `r c` has out-degree `0` and no `D_{x,y}` has a Hamiltonian path). Input arcs: `a^i_1 → a^j_2` iff `x i j`, `b^i_1 → b^j_2` iff `y i j`. -/ namespace HardnessOptimization.HamPath /-! `Idx L = Fin L → Bool` (row indices) is shared with the MDS construction. -/ /--
