import Papers.PODC2019.HardnessOptimization.HamPathGraph /-! # Claim 2.1: `DISJ(x, y) = FALSE` gives a Hamiltonian path in `D_{x,y}` Given `x(i₀, j₀) = y(i₀, j₀) = 1`, box `c` (bit `h` of layer `ℓ`) chooses the line `q_c = ¬ ι_ℓ(h)` (`ι_false = i₀`, `ι_true = j₀`), i.e. the line containing the rows whose bit `h` differs from the one of `i₀` / `j₀`. The path is `start, [g_c, forward pass of line q_c]_{c = 0..2L-1}, [r_c, backward pass of line ¬q_c]_{c = 2L-1..0}, s¹₁, a^{i₀}_1, a^{j₀}_2, s²₁, s¹₂, b^{i₀}_1, b^{j₀}_2, s²₂, end`. In the forward pass, position `d` makes a wheel detour iff `c` is the *first* box (in its layer) on whose chosen line the wheel row lies (`Detour`), so every row other than the four suffix rows is visited exactly once.
