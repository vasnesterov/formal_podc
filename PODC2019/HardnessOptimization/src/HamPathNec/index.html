import Papers.PODC2019.HardnessOptimization.HamPathGraph /-! # Claim 2.2: a Hamiltonian path in `D_{x,y}` forces `DISJ(x, y) = FALSE` We follow positions along the path (`HP.pos`, `HP.Nx u v` = "`v` comes right after `u`"). The argument (a reorganisation of the paper's Claims 2.3–2.5): 1. `claimB` (Claim 2.3): a detour `ℓ → wheel` continues `wheel → β → σ → forward`. 2. `isR_before`: all box vertices come before `s¹₁`. 3. `suffix`: after `s¹₁` the path is `a^i_1, a^j_2, s²₁, s¹₂, b^{i'}_1, b^{j'}_2, s²₂, end`. 4. `row_pred`, `beta_pred`: a row visited before `s¹₁` is entered from a launch vertex. 5. Every position `(c, q, d)` is a *block* entered at `ℓ` and left forward (`BlockF`) or backward (`BlockB`); no forward block is followed by a backward one (`no_FB`). 6. `line`, `box`: in every box one line is traversed forward from `g_c`, the other one backward from `r_c` (so the backward line has no wheel detours). 7. Hence the rows `a^ī_1, b^ī_1, a^j̄_2, b^j̄_2` (`ī`, `j̄` = complements of the forward choices) are not visited before `s¹₁`, so they are the four rows of the suffix: `x(ī, j̄) = y(ī, j̄) = 1`.
