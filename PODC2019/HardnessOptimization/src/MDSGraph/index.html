A row index `i ∈ [k]` is a bit string `i : Fin L → Bool`. * Rows: `row s ℓ i` is `a^i_1` (`s = false`, `ℓ = false`), `a^i_2` (`s = false`, `ℓ = true`), `b^i_1`, `b^i_2` (`s = true`). * Bit gadgets: `gad s ℓ h κ` with `κ = 0, 1, 2` is `f^h_S`, `t^h_S`, `u^h_S` for `S = A_ℓ` / `B_ℓ`. For every `ℓ, h` the six vertices `f_A, t_A, u_A, f_B, t_B, u_B` form a 6-cycle (in this order). * `row s ℓ i` is adjacent to `bin(i) = {f^h | i_h = 0} ∪ {t^h | i_h = 1}` as in the paper; the dominating set of the `⇐` direction uses the complementary sets `bin̄`, as in the paper. * Input edges: `a^i_1 – a^j_2` iff `x(i, j) = 1`, `b^i_1 – b^j_2` iff `y(i, j) = 1`. -/ namespace HardnessOptimization /-- A row index: a `log k`-bit string. -/ abbrev Idx (L : ℕ) := Fin L → Bool /-- Vertices of the MDS lower-bound graph. `side = false` is Alice's side (`A`), `layer = false` is the first row (`A₁`, `B₁`).
