import Papers.PODC2019.SharpThresholdLLL.Basic /-! # Sinkless orientation is an LLL instance exactly at the threshold The paper ("Applications") observes that sinkless orientation is the prime example of a problem exactly at the threshold `p = 2^{-d}`, and that the lower bounds for `p ≥ 2^{-d}` come from it. We make the instance explicit. Let `G` be a finite simple graph. Each edge carries a variable, its head, uniform on its two endpoints. The event at a node `v` is "`v` is a sink" (`v` is the head of all its edges). Then: * every variable affects exactly two events (rank 2): `sinklessInstance_evs_card`; * the dependency graph is `G`: `sinklessInstance_dep`; * `Pr[E_v] = 2^{-deg v}`: `sinklessInstance_pr`; * an assignment avoids all bad events iff it is a sinkless orientation (definitional). So on a `Δ`-regular graph, `p = 2^{-d}` exactly (`sinkless_at_threshold`). The cited `Ω(log n)` deterministic and `Ω(log log n)` randomized lower bounds for sinkless orientation are not formalized here. A port-numbering version of the round-elimination lower bound is in `Papers/PODC2019/AutomaticSpeedup` (`sinklessOrientation_lower_bound`). -/ open Finset Cslib.Probability set_option linter.unusedSectionVars false namespace SharpThresholdLLL variable {V : Type} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj] /-- The endpoints of an edge. -/ abbrev Ends (e : G.edgeSet) := {w : V // w ∈ (e : Sym2 V)} lemma card_ends (e : G.edgeSet) : Fintype.card (Ends G e) = 2 := by obtain ⟨e, he⟩ := e induction e using Sym2.inductionOn with | hf a b => have hab : a ≠ b := G.ne_of_adj (by simpa using he) rw [Fintype.card_subtype] have : (univ.filter fun w => w ∈ s(a, b)) = {a, b} := by ext w;
