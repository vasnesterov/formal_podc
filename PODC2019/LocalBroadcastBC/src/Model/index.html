import Cslib.Computability.Distributed.Byzantine.LockStep.Cover import Cslib.Computability.Distributed.Byzantine.Specs import Cslib.Computability.Distributed.Byzantine.LockStep.Agreement import Cslib.Foundations.Combinatorics.SimpleGraph.VertexConnectivity import Mathlib import Cslib.Computability.Distributed.Byzantine.LockStep.Parallel /-! # The local broadcast model (Khan–Naqvi–Vaidya, PODC 2019), on top of CSLib's lock-step model We reuse CSLib's synchronous lock-step model `Cslib.Byzantine.LockStep` (history-based deterministic protocols on a `SimpleGraph`, static Byzantine set, adversary messages `adv r p q`). The *local broadcast* model is the restriction in which **every** message is received identically by all neighbours of its sender: * honest parties broadcast: `Protocol.IsBroadcast` (the message does not depend on the receiver); * Byzantine parties broadcast as well: `Scenario.IsLocalBroadcast` (`adv r p q` does not depend on `q`); this is the whole restriction of the adversary (no equivocation). `SolvesLB G alg Z spec` / `SolvableLB G Z spec` are the corresponding solvability notions; the threshold adversary is the shared `atMost f` (at most `f` Byzantine nodes) and `Consensus` is the specification of Section 3 of the paper (agreement, validity "the output is the input of some non-faulty node", termination). The impossibility proofs use FLM-style covering systems (CSLib `CoverSystem`) in which every Byzantine node is simulated by a *single* node of the cover; the corresponding adversary is a local broadcast adversary (`CoverSystem.lbScenario`, `decides_lbScenario_iff`). Two-copy covers `twoCopy` (every node has copies `(u, false)` and `(u, true)`) suffice for the paper. -/ open Cslib.Byzantine.LockStep namespace LocalBroadcastBC universe u variable {V I M O : Type*} The adversary obeys local broadcast: a Byzantine party sends the same message to all its neighbours in every round. -/ def IsLocalBroadcast (s : Scenario V I M) : Prop := ∀ r p q q', s.adv r p q =
