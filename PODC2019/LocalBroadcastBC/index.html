Byzantine Consensus under Local Broadcast — PODC 2019

Muhammad Samir Khan, Syed Shalan Naqvi, Nitin H. Vaidya. Exact Byzantine Consensus on Undirected Graphs under Local Broadcast Model. PODC 2019. DOI 10.1145/3293611.3331619. Formalized version: arXiv 1903.11677 v2 (full version with appendices). Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The tight characterization holds for every graph with at least two nodes: under local broadcast, consensus tolerating f Byzantine faults is solvable iff the minimum degree is ≥ 2f and the graph is (⌊3f/2⌋+1)-connected. The sufficiency proof needs local changes only: step (b) of Algorithm 1 needs simple paths, Observation B.1 is used in an unstated direction, and Lemma 5.5 is applied outside its hypothesis. The hybrid model and the O(n)-round algorithm were not checked.

Mistakes in the paper

✏️ Slips

  • Theorem 4.1 and Lemma A.2 (single-node graph): Theorem 4.1 (necessity) is false for n = 1, f = 0, which the standing assumption f < n allows: the node decides its own input, so consensus is trivial, but under West's definition (k-connected requires n > k) the graph is not 1-connected (not_theorem_4_1_single_node). We prove the statement under n ≥ 2 (theorem_4_1). The proof of Lemma A.2 starts "not (⌊3f/2⌋+1)-connected ⇒ there is a vertex cut of size ≤ ⌊3f/2⌋". This misses complete graphs with n ≤ ⌊3f/2⌋ + 1, which have no cut. For f ≥ 1, Lemma A.1 (degree ≥ 2f) excludes them; for f = 0 only the single-node graph remains. The same case breaks the §4 remark that the complete graph on 2f + 1 nodes satisfies the conditions "for any f". The hypothesis f < n is also needed: for n = 1, f = 1 consensus is solvable but the minimum degree is 0 < 2 (not_degree_single_node).

Typos

  • Proof of Lemma A.1, item 4: the sentence describing Figure 2 orients the F²–W edges the other way round from the formula in the same item and from the figure. The executions need the formula's version.

Proof gaps in true statements (3)Algorithm 1, step · Observation B.1 · Lemma 5.3

🔧 Algorithm 1, step (b), in the proof of Lemma 5.3 (simple paths)

The paper lets P_uv be an arbitrary uv-path avoiding F, and its paths are walks, so along a path P_wv that repeats a node v may receive nothing and wrongly put w into N_v.

Impact. With simple paths, which Lemma 5.4 provides, the proof goes through (exists_selSpec).

Details

If P_wv repeats a node x, then x discards the value forwarded back to it by rule (iii). So v receives nothing along P_wv and wrongly puts w into N_v, even when w flooded 0. The step "v receives 0 along P_wv and correctly puts w in Z_v" in Lemma 5.3 then fails.

🔧 Observation B.1 (used in an unstated direction)

Observation B.1 states soundness (a value received along a fault-free path is the origin's value), but Lemma 5.3 also needs completeness: along every fault-free simple path the value does arrive within the phase's n rounds.

Impact. Statement true; we prove both directions (floodInv).

Details

Completeness depends on the default message (1, ⊥) and on the round in which each path prefix is accepted. For a faulty originator, "the value it floods" must be defined, as what its first-round transmission says about ⊥.

🔧 Lemma 5.3 (Lemma 5.5 applied to faulty nodes)

Lemma 5.3 applies Lemma 5.5 to faulty w, but Lemma 5.5 is stated only for non-faulty nodes.

Impact. Statement true: the proof of Lemma 5.5 works for any w, and we prove it that way (pathsExist).

The formalizationmodel, Lean names of the results, trust

Model.

  • Finite node set with a simple undirected graph known to all nodes. Synchronous lock-step rounds (CSLib LockStep). Protocols are deterministic and history-based, and may use any message type.

  • Local broadcast is a restriction on both sides. Honest protocols send the same message to all neighbours. The Byzantine adversary (static set, |B| ≤ f: the shared threshold structure atMost f of Cslib/Computability/Distributed/Byzantine/LockStep/Parallel.lean) also broadcasts, but is otherwise arbitrary (covers adaptive, rushing adversaries).

  • Consensus (§3): termination, agreement (the shared Problem.Termination, Problem.Agreement), and validity (output = input of some non-faulty node); binary values.

  • Impossibility quantifies over all broadcast protocols. Possibility uses Algorithm 1, with phases for every F with |F| ≤ f in an arbitrary fixed order, n flooding rounds each, and rules (i)–(iv). Ambiguities (ordering within a transmission, ties in step (c)) are resolved deterministically, and the proof works for every choice of simple paths in step (b). Byzantine nodes may send arbitrary, even contradictory, sets of pairs.

Proof remarks. Lemma A.2's cover edges are only "deduced from Figure 3"; we give them explicitly. Both covers tacitly need each Byzantine node to be simulated by a single cover node, so that it can still broadcast. Lemma 5.4 cites Menger, but it follows from the definition of connectivity.
