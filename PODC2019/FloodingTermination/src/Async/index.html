import Papers.PODC2019.FloodingTermination.Examples /-! # Round-asynchronous amnesiac flooding (Section 4 of Hussak–Trehan) Model (§1.1.1): computation still proceeds in global rounds, but the adversary decides, for every message, in which round it is delivered (never lost, never earlier than in the synchronous model). A node that receives the message in round `r` (from the set `I` of senders delivered in round `r`) sends it in round `r + 1` to all its neighbours outside `I`. We describe the adversary by a delay function `δ : ℕ → V → V → ℕ`: the message sent by `u` to `v` in round `r` is delivered in round `r + δ r u v` (`δ = 0` is the synchronous model, see `asends_zero_delay`). Since the process is deterministic and at most one message is sent on a directed edge per round, an *adaptive* adversary's choices in a run are exactly such a function, so quantifying over all `δ` covers adaptive adversaries. * `asyncAF_triangle_nonterminating` — the paper's example: on the triangle the adversary can keep the message circulating forever (Figure 8). * `asyncAF_terminates_of_isAcyclic` — on a finite forest (in particular on a single edge) every adversary's run terminates, so the adversary cannot *always* force non-termination. -/ namespace
