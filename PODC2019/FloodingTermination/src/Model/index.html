import Mathlib import Cslib.Foundations.Combinatorics.SimpleGraph.WalkParity /-! # Synchronous amnesiac flooding (Hussak–Trehan, PODC 2019) Model (Definition 1.1 / Algorithm 1.1 of the paper): a simple graph `G`, a source `s`, synchronous rounds `1, 2, …`. In round 1 the source sends `M` to all its neighbours. In round `t + 1`, every node `v` that received `M` in round `t` sends `M` to every neighbour `w` that did *not* send `M` to `v` in round `t`. Nodes keep no other memory. * `FloodingTermination.afStep G M` — one round of amnesiac flooding as a map on sets of directed messages (`M u v`: `u` sends to `v` in the current round). * `FloodingTermination.sends G s t u v` — in round `t`, node `u` sends `M` to `v`. * `FloodingTermination.roundSet G s t` — the round-set `R_t` of Definition 2.1: `R_0 = {s}`, and for `t ≥ 1`, `R_t` is the set of nodes receiving `M` in round `t`. * `TerminatesAfter G s T` — no message is sent in any round `t > T`; `IsTerminationTime G s T` — additionally `R_T ≠ ∅` (so `T` is the last active round). The key fact (`sends_succ_iff`, `mem_roundSet_iff`) identifies the process with breadth-first search in the bipartite double cover: `v ∈ R_t` iff `t` is a parity distance from `s` to `v`, i.e. there is a walk of length `t` from `s` to `v` and no shorter walk of the same parity. -/ namespace FloodingTermination open SimpleGraph variable {V : Type*} (G : SimpleGraph V) (s : V) /-- One synchronous round of amnesiac flooding. If `M u v` means "`u` sends `M` to `v` in round `t`", then `afStep G M v w` means "`v` sends `M` to `w` in round `t + 1`": `v` received the message in round `t`, `w` is a neighbour of `v`, and `w` did not send the message to `v` in round `t`. -/ def afStep (M : V → V → Prop) (v w : V) : Prop := G.Adj v w ∧ (∃ u, M u v) ∧ ¬ M w v /-- `sends G s t u v`: in round `t` of synchronous amnesiac flooding from the source `s`, node `u` sends a copy of the message to node `v` (Algorithm 1.1). There are no messages in round `0`. -/ def sends : ℕ → V → V → Prop | 0 => fun _ _ => False | 1 => fun u v => u = s ∧ G.Adj u v | t + 2 => afStep G (sends (t + 1)) /-- The round-sets of Definition
