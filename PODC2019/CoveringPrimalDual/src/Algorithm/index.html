import Podc.Foundations.Combinatorics.HypergraphCover /-! # Algorithm MWHVC (Section 3) Ben-Basat, Even, Kawarabayashi, Schwartzman, *Optimal Distributed Covering Algorithms*, PODC 2019 (arXiv 1902.09377v2). The input is a hypergraph with edges `inc e ⊆ V` (indexed by a finite type `E`, so parallel edges are allowed, as in the set-cover reading) and positive vertex weights `w`. The algorithm is a synchronous primal–dual algorithm on the bipartite vertex/edge network; since every step only uses information of the vertices of an edge or of the edges of a vertex, we model it by its global-state iteration: `step` performs one iteration `i ≥ 1` (steps 3a–3f of the paper), `init` is iteration `0`, and `run I P i` is the state at the end of iteration `i`. Parameters (`Params`): the rank bound `f`, the approximation parameter `ε`, the multiplier `α`, the factor `κ` by which the dual variables grow (`κ = 1` in Section 3, `κ = 1/2` in Appendix C), and the factor `c₀` of the initial deal (`c₀ = 1/2` in Section 3, `c₀ = β` in Appendix B). State: the cover `C`, the levels `ℓ(v)`, the deals `deal(e)` and the dual variables `δ(e)`. The set `E'(v)` of uncovered edges at `v` is `uncov I C v`; a vertex is active if `v ∉ C` and `E'(v) ≠ ∅`; an edge is terminated iff it is covered. The `while` loop of step 3d is `lvlUp`: the new level is the least `ℓ' ≥ ℓ(v)` with `∑_{e ∈ E(v)} δ(e) ≤ w(v)(1 - 2^{-(ℓ'+1)})`; every level increment of `v` halves `deal(e)` for every `e ∈ E'(v)`, so `deal(e)` is multiplied by `2^{-k}` where `k` is the total number of level increments of the vertices of `e` (`deal1`). -/ set_option linter.unusedSectionVars false namespace Podc.CoveringPrimalDual open Finset Cslib.Hypergraph variable {V E : Type*} [Fintype V] [Fintype E] [DecidableEq V] [DecidableEq E] /-- An instance of MWHVC: a hypergraph with nonempty edges and positive vertex weights. -/ structure Inst (V E : Type*) where /-- The vertices of each hyperedge. -/ inc : E → Finset V /-- The vertex weights. -/ w : V → ℝ inc_nonempty : ∀ e, (inc e).Nonempty w_pos : ∀ v, 0 < w v /-- The parameters of the algorithm. -/ structure Params where /-- Upper bound on the rank of the hypergraph (the paper's `f`). -/ f : ℕ /-- Approximation parameter. -/ ε : ℝ /-- Multiplier of the deals. -/ α : ℝ /-- Dual variables grow by `κ · deal(e)` (`κ = 1`: Section 3;
