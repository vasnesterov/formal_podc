Rows are indexed by a finite type `R`, columns (variables) by a finite type `J`. * Lemma 5.2 (zero-one programs → MWHVC): for every row `i` and every `S ⊆ [n]` whose indicator vector violates row `i`, add the hyperedge `σᵢ \ S` (`σᵢ` = support of row `i`). We prove that a set `T` meets every hyperedge iff `I_T` is feasible (`lemma_5_2_cover_iff`), that hyperedges are nonempty (`lemma_5_2_nonempty`), the rank bound `≤ f(A)` (`lemma_5_2_rank`) and the degree bound `≤ 2^{f(A)-1} Δ(A) < 2^{f(A)} Δ(A)` (`lemma_5_2_degree`). The stated rank bound `f' < f(A)` is false: `lemma_5_2_rank_false` (no reduction at all can achieve it on `x₁ ≥ 1`). * Proposition 5.5 is false for non-integral `M` (`prop_5_5_false`: `2x ≥ 3`, `M = 3/2`); it holds with the box `[0, ⌈M⌉]ⁿ` (`prop_5_5_ceil`). * Claim 5.6 (binary expansion): false as stated when `M < 1` (`claim_5_6_false`: `2x ≥ 1`, `⌈log₂ M + 1⌉ = 0`); its proof uses `B = ⌈log₂ M⌉` bits, which loses solutions when `M` is a power of two (`claim_5_6_proof_false`: `x ≥ 2`).
