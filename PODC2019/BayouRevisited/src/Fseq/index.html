The paper indexes the appends by `rank(appends(E), ar, e) = i` for `1 ≤ i ≤ n`; since `rank` counts the *strict* predecessors it is `0`-based, so we use `rank = i - 1` (that is, `i` ranges over `0, …, n-1`).
