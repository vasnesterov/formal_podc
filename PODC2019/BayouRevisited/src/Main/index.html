An implementation `I` of an ACT specification `S` *avoids temporary operation reordering* in the sense of Theorem 5 if * in every stable run its history extends to one abstract execution satisfying `BEC(weak, F) ∧ SinOrd(strong) ∧ BEC(strong, F)`, and * in every asynchronous or stable run its history satisfies `BEC(weak, F)`.
