import Mathlib -- CSLib candidate: Cslib/Computability/ChemicalReactionNetworks/Basic.lean /-! # Discrete chemical reaction networks and output-oblivious stable computation Severson, Haley, Doty. *Composable computation in discrete chemical reaction networks.* PODC 2019 (arXiv:1903.02637v2), Section 2. * A CRN over a finite species type `S` is a finite set of reactions `(R, P) ∈ ℕ^S × ℕ^S`; a configuration is `C : S → ℕ`; reaction `(R, P)` is applicable to `C` if `R ≤ C` and yields `C - R + P` (§2.2). * A function-computing CRN (`FunCRN S ι`) has input species `X i` (`i : ι`), an output species `Y` and (optionally) a leader species `L`; all distinct. The initial configuration for input `x : ι → ℕ` has `x i` copies of `X i`, one `L` (if there is a leader) and nothing else. * `StablyComputes f`: from every configuration reachable from `I_x` a stable configuration with output `f x` is reachable; `OutputOblivious`: `Y` is never a reactant (§2.3). * `ObliviouslyComputable f`: stably computed by an output-oblivious CRN with a leader.
