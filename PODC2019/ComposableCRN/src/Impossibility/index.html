import Papers.PODC2019.ComposableCRN.Basic /-! # Necessary conditions for oblivious computability * Observation 2.1: obliviously-computable functions are nondecreasing. * Lemma 4.1: the "contradiction sequence" criterion (via Dickson's lemma). * `max` is not obliviously-computable (§1.2, §4). * Observation 9.1: functions obliviously-computable without a leader are superadditive. All results hold for the general `FunCRN` model; the distinctness of the input, output and leader species is not used. -/ set_option linter.unnecessarySeqFocus false namespace Podc.ComposableCRN open CRN variable {ι : Type} [Fintype ι] namespace FunCRN variable {S : Type} [DecidableEq S] (C : FunCRN S ι) /-- Core of Observation 2.1: an output-oblivious CRN stably computing `f` forces `f` to be nondecreasing. -/ theorem monotone_of_stablyComputes (hO : C.OutputOblivious) {f : (ι → ℕ) → ℕ} (hf : C.StablyComputes f) : Monotone f := by intro a b hab obtain ⟨O, hO1, hO2, -⟩ := hf.exists a -- `I_b = I_a + I_{b-a}` reaches `O + I_{b-a}` have hb : b = a + (b - a) := by funext i; have : a i ≤ b i := hab i; simp only [Pi.add_apply, Pi.sub_apply]; omega have hreach : C.Reach (C.init b) (O + C.inputConf (b - a)) := by rw [hb, C.init_add]; simpa [← hb] using hO1.add (C.inputConf (b - a)) obtain ⟨O', hO'1, hO'2, -⟩ := hf b _ hreach have := hO.reach_le hO'1 simp only [Pi.add_apply] at this omega end FunCRN /-- Observation 2.1: an obliviously-computable function is nondecreasing. -/ theorem ObliviouslyComputable.monotone {f : (ι → ℕ) → ℕ} (h : ObliviouslyComputable f) : Monotone f := by obtain ⟨S, _, _, C, -, hO, hf⟩ := h exact C.monotone_of_stablyComputes hO hf /-- Lemma 4.1: if there is a sequence `a₁, a₂, …` such that for all `i < j` some `Δᵢⱼ` satisfies `f(aᵢ + Δᵢⱼ) - f(aᵢ) > f(aⱼ + Δᵢⱼ) - f(aⱼ)`, then `f` is not obliviously-computable.
