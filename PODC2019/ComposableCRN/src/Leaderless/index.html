"⇒" is Observation 9.1 (`LeaderlessObliviouslyComputable.superadditive`) together with Lemma 2.7 (cited from [10], taken as a hypothesis). For "⇐" we use a simplification of the paper's construction. By `eventually_affine_of_semilinear_of_monotone` there are `N`, `P > 0`, `c` with `f (x + P) = f x + c` for `x ≥ N`; let `red m = m` for `m < N + P` and `N + (m - N) mod P` otherwise. The CRN has species `X`, `Y` and tokens `T_q`, `q < N + P`; a token `T_q` stands for a block of `v` already consumed inputs with `red v = q`, whose output `f v` has been produced: * `X → f(1) Y + T_{red 1}`; * `T_a + T_b → (f(a+b) - f(a) - f(b)) Y + T_{red(a+b)}` for all `a, b < N + P`. Since `red (v + w) = red (red v + red w)` and `f (v + w) - f v - f w = f (red v + red w) - f (red v) - f (red w)`, merging the blocks `v` and `w` produces exactly the missing output `f (v + w) - f v - f w ≥ 0`. Eventually all inputs are consumed and at most one token remains, standing for the block `x`, with output `f x`. The paper's construction also keeps the leader-automaton reactions of Theorem 3.1 (run by the tokens); as the paper remarks, they are not needed. The construction is proved correct once for any labelling `r : ℕ → Fin n` satisfying these two identities (`Leaderless.stablyComputes`). -/ set_option linter.unusedSectionVars false namespace
