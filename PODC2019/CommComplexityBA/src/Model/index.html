import Mathlib import Cslib.Computability.Distributed.Byzantine.LockStep.Parallel import Cslib.Computability.Distributed.Byzantine.LockStep.Agreement /-! # Synchronous randomized protocols against strongly adaptive omission adversaries Model for the lower bound of Abraham, Chan, Dolev, Nayak, Pass, Ren, Shi, *Communication Complexity of Byzantine Agreement, Revisited* (PODC 2019), Section 3 (Theorems 1 and 4). * `n` nodes `P` (a `Fintype`), lock-step synchronous rounds `0, 1, 2, …` (infinite executions). * **Randomness.** One probability space `(Ω, μ)`. Node `p`'s code may depend on `ω : Ω` in an arbitrary way, so `Ω` covers private coins, shared coins and any trusted setup (PKI, common random string, random oracle). This only makes the class of protocols larger, hence the lower bound stronger. * **Protocol.** History based (inboxes and histories are those of CSLib's lock-step model): in round `r`, node `p` with input `x` and history `h` (the list of its inboxes in rounds `0, …, r-1`) sends `send p x ω h q : Option M` to each `q ≠ p` (self-messages are local computation and are not modelled); its *output* is the first `decide p x ω h = some b` along its histories (`none` forever = no output). * **Adversary** (`Adversary P f`): a *strongly adaptive omission adversary*, i.e. the most restricted adversary of the paper's lower bound ("even under a more constrained omission adversary", Section 1). It observes the communication pattern (who sends to whom), including the pattern of the current round (rushing), and then - corrupts nodes (monotonically, at most `f` in total), possibly a node that has *just* sent; - drops any message of the current round whose sender or receiver is corrupted *after* this round's corruptions: this is the **after-the-fact removal** capability; corrupted nodes otherwise run the protocol (omission failures). Adversaries are deterministic; since a protocol must resist every adversary, this only weakens the hypothesis "the protocol is secure", hence strengthens the lower bound. -/ set_option
