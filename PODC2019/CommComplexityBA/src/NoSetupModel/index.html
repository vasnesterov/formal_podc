import Papers.PODC2019.CommComplexityBA.Model /-! # Plain authenticated channels without setup (Section 7, Theorem 13) Model for Theorem 13 of the paper (the Byzantine-broadcast form of Theorem 3). * `n` nodes `P`, lock-step synchronous rounds `0, 1, 2, …` (infinite executions). * **No setup.** Every node `p` has a private random tape `ω p : T`, the tapes are independent with laws `ν p` (`Measure.pi ν`). There is no shared randomness, no PKI, no common random string. * **Plain authenticated channels.** In round `r` a node sends to each other node a *multiset* of messages (several messages per channel and round are allowed); the receiver learns the true sender. Protocols are history based (`send`, `decide`), as in `Model.lean`. * **Adversary** (`Adversary P M R C`): it has its own randomness `ρ : R` (we use `R = P → T`, i.e. it can sample fresh tapes, and `ρ` is independent of the nodes' tapes), observes all messages sent in previous rounds (no private channels), corrupts nodes adaptively (monotonically, at most `C`), and *injects* additional messages on channels with a corrupted endpoint. Corrupted nodes otherwise keep running the protocol. This is a restriction of the Byzantine adaptive adversary of the paper (it can neither remove nor alter messages), so it makes the impossibility *stronger*. * **Communication.** `FewSpeakers C`: at most `C` forever-honest nodes ever send a message. A multicast protocol with multicast complexity `≤ C` has at most `C` speakers, so this covers the paper's measure and its remark "at most `C` nodes send messages". -/ set_option linter.unusedSectionVars false open MeasureTheory open Cslib.Byzantine.LockStep (firstSome?) namespace CommComplexityBA.NoSetup /-- Messages received in one round, indexed by the (authenticated) sender. -/ abbrev MInbox (P M : Type*) := P → Multiset M /-- Local history: inboxes so far, oldest first. -/ abbrev MHistory (P M : Type*) := List (MInbox P M) /-- Messages sent in one round: `tr p q` is what `p` sends to `q`. -/ abbrev Traffic (P M : Type*) := P → P → Multiset M /-- A protocol in which node `p` uses its private tape `t : T`. -/ structure Protocol (P I M T : Type*) where send : P → I → T → MHistory P M → P → Multiset M decide : P → I → T → MHistory P M → Option Bool /-- An adaptive message-injecting adversary with randomness `R` corrupting at most `C` nodes.
