import Papers.PODC2019.CommComplexityBA.Theorem13 import Papers.PODC2019.CommComplexityBA.Basic /-! # Theorem 13 fails for `n = 2` With two nodes (sender `0` and node `1`), `C = 1`: the sender sends its bit once; node `1` outputs `true` iff it received `true` from the sender in round 0. This solves Byzantine broadcast with probability `1` against every adaptive adversary corrupting one node, and only the sender ever speaks. So the paper's Theorem 13 (BB; Theorem 3 for BA is unaffected) needs an assumption such as `n ≥ C + 2` (our `theorem_13`); the proof needs a forever-honest node other than `S` in `W_{h,b}`. -/
