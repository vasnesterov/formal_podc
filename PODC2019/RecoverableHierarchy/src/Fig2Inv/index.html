While a process `i` runs the check of iteration `k₀` with decision `d` and no reset so far, at loop index `y`, either `G C k₀ d` holds or some process `z ≠ i` with `z ≥ y` (not yet inspected) has `R[z] ≥ k₀ + 2` (`Bad`), in which case `i` will find it and reset.
