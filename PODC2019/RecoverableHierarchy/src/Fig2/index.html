import Papers.PODC2019.RecoverableHierarchy.Defs /-! # Figure 2: from conventional consensus to recoverable consensus with `≤ f` failures Golab, *Recoverable Consensus in Shared Memory* (PODC 2019; arXiv 1804.10597), Section 4, Figure 2, and its analysis in Appendix B (Lemmas 12–15, Theorem 16 = Theorem 2). Objects (`Idx n f = (Fin n ⊕ Fin (f+1)) ⊕ Fin (f+1)`, typed with CSLib's `withRW`: read/write registers `Rr` and consensus objects): * `R z` (`.inl (.inl z)`): read/write register over `ℕ`, initially `0` (the paper's `R[1..n]`); * `D k` (`.inl (.inr k)`): read/write register over `Option Bool`, initially `⊥ = none`; * `C k` (`.inr k`): an atomic consensus object `consObj Bool` (the paper's conventional wait-free consensus algorithm `C[k]`, accessed once per process by Lemma 12, so it behaves as an atomic one-shot consensus object; initial value `none`). Local states `Loc n f` = the process id and a program counter `PC n f` encoding the pseudo-code faithfully, one shared-memory access per step (each program counter denotes the point *before* an access; local computations are folded into the continuations): * `rd16 k v` — line 16 of iteration `k` (`v` is the current proposal): read `R[i]`; if it equals `k` go to line 17, otherwise to iteration `k+1`. For `k > f` the `for` loop is exhausted: the process reached the end of the pseudo-code without returning (footnote 4); we model this as a stuck state that keeps reading `R[i]` and never outputs. * `wr17 k v` — line 17: `R[i] := k+1`. * `scan k j v` — lines 18–21: for `j < k` read `D[j]` and adopt its value if not `⊥` (lines 19–20); for `j = k` propose `v` to `C[k]` (line 21) and get `d`. * `wr22 k d v` — line 22: `D[k] := d`; then, if `k < f`, the check of lines 23–26, otherwise line 28. * `chk k d v reset y` — lines 24–26 at the process `y ≠ i`: read `R[y]`; if it exceeds `R[i] = k+1` set `reset` (the paper's `d := ⊥`, line 26). The loop runs over all `y ≠ i` in increasing order without breaking. **Tiny deviation**: the paper re-reads `R[i]` at line 25; we compare with `k+1`, the value of `R[i]` known locally (only `p_i` writes `R[i]`, and it wrote `k+1` at line 17). * after the check: if not `reset`, `done d` (line 28: return `d`, an output state); otherwise line 16 of iteration `k+1` (with the current proposal `v`). `init i x = ⟨i, rd16 0 x⟩`: after a crash a process restarts the procedure from line 15 with its own input as proposal. -/ namespace Podc.RecoverableHierarchy.Fig2 open Cslib.SharedMemory
