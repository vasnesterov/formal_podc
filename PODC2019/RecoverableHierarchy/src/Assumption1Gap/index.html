import Papers.PODC2019.RecoverableHierarchy.Theorem3 /-! # The literal Assumption 1 does not support the proof of Theorem 3 The proof of Theorem 3 restricts attention to executions obeying **Assumption 1**: "a process `pᵢ` takes a crash step iff (1) `pᵢ`'s previous step was its *first access* in this execution to some TAS object, and (2) `pᵢ` is the lowest-numbered process". With *readable* TAS objects, a read is an access. Case C of the proof claims that if `p₁` has accessed the TAS object `T` then `T` holds `1`, which is false when that access was a read. We show that the restricted-model argument cannot be repaired without changing the assumption: the simple algorithm `A₀` below (one rTAS object `T` and two registers `P[0]`, `P[1]`) is **correct on all executions of the literal restricted model** (`literal_assumption1_rcorrect`), although it is not a recoverable consensus algorithm with at most one failure (`A₀_not_solvesP`, from Theorem 3 with the repaired assumption, `theorem3`). Algorithm `A₀`, process `i` with input `v`: 1. `P[i] := v`; 2. read `T` (a dummy read: under the literal Assumption 1 this is `p₀`'s first access to `T`, so `p₀` crashes right after it, and never again); 3. `tas T`: if it returns `0`, output `v`; 4. otherwise output `P[1 - i]`. In the literal restricted model the crashing process `a = 0` crashes exactly once, right after its first read of `T`, *before* its first `tas`; hence the `tas` winner never crashes afterwards and the
