import Papers.PODC2019.RecoverableHierarchy.Valency /-! # The critical state: initial bivalence and the case analysis toolkit * `Restr.biv_init`: with inputs `a ↦ 0`, `b ↦ 1` (others arbitrary, here `0`) the initial state is bivalent: `a` alone decides `0`, `b` alone decides `1` (validity + indistinguishability from the unanimous initial states). The paper's proof of Theorem 3 does not state this step. * `Restr.crit`: the bundled outcome of the construction: a bivalent `σ` with `σ a` `v`-univalent and `σ b` `w`-univalent, `v ≠ w`, and no process has output at `σ`. * The cases of the proof of Theorem 3, each yielding `v = w` (a contradiction): - `Crit.false_of_b_absorbs` (Case D: `b` cannot distinguish `σ a b` from `σ b`), with the instances `absorb_b_of_pend` (`a`'s move is a crash, Subcase D-1) and `absorb_b_of_absorb` (`b`'s operation absorbs `a`'s: `a` reads, or `b` blindly overwrites, Subcases D-1/D-2); - `Crit.false_of_a_absorbs` (Case D with roles exchanged: `a` cannot distinguish `σ b a` from `σ a`), instance `absorb_a_of_absorb`; - `Crit.false_of_commute` (Cases A and C: `σ a b = σ b a`), instances `commute_of_ne` (distinct objects) and `commute_of_commuteAt` (operations on one object commuting at its value with the same responses); - `Crit.false_of_hide` (Case B: `a`'s first triggering
