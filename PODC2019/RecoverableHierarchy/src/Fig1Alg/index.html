import Papers.PODC2019.RecoverableHierarchy.Defs /-! # Figure 1 of Golab (PODC 2019): the algorithm and its abstract view The transformation of Figure 1 turns a conventional 2-process consensus algorithm `C` into a 2-process recoverable consensus algorithm tolerating arbitrarily many *simultaneous* crash-recovery failures (`SEv.crashAll`). We model `C` by an atomic consensus object (`consObj Bool`); the registers `P[1]`, `P[2]` (here `P 0`, `P 1`) and `D` are read/write registers over `Option Bool` (`none` = `⊥`). ``` Procedure Decide(v) for process p_i 2 if P[i] = ⊥ ∧ P[other] = ⊥ then 3 P[i] := v 4 d := C.Decide(v) 5 D := d 6 return d 7 else if D ≠ ⊥ then 8 return D 9 else if P[i] ≠ ⊥ ∧ P[other] = ⊥ then 10 return P[i] 11 else if P[i] = ⊥ ∧ P[other] ≠ ⊥ then 12 return P[other] 13 else 14 return P[1] ``` Every shared-memory access is one step; the conditions of lines 2, 9 and 11 read the two registers separately (first `P[i]`, then `P[other]`), as written. Program counters: `PC`. Main results (in `Fig1.lean`): * `theorem1` (Theorem 1 = Theorem 11): `SolvesS alg` — agreement (all outputs of an execution, also of different incarnations of one process, are equal), validity and recoverable wait-freedom, with arbitrarily many simultaneous crash-recovery failures; * `lemma8` (Lemma 8): in every execution each process accesses `C` at most once. This file: the algorithm `alg`, the abstract view `St` of configurations (program counters, register values, the state of `C`, inputs) and the abstract step `sstep`, with `view (srun C α) = α.foldl
