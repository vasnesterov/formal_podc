"forced value" predicate `Good s v`: * it holds for the value of every return state (`good_of_ret`), * it is preserved by every event (`Good.sstep`), so it holds at the end of an execution for every value output at some point of it (also by incarnations that crashed afterwards), * it determines `v` (`Good.unique`), and `v` is an input (`Good.valid`). `Good s v` has three cases, matching the paper's case analysis: (a) `D = v` (decided through `C` and recorded at line 5; Lemma 9); (b) exactly one proposal `P[j] = v` is recorded and the other process cannot record its proposal any more (Lemma 10, Case 2); (c) both proposals are recorded, `D = ⊥` and nobody is in lines 3–5, so `D` stays `⊥` forever and every return is at line 14 (Lemma 10, Case 3). -/ namespace
