import Papers.PODC2019.RecoverableHierarchy.Defs /-! # The restricted failure model of Assumptions 1 and 2 The impossibility proofs of Theorems 3 and 6 restrict attention to executions in which only two processes `a` (the paper's `p₁`) and `b` (`p₂`) take steps, `b` never crashes, and `a` crashes **if and only if** its previous step was its first *triggering* operation on some object (Assumption 1: the first access to a TAS object; Assumption 2: the first access to a consensus object). Which operations trigger a crash is a parameter `trig`; the triggering objects lie in a finite set `F`, so a restricted execution has at most `|F|` crashes. In the restricted model every process has exactly one possible next move, so an execution is determined by its *schedule* `σ : List Bool` (`false` = a move of `a`, `true` = a move of `b`). We track the restricted state `RS`: the configuration, the set `trg` of objects on which `a` has already applied a triggering operation, and a flag `pend` ("`a` must crash next"). * `Restr.mv`, `Restr.ev`, `Restr.rrun`, `Restr.evs`: moves, the underlying events of CSLib's model, runs (`rrun_c`: the configuration is CSLib's `run` of the underlying events); * `Restr.numCrashes_E_le`: a restricted execution has at most `|F|` crashes; * `Restr.RCorrect`: agreement (distinct processes), validity and recoverable wait-freedom on the restricted executions — what the paper's proofs use; `SolvesP.rcorrect` derives it from the paper's specification. -/ namespace Podc.RecoverableHierarchy open Cslib.SharedMemory Cslib.SharedMemory.Recoverable set_option linter.unusedSectionVars false
