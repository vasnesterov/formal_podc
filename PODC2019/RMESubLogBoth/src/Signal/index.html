import Mathlib /-! # The Signal object of [JJJ19], Section 2 (Theorem 1) P. Jayanti, S. Jayanti, A. Joshi, *A Recoverable Mutex Algorithm with Sub-logarithmic RMR on Both CC and DSM*, PODC 2019 (arXiv 1904.02124v2), Section 2.1, Figure 2, Theorem 1, proof in Appendix D. ## Model Asynchronous shared memory, processes of an arbitrary type `P` (with decidable equality), one shared access per step, no crashes (Section 2 of the paper does not mention crashes). An execution is determined by an arbitrary *schedule* `σ : ℕ → Action P`: at each time the environment either lets an idle process invoke `set()` or `wait()`, or lets some process execute the next line of its current operation (`Action.step`). There are no fairness assumptions. Shared memory: `Bit`, `GoAddr`, and the boolean cells created by `new Boolean` (line 5). A cell is a pair `(q, k)`: the `k`-th cell allocated by process `q`; it lives in `q`'s memory partition (DSM). Line 3 is a local test and is merged with line 2; line 5 (`new Boolean`) is a local step. The abstract `State` of the Signal object (Figure 1) is a ghost field `Config.state`; it is set to `1` (`true`) exactly at the linearization point of the first effective `set()`, which is the first event that is either the completion of some `set()` or a `wait()` reading `Bit = 1` at line 8 (this is the linearization of Appendix D). Theorem 1 (i) shows that this point always lies inside a pending `set()` execution that has already performed line 1, so it is a legitimate linearization point. A second ghost field `Config.cache` records which processes hold a valid cached copy of each boolean cell; it is only used to count RMRs on a CC machine. -/ namespace Podc.RMESubLogBoth.Signal
