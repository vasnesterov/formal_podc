Model (derandomised, Section 4: the hash function `hash : E → ℝ` is fixed by the oracle; the paper's hash values lie in `[0, 1]`). We read Algorithm 1 with **set semantics**: "`sampleSet, init k 1's`" is the set `{1}`, so * `Θ = max(sampleSet)` (`theta`), initially `1`; * `update(a)` (lines 9–13): if `h(a) ≥ Θ` do nothing, else insert `h(a)` and keep the `k` smallest samples (`kSmallest`); * `query() = est = (|sampleSet| - 1) / Θ` (lines 7, 13); * `merge` (lines 15–18): keep the `k` smallest samples of the union; * `snapshot` copies `est`, `calcHint = Θ`, `shouldAdd(H, a) = (h(a) < H)` (lines 19–26). With set semantics the estimate is the exact number of distinct hash values while fewer than `k` of them have been seen, and the KMV estimator `(k - 1)/Θ` afterwards. Main declarations: * `kSmallest k s`: the `k` smallest elements of a finset of a linear order (via `rank`), with `card_kSmallest`, `kSmallest_union_left`, `kSmallest_union`, `kSmallest_insert_of_le_rank`. * `thetaSketch k hash`: the sequential sketch; `thetaSketch_run`: `run A` is the set of the `k` smallest elements of `{1} ∪ h(A)`. * `theta_run_append_le`: Θ is monotonically non-increasing along a stream. * `thetaSketch_run_filter`: the pre-filtering law (if `h(a) ≥ Θ(run A)`, `a` can be dropped from any later point of the stream). * `thetaComposable k hash`: Algorithm 1 as a `Composable` sketch. * Accuracy (Section 5.3): `thetaSketch_query_exact` (exact while fewer than `k` distinct hash values have been seen), `thetaSketch_query_of_le` (`(k - 1)/Θ` once `k` or more have been seen), and `thetaSketch_not_exact_k` (with exactly `k` distinct values the answer need not be exact: the paper's "perfect accuracy in streams with up to `k` unique
