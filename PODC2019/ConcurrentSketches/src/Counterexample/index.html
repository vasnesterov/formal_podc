import Papers.PODC2019.ConcurrentSketches.ParSketchMain /-! # The initial hint `1` must be the hint of the empty sketch Algorithm 2 initialises `hint_i` and `prop_i` to the constant `1`, while the paper only requires of a composable sketch that `calcHint()` returns a non-zero value and that `shouldAdd(h, a)` is safe *for hints `h` returned by `calcHint`*. For the paper's Θ sketch `1` is indeed the hint of the empty sketch (`Θ = 1`), but for a general composable sketch the first `b` updates of every thread are filtered with a hint that was never computed by `calcHint`, and Lemma 1 / Theorem 1 fail. `cntSketch` is an exact counter whose hints are always `2`, and `shouldAdd h a = (h ≠ 1)`: it satisfies all requirements of a composable sketch (`shouldAdd(calcHint(), a)` is always true). With the paper's initial hint `1`, every update is filtered out forever, and queries after two completed updates return `0`. This history has no linearization in `SeqSketch_{Nb}` for `N = b = 1` (`parSketch_hint_one_not_relaxed`), so `ParSketch` is not even linearisable with respect to `SeqSketch_{Nb}` (`parSketch_hint_one_not_stronglyLinearizable`).
