import Mathlib /-! # Shared memory with static permissions and split operations (model for Theorem 6.1) Aguilera, Ben-David, Guerraoui, Marathe, Zablotchi, *The Impact of RDMA on Agreement*, PODC 2019 (arXiv:1905.12143v2), Section 3 and Section 6. The model of Theorem 6.1: processes `P` access registers `R` (holding values `W`) of a memory that never fails. Permissions are static: `canRead p r`, `canWrite p r` are fixed by the algorithm. A read without permission returns `nak`; a write without permission returns `nak` and has no effect. Every operation is *split*: a process invokes it (it becomes *pending*), later it takes effect atomically at the memory (*linearization*, event `lin`), and its response is delivered to the process later still. A process may have any number of pending operations, linearized in any order (the paper allows one outstanding operation per object; algorithms obeying that restriction are a special case). Processes are deterministic automata that act only in their own steps: a step receives the oldest `k` undelivered responses (possibly none), updates the local state and invokes a finite list of new operations. Initially every process invokes the operations given by `init`. All event lists are executions (a `lin` of an operation that is not pending is a no-op, a `step` with `k` larger than the number of available responses receives all of them): the set of reachable configurations is that of the usual partial semantics. Crashes need no event: a crashed process simply takes no more steps. Safety properties quantify over all executions. *Synchronous runs* (`syncRun`) model the paper's common-case executions with the delay metric of §3: an operation invoked at time `t` takes effect at time `t + 1` and its response is received at time `t + 2`; computation is instantaneous. In round `t + 1` all operations invoked at time `t` take effect, all reads before all writes (ties between simultaneous operations are broken *read-first*), and then every non-crashed process takes one step receiving exactly the responses that became available in round `t` (those of the operations it invoked at time `t - 1`).
