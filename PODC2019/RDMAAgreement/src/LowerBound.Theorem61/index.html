import Papers.PODC2019.RDMAAgreement.LowerBound.Model /-! # Theorem 6.1: no 2-deciding consensus with static permissions Aguilera, Ben-David, Guerraoui, Marathe, Zablotchi, *The Impact of RDMA on Agreement*, PODC 2019 (arXiv:1905.12143v2), Theorem 6.1. Proof (repaired version of the paper's). In the failure-free synchronous run with read-first tie breaking, the reads a process `p` invokes at time 0 take effect before any write, so they return the initial memory; write responses are fixed by the static permissions. Hence the local state of `p` at times 0, 1, 2 is a function of its input alone (`view0`, `view1`, `view2`). Suppose it records a decision `v`. Take `v' ≠ v` and the synchronous run `E''` in which `p` is crashed from the start and everybody else has input `v'`: by termination some `q ≠ p` decides, by validity it decides `v'`. Now build the asynchronous execution `E'`: `p` (input as before) invokes its initial operations, its reads take effect at once, its writes stay pending; then the others replay `E''` (they cannot see `p`: its reads change nothing and its writes have not taken effect), so `q` decides `v'`; finally `p`'s writes take effect and `p` replays its first two steps and decides `v`, contradicting agreement. The paper's proof instead starts from an *arbitrary* execution in which `p` decides in two delays and lets a single process `p'` run alone; see `differencies.md` for why both steps need repair. -/ **Theorem 6.1** of [Aguilera et al., PODC 2019]: in the partially synchronous shared-memory model with registers with arbitrary *static* permissions, a memory that never fails, and at most one process
