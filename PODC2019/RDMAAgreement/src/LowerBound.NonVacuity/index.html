Every process has at most one operation in flight, and a step receiving no response does nothing. * `P0` (input `v0`): writes `a0 := some v0`; on the ack reads `a1`; if it is `none`, decides `v0` (fast path); otherwise reads `d` until it is `some w` and decides `w`. * `P1` (input `v1`): writes `a1 := some v1`; on the ack reads `a0`; decides the value read if any, otherwise `v1`; then writes `d := its decision`.
