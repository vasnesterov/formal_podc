import Mathlib.Data.Fintype.Fin import Mathlib.Order.Basic import Mathlib.Tactic.FinCases /-! # Consistency layers: Eventual Consistency and Eventual Consensus (Section 4.2, Appendix B) A run of a consistency layer is described, as in the paper, by the sequences `S(i, t)`: the last sequence delivered to process `p_i` at (or before) time `t` (`S(i, 0) = []`; a crashed process keeps its last sequence), by the submission of the operations (which process submitted an operation, and when), and by the set of correct processes. * `LayerRun`, `Nontriviality`, `SetStability`, `PrefixConsistency` (C1)–(C3), `EventualConsistency`. * `StableFrom R t` (the property in Eventual Stability, from time `t` on), `EventualStability` (there is such a time *in this run*: all layer properties are properties of runs), `EventualConsensus`. * `TConsistent R t` (`t`-consistency, Appendix B). **Lemma 5 is false** (`lemma5_false`): `t`-stability does not imply `t`-consistency. The proof of Lemma 5 applies (C3) to the operations at a position where two correct processes disagree, but (C3) only concerns operations submitted by *correct* processes. In the counterexample a faulty process submits `a` and `b`; after a common prefix `[c]` (submitted by a correct process) one correct process delivers `[c, a]` and the other `[c, b]`, forever. -/ namespace Podc.EventualLinearizability /-- A run of a consistency layer. -/ structure LayerRun (Proc Item : Type) where /-- `S i t`: the last sequence delivered to `p_i` at time `t` (or before). -/ S : Proc → ℕ → List Item /-- `sub o = some (j, t)`: `o` was submitted by `p_j` at time `t`; `none`: never submitted. -/ sub : Item → Option (Proc × ℕ) /-- The correct processes. -/ correct : Set Proc namespace LayerRun variable {Proc Item : Type} (R : LayerRun Proc Item) /-- `S(i, 0)` is the empty sequence. -/ def Initial : Prop := ∀ i, R.S i 0 = [] /-- **Nontriviality**: every operation in `S(i, t)` has been submitted at a time `t' ≤ t`, and appears only once in `S(i, t)`. -/ def Nontriviality : Prop := ∀ i t, (∀ o ∈ R.S i t, ∃ j t', R.sub o = some (j, t') ∧ t' ≤ t) ∧ (R.S i t).Nodup /-- **Set stability**: if `t ≤ t'` then each operation of `S(i, t)` is in `S(i, t')`. -/ def SetStability : Prop := ∀ i t t', t ≤ t' → ∀ o ∈ R.S i t, o ∈ R.S i t' /-- **Prefix consistency** (C1)–(C3) with the common prefixes `P`. -/ def PrefixConsistencyWith (P : ℕ → List Item) : Prop := (∀ i ∈ R.correct, ∀ t t', t ≤ t' → P t <+: R.S i t') ∧ (∀ t t', t ≤ t' → P t <+: P t') ∧ (∀ o j t', R.sub o = some (j, t') → j ∈ R.correct → ∃ t'', t' ≤ t'' ∧ o ∈ P t'') /-- **Prefix consistency**. -/ def PrefixConsistency : Prop := ∃ P, R.PrefixConsistencyWith P /-- **Eventual Consistency** (Section 4.2). -/ def EventualConsistency : Prop := R.Initial ∧ R.Nontriviality ∧ R.SetStability ∧ R.PrefixConsistency /-- The property required by Eventual Stability, from time `t` on: for `t ≤ t' ≤ t''`, `S(i, t')` is a prefix of `S(i, t'')`, for every process. -/ def StableFrom (t : ℕ) : Prop := ∀ i t' t'', t ≤ t' → t' ≤ t'' → R.S i t' <+: R.S i t'' /-- **Eventual Stability**: there is a time from which the run is stable. -/ def EventualStability : Prop := ∃ t, R.StableFrom t /-- **Eventual Consensus** (Section 4.2) = Eventual Consistency + Eventual Stability. -/ def EventualConsensus : Prop := R.EventualConsistency ∧ R.EventualStability /-- **`t`-consistency** (Appendix B): the sequences of any two correct processes at times after `t` are prefixes of each other. -/ def TConsistent (t : ℕ) : Prop := ∀ i ∈ R.correct, ∀ j ∈ R.correct, ∀ ti tj, t < ti → t < tj → R.S i ti <+: R.S j tj ∨ R.S j tj <+: R.S i ti end LayerRun /-! ### Lemma 5 is false -/ /-- The counterexample: processes `0, 1`
