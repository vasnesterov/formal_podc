import Papers.PODC2010.EventualLinearizability.Theorem1 import Papers.PODC2010.EventualLinearizability.Layer /-! # Algorithm 1 is not weakly consistent over Eventual Consensus Algorithm 1 of the paper (the sufficiency part of Theorem 3): on `invoke(o)`, a process sets `curr ← o` and submits `o` to the consistency layer; on `deliver(H)`, if `curr ∈ H` it completes `curr` with the result of executing `H` up to and including `curr`. We model Algorithm 1 for an arbitrary deterministic object (`alg1`): a run is a list of low-level input events (high-level invocations and layer deliveries, one per time unit, the `k`-th event at time `k + 1`); operations are identified by the order of their invocations; `alg1` produces the high-level history, and `layerOf` the consistency-layer run (`S(i, t)` = last sequence delivered to `p_i` by time `t`, submission = invocation). **Counterexample** (`algorithm1_not_weaklyConsistent`). Swap register, initially `0`: ``` 1 p1 invokes x = swap(1) (submitted) 2 p0 invokes o' = read (submitted) 3 deliver [x] to p1 x returns 0 4 deliver [x, o'] to p0 o' returns 1 5 p0 invokes o = read (submitted) 6 deliver [o, x, o'] to p0 o returns 0 (set stability allows reordering) 7 deliver [o, x, o'] to p1 8 deliver [o, x, o'] to p2 ``` The layer run satisfies Eventual Consensus (stable from time 7 on, common prefix `[o, x, o']` from time 8 on, all processes correct). The high-level history is not weakly consistent: `τ(p0, o')` must contain `x` (the only `swap(1)`), so `τ(p0, o)` contains `x` before `o`, and `o` must return `1`, not `0`. The paper's claim "Weak consistency directly derives from the set stability and nontriviality properties" (proof of Lemma 6) overlooks that set stability allows operations observed earlier to be
