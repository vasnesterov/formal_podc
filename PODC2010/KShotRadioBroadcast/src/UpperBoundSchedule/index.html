The algorithm interleaves * *Line-Transmit*: stages `a = 0, …, p` (cyclically), each made of the `p` steps `b = 0, …, p - 1` with transmission set `L_{a,b}`; * *Round-Robin*: slots `0, …, p² - 1` (cyclically), slot `m` with transmission set `{m}` (empty if `m ≥ n`), as follows: one Line-Transmit step, then `K = ⌈p / (k - 2)⌉` Round-Robin steps, and so on. Step `t ≥ 1` is a Line-Transmit step iff `(t - 1) mod (K + 1) = 0`; a *stage* is a block of `S = p (K + 1)` consecutive steps (stage `g` = steps `g S + 1, …, (g + 1) S`), during which Line-Transmit runs through all lines of direction `g mod (p + 1)`.
