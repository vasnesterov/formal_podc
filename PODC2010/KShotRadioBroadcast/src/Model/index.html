A network is a directed relation `E : V → V → Prop` (`E u v`: `u` can transmit to `v`) together with a source `s : V`. Undirected (symmetric) networks are the case `E = G.Adj` for a `SimpleGraph G`. **Oblivious protocols.** An oblivious protocol is a schedule `σ : ℕ → Finset V` of transmission sets (`σ t` is used at step `t ≥ 1`; `σ 0` is ignored). With the `k`-shot rule, a node that received the source message at step `r` transmits at the first `k` steps `t > r` with `v ∈ σ t` (`TransmitsAt`). The source holds the message at step `0`; there are no spontaneous transmissions. **Collisions.** Synchronous steps, no collision detection: an uninformed node `v` receives the message at step `t` iff exactly one of its in-neighbours transmits at step `t` (`recvTime`). -/ namespace Podc.KShotRadioBroadcast open Finset set_option linter.unusedSectionVars false variable {V : Type*} [Fintype V] [DecidableEq V] /-- An oblivious protocol: the transmission set of every step `t ≥ 1`. -/ abbrev Schedule (V : Type*) := ℕ → Finset V /-- Number of appearances of `v` in the schedule at the steps strictly between `a` and `b`. -/ def count (σ : Schedule V) (v : V) (a b : ℕ) : ℕ := ((Finset.Ioo a b).filter (fun t => v ∈ σ t)).card /-- The `k`-shot rule: a node `v` that received the message at step `r` transmits at step `t` iff `t` is one of the first `k` appearances of `v` in the schedule after step `r`. -/ def TransmitsAt (σ : Schedule V) (k r : ℕ) (v : V) (t : ℕ) : Prop := r < t ∧ v ∈ σ t ∧ count σ v r t < k theorem count_mono {σ : Schedule V} {v : V} {a b b' : ℕ} (hb : b ≤ b') : count σ v a b ≤ count σ v a b' := by unfold count exact card_le_card (filter_subset_filter _ (Ioo_subset_Ioo_right hb)) instance (σ : Schedule V) (k r : ℕ) (v : V) (t : ℕ) : Decidable (TransmitsAt σ k r v t) := by unfold TransmitsAt; infer_instance open Classical in /-- `recvTime σ k E s t v = some r` iff node `v` has received the source message by step `t`, namely at step `r ≤ t`.
