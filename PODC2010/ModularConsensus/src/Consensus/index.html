An execution of an (infinite) chain `X 0; X 1; X 2; …` of deciding objects (`ChainExec`) consists of an execution of every stage `j`, where the participants of stage `j + 1` are processes that adopted at stage `j`, with the adopted value as input. A process *decides* `v` if it commits `v` at some stage. ## Main results * `ChainExec.validity`, `ChainExec.agreement` — **safety of `U` and `B`** (Section 4.1): if every stage is a weak consensus object (validity and coherence), then decisions are inputs and no two processes decide differently (the paper derives this from Theorem 4 applied to the prefix in which everybody commits; we prove it directly for the whole chain); * `ChainExec.no_next_of_agreement` — the deterministic half of the termination argument: if the outputs of stage `j` (a conciliator) agree and stage `j + 1` (an adopt-commit object) is convergent, every process that reaches stage `j + 1` commits there, so nobody reaches stage `j + 2`; * `ChainExec.no_next_of_commit` — the fast path `A₋₁; A₀`: once a process commits at stage `j`, everybody commits at stage `j + 1` if it is convergent (with `fastPath` in `FastPath.lean`, a process that finishes `A₋₁` before any process with a different input arrives commits); * `stages_prob` — the probabilistic half, abstractly: if the probability of reaching conciliator stage `k + 1` is at most `(1 - δ)` times that of reaching stage `k`, then the chain terminates with probability 1 and the expected number of conciliator stages is at most `1 / δ` (hence `E[T(U)] ≤ 2T(A) + (1/δ)(T(C) + T(A))`, `expected_cost_le`). -/ namespace Podc.ModularConsensus
