import Cslib.Computability.Distributed.SharedMemory.Task import Mathlib.Data.Finset.Basic import Mathlib.Tactic.FinCases import Mathlib.Data.Fin.Basic /-! # Deciding objects and their composition (Section 3 of Aspnes, PODC 2010) J. Aspnes, *A modular approach to shared-memory consensus, with applications to the probabilistic-write model*, PODC 2010 (full version of May 14, 2011). A *deciding object* is a one-shot object whose inputs are values `v : V` and whose outputs are pairs `(d, v)` with a *decision bit* `d ∈ {adopt, commit}`. The properties of Section 3 only mention the inputs and outputs of an execution, so we describe an object by the set of input/output pairs its executions can produce: * `inp : P → Option V` — `some v` iff `p` invoked the object with input `v`; * `out : P → Option (Decision × V)` — `some (d, v)` iff `p` returned `(d, v)`. Executions may be partial (processes may crash or not yet have returned). This is exactly the shape of CSLib's task relation `Task.Δ` (`Cslib.SharedMemory.Task`), so the predicates below are also used as task specifications for concrete implementations (`adoptCommitTask`). ## Main definitions * `Decision`, `Validity`, `Coherence`, `Convergence`, `Agreement`; * `DObj P V`: a deciding object (the input/output pairs of its executions); * `DObj.seq X Y` — the composition `(X; Y)` of Procedure Composition; * `DObj.IsWeakConsensus`, `DObj.IsAdoptCommit`. ## Main results * `DObj.validity_seq` — **Lemma 1**: validity is preserved by composition; * `DObj.coherence_seq` — **Lemma 3**: `X` coherent, `Y` valid and coherent ⇒ `(X; Y)` coherent; * `DObj.isWeakConsensus_seq` — **Theorem 4** (safety part; termination, Lemma 2, is `Cslib.SharedMemory.Impl.seqComp_waitFree`, `SeqCompose.lean`); * `DObj.validity_seq_converse_false` — the remark after Lemma 1 (the converse fails); * `DObj.coherence_seq_needs_validity` — the validity hypothesis of Lemma 3 is needed. -/ namespace Podc.ModularConsensus /-- The decision bit of a deciding object. -/ inductive Decision where | adopt | commit deriving DecidableEq, Inhabited, Repr variable {P V : Type} /-- **Validity.** Every output value equals some process's input. -/ def Validity (inp : P → Option V) (out : P → Option (Decision × V)) : Prop := ∀ p d v, out p = some (d, v) → ∃ q, inp q = some v /-- **Coherence.** If any process outputs `(commit, v)`, then no process outputs `(d, v')` with `v' ≠ v`. -/ def Coherence (out : P → Option (Decision × V)) : Prop := ∀ p q v d w, out p = some (.commit, v) → out q = some (d, w) → w = v /-- **Convergence.** If all inputs are equal to `v`, all outputs are `(commit, v)`. -/ def Convergence (inp : P → Option V) (out : P → Option (Decision × V)) : Prop := ∀ v, (∀ p x, inp p = some x → x = v) → ∀ p d w, out p = some (d, w) → d = .commit ∧ w = v /-- **Agreement** (of a deciding object): all output values are equal. -/ def Agreement (out : P → Option (Decision × V)) : Prop := ∀ p q d e v w, out p = some (d, v) → out q = some (e, w) → v = w /-- A deciding object, described by the input/output pairs of its (possibly partial) executions. -/ def DObj (P V : Type) := (P → Option V) → (P → Option (Decision × V)) → Prop namespace DObj /-- The object satisfies validity in all its executions. -/ def Valid (X : DObj P V) : Prop := ∀ inp out, X inp out → Validity inp out /-- The object satisfies coherence in all its executions. -/ def Coherent (X : DObj P V) : Prop := ∀ inp out, X inp out → Coherence out /-- The object satisfies convergence in all its executions. -/ def Convergent (X : DObj P V) : Prop := ∀ inp out, X inp out → Convergence inp out /-- The safety part of a weak consensus object (validity and coherence); termination is a property of implementations (`Cslib.SharedMemory.Impl.WaitFree`, see `SeqCompose.lean`). -/ def IsWeakConsensus (X : DObj P V) : Prop := X.Valid ∧ X.Coherent /-- The safety part of an adopt-commit object: validity, coherence and convergence. -/ def IsAdoptCommit (X : DObj P V) : Prop := X.Valid ∧ X.Coherent ∧ X.Convergent /-- The output of the composition for a process, given its outputs from `X` and `Y`: a commit from `X` is returned immediately, otherwise the output from `Y` (if any). -/ def seqOut (oX oY : Option (Decision × V)) : Option (Decision × V) := match oX with | some (.commit, v) => some (.commit, v) | _ => oY /-- **Procedure Composition.** `(X; Y)`: run `X`; on `(commit, v)` return it, on `(adopt, v)` invoke `Y` with input `v` and return its output. An execution of `(X; Y)` consists of an execution of `X` (same inputs) and an execution of `Y` whose participants are processes that adopted from `X`, with the adopted value as input (a process that adopted from `X` may not have invoked `Y` yet, or crash in between);
