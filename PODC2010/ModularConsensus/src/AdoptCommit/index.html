Shared data: a register `proposal : Option V` (initially `⊥ = none`) and binary registers `r i`, `i : ι` (initially `0 = false`). Given write quorums `W v` and read quorums `R v` (finite sets of registers), process `p` with input `v` executes ``` 1 foreach r_i ∈ W_v do r_i ← 1 4 u ← proposal; if u ≠ ⊥ then preference ← u 7 else preference ← v; proposal ← preference 10 if r_i ≠ 0 for some r_i ∈ R_preference then return (adopt, preference) 13 else return (commit, preference) ``` The registers of a quorum are accessed in the order of `Finset.toList`; line 10 reads the registers of `R_preference` one at a time and stops at the first `1` (reading the remaining ones would not change anything). ## Main results * `theorem8_safety` / `theorem8_solves` — **Theorem 8**: if `W v ∩ R v' = ∅ ↔ v = v'`, Procedure AdoptCommit satisfies validity, coherence and convergence in every finite (possibly partial) one-shot execution (`Impl.Solves (adoptCommitTask P V)`); * `theorem8_waitFree` — termination: wait-freedom (when the read quorums have bounded size, e.g. finitely many values). The proof is an invariant (`Inv`) over all reachable configurations; its key clause `Inv.k2` says: if `p` is executing line 10 with preference `v` and has read the registers `S ⊆ R v` as `0`, then no process with input `≠ v` that read `⊥` from `proposal` writes a register of `S`. * `steps_le` — individual work: an operation performs at most `|W v| + 2 + ρ` register operations, where `ρ` bounds the sizes of the read quorums. * `commit_eq_input` — the remark in the proof: a process can only commit its own input. -/ set_option linter.unusedSectionVars false set_option linter.unusedSimpArgs false
