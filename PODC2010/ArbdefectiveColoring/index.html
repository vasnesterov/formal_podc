Verdict: 🔧 Easy fix. Sections 3 and 4 hold up to Corollary 4.4, all with explicit constants: Lemma 3.1, Theorems 3.2 and 3.5, Corollaries 3.4 and 3.6, Lemmas 4.1 and 4.2, Theorem 4.3 and Corollary 4.4, with Lemma 2.1 (Kuhn's defective colouring) and, for Lemma 4.1, the (Δ+1)-colouring of [BE09] as black-box hypotheses. Proof gaps in true statements (1)Corollary 4.4

🔧 Corollary 4.4 (case split on a)

The proof claims that p = ⌊a^{μ'}/log n⌋ > a^{μ'/2} for every superlogarithmic a, but this needs a > (log n)^{2/μ'} and fails for a = (log₂ n)² (corollary_4_4_proof_gap).

Impact. The statement stands, with a corrected threshold and a three-way case split (corollary_4_4).

Details

For "superlogarithmic" a the paper runs Legal-Coloring with p = ⌊a^{μ'}/log n⌋, μ' = μ/2. The claim p > a^{μ'/2} "since a is superlogarithmic" would bound the number of iterations by a constant. This needs a^{μ'/2} > log n, i.e. a > (log n)^{2/μ'}. Counterexample: take a = (log₂ n)² (superlogarithmic) and any μ' ≤ 1/2. Then p ≤ 1 < a^{μ'/2} for every n ≥ 4 (p = 0 if μ' < 1/2). With p = 1, line 15 gives α ↦ ⌊(3+ε)α⌋ ≥ α, so the while-loop never ends (line15_one). So the second case is only valid for a > (log n)^{2/μ'}, not for all superlogarithmic a. The a below this threshold are polylogarithmic, and the paper's remark before the corollary (Theorem 4.3 for polylogarithmic a) can handle them, but only if the threshold is made explicit and Theorem 4.3 is used with a smaller exponent (μ'' = μ²/4). This is a wrongly stated case condition, not a false statement.

Repair

We prove the corollary with three cases, where ℓ = ⌊log₂ n⌋+1:

  1. p₁ = ⌊a^{μ/2}/ℓ⌋ ≥ 16 and (3+ε)a^{μ/4} ≤ p₁: Legal-Coloring with p₁, O(a^μ + log n) rounds;

  2. otherwise a^{μ/4} ≤ 5ℓ: Theorem 4.3 with μ²/4, O(ℓ^{1+μ}) rounds;

  3. a bounded by a constant: Lemma 2.2(1).

(corollary_4_4)

Model.

  • Deterministic synchronous LOCAL model, no failures. The vertices of every graph are the elements of a fixed finite type V, which serve as the identifiers. All vertices know n = |V|, the arboricity bound a and the parameters (ε, μ, k, t, p).

  • Round complexity is CSLib's locality IsLocal R f: the output of v depends only on the edges at distance < R and the inputs at distance ≤ R. This is exactly what R LOCAL rounds compute. Each algorithm is a fixed function of (G, inputs), local for all graphs, and correct on the graphs of arboricity ≤ a.

  • Simple-Arbdefective and the greedy colouring are implemented operationally in CSLib's locally-iterative round model (vertex states with identifier, parents and colour). Their locality comes from run_isLocal. The H-partition is local by a direct induction. Procedures are composed with IsLocal.comp (radii add up). "For each subgraph Gᵢ in parallel" runs the procedure on classGraph G c, which keeps only the edges inside the colour classes. This costs no extra rounds (isLocal_classGraph).

  • Black boxes, as DefectiveAlg V Δ d K R: an R-round algorithm computing a d-defective colouring with colours < K on every graph of maximum degree ≤ Δ.

    • Lemma 2.1 [Kuhn]: Lemma21 V C R, i.e. ⌊Δ/q⌋-defective with < Cq² colours.

    • The (Δ+1)-colouring of [BE09], only for Lemma 4.1: DeltaPlusOne V C' R'.

    The paper takes R = O(log* n); our bounds are explicit in R. Both hypotheses are satisfiable. CSLib's Linial colouring is also packaged as a DefectiveAlg.

  • Arboricity is CSLib's ArboricityLE (edges covered by α forests). Lemma 2.5 is CSLib's OutOrientation.arboricityLE_of_rank. The H-partition only uses an orientation of out-degree ≤ a, so it also works for pseudo-arboricity.

  • Partial orientations are parent sets par v ⊆ N(v). Length means the number of edges on directed walks, which equals the paper's paths for acyclic orientations. Colours are 0, …, k-1.

Explicit bounds:

  • Theorem 4.3, for 0 < ε ≤ 1/2, μ > 0 and p = ⌊a^{μ/2}⌋ ≥ 16: fewer than (3+ε)^{4/μ+1}·a colours, in at most (4/μ+1)(L(9C·a^μ+2)+R) rounds. The final step of Theorem 4.3 needs only O(p² log n) = O(a^μ log n) rounds. So the legal colouring of Lemma 2.1 (q = Δ+1) suffices there, and the (Δ+1)-colouring of [BE09] is not needed for Theorem 4.3.

  • Lemma 4.1: fewer than ((2+ε)(3+ε)+1)a colours, in at most (9C+25)L·a^{2/3} + 25C'a^{2/3} + R + R' + 4L rounds.

  • Corollary 4.4: constants c₁, c₂, c₃ depending only on ε, μ, C, with time c₁(a^μ + ℓ^{1+μ}) + c₂R and fewer than c₃·a colours.

Two parameter choices that the paper leaves implicit:

  • Theorem 3.5 needs an ⌊a/t⌋-defective colouring of the H-sets. These have maximum degree ⌊(2+ε)a⌋, not a, so Lemma 2.1 must be called with parameter ≈ (2+ε)t; we use 3t (valid for ε ≤ 1).

  • Algorithm 2 calls Arbdefective-Coloring on subgraphs whose arboricity is only bounded by α. The H-partition and the defect must use the bound α, not the unknown exact arboricity (line 2 α := a(G₁) must be a known upper bound).

Not formalized. Lemma 2.1 and the [BE09] colouring (black boxes), Lemma 2.2(2) (forest decomposition), Theorem 4.5, Corollaries 4.6 and 4.7, Section 5 (Arb-Kuhn, Theorems 5.2 and 5.3) and Appendix B.

Trust. No sorry. The theorems in the table use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity:

  • Lemma21.satisfiable (NonVacuity.lean) instantiates the Lemma 2.1 hypothesis with C = 1 and n rounds. Each vertex learns its component and outputs a canonical defective colouring, which exists by Lovász's lemma (exists_defective, proved).

  • DeltaPlusOne.satisfiable does the same for the [BE09] hypothesis.

  • linialAlg is a genuine O(log* n) black box: CSLib's Linial algorithm.
