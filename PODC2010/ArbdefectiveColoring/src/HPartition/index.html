We prove: * `active_card_mul_le`: if `G` has an orientation with out-degree `≤ a` (e.g. arboricity `≤ a`, CSLib's `ArboricityLE.hasOutDegLE`), then `|S_{i+1}| · (A + 1) ≤ 2a · |S_i|` for the sets `S_i` of active vertices, so after `L` rounds no vertex is active once `n · (2a)^L < (A + 1)^L` (`not_active_of_lt`); for `A = ⌊(2+ε)a⌋` this is `L = O(log n / ε)` (see `Asymptotics.lean`). * `hPartition` (**Lemma 2.3**): the H-index `hIdx G A L v ∈ [0, L)` (the number of rounds `v` survives) defines a partition `H_0, …, H_{L-1}` of degree at most `A`: every vertex has at most `A` neighbours of H-index at least its own.
