A state stores the identifier of its vertex, its parent set (the input orientation) and the selected colour (`none` before the selection). Vertices without parents select in round `0` without communication (as in the paper). * `orientRun_spec`: on an orientation with a height function bounded by `ℓ`, after `ℓ` rounds every vertex has
