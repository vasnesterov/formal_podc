import Papers.PODC2010.ArbdefectiveColoring.Basic /-! # Locality tools: running an algorithm on all colour classes in parallel Round complexity is expressed with CSLib's extensional locality `Cslib.Local.IsLocal R f` ("`f G x v` only depends on the radius-`R` view of `v`", i.e. `f` is computed by an `R`-round LOCAL algorithm). This file adds: * `IsLocalG R f`: locality of an algorithm `f : SimpleGraph V → V → β` without inputs (the vertices are their own identifiers). * `isLocal_classGraph` (CSLib candidate): running an `σ`-round algorithm in parallel on all the subgraphs induced by the classes of a labelling (i.e. on `classGraph G (κ ∘ x)`) is again an `σ`-round algorithm. This is how the recursive procedures of the paper ("for each `Gᵢ` in parallel do") are composed. * `isLocal_one_nbr` (CSLib candidate): a function of a vertex's own label and its neighbours' labels is `1`-local. -/ open Finset Cslib.Local namespace Podc.ArbdefectiveColoring open scoped Classical set_option linter.unusedSectionVars false variable {V : Type*} [Fintype V] /-- A graph algorithm without
