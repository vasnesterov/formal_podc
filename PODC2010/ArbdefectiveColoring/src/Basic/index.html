Elkin, *Deterministic Distributed Vertex Coloring in Polylogarithmic Time*, PODC 2010 (arXiv:1003.1608), for a simple graph `G` on a finite vertex type `V` (the vertices are their own identifiers). * `classGraph G c`: the spanning subgraph of `G` that keeps the edges whose endpoints have the same `c`-value; it is the disjoint union of the subgraphs induced by the colour classes of `c`. * `IsDefective G c d` (`d`-defective colouring), `IsArbdefective G c r` (Definition 2.1: `r`-arbdefective colouring, every colour class induces a subgraph of arboricity `≤ r`; we state it for the union `classGraph G c`, and `IsArbdefective.induce` gives the per-class form), `IsLegal G c` (legal = proper colouring). * Partial orientations are given by the parent sets `par v` (the out-neighbours of `v`): `IsPartialOrientation`, `IsComplete`, `deficit`, `DeficitLE`, `OutDegLE`, directed paths `IsDirPath`, the length bound `LengthLE par ℓ` ("every directed path has at most `ℓ` edges") and acyclicity `IsAcyclic`. ## Main results * `lengthLE_iff_exists_height`: an orientation has length `≤ ℓ` iff it has a height function with values `≤ ℓ` that strictly decreases along every oriented edge. * `exists_height_of_isAcyclic`: an acyclic orientation of a finite graph has a height function. * `IsAcyclic.of_height`, `LengthLE.isAcyclic`: orientations with a height function are acyclic. -/ open Finset namespace Podc.ArbdefectiveColoring open scoped Classical set_option linter.unusedSectionVars false variable {V : Type*} [Fintype V] /-!
