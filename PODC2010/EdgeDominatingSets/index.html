Edge Dominating Sets in Port-Numbered Networks — PODC 2010

Jukka Suomela. Distributed Algorithms for Edge Dominating Sets. PODC 2010. DOI 10.1145/1835698.1835783. Formalized version: the author's version (http://users.ics.aalto.fi/suomela/doc/eds.pdf, 10 pages, same numbering as the proceedings; there is no arXiv version). Copy of the paper: paper.pdf.

Verdict: ✏️ Slip. All results are formalized and hold as stated: the lower bounds 4 - 2/d (even d) and 4 - 6/(d+1) (odd d) for d-regular graphs (Theorems 1, 2), their bounded-degree consequence 4 - 1/k (Corollary 1), and the matching algorithms (Theorems 3, 4, 5). The lower bounds are proved in a slightly stronger form than stated. The only labeled mistake is a division by |D*| = 0 on edgeless graphs, a degenerate case.

Mistakes in the paper

✏️ Slips

  • §7.8 divides by |D*|, which is 0 for an edgeless graph (degenerate case). We prove the integer form 2k·|D| ≤ (8k − 2)·|D*| instead (card_le_of_props).

Typos

  • §7.7, case c(v) = 3/2: "d_G(v) − 2 other nodes x1, x2 in addition to v" should read "in addition to s and t".

The formalizationmodel, Lean names of the results, trust

Model.

  • Deterministic synchronous message passing in anonymous port-numbered networks (Cslib/Computability/Distributed/PortNumbering/Basic.lean). A PNGraph has degrees and an involution p on ports (0 … deg v − 1); loops and multi-edges are allowed, so the quotient graphs of the covering arguments are PNGraphs too.

  • Initially a node knows only its degree. Each round it sends one message per port and receives one per port, indexed by its own port numbers. Messages and local computation are unbounded.

  • An algorithm runs for T rounds, and then every node outputs a set of its ports. The selected edge set is outEdges; Consistent is the paper's requirement that both endpoints select the edge.

  • The problem is posed on simple graphs (IsSimple, underlying SimpleGraph toSimpleGraph). IsEDS is an edge dominating set, edgeDomNum the minimum size. Approximates A T G α means: consistent, an EDS, and |D| ≤ α·γ'(G).

  • Lower bounds are stronger than in the paper. They hold for every algorithm and every running time T that outputs an EDS on the one graph G. Consistency is not assumed.

  • Upper-bound algorithms are written as local processes. Each round, a node updates its data from its neighbours' data and the remote port numbers. Algorithm.ofLocal turns such a process into a genuine message-passing algorithm, and eval_ofLocal is the bridge.
