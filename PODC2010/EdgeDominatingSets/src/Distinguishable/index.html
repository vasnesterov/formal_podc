import Papers.PODC2010.EdgeDominatingSets.Basic /-! # Distinguishable neighbours (§5 of the paper) For a node `v` of a port-numbered graph, the *label pair* of the edge behind port `i` is the unordered pair `{i, rport v i}`. Port `i` is *uniquely labelled* if no other port of `v` has the same label pair; the *distinguishable neighbour* of `v` is the neighbour behind the smallest uniquely labelled port (`dn v = some i`), if any. * `dnOf d rp`: the distinguishable port, computed from the degree and the remote port numbers only — i.e. from information a node has after one communication round. * Lemma 1 (`dn_isSome_of_odd`): a node of odd degree has a distinguishable neighbour. * `M G i j` (the paper's `M_G(i, j)`): the edges `{v, u}` with `p(v, i) = (u, j)` such that `u` is the distinguishable neighbour of `v`. * Lemma 2 (`M_matching`): each `M G i j` is a matching (in a simple graph). * `edge_mem_M_iff`: whether the edge behind port `q` of `v` is in `M G i j` can be decided by `v` from its own distinguishable port, its remote port numbers, and the distinguishable ports of its neighbours (two rounds of communication). -/ namespace Podc.EdgeDominatingSets open Cslib.PortNumbering Finset /-- Port `i` is uniquely labelled among ports `0, …, d - 1` with remote ports `rp`. -/ def IsUniq (d : ℕ) (rp : ℕ → ℕ) (i : ℕ) : Prop := ∀ j < d, j ≠ i → s(j, rp j) ≠ s(i, rp i) instance (d : ℕ) (rp : ℕ → ℕ) (i : ℕ) : Decidable (IsUniq d rp i) := by unfold IsUniq; infer_instance /-- The distinguishable port: the smallest uniquely labelled port, if any. -/ def dnOf (d : ℕ) (rp : ℕ → ℕ) : Option ℕ := (List.range d).find? fun i => decide (IsUniq d rp i) theorem dnOf_spec {d : ℕ} {rp : ℕ → ℕ} {i : ℕ} (h : dnOf d rp = some i) : i < d ∧ IsUniq d rp i := by unfold dnOf at h have h1 := List.find?_some h have h2 := List.mem_of_find?_eq_some h simp only [decide_eq_true_eq] at h1 exact ⟨List.mem_range.1 h2, h1⟩ /-- `dnOf d rp` only depends on `rp` below `d`. -/ theorem dnOf_congr {d : ℕ} {rp rp' : ℕ → ℕ} (h : ∀ i < d, rp i = rp' i) : dnOf d rp = dnOf d rp' := by unfold dnOf apply List.find?_congr intro i hi have hi := List.mem_range.1 hi rw [decide_eq_decide] unfold IsUniq constructor <;> intro H j hj hji <;> have := H j hj hji · rwa [h j hj, h i hi] at this · rwa [← h j hj, ← h i hi] at this theorem dnOf_isSome {d : ℕ} {rp : ℕ → ℕ} {i : ℕ} (hi : i < d) (h : IsUniq d rp i) : (dnOf d rp).isSome := by unfold dnOf rw [List.find?_isSome] exact ⟨i, List.mem_range.2 hi, by simpa using h⟩ /-- **Lemma 1** (combinatorial core). If no port among `0, …, d-1` is uniquely labelled and the remote ports `rp i` are `< d`... then `d` is even: the map `i ↦ rp i` pairs up the ports. -/ theorem even_of_forall_not_isUniq {d : ℕ} {rp : ℕ → ℕ} (h : ∀ i < d, ¬ IsUniq d rp i) : Even d := by -- each port `i` has a partner `j ≠ i` with the same label pair, hence `j = rp i`, `rp j = i` have key : ∀ i < d, rp i < d ∧ rp i ≠ i ∧ rp (rp i) = i := by intro i hi have := h i hi simp only [IsUniq, not_forall, not_not] at this obtain ⟨j, hj, hji, he⟩ := this rcases Sym2.eq_iff.1 he with ⟨h1, -⟩ | ⟨h1, h2⟩ · exact absurd h1 hji · subst h1; port `j` of `u` leads to both `v` and `w` have h1 : G.nbr (G.nbr v i) j = v := by rw [← hvj]; exact G.nbr_nbr hiv have h2 : G.nbr (G.nbr w i) j = w := by rw [← hwj]; exact G.nbr_nbr hiw rw [← hx₁, hx₂] at h1 rw [h1] at h2 exact hne (by rw [h2]) /-- Every node with a distinguishable neighbour is covered by `⋃ M_G(i, j)`. -/ theorem edge_dn_mem_M {G : PNGraph V} {v : V} {i : ℕ} (h : G.dn v = some i) : G.edge v i ∈ M G i (G.rport v i) := mem_M.2 ⟨v, h, rfl, rfl⟩ /-- Local characterisation of `M_G(i, j)`: the edge behind port `q` of `v` is in `M_G(i, j)` iff either `q = i` is the distinguishable port of `v` and the remote port is `j`, or the neighbour behind `q` has its distinguishable port `rport v q = i` pointing to `v`, and `q = j`. -/ theorem edge_mem_M_iff {G : PNGraph V} (hG : G.IsSimple) {v : V} {q : ℕ} (hq : q < G.deg v) {i j : ℕ} : G.edge v q ∈ M G i j ↔ (G.dn v = some q ∧ q = i ∧ G.rport v q = j) ∨ (G.dn (G.nbr v q) = some (G.rport v q) ∧ G.rport v q = i ∧ q = j) := by constructor · intro h obtain ⟨w, hw, hwj, he⟩ := mem_M.1 h obtain ⟨hiw, -⟩ := G.dn_spec hw by_cases hvw : w = v · subst hvw have : i = q := by have h' : s(w, G.nbr w i) = s(w, G.nbr w q) := he rw [Sym2.congr_right] at h' exact hG.2 w i q hiw hq h' subst this exact Or.inl ⟨hw, rfl, hwj⟩ · have h' : s(w, G.nbr w i) = s(v, G.nbr v q) := he rcases Sym2.eq_iff.1 h' with ⟨h1, -⟩ | ⟨h1, h2⟩ · exact absurd h1 hvw · -- `w = nbr v q` and `nbr w i = v` have hr : G.rport v q = i := by have e1 : G.nbr w (G.rport v q) = v := by rw [h1];
