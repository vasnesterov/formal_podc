Step `n` processes the pair `(n / Δ, n % Δ)`; `Δ²` steps cover all pairs with `i, j < Δ`. * `addStep` (phase I of Theorem 4): add `e ∈ M_G(i, j)` unless both endpoints are already covered. * `remStep` (phase II of Theorem 4): remove `e ∈ D ∩ M_G(i, j)` if both endpoints are covered by `D \ {e}`. * `matchStep` (phase I of Theorem 5): add `e ∈ M_G(i, j)` if neither endpoint is covered.
