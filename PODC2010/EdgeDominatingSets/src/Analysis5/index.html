The algorithm `A(Δ)` of §7.1 (odd `Δ = 2k + 1 ≥ 3`) outputs `D = M ∪ P`, where `M` and `P` satisfy the properties (a), (b), (c) of §7.3 (`Props`). Here we prove, purely graph-theoretically, that any such pair satisfies `|M ∪ P| ≤ (4 - 1/k)|D*|` for every edge dominating set `D*` (`card_le_of_props`, `card_le_edgeDomNum_of_props`). The proof is the integer (doubled) version of the paper's cost/weight double counting: * `internal Dstar`: the nodes covered by `D*` (`|I| ≤ 2|D*|`); every edge has an internal endpoint. * `cost y z`: twice the cost that the `D`-edge `{y, z}` charges to the internal node `y` (`2` if `z` is external, `1` if `z` is internal); `∑_{y ∈ I} ∑_z cost y z = 2|D|` (`sum_cost`). * `weight y z`: the weight of the edge `{y, z}` seen from `y` when `z` is an external `P`-node (`2 - deg z` if `{y, z} ∈ P`, `2` otherwise); the total is `≥ 0` (`sum_weight_nonneg`, §7.7). * `node_bound`: for every internal `y`, `(Δ - 1)·x(y) + w(y) ≤ 4Δ - 6` (§7.7 case analysis). The paper takes `D*` to be a minimum maximal matching; the argument only uses that `D*` is an edge dominating set (to get `|I| ≤ 2|D*|` and that every edge has an internal endpoint), so it applies to a minimum edge dominating set directly and the Yannakakis–Gavril theorem is not needed.
