import Papers.PODC2010.MultiVersionSTM.Basic /-! # Frame and commutation lemmas for STM executions Generic facts about the base-object semantics of `STM.run` (Section 3 of Perelman–Fan–Keidar, PODC 2010), used in the proof of Theorem 2. * **Traces.** `applyTrace m tr` is the memory `m` after the writes of the trace `tr`, and `TraceOK m tr` says that `tr` is consistent with `m` (every access reads the current value). The run of a program (`Prog.run_mem`, `Prog.run_traceOK`), of a step and of a schedule (`STM.run_mem`, `STM.run_traceOK`) produces a consistent trace, and its final memory is the initial memory updated along the trace. * **Frame lemma** (`Prog.run_congr`, `STM.run_congr`): a run depends only on the private states of its threads and on the values of the base objects it accesses. * **Commutation** (`STM.run_comm`): if two schedules `A` and `B` run by disjoint sets of threads only share base objects that neither of them changes, then running `B` then `A` gives the same steps (events and traces) for each part and the same final configuration as running `A` then `B`. -/ namespace Podc.MultiVersionSTM open scoped Classical variable {Tx O P : Type} /-! ### Traces -/ section
