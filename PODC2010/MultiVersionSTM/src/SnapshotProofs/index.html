import Papers.PODC2010.MultiVersionSTM.SnapshotLemmas /-! # The snapshot STMs are valid For both the eager and the lazy snapshot STM (`snapSTM lazy`, `Snapshot.lean`) we prove `snapSTM_valid`: it is strictly serializable, MV-permissive, its reads return written versions, a read returns a kept version, and garbage collection is final (`STM.Valid`). The proofs are first done at the level of histories generated by the strategy (`Gen lazy h`) and then transferred to the STM. * **Reads of written versions.** A latest version was written by a committed writer (`writes_of_latest`); an update transaction returns its own write only after writing. * **MV-permissiveness.** The only aborts are reads and commits of update transactions that fail the read-set validation. The failed read returned the then-latest version, so some update transaction committed a write of the object after the read: it is concurrent with the aborted transaction and conflicts with it (`conflict_of_not_validates`). * **Strict serializability** (of the complete transactions). The serialization position of a complete transaction is given by a key: `2 * i + 1` for an update transaction committing at index `i`; `2 * s` for a read-only transaction whose snapshot (at its commit) has length `s`, and for an aborted update transaction whose last external read has index `s` (`abSnap`: every read validates the earlier ones, so all its reads return versions of the prefix of length `s`); ties are broken by the index of the first event (`serPos`). The version of `o` in the prefix of length `s` is the one of the committed writer of `o` with the largest commit index below `s` (`WF.of_latest_some`), hence the last committed writer of `o` below the reader in the serialization. * **Versions kept.** A version that is not kept is neither the latest one nor in the snapshot of a live read-only transaction; a step only installs a version of the committing transaction (not an existing version) and moves snapshots only to the new end of the history (`snap_snoc`). -/ namespace Podc.MultiVersionSTM open scoped Classical variable {Tx O P : Type}
