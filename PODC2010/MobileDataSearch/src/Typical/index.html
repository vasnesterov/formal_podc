import Papers.PODC2010.MobileDataSearch.Basic /-! # Typical tokens and load balancing (Section 4, up to Lemma 3) Bar-Noy, Cheilaris, Feng, Levin, *Finding mobile data under delay constraints with searching costs*, PODC 2010, Section 4. A *typical* token has `p = w` (after normalization), with `∑ p = 1`. * Proposition 3: `cost(A) = 1/2 + 1/2 ∑_d P_d²` (`prop3`). * Definition 1: the `L₂` load balancing objective `lbCost p A = ∑_d P_d²`. * Lemma 3: a `(1+ε)`-approximation for load balancing is a `(1+ε')`-approximation for the typical-token search problem with `ε' = ε · O/(1+O) ≤ ε/2` (`lemma3`, `lemma3_half`, `lemma3_lt_half`), where `O` is the optimal load balancing value; `1/D ≤ O` gives `O/(1+O) ≥ 1/(D+1)` (`one_div_le_lbCost`, `lemma3_ratio_ge`), and the ratio identity `lemma3_ratio_eq` shows that this bound is attained when the load balancing ratio is attained. The paper writes "`X = (1 + Y)/2`" with `X` the load balancing goal and `Y` the search goal; by Proposition 3 it is `Y = (1 + X)/2` (the letters are swapped, a typo). -/ namespace
