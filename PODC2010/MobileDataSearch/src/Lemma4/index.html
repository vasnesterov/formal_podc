import Papers.PODC2010.MobileDataSearch.TwoRounds /-! # Lemma 4: the merging step of the paper's proof fails Bar-Noy, Cheilaris, Feng, Levin, *Finding mobile data under delay constraints with searching costs*, PODC 2010, Lemma 4. The paper merges the boxes of an instance `I_N` into four boxes `C_A, C_B, C_C, C_D` (`A = X ∩ X'`, `B = X' \ X`, `C = Y' \ Y`, `D = Y ∩ Y'` for `OPT_N = ⟨X, Y⟩`, `FRO_N = ⟨X', Y'⟩`) and claims that FRO on the merged instance `I_4` outputs `⟨{C_A, C_B}, {C_C, C_D}⟩`, hence `cost(FRO_4) ≥ cost(FRO_N)` and `cost(FRO_N)/cost(OPT_N) ≤ cost(FRO_4)/cost(OPT_4)`. FRO on `I_4` minimises over *all* prefixes of the ratio order of `I_4`, and these need not be prefixes of `I_N`, so FRO can do strictly better on `I_4`. Counterexample with `N = 5` (boxes in strict ratio order `8 > 1 > 6/7 > 5/6 > 1/4`): `p = (8, 1, 6, 5, 1)`, `w = (1, 1, 7, 6, 4)`. `FRO_N = ⟨{0,1}, {2,3,4}⟩` with cost `246`, `OPT_N = ⟨{0,3}, {1,2,4}⟩` with cost `243`; `A = {0}`, `B = {1}`, `C = {3}`, `D = {2,4}`; the merged instance `p = (8, 1, 5, 7)`, `w = (1, 1, 6, 11)` (already in strict ratio order) has `FRO_4 = ⟨{C_A,C_B,C_C}, {C_D}⟩` with cost `245 < 246`, and `OPT_4` costs `243`.
