import Mathlib /-! # Searching for a token in `N` locked boxes in `D` rounds: the model Bar-Noy, Cheilaris, Feng, Levin, *Finding mobile data under delay constraints with searching costs*, PODC 2010, Section 2. A token is in box `i` with probability `p i`; unlocking box `i` costs `w i`. A search strategy for `D` rounds is an ordered partition `⟨A₁, …, A_D⟩` of the boxes; we represent it as the map `A : Fin n → Fin D` sending each box to the round in which it is unlocked (empty rounds are allowed, see `differencies.md`). If the token is in box `i`, the searcher pays for all boxes unlocked in rounds `≤ A i`; `cost` is the expected payment. Algorithm FRO ("follow ratio order") assumes the boxes are indexed in non-increasing order of `p i / w i` (`RatioSorted`, stated without division) and returns a minimum-cost strategy among those that *respect* this order, i.e. among monotone maps `Fin n → Fin D` (`IsFRO`). Ties in the ratio order are resolved by the indexing, so a statement "for every `RatioSorted` instance and every `IsFRO` strategy" covers every tie-breaking (an adversarial one in particular). -/
