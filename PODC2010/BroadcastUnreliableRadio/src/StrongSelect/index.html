import Papers.PODC2010.BroadcastUnreliableRadio.Model /-! # The strong select algorithm (Section 5 of the paper): model and schedule Kuhn, Lynch, Newport, Oshman, Richa. *Broadcasting in Unreliable Radio Networks.* PODC 2010. Section 5 works in the weakest setting of the paper: a **directed** dual graph `(G, G')` (`DualGraph V`), **collision rule CR4** (a node reached by exactly one message receives it, a node reached by two or more messages receives an arbitrary one of them or nothing; no collision detection) and **asynchronous start** (a node is inactive, and silent, until it first receives the broadcast message). Nodes have access to a global round counter (footnote 1 of the paper: w.l.o.g., since the round number can be piggy-backed on the broadcast message). ## Strongly selective families (Definition 6) `StronglySelective F ℓ k`: the sequence of sets `F 0, …, F (ℓ - 1)` is `(n, k)`-strongly selective, i.e. every element `z` of every `Z` with `|Z| ≤ k` is *isolated* by some `F j`: `Z ∩ F j = {z}`. We identify the id set `[n]` with the node set `V` (the placement of processes on nodes is an arbitrary bijection, and all statements below quantify over all networks; so a family of id sets is transported to a family of node sets along the placement). ## The algorithm Parameters (`StrongSelect V`): `smax ≥ 1`, the log factor `f`, and families `F s` for `s = 1, …, smax`. Family `F s` consists of **exactly** `ℓ s = 4 ^ s * f` sets `F s 0, …, F s (ℓ s - 1)` (the paper has `ℓ_s ≤ k_s² f(n)` with `k_s = 2 ^ s`; a smaller family is padded by repeating sets, which keeps it strongly selective, and the exact size is needed for `ℓ'_s = 2 ℓ'_{s-1}` in the proof of Theorem 10). Rounds are numbered `1, 2, …` and divided into epochs of `L = 2 ^ smax - 1` rounds. Round `r` has (0-based) position `pos r = (r - 1) % L` in epoch `epoch r = (r - 1) / L`. The positions `2 ^ (s - 1) - 1, …, 2 ^ s - 2` of every epoch are dedicated to `F s` (`fam r = s`); they use the sets of `F s` cyclically: the `slot r`-th use of `F s` overall (counted from 0) uses the set `F s (idx r)` with `idx r = slot r % ℓ s`, in the iteration `iter r = slot r / ℓ s` of `F s`. This is the paper's formula `F_{⌊log r⌋+1}[((e - 2) 2^{⌊log r⌋} + r) mod ℓ + 1]` with 0-based indices. Iteration `m` of `F s` occupies exactly the rounds `m ℓ'_s + 1, …, (m + 1) ℓ'_s` with `ℓ'_s = 2 ^ (s + 1) f L = ℓ_s L / 2 ^ (s - 1)` (`exists_round`). A node informed (for the first time) at the end of round `t` participates, for every `s`, in exactly one iteration of `F s`: the first iteration that starts after round `t` (the source, informed "at the end of round 0", participates in iteration `0`). A participant of iteration `m` of `F s` sends in round `r` of that iteration iff it belongs to `F s (idx r)`. Strong select is oblivious, so sending only depends on the id, on the round and on the time the node got the message. Only informed nodes send, so every message is the broadcast message. ## Executions (`Execution`) An execution is described abstractly by the sets `inf t` of nodes holding the message at the end of round `t` (`inf 0 = {src}`, monotone). The senders of round `r` are computed from `inf` by the rules above (`Sends`). The **only** progress guarantee is: if exactly one node `u` sends in round `r`, then every `G`-out-neighbour of `u` holds the message at the end of round `r` (it is reached by `u`'s message and by no other message, so it receives it under CR4 — or it is `u` itself or another node that already has the message). Any additional informing is allowed: the adversary may deliver messages over `G'`-links, and CR4 may resolve collisions to a message. Every CR4 execution of strong select with asynchronous start yields such an `inf`, so bounds proved for all `Execution`s are at least as strong as the paper's claim. -/ namespace
