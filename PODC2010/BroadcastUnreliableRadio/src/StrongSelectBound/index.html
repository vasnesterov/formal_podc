Densities are handled by cross-multiplication: with `ρ = 1 / D`, `D = 12 f 2 ^ smax` (an integer), `den(1, t) < ρ` becomes `#inf t * D < t`. **Repair of the density argument.** The paper lets `T` be the least round with `den(1, T) < ρ`, where `den` counts nodes receiving the message *for the first time* in an interval. If the source is not counted, then `T = 1` whenever nobody receives the message in round 1 (e.g. the source's id is not in `F_1[1]`), and the first claim of the proof of Theorem 10 ("every node receives the message by the end of round `T`") is false; the last step of the proof (the node `u` must have got the message in `[T - 1/ρ + 1, T]`, contradicting Lemma 9) fails exactly when `u` is the source. We count the source as a first-time receiver of round 1, i.e. `den(1, t) = #inf t / t` where `inf t` (which contains the source) is the set of nodes holding the message after round `t`.
