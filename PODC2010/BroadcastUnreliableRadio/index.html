Broadcasting in Unreliable Radio Networks — PODC 2010

Fabian Kuhn, Nancy Lynch, Calvin Newport, Rotem Oshman, Andrea Richa. Broadcasting in Unreliable Radio Networks. PODC 2010. DOI 10.1145/1835698.1835779. Formalized version: the full version, MIT-CSAIL-TR-2010-029 (June 2010); numbering follows it. Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. Theorems 2 and 4 (bounds for 2-broadcastable networks), Theorem 12 (the Ω(n log n) deterministic lower bound for undirected networks) and Theorem 10 (strong select broadcasts in O(n^{3/2} √log n) rounds), with Lemmas 8 and 9, are true as stated; the existence of small strongly selective families (Theorem 7, cited from [14]) is taken as a hypothesis. The wrong steps in the proofs are closed by local changes: the case analysis of Claim 13 (Theorem 12) misses some senders, the density argument of Theorem 10 breaks down at the source, and Claim 5 (Theorem 4) miscounts. The randomized O(n log² n) algorithm was not checked.

Mistakes in the paper

✏️ Slips

  • "The algorithm terminates by T" (Section 5, end of the proof of Theorem 10): only delivery by T is shown, which is what the proof targets.

  • The proof of Theorem 10 needs SSFs of exact size 4^s f (pad by repetition) for ℓ'_s = 2ℓ'_{s−1}. The round-robin family F_{s_max} needs 4^{s_max} f ≥ n.

Typos

  • Theorem 12 says each stage adds at least log(n−1) − 2 rounds. Counting the isolated round that starts the stage, it adds at least log(n−1) − 1; we prove the resulting stronger bound.

  • Theorem 12's proof assigns the new pair to L_k; it should be L_{k+1}.

  • In Claim 13 Part 1, the cases are called "1, 2(a), 2(b)" instead of I/II/III, and the bound ends with n/2^{ℓ+2} instead of (n−1)/2^{ℓ+2}.

  • In Lemma 8's proof, den(1,T') should be den(1,T'−1), and the display writes den(T,T') for den(T',T). 2ℓ'_1 = 8f(2^{s_max} − 1), not 8f√(n/log n).

Proof gaps in true statements (3)Theorem 10 · Theorem 12 · Theorem 4

🔧 Theorem 10 (the threshold round T)

The proof claims that every node has the message by round T, the first round with den(1,T) < ρ, but den ignores the source: if the source is not in F_1[1], then den(1,1) = 0, T = 1, and the claim fails (paper_T_claim_fails).

Impact. The theorem stands: counting the source fixes the proof, with the paper's constants (Execution.theorem10).

Details

den counts nodes that get the message for the first time. If the source's identifier is not in the first set F_1[1], nobody sends in round 1.

  • The proof's final contradiction ("u received the message for the first time in [T − 1/ρ + 1, T], contradicting Lemma 9") also fails when the uninformed node's neighbour u is the source.

  • Lemma 8's count P ≤ R misses the source when T − 6ℓ'_s < 1.

  • The Lean illustration uses a 3-node directed path with s_max = f = 1, below the paper's parameter range. The same failure occurs for every n and s_max in the paper's range: the order of the sets of F_1 is arbitrary, and some set of an (n, 2)-SSF misses the source.

  • The wrong claim sits inside the proof of Theorem 10 (and in the roadmap sentence "we will eventually show that the algorithm terminates no later than round T"). Theorem 10 itself is true. Lemmas 8 and 9 also stay true with the paper's T (in Lemma 8, P ≤ R + 1 ≤ k_s suffices); we prove them for the repaired T, which the repaired proof uses.

Repair

Count the source as receiving the message in round 1, i.e. use |inf t| / t as the density. Then T > 1/ρ, and Lemmas 8, 9 and the theorem go through with the paper's constants and the bound X = n/ρ. (paper_T_claim_fails, Execution.lemma8, Execution.lemma9, Execution.theorem10)

🔧 Theorem 12 (Claim 13, Case III)

Subcases IIIa and IIIb of Claim 13 overlook senders: they ignore the processes removed from the candidate set in earlier steps, which may well send in round ℓ + 1.

Impact. The theorem stands; Part 2 of P(ℓ+1) holds by a uniform argument that replaces the two subcases (Algorithm.claim_13, theorem_12).

Details

Subcase IIIa asserts that no process outside A_k ∪ {i₁, i₁'} sends in round ℓ + 1. Subcase IIIb asserts that the only such sender is n₁. Both ignore the processes removed from the candidate set in earlier steps, for instance the two N-processes dropped in a Case I step. N_{ℓ+1} only looks at the current candidates C_ℓ, and the removed processes may well send.

Repair

Every process outside both candidate pairs is in the same state in both executions. In Case III no member of either pair sends. So the two executions have the same set of senders, disjoint from both pairs, and every process in both or neither pair receives the same value. This replaces Subcases IIIa/IIIb. (Algorithm.claim_13, theorem_12)

🔧 Theorem 4 (Claim 5)

Claim 5's proof sums over sets of exactly n − 2 − k elements, while the sets I_k only have at least that many, so the probabilities need not sum to 1.

Impact. The theorem stands; the bound is proved directly (theorem_4).

Repair

Count over all outcomes: for every outcome, at most k of the n − 2 placements succeed; then integrate.

The formalizationmodel, Lean names of the results, trust

Model.

  • Lower bounds (Sections 4, 6), Model.lean.

    • Synchronous rounds with synchronous start and collision rule CR1. A process receives ⊥, ⊤ (two or more messages, its own included) or the message.

    • Deterministic algorithms are arbitrary automata indexed by identifiers; any finite identifier set of size n is allowed. The broadcast message is a black box and is not part of the state.

    • The adversary places processes on nodes (π : V ≃ I) and, each round, chooses for every message a reach set between the G- and the G'-out-neighbourhood. It may depend on the round and the set of senders, which for deterministic algorithms is as strong as history-dependence.

    • A process is informed once it receives a message from an informed process. This over-approximates "the message arrives", so the lower bounds are, if anything, stronger.

    • Theorem 4: a randomized algorithm is a probability measure over random choices ω with a deterministic algorithm A ω. This covers private coins, and also shared randomness. The adversary only picks the placement and then follows the fixed rules of Theorem 2. "Success with probability q" means the success event contains a measurable event of probability ≥ q.

  • Upper bound (Section 5), StrongSelect.lean.

    • Directed dual graph, CR4, asynchronous start, global round counter.

    • An execution is any monotone sequence of informed sets starting from the source. The senders of each round are computed from the sequence by the strong-select schedule.

    • The only progress guarantee is that a node sending alone informs all its G-out-neighbours. Every CR4 execution is such a sequence, so the bound covers all adversaries.

    • Parameters s_max ≥ 1, f ≥ 1, families of exactly 4^s f sets.

    • The existence of small strongly selective families (Theorem 7, [14]) is a hypothesis.

Theorem 12 is proved for n − 1 a power of two (≥ 4), as in the paper's proof. Our version is stronger than the paper's: every algorithm has an execution in which some process is still uninformed after that many rounds.

  • Theorem 11: the Ω(n^{3/2}) bound for directed networks, adapted from [9].

  • Section 7: the randomized O(n log² n) algorithm.

  • That strong select stops sending.

  • Theorem 7 (small strongly selective families, cited from [14]): taken as a hypothesis.

  • Theorem 12 for n with n − 1 not a power of two: the paper assumes it "for simplicity", and the padding argument is neither in the paper nor here.

  • Non-vacuity:

    • the bridge network is shown 2-broadcastable (bridgeNet_broadcastable);
