import Papers.PODC2010.BayesianIgnorance.UpperBounds /-! # Lemma 3.5: the reduction from online Steiner tree Alon, Emek, Feldman, Tennenholtz, *Bayesian Ignorance* (PODC 2010), Lemma 3.5: there are `Θ(n)`-agent Bayesian NCS games on undirected `n`-vertex graphs with `opt^P(G) / opt^C(G) = Ω(log n)`. The paper reduces from (a distributional version of) the online Steiner tree problem: for every distribution `q` over request sequences `σ = ⟨v_1, …, v_{|σ|}⟩` (to be connected to a root `v₀`) it builds an `n`-agent Bayesian NCS game `G^q` (agent `i` has type `(v_i, v₀)`, or `(v₀, v₀)` if `i > |σ|`) and turns every strategy profile `s` into a deterministic online algorithm `ALG_q` (at step `i` buy the edges of `s_i(v_i, v₀)` not bought before) with `E_q[ALG_q] ≤ K(s)`, while `opt^C(G^q) = E_q[OPT]`. Hence `opt^P(G^q)/opt^C(G^q) ≥ E_q[ALG]/E_q[OPT]` for some deterministic online algorithm, and a distribution `q` on which every deterministic online algorithm pays `Ω(log n) · E_q[OPT]` (the Imase–Waxman lower bound on the diamond graph, made distributional via Yao's principle) gives the lemma. We formalize the reduction (`exists_onlineAlg`, `optC_le_expected_opt`, `lemma_3_5`) for an arbitrary network; the online lower bound of Imase–Waxman is **not** formalized and enters `lemma_3_5` as the hypothesis `hLB`. Request sequences of length `≤ n` are represented as `σ : Fin n → Option V` (`σ i = some v`: the `i`-th request is `v`; `none`: no request at step `i`), a harmless generalization of `V^{≤ n}`. -/ open
