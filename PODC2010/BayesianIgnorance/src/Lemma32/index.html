The construction uses the affine plane of prime order `q` over `ZMod q`: points `ZMod q × ZMod q`, lines `y = a x + b` (`Sum.inl (a, b)`) and `x = c` (`Sum.inr c`). The directed graph has a source `u`, a vertex `v ℓ` per line and a vertex `w p` per point, edges `(u, v ℓ)` of cost `1` and `(v ℓ, w p)` (`p ∈ ℓ`) of cost `0`. There are `k = q + 1` agents (`Option (ZMod q)`, `none` being agent `k`). The prior is uniform over pairs `(ℓ, π)` of a line and a permutation of `ZMod q`; under `(ℓ, π)` every agent has source `u`, agent `r` has destination `w` of the `π(r)`-th point of `ℓ`, and agent
