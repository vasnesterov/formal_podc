Every invocation of a thread starts at line 21; a failed validation restarts it (`start`). Nodes are natural numbers; a node is allocated iff it is `< cnt`, and `alloc(E)` returns the fresh node `cnt` (memory is never reclaimed). The initialized state (Section 4: the state produced by `init()`) has the tail node `0` (allocated first) and the head node `1`. A null-pointer dereference sends the thread to the local state `err` (the paper's `σ_error`); memory safety is the statement that `err` is never reached.
