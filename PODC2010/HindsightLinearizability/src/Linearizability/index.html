import Papers.PODC2010.HindsightLinearizability.History /-! # Theorem 7.5: linearizability of the set algorithm The proof follows the paper. The function `ι` of the paper maps an `add`/`remove` to the source state of its (successful) atomic section and a `contains` to a state between its invocation and response in which the link `p.n ↦ c` it last crossed was a backbone link (found by hindsight). The sequential history orders the operations by `ι`, a `contains` before the `add`/`remove` associated with the same state. Here this is the generic criterion `Cslib.SharedMemory.exists_isLinearization_of_points` (staged in `Podc/`), fed with * the abstract state `Abs (memAt α j)` of the `j`-th state (Section 7.2), * the effects `effAt α n` (successful atomic sections of `add`/`remove`, Stage II case `add`/`remove`: `step_secOk`), * the retroactive linearization points of `contains` (Stage II case `contains`: `HistC`, which combines Lemma 6.3, the Hindsight/Backbone Lemma and the Local Window Lemma). -/ namespace Podc.HindsightLinearizability open Cslib.SharedMemory HeapState variable {P : Type} [DecidableEq P] lemma Abs_initMem : Abs initMem = ∅ := by have hbb : IsBB initMem [1, 0] := by obtain ⟨L, hL⟩ := memInv_init.bb refine ⟨rfl, rfl, by simp [HeapState.Link, Mem.hs, initMem], by simp [initMem], ?_⟩ intro u hu; simp only [initMem] at hu ⊢; simp; omega ext z rw [MemInv.IsBB.mem_Abs_iff memInv_init hbb] simp [initMem, fin] lemma memAt_zero (α : List (Label P setSpec)) : memAt α 0 = initMem := by simp [memAt, cfgAt, Impl.initCfg, impl] /-- **Lemma 7.4.** In every reachable state the abstraction function is the set of integer keys of the unmarked allocated nodes: `Abs(σ) = {u.k | u ∈ N_σ ∧ ¬u.m} \ {-∞, ∞}`.
