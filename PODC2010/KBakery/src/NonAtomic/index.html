import Mathlib /-! # Figure 3 (non-atomic reads and writes) violates k-exclusion We model the algorithm of Figure 3 of the paper (Figure 5.6 of the thesis) with **non-atomic** (Lamport-safe) single-writer registers, as the paper prescribes ("atomic (non-atomic) reads and writes of variables in this paper behave the same as reads and writes of multireader single-writer atomic (safe) registers"; "if a non-atomic read and write access the same variable concurrently, then the read returns an arbitrary value"). ## Model (a sub-model of the paper's, which suffices for a counterexample) * Every register (`Want[i][j][b]`, `Ticket[i]`, `Capture[i][j][b]`) holds a value in `ℕ ∪ {∞}`. * A write takes two steps of the writer: *begin* (the register becomes busy) and *end* (the new value is stored, the register is no longer busy). A read is one step: if the register is not busy it returns the stored value; if a write is in progress it returns an arbitrary value chosen by the adversary. (Every execution of this model is an execution of the interval model of safe registers: zero-length reads overlapping a write may return anything, the others return the last written value.) * A process reads its own `Ticket[p]` and `Capture[p][i][1]` (lines 30–33, 38, 41, 44, 45) without a separate step: it is the only writer and never reads them while writing them, so such reads always return the stored value. * The `foreach` loops visit indices in the order of a fixed list `ord` of all processes (the paper leaves the order unspecified, so this is one of the allowed implementations; the counterexample uses `ord = [0, 1, 2]`). * An execution is a list of events `(p, d)`: process `p` takes its next step; `d = some v` supplies the value of a read that overlaps a write (`none` otherwise). `exec` returns `none` on an ill-formed event, so `exec … = some s` certifies a legal execution. `counterexample` exhibits, for `N = 3` processes and `k = 1`, a legal execution ending with two processes in the critical section. **The flaw.** `Ticket` is a safe register, so a process choosing its ticket while another process `r` rewrites `Ticket[r]` may read `0`, choose a ticket smaller than an *old* capture value `Capture[r][p]` that `r` wrote in an earlier passage, and immediately detect a (stale) capture. -/ namespace Podc.KBakery.NonAtomic /-- Shared registers. -/ inductive Reg
