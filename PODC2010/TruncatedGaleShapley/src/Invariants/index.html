import Papers.PODC2010.TruncatedGaleShapley.Basic /-! # Invariants of the truncated Gale–Shapley algorithm The states `run I i`, `i ≥ 1`, satisfy the invariant `Inv`: the partner function is a matching, a matched red node is matched to the head of its candidate list, an unmatched red node has an outstanding proposal to the head of its candidate list, and a blue node `b` removed from the list of a red node `r` is matched to a node it strictly prefers to `r`. `red_outcome` describes what happens to a red node in one round (unchanged, accepted, or one lost edge). -/ namespace
