port-numbering algorithm (inputs: colour and port ranking; output: the port of the partner, if any). * `toBicoloured`: the bicoloured graph with preferences defined by a simple port-numbered graph, a proper 2-colouring and port rankings. * `dec_localRun`: after `2i` communication rounds the decoded configuration is the state `run i` of the centralised algorithm (`Theorems.lean`). -/ namespace
