import Mathlib /-! # Purely probabilistic systems, probabilistic beliefs and probabilistic constraints Formalization of the model and the main results of > Y. Moses, N. Zamir. *Probably Approximately Knowing.* PODC 2020 (arXiv:2007.02984v1). A *purely probabilistic system* (pps, §2.1 of the paper) is a finite tree whose edges carry positive transition probabilities; its runs are the root-to-leaf paths. Every result of §§3–7 only uses the induced finite probability space on runs and the local states along the runs, so we abstract a pps to * a finite type `Ω` of runs with positive probabilities `μ` summing to `1`; * the length `len r` of each run (its points are `(r, t)` with `t ≤ len r`); * the local state `loc i r t` of every agent `i` at every point, with the synchrony assumption of §2.1 (every local state determines the current time, `PPS.sync`). Every tree pps of the paper yields such a structure, and conversely every such structure is the pps of a tree in which all randomness is resolved at the root (the environment's initial state determines the run). Facts are arbitrary sets of points (`Fact`), and an action of agent `i` is represented by the fact `does_i(α)` (`A : Fact Ω`). Main results: Theorem 6.2 (`PPS.theorem_6_2`), Theorem 4.2 (`PPS.theorem_4_2`), Lemma 4.3(a) (`PPS.lemma_4_3a`), Lemma 5.1 (`PPS.lemma_5_1`), Theorem 7.1 (`PPS.theorem_7_1`), Corollary 7.2
