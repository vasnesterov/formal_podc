import Cslib.Computability.Distributed.MessagePassing.Async import Mathlib.Data.List.FinRange /-! # Round-trip implementations of a multi-writer register (W1R2) The system model of §2 of Huang–Huang–Wei (PODC 2020): `n` servers `s₀, …, s_{n-1}` (`Fin n`), writers `W` and readers `R` (disjoint from the servers), communicating by asynchronous, reliable, unordered message passing (CSLib `Cslib.AsyncMP`); up to `t` servers may crash, so a client can only wait for `n - t` replies in each round-trip. Servers do not communicate with each other. A *round-trip* of a client: the client sends one message to every server; a server, upon receiving a message, processes it and replies immediately; the client collects the replies of the current round-trip and, once it has at least `n - t` of them (the scheduler decides exactly when, possibly after more replies arrived), it continues. A **W1R2 algorithm** (`W1R2Alg`) is an algorithm in which a write is one round-trip and a read is two round-trips. It is given by arbitrary deterministic functions: * servers: `reply s log c m` is the reply of server `s` to message `m` from client `c`, where `log` is the list of messages (with senders) that `s` processed before. Every deterministic server automaton is of this form (its state is a function of its log), so nothing is lost (this is also the paper's "full-info model" of §4.1); * writers (local state `LW` between operations): `wMsg w st v s` is the message sent to server `s` by `write(v)`, `wEnd` the new local state, computed from the replies; * readers (local state `LR`): `rMsg1 r st s` is the first-round message to `s`, `rMsg2 r st V₁ s` the second-round message (`V₁` = the replies of the first round, in arrival order), and `rEnd r st V₁ V₂` the returned value and the new local state. Views are lists of `(server, reply)` in arrival order, so readers may even use the arrival order. `W1R2Alg.protocol t v₀` is the induced `Cslib.AsyncMP.Protocol` implementing `register V v₀`. Messages carry the client's operation counter `k` and the round index `i` (`Pkt`), so that late replies of earlier round-trips are ignored. -/ namespace Podc.FastMWMR open Cslib.SharedMemory
