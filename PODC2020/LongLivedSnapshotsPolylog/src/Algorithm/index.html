It is a parameter; the correctness results hold for every `X`. * Every program counter performs exactly one base-object access (or returns); purely local computations (lines 13, 14, 19, 20, 23, 25, 27, 29) are folded into the continuations. `Collect(H)` reads `H[0], …, H[n-1]` one at a time. ### Reading of lines 23–25 Line 25 reads `else if c mod X = 0`: taken literally, it is executed already for `c = 0`, before the first collect of line 24, and line 27 then compares with an undefined `h₀`. The text (p. 5–6: "Otherwise, this is not the first collect …") shows the intent: the second collects happen at `c = 2X, 3X, …`.
