import Papers.PODC2020.LongLivedSnapshotsPolylog.Algorithm import Mathlib.Order.Basic import Mathlib.Data.List.Basic /-! # `ℓ`-bounded-increment executions (Definition 2.1) Definition 2.1 of the paper: an execution is `ℓ`-bounded-increment for a max register `M` if for each `WriteMax(v)` on `M` with `v > ℓ` there is a `WriteMax(v')` on `M` that precedes it with `v - ℓ ≤ v' < v`. All max registers of our models are atomic, so a `WriteMax` is one step and "precedes" is the order of the steps. The definition then only depends on the sequence `ws` of values written to `M`, in order (`BoundedIncr ℓ ws`). We show that it is equivalent to the local condition "every written value exceeds the maximum of the earlier ones (or `0`) by at most `ℓ`" (`boundedIncr_iff_stepBounded`); the direction `←` is the argument with `w*` at the end of the proof of Lemma 4.1. `wlogFrom I w C α` is the log of all writes performed along the execution `α` from `C`, where `w p l = some (k, v)` says that process `p` in local state `l` is about to write `v` to the max register with key `k`; `writesTo I w α k` is the sequence of values written to the register `k`. -/ namespace Podc.LongLivedSnapshotsPolylog open Cslib.SharedMemory /-- Maximum of a list of naturals (`0` for the empty list). -/ def lmax (ws : List ℕ) : ℕ := ws.foldr max 0 @[simp] lemma lmax_nil : lmax [] = 0 := rfl @[simp] lemma lmax_cons (a : ℕ) (ws : List ℕ) : lmax (a :: ws) = max a (lmax ws) := rfl lemma lmax_append (as bs : List ℕ) : lmax (as ++ bs) = max (lmax as) (lmax bs) := by induction as with | nil => simp | cons a as ih => simp [ih, max_assoc] lemma le_lmax {a : ℕ} {ws : List ℕ} (h : a ∈ ws) : a ≤ lmax ws := by induction ws with | nil => cases h | cons b ws ih => rcases List.mem_cons.1 h with rfl | h · simp · simp [ih h] lemma lmax_mem {ws : List ℕ} (h : 0 < lmax ws) : lmax ws ∈ ws := by induction ws with | nil => simp at h | cons b ws ih => simp only [lmax_cons] at h ⊢ rcases le_total b (lmax ws) with hb | hb · rw [max_eq_right hb] at h ⊢ exact List.mem_cons_of_mem _ (ih h) · rw [max_eq_left hb];
