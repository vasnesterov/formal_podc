import Papers.PODC2020.IntermediateValueLin.Canonical import Mathlib.Data.Fintype.List import Mathlib.MeasureTheory.Measure.Typeclasses.Probability import Mathlib.Order.ConditionallyCompleteLattice.Finset /-! # `(ε, δ)`-bounded objects and Theorem 1 (Section 4 of Rinberg–Keidar) Randomized algorithms. A randomized object is a family of deterministic objects indexed by the coin flip vector `c : Ω`; `Ω` carries a probability measure `μ`. * The sequential specification `{A(c)}` of a randomized object is a family `S : Ω → QSpec A.Op A.Resp` of deterministic sequential specifications (Section 2.2/3.3); the *ideal* specification `I : QSpec A.Op A.Resp` gives the exact quantity estimated. * A concurrent randomized algorithm is given by its executions under every coin flip vector, `E : Ω → List (Label P A) → Prop` (e.g. `E c = (impl c).Valid`). The paper's schedule `σ` fixes the order of all steps and invocations; under its uniform-step-complexity assumption the executions of a schedule under different coin flips differ only in the response values, so we identify the schedule with the common skeleton history `σ = α?`: the execution "`H(A, c, σ)`" is any `α` with `E c α` and `skel α = σ`. Definitions: * `SeqBounded` — **Definition 3**: every query of a sequential execution over- (under-) estimates the ideal value by more than `ε` with probability at most `δ/2`. * `RandIVL` — **Definition 2** (IVL for randomized algorithms): for every skeleton history `σ` there are two linearizations `L₁`, `L₂` of `σ`, common to all coin flip vectors, sandwiching every return value. * `vmin`, `vmax` — the paper's `v^I_min(H, Q)`, `v^I_max(H, Q)`: extreme ideal values of `Q` over all linearizations of the skeleton (`finite_isLinearization` shows they are attained). * `ConcBounded` — **Definition 4**. Main result: `theorem1` (**Theorem 1**): an IVL implementation of a sequential `(ε, δ)`-bounded object is a concurrent `(ε, δ)`-bounded object. Probabilities are measured with the outer measure `μ` (Lean's `μ s` is defined for every set), so no measurability of the events is needed; for measurable events this is the usual probability. The paper compares only queries; we compare all completed operations (the updates of the paper's objects return a fixed dummy value). -/ open Cslib.SharedMemory MeasureTheory open scoped ENNReal set_option linter.unusedSectionVars false namespace Podc.IntermediateValueLin /-! ### Finitely many linearizations -/ section Finite variable {P : Type} [DecidableEq P] {B : ObjSpec} lemma invoked_proc_mem {σ : List (Label P B)} {x : OpId P} (hx : Invoked σ x) : x.1 ∈ σ.map Label.proc := by by_contra h have : opsOf σ x.1 = [] := opsOf_eq_nil_of_proc_ne fun ℓ hℓ he => h (List.mem_map.2 ⟨ℓ, hℓ, he⟩) simp [Invoked, this] at hx lemma length_opsOf_le (σ : List (Label P B)) (p : P) : (opsOf σ p).length ≤ σ.length := List.length_filterMap_le _ _ /-- Two lists of entries with the same identities, each entry carrying the operation of its instance in `σ`, are equal. -/ lemma eq_of_map_fst_eq {σ : List (Label P B)} : ∀ {L L' : List (OpId P × B.Op)}, L.map Prod.fst = L'.map Prod.fst → (∀ y ∈ L, opOf σ y.1 = some y.2) → (∀ y ∈ L', opOf σ y.1 = some y.2) → L = L' | [], [], _, _, _ => rfl | [], _ :: _, h, _, _ => by simp at h | _ :: _, [], h, _, _ => by simp at h | y :: L, y' :: L', h, hL, hL' => by simp only [List.map_cons, List.cons.injEq] at h have h1 := hL y (by simp) have h2 := hL' y' (by simp) rw [h.1, h2] at h1 obtain ⟨a, o⟩ := y;
