The state is the `d × w` matrix of counters, initially `0`; `update a` increments `c[i][hᵢ(a)]` for every row `i` and returns the dummy response `0`; `query a` returns `min_i c[i][hᵢ(a)]` (`⨅ i, …`; for the degenerate `d = 0` this is `0`). * `cmIface E`: the interface object of the implementations (operations `CMOp E`, responses `ℕ`, one dummy state). All implementations `pcm h` share it, so their histories have the same type, whatever the hash functions. * `cell`: the base objects, one atomic counter per cell `(i, j) : Fin d × Fin w`, with the primitives `inc` (increment) and `read`. * `pcm h` (the paper's `PCM(c⃗)`): Algorithm 1 run concurrently. `update a` increments the cells `c[i][hᵢ(a)]` for `i = 0, …, d - 1`, one access each, then returns; `query a` reads the cells `c[i][hᵢ(a)]` one by one, keeping the running minimum, and returns it.
