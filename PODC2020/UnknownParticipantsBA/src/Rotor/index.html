import Papers.PODC2020.UnknownParticipantsBA.Model /-! # The rotor-coordinator (Algorithm 1 of the BA = Algorithm 2 of the full version) ``` 1: C_v ← ∅ ⊲ candidate coordinators (ordered by id) 2: S_v ← ∅ ⊲ selected coordinators 3: Broadcast init ⊲ Round 1 4: Broadcast echo(p) if received init from p ⊲ Round 2 5: for r ← 0 → ∞ do ⊲ Rounds 3 up to termination 6: B_v ← ∅ 7: Let n_v be the number of nodes that sent at least one message to v until round r 8: if received at least n_v/3 echo(p) and p ∉ C_v then B_v ← B_v ∪ {echo(p)} 11: if received at least 2n_v/3 echo(p) and p ∉ C_v then C_v ← C_v ∪ {p} 14: p ← C_v[r mod |C_v|] ⊲ select the next coordinator 15: Let p' be the coordinator selected in the previous round 16: if received opinion(x) from p' then accept x as the coordinator's opinion 19: if p ∈ S_v then break 22: S_v ← S_v ∪ {p} 23: if v = p then B_v ← B_v ∪ {opinion(o_v)} 27: Broadcast B_v if it is non-empty ``` The candidate-set mechanism (lines 1–13) is factored out as a *layer* (`Core`, `withRotor`) that is shared with the consensus algorithm; the rest (lines 14–27) is an `Ext`ension. The termination test of line 19 is a parameter `rule` of `rotorExt`: the paper's rule is `paperRule` (`p ∈ S_v`), our repaired rule is `fixedRule` (stop once `2r > n_v`).
