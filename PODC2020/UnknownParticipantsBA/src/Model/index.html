The set of existing nodes is `G ∪ F` (correct and faulty, disjoint and finite); neither `n = |G ∪ F|` nor `f = |F|` is known to the nodes — a protocol is a single state machine, parameterised by nothing but the node's own id and input; * in every round every correct node *broadcasts* a finite set of messages (to all nodes, including itself), computed from its state; * the receiver sees a finite set of pairs `(sender, message)` with the **true** sender id (a Byzantine node cannot forge its identifier when communicating directly); duplicates of the same message from the same sender in a round are discarded automatically (sets); * a faulty node `q` may send an arbitrary finite set of messages `adv s q v` to every node `v` in every round (different sets to different nodes, possibly none — so it may "get itself known to only a subset of the nodes"); messages may *mention* arbitrary, even non-existent identifiers. `run A E s v` is the state of node `v` after `s` steps; step `s + 1` consumes the messages broadcast at the end of step `s` (by correct nodes: `A.out (run A E s q)`; by faulty nodes: `E.adv s q v`).
