Everybody echoes `1`; nodes `3, 4, 5` echo `0`. Node `2` does not broadcast an opinion (it selected `1`, not itself). Iteration `r = 1`: the others add `1` (5 echoes) and select `C[1] = 2` again; node `2` gets `5` copies of `echo(0)` (from `3, 4, 5, 0, 1`), adds `0`, and selects `C_2[1] = 1` again: inserting a *smaller* identifier shifted the indices. All correct nodes have reselected their coordinator and `break`. No good round ever happened, and no correct node ever accepted any opinion.
