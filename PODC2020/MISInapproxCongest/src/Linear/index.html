In the paper `P = A = [ℓ + α]`, `K = Σ^α` and `c` is the Reed–Solomon code of Theorem 4. Nodes are `Node t K P A = Fin t × (K ⊕ P × A)`: `(i, inl m)` is `v^i_m ∈ A^i`, `(i, inr (h, r))` is `σ^i_{(h,r)} ∈ C^i_h`.
