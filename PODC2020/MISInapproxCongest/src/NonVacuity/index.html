The algorithm is full-information flooding: a node's state is a finite set of *facts* (weights `(a, w a)` and edges `(a, b)`); every round it sends all of them to every neighbour, merges what it receives, and records the edges to the neighbours it heard from. After `|V|` rounds every node knows exactly the weights and edges of its connected component and outputs its membership in a canonical maximum-weight independent set of that component. -/ namespace
