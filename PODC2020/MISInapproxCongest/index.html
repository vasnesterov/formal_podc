Beyond Alice and Bob: MaxIS inapproximability in CONGEST — PODC 2020

Yuval Efron, Ofer Grossman, Seri Khoury. Beyond Alice and Bob: Improved Inapproximability for Maximum Independent Set in CONGEST. PODC 2020. DOI 10.1145/3382734.3405702. Formalized version: arXiv 2003.07427 v2; numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. Theorems 1 and 2 hold, conditional on the Chakrabarti–Khot–Sun communication lower bound as in the paper, but the paper's proof miscounts the cut, which has Θ(log³ k) edges, not Θ(log² k), and so only gives Ω(n/log⁴ n) and Ω(n²/log⁴ n). Saving them takes a redesigned ingredient: a code over a constant-size alphabet in the same construction, which even improves the bounds to Ω(n/log² n) and Ω(n²/log² n) rounds. The t-party framework (Theorem 5, Corollary 1) and the combinatorial heart of the paper (Properties 1–3, Claims 1–7, Corollary 2, Lemmas 1–3) are correct.

Mistakes in the paper

✏️ Slips

  • Definition 5 reads w(I) ≥ OPT/γ; it should be w(I) ≥ γ·OPT (IsApprox). As written, no (1/2+ε)-approximation could exist.

  • Corollary 1 needs a strict gap: with Definition 6 a γ-approximation may output weight exactly γβ in both cases, so it does not decide the gap predicate. We require hi < γ·lo, and since Lemmas 2 and 3 hold for every ε, one uses ε/2 (corollary1).

Typos

  • In the proof of Claim 6 the weight is written t(4ℓ+α) instead of 4tℓ + 2tα.

  • The proof of Lemma 3 has a sign error (4t log k − 2t log k/log log k), drops a factor t in 2αt, and drops the constants of Claim 7 (t² for 3t³). Its bounds ≥ 4(t−1) log k and ≤ 3(t+2) log k still hold for k ≫ t.

  • Step (4) of Claim 4 sums 2ψ over i ≠ j ∈ [t], but step (6) counts unordered pairs.

Proof gaps in true statements (2)Theorems 1 and 2 · Lemma 3

🛠️ Theorems 1 and 2 (the cut is miscounted)

The proofs use |cut(G_x̄)| = t² log² k, but the construction of Section 4 has Θ(t² log³ k) cut edges, so the argument as written only gives Ω(n/log⁴ n) and Ω(n²/log⁴ n) rounds (paper_cut_edges).

Impact. Both theorems are true: the same construction with a constant-size alphabet proves them, and even improves the bounds to Ω(n/log² n) and Ω(n²/log² n) (theorem1, theorem2).

Details

C^i_h and C^j_h are joined by a complete bipartite graph minus a perfect matching. That is (ℓ+α)(ℓ+α−1) edges for each of the ℓ+α positions h and each pair i<j. So the cut has exactly (t choose 2)·q²(q−1) edges, q = ℓ+α ≈ log k, which is Θ(t² log³ k). Corollary 1 then gives only Ω(k/(log³ k · log n)) = Ω(n/log⁴ n) (resp. Ω(n²/log⁴ n)). Changing ℓ, α does not help: with Reed–Solomon codes the alphabet has size at least the code length, and the cut is at least (log k/log log k)³.

Repair

The construction never needs the alphabet to be as large as the code length. Take a code over an alphabet of constant size Q = 4^D (D ≈ 2t/ε), with length M = log₂ k and pairwise agreement ≤ M/D; such a code exists by Gilbert–Varshamov. Give heavy nodes weight M. All claims go through with the same proofs, and the cut has t(t−1)/2 · M · Q(Q−1) = O(log n) edges. Corollary 1 then gives T·B·log n = Ω(n) (resp. Ω(n²)), so T = Ω(n/log² n) (resp. Ω(n²/log² n)) for B = O(log n). This implies the paper's claims. (theorem1, theorem2)

🔧 Lemma 3 (the choice of t)

The proof of Lemma 3 picks t = 3/(4ε) − 1, which is too small: for ε = 1/8 and t = 5 the gap ratio between Claims 6 and 7 is 0.9 > 0.875 (= 3/4 + ε).

Impact. Statement true; any t ≥ 3/(2ε) + 3 works (lemma3, lemma3_paper).

Details

The gap between Claims 6 and 7 has leading terms 3(t+1)ℓ versus 4tℓ, with ratio 3/4 + 3/(4t). For t = 3/(4ε) − 1 this ratio exceeds 3/4 + ε. With the paper's own simplified bounds 3(t+2) vs 4(t−1) it is even 21/16 > 1 at ε = 1/8.

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous CONGEST (CSLib Cslib.Congest.Algorithm). The node set V is fixed and its names are the IDs. In each round a node sends B bits on every edge and direction. A node's input is its weight; randomized algorithms also give each node a private uniform random string. The output is one bit per node: membership in the independent set.

  • ApproxMIS A γ T ε: on every graph with node set V and weights in {0,…,n}, after T rounds the output is an independent set of weight ≥ γ·OPT with probability ≥ 1−ε. Weights must be bounded: with unbounded weights no algorithm with bounded T·B could exist, and the theorems would be vacuous. The paper's instances have O(log n)-bit weights.

  • Multi-party communication is the number-in-hand blackboard model (Definition 1). Protocols are trees in which the designated player writes one of m symbols, costing ⌈log₂ m⌉ bits. Randomized protocols have private coins. Promise pairwise disjointness uses the Chakrabarti–Khot–Sun promise: pairwise disjoint, or uniquely intersecting.

  • Hypothesis. The CKS bound (Theorem 3) is assumed as PPDLowerBound c. It says that every private-coin protocol with error ≤ 1/3 and nonempty coin spaces writes at least c·k/(t log₂ t) bits. This is implied by CKS (public-coin, binary). Everything else is proved.

  • The lower bounds are for infinitely many n, namely the sizes of the families. They hold against algorithms that may depend on V.

NonVacuity.lean

theorem1: for every ε > 0 there is C > 0 such that for infinitely many n there is a node set V of size n such that every randomized algorithm satisfying ApproxMIS A (1/2+ε) T (1/3) has C·n ≤ T·B·log n. theorem2 is the same with 3/4+ε and C·n² ≤ T·B·log n. The generic claims (claim5_generic, claim7_generic, card_code_le) hold for any code with pairwise agreement ≤ a. They serve both the paper's Reed–Solomon parameters and the repaired constant-alphabet instance. The base cases of Claims 2 and 5 use ℓ ≥ 1 and the inductive step of Claim 5 uses α ≥ 1; both are implicit in ℓ ≫ α ≥ 1, and the paper fixes k, α, ℓ as positive integers.

Theorem 4 (cited) is stated for arbitrary alphabets, but Reed–Solomon codes need a field, and the paper takes Σ = [ℓ+α] of arbitrary size. We prove Theorem 4 for prime q (theorem4). That is enough, since ℓ+α can be chosen prime. We neither prove nor refute the statement for other q.

Not formalized. The CKS lower bound itself; Remark 1 (unweighted graphs); constant diameter of the hard instances; Theorem 4 for non-prime alphabet sizes; the paper's real-valued parameter choice ℓ = log k − log k/log log k (we use integer q, α).

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity: exists_approxMIS builds, for every finite V, a full-information flooding algorithm that outputs an exact maximum-weight independent set on every graph on V with weights ≤ |V|, so the hypothesis ApproxMIS of Theorems 1–2 is satisfiable. The CONGEST model comes from CSLib (Cslib.Computability.Distributed.Congest.LowerBound). The multi-party framework is new (Podc/, CSLib candidate).
