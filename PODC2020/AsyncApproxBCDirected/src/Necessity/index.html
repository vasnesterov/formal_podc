import Cslib.Computability.Distributed.ApproxConsensus.Async.Replay import Papers.PODC2020.AsyncApproxBCDirected.Graph /-! # Necessity of 3-reach (Theorem 18, Appendix B) If `G` violates 3-reach, no algorithm solves asynchronous Byzantine approximate consensus on `G` (`threeReach_of_solves`). Proof (the paper's indistinguishability argument, made precise). Let `F, Fu, Fv, u, v` witness the failure of 3-reach and put `Rv = reach_v(F ∪ Fv)`, `Ru = reach_u(F ∪ Fu)` (disjoint). Every in-neighbour of `Rv` outside `Rv` lies in `F ∪ Fv`. * `e₁`: `Fv` Byzantine and silent, all inputs `0`, round-robin delivery (fair). By termination and validity, `v` decides `0` at some time `T₁`. * `e₂`: `Fu` Byzantine and silent, all inputs `2ε`; `u` decides `2ε` at time `T₂`. * `e₃`: `F` Byzantine; inputs `0` on `Rv` and `2ε` on `Ru`. First replay the first `T₁` events of `e₁` restricted to deliveries into `Rv` (messages from `F` are injected by the Byzantine nodes, messages from `Fv` are delayed), then the first `T₂` events of `e₂` restricted to `Ru`. Then `v` decided `0` and `u` decided `2ε`, violating convergence. The replay is the library lemma `exists_replay₂` (`Cslib/Computability/Distributed/ApproxConsensus/Async/Replay.lean`). The paper uses inputs `0` and `ε`; with the non-strict reading of "within `ε`" of Definition 1 this gives no contradiction, so we use `2ε`. More generally (`threeReach_of_solvesOn`), any two admissible inputs `a, b` with `b − a > ε` work; this covers the setting of Section 4.6 where the inputs are known to lie in `[0, K]` (with `K > ε`; for `K ≤ ε` the problem is trivial). -/ open Finset set_option linter.unusedSectionVars false namespace AsyncApproxBCDirected open Cslib.ApproxConsensus Cslib.ApproxConsensus.Async variable {V M S : Type*} [DecidableEq V] {A : Algorithm V M S} {G : Digraph V} [DecidableRel G.Adj] /-- **Theorem 18** (necessity of 3-reach), for any input range containing two values more than `ε` apart: if some algorithm solves asynchronous approximate Byzantine consensus on `G` with up to `f` faults for inputs in `I`, then `G` satisfies 3-reach. -/ theorem threeReach_of_solvesOn [Fintype V] {f : ℕ} {ε : ℝ} {I : Set ℝ} {a b : ℝ} (ha : a ∈ I) (hb : b ∈ I) (hab : ε < b - a) (hA : SolvesOn I A G f ε) : ThreeReach G f := by classical intro F Fu Fv u v hF hFu hFv hu hv by_contra hcon push Not at hcon set Rv : Finset V := univ.filter fun w => Reaches G (F ∪ Fv) w v set Ru : Finset V := univ.filter fun w => Reaches G (F ∪ Fu) w u have hdis : Disjoint Rv Ru := disjoint_left.mpr fun w h1 h2 => by simp only [Rv, Ru, mem_filter, mem_univ, true_and] at h1 h2;
