import Mathlib /-! # Algorithm 3 (Filter-and-Average) A node `v` holds a finite set `Mv` of messages `(value, propagation path)`. It sorts them by value (ties in any order), removes the longest prefix `O^lo` and the longest suffix `O^hi` that admit an `f`-cover (a set of at most `f` nodes meeting every path), and outputs the midpoint of the minimum and the maximum of the remaining values. Corrections w.r.t. the paper: * line 5 of Algorithm 3 reads `(max − min)/2`; it must be `(max + min)/2` (`IsFA`); * covers never contain the node `v` itself (`CoverFor`): every path of a message received by `v` ends at `v`, so the cover `{v}` would trim everything when `f ≥ 1`. `IsFA.props` extracts the four facts used by the correctness proof (Lemma 15, Theorem 16): the minimum `a` of the trimmed vector is at most the value of every message avoiding the cover of `O^lo`; the maximum `b` is at least the value of every message avoiding the cover of `O^hi`; and `a, b` lie between any bounds that hold for all messages avoiding some `f`-set not containing `v`. `IsFA.exists`: the output is well defined as soon as `v` holds its own message (path `[v]`). -/ open Finset set_option
