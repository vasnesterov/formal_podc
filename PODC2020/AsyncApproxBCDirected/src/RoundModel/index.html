import Papers.PODC2020.AsyncApproxBCDirected.Graph import Papers.PODC2020.AsyncApproxBCDirected.FilterAverage /-! # One asynchronous round of Algorithm BW: model We model one asynchronous round `r` of Algorithm BW (Algorithm 1) at the level of the information received by the correct nodes over (global, unobservable) time `t : ℕ`. **Communication layer (hypotheses).** The two flooding primitives of the paper are not implemented message by message; instead `RoundExec` records what every correct node has received by time `t` and assumes exactly the guarantees that RedundantFlood (Appendix E) and FIFO-Flood / FIFO-Receive (Appendix F) provide on reliable asynchronous links against Byzantine nodes: * `M v t` — the value messages `(x, p)` received by `v` by time `t` (the path `p` ends at `v`); `acc p` is the value that the terminal node of `p` accepted (received first) on path `p`. A correct relay forwards its accepted value on every redundant extension (`M_live`, `acc_snoc`), only after accepting it (`M_src`); a message whose last hop is correct carries the accepted value (`M_honest`); a node knows its own value (`acc_self`, `M_live_self`). Byzantine nodes may send anything, any number of times. * `CR v t` — the `COMPLETE` messages `(c, p, M^c, F')` FIFO-received by `v` through the path `p` from the initiator `c`, by time `t`. Along a path of correct nodes they are genuine (`CR_honest`), arrive in the sending order of `c` (per-path FIFO, `CR_fifo`; `idx` is the FIFO counter of `c`) and eventually arrive (`CR_live`). **Protocol logic (definitions).** Everything the algorithm *decides* is defined from these data: Maximal-Consistency (line 10, `MCAt`, `mcTime`, `mcMsg`), the `COMPLETE` messages sent (`Sent`), the FIFO-Receive-All condition (line 12, `FIFORecAll`), `Completeness` (Algorithm 2), `Verify` (lines 20–26), the first verified thread (`Executes`, lines 14–18) and the new value (`Output`, Algorithm 3).
