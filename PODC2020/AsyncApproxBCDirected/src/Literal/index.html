Then `{v}` is an `f`-cover of every set of messages held by `v` (as soon as `f ≥ 1`), and * `Completeness(Mv, M^c, Fu)` (Algorithm 2) is **never** satisfied: choose `Fw` with `v ∈ Fu ∪ Fw`, so that `v ∉ S_{Fu,Fw}` and `H = {v} ⊆ V \ S_{Fu,Fw}` (`not_completenessLit`); * hence `Verify` (lines 20–26) never holds in any thread, because FIFO-Receive-All includes `v`'s own `COMPLETE(Fv)` (`never_verifyLit`): no correct node ever executes Filter-and-Average, contradicting Theorem 9; * Filter-and-Average trims the whole vector (`not_isFALit`). The intended reading (used in the rest of the formalization) never puts `v` in a cover. 2. **`(max − min)/2`.** Line 5 of Algorithm 3 sets `x_v[r+1] = (max O' − min O')/2`.
