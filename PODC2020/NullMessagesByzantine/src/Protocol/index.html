import Cslib.Computability.Distributed.Byzantine.LockStep.Agreement import Cslib.Computability.Distributed.Byzantine.LockStep.Sequential import Mathlib /-! # The SmallCouncil layer (Goren–Moses, PODC 2020, Figure 1) Processes are `Fin n`; the Council is `{0, …, t}`. The model is CSLib's synchronous lock-step Byzantine model `Cslib.Byzantine.LockStep` on the complete graph `⊤`: in round `r` (0-indexed, so the paper's round `r + 1`, sent at the paper's time `r`) every process sends an `Option` message to every other process; `none` is a *null message*. The history after `r` rounds is the local state at time `r`. Messages are `Bool ⊕ M₂`: layer messages carry one bit, `M₂` is the message type of the base protocol `B`. * round 0 (time 0, lines 01–03): `p` sends its input `x` to council member `j` iff `par j ≠ x` (silence encodes `x = par j`, where `par j = j mod 2`); * round 1 (time 1, lines 04–07): council member `j` reconstructs the votes (`values`), computes `rec = MAJ(values)` and sends `rec` to `i` iff `values i ≠ rec` (silence encodes "`rec` = the value you reported"); * round 2 (time 2, lines 08–10): a process without a unanimous recommendation sends `err` to all; * time 3 (line 11): a process that got no `err` decides its estimate `est`; * round 3 (line 12): a process that got an `err` sends `help!` to all; * rounds `≥ 4` (lines 13–15): a process that got a `help!` runs `B` with input `est`; if it has not decided at time 3, it decides `B`'s decision. **Self-delivery.** Simple graphs have no loops, so a process does not receive its own broadcasts. The paper's "send to all" includes the sender: a process that sends `err` (resp. `help!`) also counts it as received. The flag `selfRcv` selects this convention (`true`, the paper's protocol) or the literal "own messages are not received" reading (`false`), which is broken (`SelfDelivery.lean`). -/ namespace
