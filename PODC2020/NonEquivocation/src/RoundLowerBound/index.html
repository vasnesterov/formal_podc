We prove that with `k ≤ t` rounds interactive consistency cannot be solved even against (send-)omission faults, as soon as `n ≥ t + 2`; since omission runs are weakly non-equivocating (`wne_of_omission`), the same holds under weak non-equivocation. The proof is the classical chain argument (Dolev–Strong / Aguilera–Toueg style) over *omission runs*: a run is given by the input `x` of a fixed source `s` (everybody else has a fixed filler input) and an omission pattern `O r a b` ("the round-`r` messages of `a` to `b` are omitted"). * `RoundLB.claim j`: two runs whose patterns (with senders in `F`) agree on all rounds `≤ k - j` lead to the same decisions of the correct processes, provided `|F| + j ≤ t + 1` and `|F| + j + 1 ≤ n`. The induction step changes the round-`r` messages into one receiver `b` at a time, silencing `b` in all later rounds (by the induction hypothesis with the faulty set `F ∪ {b}`), so that only `b`'s view changes (`RoundLB.σ_eq_swap`). * With `F = {s}` and `j = k`, the run "`s` behaves correctly" is connected to the run "`s` is silent", in which the input of `s` is invisible to everybody else;
