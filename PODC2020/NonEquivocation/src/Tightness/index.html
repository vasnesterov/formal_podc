import Papers.PODC2020.NonEquivocation.PSL /-! # Theorem 6.1 (tightness of `n > 2t`) — corrected — and the exact solvability threshold Madsen–Debois, PODC 2020, Section 6. Theorem 6.1 claims: for every number of rounds `k` and `n ≤ 2t`, no deterministic algorithm solves interactive consistency in the weak non-equivocation fault model. This is **false for `n ≤ 3`** (`theorem_6_1_false_n2`, `theorem_6_1_false_n3`): if at most one process is non-faulty there is nothing to agree on, so for `n = 2, t = 1` and `n = 3, t = 2` the problem reduces to `t = 0`, resp. `t = 1`, which Algorithm 2 solves. The paper's proof needs four non-empty groups `O, Q, R, S` ("WLOG `n = 2t`", groups of size `t/2`), i.e. `n ≥ 4`. For `n ≥ 4` the statement holds, with the paper's four runs (`not_solvesIC_of_groups`, `theorem_6_1`). We construct the runs as an `ExecSys` with four worlds in which every faulty group imitates the non-faulty behaviour of the same group in another world (so nobody equivocates), and `O` omits towards `S` in runs 3 and 4. The precise threshold is `icSolvable_wne_iff`: interactive consistency is solvable under weak non-equivocation iff `n > 2t` or `n ≤ 3`. -/ namespace NonEquivocation open Finset variable {P V : Type*}
