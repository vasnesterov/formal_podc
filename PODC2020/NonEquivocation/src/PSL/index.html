Madsen–Debois, PODC 2020, Section 5. `psl t S τ p q` is Algorithm 2 (`PSL(σ_p, n, t, p, q, P)`): process `p` with local view `τ` (`τ w = σ(p|w)`) computes the entry of source `q`, among the active processes `S`: 1. lines 1–7: own entry: `p`'s private value (`⟨⊥⟩` if it is `⊥`); 2. lines 8–10: if `p` has a consistent `q`-majority (Definition 4.3) for a value `v`, return `v`; 3. lines 11–19: otherwise recursively compute an interactive-consistency vector of the instance `σ̂(p|w) = σ(p|w|q)` on `S \ {q}` with `t - 1` faults; 4. lines 20–24: return a value `v ≠ ⟨⊥⟩` that occurs at least `t` times in that vector, or `⟨⊥⟩`. **Readings fixed here** (see `differencies.md`): the value `v` of line 8 is a genuine value (not `⊥`; this is the type-consistent reading, since line 2 says `⊥ ∉ V`; a reading allowing `⊥` breaks agreement, see `literal_line8_fails`); the choice in line 20 is deterministic (any fixed choice function: `Classical.choose`); for `t = 0` without majority the algorithm returns `⟨⊥⟩` (this never happens in admissible runs). `theorem_5_1`: with `t + 1` rounds, `psl t` solves interactive consistency in the weak non-equivocation fault model whenever `n > 2t`. -/
