Non-Equivocation in Synchronous Agreement — PODC 2020

Mads Frederik Madsen, Søren Debois. On the Subject of Non-Equivocation: Defining Non-Equivocation in Synchronous Agreement Systems. PODC 2020. DOI 10.1145/3382734.3405731. Formalized version: the PODC proceedings version (no arXiv version; the online appendix with the full proofs was not available to us). Numbering follows it. Copy of the paper: paper.pdf.

Verdict: 🔧 Easy fix. Under strong non-equivocation interactive consistency (IC) takes 1 round for any n, t, and under weak non-equivocation it takes exactly t + 1 rounds and n > 2t processes, for n ≥ 4. Local conditions repair everything: the impossibility of Theorem 6.1 needs n ≥ 4, majorities must be for genuine values, and the authenticated Byzantine model needs one more case.

Mistakes in the paper

🔧 Theorem 6.1 for n ≤ 3 (impossibility for n ≤ 2t under weak non-equivocation)

Theorem 6.1 claims that no algorithm solves IC under weak non-equivocation for n ≤ 2t, but for n = 2, t = 1 and n = 3, t = 2 IC is solvable (theorem_6_1_false_n2, theorem_6_1_false_n3).

Impact. In that range the theorem contradicts the paper's own Theorem 4.2. For n ≥ 4 the four-run argument is correct (n = 1 is trivial), so the bound n > 2t stays tight there. We prove the exact threshold: IC is solvable under weak non-equivocation iff n > 2t or n ≤ 3 (theorem_6_1, icSolvable_wne_iff).

Details

When at most one process is correct, only its own entry is constrained. So these cases reduce to t = 0, resp. t = 1, which Algorithm 2 solves. The proof needs four non-empty groups O, Q, R, S, i.e. n ≥ 4. The paper contradicts itself here: its own Theorem 4.2 ("solvable for any n > 1 if t ≤ 1") covers n = 2, t = 1, which lies inside "n ≤ 2t". "WLOG n = 2t" with groups of size t/2 hides this, and it does not fit odd t either.

🔧 Lemmas 4.7 and 4.8; Algorithm 2, line 8 (when v ranges over V ∪ {⊥})

Under the reading in which ⊥ counts as a value, Lemma 4.7 ("no consistent majority for ⊥") and Lemma 4.8 fail for n = 3, t = 1, two rounds, and a reading of line 8 of Algorithm 2 that allows v = ⊥ breaks agreement (lemma_4_7_false, literal_line8_fails).

Impact. Algorithm 2 is not wrong as printed: line 9 returns v into a vector of values, so the type-consistent reading is v ∈ V; under it the lemmas hold (lemma_4_8 for Maj) and the algorithm is correct (theorem_5_1).

Details

The paper uses V inconsistently: line 2 of Algorithm 2 says "⊥ ∉ V", but Lemma 4.7 concludes "v ≠ ⊥" for v ∈ V, so there ⊥ counts as a value. The proof of Lemma 4.7 claims that Q contains a correct process that reported ⊥. That process may be the decider p itself, and by the convention σ(p|p|q) = σ(p|q) its "report" is the ⊥ it received. Instance: n = 3, t = 1, two rounds, and the faulty q = 2 omits everything to 0 but otherwise behaves correctly. Then {0, 2} is a consistent 2-majority for ⊥ at 0, since the only admissible route is 0|2. At 1, {1, 2} is one for v.

  • Lemma 4.8 is false on the same instance: two correct processes have 2-majorities for different values. Its proof appeals to Lemma 4.7, which is the failing step.

  • A reading of line 8 that allows v = ⊥ then breaks agreement: 0 returns ⊥ and 1 returns v.

🔧 Section 7.2 (definition of the authenticated Byzantine model)

As printed, σ(w'|p|w) ∈ {σ(p|w), ⊥} for correct p forgets the ⟨⊥⟩ convention of Definition 2.1, so with k ≥ 2 rounds it excludes crash executions and Fig. 4's "Omission ⊆ AB" fails (silentσ_not_authByzLiteral).

Impact. The intent is clear: with the intended model (absent, p's report, or ⟨⊥⟩) all Fig. 4 relations hold (authByz_of_omission).

Details

The printed condition compares with what p received. A correct process that observes an omission reports ⟨⊥⟩ ≠ σ(p|w) = ⊥. (Our first attempted repair, without ⟨⊥⟩, fails for k ≥ 3; this concerns our repair, not the paper.)

✏️ Slips

  • In Definitions 3.1 and 4.1, r = p must be excluded. Otherwise the convention σ(p|p|w) = σ(p|w) forces faulty processes to relay truthfully.

  • In Algorithm 1, line 5 r must range over processes other than p and q. Otherwise line 6 returns ⊥.

Typos

  • Definition 4.3: q ∈ Q is stated in the text ("including q") but missing from the formula.

  • Section 3 has a truncated sentence ("a faulty process q may receive v from").

  • Section 4.1 cites Definition 2.1 for weak non-equivocation, where Definition 4.1 is meant.

The formalizationmodel, Lean names of the results, trust

Model. The paper's framework, formalized directly (Model.lean):

  • n synchronous processes (Fintype P) with reliable channels run the full-information relay protocol of Pease–Shostak–Lamport for k rounds. The outcome is a message map σ : List P → Option V (none = ⊥). σ (p :: q :: w) is what q told p in round |w| + 1, and σ [p] is p's private value. Only routes without consecutive duplicates are constrained. ⟨⊥⟩ is a distinguished ordinary value (OmitVal).

  • A fault model is a predicate on (rounds k, static faulty set F, σ). We define:

    • byzantine = Definition 2.1 only;

    • wne = Definition 2.1 + Definition 4.1;

    • sne = Definition 2.1 + Definition 3.1;

    • omission, crash, authByz (§7.2, Fig. 4).

  • An algorithm is a deterministic function A p (view k σ p) q. Here view is p's local view of the first k rounds. SolvesIC M k t A requires validity and agreement of IC for every admissible σ with |F| ≤ t; termination is implicit (decision after k rounds).

  • Impossibility results quantify over all such algorithms. Their runs are built as families of full-information executions in which a faulty process imitates the correct behaviour of another "world" towards everybody it does not omit (ExecSys, FLM-style). So it never equivocates.

  • Line 20 of Algorithm 2 is made a deterministic choice, and the recursion bottoms out at t = 0, not at t = 1.

Not formalized.

  • The informal converses "Byzantine broadcast oracle ⇒ strong NE" (§3) and "crusader agreement oracle ⇒ weak NE" (§7.1), including Dolev's t + 2-round mapping.

  • The "algorithms can / cannot solve agreement" reading of the §7.2 examples (only their fault-model memberships are proved).

  • The consensus column of Table 1.

  • Example (3) of §7.2 deduces "t ≥ 2, n ≥ 5" from an algorithmic criterion ("general-omission algorithms cannot solve agreement"), which we did not formalize. As a pure fault-space separation, a smaller witness exists: a single faulty process lying consistently about its own value (n = 3, t = 1) is in weak NE ∩ AB but not in Omission (sne_inter_authByz_not_le_omission). This reinterprets the claim; it does not refute it.

  • The paper's proof of Theorem 5.1 was not compared with ours: it is only sketched, and its hard case (one correct process has a consistent majority and another has none) is deferred to an appendix (Lemma C.1) we could not access. The theorem itself is proved in full (psl_correct): every member of Q \ {q} gets value v in the recursive vector, which gives ≥ t votes. Any competing value with ≥ t votes comes from a correct process (only t − 1 faulty ones remain). By weak non-equivocation of q's first-round message it equals v. This also covers v = ⟨⊥⟩.

  • The paper's proof of the Section 6 round lower bound is in the same appendix; we proved the bound independently and did not compare the two.

Trust. No sorry. All listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity: the fault models are inhabited by fault-free and crash executions (ExecSys, mkσ). Algorithm 2 and the Section 3 algorithm satisfy the solvability hypotheses (theorem_5_1, sne_solvesIC). The model is self-contained (Mathlib, plus the shared vote counting Finset.countEq of Cslib/Foundations/Data/Finset/Quorum.lean).
