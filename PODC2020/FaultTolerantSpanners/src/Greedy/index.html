import Papers.PODC2020.FaultTolerantSpanners.LBC import Cslib.Foundations.Combinatorics.SimpleGraph.FaultTolerantGreedy /-! # Algorithm 3: the modified greedy algorithm (Section 3.2 of Dinitz–Robelle, PODC'20) The edges of `G` are given as a list `L` of ordered pairs (`(u, v)` stands for the edge `{u, v}`), in arbitrary order; every edge of `G` must occur in `L` (in at least one orientation) and every entry of `L` must be an edge of `G`. Starting from the empty graph, the algorithm scans `L` and adds the edge `(u, v)` to the current graph `H` iff a decision procedure `dec H u v` answers YES. This generic greedy scheme is `SimpleGraph.greedyGraph dec L` (the list of added edges, in insertion order, is `greedyEdges dec L`); it and its correctness for any decision procedure that answers NO only when no small fault set separates `u, v` (`greedyGraph_isVFTSpanner`, `greedyGraph_isEFTSpanner`) are in `Cslib/Foundations/Combinatorics/SimpleGraph/FaultTolerantGreedy.lean`, shared with Bodwin–Patel (PODC'19). * `modifiedGreedy O k f L` — **Algorithm 3**: `dec H u v := lbc O H u v (2k - 1) f` (Algorithm 2 with `t = 2k - 1`, `α = f`, run on the current `H`, unweighted). * `modifiedGreedyEdge O k f L` — the EFT variant (edge version of Algorithm 2).
