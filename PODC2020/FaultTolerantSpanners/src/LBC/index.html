import Cslib.Foundations.Combinatorics.SimpleGraph.Spanner import Mathlib /-! # Algorithm 2: the gap problem LBC(t, α) (Section 3.1 of Dinitz–Robelle, PODC'20) **Length-Bounded Cut.** For terminals `u, v` of an unweighted graph `G`, a *length-`t` cut* is a set `F ⊆ V \ {u, v}` with `d_{G \ F}(u, v) > t` (`IsLengthCut`). In the gap problem `LBC(t, α)` one must answer YES if there is a length-`t` cut of size `≤ α` and NO if there is none of size `≤ α t`. **Algorithm 2** (`lbc`): starting from `F = ∅`, repeat `α + 1` times: look for a `u`–`v` path of length `≤ t` in `G \ F` (by BFS); if there is none, answer YES; otherwise add the interior vertices of the path to `F`. After `α + 1` rounds answer NO. The BFS step is modelled by an arbitrary *short-path oracle* `O` (`ShortPathOracle`): `O G u v t` returns some `u`–`v` walk of length `≤ t` in `G` if one exists and `none` otherwise (`ShortPathOracle.Spec`). Theorem 4 is proved for every such oracle, i.e. for every choice of the path found in each round. The core of the argument is the generic "frequency" approximation for hitting sets (`hitLoop`), which we instantiate both for vertex cuts (`lbc`) and edge cuts (`lbcEdge`, the EFT variant). -/ open
