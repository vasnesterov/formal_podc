Efficient Fault-Tolerant Spanners — PODC 2020

Michael Dinitz, Caleb Robelle. Efficient and Simple Algorithms for Fault-Tolerant Spanners. PODC 2020. DOI 10.1145/3382734.3405735. Formalized version: arXiv 2002.10889 v2. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The sequential part (Sections 2–4) holds as stated: the modified greedy algorithm, which uses the length-bounded-cut approximation (Algorithm 2), outputs an f-VFT (2k−1)-spanner with O(k f^{1−1/k} n^{1+1/k}) edges, weighted and unweighted, and we prove it with the explicit constant 32. Lemma 7's hypothesis f = o(n) is too weak for its proof's estimate, which needs kf = o(n); the statement stays true (when kf ≥ n the claimed subgraph exists trivially), so only the proof needs repair, and the proof of Lemma 3 has a wrong step (p = 1). Running times and the distributed results were not checked.

Mistakes in the paper

✏️ Slips

  • Lemma 3 (weighted, "if" direction, case p = 1): the paper writes d_{H\F}(u, v) = w(u, v) = d_{G\F}(u, v), but H need not contain the edge uv. What holds, and suffices, is d_{H\F}(u, v) ≤ t·w(u, v) by hypothesis. We prove the full iff by a different argument: a non-tight edge has a strictly lighter walk made of strictly lighter edges, so strong induction on the number of lighter edges applies; no shortest paths are needed (isWeightedVFTSpanner_iff).

Proof gaps in true statements (1)Lemma 7

🔧 Lemma 7 (hypothesis f = o(n))

The lemma assumes f = o(n), but the estimate s(s−1)/(n(n−1)) ≥ (1−o(1))/(4((2k−1)f)²) needs kf = o(n), since k may grow with n.

Impact. Theorem 8 is not affected, because it is trivial when kf = Ω(n), but its split on f = Ω(n) has to move there; Lemma 7 is replaced by an exact form (SimpleGraph.IsBlockingSet.exists_dense_subgraph).

Repair

We replace the asymptotic lemma by exact counting over all s-subsets: if |B| ≤ D·m and 2Ds ≤ n, some s-set carries a subgraph of girth > 2k with m·s(s−1) ≤ 2n(n−1)·|E(H′)|. A case split at n < 8(2k−1)f replaces "if f = Ω(n) the theorem is trivial".

The formalizationmodel, Lean names of the results, trust

Model.

  • Sequential, deterministic algorithms on a finite simple graph. Distances are unweighted in ℕ∞, or weighted with weights ≥ 0 in ℝ≥0∞; ⊤ means unreachable.

  • G \ F keeps the vertex type and deletes all edges at F. For u, v ∉ F this gives the same distances as G[V \ F].

  • The edge order is any list of the edges, in either orientation, with duplicates allowed. For Algorithm 4 it is sorted by weight.

  • "Run BFS to find a path of length ≤ t in G \ F" is an arbitrary oracle that returns some short walk if one exists. All theorems hold for every such oracle, i.e. for every choice of path.

  • Running times are not modelled. Structurally, Algorithm 2 makes at most α + 1 oracle calls.

Not formalized.

  • The distributed results (Section 5, Theorems 11–15). They rest on black boxes with w.h.p. guarantees: padded decompositions, Baswana–Sen, and the [DK11] reduction.

  • Running times (Theorem 4's O((m+n)α), Theorem 9), and Algorithm 1 (motivation only).

  • The size bound for edge faults, which the paper only asserts to be "essentially identical". EFT correctness is formalized.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity: valid oracles (ShortPathOracle.exists_spec) and weight-sorted edge lists (exists_sorted_edgeList) exist, and exists_vft_spanner combines them. The Moore bound, which the paper cites, is proved. The spanner, girth and blocking-set infrastructure is in CSLib Cslib/Foundations/Combinatorics/SimpleGraph/{Spanner,WeightedSpanner,Girth,BlockingSet}.lean. The generic greedy scheme (SimpleGraph.greedyGraph, its correctness greedyGraph_isVFTSpanner / greedyGraph_isWeightedVFTSpanner and EFT analogues, blocking sets from insertion histories exists_blockingSet_of_insertion, exists_sorted_edgeList) is in Cslib/Foundations/Combinatorics/SimpleGraph/FaultTolerantGreedy.lean, shared with Bodwin–Patel.
