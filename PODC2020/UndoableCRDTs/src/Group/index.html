It is an abelian group under concatenation (Section 2.4), finitely generated (Section 2.5). We write it additively. * `UndoableCRDT.eval s : G s → S`, `[a] ↦ s · a`, is injective; for `s = s₀` it is a bijection (`stateEquiv`), because all states are reachable. * **Proposition 3** (`prop3`):
