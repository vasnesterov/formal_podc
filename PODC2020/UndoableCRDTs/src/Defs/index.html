Dolan, *Brief Announcement: The Only Undoable CRDTs are Counters*, PODC 2020 (arXiv:2006.10494). * `OpSystem`: a set of states `S` with an initial state `s0` and a family of *partial* primitive operations `P`. Actions `P*` are lists of operations, applied left to right (`s · p · q = q (p s)`; `act s [p, q]`). * `OpSystem.Commutative` (Axiom 1), `OpSystem.Undoable` (Axiom 2), `OpSystem.Reachable`. * `CRDT`: an operation system with finitely many primitive operations, all states reachable, satisfying Axiom 1. `UndoableCRDT`: a CRDT also satisfying Axiom 2. * `CRDTEquiv`: equivalence of CRDTs (Section 2.2). * `CRDT.tuple`: the tuple construction (Section 2.3). * `modCounter n`: the counter modulo `n` (Section 1.1); `modCounter 0` is the unbounded counter (its state type is `ZMod 0 = ℤ`, definitionally). -/ universe u v u₁ v₁ u₂ v₂ w namespace UndoableCRDTs /-- States, an initial state and partial primitive operations (Section 2).
