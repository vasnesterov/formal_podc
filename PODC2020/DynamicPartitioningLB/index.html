Verdict: 🔧 Easy fix. Theorem 2.1 (every deterministic online algorithm for the learning model is Ω(kℓ)-competitive, k ≥ 3, ℓ ≥ 2) holds, even with a slightly better constant: ((k-2)(ℓ-1)-2)/2 instead of ((k-2)(ℓ-1)-4)/2. The adversary in the paper does not work as written: it assumes that the algorithm always keeps the revealed ground sets together, and it gets stuck when the pivot is the one node of B's home cluster outside B, but two local additions repair it. Theorem 2.2 (PPL is O(kℓ)-competitive) and Lemma 3.1 have no proof in the paper and we prove both, while Theorem 3.2 (ALG3 is O(ℓ)-competitive) has no proof in the paper and is not formalized, so this verdict does not cover it.

Mistakes in the paper

✏️ Slips

  • In the final count of the proof of Theorem 2.1, B contributes |B| - 1 = k - 2 to Σ(|C*| - 1), but the proof subtracts k - 1. This only weakens the bound, and the printed ratio follows (theorem_2_1_paper).

Typos

  • The proof of Theorem 2.1 stops at < ℓ + 3 isolated nodes, while < ℓ + 2 suffices, because B's home cluster has no isolated node. This only weakens the bound.

  • The pigeonhole step needs only ℓ isolated nodes, not ℓ + 1.

Proof gaps in true statements (2)Theorem 2.1 · Theorem 2.1

🔧 Theorem 2.1 (the algorithm is assumed to keep every ground set in one cluster)

The proof says "Any competitive algorithm under the learning model maintains a perfect partition of ground sets", but a deterministic algorithm may split a revealed ground set, for example by moving a node of B away for a while, and nothing in the proof covers this.

Impact. Statement true; repaired with repair requests (theorem_2_1).

Repair

Whenever the algorithm's current configuration splits a ground set, the adversary requests a split pair, which costs the algorithm at least 1 (it pays for the request or migrates). The adversary moves on to the next pivot step only when all ground sets are back together. Between two such moments the algorithm migrates at least two nodes (LB.two_le_dist; this also covers an algorithm that moves B instead of the pivot). If the algorithm never puts the ground sets back together, the repair requests alone make its cost large enough. (theorem_2_1)

🔧 Theorem 2.1 (the pivot step is undefined when the pivot is z)

If the pivot is z, the node of B's home cluster that is not in B, the required "ground set of the same origin residing in a different cluster" does not exist, and following the text the construction stops after O(1) swaps.

Impact. Statement true; repaired by making z part of the first pair (LB.grow_shape).

Details

The paper does not control z: during the requests inside B the algorithm may move z away, so x₀ ≠ z, and later choose z as a new pivot. Then the only other ground set with z's origin is B itself, and B is in the same cluster as z. Following the text literally, the adversary would request (z, b) with b ∈ B. That request is internal, and B ∪ {z} then fills the cluster, so no pivot is left.

Repair

Make z part of the first pair {x₀, y₀}. In our adversary B is never requested before the first pivot step, so x₀ = z, and y₀ comes from another cluster. Every later pivot then has an origin other than B's home cluster. With k ≥ 3 it always has a partner of the same origin (LB.grow_shape).

The formalizationmodel, Lean names of the results, trust

Model.

  • Not a distributed model: online algorithms against an adaptive adversary. n nodes, ℓ clusters (Fin ℓ) of capacity k. A configuration V → Fin ℓ is balanced if every cluster has at most k nodes; with n = kℓ this means exactly k. There is no resource augmentation.

  • Serving request (u, v) costs 1 if the configuration in which it is served separates u and v. Migration costs α ≥ 1 per moved node. Before serving a request the algorithm may repartition.

  • A deterministic online algorithm (OnlineAlg) is a map from the requests revealed so far to a balanced configuration. Adaptivity of the adversary is automatic. OPT (optCost) is the minimum over all balanced offline schedules starting in the initial configuration.

  • Learning model, finite form (IsLearningInput): the requests admit a perfect partition. Static form (IsStaticLearningInput, Section 2): an infinite sequence that admits a perfect partition, in which every communicating pair communicates infinitely often. The lower bound is proved in both forms. Theorem 2.2 needs the static form (see below).

  • Lower-bound instance: nodes Fin ℓ × Fin k (cluster of origin, index), initial partition Prod.fst. A lower bound for one instance is a lower bound for the problem.

  • Competitive ratio: the paper leaves the notion implicit. In the learning model every sensible algorithm has bounded total cost (PPL pays at most 2(n-1)α·n), so no lower bound is possible if the additive constant β may depend on α. Theorem 2.1 holds for strict competitiveness, or for β independent of α (letting α → ∞). We prove c ≥ ((k-2)(ℓ-1)-2)/2 - β/(4α) for every (c, β)-competitive algorithm with c ≥ 0 (theorem_2_1_competitive, theorem_2_1_omega).

Results stated without proof in the paper. This brief announcement omits these proofs; we supply them.

  • Theorem 2.2 (PPL is O(kℓ)-competitive), with ratio 2(kℓ-1) in the static learning model (theorem_2_2, theorem_2_2_kl). PPL never pays for a request. While D = dist(init, P*) for a perfect partition P*, every configuration PPL visits is within D of init. Each repartition merges two components, so there are at most n - 1 of them, and each costs at most 2αD. Any offline algorithm with finite cost ends in a perfect partition and pays at least αD. This uses "pairs communicate forever": on a finite sequence OPT may simply pay for the requests (one request: OPT = 1, PPL ≥ 2α). Section 2 makes "communicate forever" part of the model, so this does not contradict Theorem 2.2.

  • Lemma 3.1 (k = 3: a repartition needs at most two swaps; K3.lemma_3_1, K3.lemma_3_1_closest). For clusters of size 3, if a balanced configuration respecting the merged components exists, one exists at distance at most 4 (two swaps). The hard case is when a and b are singletons sitting next to pairs. A counting argument then finds a cluster made of three singletons (K3.exists_triple).

Not formalized. Theorem 3.2 (ALG3 is O(ℓ)-competitive for k = 3): the paper gives no proof and does not fully specify ALG3's phases. The matching Ω(ℓ) lower bound for k = 3 in the general model is theorem_2_1_general with k = 3.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity: theorem_2_1_static builds static learning inputs, so the hypothesis of Theorem 2.2 is satisfiable. PPL is a concrete OnlineAlg (ppl). The model (Model.lean) is self-contained on top of Mathlib. The generic online-algorithm and cost definitions are a CSLib candidate.
