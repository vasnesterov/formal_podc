import Mathlib /-! # Dynamic balanced graph partitioning: the model Pacut, Parham, Schmid, *Brief Announcement: Deterministic Lower Bound for Dynamic Balanced Graph Partitioning*, PODC 2020, Section 1 ("Model") and Section 2 (learning model). * Nodes form a finite type `V`; there are `ℓ` clusters `Fin ℓ`, each of capacity `k`. A *configuration* is a map `V → Fin ℓ`; it is `Balanced k` if no cluster holds more than `k` nodes (with `|V| = k ℓ` this means exactly `k` nodes per cluster, `card_fiber_eq`). * A request is a pair of nodes. Serving request `(u, v)` in configuration `Q` costs `1` if `Q` separates `u` and `v` (external request) and `0` otherwise. Migrating from `P` to `Q` costs `α · dist P Q`, where `dist P Q` is the number of nodes placed differently. * A *schedule* `O : ℕ → Config` serves request `σ[t]` in configuration `O (t+1)`, after migrating from `O t`; `O 0` is the initial configuration. `schedCost α σ O` is its total cost. * A deterministic online algorithm (`OnlineAlg`) chooses, after seeing the requests `σ[0..t]`, the configuration `conf (σ.take (t+1))` in which `σ[t]` is served (it may repartition before serving). Its cost is `algCost`. `optCost` is the optimal offline cost (minimum over all balanced schedules starting in `init`). * Learning model: the communication pattern admits a *perfect partition*, i.e. a balanced configuration in which every request is internal (`IsLearningInput`). -/ set_option linter.unusedSectionVars false namespace Papers.PODC2020.DynamicPartitioningLB open Finset /-- A
