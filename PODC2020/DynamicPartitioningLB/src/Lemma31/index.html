ALG3 keeps a component-respecting balanced configuration `P` (clusters of size `3`); when the components of `a` and `b` (with `P a ≠ P b`) are merged it moves to the component-respecting configuration *closest to `P`*, if one exists. We prove that some (hence the closest) such configuration is at distance `≤ 4` from `P`, i.e. two swaps suffice (`lemma_3_1`, `lemma_3_1_closest`). Components are given by a labelling `comp : V → V`; the merged component structure is expressed by the requirement `Q a = Q b` on top of respecting `comp`. **Proof.** Let `X = P a`, `Y = P b`. Feasibility gives `|C(a)| + |C(b)| ≤ 3`. * If `Y` holds a singleton component `s ≠ b` and `a` is a singleton, swap `a ↔ s` (this covers `|C(b)| = 2`). Symmetrically for `X`. * Otherwise `a`, `b` are singletons and `X`, `Y` hold no other singleton. Every cluster of a component-respecting configuration has `(#singletons, #nodes in pairs) ∈ {(0,0), (3,0), (1,2)}` (`cluster_shape`). If no cluster of `P` consisted of three singletons, `2·#singletons = #pair-nodes` would hold globally; but a feasible `Q` has a cluster `{a, b, ·}` of three singletons, so `2·#singletons ≥ #pair-nodes + 6`.
