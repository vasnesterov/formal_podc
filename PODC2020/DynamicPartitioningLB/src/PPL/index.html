The paper states Theorem 2.2 without proof; we prove it with ratio `2 (n - 1)`, `n = k ℓ`, in the static learning model (`IsStaticLearningInput`: a fixed communication pattern admitting a perfect partition, every communicating pair communicating forever). **Algorithm** (`ppl`). PPL maintains components (as a labelling `comp : V → V`, two nodes being in the same component iff they have the same label) and a configuration collocating every component. On an inter-cluster request `(u, v)` it merges the components of `u` and `v` and moves to a balanced component-respecting configuration *closest to the initial configuration* (`closest`). **Proof.** * PPL never pays for a request: after a merge it serves the request locally. * If `P*` is any perfect partition at distance `D` from `init`, `P*` respects every component, so PPL's configurations are always at distance `≤ D` from `init`; a repartition costs `≤ α (D + D)`. Every repartition merges two components, so there are at most `n - 1` of them: `PPL ≤ 2 (n - 1) α D` (`ppl_cost_le`). * Any offline schedule with bounded cost eventually stays in one configuration, which must be a perfect partition (otherwise it pays forever for a pair that communicates forever); reaching it costs `α · dist init P* ≥ α D` (`schedule_lb`). -/ set_option linter.unusedSectionVars
