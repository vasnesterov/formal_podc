import Papers.PODC2020.DynamicPartitioningLB.Model /-! # The adversary of Theorem 2.1 (lower bound `Ω(k ℓ)`) Pacut, Parham, Schmid, PODC 2020, Section 2.1. We work with `ℓ = L + 2` clusters and capacity `k = K + 3`; the nodes are `Node L K = Fin ℓ × Fin k` (cluster of origin, index) and the initial configuration is `Prod.fst`. **The ground sets** (the communication pattern revealed by the adversary) are, at every time: * `B` = the `k - 1` nodes `(0, j)`, `j ≠ 0`, of cluster `0` (never requested unless the algorithm separates them); * the pair `{z, y₀}` with `z = (0,0)` and `y₀ = (1,0)`; * for every origin `c`, the set of nodes of `J` with origin `c` (empty or of size `≥ 2`); * singletons (the *isolated* nodes). `SameGS J u v` says that `u` and `v` are in the same ground set. **The adversary** (`next`, `run`). If the algorithm's current configuration separates two nodes of the same ground set, the adversary requests such a pair (a *repair* request; it costs the algorithm `≥ 1`). Otherwise (all ground sets collocated) and while at least `ℓ + 2` nodes are isolated, it joins the *pivot* — the unique node collocated with `B` outside `B`, which is isolated — to the ground set of its origin (or to a fresh isolated node of its origin when that ground set is empty), and requests a pair of the new ground set. This is the pivot-eviction adversary of the paper; the differences (repair requests, `{z, y₀}` fixed in advance, the choice of the ground set to join) are discussed in `differencies.md`. **Accounting.** Between two consecutive configurations in which all ground sets are collocated (`Q` and the next one) the algorithm migrates at least two nodes (`two_le_dist`); the invariant `Inv` keeps track of `2α (s - 1) + α · dist Q P ≤ ALG`, where `s` counts the phases. -/ set_option linter.unusedSectionVars false namespace Papers.PODC2020.DynamicPartitioningLB.LB open Finset Classical
