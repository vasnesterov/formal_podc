import Papers.PODC2020.RoundBasedKSetTopology.UpperBounds /-! # One-round lower bound for simple closed-above models (Theorem 5.1) Theorem 5.1 of the paper reads: *"Let `k ≤ γ(G)`. Then `k`-set agreement is not solvable on `↑G` in a single round."* For `k = γ(G)` this contradicts Theorem 3.2 (`theorem_5_1_false`). The intended statement, recoverable from the text after Theorem 3.2, is `k < γ(G)`. We prove it (`theorem_5_1`) by a direct combinatorial argument instead of the topological one of Castañeda et al.: 1. validity forces every process to decide an input it has heard (otherwise change the inputs of the processes it does not hear; `decides_heard`); 2. with pairwise distinct inputs and the graph `G` itself, the processes whose inputs are decided form a dominating set of `G`, so at least `γ(G)` values are decided. The argument needs at least `n` input values (`α ↪ V`); the paper does not fix the input set. The lower bound holds for full-information algorithms and any model containing `G` (`domNum_le_of_solvesOneRound`), so one-round `k`-set agreement on `↑G` is solvable iff `γ(G) ≤ k` (`oneRoundSolvable_up_iff`). -/ namespace Podc.RoundBasedKSetTopology open Cslib.HeardOf Finset variable {α V : Type*} -- CSLib candidate: Cslib/Computability/Distributed/DynamicNetworks/HeardOf (validity forcing) /-- Validity forces every process to decide the input of a process it hears: otherwise replacing the inputs of the unheard processes by the decider's own input yields an indistinguishable execution in which the decision is no input at all. -/ theorem decides_heard {k : ℕ} {M : Set (Graph α)} {δ : Decision α V} (hδ : SolvesOneRound k M δ) {G : Graph α} (hG : G ∈ M) (x : α → V) (p : α) : ∃ q, Hears G p q ∧ δ p (msgs G x p) = x q := by classical by_contra hne simp only [not_exists, not_and] at hne set x' : α → V := fun q => if Hears G p q then x q else x p have hmsg : msgs G x' p = msgs G x p := by funext q; unfold msgs; by_cases h : Hears G p q <;> simp [h, x'] obtain ⟨q, hq⟩ := (hδ G hG x').1 p simp only [hmsg] at hq by_cases h : Hears G p q · exact hne q h (by simpa [x', h] using hq) · exact hne p (hears_self G p) (by simpa [x', h] using hq) /-- **Lower bound.** If an algorithm solves `k`-set agreement in one round on a model containing `G`, with at least `n` possible input values, then `γ(G) ≤ k`. -/ theorem domNum_le_of_solvesOneRound [Fintype α] (e : α ↪ V) {k : ℕ} {M : Set (Graph α)} {δ : Decision α V} (hδ : SolvesOneRound k M δ) {G : Graph α} (hG : G ∈ M) : domNum G ≤ k := by classical rcases isEmpty_or_nonempty α with hα | hα · obtain ⟨P, -, hP⟩ := exists_dominating_card_domNum G rw [← hP, Finset.eq_empty_of_isEmpty P]; exact ⟨d p, ⟨p, rfl⟩, ((hd p).2).symm⟩ · rintro ⟨_, ⟨p, rfl⟩, rfl⟩; exact ⟨p, (hd p).2⟩ have hk := (hδ G hG e).2 rw [hrange, Set.ncard_coe_finset, card_image_of_injective _ e.injective] at hk exact (domNum_le_card hdom).trans hk /-- **Theorem 5.1 (corrected: `k < γ(G)`).** With at least `n` input values, `k`-set agreement is not solvable in one round on the simple closed-above model generated by `G` when `k < γ(G)`. -/ theorem theorem_5_1 [Fintype α] (e : α ↪ V) (G : Graph α) {k : ℕ} (hk : k < domNum G) : ¬ OneRoundSolvable V k (closedAbove {G}) := by rintro ⟨δ, hδ⟩ have := domNum_le_of_solvesOneRound e hδ (G := G) ⟨G, rfl, le_rfl⟩ omega /-- **Theorem 5.1 as stated (`k ≤ γ(G)`) is false**, for every graph: `γ(G)`-set agreement is solvable on `↑G` in one round (Theorem 3.2). -/ theorem theorem_5_1_false [Fintype α] [LinearOrder V] [Nonempty V] (G : Graph α) : ¬ ∀ k ≤ domNum G, ¬ OneRoundSolvable V k (closedAbove {G}) := fun h => h _ le_rfl (theorem_3_2 G) /-- Theorems 3.2 and 5.1 together: one-round `k`-set agreement on `↑G` is solvable iff `γ(G) ≤ k` (inputs from a linear order with at least `n` values). -/ theorem oneRoundSolvable_up_iff [Fintype α] [LinearOrder V] [Nonempty V] (e : α ↪ V) (G : Graph α) (k : ℕ) : OneRoundSolvable V k (closedAbove {G}) ↔ domNum G ≤ k := ⟨fun h => by by_contra hk;
