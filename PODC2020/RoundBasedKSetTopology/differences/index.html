Differences between the formalization and the paper

Rendered from differencies.md of K-set agreement bounds in closed-above round-based models — PODC 2020.

Shimi, Castañeda, K-set agreement bounds in round-based models through combinatorial topology, PODC 2020 (full version arXiv:2003.02869 v2, which has the same statements).

False or wrong statements

  1. Theorem 5.4 is false (❌: it is the paper's main lower bound for general closed-above models, a primary contribution of the abstract and title). Counterexample: S = {star with center c}, any n ≥ 2. Here l = n − 2, yet consensus is solvable in one round (theorem_5_4_false; concrete n = 3 instance as an example). The counterexample satisfies all of the paper's hypotheses. The model is a closed-above model generated by a set of graphs, the theorem is explicitly for general (not necessarily symmetric) closed-above models, and n = 3 is not degenerate. Failing proof step: Appendix B ignores the case where the intersection ⋂ C_{G_i}(φ_i) is empty.

  2. Theorem 6.11 is false (❌, a multi-round extension), by the same example for every r ≥ 1 (theorem_6_11_false).

  3. "γ^dist(S) = n − s + 1" for the symmetric model of unions of s stars (Section 5 text, Appendix G) is false for s = 1, n ≥ 3: γ^dist ≤ n − 1 (distDomNum_stars_le). ❌ The proof of Theorem 6.13 relies on it. Theorem 6.13 itself is not formalized; it is unestablished, not refuted.

  4. Theorem 5.1: k ≤ γ(G) should be k < γ(G) (✏️). The sentence after Theorem 3.2 states k < γ(G), and for k = γ(G) the statement contradicts Theorem 3.2 (theorem_5_1_false). We prove the corrected version (theorem_5_1).

  5. Theorem 6.10: γ(G) − 1 should be γ(G^r) − 1 (✏️). The literal statement is false (theorem_6_10_false: directed 3-cycle, r = 2). The intended bound is recoverable from Theorem 6.3 (the matching upper bound uses G^r), from Theorem 6.11 (uses S^r) and from the proof in Appendix E (works with ↑G^r). The fix is the missing exponent r, a dropped superscript: the paper uses γ(G^r) consistently everywhere else.

  6. Section 3.2: "every covering number of a star equals 1" is false; cov_i = i (star_cov_eq). The inequality it is meant to support (n − cov_i ≥ γ^eq − i, so the covering bound does not improve on γ^eq) still holds (star_example). 🔧 (a side computation whose stated conclusion is correct).

Modelling choices

  • Graphs. Cslib.HeardOf.Graph α = α → α → Prop (G j i: i receives j), with self-loops implicit through Hears, as the paper assumes ("we assume self-loop"). ↑G = {H | G ≤ H} is edge inclusion. Since loops are implicit, adding or removing explicit loops changes nothing.

  • Model. closedAbove S; since the model is oblivious (Com = (⋃_{G∈S} ↑G)^ω), the adversary independently picks one graph of closedAbove S per round. Sym(S) is the set of all relabelings relabel π G.

  • Algorithms.

    • One round: full information, i.e. a decision map applied to the received vector msgs G x p.

    • r rounds: oblivious algorithms (Definition 2.5), i.e. a decision map applied to the known (process, input) pairs known Gs x p. These pairs are the flattened full-information view.

    • The paper's remark that "the full-information protocol might still be used for deciding when to apply the decision map" is not modelled: an r-round algorithm decides after exactly r rounds, which is what "solvable in r rounds" means.

  • k-set agreement. Validity: every decision is the input of some process. Agreement: at most k distinct decisions (Set.ncard).

  • Inputs.

    • Upper bounds: any nonempty linearly ordered input type (the paper assumes a total order; Nonempty V is needed for a decision map to exist at all).

    • Lower bounds (Theorems 5.1, 6.10): at least n input values (α ↪ V). The paper never fixes the input set. Our proof uses distinct inputs. With fewer values (but > k) the statement is presumably still true via Sperner-type arguments, but this is not proved.

    • The counterexamples (Theorems 5.4, 6.11) work for every input type.

  • Numbers. γ, γ^eq use the paper's range i ∈ [1, n]. γ^eq(S) = sSup, cov_i(S) = sInf over S, cov_i, γ^dist and max-cov are literal transcriptions. In particular, S_i ranges over subsets of S of size min(i, |S|), i.e. distinct graphs. M_i uses natural-number floor division. l is an integer (it can be negative). Theorem 5.4's "(l+1)-set agreement" is read as k with (k : ℤ) = l + 1.

  • Products. gprod G H u v := ∃ w, Hears G w u ∧ Hears H v w (Definition 6.1 with implicit loops). S^r is {G₁ ⊗ ⋯ ⊗ G_r | Gᵢ ∈ S} (powSet). The empty product has only self-loops.

  • Covering sequences (Definitions 6.6/6.8) are indexed from 0 (covSeq i S 0 = s₁). "keq−dom(G)" in Definition 6.8 is read as γ^eq(G).

Strengthenings / extra results

  • Theorem 3.7 / Corollary 3.8 hold for every i ≤ n, not just i ∈ [1, γ^eq(S)[ (theorem_3_7_general).

  • Theorems 3.2 + 5.1 (corrected) give an exact characterization: on ↑G, one-round k-set agreement is solvable iff γ(G) ≤ k (oneRoundSolvable_up_iff). Theorems 6.3 + 6.10 (corrected) give the same for r rounds and oblivious algorithms, with γ(G^r) (obliviousSolvable_up_iff).

  • The lower bounds are proved for full-information one-round algorithms and for any model containing G (domNum_le_of_solvesOneRound). For general S this gives the valid (but weak) bound k < max_{G∈S} γ(G) ⇒ impossible (not_solvable_of_lt_domNum).

  • Theorem 6.9's proof sketch ("by induction on the sequence index") is completed with the monotonicity of covering numbers (cov_mono). Also, a set of size ≥ s reaches at least s_{k+1} processes, not just a set of size exactly s_k (covSeq_step).

Proof differences

  • Theorem 5.1 (corrected) and 6.10 (corrected): the paper cites Castañeda et al. [6, Thm 5.1] (topological). We give a direct combinatorial proof. Validity forces each process to decide a heard input (decides_heard: replace the inputs of unheard processes). With pairwise distinct inputs, the processes whose inputs are decided then dominate G (resp. G^r).

  • Theorems 3.4/3.7: the paper's "the i processes with the smallest initial values" is exists_lowerSet. The key step "a process hearing one of them decides one of their values" (ncard_range_minFrom_le) also covers ties.

Not formalized

  • Section 4 (simplicial complexes, pseudospheres, nerve lemma, shellability, Lemma 4.17, Theorem 4.12).

  • Corollary 5.5 (symmetric lower bound). Its derivation goes through the flawed proof of Theorem 5.4. A brute-force check (n ≤ 4, all graphs up to isomorphism, script in the work folder) found no instance where Corollary 5.5's bound exceeds the paper's own upper bounds (Corollaries 3.5, 3.8). So it is neither confirmed nor refuted.

  • Theorem 6.13 (stars). For s = 1 it holds because iterated immediate snapshots embed into the model (every IS round contains a star). For s ≥ 2 its status is open here; its proof uses the wrong value of γ^dist.
