K-set agreement bounds in closed-above round-based models — PODC 2020

Adam Shimi, Armando Castañeda. K-set agreement bounds in round-based models through combinatorial topology. PODC 2020. DOI 10.1145/3382734.3405752. Formalized version: the PODC proceedings version; the full version arXiv 2003.02869 v2 (same statements, proofs in the appendix) was used for the proofs.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ❌ Intent lost. The general lower bounds, Theorems 5.4 and 6.11, are the paper's new topological results, and they are false: for the closed-above model generated by a single star (n ≥ 2), Theorem 5.4 claims that (n-1)-set agreement is impossible in one round, but consensus is solvable there. The claimed tight (n − s) bound for unions of stars does not follow either, since its γ^dist computation is wrong. All upper bounds (Theorems 3.2, 3.4, 3.7, 6.3–6.5, 6.7, 6.9, Corollaries 3.5, 3.8, Lemma 6.2) are correct, and the intended versions of Theorems 5.1 and 6.10 (k < γ(G), γ(G^r)) hold, by a short combinatorial argument instead of topology, but Theorem 5.1 is the bound the paper takes from prior work.

Mistakes in the paper

❌ Theorems 5.4 and 6.11 (general lower bounds, one and multiple rounds)

Theorem 5.4 is false for the closed-above model generated by a single star, for every n ≥ 2: it gives l = n − 2, so it claims (n−1)-set agreement is impossible in one round, but consensus is solvable there (theorem_5_4_false). Theorem 6.11 is false by the same example: products of stars are stars, so S^r = {G^r} with G^r a star, l = n − 2 for every r ≥ 1, and consensus is still solvable (theorem_6_11_false).

Impact. The paper's main lower bound for general closed-above models fails, and its multi-round extension with it; only the trivial bound "impossible for k < max_{G∈S} γ(G)" follows for general S (not_solvable_of_lt_domNum). The symmetric specialization (Corollary 5.5) loses its derivation, but is not refuted.

Details

Take S = {G}, where G is the star with center c: c sends to everybody, and the other processes send nothing. For a single graph, γ^dist({G}) = γ^eq(G) = n, because a set dominates the star iff it contains c. A non-dominating set P of size t hears only itself, so max-cov_t = t, M_t = n − t, and l = min(n − 2, n − 2) = n − 2. But every process hears c in every graph of ↑G, so "decide c's input" solves consensus in one round (Theorem 3.2 with γ(G) = 1). For n = 3 the theorem claims that 2-set agreement is impossible.

Where the proof breaks (Appendix B of the full version). Let the input facets φ_0, …, φ_t differ at a set P of t processes. The proof says ⋂ C_{G_i}(φ_i) is "either empty or a pseudosphere". It then uses the bound for the non-empty case only. When P contains a process heard by everybody, the intersection is empty. Lemma 4.17 needs it to be (l − t)-connected, and an empty complex is not. More conceptually, for a single graph γ^dist quantifies over all sets of a given size. So it reduces to the equal-domination number, while the tight single-graph bound (Theorem 5.1) is governed by the ordinary domination number γ(G) ≤ γ^eq(G).

The theorem is stated for general (non-symmetric) closed-above models, so Corollary 5.5 is not refuted by this example.

❌ Section 5 and Appendix G (γ^dist(S) = n − s + 1 for unions of s stars)

The computation γ^dist(S) = n − s + 1 for the symmetric model of unions of s stars is wrong: for s = 1, n ≥ 3 we have γ^dist(S) ≤ n − 1 (distDomNum_stars_le, distDomNum_stars_ne).

Impact. The claimed "tight" lower bound (n − s) for stars, and the proof of Theorem 6.13, do not follow from Theorem 5.4 even where that theorem might hold. Theorem 6.13 itself is not refuted.

Details

The argument picks one graph whose centers avoid P. But Definition 5.2 asks for min(i, |S|) distinct graphs. For s = 1 and n ≥ 3, a set of n − 1 processes misses only one possible center, so any two distinct stars include one whose center it contains. Hence γ^dist(S) ≤ n − 1 < n.

🔧 Section 3.2 (covering numbers of a star)

Section 3.2 says that "every covering number of a star equals 1"; in fact cov_i = i (star_cov_eq).

Impact. The conclusion drawn there still holds: n − cov_i = n − i ≥ γ^eq − i, so covering numbers do not improve the bound (star_example). The claims about the second graph of Figure 1 are correct (figure1_example).

✏️ Slips

  • Theorem 5.1 (k ≤ γ(G) should be k < γ(G)). Theorem 5.1 says k ≤ γ(G), which for k = γ(G) contradicts Theorem 3.2 (theorem_5_1_false). The text after Theorem 3.2 states the intended k < γ(G). We prove the corrected statement (theorem_5_1).

  • Theorem 6.10 (γ(G) − 1 should be γ(G^r) − 1). Theorem 6.10 is false as written: for the directed 3-cycle, γ(G) = 2, so it claims consensus is impossible in any number r > 0 of rounds, but after 2 rounds everybody has heard everybody (γ(G²) = 1) (theorem_6_10_false). The intended γ(G^r) is recoverable from Theorem 6.3 and Appendix E. We prove it (theorem_6_10); together with Theorem 6.3 it shows that γ(G^r) is tight (obliviousSolvable_up_iff).

  • Definition 6.1 reads "(u,v) ∈ Π ⟹ ∃w …"; it should read "(u,v) ∈ E ⟺ ∃w …".

Typos

  • Definition 6.8 uses "keq−dom(G)" for γ^eq(G).

  • Appendix C writes "max-cov_t({G}) = t" in the second case, which should be "> t".

Full list of differences (including modelling choices and minor imprecisions): differencies.md.

The formalizationmodel, Lean names of the results, trust

Model.

  • n = |α| processes (any Fintype), synchronous communication-closed rounds, no crashes. Each round's directed communication graph is chosen by an oblivious adversary from ↑S = {H | G ≤ H for some G ∈ S} (closed-above model). Graphs are Cslib.HeardOf.Graph α, with self-loops implicit (Hears), as the paper assumes.

  • One-round algorithms are full information: a decision map applied to the vector of received inputs (Cslib.HeardOf.msgs). r-round algorithms are oblivious (Definition 2.5): flood the known (process, input) pairs and apply a decision map to them after r rounds. These pairs are exactly the inputs of the in-neighbours in the product G₁ ⊗ ⋯ ⊗ G_r (known_eq_msgs).

  • k-set agreement: every decision is some process's input, and at most k distinct values are decided. Deterministic algorithms, no randomness.

  • Inputs: the upper bounds use any nonempty linearly ordered V (the paper assumes a total order). The lower bounds (Theorems 5.1, 6.10) assume at least n input values (α ↪ V); the paper does not fix the input set. The counterexamples work for every V.

  • The combinatorial numbers (γ, γ^eq, cov_i, γ^dist, max-cov_i, M_i, l, covering sequences) are defined literally as in the paper, with sInf/sSup over ℕ.

Not formalized. The combinatorial-topology part: Section 4 (pseudospheres, nerve lemma, Lemma 4.17, Theorem 4.12), Corollary 5.5 (lower bound for symmetric models) and Theorem 6.13 (stars). These are neither proved nor refuted; their proofs depend on the flawed argument of Theorem 5.4. A brute-force comparison of Corollary 5.5 with the paper's own upper bounds over all graphs with n ≤ 4 found no conflict. For s = 1, Theorem 6.13 is true, because one-round immediate snapshots embed into the model (not formalized); for s ≥ 2 its status is open.

Trust. No sorry; all listed theorems use only the axioms propext, Classical.choice, Quot.sound. The model reuses Cslib.HeardOf (Graph, Hears, msgs) from Cslib/Computability/Distributed/DynamicNetworks/HeardOf.lean. The corrected Theorem 5.1 is proved directly. Validity forces each process to decide an input it has heard. With pairwise distinct inputs, the processes whose inputs are decided then form a dominating set, so at least γ(G) values are decided. This also gives the tight characterizations oneRoundSolvable_up_iff and obliviousSolvable_up_iff.
