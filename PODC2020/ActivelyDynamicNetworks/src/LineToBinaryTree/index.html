The initial network is the line `0 - 1 - ⋯ - n` (`n + 1` nodes, diameter `d = n`) rooted at the endpoint `0`, each node knowing its parent. In every round, each node whose parent is not the root and whose grandparent has fewer than two children activates the edge to its grandparent and deactivates the edge to its parent; otherwise it does nothing. (The paper says a node repeats this "until" its grandparent has two children or it is attached to the root; the closed form below shows that a node that stops never satisfies the condition again, so the stateless rule used here has the same executions.) * `exec n r`: the snapshot after `r` rounds; `exec_zero` (the line), `isExec` (valid execution), `exec_eq` (closed form: the parent of `i` after `r` rounds is `i - 2^min(r, kk i)`). * `exec_stable`, `exec_succ_ne`: the algorithm stops changing the network exactly after `kk n ≤ ⌈log₂ d⌉` rounds (`kk_le_clog`). * `final_isDepthTree`, `final_edist`: the final network is the complete binary tree in level order: node `i` has depth `⌊log₂ (i+1)⌋`, the depth is `⌊log₂ (n+1)⌋`. * `childCount_le_two`, `degree_le_three`: in every snapshot every node has at most two children, hence degree at most `3`. * `activeEdges_le`, `numActivated_le`, `totalActivations_le`: at most `2(n+1) - 3` active edges during a round, at most `n - 1` activations per round, at most `(n-1)⌈log₂ d⌉` in total. -/ namespace Podc.ActivelyDynamicNetworks.LineToBinaryTree open SimpleGraph Cslib.DynNet.Active LineArith variable (n : ℕ) /-- The closed form: parent pointers after `r` rounds. -/ def QF (r : ℕ) (i : Fin (n + 1)) : Fin (n + 1) := ⟨Q r i, (Nat.sub_le _ _).trans_lt i.2⟩ /-- Number of children of `g` under the parent map `P`. -/ def childCount (P : Fin (n + 1) → Fin (n + 1)) (g : Fin (n + 1)) : ℕ := (Finset.univ.filter fun j => j ≠ g ∧ P j = g).card /-- The nodes that move in a round: parent not the root, grandparent with fewer than two children. -/ def movers (P : Fin (n + 1) → Fin (n + 1)) (u : Fin (n + 1)) : Prop := P u ≠ 0 ∧ childCount n P (P (P u)) < 2 instance (P : Fin (n + 1) → Fin (n + 1)) : DecidablePred (movers n P) := fun _ => by unfold movers;
