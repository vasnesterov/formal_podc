import Podc.Computability.Distributed.DynamicNetworks.ActivelyDynamic import Podc.Foundations.Combinatorics.SimpleGraph.ParentGraph /-! # Pointer jumping as rounds of an actively dynamic network Both basic subroutines of Michail–Skretas–Spirakis (PODC 2020, §2.3), TreeToStar and LineToCompleteBinaryTree, have the same per-node rule: a node of the current rooted tree that decides to move activates the edge to its grandparent (a potential neighbour) and deactivates the edge to its parent. If the set of moving nodes is `S` (non-root children only), the new parent map is `jump P S`. * `jumpAct P S` / `jumpDeact P S`: the edges activated / deactivated by the moving nodes. * `parentGraph_jump`: the snapshot after the round is `(E ∪ jumpAct) \ jumpDeact`, i.e. exactly the graph of the new parent map. * `validRound_jump`: this is a valid round of the model (`Cslib.DynNet.Active.ValidRound`): every activated edge joins two potential neighbours (common neighbour: the old parent). * `ncard_jumpAct_le`: at most `|S|` edges are activated. -/ namespace
