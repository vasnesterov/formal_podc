The Depth-`d` Tree problem asks to reconfigure the initial network into a rooted tree of depth `d` (`IsDepthTree`). The lower bounds below hold for **every** execution of the actively dynamic model (`Cslib.DynNet.Active.IsExec`), i.e. for any centralized strategy, started on a spanning line `pathGraph n`. They only use that the final snapshot has all nodes within distance `d` of some node `r` (so they hold for any target of radius `d`, tree or not). * `lemma_6_1` (Lemma 6.1 / D.2): `n - 1 ≤ 2^(T+1) · d`, since one round at most halves distances and the endpoints of the line start at distance `n - 1`. Corollaries: `lemma_6_1_log` (`⌊log(n-1)⌋ ≤ T + 1 + ⌈log d⌉`) and `lemma_6_1_asymp` (for `d ≤ ⌊log n⌋ + 1`: `⌊log n⌋ ≤ 2T + 7`, i.e. `T = Ω(log n)`). * `lemma_6_2_total` (Lemma 6.2 / D.3): `n - 1 ≤ (total activations) + 2d`, since each activated edge shortens a distance by at most one. No time bound is needed.
