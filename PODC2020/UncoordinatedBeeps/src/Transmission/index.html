Global rounds are integers; node `u` wakes up in global round `wake u`, and its local round `r_u ≥ 1` is the global round `g_u(r_u) = wake u + r_u - 1`. In an *uncoordinated transmission scenario* every node `u` starts a finite set `tx u` of codeword transmissions `(c, s)` (codeword `c` of length `l`, global start round `s ≥ wake u`); `u` beeps in global round `r` iff some transmission `(c, s) ∈ tx u` has `c[r - s] = 1`, i.e. a node transmitting several codewords beeps the bitwise OR of them. The history `H_v` of `v` records in each local round whether `v` or a neighbour beeped. Since a beeping node is awake and `v` listens only in its awake rounds, beeps are always delivered. The *conflict* at `v` and global round `r` is the number of distinct codeword transmissions `(c, s)` started in `v`'s closed neighbourhood within `l - 1` rounds of `r` (`s ∈ {r - l + 1, …, r + l - 1}`). -/ namespace Podc.UncoordinatedBeeps open Word /-- An uncoordinated transmission scenario with codewords of length `l` on the graph `G`. -/ structure Scenario (V : Type*) (l : ℕ) where /-- The (static) communication graph. -/ G : SimpleGraph V /-- The global wake-up round of each node. -/ wake : V → ℤ /-- The codeword transmissions `(codeword, global start round)` started by each node. -/ tx : V → Finset (Word l × ℤ) /-- Nodes only transmit when awake. -/ tx_awake : ∀ u, ∀ p ∈ tx u, wake u ≤ p.2 namespace Scenario variable {V : Type*} {l : ℕ} (S : Scenario V l) /-- The global round `g_v(r_v)` of local round `r_v` of `v` (local rounds start at `1`). -/ def g (v : V) (rv : ℤ) : ℤ := S.wake v + rv -
