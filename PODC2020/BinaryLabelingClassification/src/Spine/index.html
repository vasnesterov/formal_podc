import Papers.PODC2020.BinaryLabelingClassification.Families /-! # Solutions along a spine of relevant nodes Two combinatorial facts behind the `Ω(n)` lower bounds of §8, stated for an arbitrary graph with a path `w₀ – b₀ – w₁ – b₁ – ⋯` of relevant white (`w_k`) and black (`b_k`) nodes: * **V.a** (`W = 10⁺1`, `B = 010`): every relevant white node labels all its edges alike, and every relevant black node of degree 2 has exactly one edge in `X`. Hence the labels alternate along the spine: `x(w_{i+n}, b_{i+n}) = x(w_i, b_i) xor (n odd)` (`va_alternate`). In the paper's words, the degree-`d` nodes are properly 2-coloured. * **VI.b, easiest problem** (`W = 110⁺`, `B = 0⁺11`): read `X` as an orientation (edges in `X` from black to white); then every relevant node has at most one incoming edge, so along the spine, once an edge points right, all later edges point right (`dirR_mono`). -/ namespace Podc.BinaryLabeling open SimpleGraph variable {V : Type*} [Finite V] {G : SimpleGraph V} {x : V → V → Bool} lemma degX_eq_zero_iff {v : V} : degX G x v = 0 ↔ ∀ w, G.Adj v w → x v w = false := by rw [degX, Set.ncard_eq_zero (Set.toFinite _)] constructor · intro h w hw by_contra hc have : w ∈ {w | G.Adj v w ∧ x v w = true} := ⟨hw, by simpa using hc⟩ rw [h] at this; Edge `2k` is `w_k – b_k`, edge `2k + 1` is `b_k – w_{k+1}`. -/ def dirR (x : V → V → Bool) (w b : ℕ → V) (s : ℕ) : Bool := if s % 2 = 0 then !x (w (s / 2)) (b (s / 2)) else x (w (s / 2 + 1)) (b (s / 2)) /-- VI.b (easiest problem): at a relevant node, a right-pointing edge is followed by a right-pointing edge (at most one incoming edge). -/ lemma dirR_step (hsol : IsSolution (viEasy d δ hd hδ) G f x) (w b : ℕ → V) (s : ℕ) (hw : s % 2 = 1 → f (w (s / 2 + 1)) = true ∧ deg G (w (s / 2 + 1)) = d ∧ b (s / 2) ≠ b (s / 2 + 1)) (hb : s % 2 = 0 → f (b (s / 2)) = false ∧ deg G (b (s / 2)) = δ ∧ w (s / 2) ≠ w (s / 2 + 1)) (h1 : ∀ k, G.Adj (w k) (b k)) (h2 : ∀ k, G.Adj (b k) (w (k + 1))) (h : dirR x w b s = true) : dirR x w b (s + 1) = true := by unfold dirR at h ⊢ rcases Nat.mod_two_eq_zero_or_one s with hs | hs · obtain ⟨hbf, hbd, hne⟩ := hb hs have hs1 : (s + 1) % 2 = 1 := by omega have hdiv : (s + 1) / 2 = s / 2 := by omega simp only [hs, hs1, ↓reduceIte, hdiv, one_ne_zero] at h ⊢ have hB := hsol.2.2 _ hbf hbd simp only [viEasy, Set.mem_insert_iff, Set.mem_singleton_iff] at hB by_contra hc have hx1 : x (b (s / 2)) (w (s / 2)) = false := by rw [← hsol.1 (h1 _)];
