import Mathlib import Cslib.Computability.Distributed.Local.OnlineLocalLocality /-! # Binary labeling problems: definitions and Observation 3.2 Basic notions of *Classification of Distributed Binary Labeling Problems* (Balliu, Brandt, Efron, Hirvonen, Maus, Olivetti, Suomela; PODC 2020 brief announcement, full version arXiv:1911.13294v3). * `Problem`: a binary labeling problem `Π = (d, δ, W, B)` (§3.1). * An instance is a graph `G` with a proper 2-colouring `f : V → Bool` (`true` = white). * A candidate solution `X ⊆ E` is given as an edge labelling `x : V → V → Bool`: `x v w` is the label of the edge `{v, w}`; it has to be symmetric on edges (`IsSolution`). * Model of computing (§5): deterministic LOCAL with unique identifiers. Nodes are the elements of the type `V` (the identifiers), so a `T`-round algorithm is a function of the radius-`T` view (`Cslib.Local.IsLocal`). A *white algorithm* `A G f u w` gives the label that the white node `u` writes on its edge to `w` (`whiteOut`); a *black algorithm* is the same with black nodes deciding (`blackOut`). `WhiteSolvable Π V T`: some `T`-round white algorithm solves `Π` on every tree on `V` with every proper 2-colouring. * Observation 3.2 (combinatorial part: `isSolution_compl_iff`, `isSolution_swap_iff`; complexity part: `observation_3_2_compl`, `observation_3_2_swap`), Observations 3.4, 5.1, 5.2. -/ namespace Podc.BinaryLabeling open SimpleGraph Cslib.Local variable {V : Type*} /-- A binary labeling problem `Π
