This file formalizes the purely combinatorial part of the round elimination argument (§10.3, §10.5, §10.6): * Configurations of a node of degree `k` are tuples `c : Fin k → α`; the constraint only sees the multiset of labels `cfg c` (the paper's configurations are multisets). Constraints are therefore predicates on `Multiset α`. * Output problems (§10.3). For a set-valued configuration `Y : Fin k → Set α`, `allChoices C Y` (every choice `c i ∈ Y i` satisfies `C`) and `exChoice C Y` (some choice satisfies `C`). The black output problem of `(W, B)` has white constraint `exChoice W` and black constraint `allChoices B`; the white output problem is the colour-swapped construction. * Maximality (§10.3, "Simplification via maximality"): `Dom Y Z` (`Z` dominates `Y` up to a permutation of the ports) and `IsMaximal C Y`. * `Lbl`: the four labels `A, H, T, X` of FDSO(s) (Definition 10.6), and the renaming `ι` of the bold labels of Lemmas 10.8/10.9 as sets of labels: `A = {X}`, `H = {H, X}`, `T = {T, X}`, `X = {A, H, T, X}`. The bold labels are again represented by `Lbl`, via `ι`. Main results: * `lemma_10_8_black`, `lemma_10_8_white`: the black output problem of FDSO(s) is `Π₁ = (W₁, B₁)`. * `lemma_10_9_white`, `lemma_10_9_black`: the white output problem of `Π₁` is FDSO(s)
