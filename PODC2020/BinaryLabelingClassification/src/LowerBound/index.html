Nodes far (`≥ T`) from the four boundary nodes of the mirrored segment see the same radius-`T` view in both trees, hence produce the same output; but the spine order differs. * **Theorem 8.1 (V.a).** Labels alternate along the spine (`va_alternate`). Mirroring the segment `w_1 – ⋯ – w_{2T+4}` (`2T + 3` steps, an odd number) moves `w_{T+2}` to spine index `T + 3`, so the parity of its spine distance to the far node `w_{3T+5}` changes, while both nodes produce the same labels: contradiction. (The paper instead reduces 2-colouring of paths; the content is the same.) * **Theorem 8.2 (VI.b, easiest problem).** Edge directions are monotone along the spine (`dirR_mono`). With three far-apart white nodes `w_c`, `w_k`, `w_e` (`c < k < e`): if the edge right of `w_k` points left, mirroring around `w_c` makes `w_c` point right while `w_k` keeps a left-pointing edge; otherwise mirroring around `w_e` gives the symmetric contradiction. This is the paper's "mirror the subpath around `v₁` (or `v₄`)" argument, with the paper's reduction to the almost-oriented-path problem done inside the caterpillar.
