Space-Optimal Election in Anonymous Memory (Bezout) — PODC 2020

Emmanuel Godard, Damien Imbs, Michel Raynal, Gadi Taubenfeld. From Bezout's Identity to Space-Optimal Election in Anonymous Memory Systems. PODC 2020. DOI 10.1145/3382734.3405727. Formalized version: the proceedings text (HAL hal-03148627); there is no arXiv version. Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. All results are proved: Theorems 1, 2 and 4, and Corollaries 1–3 as iff characterizations. But the termination proofs of Algorithms 1 and 2 and the safety proof of Algorithm 2 are sketches whose missing steps took new arguments and invariants.

Mistakes in the paper

✏️ Slips

  • Section 4: "both u′ and v′ are positive" fails for m = 1, n = 2, (u, v) = (−1, 1), where v′ = 0 (v_prime_zero_example). The same paragraph starts with "v′ is positive or null"; only v′ ≥ 0 is needed, and that holds (paper_rewrite).

  • The proof of Theorem 2 says line 8 "leaves REG.id = id_ℓ", but the code writes ⊥; we follow the code.

  • In the proof of Claim 1, loser_i "false" should be "true".

  • Section 5.2, Case 1: "jumps to the level" where the code increments by one.

Typos

  • Algorithm 2: reg_i.discarded should be reg_i[x].discarded.

  • Sections 3.2, 5.2, 5.3: wrong line references (N(2)/N(3) instead of N(5)/N(6), N(3) instead of N(4); "the predicate of line 16" means lines 5–6).

Proof gaps in true statements (4)Theorem 2 · Lemma 2 · Lemma 1 · Theorem 1

🛠️ Theorem 2 (Algorithm 1, termination proof)

"This pattern is repeated until all processes except one are losers" does not explain why two candidates cannot overwrite each other forever while losers keep re-announcing their loss.

Impact. Statement true; repaired (Alg1.alg1_terminates, Alg1.alg1_agreement).

Details

The missing step is a "minimal discarded set" argument. Once the candidates and their sets are stable, any ⊥-value a candidate c′ reads was written by a loser j who had read another candidate c's value without j in it, so D_c ⊊ D_{c′}. This is impossible for the candidate with the smallest set. The committing phase needs "quiet" losers: once the leader knows j, j never writes again. Line 16 copies REG.discarded without checking its phase; the paper ignores this, and it turns out to do no damage.

🛠️ Lemma 2 (safety of Algorithm 2)

The proof reuses Claim 1 of Algorithm 1 for each competition, which does not cover writes decided from an earlier, non-atomic collect, and the counting behind "exactly d leaders" is missing.

Impact. Statement true; repaired (theorem_4, Alg2.alg2_agreement).

Details

In Algorithm 2 a process decides a write from a copy read in an earlier, non-atomic collect, and the write can land much later. The property really needed is that a write for level L never lands after the register has reached level L + 1. Proving it takes a per-register invariant over every process's status for that register. For the count: when the first process sets finishing, every process has already won exactly v ℓ competitions, because the collected sum of levels never exceeds the true sum, levels being monotone.

🛠️ Lemma 1 (termination of Algorithm 2)

The one-paragraph proof asserts that all competitions with a candidate terminate, without handling candidate sets that change over time or showing that some open register keeps a stable candidate.

Impact. Statement true; repaired (theorem_4, Alg2.alg2_terminates).

Repair

Our termination proof shows that once solved competitions stop increasing, the candidate flags, to_win and finishing stabilize. It then finds an open register with a stable candidate, using d ≤ n, and replays Algorithm 1's convergence argument there.

🔧 Theorem 1 (lower bound, "at the same state")

The proof says that processes of a group with the same number of steps are "in the same state", but literally they differ by their identifiers and are in the same state only up to a renaming of identifiers.

Impact. Statement true; repaired (theorem_1_1, theorem_1_2).

Details

The proof fixes the anonymity permutations lazily, through "the k-th new register pᵢ accesses". This is legitimate without snapshots, and the paper explains it.

Repair

We fix the permutations in advance (process i of each group sees the memory rotated by i·m/δ), which also covers snapshots.

The formalizationmodel, Lean names of the results, trust

Model.

  • Asynchronous shared memory (CSLib Impl), fault-free, deterministic processes. All n processes participate: each invokes elect() exactly once.

  • Termination: in every fair infinite execution where all processes invoke, every process returns. Fair means a pending process eventually takes a step.

  • Anonymous memory of m registers, all with the same initial value. Each process has its own adversarial permutation of the register names, fixed for the run (CSLib SymAlg.impl). Lower bounds allow arbitrary read-modify-write accesses and atomic snapshots. The algorithms use plain reads and writes only (ReadWrite), and Algorithm 2's collect is m separate reads.

  • Symmetry ("identifiers compared only for equality") is semantic. The algorithm commutes with every renaming of identifiers, and the initial register value is not an identifier.

  • Outputs are bits ("am I elected?") for DElection d / ExactElection d. This is weaker than the paper's leader-set outputs, so the impossibility is stronger. The algorithms are also proved to agree on the leader set itself.

  • Lower bounds need correctness for every permutation choice but only one injective identifier assignment.
