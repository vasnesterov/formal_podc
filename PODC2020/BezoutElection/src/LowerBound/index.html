Let `δ = gcd(m, n)`. Split the `n` processes into `k = n/δ` groups of `δ` processes; the `i`-th member of every group sees the anonymous memory rotated by `i · (m/δ)` and has identifier `τ^i` applied to the identifier of the first member, where `τ` cycles every group. In the lock-step execution (`exists_symmetric_outcome`) all members of a group return the same bit, so the number of elected processes is a multiple of `δ` (`exists_elected_mul`). Hence a terminating symmetric `d`-election algorithm needs `δ ≤ d` (Theorem 1(1)) and an exact `d`-election algorithm needs `δ ∣ d` (Theorem 1(2)). The result holds for arbitrary read-modify-write registers *and* atomic snapshots of the whole anonymous memory, for any register values and local states, and it uses a single injective identifier
