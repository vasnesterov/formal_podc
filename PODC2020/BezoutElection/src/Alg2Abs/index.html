import Papers.PODC2020.BezoutElection.Alg2 /-! # Algorithm 2: the per-register abstraction Godard, Imbs, Raynal, Taubenfeld, PODC 2020, Section 5. Fix one physical register `x`. What happens at `x` is Algorithm 1 (with levels): every process alternates between reading `x` (during a collect), *processing* its copy of `x` later in its for loop (lines N(6)–N(19) for the local name of `x`), and possibly writing `x`. We abstract a configuration to * the value `reg` of `x`; * for every process its local variables for `x` (`ph`, `D`, `lo`, `lv`, `ca`: `phase`, `discarded`, `loser`, `level`, `candidate` at the local name of `x`) and its *status* for `x` (`fresh`: it will read `x`; `copy v`: it read `v` and has not processed it yet; `pend w`: it will write `w`). Abstract steps (`AStep`): `read`, `proc` (processing a copy; the global parts of the candidacy predicate of line M(10) and the flag `finishing` are arbitrary oracles `ok`, `fin`) and `write`. -/
