Fault-Tolerance in Distributed Optimization: The Case of Redundancy — PODC 2020

Nirupam Gupta, Nitin H. Vaidya. Fault-Tolerance in Distributed Optimization: The Case of Redundancy. PODC 2020. DOI 10.1145/3382734.3405748. Formalized version: the proceedings version (there is no arXiv version). Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. Theorem 2 (linear convergence of gradient descent with the CGC filter under 2f-redundancy) is fully proved; its part (i) ρ ≥ 0 fails only when W* = ℝ^d. Theorem 1 ("2f-redundancy is necessary") is under-specified: read literally it is vacuous, and read as what its proof shows (indistinguishability) it is true and tight, provided exactly f agents are faulty, n > 2f and the honest costs share a minimum point; we prove this repaired form in both directions. So the necessity half of the paper holds only in this weaker, per-execution form.

Mistakes in the paper

⚠️ Theorem 1 ("2f-redundancy is necessary"; under-specified)

Definition 2 does not say on which inputs the algorithm must be correct, so Theorem 1 is vacuous when read literally and true only when read as what its proof shows, indistinguishability (theorem1, theorem1_indistinguishable).

Impact. Necessity survives only per execution: the indistinguishability reading is true and tight, provided exactly f agents are faulty (see the next item), n > 2f and the honest costs share a minimum point; we prove this repaired form in both directions.

Details

There are three readings.

  • (a) Literal: vacuous. The proof turns the faulty agents' functions into honest functions of a second execution, so it asks for correctness on all executions. In that model no deterministic algorithm is f-resilient once f ≥ 1, so "f-resilient ⇒ 2f-redundant" holds trivially. Even a 2f-redundant execution is confused there. Example: n = 3, f = 1, received x², x², (x−2)²; honest agents {0, 1} (minimum 0) vs. {1, 2} (minimum 1). The partner x², (x−2)² has no common minimum point. (theorem1, no_resilient_allExecs, redundant_execution_confusable)

  • (b) Sharp: false, but not claimed by the paper. "An algorithm that is f-resilient on all 2f-redundant inputs cannot also be f-resilient on a non-redundant input." Counterexample in the paper's sensing setting: n = 3, f = 1, honest costs x² and y² on ℝ². More generally, any execution whose honest costs share a minimum point can be added to the 2f-redundant class. The paper never states this reading, so it is not an error of the paper. It does show that 2f-redundancy is not a maximal solvable class. (sharp_necessity_false, exists_resilient_redundant_insert)

  • (c) Indistinguishability: true and proved. This is what Part II actually shows. Let f ≥ 1, 2f < n, exactly f agents faulty, and suppose the honest costs share a minimum point. Then the execution is not 2f-redundant iff the faulty agents can send convex differentiable functions such that another execution yields the same received vector, has honest costs with a common minimum point, and has a solution set disjoint from the true one. Then no deterministic algorithm is correct on both. The (⇒) direction is the paper's construction with C_B = ‖x − ŵ‖². For (⇐), the two honest sets share ≥ n − 2f agents, and the partner's common minimum point solves that subset, hence by 2f-redundancy the true execution. (theorem1_indistinguishable)

⚠️ Theorem 1, Part II of the proof (exactly f faulty agents)

Part II assumes exactly f faulty agents ("Then |H| = n − f"), and with fewer faults reading (c) is false: n = 3, f = 1, no faulty agent, costs x², y², x² + y² on ℝ² (theorem1_indistinguishable_false_fewer_faults).

Impact. Under reading (c) "up to f" is not saved; the repair is "exactly f faulty agents", the case the proof treats.

Details

In the counterexample the execution is not 2f-redundant, yet every execution producing the same received vector has the origin as a solution.

✏️ Slips

  • Theorem 1 needs n > 2f, which the proof uses but the statement omits, and it is false for n = f = 1 (theorem1_false_n_eq_one). Definition 1 then includes the empty subset, so a single honest agent with cost x² violates 2f-redundancy, while "output a minimum point of the received function" is f-resilient.

  • "2f-redundancy implies n > 2f" (Appendix B) does not follow from Definition 1.

  • Theorem 2 (i), ρ ∈ [0, 1), fails when W* = ℝ^d (e.g. all honest costs constant): with n = 3, f = 1, μ = 1, λ = 30, η = 29/3 < η̄ = 58/3 we get ρ = −840 (theorem2_rho_nonneg_false). Appendix B derives λ ≤ μ from a point outside W*; without one, λ is unconstrained. Part (ii) is trivially true there, and (i) holds under W* ≠ ℝ^d (theorem2_rho_nonneg).

  • Existence of minimum points is assumed tacitly. Definition 2 and the projection in Assumption 4 need W* ≠ ∅.

  • Theorem 2, step (29) ⇒ (30) ("every honest gradient vanishes on W*") needs f ≥ 1 and fails for f = 0. Theorem 2 still holds for f = 0 via the Lipschitz bound on the aggregate gradient (Assumptions.key_estimates).

The formalizationmodel, Lean names of the results, trust

Model.

  • Theorem 1 model. This is the paper's "best case for the server". There are n agents and at most f Byzantine ones. The server gets one cost function per agent and applies a deterministic map alg. Honest agents send their own convex differentiable cost; faulty agents send arbitrary convex differentiable functions. f-resilience is relative to an explicit class K of executions (honest set + honest costs). AllExecs contains all executions with ≤ f faults whose honest aggregate has a minimum point; RedExecs is its 2f-redundant part. Protocol.resilient_toAlg transfers the impossibility to every deterministic interactive protocol in which a Byzantine agent can mimic an honest one.

  • Theorem 2 model. The system is synchronous and server-based. In each iteration honest agents send ∇Q_i(w^t), and faulty agents send arbitrary vectors (adaptive adversary; a missing gradient is one such choice). The CGC filter scales the f largest vectors down to the (n−f)-th smallest norm (defined as an order statistic, independent of tie-breaking), and w^{t+1} = w^t − η Σ ĝ_j. The paper's termination rule is the case "threshold = 0", in which the update is the identity.

  • Space. Costs live on a real inner product space, which includes ℝ^d. The space is complete for Theorem 2. Lemma 1 and the sufficiency results hold for arbitrary functions on any type.

  • [w]_{W*} is any nearest-point map onto W* (unique), and it exists whenever W* ≠ ∅.

Trust. No sorry; all listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity of Theorem 2: example_assumptions instantiates all hypotheses with one Byzantine agent (n = 4, f = 1, costs x²/2, α = 1/12, ρ = 15/16). exists_proj shows that the projection field can always be filled. The counterexamples are explicit instances on ℝ and ℝ × ℝ. The model is self-contained (Mathlib, plus the shared quorum arithmetic Cslib/Foundations/Data/Finset/Quorum.lean). CSLib's Byzantine message-passing models were not needed, because the paper argues in a one-shot model. Unlike PODC2013/ByzantineVectorConsensus (inputs are points, validity is a convex-hull condition), the inputs here are cost functions, so no code is shared. CSLib candidates:

  • mem_argmin_iff_of_hasFDerivAt;

  • the order statistic threshold with threshold_spec.

The first-order condition (ConvexOn.add_fderiv_le / ConvexOn.add_inner_le) and finite sums of convex functions (ConvexOn.fun_sum, used by convexOn_agg) are shared code in CSLib, Cslib/Foundations/Analysis/Convex/FirstOrder.lean.
