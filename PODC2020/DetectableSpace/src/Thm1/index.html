Let `A` be an obstruction-free implementation of the CAS object `casRC V v₀` (operations `read` and `cas old new`) for `N = Fintype.card P` processes, which is durably linearizable and detectable (`DurLinDet`), where `V` has at least `N` values. Then the set of shared-memory states of reachable configurations has at least `2 ^ (N - 1)` elements, i.e. `A` has `2 ^ (N - 1)` reachable configurations no two of which are memory-equivalent. Only the *shared* non-volatile memory is counted (private NVM and local states are not), which is what the paper claims. `theorem1_bits`: any encoding of the reachable shared-memory states into `b` bits that is injective satisfies `N - 1 ≤ b`. **Proof.** The paper argues by induction on `N`, applying the induction hypothesis to an algorithm obtained by "fixing `C_ns` as an initial configuration" and halting `p_N`. We unroll this induction into an explicit construction (`Gadget`): processes `p 0, …, p (m-1), q` (`m = N - 1`), values `w 0 = v₀, …, w m`, and at level `i` the operation `c i = cas (w i) (w (i+1))`. For a branch vector `b`, level `i` (`lvl`) runs: `p i` invokes `c i` and takes `k` solo steps, then `q` runs `c i` solo to completion. Let `mstar` be the least `k` after which `q`'s `c i` returns `false` (it exists by obstruction-freedom, and `mstar ≥ 1`); branch `b i = false` takes `mstar - 1` steps (`q` returns `true`), branch `b i = true` takes `mstar` steps (`q` returns `false`). The `mstar`-th step of `p i` (the *modifying step* `s`) changes the shared memory (otherwise `q` could not tell the difference, `qr_eq_of_sh`), so it is a shared-memory step: `p i` is still running and its private memory is the same in both branches (`s_step`, `level_pv`). Linearizability facts about the chain of `cas` operations (`run_ge`, `run_up`, `run_after`, `lin_first`, `lin_second`) determine `q`'s responses. If two branches first differ at level `j` and end in configurations with the same shared memory, then after a system-wide crash the recovery of `p j` returns the same value in both (`crash_recover`), but it must not return `true` in the branch where `q`'s level-`j` operation succeeded (`lin_final_ns`) and must return `true` in the other one (`lin_final_s`) — a contradiction (`distinct_aux`). Hence the `2 ^ m` branches give pairwise different shared memories (`lower_bound`). Compared with the paper's text: the existence of the modifying step needs that `q`'s `c i` returns `true` when `p i` has invoked its operation but taken no step; this is shown by transferring `q`'s solo run from the configuration before `p i`'s invocation (`qr_zero`), since a pending operation of `p i` could otherwise be linearized before `q`'s. The induction hypothesis of the paper is applied to a configuration which is not initial (with `p_N` pending and the domain restricted to `V \ {0}`); the unrolled construction makes this step precise.
