Toggle indices `0, 1` are `false, true`; `1 - b` is `!b`. * Private non-volatile memory of `p`: `Ann_p.CP` (`cp`), `Ann_p.result` (`res`, `none` = `⊥`), `RD_p` (`rd`, `none` = `⊥`) and `T_p` (`T`, initially `0`). At invocation the system sets `Ann_p.CP := 0` and `Ann_p.result := ⊥` (`aux`). * `R` is initially `⟨v_init, 0, t₀⟩`. The paper has `t₀ = 0`; we show that this is incorrect (`Alg1Counter.lean`) and that `t₀ = 1` is correct (`Alg1Fix.lean`).
