Doubly-perturbing objects (Definition 3, Lemmas 3–8) Sequential histories are lists of pairs `(process, operation)`; the sequential specification does not depend on processes, which only matter for "by a different process" and "`p`-free". * `PerturbingWrt O H p o p' o'` — `o` by `p` is perturbing w.r.t. `o'` by `p' ≠ p` after `H`; * `DPWitness O p o`, `DoublyPerturbing O P` — Definition 3; * Lemma 3 (`register_doublyPerturbing`), Lemma 5 (`counter_doublyPerturbing`, also for the bounded counter `bcounter 2`), Lemma 6 (`cas_doublyPerturbing`), Lemma 7 (`faa_doublyPerturbing`), Lemma 8 (`queue_doublyPerturbing`); * Lemma 4 (`maxReg_not_doublyPerturbing`): a max register is not doubly-perturbing. -/ namespace Papers.PODC2020.DetectableSpace open Cslib.SharedMemory variable {P : Type} /-- State after a sequential history. -/ def stateAfter (O : ObjSpec) (H : List (P × O.Op)) : O.State := O.runOps O.init (H.map Prod.snd) /-- Response of `o` after the sequential history `H`. -/ def respAfter (O : ObjSpec) (H : List (P × O.Op)) (o : O.Op) : O.Resp := (O.δ (stateAfter O H) o).2 /-- `o` by `p` is perturbing with respect to `o'` by a different process `p'` after `H`: `o'` returns different responses in `H ∘ o ∘ o'` and in `H ∘ o'`. -/ def PerturbingWrt (O : ObjSpec) (H : List (P × O.Op)) (p : P) (o : O.Op) (p' : P) (o' : O.Op) : Prop := p' ≠ p ∧ respAfter O (H ++ [(p, o)]) o' ≠ respAfter O H o' /-- `o` by `p` is perturbing after `H`. -/ def Perturbing (O : ObjSpec) (H : List (P × O.Op)) (p : P) (o : O.Op) : Prop := ∃ p' o', PerturbingWrt O H p o p' o' /-- `o` by `p` witnesses that `O` is doubly-perturbing (Definition 3): there are `H₁` and `o_r` by `r` such that `o` is perturbing w.r.t. `o_r` after `H₁`, and a `p`-free extension `E` of `H₁ ∘ o ∘ o_r` after which `o` is perturbing again. -/ def DPWitness (O : ObjSpec) (p : P) (o : O.Op) : Prop := ∃ (H₁ : List (P × O.Op)) (r : P) (o_r : O.Op), PerturbingWrt O H₁ p o r o_r ∧ ∃ E : List (P × O.Op), (∀ x ∈ E, x.1 ≠ p) ∧ Perturbing O (H₁ ++ [(p, o), (r, o_r)] ++ E) p o /-- Definition 3: `O` is doubly-perturbing (for the process set `P`). -/ def DoublyPerturbing (O : ObjSpec) (P : Type) : Prop := ∃ (p : P) (o : O.Op), DPWitness O p o lemma stateAfter_append (O : ObjSpec) (H H' : List (P × O.Op)) : stateAfter O (H ++ H') = O.runOps (stateAfter O H) (H'.map Prod.snd) := by simp [stateAfter,
