import Papers.PODC2020.DetectableSpace.Lin import Papers.PODC2020.DetectableSpace.Perturbing /-! # Algorithm 2: a bounded-space detectable CAS object (Section 4.1) The shared variable `C` (supporting read and CAS primitives) stores the value of the implemented object together with a bit vector `vec : P → Bool` (one bit per process). Process `p` has a private non-volatile announcement structure `Ann_p` (fields `CP` and `result`, written by the system at invocation: `Ann_p.CP := 0`, `Ann_p.result := ⊥`) and a private non-volatile register `RD_p`. Pseudocode (code for process `p`); every numbered line that accesses memory is one atomic step, purely local computations (lines 29, 32) are merged with the preceding step: ``` Cas(old, new): Cas.Recover(old, new): 28 ⟨val, vec⟩ := C 38 if Ann_p.result ≠ ⊥ then 29 if val ≠ old then 39 return Ann_p.result 30 Ann_p.result := false 40 if Ann_p.CP = 0 then 31 return false 41 return fail 32 newvec := flipBit(vec, p) 42 ⟨val, vec⟩ := C 33 RD_p := newvec[p] 43 if vec[p] ≠ RD_p then 34 Ann_p.CP := 1 44 return fail 35 res := C.CAS(⟨val,vec⟩, ⟨new,newvec⟩) 45 Ann_p.result := true 36 Ann_p.result := res 46 return true 37 return res ``` `Read`: read `C`, persist the value in `Ann_p.result`, return it. `Read.Recover`: if `Ann_p.result ≠ ⊥` return it, otherwise re-execute `Read`. Note: the paper's proof of Lemma 2 says that when `Ann_p.CP = 0` "Cas.Recover simply re-invokes Op (line 41)", but the code (line 41) returns `fail`; we follow the code. `alg2Gen fix v₀` is Algorithm 2 (`fix = false`, `alg2`) or our corrected version (`fix = true`, `alg2fix`): there, `Cas(old, new)` with `old = new` reads `C` once, persists `result := (val = old)` and returns it, never writing `C`. The initial value of `RD_p` (`⊥` in the paper) is modelled as `false`; it is irrelevant since `RD_p` is only read when `Ann_p.CP = 1`, i.e. after line 33 of the current operation. -/ namespace
