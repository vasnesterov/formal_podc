import Papers.PODC2020.DetectableSpace.Alg2Defs /-! # Algorithm 2 is not linearizable when `Cas(v, v)` is allowed Two processes `p ≠ q` both invoke `Cas(v₀, v₀)` on the initial object (value `v₀`). Both read `C = ⟨v₀, 0…0⟩` at line 28; `p` completes its operation (its hardware CAS at line 35 succeeds, flipping `vec[p]`, the value stays `v₀`) and returns `true`; then `q`'s hardware CAS fails because `vec[p]` changed, and `q` returns `false`, although the value of the object was `v₀` throughout. The (crash-free!) history is `inv₀ p Cas(v₀,v₀)`, `inv₁ q Cas(v₀,v₀)`, `res₀ true`, `res₁ false`, and it has no linearization: every `Cas(v₀, v₀)` applied to the state `v₀` returns `true` and leaves the state `v₀`.
