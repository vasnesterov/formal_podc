The state is a pair `(token, bit)` of functions `ℕ → Bool`. A step on the edge `t → succ t` is Protocol 3 of the paper (SS-Token, from Angluin et al.): a non-leader successor copies a different bit and takes the token; the leader flips its bit when it equals its predecessor's and takes the token. In both cases the successor's bit is negated. * `run_legit`: stepping along the ring `0, 1, 2, …` for `2N + p` steps from **any** state yields the legitimate state `Legit p b` (one token at `p`, bits `b` up to `p`, `¬b` after). * `Legit.step`: a step in a legitimate state either moves the token one position forward (on the token's edge) or changes nothing. -/ namespace SSLERegular.TokenRing /-- Successor position on the ring of size `N`. -/ def succP (N t : ℕ) : ℕ := if t + 1 = N then 0 else t + 1 /-- Does SS-Token fire on the edge `t → succP N t`? -/ def Fires (N : ℕ) (bt : ℕ → Bool) (t : ℕ) : Prop := (succP N t ≠ 0 ∧ bt (succP N t) ≠ bt t) ∨ (succP N t = 0 ∧ bt t = bt (succP N t)) instance (N : ℕ) (bt : ℕ → Bool) (t : ℕ) : Decidable (Fires N bt t) := by unfold Fires;
