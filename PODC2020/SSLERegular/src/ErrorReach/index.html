Proof: 1. *Spread*: a flagged initiator may raise the flag of its responder (`RandBit2 = true`) while staying flagged (`RandBit1 = true`); along walks, all nodes become flagged. 2. *Prepare the root*: pick an edge `r — v`; let `r` take a state whose colour is `D v`'s `prevColor` and whose predecessor/successor colours all avoid `D v`'s colour (`RootOK`). 3. *Finalize* every node `x ≠ r` in order of decreasing distance from `r`, as initiator with a neighbour closer to `r` as responder: `x` takes the state `D x`; the responder stays flagged and (SS-TwoHop keeps colours) keeps its skeleton, so `r` stays `RootOK`. 4. *Last interaction* `(r, v)`: there is no virtual edge between `r` and `v`, so the ring part leaves `v` untouched and flags `r`; `r` takes `D r` and `v` gets exactly `D v`'s
