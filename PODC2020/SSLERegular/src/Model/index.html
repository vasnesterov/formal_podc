import Cslib.Computability.Distributed.PopulationProtocols.Nondet import Mathlib.Combinatorics.SimpleGraph.Finite /-! # Population protocols on graphs (Chen–Chen, PODC 2020, Section 2) Hsueh-Ping Chen and Ho-Lin Chen, *Self-Stabilizing Leader Election in Regular Graphs*, PODC 2020, Section 2. * A protocol (`GProtocol Q`, the shared nondeterministic model `Cslib.PopulationProtocol.NProtocol` of `Cslib.Computability.Distributed.PopulationProtocols.Nondet`) has a **nondeterministic** transition function `δ : Q → Q → Set (Q × Q)`: `(r, s) ∈ δ p q` iff an initiator in state `p` and a responder in state `q` may move to `(r, s)`. Randomized rules of the paper ("`u ← RandState`", "randomly do …") are modelled by their support, which is all that matters under global fairness and, for finite state spaces, for "probability 1" statements (`Cslib.Computability.Distributed.SelfStabilization.Markov`). * A configuration is `V → Q`; a step lets two **adjacent** nodes `u, v` of the communication graph `G` interact, `u` as initiator, `v` as responder (`GProtocol.Step`, i.e. `NProtocol.StepOn G.Adj`). Both orders are scheduled. Runs and global fairness are those of `Cslib.TransitionSystem`. * `OutputStable`, `ValidStable` (output-stable with exactly one leader), `SolvesSSLE` (paper's definition: every globally fair execution reaches a valid output-stable configuration), and `SelfStab` (from every configuration a valid output-stable configuration is reachable). * `solvesSSLE_iff`: `SolvesSSLE ↔ SelfStab` (finite state space, at least one edge), and `selfStab_iff_selfStabilizes`: `SelfStab` is `Cslib.TransitionSystem.SelfStabilizes` for the set of valid output-stable configurations. * `derc_lemma`: Lemma 2.1 (detect-error-and-random-change), with the hypotheses that the paper states only in the surrounding text made explicit. -/ open Finset Cslib.PopulationProtocol Cslib.TransitionSystem namespace
