import Papers.PODC2020.InfiniteArrivalHierarchy.Objects /-! # Algorithm 3 of Perrin–Mostéfaoui–Bonin (PODC 2020): multi-valued from binary consensus in `M₃` Shared infinite arrays `proposed[j]` (registers over `Option V`, initially `none`), `isSet[j]` (registers over `Bool`, initially `false`) and `cons[j]` (binary consensus objects). Code of `p_i` with input `val_i`: ``` proposed[i] ← val_i; isSet[i] ← true; for j = 0, 1, 2, …: b ← isSet[j]; if cons[j].propose(b) then return proposed[j] ``` Each step of the model is exactly one shared access (`Loc` is the program counter). The paper gives no proof (Proposition 3). Our proof: agreement/validity from an invariant (`GInv`): a decided value is `val_j` for the least `j` with `cons[j] = true`, and `cons[j] = true → isSet[j] = true`. Wait-freedom: `cons[j]` is decided `false` only by a process `q` that read `isSet[j] = false` after setting its own flag (ghost `FlagBefore`), so the process whose flag was set first never sees its `cons` decided `false` (`consR_ne_false_of_first`); a process that never decides passes all rounds, contradiction. ## Main statements * `alg3_solvesCons`: Proposition 3 (core): Algorithm 3 solves consensus in `M₃`. * `alg3_poised_lt`: with `n` processes, only objects of index `< n` are ever accessed. * `alg3_solvesCons_bounded`: Algorithm 3 solves consensus in `Mⁿ₁`. -/ namespace
