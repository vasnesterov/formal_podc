import Papers.PODC2020.InfiniteArrivalHierarchy.Objects /-! # Partitioned executions (Definition 4) for Proposition 4 Infrastructure for the proof of Proposition 4 of Perrin–Mostéfaoui–Bonin (PODC 2020): binary consensus objects (`consObj Bool`, indexed by `ιc`) and window registers (`windowObj (W j) (w j)`, indexed by `ιw`), processes `ℕ` with input `p` for process `p`. A partition of the processes is given by class labels `cls : ℕ → ℕ`. A set `U` of processes is *saturated* (`Sat cls U`) if it is a union of classes. The *restriction* of an execution `σ` to `U` is `σ.filter (· ∈ U)` (`rexec A U σ` is its final configuration). Definition 4 of the paper (`α` is `Π'`-partitioned: the restriction to every class is a valid execution in which the processes of the class have the same local states) is strengthened here to the invariant `Inv`: * `loc`: for **every** saturated `U` (union of classes), the processes of `U` have the same local states in the restriction to `U` as in the real execution. (The paper only asks this for single classes; unions are needed when classes are merged, see `differencies.md`.) * `untouched`: the objects outside the set `X` of "used" objects are in their initial state in the real execution and in every restriction; * `good`: every binary consensus object `j ∈ X` is undecided-as-initially or decided `dv j` (in the real execution and in every restriction), where `dv j` is the initial decision if any and the value `b j` proposed by the processes covering it otherwise. Steps preserving the invariant (`Inv.step`): writes on window registers of `X`, proposals of `b j` on consensus objects of `X`, and any operation on an object of `X` whose state is the same in the real execution and in all restrictions containing the stepping process (and is decided, for consensus objects). -/ namespace Podc.InfiniteArrivalHierarchy.Prop4 open Cslib.SharedMemory
