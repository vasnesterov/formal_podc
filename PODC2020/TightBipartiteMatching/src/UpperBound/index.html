For `1 ≤ y ≤ d`, `x ≤ Δ = d + 1`, the encoded bipartite `x`-maximal `y`-matching problem `Φ^W_Δ(x, y)` can be solved by a white algorithm in `T_Δ(x, y)` rounds in the port-numbering model, on every `Δ`-regular port-numbered (multi)graph with a given proper 2-colouring. The algorithm is the proposal algorithm of `UpperBoundRun` (`k = ⌈(Δ - x)/y⌉`): * if `⌈(Δ - x)/y⌉ < ⌈Δ/y⌉`: white nodes are active in rounds `0, 2, …`, and we run `2k` rounds; * otherwise: black nodes are active in rounds `0, 2, …`, and we run `2k - 1` rounds (this solves the `x = 0` problem). At the end, a white node outputs (`out`): `M` on its matched ports and `O` elsewhere; if it is unmatched but has received proposals (in the last round) it accepts one of them (`M` there, `O` elsewhere); otherwise it outputs `P` on the ports over which it proposed and `X` elsewhere (first case), or `P` on all ports (second case: then all its neighbours are matched). -/ namespace
