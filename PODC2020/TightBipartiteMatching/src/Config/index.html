A node holding the port-indexed tuple `f : Fin Δ → L` has configuration `mset f`. * A *condensed configuration* `[S₁]^{n₁} ⋯ [S_r]^{n_r}` (a "regular expression" in the paper) is a list of blocks `(S_i, n_i)`; it generates the multisets `m₁ + ⋯ + m_r` with `|m_i| = n_i` and all elements of `m_i` in `S_i` (`Cond.Gen`). A constraint is a finite union of these (`Cond.Gens`). Generic tools: * `rel_mset_iff`: choices of one element per set ↔ `Multiset.Rel`; * `Cond.gen_lift`: existential lifting of a condensed configuration along a relation (the computation behind Observation 2.2); * `exists_perm_lt_card`: sort ports by a key (used to build configurations with exact label counts); * label counting for the five labels of the paper. -/ -- CSLib candidate
