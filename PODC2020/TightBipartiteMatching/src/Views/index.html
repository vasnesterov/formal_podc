import Papers.PODC2020.TightBipartiteMatching.Config /-! # Views in the 2-coloured `Δ`-regular port-numbered tree We model deterministic `t`-round algorithms in the port-numbering model on 2-coloured `Δ`-regular trees (no identifiers, no inputs except the colour, which is implicit) as functions of the radius-`t` view, as is standard for round elimination (§2.2). Throughout `Δ = d + 1`. * `Br d t` is a *branch of depth `t`*: what a node sees behind one of its ports. A branch of depth `t + 1` consists of the port number `j` of the edge at the far endpoint `w` and, for each other port of `w` (indexed by `c : Fin d` via `j.succAbove c`), a branch of depth `t`. * `View d t = Fin (d + 1) → Br d t` is the radius-`t` view of a node: everything within distance `t`, including the port numbers of all edges with at least one endpoint at distance `< t`. This is exactly the information a node can gather in `t` rounds in a tree (see `Bridge.lean` for the connection with CSLib's message-passing algorithms). * `nbrView t V k : View d t` is the radius-`t` view of the neighbour behind port `k`, computed from the radius-`(t + 1)` view `V` (re-rooting). * `Solves A Act Pas`: the algorithm `A` (run by the nodes of one colour, the *active* side) outputs a label on each port; every active node's configuration is in `Act` and every passive node's configuration (the labels its `Δ` neighbours put on the connecting edges) is in `Pas`. Since every radius-`t` view and every radius-`(t + 1)` view of a passive node occurs in some port numbering of the infinite tree, this is correctness on all port numberings of the tree. -/ -- CSLib candidate (bipartite round elimination infrastructure) namespace TightBipartiteMatching /-- Branches of depth `t` of the port-numbered `(d+1)`-regular tree. -/ def Br (d : ℕ) : ℕ → Type | 0 => Unit | t + 1 => Fin (d + 1) × (Fin d → Br d t) namespace Br variable {d : ℕ} /-- The branch of depth `t + 1` with far port `j` and sub-branches `ch`. -/ def mk {t : ℕ} (j : Fin (d + 1)) (ch : Fin d → Br d t) : Br d (t + 1) := (j, ch) /-- The port number, at the far endpoint, of the edge leading into the branch. -/ def port {t : ℕ} (b : Br d (t + 1)) : Fin (d + 1) := (show Fin (d + 1) × (Fin d → Br d t) from b).1 /-- The sub-branches of the far endpoint (behind its ports `port.succAbove c`). -/ def child {t : ℕ} (b : Br d (t + 1)) : Fin d → Br d t := (show Fin (d + 1) × (Fin d → Br d t) from b).2 @[simp] theorem port_mk {t : ℕ} (j : Fin (d + 1)) (ch : Fin d → Br d t) : (mk j ch).port = j := rfl @[simp] theorem child_mk {t : ℕ} (j : Fin (d + 1)) (ch : Fin d → Br d t) : (mk j ch).child = ch := rfl @[simp] theorem mk_port_child {t : ℕ} (b : Br d (t + 1)) : mk b.port b.child = b := rfl theorem ext_iff' {t : ℕ} {b b' : Br d (t + 1)} : b = b' ↔ b.port = b'.port ∧ b.child = b'.child := by constructor · rintro rfl;
