# K-set agreement bounds in closed-above round-based models — PODC 2020

Adam Shimi, Armando Castañeda. *K-set agreement bounds in round-based models through combinatorial topology.*
PODC 2020. DOI [10.1145/3382734.3405752](https://doi.org/10.1145/3382734.3405752). Formalized version: the PODC
proceedings version; the full version arXiv [2003.02869](https://arxiv.org/abs/2003.02869) v2 (same statements, proofs
in the appendix) was used for the proofs.

**Verdict: 🚨 Headline claim false.** The general one-round lower bound, Theorem 5.4, is false. For the
closed-above model generated by a single star (`n ≥ 2`), it claims that `(n-1)`-set agreement is impossible in one
round, but consensus is solvable there. Theorem 6.11 (its multi-round version) fails on the same example. Theorems 5.1
and 6.10 are false as written, but their intended versions (`k < γ(G)`, `γ(G^r)`) hold and we prove them, by a short
combinatorial argument instead of topology. All upper bounds (Theorems 3.2, 3.4, 3.7, 6.3–6.5, 6.7, 6.9,
Corollaries 3.5, 3.8, Lemma 6.2) are correct.

## Mistakes in the paper

* **Theorem 5.4 (general lower bound) is false.** Take `S = {G}`, where `G` is the star with center `c`: `c`
  sends to everybody, and the other processes send nothing. For a single graph,
  `γ^dist({G}) = γ^eq(G) = n`, because a set dominates the star iff it contains `c`. A non-dominating set `P` of
  size `t` hears only itself, so `max-cov_t = t`, `M_t = n − t`, and `l = min(n − 2, n − 2) = n − 2`. The theorem
  then claims that `(n−1)`-set agreement is impossible in one round on `↑G`. But every process hears `c` in every
  graph of `↑G`, so "decide `c`'s input" solves consensus in one round (Theorem 3.2 with `γ(G) = 1`). This is false
  for every `n ≥ 2`; for `n = 3` the theorem claims that 2-set agreement is impossible.
  *Where the proof breaks* (Appendix B of the full version). Let the input facets `φ_0, …, φ_t` differ at a set `P`
  of `t` processes. The proof says `⋂ C_{G_i}(φ_i)` is "either empty or a pseudosphere". It then uses the bound for
  the non-empty case only. When `P` contains a process heard by everybody, the intersection is empty. Lemma 4.17 needs
  it to be `(l − t)`-connected, and an empty complex is not. More conceptually, for a single graph `γ^dist`
  quantifies over *all* sets of a given size. So it reduces to the equal-domination number, while the tight
  single-graph bound (Theorem 5.1) is governed by the ordinary domination number `γ(G) ≤ γ^eq(G)`. The theorem is
  stated for general (non-symmetric) closed-above models. The symmetric specialization (Corollary 5.5) is therefore
  unproven but not refuted. A brute-force comparison of Corollary 5.5 with the paper's own upper bounds over all
  graphs with `n ≤ 4` found no conflict. What does follow for general `S` is the trivial bound "impossible for
  `k < max_{G∈S} γ(G)`". (`theorem_5_4_false`, `not_solvable_of_lt_domNum`)
* **Theorem 6.11 (multi-round general lower bound) is false**, by the same example: products of stars are stars, so
  `S^r = {G^r}` with `G^r` a star, and `l = n − 2` for every `r ≥ 1`. Consensus is still solvable.
  (`theorem_6_11_false`)
* **The computation `γ^dist(S) = n − s + 1` for the symmetric model of unions of `s` stars is wrong**, both in
  Section 5 and in Appendix G. The argument picks *one* graph whose centers avoid `P`. But Definition 5.2 asks for
  `min(i, |S|)` *distinct* graphs. For `s = 1` and `n ≥ 3`, a set of `n − 1` processes misses only one possible
  center, so any two distinct stars include one whose center it contains. Hence `γ^dist(S) ≤ n − 1 < n`. So the
  claimed "tight" lower bound `(n − s)` for stars (and the proof of Theorem 6.13) does not follow from Theorem 5.4
  even where that theorem might hold. Theorem 6.13 itself is not refuted. For `s = 1` it is true, because one-round
  immediate snapshots embed into the model; this is not formalized. (`distDomNum_stars_le`, `distDomNum_stars_ne`)
* **Theorem 5.1 says `k ≤ γ(G)`; it should say `k < γ(G)`.** For `k = γ(G)` it contradicts Theorem 3.2. The text
  after Theorem 3.2 states the intended `k < γ(G)`. We prove the corrected statement. This is a typo with evident
  intent. (`theorem_5_1_false`, `theorem_5_1`)
* **Theorem 6.10 says `(γ(G) − 1)`; it should say `(γ(G^r) − 1)`.** For the directed 3-cycle, `γ(G) = 2`, so the
  theorem claims that consensus is impossible in any number `r > 0` of rounds. But after 2 rounds everybody has
  heard everybody (`γ(G²) = 1`). The intended version is recoverable from Theorem 6.3 and Appendix E. We prove it, and
  together with Theorem 6.3 it shows that `γ(G^r)` is tight. (`theorem_6_10_false`, `theorem_6_10`,
  `obliviousSolvable_up_iff`)
* Minor slips:
  - Section 3.2 says that "every covering number of a star equals 1"; in fact `cov_i = i`. The conclusion drawn
    there still holds: `n − cov_i = n − i ≥ γ^eq − i`, so covering numbers do not improve the bound
    (`star_example`). The claims about the second graph of Figure 1 are correct (`figure1_example`).
  - Definition 6.1 reads "`(u,v) ∈ Π ⟹ ∃w …`"; it should read "`(u,v) ∈ E ⟺ ∃w …`".
  - Definition 6.8 uses "`keq−dom(G)`" for `γ^eq(G)`.
  - Appendix C writes "`max-cov_t({G}) = t`" in the second case, which should be "`> t`".

## The formalization

**Model.**
* `n = |α|` processes (any `Fintype`), synchronous communication-closed rounds, no crashes. Each round's directed
  communication graph is chosen by an oblivious adversary from `↑S = {H | G ≤ H for some G ∈ S}` (closed-above
  model). Graphs are `Cslib.HeardOf.Graph α`, with self-loops implicit (`Hears`), as the paper assumes.
* One-round algorithms are full information: a decision map applied to the vector of received inputs
  (`Cslib.HeardOf.msgs`). `r`-round algorithms are *oblivious* (Definition 2.5): flood the known
  `(process, input)` pairs and apply a decision map to them after `r` rounds. These pairs are exactly the inputs of
  the in-neighbours in the product `G₁ ⊗ ⋯ ⊗ G_r` (`known_eq_msgs`).
* `k`-set agreement: every decision is some process's input, and at most `k` distinct values are decided.
  Deterministic algorithms, no randomness.
* Inputs: the upper bounds use any nonempty linearly ordered `V` (the paper assumes a total order). The lower bounds
  (Theorems 5.1, 6.10) assume at least `n` input values (`α ↪ V`); the paper does not fix the input set. The
  counterexamples work for every `V`.
* The combinatorial numbers (`γ`, `γ^eq`, `cov_i`, `γ^dist`, `max-cov_i`, `M_i`, `l`, covering sequences) are
  defined literally as in the paper, with `sInf`/`sSup` over `ℕ`.

**Not formalized.** The combinatorial-topology part: Section 4 (pseudospheres, nerve lemma, Lemma 4.17, Theorem 4.12),

their proofs depend on the flawed argument of Theorem 5.4.

**Trust.** No `sorry`; all listed theorems use only the axioms `propext`, `Classical.choice`, `Quot.sound`. The model
reuses `Cslib.HeardOf` (`Graph`, `Hears`, `msgs`) from
`Cslib/Computability/Distributed/DynamicNetworks/HeardOf.lean`. The corrected Theorem 5.1 is proved directly. Validity
forces each process to decide an input it has heard. With pairwise distinct inputs, the processes whose inputs are
decided then form a dominating set, so at least `γ(G)` values are decided. This also gives the tight
characterizations `oneRoundSolvable_up_iff` and `obliviousSolvable_up_iff`. CSLib candidates (marked
`-- CSLib candidate`): closed-above models and domination numbers (`Defs.lean`), `exists_lowerSet` (`Basic.lean`),
`decides_heard` (`LowerBoundSimple.lean`), and `reach_iff_hears`/`known_eq_msgs` (`MultiRound.lean`).
