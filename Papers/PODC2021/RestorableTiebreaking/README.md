# Restorable Shortest Path Tiebreaking — PODC 2021

Greg Bodwin, Merav Parter. *Restorable Shortest Path Tiebreaking for Edge-Faulty Graphs.* PODC 2021.
DOI [10.1145/3465084.3467913](https://doi.org/10.1145/3465084.3467913). Formalized version: arXiv
[2102.10174](https://arxiv.org/abs/2102.10174) v4; numbering follows it.
Copy of the paper: [paper.pdf](paper.pdf).

**Verdict: ⚠️ Correct with fixes.** The main result is proved in full: every graph has a consistent, stable,
`f`-restorable replacement-path tiebreaking scheme, generated by antisymmetric tiebreaking weights
(Theorems 2, 19, 20, 23). So is the `C₄` impossibility of symmetric restorable schemes (Theorem 37), and
the correctness of the preserver, labeling and `+4`-spanner applications. Two things needed fixing.
Definition 17 omits the hypothesis that `s, t` stay connected, so Theorem 19 read literally is false on
every graph in which some allowed fault set separates two vertices (e.g. any graph with a bridge). The union bound in Corollary 22 miscounts the fault sets, so its constant must be
changed.

## Mistakes in the paper

- **Definition 17 / Theorem 19: missing connectivity hypothesis.** *False only in a degenerate case.*
  - Definition 17 asks for a replacement path for every nonempty fault set `F` and every pair `s, t`. It
    does not require that `s` and `t` remain connected in `G \ F`.
  - When `F` cuts `s` from `t`, no replacement path exists. So no scheme is restorable on any graph in
    which some `F` with `|F| ≤ f` separates two vertices: any graph with a bridge (`f ≥ 1`), and any
    disconnected graph with an edge. Theorem 19 fails, e.g., on the single-edge graph `K₂`, which does
    have ATW functions.
  - Theorem 2 states the correct hypothesis ("an `s ⇝ t` path remains"). With it added to Definition 17,
    Theorem 19 holds. (`theorem19_literal_false`; repaired: `theorem19`)
- **Corollary 22: union bound over `s, t, F` is miscounted.** *A false intermediate claim; the corollary
  holds after changing a constant.*
  - The proof bounds the number of choices of `(s, t, F)` with `|F| ≤ f` by `n^{f+2}`. There are about
    `n² · |E|^f`, which is up to about `n^{2f+2}`. Already `K₄` with `f = 1` has `16 · 7 = 112 > 4³`
    choices with ordered pairs (`84 > 64` excluding `s = t`).
  - With the paper's `W = n^{f+4+c}`, the union bound therefore only gives about `n^{f−c}`, not `n^{−c}`.
  - `W = n^{2f+4+c}` repairs the bound and keeps `O(f log n)` bits per weight.
  - We prove the correct bound `n² · N_f · |E| / (2W+1)` with the isolation lemma. The final arithmetic
    (choice of `W`, `O(f log n)` bits) is not stated in Lean.
  
  (`paper_count_false`; repaired: `corollary22`)
- **Proof gaps with true statements.**
  - **Theorem 23.** The uniqueness argument picks the minimum-ID edge of `π₁ \ π₂` instead of the whole
    symmetric difference. (It also speaks of arbitrary paths, ignoring lengths; the `±2r(e)` terms of
    oppositely traversed edges are harmless for large `C`.) (`theorem23`)
  - **Corollary 22.** Applying the isolation lemma to signed directed weights needs that all shortest
    `s ⇝ t` paths cross each edge in the same direction and that the weight distribution is symmetric
    under negation; the proof does not say so. (`corollary22`, via `tau` and a sign flip)
  - **Lemma 32.** The proof omits replacement paths that contain no clustered vertex. (`lemma32_correct`)
  - **Theorem 30.** The proof says "restorable `f`-RPTS" where an `(f+1)`-restorable `(f+1)`-RPTS is needed.
    (`theorem30_correct`)
  - **Theorem 21 (isolation lemma).** It is stated for a set of paths but needs distinct edge sets.
- **Appendix B (Theorem 27, not formalized).** Several slips, none affecting the asymptotics:
  - the bipartite weights should be `1 + (λ−j)/n⁴`;
  - `v*` is never defined;
  - labels are undefined for the last copy at each level, so only a constant fraction of the bipartite
    edges is forced;
  - the weights `W` do not break all ties, so a further generic perturbation is needed to obtain a full
    RPTS.

  A numerical check (`scripts/thm27.py`) confirms the corrected construction for `f ≤ 3` and small `d`.

## The formalization

**Model.**
- **Graphs and faults.** A finite undirected unweighted graph `G : SimpleGraph V`. Edge faults
  `F : Finset (Sym2 V)` (deterministic, arbitrary). `G \ F` is `G.deleteEdges F` and distances are
  `edist`.
- **Paths.** Selected paths are walks of `G` (`G.Walk s t`). A replacement path is `IsShortestIn F`: it
  avoids `F` and is a shortest walk of `G \ F`.
- **Schemes.** A scheme `π : Finset (Sym2 V) → ∀ s t, Option (G.Walk s t)` selects `π(s, t | F)`.
- **Weights.** `G*` has dart weights `1 + r(u,v)` (`wstar`). Our `IsATW` reads Definition 18 with lightest
  *walks*; `IsATWPath` reads it with lightest *simple paths*. The two are proved equivalent.
- **Randomness.** Only in Theorem 20 (uniform product measure on `[-ε, ε]^{Sym2 V}`) and Corollary 22
  (uniform `{−W,…,W}^{Sym2 V}`, counting form).
- **Not modelled.** No distributed or computational model is formalized; running times, bit lengths and
  the CONGEST results are outside the formalization.

**Not formalized.**
- The size bound of Theorem 26 (cited from [9], proof sketch only) and therefore the sizes in
  Theorems 5, 7, 10, 30, 31 and 33 for `f ≥ 1`.
- The expected-size part of Lemma 32.
- The lower bound of Theorem 27 (checked numerically only).
- All running-time, bit-complexity and CONGEST results: Theorems 3, 8, 28, 29 (runtime), 35, Corollary 9
  and Lemmas 34–36.

**Trust.** No `sorry`. All theorems in the table use only the axioms `propext`, `Classical.choice` and
`Quot.sound`.

Non-vacuity:
- ATW functions exist for every finite graph (`theorem23`), so `theorem19` is not vacuous.
- Theorem 2 is an existence statement.
- `theorem37` and `theorem19_literal_false` are refutations on concrete graphs (`C₄`, `K₂`).

General graph infrastructure is in `Podc/Graphs/ShortestWalks.lean` (CSLib candidate). It covers:
- walks avoiding a fault set and shortest walks of `G \ A`;
- splitting at a dart;
- orientation of edges on shortest walks;
- distinct shortest walks have distinct edge sets;
- directed dart weights and the bypass weight bound.

The isolation lemma is in `Podc/Combinatorics/IsolationLemma.lean` (CSLib candidate).
