# Broadcasting in Noisy Radio Networks — PODC 2017

Keren Censor-Hillel, Bernhard Haeupler, D. Ellis Hershkowitz, Goran Zuzic. *Broadcasting in Noisy Radio
Networks.* PODC 2017. DOI [10.1145/3087801.3087808](https://doi.org/10.1145/3087801.3087808). Formalized
version: arXiv [1705.07369](https://arxiv.org/abs/1705.07369) v1 (full version); numbering follows it.

**Verdict: 🛠️ Proof repaired.** The formalized results all hold as stated, for every constant
`p ∈ (0, 1)`:
* the star gap (Lemmas 15 and 16, Theorem 17): with receiver faults, adaptive routing on the star has
  throughput `Θ(1/log n)`, coding has `Θ(1)`, so the coding gap is `Θ(log n)`;
* the sender-fault transformation for routing (Lemma 25).

The proof of the routing lower bound in Lemma 15 does not work and had to be replaced. The upper-bound
half of Lemma 15 relies on an independence that the paper never justifies.

## Mistakes in the paper

* **Lemma 15, impossibility half (`Ω(k log n)` rounds): the proof is broken; the statement is true.**
  - The proof first proves `E[Xᵢ] ≥ (log n)/4`, where `Xᵢ` is the number of broadcasts of `mᵢ`. A few
    lines later it uses "since `E[Xᵢ] ≤ (log n)/4`".
  - The thresholds change mid-argument (`(log n)/16`, then `(log n)/8`, then `(log n)/16`) and do not
    follow from "`(k log n)/4` rounds".
  - It applies Chernoff to `Xᵢ`, which is not a sum of independent indicators (this is the "Chernoff on
    a non-sum" from triage).
  - It applies Chernoff to `S = Σ Sᵢ` without independence of the `Sᵢ` under an adaptive schedule.
  - That Chernoff step concludes `exp(-Ω(E[S]))`, which is useless because `E[S] ≤ k/n^c` is tiny. It
    then turns this into `exp(-Ω(n^c))`.

  Our proof couples the round coins with per-message coin columns: the `j`-th transmission of `mᵢ` uses
  its own column. This is legitimate for every adaptive schedule because each round reads a fresh column
  (`sum_couple`). With fewer than `⌈k/2⌉·T` rounds, more than `k/2` messages are sent fewer than `T`
  times. Each such message reaches all `n` leaves with probability `(1 - p^T)^n`, independently of the
  other messages. A union bound over the `C(k, ⌊k/2⌋+1)` candidate sets of messages finishes the proof.
  (`star_prob_delivered_le`, `star_routingRounds_ge`)
* **Lemma 15, possibility half: missing independence; statement true.** The proof dominates
  `Y = Σ Yᵢ` by a sum of independent geometric variables. This needs the per-message cover times to be
  independent, but they are generated by one adaptive run, and the paper does not address this. The same
  coupling makes them independent. We then use a direct exponential-moment bound instead of Doerr's
  Theorem 34, with `λ = 2/(1+p)` and `E[λ^{excess}] ≤ 2`. (`star_greedy_succeeds`)
* **Lemma 25: the construction is under-specified; statement true.** "Broadcast `m_{i1}` until it
  succeeds" is not directly expressible: an adaptive routing schedule (Definition 14) sees only who
  knows which message, not the sender's coin. Our implementation lets a node broadcast the least
  sub-message still unknown to one of its faultless receivers. It also lets only the faultless
  broadcasters of the round transmit, so extra receptions cannot create new collisions.
  (`SenderTransform.sch`, `SenderTransform.delivered_of_good`)
* **Typos and small slips.**
  - Lemma 15: `Pr(Hᵢ ≥ t) = (1/2)^t` should be `(1/2)^{t-1}`; the domination still holds.
  - Lemma 25: "sends `k'₀ = k₀x` messages in `(τ-ε)^{-1}(1-p)^{-1}(1+η)` rounds" is missing the factor
    `k'₀`.

## The formalization

**Model.** (`Model.lean`)
* **Network.** Synchronous radio network on a finite simple graph with source `s`. A listening node hears
  a neighbour iff that neighbour is its unique broadcasting neighbour. There is no collision detection.
* **Faults.** Every node flips an independent coin per round, clean with probability `1 - p`. With
  receiver faults, the receiver's coin decides whether it receives a transmission it hears; with sender
  faults, the sender's coin decides, and noise still collides. The faultless model sets all coins clean.
* **Routing.** Messages are `Fin k`. An adaptive routing schedule is a function
  `round → knowledge state → action of every node` (Definition 14). A node told to send a message it does
  not know stays silent. Faultless routing schedules are static.
* **Coding.** Each node's action is an arbitrary function of its input and of its own reception history.
  Messages and packets come from the same finite alphabet `A k`; for Lemma 16 these are finite fields
  with `|F k| ≥ k²`.
* **Randomness.** The only randomness is the fault coins. Schedules are deterministic, as in the
  paper (Section 3.1, Definition 14); nodes never observe their own coins, only what they receive.
* **Success and throughput (Definition 1).** Success means every node knows (coding: decodes) all `k`
  messages after `R` rounds with probability `≥ 1 - 1/k`; for coding this must hold for every message
  vector. `routingRounds` and `codingRounds` are the least such `R` (`⊤` if none exists). Throughput is
  `limsup_k k / rounds(k)` in `ℝ≥0∞`.
* **Star.** The source plus `n` leaves, as in the paper's footnote. `Θ(·)` is read as "for fixed `p`,
  for all `n ≥ n₀(p)`, with constants depending on `p`".
