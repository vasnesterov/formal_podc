import Papers.PODC2024.MemSnap.Main /-! # Lemma 7.2 as printed is false The third disjunct of the definition of `Q` (Figure 2) admits, for a component `j` with `B[j].seq ≠ X`, the snapshot value `a_μ` of any process `μ` poised at line 12 with `b_μ = B[j]`, whatever the value `x_μ` it read from `X`. If `x_μ < X`, the CAS of `μ` would *not* make `B[j].seq` equal to `X`, and `a_μ` may be an outdated value. **Execution** (one component, word = read/write register over `ℕ` with initial value `0`, updaters `ν = 0`, `μ = 1`, scanner `σ = 2`): 1. `ν` invokes `update(write 1)`, finishes `forward` (`B.seq = X = 0`) and is poised at line 7; 2. `μ` invokes `update(write 1)` and reads `b_μ = B = (0, 0)` (line 9); 3. `σ` clicks: `X = 1`; 4. `μ` reads `x_μ = X = 1` (line 10) and `a_μ = A = 0` (line 11): poised at line 12; 5. `ν` writes `A = 1` (line 7) and returns; 6. `σ` clicks again: `X = 2`, `σ` is at line 2. Now `B = (0, 0) = b_μ`, `B.seq = 0 ≠ X`, and the possibility `p` with `val = 1`, `snap = a_μ = 0`, `p.σ = ack` and no other process linearized belongs to `Q` (with `S = ∅`, third disjunct with witness `μ`). But `ν`'s update completed before the second click was invoked, so in every linearization it precedes that click and the snapshot contains `1`: `p` is realized by no linearization (`not_tracked`), hence (`tracked_of_mem_PP`) `p ∉ P`, and `Q ⊆ P` fails (`lemma_7_2_false`). The corrected `Q` (with `x_μ = X`) does not contain `p`; for it the lemma holds (`lemma_7_2_fixed`).
