import Podc.Computability.Distributed.RateAllocation.MaxMinFair /-! # Clos networks and macro-switches (Section 2 of Ferreira–Atre–Sherry–Sobrinho, PODC 2024) The Clos network `C_n` has `n` middle switches `M_m`, `2n` input switches `I_i`, `2n` output switches `O_i`, and `n` source (destination) servers per input (output) switch. A server is a pair `(i, j) : Fin (2n) × Fin n` (switch, server index), so `s_i^j` / `t_i^j` of the paper are `(i - 1, j - 1)` here (all indices are 0-based). The links are * `srcLink s` — from source server `s = (i, j)` to its input switch `I_i`; * `up i m` — from `I_i` to `M_m`; * `down m o` — from `M_m` to `O_o`; * `dstLink t` — from output switch `O_o` to destination server `t = (o, j)`; all of unit capacity. A collection of flows is a finite type `F` with a source and a destination server for each flow (several flows may share a source–destination pair). A *routing* assigns to each flow a middle switch, i.e. one of the `n` source–destination paths of `C_n`. The macro-switch `MS_n` replaces the middle stage by infinite-capacity links between all input and output switches; links of infinite capacity never constrain an allocation, so a flow of `MS_n` traverses only its two server links (`macroSwitch`). -/ namespace Podc.DataCenterRouting open Cslib.RateAllocation Finset /-- A server: an input/output switch index in `Fin (2n)` and a server index in
