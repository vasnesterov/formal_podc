import Papers.PODC2024.SSLeaderElectionDirected.Defs import Cslib.Foundations.Combinatorics.Digraph.Walk /-! # Algorithm C-MAI(D, ≺, I): minimum ancestors' input (Section 3) Altisen, Cournier, Defalque, Devismes, *On Self-stabilizing Leader Election in Directed Networks*, PODC 2024 (HAL hal-04434345v4). Every process `p` has a constant input `I p ∈ D` (`D` totally ordered) and a key `p.K = (p.M, p.d) ∈ D × [0..α]`, ordered lexicographically. Its only action is `ReplaceKey :: BestKey(p) ≠ p.K → p.K ← BestKey(p)` where `BestKey(p) = min ({(I p, 0)} ∪ {(q.M, q.d + 1) | q ∈ Γ⁻(p), q.d < α})`. The goal is `p.K = (MinI(p), Mind(p))` (`target`): `MinI(p)` is the least input among the ancestors of `p` and `Mind(p)` the distance from a closest ancestor with that input. This file contains the definitions, the order on keys, and the properties of `MinI`/`Mind` (Property 1). It also introduces `Run`: a sequence of key configurations in which, at each step, an arbitrary set of processes `A t` executes `ReplaceKey` with respect to *time-dependent* inputs `I t`. Plain executions of C-MAI are runs with constant inputs; layers of the composition `PEL = E ∘ A ∘ MI` are runs whose inputs are eventually constant. -/ set_option linter.unusedSectionVars false open
