The two processes are `Proc.w` (writer) and `Proc.r` (reader). In our model a failed `TryRead` directly restarts the up-scan at index `0` (the step that reads `A[K-1] = 0` moves to the up-scan state at `0`). ## Proof Linearizability uses the reads-from criterion `SWSRReadsFrom` of `Cslib.Computability.Distributed.SharedMemory.SWSRRegister`. The reads-from assignment is computed by a *ghost run* (`ghost`) alongside the execution: for every cell `i`, `src i` is the number of the `Write` (1-based, `0` = initial value) that performed the last low-level write to `A[i]`; when the reader reads `A[j] = 1` and sets `val ← j` it records `cur ← src j`; when the `Read` returns, `cur` is its reads-from value. The invariant `Inv` (preserved by every step, `inv_run`) contains: * `A[i] = 1 ↔ value of write src(i) = i` (`Inv.mem`), and the shape of `src` during a write; * the paper's case analysis (read-before-read, cases `v₁ = v₂`, `v₁ > v₂`, `v₁ < v₂`) is turned into forward invariants about the last completed read (`last`, `lastv`): `src[lastv] ≥ last` and every `A[j] = 1` with `j ≤ lastv` has `src j ≥ last`; once the up-scan passes `lastv`, all `src ≥ last`. HI: in a state-quiescent configuration the writer is idle (or `K = 1`), so `A` is the indicator of the current value (`mem_of_stateQuiescent`). Lock-freedom: once responses stop, the writer takes at most `2K + 2` more steps (measure `wμ`), and then the reader, running against a fixed memory that contains a `1` (`exists_one`), returns within `4K + 1` steps (measure `rμ`). ## Main results * `alg2` — the implementation; `rf` / `ghost` — the reads-from assignment. * `linearizable`, `lockFree`, `stateQuiescentHI`, `theorem9` (Theorem 9). *
