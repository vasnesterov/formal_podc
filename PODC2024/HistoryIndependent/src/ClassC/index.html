The state space is partitioned into `t` nonempty classes (`cls` is surjective), a read-only operation `oread` distinguishes states of different classes, and for any two distinct states `q ≠ q'` the operation `ochange q q'` moves the object from `q` to `q'`. (The operations `ochange q q'` are part of the data so that access disciplines, e.g. single-writer registers, can be expressed.) -/ structure ClassC (A : ObjSpec) (t : ℕ) where /-- The partition of the state space into `t` classes. -/ cls : A.State → Fin t cls_surj : Function.Surjective cls /-- The distinguishing read-only operation. -/ oread : A.Op oread_ro : A.ReadOnly oread oread_sep : ∀ q q', cls q ≠ cls q' → (A.δ q oread).2 ≠ (A.δ q' oread).2 /-- The operation moving from `q` to `q'`. -/ ochange : A.State → A.State → A.Op ochange_spec : ∀ q q', q ≠ q' → (A.δ q (ochange q q')).1 = q' namespace ClassC variable {A : ObjSpec} {t : ℕ} (K : ClassC A t) /-- A representative state of each class. -/ noncomputable def rep (i : Fin t) : A.State := (K.cls_surj i).choose lemma cls_rep (i : Fin t) : K.cls (K.rep i) = i := (K.cls_surj i).choose_spec open Classical in /-- The avoidance data of an object in `C_t`: representatives of the classes, single-operation paths `ochange`. -/ noncomputable def avoidData : AvoidData A t where oread := K.oread oread_ro := K.oread_ro rep := K.rep resp_inj := by intro i j hij by_contra hne exact K.oread_sep (K.rep i) (K.rep j) (by rw [K.cls_rep, K.cls_rep]; exact hne) hij path i j := [K.ochange (K.rep i) (K.rep j)] path_end i j hij := by have : K.rep i ≠ K.rep j := fun h => hij (by rw [← K.cls_rep i, h, K.cls_rep]) simp [K.ochange_spec _ _ this] path_mid i j hij m hm := by have : K.rep i ≠ K.rep j := fun h => hij (by rw [← K.cls_rep i, h, K.cls_rep]) simp only [length_singleton] at hm rcases Nat.le_one_iff_eq_zero_or_eq_one.1 hm with rfl | rfl · left; simp · right; simp [K.ochange_spec _ _ this] start j := if A.init = K.rep j then [] else [K.ochange A.init (K.rep j)] start_end j := by split_ifs with h · simpa using h · simp [K.ochange_spec _ _ h] end ClassC /-- **Theorem 17.** For any object in the class `C_t` (`t ≥ 2`), there is no wait-free, state-quiescent history-independent implementation from base objects with fewer than `t` states.
