import Cslib.Computability.Distributed.SharedMemory.SWSRRegister import Mathlib /-! # Algorithm 4: a wait-free quiescent HI SWSR `K`-valued register (definitions) Algorithm 4 of Attiya, Bender, Farach-Colton, Oshman, Schiller, *History-Independent Concurrent Objects* (PODC 2024): a single-writer single-reader register with values `Fin K` (the paper's `{1, …, K}`, here 0-based) and initial value `v₀`, implemented from binary registers `A[0..K-1]` (initially `A[v₀] = 1`, all others `0`), `B[0..K-1]` (initially `0`) and `flag[1], flag[2]` (initially `0`). The writer keeps a local variable `last` (`last-val`, initially `v₀`). ``` Read(): Write(v): 1: flag[1] ← 1 11: if ∀ j, B[j] = 0 then 2: for it = 1, 2 do 12: if flag[1] = 1 then 3: val ← TryRead() 13: B[last] ← 1 4: if val ≠ ⊥ then goto 7 14: if flag[2] = 1 or flag[1] = 0 then 5: for j = 1..K do 15: B[last] ← 0 6: if B[j] = 1 then val ← j 16: A[v] ← 1 7: flag[2] ← 1 17: for j = v-1 .. 1 do A[j] ← 0 8: for j = 1..K do B[j] ← 0 18: for j = v+1 .. K do A[j] ← 0 9: flag[1] ← 0; flag[2] ← 0 19: last ← v 10: return val ``` `TryRead()` scans `A` upwards for the first `j` with `A[j] = 1` (returning `⊥` if there is none), then scans downwards from `j - 1` and returns the smallest index read as `1`. ## Modelling * Two processes `Proc.w` (writer) and `Proc.r` (reader); `allowed = RWOp.SWSR w r`. * Base objects `Cell K`: `a j`, `b j`, `f1`, `f2`, all binary registers. * Local states `Loc K` hold the writer's `last` and program counter `wpc`, and the reader's program counter `rpc` (each process only uses its own fields). Program counters are *normalized*: each one denotes exactly one pending low-level access (loops are unrolled into states carrying the loop index; the exit of a loop goes directly to the state of the next access), or the return. The writer's local update of `last` (Line 19) happens with the return. * The reader's `val` is an `Option (Fin K)` (`none` = `⊥`); a `Read` returns `val.getD v₀` (by Lemma 10, `val ≠ ⊥` when it returns, `lemma10`). * The paper's `flag[2] = 1 or flag[1] = 0` in Line 14 reads `flag[2]` first and only reads `flag[1]` if `flag[2] = 0` (short-circuit; as described in the paper's text: "it reads flag[2] and then flag[1]"). Similarly the scan of Line 11 stops at the first `B[j] = 1`. ## Files * `Alg4State` — abstract state with ghost variables, transition function `sstep`, simulation (`rel_run`); the ghost state of an execution is `sOf v₀ α`. * `Alg4Inv`, `Alg4StepR`, `Alg4StepW`, `Alg4Main` — the invariant `Inv` and its preservation (`inv_sOf`). * `Alg4Lin` — the history in terms of the abstract state (`link`), the reads-from assignment `rfOf`, the reads-from criterion (`readsFrom`), linearizability (`isLinFun`, `linearizable`). * `Alg4WaitFree` — `Impl.waitFree_of_potential` (general) and `waitFree`. * `Alg4Thm` — `lemma34`, `lemma10`, `lemma11`, `mem_quiescent`, `quiescentHI_any`, `quiescentHI`, **`theorem12`**, and the non-vacuity check `nonvacuous`. -/ namespace Cslib.SharedMemory namespace Alg4
