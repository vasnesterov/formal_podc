A *log* is a list of blocks (`List α`); `Λ <+: Λ'` means `Λ'` extends `Λ` (Definition 1). A *vote assignment* `M : P → Option (List α)` records the (at most one) vote that a receiver counts for each process after discarding equivocations; it is the set `M_r^i` of Figure 3. The tally of Figures 2/3 outputs `(Λ, 1)` if more than `2m/3` of the `m` counted votes are for extensions of `Λ`, and `(Λ, 0)` if more than `m/3` (but not more than `2m/3`) are. This file contains the pure counting arguments behind Lemma 1: an abstract "faithful tally" (every honest process of `H` is counted with its true vote, every counted process lies in a universe `U`, `|H| > 2|U|/3`) and the consequences graded consistency, integrity, validity, uniqueness and bounded divergence. -/ namespace Podc.SleepyTOB open Finset noncomputable section open Classical variable
