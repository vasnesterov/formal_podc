import Papers.PODC2024.BoundedRegisterPower.Alg2 import Mathlib.Data.Fintype.Pi import Mathlib.Logic.Relation /-! # Biran–Moran–Zaks conditions give path systems Lemma 5.7 of the full version (Biran, Moran, Zaks 1990), for two processes: a task `Δ` is `1`-resilient (= wait-free) solvable iff some set `O'` of output vectors satisfies * *connectivity*: for every input `X`, the graph on `Δ(X) ∩ O'` whose edges join vectors differing in at most one entry is connected; * *covering*: for every partial input `X^i` (input `x_j` of `j = !i` only) there is an output `y_j` such that for every input `x_i` some vector of `Δ(x_i, x_j) ∩ O'` has `j`-entry `y_j`.
