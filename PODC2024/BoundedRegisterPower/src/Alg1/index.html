import Podc.Computability.Distributed.SWMR.Basic import Mathlib.Tactic /-! # Algorithm 1: wait-free two-process ε-agreement with 1-bit registers Delporte-Gallet, Fauconnier, Fraigniaud, Rajsbaum, Travers, *The Computational Power of Distributed Shared-Memory Models with Bounded-Size Registers*, PODC 2024, Section 5.1. Processes are `Bool` (the other process of `p` is `!p`). Every process owns two registers, indexed by `Bool`: `false` is the write-once input register `I` (`Option Bool`, initially `none` = ⊥) and `true` is the 1-bit register `R` (`Bool`, initially `false` = 0). Outputs are numerators `m : ℕ` standing for `m / (2k+1)`. ## Encoding One step = one shared-memory access or the decision. Line 8 (`x_me ← I_me.read()`) is not a step: the process keeps `x_me = myInput` in its local state. After deciding, a process keeps reading its own register `R` (the model requires every step to be an action). Hence a process takes at most `2k+3` steps before deciding: write `I`, `≤ k` iterations of (write `R`, read `R_other`), read `I_other`, decide. ## Proof The invariant `Inv` says that memory and outputs are functions of the local states and that the pairwise invariant `Rel` holds: (F2) the number of completed iterations of a process is at most the number of writes of the other one; (F4) the two processes never `break` in the same iteration (Lemma 5.2); (F5) reading `⊥` from `I_other` only happens before completing an iteration. The case analysis of Lemmas 5.1–5.5 is `outVal_agree`. ## Main statements * `alg1_solves`: Proposition 5.1 (wait-free `1/(2k+1)`-agreement, `k ≥ 1`); * `alg1_decides`: step bound `2k+3`; * `alg1_lemma_5_6`: Lemma 5.6 (decisions `0`/`1` only by processes with that input);
