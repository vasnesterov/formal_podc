We work with an arbitrary finite set of processes `P` and a set `G` of "early" processes (`p₁, …, p_{n-t+1}` in the paper) such that * `2 ≤ |G|` (so that consensus among `G` is impossible), * `|Gᶜ| + 1 ≤ t` (the processes outside `G` crash initially and one more process may crash), * `|G| ≤ t` (all processes of `G` may crash), * `Gᶜ` is nonempty. For `P = Fin n` and `|G| = n - t + 1` these are exactly `n > 2` and `n/2 < t < n`.
