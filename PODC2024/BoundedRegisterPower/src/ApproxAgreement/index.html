Released under Apache 2.0 license as described in the file LICENSE. -/ import Podc.Computability.Distributed.SWMR.Basic import Mathlib /-! # Lemma 2.2: wait-free binary `1/k`-agreement with unbounded registers The classical fact (Lemma 2.2 of the paper) that binary `1/k`-agreement is wait-free solvable by any number of processes in the read/write model with unbounded single-writer registers. ## Algorithm (iterated collect-midpoint) Every process `p` keeps a current value `v` (initially its input `0` or `1`) and runs `R` rounds. In round `r` it writes the list of its round values `[v₀, …, v_r]` to its register, then reads the registers of all processes (in the order of a fixed list `L`), taking the `r`-th entry of every list long enough; `lo`/`hi` are the minimum/maximum of the values taken (initialised to `v_r`). Then `v_{r+1} := (lo + hi) / 2`. After `R` rounds it decides `⌊k · v_R⌋₊` and then does no-op reads forever. Any two processes finishing round `r` took a common value (whichever wrote first is read by the other), so the spread of the round values halves every round; with `R = k` the final values are `1/2^k ≤ 1/k` apart. The local state also records ghost information (all round values, all ranges, and the results of all reads), which is harmless since local states are unbounded in this model. -/ namespace
