The certificate for a graph with `n` vertices is the number `c = (2 ^ n - 1) + 2 ^ (n + 1) * (idx + |L_n| * code)`, i.e. the bit string `1ⁿ 0 · idx · code`: * `n` in unary (so the verifier can read it without knowing it), * `idx`, the index of a hash function `h` in the hash list `L_n = fam M n` for `(n, M n)`, * `code < n' ^ n`, the list `L` of the paper: the `n'`-ary digits of `code` are the vertices of `H` (via a fixed enumeration of `W`) assigned to the hash values `0, …, n - 1`. Node `u` accepts iff the colour `L[h(Id u)]` is defined and is adjacent in `H` to `L[h(Id v)]` for every neighbour `v`. The size is `n + 1 + ⌈log₂ |L_n|⌉ + n ⌈log₂ n'⌉` (`certSize`), which is `≤ 10 (n log₂ n' + log₂ log₂ M(n))` (`certSize_le`). -/ open Finset Real namespace Podc.GlobalCertificationHashing /-! ### The
