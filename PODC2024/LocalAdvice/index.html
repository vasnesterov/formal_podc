Local Advice and Local Decompression — PODC 2024

Alkida Balliu, Sebastian Brandt, Fabian Kuhn, Krzysztof Nowicki, Dennis Olivetti, Eva Rotenberg, Jukka Suomela. Brief Announcement: Local Advice and Local Decompression. PODC 2024. DOI 10.1145/3662158.3662805. Formalized version: the full version Distributed Computation with Local Advice, arXiv 2405.04519 v2 (22 Aug 2025); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. The 3-colouring result holds: every 3-colourable graph of maximum degree Δ can be 3-coloured in O(Δ⁹) rounds with 1 bit of advice per node (Theorem 30), and Lemmas 31–34 hold, including the Lovász-Local-Lemma step of Lemma 32. Theorem 5 (advice algorithms can be made order-invariant), on which the ETH lower bound rests, also holds, but its proof ignores that LOCAL nodes know n and it took a new Ramsey argument; the rest is slips: the cited Lemma 1 is false in the corner d = 0, and the decoder's description has a typo. The other main results (sub-exponential growth, balanced orientations, Δ-colouring and the ETH bound itself) were not checked.

Mistakes in the paper

✏️ Slips

  • Lemma 1 (symmetric local lemma, cited) for d = 0. With the condition e·p·d ≤ 1, one event of probability 1 depends on no other event and satisfies e·1·0 ≤ 1, yet it always occurs (lemma_1_as_stated_false). This is a degenerate corner of a cited textbook result: the standard condition is e·p·(d+1) ≤ 1, and the only use (Lemma 32, d ≤ 48Δ⁸, p ≤ 1/(144Δ⁸)) satisfies it as well (used instead: Cslib.Probability.exists_forall_not_of_symmetric).

  • Decoder of Theorem 34 (page 42, "receive color 1"). The decoder takes x as the smallest identifier "among all nodes in the (30Δ³)-hop neighborhood of w in C(u) that receive color 1", but no node of C(u) has colour 1; it must be "receive bit 1". The intent is evident from the overview of Appendix D and the proof of Theorem 34; that proof drops the qualifier altogether ("the smallest-ID node among all nodes in the neighborhood").

Typos

  • The existence of a greedy 3-colouring of a 3-colourable graph is used but not shown. It is easy: take a proper colouring with minimal colour sum (exists_isGreedy).

Proof gaps in true statements (1)Theorem 5

🛠️ Theorem 5 (order-invariance: the proof ignores the knowledge of n)

The paper's LOCAL model (Section 3.1) gives every node n, but the proof treats A as one map from labelled radius-T views to outputs and then runs it on a padded graph H with N ≫ n nodes, where it behaves as the different map A_N.

Impact. Theorem 5 stands with a new core step, and the resulting A' does not even depend on n (theorem_5).

Details

The proof colours s-subsets of identifiers by that map and takes an infinite monochromatic set I. Then it runs A on a graph H made of many copies of G, with N ≫ n nodes and N chosen after I. If A reads n, the behaviour on H is that of A_N, and I was built for the wrong map.

Repair

For each M, apply finite Ramsey on {1, …, N_M} with N_M = (R(M) + M)! to A_{N_M}. That gives a homogeneous M-set whose behaviour is one of finitely many types. By pigeonhole one type F* occurs for infinitely many M. For a graph with n nodes take such an M ≥ n + s; then n | N_M, so H can be exactly N_M / n copies of G. (theorem_5)

The formalizationmodel, Lean names of the results, trust

Model.

  • 3-colouring (Theorems 30, 34; Lemmas 31–33). Deterministic synchronous LOCAL with unique identifiers and no failures. The nodes of every graph are the elements of a fixed finite linearly ordered type V, and the order is the identifier order. An R-round algorithm is a function SimpleGraph V → (V → Bool) → V → Fin 3 whose output at u depends only on the radius-R view of u (CSLib Cslib.Local.IsLocal: edges at nodes at distance < R, labels at distance ≤ R). The advice is one bit per node, and the algorithm knows the degree bound Δ. The paper's colours 1, 2, 3 are 0, 1, 2. Components of G_{2,3} and distances dist_C are those of the graph H23 G φ on V, where colour-1 nodes are isolated. Nodes in different components are at distance ⊤, so the per-component ruling sets R_C merge into one set R.

  • Theorem 5. Identifiers are natural numbers. An instance is a finite node set Vs ⊆ ℕ, a graph on ℕ with edges inside Vs, and node inputs from a finite alphabet. The algorithm A : ℕ → SimpleGraph ℕ → (ℕ → In × (Fin β → Bool)) → ℕ → Out gets the number of nodes n as first argument, and each A n is T-local. The paper's "identifiers in {1,…,poly(n)}" is abstracted as any admissibility predicate that accepts every {1,…,N}. "Component-wise defined" means: a valid solution restricts, along an isomorphism onto a union of components, to a valid solution. The graph family must be closed under disjoint unions of copies. The conclusion is stronger than the paper's: A' is order-invariant, does not know n, and works for arbitrary identifiers.

  • Randomness appears only inside a proof (Lemma 32): the LLL on a uniform finite product space, where probabilities are counts.
