All Byzantine Agreement Problems Are Expensive — PODC 2024

Pierre Civit, Seth Gilbert, Rachid Guerraoui, Jovan Komatovic, Anton Paramonov, Manuel Vidigueira. All Byzantine Agreement Problems Are Expensive. PODC 2024. DOI 10.1145/3662158.3662780. Formalized version: arXiv:2311.08060v2 (numbering follows it). Companion of On the Validity of Consensus (PODC 2023, ValidityConsensus). Copy of the paper: paper.pdf.

Verdict: 🔧 Easy fix. The main result holds: every non-trivial Byzantine agreement problem needs Ω(t²) messages, even in synchrony, and we prove it for every t < n with the explicit bound t² ≤ 32 · #messages, with or without signatures (the paper proves the weak-consensus bound even against omission faults; we also get the omission version for every non-trivial problem). Lemma 1's proof covers only t divisible by 8 and is repaired by rounding its parameters. The solvability characterization (Theorem 4) is proved too, but Lemma 10 and the unauthenticated half of Theorem 4 are false for n = 2, t = 1, and one added condition corrects them.

Mistakes in the paper

🔧 Lemma 10 and Theorem 4 (unauthenticated), n = 2, t = 1

Lemma 10 (unauthenticated-solvable with n ≤ 3t ⇒ trivial) and the unauthenticated half of Theorem 4 are false for n = 2, t = 1: weak consensus, a non-trivial problem, is solvable there by "exchange proposals; decide the common value if they agree, a default otherwise" (lemma10_counterexample, theorem4_unauth_as_stated_false).

Impact. The lower bound and the authenticated half of Theorem 4 are unaffected, and we prove corrected statements (trivial_of_solvableSync, theorem4_unauth').

Details

Theorem 4 says a non-trivial problem is unauthenticated-solvable iff CC holds and n > 3t. Both statements rest on the cited FLM-style fact that weak consensus needs n > 3t. With two processes and one fault, every faulty execution has a single correct process, so Agreement constrains only fault-free executions. The same idea solves interactive consistency. The FLM argument needs three non-empty groups of size ≤ t, i.e. n ≥ 3.

Repair

Lemma 10 holds for 3 ≤ n ≤ 3t. A non-trivial problem is unauthenticated-solvable iff CC holds and (n > 3t or n ≤ 2). (trivial_of_solvableSync, theorem4_unauth')

Proof gaps in true statements (1)Lemma 1

🔧 Lemma 1 (the "without loss of generality" step)

Lemma 1 is proved only for t ≥ 8 divisible by 8: for other t the group sizes t/4 and t/2 must be rounded, and t = 1 admits no group of size ≥ 1 of the required kind.

Impact. Statement true for every t < n; repaired (omission_lower_bound, omission_lower_bound_sq, one_message).

Repair

We prove a parametric bound (⌈β/2⌉·σ messages) and choose parameters for every t. For t = 1 we add a separate zero-message argument: without any messages each process decides as in isolation, which contradicts Agreement in a mixed fault-free execution. (omission_lower_bound, omission_lower_bound_sq, one_message)

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchrony. The shared partially synchronous Byzantine model, restricted to runs with gst = 0. Delays lie in [0, δ]; δ = 0 is the paper's lock-step round model.

    • n deterministic processes, at most t < n statically Byzantine, authenticated links.

    • Optional ideal signatures (unforgeable tokens). Every lower bound is proved with signatures.

    • The lower bounds hold for every δ; Algorithm 1 is stated for δ = 0.

  • Omission model. A lock-step execution is the inputs plus a set of omitted message batches. A fault set is admissible if every omitted batch has an endpoint in it, so the paper's swap_omission (Lemma 15) is just another admissible fault set for the same execution. Omission executions are simulated by Byzantine runs, so the omission lower bounds transfer.

  • Message complexity. Messages sent by correct processes to others from time 0. Omitted messages count, and self-messages do not. Results are stated as "some valid run has ≥ … messages within finite time".

Remarks.

  • Algorithm 1 (Lemma 6) needs lock-step rounds. It assumes that a fault-free execution is determined by the proposals. That fails if the adversary may choose delays in [0, δ] with δ > 0. This is harmless: the paper's model is lock-step, and we prove Theorem 3 directly in the omission model for every δ.

  • The proof of Theorem 5 assumes "without loss of generality n = 2t"; we prove it for every n ≤ 2t.

  • "Without loss of generality, the default is 1" before Lemma 4 is made explicit.

  • As in the 2023 paper, "Γ is computable" requires the algorithm to be computable.
