import Mathlib.Tactic import Mathlib.Data.List.Basic /-! # Broadcast abstractions, their symmetry properties, and algorithms on top of them Gay, Mostéfaoui, Perrin, *No Broadcast Abstraction Characterizes k-Set-Agreement in Message-Passing Systems* (PODC 2024 brief announcement; extended version HAL hal-04571653). ## Broadcast level (Sections 3.1, 3.2, Definition 5) A *B-execution* (`BExec`) records the events of a broadcast abstraction at the times they occur (`none` = no event of the abstraction at that time), together with the set of correct processes: * `bc p m` — `p` invokes `B.broadcast(m)`; * `ret p m` — `p` returns from `B.broadcast(m)`; * `dl p q m` — `p` B-delivers `m` from `q`. A message is identified by its sender and its message object `m : M`; a process never broadcasts the same object twice (`UniqueBc`, the paper's "each broadcast message is unique, regardless of having identical content"). At the algorithm level the message objects are pairs `(id, content) : ℕ × C`: the algorithm chooses the content, the identifier is arbitrary (chosen by the environment, e.g. a local sequence number). A *broadcast abstraction* is a set `S` of B-executions, all of which satisfy the four properties of Section 3.1 (BC-Validity, BC-No-Duplication, BC-Local-Termination, BC-Global-CS-Termination) and the well-formedness of the invocations (Definition 1). * `Compositional S` (Definition 2): `S` is closed under restriction to any set of messages. * `ContentNeutral S` (Definition 3): `S` is closed under injective renaming of the messages (sender-preserving: the renaming may depend on the sender). * `NSolo N E` (Definition 5). ## Algorithm level (`CAMP_n[B]`, Section 2) An algorithm `A` (`Algo`) is deterministic: the next action of process `p` (broadcast a content, decide a value, or wait) is a function of its proposal and its local history (its own invocations, returns, deliveries and decisions). An execution of `A` on top of `S` (`AExec`, `Admissible`) is a sequence of steps whose projection to the broadcast events belongs to `S`, whose steps of `A` follow `A`, and in which every correct process takes infinitely many steps of `A`. `SolvesKSA k A S`: every admissible execution satisfies k-SA-Validity, k-SA-Agreement and k-SA-Termination (Section 4.1). Model simplification: `A` uses only the broadcast abstraction, no point-to-point channels. The algorithms we consider (`Counterexample.lean`) never use point-to-point channels, so this is a sub-case of the paper's `CAMP_n[B]`. -/ namespace Podc.NoBroadcastKSA set_option
