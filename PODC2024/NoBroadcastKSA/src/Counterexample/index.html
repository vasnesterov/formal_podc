import Papers.PODC2024.NoBroadcastKSA.Spec /-! # Lemma 9 is false **Lemma 9** of the paper: for all `k > 1` and every content-neutral and compositional broadcast abstraction `B`, if some algorithm `A` solves k-SA in `CAMP_{k+1}[B]`, then there is `N > 0` such that `B` admits no `N`-solo execution. Counterexample (`lemma9_false`). Call a message *chained* (`Chained`) if its sender had already B-delivered one of its own messages when it invoked `broadcast` for it. The abstraction `chainedBO k` is *k-Bounded-Order broadcast restricted to chained messages*: among any `k + 1` distinct chained messages, two are delivered in the same order by all processes (`PQ`). It is compositional and content-neutral, and it contains every uniform total-order execution (`totalOrder_mem`), so it is implementable from consensus. The algorithm `algQ`: * broadcast a dummy message, wait until it returns and is delivered locally; * broadcast the proposal (this message is chained); * decide the value of the first value message delivered. solves k-SA in `CAMP_{k+1}[chainedBO k]` (`algQ_solves`). But for every `N` the abstraction admits an `N`-solo execution (`soloExec_mem`, `soloExec_nSolo`): every process invokes its `N` broadcasts before delivering anything, so no message is chained and the ordering property is void. The paper's proof fails at "`αᵢ` is indistinguishable from `δ`": an `N`-solo execution fixes only the order of deliveries, not when the invocations happen relative to the deliveries, so the local pattern of `pᵢ` in `δ` need not be the one of the solo run `αᵢ`. -/ namespace Podc.NoBroadcastKSA open BExec variable {P M : Type} /-! ## The abstraction `chainedBO k` -/ /-- The message `(q, m)` is
