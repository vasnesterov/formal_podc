import Papers.PODC2024.TetraBFT.ViewLiveness /-! # Termination of TetraBFT with a repaired view-change echo rule (not in the paper) The paper's echo rule ("on `f + 1` view-change messages for `v'`, send one for `v'` unless one for `v'` *or any higher view* was sent") can deadlock (`Counterexample.lean`). With the repaired rule (`prm.fixEcho = true`: echo every view `w ≥` the current one with `f + 1` view-change messages for which no view-change message was sent yet), views synchronize after GST: * **spacing**: a correct node reaches view `u + 1` only after some correct node spent a full timeout in a view `≥ u`; so the first time a correct node reaches `u + 1` is at least `T` after the first time a correct node reaches `u` (`reach_spacing`); * **catch-up**: if the first correct node reaches `u` at time `e ≥ GST`, every correct node is in `u` during `[e + 2δ + 2, e + T)` (`sync_window`); * **progress**: every view is eventually reached (`reach_all`). With a timeout `T ≥ 8δ + 9` (the paper's `9Δ` up to the discrete-time constants) and a correct leader for infinitely many views, the window contains the `6(δ + 1)` ticks needed by `decides_of_synchronized_view`, so every correct node decides (`fixed_termination`), and the repaired protocol solves consensus (`fixed_solvesConsensus`). -/ set_option linter.unusedSectionVars false
