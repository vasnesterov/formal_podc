import Papers.PODC2024.TetraBFT.Defs /-! # Safety of single-shot TetraBFT (Lemmas 6–8, Theorem 1: agreement) We prove safety for every *abstract execution*: a set of faulty nodes and, for each correct node, the set of votes it ever cast, subject to the four guarantees the protocol gives (`Execution.SafetyHyp`): * (one value) a correct node casts at most one vote-k per view; * (quorum) a correct vote-k (k = 2, 3, 4) for `x` in view `r` is preceded by a quorum of vote-(k−1) messages for `x` in view `r` — only the *correct* members of that quorum are known to have cast those votes, Byzantine members may have sent anything to anybody; * (Rule 3) a correct vote-1 for `x` in view `r` is preceded by a set `S` of proof messages for view `r` such that `x` is safe by Rule 3, where every correct sender reported *honestly* (`IsReport`) its votes of views `< r` (Byzantine senders may report anything); * (decision) a correct node decides `x` in view `v` only if `x` is *committed* in `v`: some quorum's correct members all cast vote-4 for `x` in `v`. No timing, no channels and no view synchronization are involved, so this covers all asynchronous executions. `Refinement.lean` shows that the message-level protocol (`Protocol.lean`) produces such executions. -/ namespace TetraBFT open Finset Cslib.Quorum variable {P V : Type*} [Fintype P] [DecidableEq P] /-- An abstract execution: faulty nodes, votes cast by correct nodes, and decisions (`decided p x v`: node `p` decides `x` in view `v`). -/ structure Execution (P V : Type*) where faulty : Finset P voted : P → Vote V → Prop decided : P → V → ℕ → Prop namespace Execution variable (E : Execution P V) (f : ℕ) /-- `x` is committed in view `v`: there is a quorum whose correct members cast vote-4 for `x` in view `v`. -/ def Committed (x : V) (v : ℕ) : Prop := ∃ Q : Finset P, Fintype.card P -
