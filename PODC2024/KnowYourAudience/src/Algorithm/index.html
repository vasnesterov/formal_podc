import Papers.PODC2024.KnowYourAudience.Decode /-! # The view-based algorithm Each agent stores its view: after round `t` its state is `⟨t, (input, R)⟩` where `R` is the multiset of the depth-`(t-1)` views received from its in-neighbours. In round `t + 1` it sends its depth-`t` view, tagged with `dd (outdegree)` (`dd = id`: outdegree awareness; `dd = 0`: simple broadcast / symmetric communications). From round `t + 2 ≥ 2` on, it decodes (`decodeQ`) its view at depth `s + 1 = ⌊t/2⌋ + 1` with lookahead `K = t - ⌊t/2⌋` (`classes`, `solve`), and its output is any function `G` of its state and of the decoded multiset. * `run_viewAlg`: the state of agent `i` after round `t` (the algorithm builds views). * `viewAlg_decode`: eventually every agent decodes a nonempty multiset `u` with `n • u = |u| •
