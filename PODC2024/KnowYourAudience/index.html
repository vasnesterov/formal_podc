Know Your Audience — PODC 2024

Bernadette Charron-Bost, Patrick Lambein-Monette. Brief Announcement: Know Your Audience. PODC 2024. DOI 10.1145/3662158.3662784. Verdict: 🔧 Easy fix. Theorem 4.1 says that, with output port awareness, symmetric communications or outdegree awareness, a function is computable in static strongly connected anonymous networks iff it is frequency-based. The direction "frequency-based ⇒ computable" is true, and so are Corollaries 4.3 (size known) and 4.4 (one leader), while "computable ⇒ frequency-based" (and Corollary 4.2) fails only on networks with at most two agents; one condition on vector lengths saves it, and we prove the exact corrected characterisation: "frequency-based on vectors of length ≥ 2" (outdegree and output port awareness), and "symmetric and frequency-based on vectors of length ≥ 3" (symmetric communications). All the paper's examples (average computable, sum not) and its proof idea survive; Section 5 (dynamic networks) was not checked.

Mistakes in the paper

🔧 Theorem 4.1, (ii) ⇒ (i), and Corollary 4.2 (networks with at most two agents)

isSingleton(v) = [|v| = 1] is computable in every model, even simple broadcast, and with symmetric communications so is isPair(v) = [|v| = 2], yet neither is frequency-based: isSingleton(a) = 1 ≠ 0 = isSingleton(a, a) and isPair(a, b) = 1 ≠ 0 = isPair(a, b, a, b) (theorem_4_1_ii_imp_i_false, theorem_4_1_false, theorem_4_1_false_symmetric_K2, corollary_4_2_false).

Impact. The direction "frequency-based ⇒ computable", Corollaries 4.3 and 4.4, the paper's examples and its proof idea survive, and we prove the exact corrected characterisation. The failures are exactly at the sizes where the network is unique and self-identifying, so every symmetric function is computable there: n = 1 in every model, and n = 2 with symmetric communications, where K₂ is the only 2-agent network and its agents know it after two rounds. In the directed models, where K₂ is not recognisable, the theorem holds at n = 2.

Details

The paper's model (§2.1–2.2) puts a self-loop at every agent, and the transition function receives the multiset of received messages. So after round 1 an agent knows its indegree. In a strongly connected network the indegree is 1 iff the agent is alone, from every initial configuration. In a connected bidirectional network, an agent with a single neighbour whose neighbour also has a single neighbour lives in K₂. Agents learn their degree in round 1 and their neighbours' degrees in round 2.

Where the proof breaks: the proof of (ii) ⇒ (i) (§4.1) lifts both input vectors along the rings R_n → R_p ← R_m, where p is the lcm of the denominators of the frequencies. A bidirectional ring of size ≤ 2 is a multigraph (R_2 has a double edge and R_1 three loops), not a network of the class (§2.1 networks are simple digraphs ([n], E_t) with self-loops). So for p ≤ 2 (or n, m ≤ 2) Lemma 3.2 does not apply: the proof silently needs sizes ≥ 3.

Repair

For outdegree and output port awareness the failure matters only for n = 1. We use directed cycles instead and lift along C_{n'n} → C_n and C_{nn'} → C_{n'} (n, n' ≥ 2), together with Lemma 3.3 at length nn' (frequencyBasedFrom_two_of_computable). For symmetric communications we use bidirectional rings, which needs n, n' ≥ 3 (frequencyBasedFrom_three_of_computable_symmetric). These bounds are optimal, by isSingleton and isPair. The positive algorithm then has to treat n = 1 (and n = 2 for symmetric communications) separately (theorem_4_1_corrected, theorem_4_1_corrected_symmetric, corollary_4_2_corrected*).

✏️ Slips

  • Lemma 3.3: "if f is computed in an anonymous network class then f is multiset-based" holds only on the vector lengths of the networks in the class: computability in C_k says nothing about other lengths. Every use in the paper involves classes with networks of all sizes, so the uses are fine (Computes.perm_eq).

  • Table 1 and §6 (simple broadcast, cited from [20]): the claim that only set-based functions are computable with simple broadcast also fails at n = 1 in this paper's model (isSingleton_computable .broadcast).

Proof gaps in true statements (1)§4.3, symmetric variant of the algorithm

🔧 §4.3, symmetric variant of the algorithm

"Up to some permutation of the vertices in B, we may assume that none of the degrees d_{1,2}, …, d_{m−1,m} is zero, since B is strongly connected" assumes a Hamiltonian path in the minimum base, which fails, e.g., for a star with four distinct input values, which is its own minimum base.

Impact. The positive result with symmetric communications holds (theorem_4_1_i_imp_ii): our symmetric algorithm does not use this variant, and reads class outdegrees as indegrees in eq. (1).

Repair

Propagating eq. (4) along a spanning tree repairs the formula (not formalized).

Model.

  • Static network = simple directed graph on Fin n (n ≥ 1) with a self-loop at every agent and a local output port numbering. Synchronous lock-step rounds with synchronous starts; no failures; deterministic anonymous algorithms. An agent sends send(state, outdegree, port), and its transition gets the multiset of received messages. The models restrict send (CommModel.Allowed): simple broadcast and symmetric communications see only the state, outdegree awareness the state and the outdegree, output port awareness everything. Symmetric communications also restrict to bidirectional networks.

  • f : List Ω → X, where X is any metric space (main statements) or topological space. A computes f in a class if in every network of the class, for every input vector, every agent's output converges to f of the inputs.

  • Initial state = function of the input (the paper allows a set Q₀ of initial states). The counterexample algorithms are correct from every initial configuration, so they also compute in the paper's sense (detectOne_out, detectTwo_out).

  • Leaders (Cor. 4.4): inputs (value, isLeader) with exactly one leader (OneLeader). Known size / bound: classes sizeEq k, sizeLE B.

The positive direction uses an infinite-state view algorithm (viewAlg). At round t it reads, at depth ⌊t/2⌋, the colour-refinement classes of all agents (= the minimum base, once refinement has stabilised). It then reads the edge multiplicities and outdegrees between classes, and outputs f of the multiset given by any positive integer solution of eq. (1). The rank-one property of eq. (1) is proved by a maximum principle (if z > 0 solves it and the class graph is strongly connected, every solution is a multiple of z) instead of the paper's Perron–Frobenius argument. With symmetric communications the outdegree of a class is read off as its indegree, so no outdegree-learning phase is needed.

Not formalized. Section 5 (dynamic networks, Push-Sum). The finite-state, self-stabilizing version of the minimum-base algorithm and the n + D time bound. The covering-based variants of §4.3. The extension to ℓ known leaders.
