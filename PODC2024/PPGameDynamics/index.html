Game Dynamics in the Population Protocol Model — PODC 2024

Dan Alistarh, Krishnendu Chatterjee, Mehrdad Karrabi, John Lazarsfeld. Game Dynamics and Equilibrium Computation in the Population Protocol Model. PODC 2024. DOI 10.1145/3662158.3662768. Formalized version: arXiv 2307.07297 v3 (May 2024); numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. The exact stationary results hold (Theorem 2.4, Propositions A.1 and A.3, the stationary part of Theorem 2.7 and Proposition 2.8), and so does the Ω(km) mixing lower bound. The upper bound on the mixing time of the (k, a, b, m)-Ehrenfest process (Theorem 2.5) is false as stated: it ignores the laziness of the chain and fails when a + b is small, and its corrected form is not proved. The mixing and convergence claims of Theorem 2.7 and the equilibrium result Theorem 2.9 were not checked.

Mistakes in the paper

❌ Theorem 2.5, upper bound (and Proposition A.7, Lemmas A.5, A.8)

The bound t_mix = O(k² m log m) (a = b), resp. O(min{k/|a−b|, k²} m log m) (a ≠ b), ignores the laziness of the chain: for k = m = 2 and a = b = ε, t_mix ≥ 1/(2ε) grows without bound while the claimed bound stays fixed (theorem_2_5_upper_false, theorem_2_5_upper_false_ne, lemma_A_8_false).

Impact. Every k² term needs a factor 1/(a+b); the k/|a−b| branch is correct. This corrected bound is not proved in Lean, because the coupling part is not formalized.

Details

The theorem fixes any a, b > 0 with a + b ≤ 1. From x = (m, 0, …, 0) the chain stays put with probability 1 − a, so t_mix grows like 1/a as a → 0, while the claimed bound does not depend on a once k, m are fixed. Concretely, take k = m = 2 and a = b = ε. Then P(x, x) = 1 − ε and π(x) = 1/4, so d(t) ≥ (1 − ε)^t − 1/4, and d(t) ≤ 1/4 forces t ≥ 1/(2ε). The same happens for a = 2b = 2ε, where min{k/|a−b|, k²} = k².

The error is in Proposition A.7. For a = b, the process Z_t² − t is not a martingale (the right one is Z_t² − 2at), so E[τ_absorb] = k²/(2a), not k². The claim "the right-hand side of (26) is at most k²" fails in the same way: it tends to k²/(a+b) as a − b → 0.

If one reads the O of Theorem 2.5 as allowing constants that depend on a, b, the theorem itself survives, but the explicit |a − b| shows that the bound is meant uniformly in a, b. In any case the constant-free numbered statements behind it are false:

  • Proposition A.7 claims E[τ_absorb] ≤ k² for a = b, but the truth is k²/(2a).

  • Lemma A.5 claims E[τ_coal] ≤ k²; for k = 2, z = 1, w = 2 the walks coalesce at the first non-null step, so E[τ_coal] = 1/(a+b).

  • Lemma A.8 claims Pr[τ_couple > 2Φ log(4m)] ≤ 1/4, hence d(2Φ log(4m)) ≤ 1/4. Take the fixed values k = m = 2, a = 1/100, b = 1/200. Then Φ = 8 and 2Φ log₂ 8 = 48, but d(t) > 1/4 for all t ≤ 48 (lemma_A_8_false).

🔧 Proposition A.9 ("D ≥ km")

The diameter of the transition graph is (k−1)m, not ≥ km, since each ball moves at most k − 1 urns; e.g. k = m = 2 gives the path (2,0) – (1,1) – (0,2) with D = 2 < 4.

Impact. Off by one urn; the conclusion t_mix = Ω(km) holds: we prove t_mix ≥ (k−1)m/2 for all a, b (theorem_2_5_lower).

✏️ Slips

  • Theorem 2.7 (formula p_j ∝ (1/β − 1)^{j−1}, sampling convention): the stationary formula is exact only if the responder is drawn uniformly from all n agents, independently of the initiator; under the standard distinct-pair scheduler it is off by O(1/n) (distinct_counterexample). The paper's own computation in Section 2.2.1 fixes the convention, and the formula is exactly right in that model (theorem_2_7_stationary). That section says the initiator, at level j, meets a non-AD agent with probability (z_j/n)(1 − β), which is exact only if a GTFT agent may "meet itself". With the standard population-protocol scheduler (an ordered pair of distinct agents, as in the paper's references), the count process is still exactly an Ehrenfest process, but its parameters are a' = γ(n−1−βn)/(n−1) and b' = γβn/(n−1). So the stationary law is multinomial with ratio λ' = (n−1−βn)/(βn) = (1/β − 1) − 1/(βn), not 1/β − 1. Example: one AD and two GTFT agents, k = 2. The paper's law gives π(2,0) = 1/9; the true stationary law gives 1/4.

Typos

  • Definition 2.3 writes P : Δ_k^m → Δ_k^m for a matrix on Δ_k^m × Δ_k^m.

  • In A.3, the index runs over "j = 0, …, k − 1" (it should be j ∈ [k−1]), and an "inequality" should be "equality".

  • Remark A.2 says Δ_k^m for Δ_2^m.

  • In Proposition A.6, Z is initialized both to z and to 0.

  • Lemma A.8 needs log = log₂.

  • Contribution (ii) in §1.2 says O(kn log n) for β ≠ 1/2, hiding the factor 1/|1 − 2β| of Theorem 2.7.

Full list of differences (including modelling choices and minor imprecisions): differencies.md.

The formalizationmodel, Lean names of the results, trust

Model.

  • Finite discrete-time Markov chains are row-stochastic real matrices, as in CSLib's Cslib.Probability.Markov. A stationary distribution is a probability vector with π P = π. Mixing is d(t) ≤ 1/4 (IsMixedAt, total variation, maximum over starting states). We state "t_mix ≤ T" as "some t ≤ T has d(t) ≤ 1/4", so we never need sInf.

  • The (k, a, b, m)-Ehrenfest process is defined on Δ_k^m as an urn chain. With probability r(i,j)·x_i/m, one ball moves from urn i to urn j. The rates are a for j → j+1 and b for j+1 → j. Lemmas ehrenfest_apply_up/down/self/other check entrywise that this is exactly Definition 2.3. Urn j of the paper is index j − 1 ∈ Fin k.

  • The k-IGT dynamics (Definition 2.1) is a one-way CSLib population protocol (igt k) on states AC / AD / GTFT(level). Agent kinds are fixed by τ : A → Kind (an (α, β, γ) population with n = |A|). There are two random schedulers: replKernel draws the initiator and the responder independently and uniformly, which is the model behind (5). distinctKernel draws an ordered pair of distinct agents, the standard PP scheduler (CSLib's uniformKernel). Exactly one interaction happens per step.

  • The count vector z^t is counts. "{z^t} is the Ehrenfest process" is proved as exact lumpability. For every start configuration C, every t and every y, P[z^t = y] equals the t-step Ehrenfest probability from z(C) to y.

  • Our Theorems 2.4/2.7 and Propositions A.1/A.3 hold for all k ≥ 1 and m ≥ 0. The paper needs k, m ≥ 2.

  • The paper calls the multinomial "the unique stationary distribution" in Theorem 2.4, but detailed balance gives only stationarity, and irreducibility is argued only for k = 2, 3 ("easy to see"). We prove irreducibility for all k (ehrenfest_isIrreducible).

Not formalized. The corrected Theorem 2.5 upper bound (coupling, Lemmas A.5, A.8); the mixing-time bounds and the convergence claim of Theorem 2.7; Proposition 2.2 and Theorem 2.9 (game payoffs, ε-approximate distributional equilibrium); Appendices B–D. The derivation of Theorem 2.7's mixing upper bound uses the false Theorem 2.5, but the bound itself looks fine after the 1/(a+b) correction: there a + b = γ and m = γn, so (k²/γ)·m log m ≤ k² n log n. For Theorem 2.7's lower bound t_mix ≥ Ω(kn), Theorem 2.5 gives only Ω(km) = Ω(kγn), which is Ω(kn) only for constant γ; the statement is plausible (the chain is lazy with rate ≤ γ, which compensates).

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity: the hypotheses of theorem_2_7_stationary hold for the 3-agent population τ₀ (an example in IGT.lean), and ehrenfest_isStationary gives the stationary distribution that theorem_2_4 and proposition_2_8 assume.
