import Papers.PODC2024.ListDefectiveColoring.Section41 /-! # The paper's defect function (10) breaks Section 4.1 of [FK24] Fuchs, Kuhn. *Simpler and More General Distributed Coloring Based on Simple List Defective Coloring Algorithms* (PODC 2024; arXiv:2405.04648), cited as [FK24]. Section 4.1 defines the modified defects (eq. (10)) `d'_v(x) := ⌊(d_v(x) + 1) / (7θ)⌋ - 1` and claims that they are non-negative and satisfy `∑_{x ∈ L_v} (d'_v(x) + 1) ≥ (1/(7θ)) ∑_{x ∈ L_v} (d_v(x) + 1)` (eq. (11)). Both claims fail as soon as `d_v(x) + 1 < 7θ`: then `d'_v(x) = -1`. With negative defects, condition (12) never holds, so all lists `L_{v,i}` and all sets `H_i` are empty and *no node is ever coloured* (`it_eq_none_of_neg`); the run that colours nothing is a valid run (`isRun_none_of_neg`). Concretely, on the triangle `K₃` (maximum degree `2`, so `Δ = 2` needs no convention) with `θ = 1`, `S = 1`, zero defects (proper list colouring) and lists of size `85`, all hypotheses of Theorem 1.4 hold (slack `85 > 84 = 42 θ log Δ · S · deg(v)`, and also `85 > 21 θ (⌈log Δ⌉ + 1) S deg(v)`), but the Section 4.1 algorithm *as defined with eq. (10)* colours no node (`theorem_1_4_paper_defects_false`). This is a floor/ceiling slip in eq. (10): the paper itself states `d' ≥ 0`, and `⌈(d+1)/(7θ)⌉ - 1 = ⌊d/(7θ)⌋` (`dPrime`, see `Section41.lean`) makes Theorem 1.4 hold.
