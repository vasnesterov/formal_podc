import Papers.PODC2024.ListDefectiveColoring.Basic /-! # Lemma 4.5 of [FK24]: colour space reduction The colour space `C` is partitioned into subspaces `C_i` (`part : α → ι`, colour `x` lies in the subspace `part x`). Every node first picks a subspace `i`, by solving a list *defective* colouring instance `J` with colour space `ι` (cost `T_D(σ, p)`), and then solves the list *arbdefective* colouring instance `K` with list `L_{v,i} = L_v ∩ C_i` on the subgraph of edges whose endpoints picked the same subspace (cost `T_A(S/σ, ⌈C/p⌉)`). We formalize the combinatorial ("spec-level") content, for *any* solutions of the sub-instances: * `FK24.ColorSpace.choice_hasSlack`: `J` has slack `σ` (first display of the proof); * `FK24.ColorSpace.sub_hasSlack`: for every list defective colouring `ψ` of `J`, the instance `K` has slack `S/σ` on `sameClass G ψ` (second display of the proof); * `FK24.ColorSpace.isListArbdefective_of_sub`: every list arbdefective colouring of `K` on `sameClass G ψ` is a list arbdefective colouring of the original instance on `G`; * `FK24.lemma45`: the combination (Lemma 4.5, eq. (17)). **Gap in the proof's construction (trivial fix).** In the paper the subspace-choice instance has *all* `p` subspaces in every list. Then a node may pick a subspace `i` with `L_v ∩ C_i = ∅` (its defect `d_{v,i} = 0` is not violated if it has no neighbour picking `i`), after which it has an empty list. The step `(S/σ) · d_{v,i} ≥ ...`, `∑_{L_{v,i}} (d_v(x)+1) > (S/σ) d_{v,i}` fails for `d_{v,i} = 0`. We use the lists `{i | L_v ∩ C_i ≠ ∅}` (`(I.L v).image part`) instead; the slack computation of the paper goes through unchanged. `FK24.ColorSpace.paper_counterexample` shows that the construction with all subspaces can fail. The round-time statement (17) of Lemma 4.5 itself is not refuted.
