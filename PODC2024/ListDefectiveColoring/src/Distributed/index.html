A node's state (`NodeState`) contains its identifier, its initial colour, its out-neighbourhood (as a set of identifiers), its list and defect function (the local input), and the two outputs `S_v` and `x_v` (initially `none`). Identifiers are only used to recognise out-neighbours; the step function does not depend on the graph. Model: synchronous, deterministic, fault-free LOCAL rounds; all nodes start at round `0` and know `p` and `q`. Every node broadcasts its whole state each round, which is LOCAL; the paper's message size claim (Lemma 3.3: "the nodes exchange a list of `p` colours"; in Phase I the only new information is `S_v`, in Phase II only `x_v`) is not formalized. * Rounds `0, …, q-1` (Phase I): in round `t` the nodes with initial colour `t` choose `S_v` (a best `min(p, |L_v|)`-subset for the score `d_v(x) − k_v(x)`). * Rounds `q, …, 2q-1` (Phase II): in round `2q-1-c` the nodes with initial colour `c` choose `x_v ∈ S_v` with `k_v(x_v) + r_v(x_v) ≤ d_v(x_v)`. ## Main results * `twoSweep_correct` (**Lemma 3.3**, and **Theorem 1.1** for `ε = 0`): from a proper `q`-colouring, after `2q` rounds every node has output a colour and the outputs form an oriented list defective colouring, provided the slack condition (2) holds. * `twoSweep_listColoring`: the corollary for list colouring with lists of size `≥ β² + β + 1` (Section 1.1, "List coloring with bounded outdegree", `p = β + 1`, all defects `0`). * `twoSweep_threeColoring`: list `d`-defective colouring with lists of size `3` whenever `d > (2Δ − 3)/3` (Section 1.1, generalizing [BHL+19]), using `out v = N(v)`. -/ open Finset Cslib.LocallyIterative namespace FK24 variable {V α : Type*} /-- The local state of a node in the Two-Sweep algorithm. -/ structure NodeState (V α : Type*) where /-- The node's identifier. -/ id : V /-- The initial colour (from the proper `q`-colouring). -/ c : ℕ /-- The identifiers of the out-neighbours. -/ out : Finset V /-- The colour list `L_v`. -/ L : Finset α /-- The defect function `d_v`. -/ d : α → ℕ /-- The sublist `S_v` chosen in Phase I. -/ S : Option (Finset α) /-- The final colour `x_v` chosen in Phase II. -/ col : Option α namespace TwoSweepAlg /-- A best `m`-subset of `L` for the score `g` (any fixed choice;
