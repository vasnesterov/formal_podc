import Papers.PODC2024.ListDefectiveColoring.Basic import Papers.PODC2024.ListDefectiveColoring.NeighborhoodIndependence /-! # Section 4.1 of [FK24]: from list arbdefective to list defective colouring Fuchs, Kuhn. *Simpler and More General Distributed Coloring Based on Simple List Defective Coloring Algorithms* (PODC 2024; arXiv:2405.04648), cited as [FK24]. The algorithm of Section 4.1 solves a list defective colouring instance on a graph of neighbourhood independence `θ` by `⌈log Δ⌉ + 1` calls of an arbitrary list *arbdefective* colouring algorithm `A` (solving `P_A(S, C)`). Iterations are numbered `top, top - 1, …, 0` (`top = ⌈log Δ⌉`), so a *larger* index means an *earlier* iteration. In iteration `i`: * `aCount G it col v x i` (`a_v(x, i)`): neighbours of `v` coloured with `x` in iterations `> i`; * `uncolCount G it v i` (`deg(v) - deg~(v, i)`): neighbours of `v` not coloured in iterations `> i`; * `dI i = 2^i - 1` (`d_i`); * `Cond` (eq. (12)): `d_i ≤ d'_v(x) - a_v(x, i)`; * `InL` (`x ∈ L_{v,i}`): `x ∈ L_v`, eq. (12) holds in iteration `i` but in no earlier iteration; * `InH` (`v ∈ H_i`, eq. (13)): `v` is uncoloured and `∑_{x ∈ L_{v,i}} (d_i + 1) > S · (deg(v) - deg~(v, i))`. All nodes of `H_i` are coloured in iteration `i` by `A` with the lists `L_{v,i}` and the uniform defect `d_i`. We do not fix `A`: a *run* (`IsRun`) is any assignment of iterations `it` and colours `col` such that every node is coloured exactly in the iteration in which it lies in `H_i`, with a colour of `L_{v,i}`, and the colouring of each `H_i` is `d_i`-arbdefective (this is exactly the output specification of `P_A(S, C)` on `H_i`: the instance has slack `S` there, since the `H_i`-degree of `v` is at most `deg(v) - deg~(v, i)`; see `Section41Exists.lean`). The round complexity `(⌈log Δ⌉ + 1) · T_A(S, C)` is not modelled. The defect function `d'` used to define the lists is a parameter of the model. The paper's choice (eq. (10)) `d'_v(x) = ⌊(d_v(x) + 1) / (7θ)⌋ - 1` is negative when `d_v(x) + 1 < 7θ`, which breaks the algorithm (see `Section41Counterexample.lean`); we use the corrected `dPrime I θ v x = ⌊d_v(x) / (7θ)⌋` (`= ⌈(d_v(x) + 1)/(7θ)⌉ - 1`). ## Main results * `lemma_4_2`: every node is coloured in some iteration `≤ top`; * `lemma_4_3`, `lemma_4_3_sharp`: a node coloured with `x` has fewer than `max 1 (7θ · d'_v(x))` (in fact at most `4θ · d'_v(x)`) coloured neighbours of colour `x`; * `theorem_1_4`, `theorem_1_4_paper_slack`: Theorem 1.4 (correctness part). -/ open Finset SimpleGraph open scoped Classical namespace FK24 namespace Sec41 variable {V α : Type*} (G : SimpleGraph V) [G.LocallyFinite] /-! ### The model -/ /-- `u` has been coloured before iteration `i`, i.e. in some iteration `j > i` (iterations run from `top` down to `0`). -/ def ColoredBefore (it : V → Option ℕ) (u : V) (i : ℕ) : Prop := ∃ j, it u = some j ∧ i < j /-- The paper's `a_v(x, i)`: the number of neighbours of `v` coloured with `x` before iteration `i`. -/ noncomputable def aCount (it : V → Option ℕ) (col : V → α) (v : V) (x : α) (i : ℕ) : ℕ := #{u ∈ G.neighborFinset v | ColoredBefore it u i ∧ col u = x} /-- The paper's `deg(v) - deg~(v, i)`: the number of neighbours of `v` that are not coloured before iteration `i`. -/ noncomputable def uncolCount (it : V → Option ℕ) (v : V) (i : ℕ) : ℕ := #{u ∈ G.neighborFinset v | ¬ ColoredBefore it u i} /-- The round specific defect `d_i = 2^i - 1` of [FK24, Section 4.1]. -/ def dI (i : ℕ) : ℕ := 2 ^ i - 1 /-- Equation (12) of [FK24]: `d'_v(x) - a_v(x, i) ≥ d_i`. -/ def Cond (d' : V → α → ℤ) (it : V → Option ℕ) (col : V → α) (v : V) (x : α) (i : ℕ) : Prop := (dI i : ℤ) ≤ d' v x - aCount G it col v x i /-- `x ∈ L_{v,i}`: `x ∈ L_v` satisfies eq.
