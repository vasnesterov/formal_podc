Vertices as in `DirectedGadget.lean`. Edges: `ℓ_i r_i` and `ℓ'_i r'_i` of weight `1` ("light"); `ℓ_i ℓ'_j` iff `x (i, j)` and `r_i r'_j` iff `y (i, j)`, of weight `w` ("heavy"); and — our addition for the constant-diameter claim — `hub v` of weight `2w` for every `v ≠ hub`. Lemma 14 (generalised): if the sets intersect there is a cycle of weight `2w + 2`; otherwise every cycle has weight `≥ 4w` (`uGraph.weight_ge`). The paper's argument ("bipartite, the light edges form a matching, so a cycle has at most as many light as heavy edges, hence a cycle with `≥ 6` edges weighs `≥ 9`") only covers `w = 2`: for large `w` it gives only `3w + 3` for a `6`-cycle, which is below `4w`. The repair uses that a light edge is the only kind of edge between Alice's side `L ∪ L'` and Bob's side `R ∪ R'`, so every cycle has an *even* number of light edges. -/ namespace
