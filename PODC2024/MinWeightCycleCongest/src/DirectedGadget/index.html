Vertices: `ℓ_i, ℓ'_i, r_i, r'_i` (`i < k`), plus — our addition, needed for the "constant diameter" claim — a sink `hub` with an arc from every other vertex, and `p` padding vertices `pad_j` (so that every `n ≥ 1` is realised as `n = 4k + 1 + p`). Arcs: `ℓ_i → r_i`, `r'_i → ℓ'_i`; `ℓ'_j → ℓ_i` iff `x (i, j)` (Alice's set contains the pair `(i, j)`, the paper's `S_a[(i-1)k + j] = 1`); `r_i → r'_j` iff `y (i, j)`; `v → hub` for `v ≠ hub`. All arcs have weight `1`. Lemma 13: if the sets intersect there is a directed `4`-cycle; otherwise every directed cycle has length `≥ 8` (`dGraph_len_ge_eight`).
