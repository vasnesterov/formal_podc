import Papers.PODC2024.Swiper.WeightRestriction /-! # Swiper's construction for Weight Restriction (Appendix A.1, faithful route) The paper's proof of Theorem 2.1 considers `(t_s)_i = ⌊w_i s + αw⌋`, a *locally minimal viable* `s*` (`t_{s*}` viable, `t_{s*-ε}` not viable for all small `ε > 0`), the set `J = {i | w_i s* + αw ∈ ℤ}` of parties "on the border", the assignment `t'` that takes one ticket from every party of `J`, and then removes tickets from parties in `J` "as long as the ticket assignment stays viable", ending with `t̂` viable and `t̂̂ = t̂ - e_j` not viable. Here: * `exists_locallyMinimal`: a locally minimal viable `s*` exists. The paper only says "since we already proved that viable values of `s` exist, it is easy to see that such `s*` exists"; no such earlier proof is in the paper. We supply both steps: viable values exist by the key lemma (`exists_viable`), and the infimum of the viable values is attained by right-continuity of the floor (a discreteness argument); it is positive because `t_s = 0` for small `s`. * `border_nonempty`: `J ≠ ∅` ("Moreover, there must be some `j` such that `s* w_j + αw` is an integer"). * `ts_sub_eventually_eq`: footnote 6, `t' = t_{s*-ε}` for all small `ε > 0`; hence `t'` is not viable (`not_viable_removeTickets_border`). * `exists_removal`: the removal process stops at some `t̂ = t* - 1_K` (`K ⊆ J`) viable with `t* - 1_{K ∪ {j}}` not viable, `j ∈ J \ K`. * `removal_bound`: any such stopping point has `T ≤ ⌈αw (1 - αw) / (αn - αw) · n⌉`. * `wr_upper_bound_swiper`: Theorem 2.1 again, via this construction. -/ namespace
