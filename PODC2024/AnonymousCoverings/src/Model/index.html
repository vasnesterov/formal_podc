import Mathlib import Cslib.Foundations.Data.Nat.Descent /-! # Write–scan loops in the fully-anonymous shared-memory model Losa and Gafni, *Understanding Read-Write Wait-Free Coverings in the Fully-Anonymous Shared-Memory Model* (PODC 2024), study algorithms in which every processor repeatedly * writes its local information to a register it has not written since it last wrote all registers (fair, round-robin writes; label `l0`/`write` of Figures 1 and 3), and then * reads all registers one by one, in any order (label `l1`/`scan`). This file contains a generic model of such *write–scan loops*. * Processors `P` and registers `R` are finite types. The registers are anonymous: the paper fixes, for each processor, an unknown permutation (wiring) of the registers, and the algorithms pick a register nondeterministically (`with (r ∈ R \ written)`), so the wiring is absorbed into the nondeterministic choice of the register in each step (`Act.write p r`, `Act.read p r` name *physical* registers). Quantifying over all executions of the nondeterministic model covers every wiring and every deterministic resolution of the choices. * A register holds a value of type `X` together with a ghost field `writer` (the processor that wrote it last; `none` initially). The algorithms never read the ghost field. * The local state of a processor consists of algorithm data `d : D`, the set `written` of registers written in the current round-robin cycle, and `scan : Option (Finset R)`: `none` at the write label, `some S` while scanning, where `S` is the set of registers read in the current scan. * An algorithm (`Algo`) says what a processor writes (`wr`), how a read updates its data (`rd`), what it computes at the end of a scan (`fin`), and when it stops (`stop`, checked at the write label; a stopped processor can only take idle steps). * An execution is an infinite sequence of configurations with a sequence of actions, each consecutive pair being a step of the action's processor (asynchrony: the schedule is arbitrary). -/ namespace
