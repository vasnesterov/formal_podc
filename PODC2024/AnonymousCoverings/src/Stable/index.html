The paper's GST only requires the writes of non-live processors to be overwritten; a register may still hold an old view of a live processor, so we also wait until every register has been rewritten after the views stabilized. `Exec.readsOnlyFrom_minimal`: live processors whose stable view is minimal read, after `T₀`, only from live processors with the same stable view (Lemma 4.4 applied to a
