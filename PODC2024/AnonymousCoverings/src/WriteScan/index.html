import Papers.PODC2024.AnonymousCoverings.Stable /-! # The write–scan loop (Figure 1) and the eventual pattern (Theorem 4.8) Figure 1 of the paper: each processor writes its view (the set of inputs it knows) to a register it has not written in the current round-robin cycle, then reads all registers one by one, adding the values read to its view, forever. **Theorem 4.8** (`theorem_4_8`): in every infinite execution with at least as many registers as processors, the stable views (views of live processors after stabilization, Definition 4.2) have a least element: the stable-view graph (Definition 4.3: vertices = stable views, edges = strict inclusion) is a DAG with a unique source (`theorem_4_8_unique_source`). The hypothesis `card P ≤ card R` is needed: with fewer registers than processors two non-communicating groups can coexist forever (`Counterexamples.lean`). The paper does not state the number of registers in Section 4, but its proofs use `N` registers. -/ namespace Podc.AnonymousCoverings open Finset variable {P R V : Type*} [Fintype P] [DecidableEq P] [DecidableEq R] [Fintype R] [DecidableEq V] /-- **Figure 1** (the write–scan loop): the local data is the view, the written value is the view, a read adds the value read to the view; the loop never stops. -/ def writeScan : Algo R (Finset V) (Finset V) where wr d := d rd d _ x := d ∪ x fin d := d stop _ := False /-- Initial configuration: empty registers; each processor at the write label with view `{input p}` and nothing written. -/ def initCfg {D : Type*} (d₀ : P → D) {X : Type*} (x₀ : X) : Cfg P R D X := ⟨fun _ => ⟨x₀, none⟩, fun p => ⟨d₀ p, ∅, none⟩⟩ namespace Exec variable (e : Exec (P := P) (writeScan (R := R) (V := V))) omit [Fintype P] in /-- In Figure 1 the view changes only by a read, which adds the value read. -/ theorem ws_view_succ (t : ℕ) (p : P) : (e.loc (t + 1) p).d = (e.loc t p).d ∨ ∃ r, e.act t = .read p r ∧ (e.loc (t + 1) p).d = (e.loc t p).d ∪ (e.reg t r).val := by by_cases hm : e.Moves t p · obtain ⟨r, hr | hr⟩ := hm · left;
