import Papers.PODC2024.FairOrderingSocialChoice.Batches /-! # Lemma 3.8: the Themis example Lemma 3.8 of [Ramseyer–Goel]: in Themis, even if all replicas report `τ` before `τ'`, there are no faulty replicas and no cycles of `γ`-ordering dependencies for any `γ > 1/2`, the output may put `τ'` before `τ`. We do not model the Themis protocol. We formalize the example of the paper's proof and Themis's dependency rule as the proof paraphrases it: with `w(τ, τ')` the number of votes for `τ ≺ τ'`, a dependency `(τ, τ')` is included if (1) `w(τ, τ') ≥ w(τ', τ)` and (2) `w(τ, τ') ≥ n(1 - γ) + f + 1`, ties in (1) being broken arbitrarily (`ThemisDeps`). Inside a strongly connected component Themis walks along a Hamiltonian cycle. The example: `n = 2g` replicas, `f = 0`; `g` replicas receive `τ₁ ≺ τ₂ ≺ τ₃`, the other `g` receive `τ₃ ≺ τ₁ ≺ τ₂` (transactions `0, 1, 2 : Fin 3`). Then `w(τ₁, τ₂) = 2g` and all other pairs are tied at `g`, so the cycle `τ₁ → τ₂ → τ₃ → τ₁` is a valid choice of dependencies **provided `g ≥ n(1 - γ) + 1`, i.e. `γ ≥ 1/2 + 1/n`** (`cycleDeps_iff`). The paper's justification of (2) via "`(1 - γ) + (f + 1)/n ≤ (1 - γ) + 2f/n`" fails for `f = 0` (`paper_step_false`); e.g. for `n = 4`, `γ = 3/5` the cycle is not a valid dependency set.
