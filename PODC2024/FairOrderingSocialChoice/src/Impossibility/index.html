Goel. *Fair Ordering in Replicated Systems via Streaming Social Choice* (arXiv 2304.02730v4; Brief Announcement at PODC 2024). **Lemma 3.4.** No protocol achieves exact `γ`-minimality (Definition 3.3) with `f` faulty replicas when `1/2 < γ ≤ 1` and `f > n mod (n - ⌈γ n⌉ + 1)`; this holds even for the weak version that only constrains scenarios whose true `γ`-graph is acyclic. Main statement: `lemma_3_4`. ## The paper's proof does not work The paper splits the replicas into `k = n / (n - m + 1)` groups of `d = n - m + 1` replicas (`m = ⌈γ n⌉`), group `j` reporting the rotation `τ_{j+1} ≺ ⋯ ≺ τ_j`, plus `n mod d` faulty replicas copying one group, and claims that the pairs `(τ_i, τ_j)`, `i < j`, then receive at least `m` votes. In fact every arc of the cyclic order contains a whole group, so *every* ordered pair gets at most `n - d = m - 1 < γ n` votes, and exact `γ`-minimality imposes no constraint on the output (`lemma_3_4_paper_construction_vacuous`, concretely `lemma_3_4_paper_construction_n7` for `n = 7`, `γ = 2/3`). ## Corrected proof All scenarios share the *reported* profile `P` above (group `j` reports `rot j`, the extra `r` replicas join group `0`). In scenario `i`, `|group i| - (n - m) ≤ r + 1 ≤ f` replicas of group `i` are faulty and truly voted `rot (i + 1)`. Then group `i` has `n - m` true members and every other group at least `d = n - m + 1`, so the only pair with `≥ m` true votes is `(τ_i, τ_{i+1})`: the true `γ`-graph is a single edge (acyclic) and exact `γ`-minimality forces `τ_i` before `τ_{i+1}` in the output on `P`. Since `P` is the same in all `k` scenarios, the output would contain the cycle `τ₀ → τ₁ → ⋯ → τ_{k-1} → τ₀` (`cyclic_fails`). If `k = 1` (then `f ≥ m`), two transactions suffice: everybody reports `τ₀ ≺ τ₁`; either all are honest, or `m` of them truly voted `τ₁ ≺ τ₀`. `lemma_3_4_n7_f1` proves the remark that `n = 7`, `γ = 2/3` admits `f = 1`, which the stated condition (`f > 7 mod 3 = 1`) does not cover (`lemma_3_4_n7_f1_not_covered`); it uses groups of unequal sizes `3, 3, 1`.
