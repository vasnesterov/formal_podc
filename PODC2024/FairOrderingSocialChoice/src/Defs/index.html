import Cslib.Foundations.SocialChoice.Aggregation import Mathlib /-! # Fair ordering via streaming social choice: definitions of Section 3 G. Ramseyer, A. Goel. *Fair Ordering in Replicated Systems via Streaming Social Choice* (arXiv 2304.02730v4; Brief Announcement at PODC 2024). `n` replicas (a finite type `ι`) each submit an ordering vote on a set of transactions `X`. In the static setting (Sections 3–4) every replica votes on every transaction, so a vote is a strict total order on `X`: a `Cslib.SocialChoice.Pref X`, where `P a b` means "`a` before `b`". * `count σ a b`: the number of replicas reporting `a ≺ b` (the ordering graph of Def. 3.2 has edge weight `count σ a b / n`). * `AtLeast σ γ a b`: at least `γ n` replicas report `a ≺ b`. * `ExactlyMinimal T γ out` (Def. 3.3) and `MinimalBatchFair T γ δ out` (Def. 3.5): the output order `out` reverses a pair that `γ n` replicas *truly* received in order only if a chain of pairs, each received in order by `γ n` (resp. `(γ - 2δ) n`) replicas, is output in order from the second transaction back to the first. `T` is the profile of true (observed) orderings. * Faulty replicas: `Agree T P F` says that the reported profile `P` coincides with the true profile `T` outside the faulty set `F`. A deterministic ranking algorithm is an aggregation map `Cslib.SocialChoice.Aggregation ι X = Profile ι X → Pref X` applied to the reported profile. -/ namespace Podc.FairOrderingSocialChoice open Cslib.SocialChoice Finset Relation variable {ι X : Type*} [Fintype ι] /-- Number of replicas whose vote puts `a` before `b`. -/ noncomputable def count (σ : Profile ι X) (a b : X) : ℕ := by classical exact #{i | (σ i).P a b} theorem count_def [DecidableEq ι] (σ : Profile ι X) (a b : X) [DecidablePred fun i => (σ i).P a b] : count σ a b = #{i | (σ i).P a b} := by unfold count; congr 1; ext; simp theorem count_le (σ : Profile ι X) (a b : X) : count σ a b ≤ Fintype.card ι := by classical unfold count; exact card_filter_le _ _ /-- For distinct `a, b`, the counts of the two directions add up to `n`. -/ theorem count_add_count (σ : Profile ι X) {a b : X} (hab : a ≠ b) : count σ a b + count σ b a = Fintype.card ι := by classical unfold count rw [← card_union_of_disjoint] · convert card_univ (α := ι) ext i; simp only [mem_union, mem_filter, mem_univ, true_and, iff_true] exact (σ i).total hab · rw [disjoint_filter]; intro i _ h h'; exact (σ i).asymm h h' /-- The weight `w(a, b)` of the ordering graph (Def. 3.2): the fraction of replicas reporting `a ≺ b`. -/ noncomputable def weight (σ : Profile ι X) (a b : X) : ℝ := count σ a b / Fintype.card ι /-- At least `γ n` replicas report (or received) `a ≺ b`. -/ def AtLeast (σ : Profile ι X) (γ : ℝ) (a b : X) : Prop := γ * Fintype.card ι ≤ count σ a b /-- **Definition 3.3** (exact `γ`-minimality).
