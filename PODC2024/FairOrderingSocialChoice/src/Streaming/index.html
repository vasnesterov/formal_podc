import Papers.PODC2024.FairOrderingSocialChoice.RankedPairs /-! # Streaming Ranked Pairs (Section 5, Algorithm 3) Ordering votes are finite lists (Def. 2.2); `σ' ` *extends* `σ` if every `σ i` is a prefix of `σ' i`. At any time, the algorithm sees the current votes `σ : ι → List α`. * `V σ`: transactions on which every replica has voted; `Partial σ u`: voted by some but not all. * `cnt σ a b`: number of replicas whose vote has `a` before `b` (the weight of Def. 3.2, times `n`). * The *streamed ordering graph* (Def. 5.7) has an extra vertex `v̂` (`none : Option α`), edges `(τ, v̂)` for all `τ ∈ V σ` and `(v̂, τ)` iff some partially-voted transaction precedes `τ` in some vote (`FutIn σ τ`). Both are indeterminate from the start. * `InR σ a x` (`x ∈ R_a`: `w(x, a) = 0`) and `InP σ b x` (`x ∈ P_b`: `w(x, b) = 1`) (Def. 5.5); `U σ (a, b) = (V \ (R_a ∪ P_b)) ∪ {v̂}`. * `dec σ tb e ∈ {acc, rej, ind}`: Algorithm 3's decision on the edge `e` between transactions of `V σ`. Edges are processed in decreasing weight, ties broken by a fixed global injective rule `tb` (`key`). An edge is rejected if `H|U` has a determinate path back, accepted (determinate) if `H|U` has no path back at all, and indeterminate otherwise; accepted and indeterminate edges are added to `H`. * `output σ tb`: the transactions output (see below), ordered by `detLt` (determinate edges). ## Output rule (repaired) Algorithm 3 outputs "the topological sort of `H` (determinate edges only), up to but not including the first transaction bordering an indeterminate edge". Literally, *every* `τ ∈ V` borders the indeterminate edge `(τ, v̂)` added at initialization, so the output would always be empty. We read "bordering" as: incident to an indeterminate edge between two transactions, or the target of the edge `(v̂, τ)` (`Clean`). For a clean `τ`, all edges between `τ` and other transactions are determinate, so the clean transactions that precede every non-clean one in the topological order are well defined: `output σ tb = {x | Clean x ∧ ∀ dirty y, detLt x y}`. ## Main results * `observation_5_4`, `lemma_5_6`: Ranked Pairs on a complete profile always chooses weight-1 edges; chosen paths from `b` to `a` avoid `R_a ∪ P_b`. * `dec_mono`: decisions are stable under extension of the votes (the core of Lemma 5.8 and Corollary 5.9; the paper's one-line proof of Corollary 5.9 does not argue this). * `lemma_5_8`: determinate decisions agree with non-streaming Ranked Pairs on any counterfactual completion of the votes (with the same tie-breaking rule). * `theorem_5_10`: the output is an initial segment of Ranked Pairs' output on any completion. * `corollary_5_9`: Algorithm 3 is monotonic. -/ namespace Podc.FairOrderingSocialChoice.Streaming open Finset Relation RP variable {ι α : Type*} [Fintype ι] [DecidableEq α]
