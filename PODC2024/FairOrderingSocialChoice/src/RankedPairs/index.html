import Mathlib /-! # Ranked Pairs: the greedy acyclic edge selection Ranked Pairs (Tideman; Algorithm 2 of Ramseyer–Goel) iterates over the ordered pairs `(a, b)` of distinct candidates in decreasing order of weight and accepts an edge unless it closes a directed cycle with the edges accepted so far. The output ranking is the transitive closure of the accepted edges. We abstract the processing order as a `key : α × α → β` into a well-founded linear order: edges are processed in increasing `key`. Ranked Pairs is the case where `key` is weight-antitone (heavier edges first) and injective (ties broken by a fixed rule). Candidates range over a set `S`. * `accepted S key e`: the edge `e` is accepted (defined by well-founded recursion on `key`). * `before S key e`: the edges accepted before `e` is processed. * `rpLt S key`: the output relation (transitive closure of accepted edges). * `rpLt_irrefl` (acyclicity), `rpLt_total`: the output is a strict total order on `S`. * `rejected_path` (Lemma 5.3 shape): a rejected edge `(a, b)` is closed by a path `b ⇝ a` of edges accepted earlier. * `accepted_of_top`: an edge is accepted if every earlier accepted edge belongs to a relation `U` that contains it and is acyclic (used for Observation 5.4: weight-1 edges are always accepted). -/ -- CSLib candidate: a generic `Ranked Pairs` / greedy-acyclic-selection module for -- `Cslib/Foundations/SocialChoice/`. namespace
