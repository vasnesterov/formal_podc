import Cslib.Computability.Distributed.SharedMemory.Mutex import Cslib.Computability.Distributed.SharedMemory.Objects.FetchAdd import Cslib.Computability.Distributed.SharedMemory.Objects.MaxRegister import Cslib.Computability.Distributed.SharedMemory.Objects.Snapshot import Cslib.Computability.Distributed.SharedMemory.OneAccess import Cslib.Computability.Distributed.SharedMemory.Task import Papers.PODC2024.StrongLinCN2.Packing /-! # Max register and atomic snapshot from `fetch&add` (Theorems 1 and 2) Attiya, Castañeda and Enea, *Strong Linearizability using Primitives with Consensus Number 2*, PODC 2024, Sections 3.1 and 3.2. `n` processes `Fin n` share one unbounded `fetch&add` register `R`; bit `j` of process `i` is bit `j * n + i` of `R` (`Packing.lean`). * **Max register (Theorem 1).** Process `i` stores the largest value it has written in unary (bits `1, …, prevLocalMax`). `WriteMax(K)`: if `K ≤ prevLocalMax` then `fetch&add(R, 0)`; otherwise `fetch&add(R, ∑_{j = prevLocalMax+1}^{K} 2^{j n + i})` and `prevLocalMax := K`. `ReadMax`: `fetch&add(R, 0)`, reconstruct each process's maximum (the number of its set bits) and return the largest. Register values are natural numbers. * **Snapshot (Theorem 2).** Process `i`'s component (a natural number) is stored in binary in its bits. `update(v)`: if `v = prevVal` then `fetch&add(R, 0)`; otherwise `fetch&add(R, posAdj − negAdj)` (bits to set minus bits to clear) and `prevVal := v`. `scan`: `fetch&add(R, 0)` and decode. The adjustment may be negative, so `R` is an integer `fetch&add` register. Both are single-access implementations (`Cslib/Computability/Distributed/SharedMemory/OneAccess.lean`), hence wait-free and strongly linearizable, with linearization point at the unique `fetch&add`.
