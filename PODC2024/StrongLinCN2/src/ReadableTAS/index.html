The processes share a (non-readable) test&set object `ts` and a read/write register `state`, initially `0` (`false`). * `read()`: read `state` and return the value read; * `test&set()`: `b ← ts.test&set()`, then `state.write(1)`, then return `b`. Linearization (paper): reads at their read of `state`; let `e` be the first write of `1` to `state` and `op*` the test&set that obtains `0` from `ts`: `op*` is linearized at `e`, followed by all test&set operations that accessed `ts` before `e`; every other test&set is linearized at its access to `ts`. We prove this is a forward simulation (`linSim`), hence the implementation is strongly linearizable; it is wait-free (at most two accesses per operation).
