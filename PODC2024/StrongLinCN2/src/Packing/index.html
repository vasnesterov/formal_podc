import Mathlib /-! # Interleaved bit packing Attiya, Castañeda and Enea (PODC 2024, Sections 3.1–3.2) store an `n`-component vector in a single unbounded `fetch&add` register `R` by *interleaving* the bits of the processes: bit `j` of process `i` is bit `j * n + i` of `R`. Here a component is described by its set of bits `E i : Finset ℕ`; `pack n E = ∑ i, ∑ j ∈ E i, 2 ^ (j * n + i)`. * `comp_pack`: the bits of component `i` can be read back from `pack n E`; * `pack_update_of_subset`, `pack_update_int`: changing component `i` changes `pack` by the sum of the bits set minus the sum of the bits cleared (the `fetch&add` argument). -/ namespace StrongLinCN2
