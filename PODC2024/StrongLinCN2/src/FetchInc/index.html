The processes share an infinite array `M[0], M[1], …` of readable test&set objects (base objects `rtasObj`, indexed by `ℕ`, all initially `0` = `false`). * `fetch&increment()`: apply test&set to `M[0], M[1], …` in increasing order until one returns `0`; return its index. * `read()`: read `M[0], M[1], …` until one reads `0`; return its index. Linearization (paper): every operation is linearized at the step where it obtains `0` (by a test&set or a read). The set entries always form a prefix `M[0..F-1]` and the abstract state is `F` (the paper says "the maximum index `i` such that `M[i]` is `0`", a typo for the minimum). We prove that this is a forward simulation (`linSim`), hence the implementation is strongly linearizable, and that it is lock-free (`lockFree`): a potential that strictly decreases with every invocation and every internal step (`pot_lt`), so an execution without responses is finite.
