import Papers.PODC2025.ByzantineSWMRRegisters.Impossibility import Papers.PODC2025.ByzantineSWMRRegisters.Objects /-! # Main impossibility results of Hu–Toueg (PODC 2025) Implementations from SWMR registers: base objects `register (Val i) (v₀ i)`, `i : ι`, where only `owner i` may write register `i` (`swmrAccess owner`); processes `P` (finite, `n = card P`); at most `f` Byzantine processes. Correctness is `Impl.ByzCorrect` (Byzantine linearizability of every finite execution + termination in fair executions, Definition 9). * `theorem29`: no correct implementation of the one-shot test-or-set object if `3 ≤ n ≤ 3f`. * `theorem31_verifiable`, `theorem31_authenticated`, `theorem31_sticky`: no correct implementation of a verifiable / authenticated / sticky register if `3 ≤ n ≤ 3f` (for the authenticated register: if some value differs from the initial one; for the sticky register: if the value domain is nonempty). The proofs instantiate `SigTest.no_byzCorrect`; Theorem 31 is proved directly (the paper derives it from Theorem 29 and Observation 30, which tacitly needs a composition property of Byzantine linearizable implementations). -/ namespace Podc.ByzantineSWMRRegisters open Cslib.SharedMemory Cslib.SharedMemory.Byzantine variable {P : Type} [Fintype P] [DecidableEq P] {ι : Type} [DecidableEq ι]
