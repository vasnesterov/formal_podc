import Papers.PODC2025.ByzantineSWMRRegisters.SigTest /-! # The objects of Hu–Toueg (PODC 2025) Sequential specifications (as CSLib `ObjSpec`s) and invocation disciplines (`allowed`) of * the one-shot **test-or-set** object (Definition 26), setter `s`; * the SWMR **verifiable register** (Definition 10), writer `w`, values `V`, initial value `v₀`; * the SWMR **authenticated register** (Definition 15); * the SWMR **sticky register** (Definition 21), initially `⊥` (`none`); and their `SigTest` structures (`tosSig`, `verSig v`, `authSig v`, `stickySig v`), which encode the validity/unforgeability/relay properties (Observations 11–13, 16–18, 22–24, 27). Also the SWMR register base objects (`swmrAccess`, `swmr_singleWriter`).
