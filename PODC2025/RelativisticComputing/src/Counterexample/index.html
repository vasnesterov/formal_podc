This assumes that `<_S` has order type at most `ω`, which is false in general: * even for two processors, `<_S` can have order type `ω + 1` (`omegaPlusOne`): the statement still holds, because every countable linear order embeds into `ℝ` (`lemma_6_3_of_countable`); * for uncountably many processors the statements are false: with processors indexed by the "double arrow" `ℝ ×ₗ Bool`, each taking one step and sending no message, the empty relation is a computational execution and the lexicographic order of the processors is a total ordering of it, but this order does not embed into `(ℝ, <)`, so it is not a classical execution (`lemma_6_4_false`, `lemma_6_3_false`; the same order is a total ordering of a relativistic execution in which all steps are simultaneous for one observer, refuting Corollary 6.5: `corollary_6_5_false`). Consequently (1) ⟹ (2) of the Central Theorem fails for the property "the order embeds into the real line" (`theorem_6_7_false`); (1) ⟹ (3) fails as well when observers may perceive simultaneous steps
