import Papers.PODC2025.ByzantineStableMatching.Groups /-! # Lemma 13: authenticated one-sided / bipartite lower bound Paper: if `tR = k` and `tL ≥ k/3`, bSM is impossible in a one-sided network, even with signatures. The paper's proof first reduces to `k = 3` via "Corollary 2 and Lemma 3", which is incorrect: Lemma 3 only gives `⌊k/⌈k/3⌉⌋` Byzantine parties on the right of the 6-party system, which is `< 3` e.g. for `k = 4, 5, 7` (and Corollary 2 is about unauthenticated bipartite networks). We instead run the paper's split-brain argument (Fig. 4) directly for every `k ≥ 2`: `L` is split into groups `a`, `b`, `c` of size `≤ ⌈k/3⌉` (`a`, `c` nonempty; `b` may be empty). All of `R` and group `b` are Byzantine and each simulates two copies of itself; copy `1` talks only to `a` (and treats `c` as crashed), copy `2` only to `c`.
