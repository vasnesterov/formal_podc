import Papers.PODC2025.ByzantineStableMatching.Problem import Cslib.Computability.Distributed.Byzantine.LockStep.Parallel /-! # Lemma 1: Byzantine broadcast suffices for bSM **Lemma 1** of Constantinescu, Dufay, Ghinea, Wattenhofer, *Byzantine Stable Matching* (PODC 2025): whenever Byzantine broadcast is available, bSM is solvable. Every party distributes its preference list by Byzantine broadcast (one instance per party, run in parallel = interactive consistency, see `Cslib.Byzantine.LockStep.IC_of_BB`); then every party runs Gale–Shapley offline on the agreed vector of lists and outputs its partner. * `offline`: the offline step (partner index of a party in the Gale–Shapley matching of a vector of lists). * `offlineMatch`: spec-level statement — any decision relation satisfying `IC` yields, after the offline step, a decision relation satisfying `bSM`. Reusable for other protocols that end with an agreed vector of lists. * `bSM_of_IC`, `bSM_of_IC_auth`, `lemma1`, `lemma1_auth`. -/ namespace Papers.PODC2025.ByzantineStableMatching open
