import Podc.Foundations.Combinatorics.SimpleGraph.EdgeColoring.Basic import Podc.Computability.CommunicationComplexity.OneRound /-! # The two-party edge colouring problem Chang–Mishra–Nguyen–Salim, *Round and Communication Efficient Graph Coloring*, PODC 2025, Section 3.1. The vertex set `V` (and `n = |V|`, `Δ`) are known to both parties; the edges of the input graph `G = A ⊔ B` are partitioned between Alice (`A`) and Bob (`B`), and `G` has maximum degree `≤ Δ`. In the edge colouring problem each party outputs colours for **its own edges** only; the outputs solve the `k`-edge colouring problem if together they form a proper edge colouring of `G` with the colours `0, …, k - 1`. Colourings are functions `Sym2 V → ℕ` (`SimpleGraph.IsProperEdgeColoring`). Degrees are `(G.neighborSet v).ncard`. This file also contains the deferral procedure shared by Theorem 3 and Algorithm 2: repeatedly move an edge both of whose endpoints have (current) degree `≥ θ` from the remaining graph to the deferred graph (`exists_deferral`). -/ namespace Podc.RoundEfficientColoring open SimpleGraph variable {V : Type*} open Classical in /-- The combined colouring: Alice's colours on her edges, Bob's colours on the other edges. -/ noncomputable def combine (A : SimpleGraph V) (cA cB : Sym2 V → ℕ) : Sym2 V → ℕ := fun e => if e ∈ A.edgeSet then cA e else cB e /-- A valid input with maximum degree `≤ Δ`:
