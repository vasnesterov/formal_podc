Salim, *Round and Communication Efficient Graph Coloring*, PODC 2025 (arXiv 2412.12589). Vertices `v_A, v_B, v_1, …, v_7`. Alice receives a uniformly random pair `S_A ⊆ {1,…,7}` (her edges are `{v_A, v_i}`, `i ∈ S_A`), Bob independently a uniformly random pair `S_B` (edges `{v_B, v_i}`). Without communication and with private randomness only, each colours their own edges with colours `{c_1, c_2, c_3}`. They win iff the union is a proper edge colouring. ## Model * Indices `1..7` are `Fin 7`, colours are `Fin 3`; an input is a 2-element `Finset (Fin 7)` (`inputs`, 21 of them). * An output of Alice is a map `a : Fin 7 → Fin 3`, `a i` being the colour of `{v_A, v_i}`; only the values on `S_A` matter for winning, so this loses no generality. * A randomized private-coin strategy is a stochastic kernel `p : Finset (Fin 7) → (Fin 7 → Fin 3) → ℝ` (`IsStrategy`): `p s a` is the probability of output `a` on input `s`.
