Round and Communication Efficient Graph Coloring — PODC 2025

Yi-Jun Chang, Gopinath Mishra, Hung Thuan Nguyen, Farrel D. Salim. Round and Communication Efficient Graph Coloring. PODC 2025. DOI 10.1145/3732772.3733508. Formalized version: arXiv 2412.12589 v2 (9 May 2025); numbering follows it. Copy of the paper: paper.pdf.

Verdict: ✏️ Slip. The edge-colouring results we checked hold: Theorem 2, the deterministic (2Δ−1)-edge colouring with O(n) bits and O(1) rounds, which we even get in a single round; Theorem 3, 2Δ colours without communication; and Lemma 6.2, the ZEC game bound 11024/11025, while Fournier's theorem (Prop. 3.5) and Vizing's theorem (Prop. 3.4) are proved too. What is wrong is only slips, chiefly Lemma 5.3 in the degenerate case Δ = 0. The vertex-colouring protocol (Theorem 1) and the final lower bound (Theorem 4) were not checked.

Mistakes in the paper

✏️ Slips

  • Lemma 5.3 for Δ = 0 (matching covering the degree-Δ vertices). Lemma 5.3 claims that in a graph of maximum degree Δ whose degree-Δ vertices are independent, some matching covers all degree-Δ vertices. It fails for Δ = 0: a single isolated vertex has degree Δ and no matching covers it (lemma_5_3_false_of_zero). Algorithm 2 uses the lemma only for Δ ≥ 8, and for Δ ≥ 1 the lemma holds (lemma_5_3_matching): Hall's theorem gives every degree-Δ vertex its own neighbour using only "maximum degree ≤ Δ", and the independence hypothesis then makes the chosen edges pairwise disjoint.

  • Proof of Theorem 2: "for Δ < 7 apply Lemma 5.1 … otherwise, for Δ ≥ 8" leaves out Δ = 7. Lemma 5.1 covers it.

  • Lemma 5.2 says "the maximum degree of DG is 2" where "at most 2" is meant.

Typos

  • Proof of Lemma 6.2, last display: E_A ∩ E_B ∩ E_1 ∩ E_2 should be E_A ∩ E_B ∩ E'_A ∩ E'_B.

  • Proof of Theorem 3: the step "sequentially identifies edges connecting two vertices of degree Δ and colors them using any color from the other party's palette" is correct only if degree means the current degree in the remaining graph. With the current-degree reading, the one Algorithm 2 uses and the one we formalize (exists_deferral), the deferred edges form a maximal matching and one colour of the other palette suffices. If it means the degree in the party's graph, all such edges are deferred at once and they need not be colourable with Δ colours: take Alice holding a triangle with Δ = 2.

The formalizationmodel, Lean names of the results, trust

Model.

  • Two-party, edge-partition model (Section 3.1). The vertex set (Fin n for the protocols), n and Δ are public. Alice holds A : SimpleGraph V, Bob holds B, with Disjoint A B, and G = A ⊔ B has maximum degree ≤ Δ (ValidInput). This is more general than the paper's "maximum degree exactly Δ". Each party outputs colours for its own edges. The outputs are correct if the combined colouring is a proper edge colouring with colours < k (SolvesEdgeColoring). Colourings are maps Sym2 V → ℕ.

  • Deterministic protocols, no randomness. Zero communication (Theorem 3): each output is a function of that party's own edge set. One round (Theorem 2): a OneRoundProtocol where both parties simultaneously send a bit string and then output (the paper's footnote 1 convention). Cost is the total number of bits.

  • Message lengths cannot hide information: theorem_2_tree restates Theorem 2 as a protocol tree of CSLib's Cslib.CommunicationComplexity.Protocol, where each message is one symbol of a fixed alphabet. Its cost is ≤ 224 n + 2.

  • ZEC game (Lemma 6.2): private-coin randomized strategies are stochastic kernels, one per input. Inputs are independent and uniform over the 21 pairs. The winning probability is an explicit finite sum.
