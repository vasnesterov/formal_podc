import Papers.PODC2025.TwoStepConsensusLB.Merge /-! # Basic facts used by the lower bounds * `decide_init_ne`: a consensus protocol never decides in its initial state (needs two values); hence a process that decides by `2Δ` in an `E`-faulty synchronous run is not in `E` (`not_mem_of_decidesAt`). * `syncRun_st_eq`: the states of an `E`-faulty synchronous run do not depend on the inputs of the processes of `E` (Lemma 2 of the paper), and its consequence `syncRun_decides_eq`: if all processes outside `E` propose `w`, only `w` can be decided. * `splitRun`: the classical partition argument
