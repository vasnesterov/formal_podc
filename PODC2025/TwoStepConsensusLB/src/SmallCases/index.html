This hypothesis is needed: with a single process, "decide your own input at once" is a `1`-resilient `0`-two-step consensus task protocol, although `n = 1 < 3 = max {2e + f, 2f + 1}`. -/ set_option linter.unusedSectionVars false namespace TwoStepConsensus open _root_.Cslib.CrashPartialSync /-- "Decide your own input": the state is the decision. -/ def selfDecide (V : Type*) : Protocol Unit V Unit (Option V) where init _ := none step _ _ s i _ := s.orElse fun _ => i send _ _ _ := [] decide _ s := s theorem selfDecide_st {V : Type*} (R : Run Unit V Unit) (I : Unit → V) (hR : R.inv = taskInv I) (τ : ℕ) : R.st (selfDecide V) τ () = none ∨ R.st (selfDecide V) τ () = some (I ()) := by induction τ with | zero => left;
