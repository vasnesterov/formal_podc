import Mathlib /-! # The synchronous Data Retrieval model with crash faults (§1.1, §5 of arXiv 2412.19649) `k` peers `Fin k` form a clique; a trusted source stores `X : Fin n → Bool`. Execution proceeds in synchronous rounds `r = 1, 2, …`; round `r` consists of 1. the **query sub-round**: peer `p` in local state `s` queries the bits `query p s`; 2. the **response sub-round**: it gets the answers `ans X (query p s)`; 3. the **message sub-round**: it sends `send p s a q` to every peer `q` (possibly itself; `none` = no message), receives its inbox, and moves to the state `step p s a inbox`. Protocols are deterministic. **Crash faults** (`Pattern`): `crash p = some c` means that `p` crashes in round `c`: it behaves correctly in rounds `< c`, in round `c` its messages reach only the peers `q` with `reach p q` (it may stop in the middle of the message sub-round), and it does nothing afterwards (its state is frozen; it is never looked at again). At most `f` peers crash (`Pattern.Admissible f`). The adversary chooses the input and the crash pattern (deterministic protocols: an all-knowing adversary is the same as quantifying over all patterns).
