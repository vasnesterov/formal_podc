import Mathlib /-! # The one-round lower bound (§3 of Augustine et al., arXiv 2412.19649) Data Retrieval model with `n` peers (`Fin n`) and an `n`-bit source `X : Fin n → Bool` (the paper uses `n` both for the number of peers and of bits in §3). A **one-round randomized algorithm** (class `A(q, 1)`): every peer `v` draws a private random string `R v : Ω v` (independently of the other peers), queries the set of bits `qry v (R v)` in the query sub-round (the set cannot depend on `X`: nothing has been received yet), sends to every peer `u` a message `msg v (R v) a u` that depends on its random string and on the answers `a` of its queries, and finally outputs `out v (R v) a inbox`, an `n`-bit vector. Randomness: each `Ω v` is a finite type with probability weights `w v`; the random profile `R : (v : Fin n) → Ω v` has probability `∏ v, w v (R v)` (independent private coins). Adversary (the "weak" non-adaptive adversary of Definition 3.1): it fixes the input `X`, a set `Byz` of `(n-1)/2` Byzantine peers, and the messages of the Byzantine peers as a function of their own random strings. The adversary used in the proof is the paper's: the Byzantine peers run the algorithm honestly, but on the input `X` with bit `ℓ` flipped. Main results: `lemma_3_3` (some bit is skipped by some peer with probability `≥ 1 - 1/e`), `claim_3_5` (indistinguishability), `theorem_3_6` (every algorithm in `A(n-1, 1)` fails with probability `≥ (1 - 1/e)/4` against this adversary). Since the Byzantine peers send exactly the messages of honest peers, the bound also holds in the broadcast model (`theorem_3_6_broadcast`). -/ namespace Podc.ByzantineDownload.LowerBound open Finset
