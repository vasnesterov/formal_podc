(2) is necessary * `deterministic_impossible` (§1.3, "On the use of randomness"): no deterministic uniform beeping protocol solves Eventual Leader Election on any graph with at least two nodes and no isolated node when all nodes start in the same state — all nodes stay in the same state forever. * `triangle_no_leader` (§5, Discussion; necessity of `V ⊆ W_0` in Eq.
