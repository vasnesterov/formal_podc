import Papers.PODC2025.MinimalistLE.Basic /-! # The pair chain of two leaders and its Lyapunov function While a node is a leader, its phase follows the 3-state chain `W → B` (coin `true`), `W → W` (coin `false`), `B → F → W`. For two leaders `u, v` we follow `(x_u, x_v, Δ)` with `Δ = N(u) − N(v)` (difference of beep counts). With `a = 1 + 2p`, the function `M = Δ + h(x_u) − h(x_v)` (`h(W) = 0`, `h(B) = −2p/a`, `h(F) = −p/a`) is a martingale whose conditional variance has stationary mean `v̄ = 2p(1−p)/a³`; adding the corrector `k(x_u) + k(x_v)` (`k(W) = 0`, `k(B) = 2p(1−p)/a³`, `k(F) = p(1−p)/a³`) gives the Lyapunov function `g = ((D+2)² − M² + k(x_u) + k(x_v)) / v̄` with exact drift `−1` (`lyap_drift`). -/ namespace MinimalistLE instance : Fintype Phase := ⟨{.W, .B, .F}, by intro x;
