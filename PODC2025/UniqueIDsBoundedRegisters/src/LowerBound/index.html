We keep a list `S` of poised processes and a set `U` of registers that the poised processes can restore to their current value (`Restorable`, Claim 1). A process that runs to completion either changes some register outside `U` (then `U` grows by that register — the paper's "special" processes), or changes only registers of `U`; in the latter case the poised processes restore the memory to its state before it started (`restore_many`), and a fresh process replays its solo run (anonymity, `runFrom_mirror`) and returns the same identifier.
