Local Computation Algorithms for Knapsack — PODC 2025

Clément L. Canonne, Yun Li, Seeun William Umboh. Local Computation Algorithms for Knapsack: impossibility results, and how to avoid them (Brief Announcement). PODC 2025. DOI 10.1145/3732772.3733515. Formalized version: arXiv 2504.01543 v1 (full version); numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. The impossibility results (Lemma 3.1, Theorems 3.2–3.4) are true, although their proofs needed new arguments: the reductions of 3.2/3.3 break the paper's own normalisation of the profits, and Lemma 3.5 in the proof of 3.4 is not justified. The other half of the paper, how weighted sampling avoids them, is lost: Theorem 4.1 ("Algorithm 2 LCA-KP is an LCA giving access to a (1/2, 6ε)-approximate solution"), the paper's main theorem, is false, because on a Knapsack instance whose items all have the same efficiency LCA-KP answers "no" to every query, with probability close to 1. Lemma 4.6, on which it rests, is false on the same instance, and no repaired algorithm was proved.

Mistakes in the paper

❌ Theorem 4.1 and Lemma 4.6 (LCA-KP is a (1/2, 6ε)-approximation LCA; ties in efficiency)

On N identical items (weights 1, weight limit N/2, ε = 1/m with m ≥ 30, N ≥ m²), LCA-KP answers "no" to every query with probability ≥ 1 − ε/36, which is not a (1/2, 6ε)-approximation (Sec4.theorem_4_1_false), and no equally partitioning sequence exists (Sec4.no_eps_uniform).

Impact. The main positive result is lost, even in the weakest, per-query reading of correctness; there is no local fix, and the existential claim of Theorem 1.4 is at best unestablished. The impossibility results are unaffected.

Details

In normalised form every item has profit and weight 1/N. All items are small with efficiency 1, so the efficiency distribution that rQuantile samples is a point mass at 1. Suppose all quantiles are accurate, which by Theorem 4.5 happens with probability ≥ 1 − tβ ≥ 1 − ε/36. Then every 1 − kq lies in (τ, 1 − τ), and every ẽ_k = 1. So every item of Ĩ is a copy of (ε², ε²) with efficiency 1. CONVERT-GREEDY finds no index k with ẽ_k > p_j/w_j = 1, sets e_small = −1, and LCA-KP answers "no" to every query (Sec4.answerKP_uniform). This holds for any sample and any tie-breaking in the sort. The empty set is not a (1/2, 6ε)-approximation, since OPT ≈ 1/2. Even in the weakest, per-query reading of correctness, no seed-dependent (1/2, 6ε)-approximate solution agrees with each answer with probability ≥ 1 − ε.

Reading > as ≥ in Line 3 of Algorithm 3 does not help: LCA-KP then answers "yes" to every item, which is infeasible. The paper never assumes distinct efficiencies, and ties are built into the design: the synthetic items of Ĩ have efficiency exactly ẽ_{k+1}.

Theorem 4.1 rests on Lemma 4.6 (an equally partitioning sequence exists with probability ≥ 1 − 13ε/36). On the same instance every set A_k(I) of Definition 4.3 is either empty or contains every item, so no equally partitioning sequence of length t ≥ 1 exists and the probability in Lemma 4.6 is 0. The proof of Lemma 4.6 turns Pr[p/w > ẽ_k] ≤ kq + τ into Pr[p/w ≥ ẽ_k] ≤ kq + τ, which ignores the mass of items with efficiency exactly ẽ_k.

✏️ Slips

  • Theorem 3.4 says "(t(n), 4/5)-LCA", which is failure probability 4/5 by Definition 2.2. The proof uses success probability 4/5, and we formalize that version. The literal version cannot follow from the paper's distribution: a 1-query algorithm that answers "yes" on a weight-3/4 item with a random hash bit succeeds with probability 1/2 > 1/5 on it.

  • The proof of Theorem 3.4 draws (i, j) uniformly from [n]², so i = j is possible, and then the weights are ill-defined. We use distinct pairs.

  • Theorem 2.7 states the sample complexity with Ω̃; it should be Õ.

  • The approximation guarantee is stated inconsistently: (1/2 + ε) in Theorem 1.4, (2 + ε) in the technical overview, (1/2, 6ε) in Theorem 4.1.

  • Algorithm 3, Lines 2–3 do not say what happens when no k satisfies ẽ_k > p_j/w_j, or when no j ≥ 1 exists. The evident reading is k = 0, the branch k < 3.

Typos

  • The "τ-approximate p-quantile" of Theorem 4.5 is never defined; its proof derives the definition.

Proof gaps in true statements (3)Theorems 3.2 and 3.3 · Theorem 3.4 · Theorem 3.4

🛠️ Theorems 3.2 and 3.3 (the reduction leaves the paper's model)

The reduction instance I(x) from OR_{n−1} has total profit |x| + β, so it violates the normalisation of Definition 2.2, and normalising it requires knowing |x|.

Impact. Statements true; proved both for LCAs correct on unnormalised instances (the paper's reduction, theorem_3_2, theorem_3_3) and for LCAs correct only on normalised instances (theorem_3_2_normalized, theorem_3_3_normalized).

Details

The paper's reduction only applies to LCAs that are correct on unnormalised instances. We formalize it in that setting (theorem_3_2, theorem_3_3, bound n/3 on n + 1 items).

Repair

For LCAs required to be correct only on normalised instances we use a different hard family and a direct argument. The first item of a block of b = ⌊1/α²⌋ + 1 items takes the profit of the whole block. This gives the bound ⌊n/b⌋/3, still Ω(n) for fixed α. (theorem_3_2_normalized, theorem_3_3_normalized)

🛠️ Theorem 3.4 (Lemma 3.5 is not justified)

Lemma 3.5's argument that the default answer to each query k must be "yes" confuses an error conditional on the query being k with the 1/5 bound, which is an average over all k.

Impact. Theorem 3.4 is true with the paper's constant, by a new joint count (theorem_3_4, theorem_3_4_perQuery, LCA.count_le).

Details

The argument is that answering "no" costs error 1/3 − 1/10 > 1/5. An algorithm may answer "no" on a constant fraction of the k and still meet the average bound. The lemma's hypotheses are in fact unsatisfiable (they contradict Theorem 3.4), so the lemma is vacuously true, but its proof does not show this.

Repair

Let y be the fraction of default "yes" answers. The algorithm fails on a ½(1 − y) + ½(y² + (1 − y)²) − O(q/n) ≥ 7/16 − O(q/n) fraction of the hard distribution. This gives t(n) ≥ n/11 for every n ≥ 2 with success probability 4/5, the paper's constant, and t(n) ≥ n/40 − 1/5 under the per-query reading. (theorem_3_4, theorem_3_4_perQuery, LCA.count_le)

🔧 Theorem 3.4 (hard distribution outside the model)

The instances have weights 3/4, 1/4 and profits 0, while Definition 2.2 requires integer weights and total profit 1.

Impact. Statement true (theorem_3_4).

Repair

We scale the weights to 3, 1 with weight limit 4 and use profits 1/n.

The formalizationmodel, Lean names of the results, trust

Model.

  • Knapsack instance on n items (Instance): real profits, natural-number weights, weight limit K. WellFormed means non-negative profits and weights ≤ K. Normalized additionally requires total profit 1, as in Definition 2.2.

  • Randomized LCA (LCA): a PMF over random seeds. For each weight limit, seed and query there is an adaptive query tree over the item oracle i ↦ (p_i, w_i) that outputs yes/no. Since the answer is a function of (instance, seed, query), the LCA is stateless, parallelizable and query-order oblivious by construction (Definitions 2.2–2.4). Complexity is the worst-case number of item queries per answer (QueryBound, the paper's t(n) as query complexity).

  • Correctness is formalized in two readings. Per-query (Correct): there is a seed-dependent solution C r such that each single answer agrees with it and C r is valid with probability ≥ 1 − δ. Global (CorrectStrong): the set of "yes" items is valid with probability ≥ 1 − δ. Global implies per-query. Theorems 3.2 and 3.3 and the refutation of 4.1 use the weaker per-query reading, so they hold in both. Theorem 3.4 is proved in both readings.

  • Lower bounds quantify over all randomized LCAs with arbitrary seed spaces. The easy direction of Yao's principle is an averaging lemma (sum_mul_probReal_le).

  • Section 4: LCA-KP (Algorithm 2 with Algorithm 3) is modelled as a function of one run's random data: the sample R, the rQuantile outputs ẽ_k, and the sorting order of Ĩ. The only property of rQuantile used is the accuracy guarantee of Theorem 4.5. The probabilistic statement takes as hypothesis that each run is accurate with probability ≥ 1 − ε/36, which is what Theorem 4.5 with β = ε²/36 and t ≤ 1/ε calls gives.
