The paper draws `(i, j)` from `[n]²`, which allows `i = j` (ill-defined weights); we use ordered pairs of distinct indices. The paper's Lemma 3.5 argues *per query `k`* that the answer on the "default view" (only zero weights seen) must be "yes", from the global error bound `1/5`; this does not follow (the error is an average over `k`). We replace it by a joint counting argument: if `b_k` is the default answer on query `k` and `m` of the `b_k` are "yes", the deterministic algorithm fails on * `(i, j, light)` whenever `b_i = no` and `j` is not probed on the default run of `i`;
