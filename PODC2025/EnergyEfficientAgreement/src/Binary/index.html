The brief announcement only sketches the algorithm; its full version (cited by the brief announcement for the proof) gives it as Algorithm 3, formalized here as `binary` / `algorithm3`: * `f` committees `C_1, …, C_f` of size `⌈√n⌉` from `JoinCommittees(f, ⌈√n⌉)`; `T₀ = ⌈(f + 1)/√n⌉`; * round `1`: everybody is awake; a player with input `X = 1` sets `T ← T₀` and sends `1` to `C_1`; a player that receives `1` while `Y = 0` sets `Y ← 1`, `T ← T₀`; * round `h ∈ [2, f]`: a player with `T > 0` wakes up, sets `T ← T - 1` and sends `1` to `C_h`; the members of `C_h` wake up, and one that receives `1` while `Y = 0` sets `Y ← 1`, `T ← T₀`; * round `f + 1`: everybody is awake; players with `Y = 1` or `X = 1` broadcast `1`; a player that receives `1` or has `X = 1` sets `Y ← 1`; everybody decides `Y`. `algorithm3_violates_agreement`: for `n = 5`, `f = 3` an adversary crashing 3 players makes the two non-faulty players decide differently. The value `1` is relayed along a chain of players that crash one per round; in round `3` the only relay `p₄` sends to `C_3 = {p₂, p₃, p₄}`, whose other members have already crashed, so the adversary needs no crash in that round; `p₄` then crashes in round `4 = f + 1` while broadcasting, reaching only `p₀`.
