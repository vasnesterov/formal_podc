import Papers.PODC2025.LanguageDecidability.CounterDefs /-! # Sequential counter words used for Lemma 5.2 and for `SEC_COUNT ∉ RTO` * `seqW op` — the sequential history of the operations `op 0, op 1, …` (each operation is a process, an invocation and a response; the invocation of `op u` is at `2u`, its response at `2u + 1`); it is well-formed if every process has infinitely many operations (`wf_seqW`). * `cw hn f` — process `0` increments once, then the processes read in round-robin (the `u`-th read is by process `u mod n` and returns `f u (u mod n)`). * `cw hn gBad` — process `0` reads `1`, every other process reads `0` forever: not in `WEC_COUNT` for `n ≥ 2` (property (3) fails), `cw_bad_not_mem`. * `cw hn (gGood J)` — the same for the first `J` reads, then every read returns `1`: in `SEC_COUNT ⊆ WEC_COUNT` (`cw_good_mem`). The paper's word `<⁺₁ >₁ <₂ >⁰₂ <₁ >⁰₁ …` (proof of Lemma 5.2) cannot be used: `p₁` reads `0` after its own completed `inc`, which violates property (1), so its continuations `x(F) <₁ >¹₁ <₂ >¹₂ …` are not in `WEC_COUNT` either.
