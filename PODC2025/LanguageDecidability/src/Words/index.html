import Mathlib /-! # Distributed alphabets, well-formed ω-words and real-time oblivious languages (Section 2, §5.2) Castañeda, Rodríguez, *Asynchronous Fault-Tolerant Language Decidability for Runtime Verification of Distributed Systems*, PODC 2025 (arXiv 2502.00191v3). * `Sym I O` — the distributed alphabet `Σ = ⋃ᵢ Σᵢ`, `Σᵢ = Σᵢ< ∪ Σᵢ>`: a symbol is a process `p` together with an invocation symbol (`I p`) or a response symbol (`O p`). Local alphabets are disjoint because the process is part of the symbol. * `WF` — Definition 2.1 (well-formed ω-words). Condition (3) (fairness) is automatic for `ℕ`-indexed words. * `RTO` — Definition 5.3 (real-time oblivious languages). The shuffle `α|1 ⧢ ⋯ ⧢ α|n` (Definition 5.2) is the set of words `α'` with `α'|p = α|p` for every process `p`. * `rto_iff_swapClosed` — a language is real-time oblivious iff it is closed under transposing two adjacent symbols of different processes (at any finite position). -/ namespace Podc2025.LanguageDecidability variable {n : ℕ} {I O : Fin n → Type} /-- Symbols of the distributed alphabet: a process and an invocation or a response symbol. -/ abbrev Sym (I O : Fin n → Type) := Σ p : Fin n, I p ⊕ O p /-- ω-words over the distributed alphabet. -/ abbrev Word (I O : Fin n → Type) := ℕ → Sym I O /-- `cnt x p k`: the number of symbols of process `p` among the first `k` symbols of `x`. -/ def cnt (x : Word I O) (p : Fin n) : ℕ → ℕ | 0 => 0 | k + 1 => cnt x p k + if (x k).1 = p then 1 else 0 /-- **Definition 2.1** (well-formed ω-words): every local word is infinite (reliability) and alternates invocations and responses, starting with an invocation (sequentiality). -/ structure WF (x : Word I O) : Prop where reliable : ∀ p N, ∃ m, N ≤ m ∧ (x m).1 = p seq : ∀ m, (x m).2.isLeft = true ↔ Even (cnt x (x m).1 m) /-- **Definition 2.2**: a distributed language is a set of well-formed ω-words. -/ def IsDistLang (L : Set (Word I O)) : Prop := ∀ x ∈ L, WF x /-- The finite prefix of length `k`. -/ def pfx (x : Word I O) (k : ℕ) : List (Sym I O) := (List.range k).map x /-- The suffix starting at position `k`. -/ def shift (x : Word I O) (k : ℕ) : Word I O := fun m => x (m + k) /-- `app l y` is the ω-word `l y` (finite word followed by an ω-word). -/ def app (l : List (Sym I O)) (y : Word I O) : Word I O := fun m => if h : m < l.length then l[m] else y (m - l.length) /-- The local word of process `p` in a finite word. -/ def proj (p : Fin n) (l : List (Sym I O)) : List (Sym I O) := l.filter (fun a => decide (a.1 = p)) /-- **Definition 5.3** (real-time oblivious languages): for every `αβ ∈ L` with `α` finite and every `α' ∈ α|1 ⧢ ⋯ ⧢ α|n` (i.e. `α'|p = α|p` for every `p`), `α'β ∈ L`. -/ def RTO (L : Set (Word I O)) : Prop := ∀ x ∈ L, ∀ (k : ℕ) (α' : List (Sym I O)), (∀ p, proj p α' = proj p (pfx x k)) → app α' (shift x k) ∈ L /-- Transposition of the symbols
