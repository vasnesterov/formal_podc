import Papers.PODC2025.LanguageDecidability.Classes /-! # Eventually consistent counters (Example 3, Definitions 2.7, 2.8) and the algorithm of Figure 5 Alphabet (Example 3): `Σᵢ< = {<ᵢ⁺ (inc), <ᵢ (read)}`, `Σᵢ> = {>ᵢ (ack), >ᵢˣ (value x)}`. Positions in an ω-word: the response at position `r` of process `p` belongs to the operation whose invocation is the last symbol of `p` before `r` (`x` is well-formed). * `Typed x` — every operation is `inc : ack` or `read : val v` (the paper's languages are about counter histories, so ill-typed operations are not in them). * `WEC1` — (1) every `read` of `p` returns at least the number of `inc`s of `p` before it. * `WEC2` — (2) every `read` of `p` returns at least the value of every earlier `read` of `p`. * `WEC3` — (3), *intended reading*: finitely many `inc`s, and eventually every `read` returns their number. * `WEC3lit` — (3), *literal reading*: "for every finite prefix `α` such that the suffix `β` has only `read` operations, eventually all operations in `β` return the number of `inc` operations in `α`": vacuous if there are infinitely many `inc`s. * `SEC4` — (4) every `read` returns at most the number of `inc`s that precede or are concurrent to it, i.e. whose invocation is before the `read`'s response. * `WEC`, `WEClit`, `SEC` — the languages `WEC_COUNT` (both readings) and `SEC_COUNT`. * `fig5Alg` — the algorithm of Figure 5, literally; `wecAlg` — the corrected algorithm: the safety check of the second clause of Line 06 is made only for `read` operations, and ill-typed operations also set the flag. -/ namespace Podc2025.LanguageDecidability.Counter open
