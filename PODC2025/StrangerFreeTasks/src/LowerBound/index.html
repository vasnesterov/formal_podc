import Papers.PODC2025.StrangerFreeTasks.StrangerFree import Papers.PODC2025.StrangerFreeTasks.BoundedLA /-! # `k`-bounded lattice agreement for `k + 1` processes is stranger-free (§3.2) The paper argues: for `k + 1` processes, containment and self-inclusion give that for any two outputting processes one output contains the other process, "and thus" the task is stranger-free. The missing step — *if `j` is in `i`'s output then `j` appears in `i`'s view* — is validity plus a causal-erasure argument (`Impl.fullInfo_exists_erase`): if `j` did not appear in `i`'s view, erasing the causal future of `j` gives an execution in which `j` does not participate but `i` outputs the same set, violating validity. ## Main results * `boundedLA_strangerFree`: for `|P| = k + 1`, `boundedLA P k` is stranger-free for every progress condition (even the strongest variant, quantifying over obstruction-free algorithms). * `boundedLA_lowerBound` (lower bound of Theorem 3.1): every obstruction-free (in particular every wait-free) algorithm solving `k`-bounded lattice agreement for `k + 1` processes uses at least `k + 1` registers. -/ set_option linter.unusedSectionVars false
