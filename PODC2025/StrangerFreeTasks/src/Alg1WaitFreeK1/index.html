Contrast with `alg1_not_waitFree` (`Alg1Livelock.lean`): for `k ≥ 2` it is not. Proof (by contradiction). Suppose process `p` takes infinitely many steps in an infinite execution. 1. `p` never decides: a decided process is stuck (its only action is to return). 2. No configuration is `Doomed` for `p`: from a doomed configuration `p` decides within a bounded number of its own steps (`doomed_step`, potential `pot`). 3. Hence a process `x ≠ p` never writes `A[1]` twice (`IA`: in its odd iterations after its third write it sees another process and outputs), and it writes `A[1]` at all only if its first collect read the initial value of `A[1]` (`PROV`), i.e. if it took a step before the first write to `A[1]`. So only finitely many writes to `A[1]` by processes other than `p` happen. 4. After the last of them, the next odd iteration of `p` (in which it writes `A[0]`) sees an unchanged `A[1]`, and `A[0]` can only change to a non-`p` value, which would make the configuration doomed; so the snapshot succeeds and `p` outputs (`QP`, `qp_final`) — contradicting 1.
