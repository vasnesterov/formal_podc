import Papers.PODC2025.StrangerFreeTasks.LowerBound import Mathlib import Cslib.Computability.Distributed.SharedMemory.Mutex import Cslib.Computability.Distributed.SharedMemory.Potential import Cslib.Computability.Distributed.SharedMemory.Task /-! # The bound of Theorem 2.1 is tight for `n = 2` Theorem 2.1 of the paper: every wait-free read/write algorithm for a stranger-free task for `n` processes uses at least `n` registers. By §3.2, `1`-bounded lattice agreement for two processes is stranger-free (`boundedLA_strangerFree`). Here we show that the bound is attained for `n = 2`: the following algorithm solves `1`-bounded lattice agreement for processes `Fin 2` wait-free with two binary registers `R[0], R[1]` (initially `false`); `p + 1` is the other process. ``` R[p] ← true if R[p + 1] then output {p, p + 1} else output {p} ``` Correctness: if `p` reads `false` then `p + 1` has not written yet, so when `p + 1` later reads `R[p]` it sees `true`; hence the two processes never both output singletons, and every two outputs of size `≤ 1` coincide. ## Main results * `twoAlg_solves`, `twoAlg_waitFree`; * `theorem_2_1_tight`: the task is stranger-free and solved wait-free with exactly two registers. -/ namespace Cslib.SharedMemory.StrangerFree open Cslib.SharedMemory Impl /-- Program counters of the two-process algorithm. -/ inductive TPh where /-- Not invoked yet. -/ | idle /-- About to write `R[p] ← true`. -/ | wr /-- About to read `R[p + 1]`. -/ | rd /-- Output `o` decided. -/ | done (o : Finset (Fin 2)) deriving DecidableEq /-- Whether a process in this phase has already written `true` into its register. -/ def TPh.written : TPh → Bool | .idle => false | .wr => false | .rd => true | .done _ => true /-- The two-process, two-register algorithm for `1`-bounded lattice agreement. -/ noncomputable def twoAlg : Impl (laObj (Fin 2)) (RegFamily (Fin 2) Bool false) (Fin 2) TPh where memInit _ := false locInit _ := .idle invoke _ l _ := match l with | .idle => .wr | l => l act p l := match l with | .wr => .access p (.write true) (fun _ => .rd) | .rd => .access (p + 1) .read (fun b => .done (if b then {p, p + 1} else {p})) | .done o => .ret o (.done o) | .idle => .ret (∅ : Finset (Fin 2)) .idle /-- Configurations of the algorithm. -/ abbrev TCfg := Config (laObj (Fin 2)) (RegFamily (Fin 2) Bool false) (Fin 2) TPh /-! ### `Fin 2` facts -/ lemma fin2_add_one_add_one (p : Fin 2) : p + 1 + 1 = p := by revert p;
