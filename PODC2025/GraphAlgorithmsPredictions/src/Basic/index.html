import Mathlib -- CSLib candidate: `IsMIS`, `IsMISOn`, `restrict`, `isMIS_union_of_extendable` (SimpleGraph MIS API) /-! # Maximal independent sets and extendable partial solutions Basic notions for Boyar–Ellen–Larsen, *Distributed Graph Algorithms with Predictions* (PODC 2025, Brief Announcement; full version arXiv:2501.05267). * `IsMIS G s`: `s` is a maximal independent set of `G` (independent and dominating); equivalent to Mathlib's `Maximal G.IsIndepSet s` (`isMIS_iff_maximal`). * `restrict G R`: the subgraph induced by `R`, on the same vertex type. * `isMIS_union_of_extendable` (Section 3 of the paper): if `I` is independent, the partial solution "`I` outputs 1, the neighbours of `I` output 0" is *extendable*: together with any MIS of the subgraph induced by the remaining nodes it is an MIS of the whole graph. -/ namespace Podc.GraphAlgorithmsPredictions open SimpleGraph variable {V : Type*} /-- `s` is a maximal independent set of `G`: no two members are adjacent and every non-member has a neighbour in `s`. -/ def IsMIS (G : SimpleGraph V) (s : Set V) : Prop := G.IsIndepSet s ∧ ∀ v ∉ s, ∃ u ∈ s, G.Adj v u /-- `IsMIS` is maximality among independent sets. -/ theorem `N(I)` outputs 0". -/ def remainder (G : SimpleGraph V) (I : Set V) : Set V := {v | v ∉ I ∧ ∀ u ∈ I, ¬ G.Adj v u} /-- **Extendability** (Section 3): if `I` is independent, then `I` together with any
