Both are independent, hence extendable (`pruneSet_extendable`, `pruneSet'_extendable`), and `pruneSet ⊆ pruneSet'`. * `pruneAlg_status`: after 3 rounds of the pruning algorithm, the nodes of `I` output 1, their neighbours output 0, and the remainder (the union of the *error components*) is active. * `eta G x`: the error measure `η` = the maximum number of nodes of an error component. * `predAlg_consistent`: if the prediction is an MIS, then `η = 0` and the algorithm outputs the prediction after 3 rounds (consistency `c(n) = 3`). * `predAlg_correct`: in general, every node has terminated after `η + 3` rounds and the output is an MIS (`η`-degrading). * `greedy_round_complexity`: the Distributed Greedy MIS Algorithm alone terminates within `n` rounds on an `n`-node graph
