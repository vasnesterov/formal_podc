Model: synchronous LOCAL, CSLib's locally-iterative model `Cslib.LocallyIterative.Algorithm` (in every round a node updates its state from its own state and the *set* of its neighbours' states). Node names are identifiers (a linear order on `V`); a node's state `St V` holds its identifier, its prediction bit and its status (`active`, or terminated with output `1` = `inMIS` / output `0` = `outMIS`). All algorithms here are built from three rules (`Rule`), one per round: * `prune`: an active node with prediction `1` all of whose neighbours have prediction `0` outputs 1; * `max`: an active node whose active neighbours all have smaller identifiers outputs 1; * `out`: an active node with a neighbour that output 1 outputs 0. * `pruneAlg` (Section 3, the "simple 3 round initialization algorithm"): `prune`, then `out`. * `greedyAlg` (Section 4, the Distributed Greedy MIS Algorithm): `max` in odd rounds, `out` in even rounds (rounds counted from 1). * `predAlg = pruneAlg.seq 3 greedyAlg` (Section 5): 3 rounds of pruning, then greedy. -/ namespace Podc.GraphAlgorithmsPredictions open SimpleGraph Cslib.LocallyIterative /-- Status of a node. -/ inductive Status | active | inMIS | outMIS deriving DecidableEq /-- State of a node: identifier, prediction, status. -/ structure St (V : Type*) where id : V pred : Bool status : Status /-- The rules executed in one round. -/ inductive Rule | prune | max | out variable {V : Type*} [LinearOrder V] open Classical in /-- One round of a rule, for a node with state `s` that sees the set `N` of its neighbours' states.
