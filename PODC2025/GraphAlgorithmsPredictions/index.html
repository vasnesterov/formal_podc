Verdict: ✅ Correct. Theorem 4.1 (every deterministic component-size bounded MIS algorithm needs (n − 5)/2 rounds on an n-node line) holds, by the paper's own Ramsey proof, and so do the 3-round pruning algorithm, the round bound n of the Distributed Greedy MIS Algorithm, consistency, and the η + 3 round bound of "pruning, then greedy on every error component". The same Ramsey argument applied directly to MIS gives the slightly better bound (n − 4)/2. The framework's asymptotic definitions and the generic compositions of Section 5 were not checked.

Model.

  • Synchronous, fault-free, deterministic LOCAL. Nodes are named by distinct identifiers (the convention of CSLib's Cslib.Local), so comparisons of identifiers are comparisons of node names.

  • Lower bound (Line.lean, LowerBound.lean). A T-round algorithm is any function f : SimpleGraph ℕ → (ℕ → Lab) → ℕ → β with Cslib.Local.IsLocal T f: the output of a node depends only on the edges at distance < T and the labels at distance ≤ T. An n-node line is an injective placement id : Fin n ↪ ℕ; the label of a node holds the identifiers of its left and right neighbours (so after T rounds a node knows the identifiers up to distance T + 1, and the orientation). The algorithm may depend on n (nodes know n), and must be correct for every placement of arbitrary natural identifiers, i.e. its round count does not depend on the identifier domain. Every component-size bounded algorithm is such an algorithm, and algorithms that ignore the orientation or see less are special cases, so the lower bound covers them. The *_bounded variants show that identifiers below an explicit D(n, T) already suffice ("d is a sufficiently large function of n").

  • Algorithms (Algorithm.lean, Greedy.lean, Main.lean). CSLib's locally-iterative model (Cslib.LocallyIterative.Algorithm): in each round a node updates its state from its own state and the set of its neighbours' states. A state holds the identifier, the prediction bit and the status (active / output 1 / output 0). pruneAlg = prune rule, then "output 0 if a neighbour output 1"; greedyAlg = local-maximum rule in odd rounds, "output 0" rule in even rounds; predAlg = pruneAlg.seq 3 greedyAlg. Graphs are finite (Fintype V), identifiers linearly ordered.

  • The error measure η is the paper's: the maximum number of nodes of an error component, i.e. a connected component of the subgraph induced by the nodes the pruning algorithm leaves active (eta).

Remarks.

  • Theorem 4.1 is not tight in its constant (a remark, not a mistake: the paper's bound is true). Applying Ramsey directly to the MIS outputs gives three consecutive middle nodes with the same output: all three in the MIS contradicts independence, none in the MIS contradicts maximality. This needs a window of 2T + 5 nodes and gives T ≥ (n − 4)/2. The paper's detour through 3-colouring (Lemma 5 of the full version) loses one round. (mis_lowerBound_sharp)

  • Lemma 4 of the full version holds for any finite number of colours, not only 3: the Ramsey argument never uses the number of colours. (lemma_4)

  • Round counting of the pruning algorithm (proof remark). The paper's third round only tells the remaining active nodes that the neighbours of I have terminated. With the usual "send, receive, compute" round convention (CSLib's locally-iterative model) this message is part of the next round, and 2 rounds suffice. This is a counting convention, not an error: we prove the paper's 3 (round 3 is idle in our model).

Not formalized.
