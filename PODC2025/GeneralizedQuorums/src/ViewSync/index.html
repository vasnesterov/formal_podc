import Mathlib /-! # Proposition 2 (view synchronization by growing timeouts, §7) A process spends time `v · C` in view `v` (it enters view `v + 1` when the timer set at line 29 expires). After GST clocks do not drift, so in real time process `p` is in view `v` exactly during `[a p + C·v(v-1)/2, a p + C·v(v+1)/2)` for a constant `a p` (its start time minus its clock offset), for all large enough `v`.
