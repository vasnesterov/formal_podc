CSLib's `register V v₀`; * SWMR atomic snapshots (`snapSafe`): linearizability w.r.t. `snapObj P V v₀`, for histories in which every process only updates its own segment. Each has conflicting operations for any two distinct processes, provided the value domain is not trivial (two incomparable elements for lattice agreement, two distinct values otherwise).
