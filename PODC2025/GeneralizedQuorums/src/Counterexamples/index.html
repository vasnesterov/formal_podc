The paper's proof silently assumes two incomparable elements (and two distinct values for registers, snapshots and consensus; the same algorithm shows that these hypotheses are needed too). * `Uf_not_unique`: `U_f` depends on the quorum system, not only on `F`, so "U_f is the largest set of processes for which termination can be guaranteed" (§4, after Theorem 2) has to be read relative to
