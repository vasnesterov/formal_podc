Code at `pᵢ`: ``` Val[i] ← vᵢ; v[i][0] ← O.(i = 0 ? f : g); Ret[i] ← v[i][0] op ← i; for cnt = 0 .. k-1: Round[i][cnt] ← op; other ← Round[1-i][cnt]; op ← (other ≠ ⊥) ? op + 2·other : 3·op Next_op[i] ← op; v[i][1] ← O.c_op; v[1-i][0] ← Ret[1-i]; nx ← Next_op[1-i] decision (lines 23–39, `decideC2`), then read and return `Val[j]`. ``` with the correction of line 30 (`v[0][1]`, the second response of `p₀`, instead of `v[1][1]`). Shared objects: one copy of `O` (index `Sum.inr ()`, initially in state `s`) and registers (index `Sum.inl r`, `r : Reg`), all of the same type `register (RV O.Resp) .bot` (a register holding a tagged value; `⊥ = .bot`). The local state `LS` is a record with a program counter `pc` (`0 … 10`). It remembers the list `rs` of the values read in the rounds of the loop (instead of only `cnt` and `op`; `cnt` is `rs.length` and `op` is `opOf i rs`).
