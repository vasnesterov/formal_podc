import Papers.PODC2025.TwoShotConsensusObjects.NecReductionSim /-! # Removing one copy of `O` (the construction in the proof of Proposition 2) If, from a reachable configuration `F` of a consensus algorithm `A`, no process can decide before accessing copy `k` again, and a "decision rule" `dec p c` (decide the input of `p₀` iff `dec p c`) on the operation `c` that a process is poised to apply to `k` is consistent on simultaneously poised pairs and correct for the two solo runs, then consensus can be solved with one copy of `O` fewer (Proposition 2 of the paper): each process writes its input
