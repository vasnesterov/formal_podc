import Mathlib /-! # Rendezvous on the labelled line: trajectories, the CarefulWalk reduction (Theorem 3.1) Bourreau, Narayanan, Nolin, *Optimal Deterministic Rendezvous in Labeled Lines*, PODC 2025 (arXiv:2505.04564v2). An agent that is woken up in round `τ` and then follows the trajectory `b : ℕ → V` (position after `t` rounds of its own clock) is at `delayed τ b t = b (t - τ)` in global round `t` (truncated subtraction: it sits at its start `b 0` while asleep). Two agents *meet* in round `t` if they are at the same node; *meet or cross* additionally counts a simultaneous traversal of one edge in opposite directions in rounds `t - 1 → t`. `careTraj lab a` is the trajectory of `care(A)` (Algorithm 1, CarefulWalk) when `A` follows `a`: every round of `A` becomes four rounds; a stay is stretched, a move `p → q` becomes "wait, cross, (wait | back and forth), (wait | cross)" according to whether the label increases. `care_meet` is the trajectory-level content of Theorem 3.1: for **any** type of nodes with injective labels (the paper's "labelled graph"), a meet-or-cross of the `A`-trajectories with delay `⌈τ/4⌉` within `T` rounds yields a meeting at a node of the `care`-trajectories with delay `τ` within `4T` rounds. -/ namespace Podc.RendezvousLabeledLine variable {V : Type*} /-- Global position in round `t` of an agent woken up in round `τ` whose own trajectory is `b`. -/ def delayed (τ : ℕ) (b : ℕ → V) (t : ℕ) : V := b (t - τ) /-- Rendezvous with simultaneous edge-crossing detection: same node in round `t`, or the two agents swapped their positions in rounds `t - 1 → t`. -/ def MeetOrCross (x y : ℕ → V) (t : ℕ) : Prop := x t = y t ∨ (0 < t ∧ x t = y (t - 1) ∧ y t = x (t - 1)) /-- Trajectory of `care(A)` (Algorithm 1, CarefulWalk, applied to every round of `A`). -/ def careTraj (lab : V → ℕ) (a : ℕ → V) (t : ℕ) : V := if t % 4 ≤ 1 then a (t / 4) else if t % 4 = 2 then a (t / 4 + 1) else if lab (a (t / 4)) < lab (a (t / 4 + 1)) then a (t / 4 + 1) else a (t / 4) lemma careTraj_four_mul (lab : V → ℕ) (a : ℕ → V) (k : ℕ) : careTraj lab a (4 * k) = a k := by simp [careTraj] lemma careTraj_four_mul_add_one (lab : V → ℕ) (a : ℕ → V) (k : ℕ) : careTraj lab a (4 * k + 1) = a k := by simp only [careTraj];
