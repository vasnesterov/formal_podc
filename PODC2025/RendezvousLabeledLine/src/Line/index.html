import Papers.PODC2025.RendezvousLabeledLine.Model /-! # Agents on the infinite labelled line **The line.** Nodes are the integers `ℤ`; a labelling is an injective `ℓ : ℤ → ℕ` (the paper uses labels in `ℕ*`; `0` is harmless here). **Agents (frame model).** An agent does not know the orientation of the line nor its position. Port numbers are adversarial, but an agent always knows through which port it entered the current node, hence it can keep walking in the same direction or turn back; it can therefore maintain its position relative to its start node in *its own frame*, in which "port 0 at the start node" is the positive direction. We model a deterministic algorithm by its trajectory in its own frame: `pos μ t : ℤ` is the agent's position after `t` rounds of its own clock when the labels seen in its frame are `μ` (`μ i` = label of the node at frame position `i`). The algorithm must be *causal*: the move in round `t + 1` depends only on the labels of the nodes visited up to round `t`. Both agents run the same algorithm; agent `α` starts at `v` with frame orientation `ε = ±1`, so its global position is `v + ε * pos (ℓ ∘ (v + ε * ·)) t` (`Algo.traj`). Proposition 3.2 (two ways to force a meeting on the line) and the line form of Theorem 3.1 (`thm_3_1`) are proved here. -/ namespace Podc.RendezvousLabeledLine open Function /-! ### Proposition 3.2 -/ /-- Meeting (at a node, or by crossing an edge in opposite directions) in some round of `[T, T']`;
