import Papers.PODC2025.RendezvousLabeledLine.Line import Cslib.Foundations.Data.Nat.LogStar /-! # Early-stopping coloured ruling sets on the line: the interface used by Algorithm 5 Algorithm 5 only uses the *output* of `ES-ColPathRulingSet(R)` (Algorithm 3) and the fact that a node `u` commits to it within `κ₃ R log* ℓ(u)` rounds (Lemma 3.5). An `R`-round LOCAL algorithm is the same as a map from `R`-balls to outputs, so we record Lemma 3.5 as a *rule*: a membership predicate `inS R ℓ` and a colouring `col R ℓ` of the infinite line labelled by `ℓ` such that * `inS R ℓ` is an `(R, R - 1)`-ruling set of `ℤ` (`packing`, `covering`), * `col R ℓ` takes values in `[17]` and is proper on `G^{9R-1}[S]` (`proper`), * (early stopping, Lemma 3.5 (1)–(3)) every node `u` *knows* some ruling-set node within distance `R - 1` and its colour (`knows`, `knows_exists`), and what it knows is determined by the labels within distance `κ R log* ℓ(u)` of `u` (`local_`); it need not know *all* ruling-set nodes within `R - 1` (nodes of larger labels may join the ruling set after `u` committed), * the rule commutes with the isometries of the line (`inS_frame`, `col_frame`): it is computed from the labelled line, which has no orientation and no origin.
