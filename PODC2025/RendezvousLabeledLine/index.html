Optimal Deterministic Rendezvous in Labeled Lines — PODC 2025

Yann Bourreau, Ananth Narayanan, Alexandre Nolin. Brief Announcement: Optimal Deterministic Rendezvous in Labeled Lines. PODC 2025. DOI 10.1145/3732772.3733537. Formalized version: the full version, arXiv 2505.04564 v2 (24 pp.); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. The main result, Theorem 1.1, holds: rendezvous within O(D log* ℓ_min) rounds of the first wake-up, with an explicit constant and no assumption left open (Lemma 2.1, the cited MIS/colouring subroutine, is also proved for the graphs used). The complexity proof of Lemma 3.5 (early-stopping coloured ruling sets) does not work as written and would lose the optimal bound, so saving it takes a redesign of the colouring step of Algorithm 3 with a new induction on levels. Theorem 3.1 (CarefulWalk) and Proposition 3.2 hold as stated, the other repairs are local, and the cited lower bound behind "optimal" was not checked.

Mistakes in the paper

🛠️ Lemma 3.5 (1) (running time of the early-stopping coloured ruling set)

The recurrence T_i ≤ max(O(R·i), T_{i-1}) + O(R·i) for the commitment round of level V_i only gives T_i = O(R i²), not the claimed "by induction T_i ∈ O(R·i)" (lemma_3_5_recurrence_gap).

Impact. We do not know whether the printed Algorithm 3 meets the bound. With the colouring step changed the bound holds (ES.rule, ES.colLe_isLocal), and so does Theorem 1.1. Left unrepaired, Theorem 1.1 would only give O(D (log* ℓ_min)²).

Details

T_i = 1+2+⋯+i satisfies the recurrence with equality. The +O(R·i) comes from the (deg+1)-list colouring (line 11), run with Lemma 2.1 in Θ(R log* n_i) = Θ(R i) rounds. It starts only after all lower levels have committed, because the lists depend on their colours. Line 4's "wait Θ(R·i) rounds" is therefore also unjustified.

Repair

Keep the membership computation as in the paper: membership of level i is decided after 816 R i rounds, because the chain through lower levels only adds O(R) per level. Split the colouring into two parts:

  • Linial's colour reduction on G^{9R-1}[N_i], where N_i is the set of new ruling-set nodes of level i. It does not need the lower levels' colours.

  • A sweep over the resulting 4096 classes, in which each node takes the least colour in [17] not used within distance 9R-1. This costs O(R) rounds after the lower levels' colours are known.

Then colours of level i are fixed after 40000 R i rounds, and Lemma 3.5 holds with κ₃ = 40001 (ES.rule, ES.colLe_isLocal).

🔧 Lemma 4.5 (T_{α,L} + 7L)

The proof places the ZWalk(8R_α) of SearchingWalk between rounds T+5L and T+6L, but it lasts 32R ≤ 2L rounds and can end at T+7L, so the argument only gives T_{α,L} + 8L (lemma_4_5).

Impact. Unestablished, not refuted: we prove T_{α,L} + 8L and do not know whether T+7L itself fails. This only changes the constant of Theorem 1.1.

Details

In the case R_β > R_α the extra delay τ then gives T+τ+5L+24R_β < T+8L rather than T+7L.

✏️ Slips

  • Lemma 3.5 (2) ("if outside S, v knows the members of S at distance ≤ R-1") is false for the final ruling set S: a node of a higher level can join S within R-1 of v after v committed, if it is at distance ≥ R from v's ruling-set neighbour. It holds only for S_T at v's commitment round T. What v knows at commitment time is S_T ∩ N^{R-1}(v), which contains at least one node by part (3). That is all Algorithm 5 needs (it only needs some known ruling-set node). Our interface ColRuling.knows is stated this way.

  • N^k(v) is defined as an open neighbourhood (distance in [1, k]). Line 4 of Algorithm 5 and the proofs of Lemmas 4.4–4.7 need closed balls.

Typos

  • Lemma 4.7 uses "the first bit where the colours differ"; any differing bit works.

Proof gaps in true statements (1)Lemma 3.4

🔧 Lemma 3.4 (iteration count of the greedy extension)

The claim that a node w with locally maximal b_w lies within 2R-3 of v is not justified, and "N^{3R-4}(v) contains at most 6 ruling-set nodes, therefore 6 iterations suffice" is off by one.

Impact. Statement true; the algorithm's 6 iterations are enough (gIter_spec).

Details

  • A hill-climbing argument can end farther away (up to 3R-4).

  • With the paper's count one would need 7 iterations.

  • The correct count is that at most 2 added nodes lie on each side of v, at distance in [R, 3R-3]. So 5 iterations suffice and the algorithm's 6 are enough. The same argument gives 3 iterations, against Algorithm 3's 4 (gIter_spec).

The formalizationmodel, Lean names of the results, trust

Model.

  • The line is ℤ, with an injective labelling ℓ : ℤ → ℕ.

  • Time is synchronous rounds. The second agent wakes up τ rounds after the first; τ is arbitrary and unknown. A sleeping agent sits at its start node and can be found there (delayed τ b t = b (t - τ)).

  • The agents are deterministic and identical, with no communication. They know neither D nor τ, neither positions nor orientation.

  • Frame model (Algo, Line.lean). An agent cannot see the orientation of the line, but it knows the port it entered by, so it can keep walking straight or turn back. We therefore describe an algorithm by its trajectory pos μ t in the agent's own frame: start node 0, port 0 at the start is +1, and μ is the labelling read in that frame. The algorithm is causal: the move in round t+1 depends only on the labels of the nodes visited by round t. The adversary picks the start nodes, the delay, the labelling and both frame orientations ε = ±1. This model allows fewer algorithms than raw port numbers, which an algorithm could exploit, and every frame algorithm is implementable with ports. So our upper bounds hold in the paper's model.

  • Rendezvous means being at the same node in the same round (thm_1_1). The variant with simultaneous edge-crossing detection (MeetOrCross) is used for Algorithm 5 itself, as in the paper.

  • LOCAL / ES-LOCAL (LocalBasic.lean). A T-round LOCAL algorithm is a rule (ℤ → ℕ) → ℤ → α whose value at v depends only on the labels within distance T of v (IsLocal). Early stopping means the radius depends on the node's own label. Algorithms on the unoriented line commute with the isometries of ℤ (IsEquivar); this is what lets both agents simulate the same ruling set.

  • log* is lstar n = Nat.logStar n + 1, the paper's convention log* ≥ 1 (with ⌊log₂⌋).
