Dynamic Distributed Subgraph Finding — PODC 2025

Yi-Jun Chang, Lyuting Chen, Yanyu Chen, Gopinath Mishra, Mingyang Yang. Brief Announcement: The Complexity Landscape of Dynamic Distributed Subgraph Finding. PODC 2025. DOI 10.1145/3732772.3733522. Formalized version: arXiv 2411.11544 v3 (full version).

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. The two lower bounds hold: Theorem 1.3 (Ω(log log n) for one-round MemDetect(K_s) under edge insertions) and Theorem 1.6 (Ω(log log log n) for one-round Detect(K_s) under node and edge insertions), both on bounded-degree networks, with explicit constants, and so does Theorem 1.4 (O(Δ² log log n) one-round MemList(K₃) under edge insertions), once the periodic updates are also run on the edges of G⁰. The algorithm of Theorem 1.7 (List(K₃) under node and edge insertions) is incorrect, because the rule by which a node infers a triangle is unsound once node insertions are allowed, so Theorem 1.7 and the upper half of Corollary 1.8, the tightness of the Ω(log log log n) bound, are not established. The characterizations of Sections 6–8 were not checked.

Mistakes in the paper

❌ Theorem 1.7 (the List(K₃) algorithm under node and edge insertions)

The algorithm lists a non-existent triangle: on a network of maximum degree 2 with G⁰ = {v, w}, where round 2 inserts a node x with edges {x, u}, {x, w} and round 3 inserts {u, v}, node v lists {u, v, w} although u and w are not adjacent (Alg17.theorem_1_7_algorithm_unsound).

Impact. Theorem 1.7 (existence of some O(Δ log log log n) algorithm) and the upper half of Corollary 1.8 are not established; the lower bounds (Theorems 1.3, 1.6) and Theorem 1.4 are unaffected.

Details

In the case t_uv − t_uw ≤ d, the proof lets v list {u, v, w} by reusing the argument for node v in Theorem 1.4. When {u, v} appears, v receives R_edge(u) ∋ j from u. It had received (Signal) from w j rounds earlier. Since only one change happens per round, it concludes that that change was the edge {u, w}. With node insertions, that change can instead be a new node x adjacent to both u and w. In the network above, in round 3, u reports R_edge(u) = {1} and w signalled in round 2, so v lists {u, v, w}. The Lean theorem covers every window d ≥ 1, every implementation of the remaining message parts (bit reports, periodic 1-DBList updates) and every additional output rule.

✏️ Slips

  • The definitions of List(H) and MemList(H) in §1.2 do not say that only real copies may be listed; without that, listing all triples solves List(H), which would contradict Observation 1.1 together with Theorem 1.6. §5.3 shows soundness is meant.

  • The proof of Theorem 1.4 orders the edges as t_vw < t_uw < t_uv, which ignores ties at time 0 (two edges of G⁰), where no Signals exist; such edges are known from G⁰.

  • The last paragraph of the proof of Theorem 1.6 says "node a" for node b.

Proof gaps in true statements (5)Theorem 1.4 · Theorem 1.3, proof of Lemma 4.2 · Theorem 1.3 · Theorems 1.3 and 1.6 · Theorem 1.6

🔧 Theorem 1.4 (periodic updates for edges of G⁰)

The algorithm never starts periodic updates for edges of G⁰, so with {v, w} ∈ G⁰, {u, w} inserted in round t ≥ 1 and {u, v} more than d rounds later, read literally v never learns {u, w} (no Lean counterexample).

Impact. We start the updates in round 1, and Theorem 1.4 then holds (theorem_1_4, alg14_solves).

Repair

The paper also argues only that the true triangles are listed. We add explicit listing rules and prove that no node lists a non-triangle.

🔧 Theorem 1.3, proof of Lemma 4.2 (number of classes)

A class is a vector of message patterns over all j ∈ [t], so there are 2^{O(Bt²)} classes, not t · 2^{O(Bt)}.

Impact. Statement true: this is still n^{o(1)}, so the argument survives (hypothesis h2 of Hard.not_solves_13).

🔧 Theorem 1.3 (choice of b and c)

Lemma 4.1 only gives b one friend w.r.t. (a, i), so c = d is possible, and I* may contain b.

Impact. Statement true, at the cost of a factor 2 in the count (Hard.select13).

Details

If c = d, then d is attached to both cliques in (S2), and a can learn about K^{i*} through d.

Repair

We choose b ∉ I* with at least two friends besides itself.

🔧 Theorems 1.3 and 1.6 (Ω(·) proved as "not o(·)")

Both lower-bound proofs only use B = o(log log n) (resp. o(log log log n)), so they show "not o(·)" rather than Ω(·).

Impact. Statements true: the counting works for B ≤ c · log log n, and we prove the Ω form with c = 1/8 (resp. c = 1/16).

🔧 Theorem 1.6 (possible reporters)

The last paragraph of the proof considers only nodes of K^i ∪ {a, b} as possible reporters and forgets the untouched cliques K^j, j ≠ i.

Impact. Statement true: those nodes see the same in (S1) and (S4) (theorem_1_6).

The formalizationmodel, Lean names of the results, trust

Model.

  • Deterministic, synchronous, failure-free; no randomness. Insertion-only dynamic networks on the identifier set V (Fin n in the main theorems), with two change models. EdgeIns: each round inserts at most one edge. NodeEdgeIns: alternatively one new node with arbitrary edges to present nodes. The adversary is any such network. Deletions are not modelled; no checked result uses them.

  • Every node knows G⁰, its identifier and the round number. In each round the change happens first. Then each node sends one message from the alphabet M to each neighbour; B bits means |M| ≤ 2^B. A one-round algorithm must be correct after every round on every network of maximum degree ≤ Δ.

  • Theorem 1.4's algorithm (Theorem14Alg.lean) uses full-history states (FullHist.lean). It uses d = ⌊log₂ n⌋ + 2 and T = ⌊d/2⌋. A neighbour list is sent in T blocks of 2Δ bits, using an injective encoding that exists by counting. Each round's message also carries a Signal bit and, to a new neighbour, the two recent records as lists of ages.

  • Not-yet-inserted nodes run with input "absent". They know more than in the paper, so the lower bounds are at least as strong; their outputs are ignored.

  • The lower bounds quantify over all algorithms (arbitrary state spaces). NonVacuity.lean shows that with unbounded messages both problems are solvable in one round.

Corollaries 1.5/1.8 are not stated separately. The remaining cases of the correctness proof of Theorem 1.7 (node insertion, t_uv − t_uw > d) were not checked.

Open remarks on Theorem 1.7. A fix seems cheap: a freshly inserted node flags itself, and u reports its own insertion age. We have not formalized such a fix, so whether a repaired algorithm exists is open here.

We also checked on paper, but not in Lean, that no other decision rule rescues these messages (for T ≥ 2). This needs a slightly different network: {v, w} is inserted in round 1 rather than being in G⁰. Otherwise u could list the triangle from its knowledge of G⁰. Then {u, w} is inserted in round 2 and {u, v} in round 3, which is exactly the paper's case t_vw < t_uw < t_uv, t_uv − t_uw ≤ d. With suitable identifiers, each of u, v, w sees the same messages as in some triangle-free network. For v it is the network of the counterexample above. For u it is a network where a node z adjacent to v and w is inserted in round 1 instead of {v, w}. For w it is a network where a node x adjacent to u and v is inserted in round 3 instead of {u, v}.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. The hard scenarios are checked to be valid networks of the respective model with maximum degree s − 1 (edgeIns_S1, nodeEdgeIns_S4, degLE_S2, …). Model, full-history algorithms and the two counting lemmas are CSLib candidates (Model.lean, FullHist.lean, Counting.lean).
