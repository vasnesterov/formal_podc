import Mathlib /-! # Dynamic distributed subgraph finding: the model Chang–Chen–Chen–Mishra–Yang, *The Complexity Landscape of Dynamic Distributed Subgraph Finding* (PODC 2025, arXiv 2411.11544v3), Section 1.1–1.2 (model of Bonne and Censor-Hillel). * `InsNet V`: an insertion-only dynamic network on the identifier set `V`: for every round `r` the set of present nodes `pres r` and the graph `adj r`, both monotone in `r`. `G⁰ = (pres 0, adj 0)`. * Topological changes: `EdgeInsStep D r` (round `r + 1` inserts at most one edge, no node), `NodeInsStep D r` (round `r + 1` inserts one new node with an arbitrary set of edges to present nodes). The two models of the paper used here: `EdgeIns D` (edge insertions only) and `NodeEdgeIns D` (node and edge insertions). * `Algorithm V M O`: a deterministic synchronous algorithm with message alphabet `M` (bandwidth `B` bits ↔ `card M ≤ 2 ^ B`). Every node knows `G⁰` and its identifier, and in every round `r ≥ 1` it sees its *local input* `loc D r v` (whether it is present and its current neighbour set), sends one message to each neighbour (computed from its state and local input), and updates its state from the messages received from its neighbours. The topological change of round `r` happens before the communication of round `r`. Round numbers are global knowledge. * `state A D r v`: the state of `v` after round `r`; `A.out (state A D r v)` is its output for `G^r`. A one-round algorithm must be correct after every round (`Solves`). * Problems: `MemDetectOK`, `DetectOK` (target `K_s`), `MemListOK`, `ListOK` (target `K₃`). Absent (not yet inserted) nodes run the algorithm with local input `none`; this only gives them more knowledge (they know the round number and `G⁰`), which makes lower bounds stronger, and their outputs are ignored. -/ namespace Podc.DynamicSubgraphFinding open Classical -- CSLib candidate: Cslib/Computability/Distributed/DynamicNetworks/Insertion.lean (bandwidth-limited -- synchronous
