Model: a simple graph `G`, synchronous rounds. A *configuration* (Definition 3.1) is a set `S` of directed messages `(u, v)` ("`u` sent the message to `v` in the current round"); it is *on `G`* (`IsConfig G S`) if every message travels along an edge. One round of amnesiac flooding with initiator set `I` is the operator `A_{I,G}` of Definition 3.2 (`step G I`): `(u, v) ∈ A_{I,G}(S)` iff `uv ∈ E`, `(v, u) ∉ S`, and `u` received a message in `S` or `u ∈ I`. `af G = A_{∅,G}` is the fault-free round without new initiators. * `Terminates G S` — `A_∅^k(S) = ∅` for some `k`; * `runFrom G Is S` — apply `A_{I_1}, …, A_{I_k}` (multicast, Lemma 3.1 / Theorem 2.1); * `Reachable G S` — `S = A_{I_k} ⋯ A_{I_1}(∅)` for some sequence (Theorem 5.5 (2)); * `rev S` — the reversed configuration `S̄` (Definition 5.5); * `sources G S` — the nodes sending to all their neighbours (the sinks of `S̄`).
