import Papers.PODC2025.AmnesiacFloodingFaults.Model /-! # Balance of a configuration along a closed walk A closed walk of length `L ≥ 1` is a map `w : ZMod L → V` with `w k ~ w (k + 1)`. A message `(w k, w (k+1))` travels *clockwise* at position `k`, a message `(w k, w (k-1))` travels *anticlockwise* at position `k`; in both cases its *head* (sender) sits at position `k`. Pulling a configuration back along the walk gives a configuration on the cycle graph `C_L` (for a faux-even cycle this is the paper's even cycle representation `S^{2,H}` on `H²`, Definition 5.3), and one round of amnesiac flooding on `G` becomes one round on `C_L` in which some nodes are activated from outside the cycle (`ind_cw_step_sub`). In particular the per-node conservation law `[cw' k] - [ccw' k] = [cw (k-1)] - [ccw (k+1)]` holds. * `classSum S w k₀` — the number of clockwise minus anticlockwise messages whose heads are at positions `k₀ + 2i`, i.e. in the parity class of `k₀` when `L` is even, and anywhere when `L` is odd; * `BalancedOn S w` — all class sums vanish. For a cycle this is exactly the paper's condition (Definition 5.4): equally many messages in each direction on an odd cycle, and, on an even cycle, for every message `m` equally many messages in each direction among those whose heads are at even distance from the head of `m`. Main results: * `balancedOn_step_iff` — balance along any closed walk is invariant under `A_{I,G}` (Lemma A.1); * `not_balancedOn_of_front` — the key new lemma: if a message travels once around the closed walk (a clockwise "front" at position `k₀ + t` at every time `t ≤ L`), the configuration was imbalanced on the walk.
