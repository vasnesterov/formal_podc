import Papers.PODC2025.BAWithPredictions.Plurality import Cslib.Foundations.Data.Finset.Quorum /-! # Graded consensus and conciliation with a core set (Sections 7.1 and 7.2) The two building blocks of Algorithm 5 of [BDEG25], verified at the level of one instance: * **Algorithm 3** (graded consensus with core set, two rounds): `gcB` (the value `b_i` set after round 1, lines 3–6) and `gcOut` (the returned pair after round 2, lines 9–16). * **Algorithm 4** (conciliation with core set, one round): `conc` (lines 2–6). Each instance is described by the *receptions* of the honest processes: `r1 i j`, `r2 i j` (`rc i j` for conciliation) is what the honest `p_i` received from `p_j`. The honest senders' messages are received exactly as sent (the synchronous model), messages from faulty senders are arbitrary. The paper's assumption on the listening sets is `CoreSet`: `|L_i| ≤ 3k + 1` (the paper has `= 3k + 1`) and a core set `G` of at least `2k + 1` honest processes contained in every honest `L_i`. * Lemmas 7, 8, 9 of [BDEG25]: `lemma7`, `lemma8` (strong unanimity), `lemma9` (coherence). * Lemmas 10–14 of [BDEG25]: `lemma10`, `lemma11`, `lemma12`, `lemma13` (agreement), `lemma14` (strong unanimity). Choices for under-specified points of the paper: * "a value which occurs at least `m` times" (`thr`, the library selector `Finset.threshold?`): an arbitrary such value (by choice). For `m = 2k + 1` it is unique because `|L_i| ≤ 3k + 1`; for `m = k + 1` (Algorithm 3, line 14) it need not be unique, and Lemma 9 holds for every choice. * Conciliation: the paths from `y` to `z` include the trivial path (`y = z`), and `m_i[z]` is only used for `z ∈ T_i ∩ L_i` (the paper's line 4 "`y ∈ L_y`" is read as "`y ∈ T_i`"). If `T_i ∩ L_i = ∅` (impossible under the core-set assumption) `p_i` returns its own input.
