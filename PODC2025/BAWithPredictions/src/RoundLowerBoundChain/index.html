import Papers.PODC2025.BAWithPredictions.RoundLowerBound /-! # An unconditional early-deciding lower bound (`f + 1` rounds) and a weak Theorem 13 The paper's Theorem 13 relies on the Dolev–Reischuk–Strong early-deciding bound `min (f + 2) (t + 1)` (`EarlyDecidingLB`, a hypothesis). Here we prove, in the same lock-step Byzantine model, the classical weaker bound: every deterministic Byzantine agreement algorithm (without predictions) for `n ≥ t + 2` processes tolerating `t` Byzantine faults has, for every `f ≤ t`, a reliable execution with at most `f` Byzantine processes in which some honest process has not decided after `f` rounds (`earlyDecidingLB_weak`). Plugged into the reduction this gives Theorem 13 with `+1` instead of `+2`, unconditionally (`roundLowerBound_weak`). The proof is the classical chain argument over *send-omission* runs (`osc x O`: inputs `x`, omission pattern `O r a b` = "the round-`r` message of `a` to `b` is lost"); a run whose omitters lie in `F` is turned into a reliable run with Byzantine set `F` by `padScenario`. With `k = f`: * `claim j`: runs with the same inputs, omitters in `F`, `|F| + j ≤ k + 1`, `|F| ≤ k`, whose patterns agree on rounds `< k - j` lead to the same decision (`SameVal`). The step changes the round-`(k - j - 1)` messages one receiver `b` at a time; for `j ≥ 1` the receiver is first silenced in all later rounds (`claim j` with `F ∪ {b}`), so only `b` notices (`hist_osc_swap`); in the last round nothing needs to be silenced. * Changing one input: silence its owner in all `k` rounds (`claim k` with `F = {a}`). -/ namespace BAWithPredictions open
