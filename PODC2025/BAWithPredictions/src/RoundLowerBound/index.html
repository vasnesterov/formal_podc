Model: CSLib's synchronous lock-step model (`Cslib.Byzantine.LockStep`) on the complete graph, deterministic history-based protocols, static Byzantine adversary, reliable channels. A process' input is a pair `(v, a)` of a value `v : V` and a classification prediction `a : P → Bool` (`a j = true`: "`p_j` is predicted honest"). The paper reduces Theorem 13 to the early-deciding lower bound of Dolev–Reischuk–Strong for algorithms *without* predictions, which it cites. We state that bound as an explicit hypothesis (`EarlyDecidingLB`) — in the **Byzantine** model, see the docstring — and prove the reduction: * `simProtocol X alg`: the prediction-free algorithm `S'` on the processes outside `X`, which run `alg` with the prediction "`X` is faulty, everyone else is honest"; the processes of `X` are silent Byzantine (`liftScenario`, `status_liftScenario`, `solves_simProtocol`). * `padScenario` (shared, `Cslib/Computability/Distributed/Byzantine/LockStep/Basic.lean`): Byzantine processes that behave exactly as honest ones (used to reach exactly `f` faults). * `roundLowerBound`: Theorem 13 conditional on `EarlyDecidingLB`, with the sharper bound `min (f' + 2) (t - f + f' + 1)` for `f' = min f ⌊B/(n-f)⌋`; `roundLowerBound_paper`: the paper's four-term bound. -/ namespace BAWithPredictions open Cslib.Byzantine.LockStep Finset /-- **Byzantine agreement with predictions**: Byzantine agreement (termination, strong unanimity, agreement) on the value component of the inputs; the prediction component is advice only. -/ def BAP {P V : Type*} : Spec P (V × (P → Bool)) V := fun x H dec => BA (fun p => (x p).1) H dec /-!
