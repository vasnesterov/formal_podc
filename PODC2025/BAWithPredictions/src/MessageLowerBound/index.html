We work in CSLib's synchronous Byzantine model (`Cslib.Byzantine.PartialSync`, runs with `gst = 0`, any delay bound `δ`; `δ = 0` is the lock-step model), with or without signatures. Inputs are pairs `(value, prediction)`; the prediction type `Pr` is arbitrary and "correct prediction" is an arbitrary predicate `Cor F p a` ("`a` is a correct prediction for `p` when `F` is the faulty set"), of which we only assume that every honest process *has* a correct prediction. For classification predictions `Cor F p a := a = correctPred F` (`message_lower_bound_classification`). The proofs are done in the **omission model** (`OmExec`), where the faulty set is only an *admissible* set for a fixed execution; omission executions are Byzantine runs (`OmExec.toRun`), so the bounds transfer. * `t_sq_om`: `⌊t/2⌋ · ⌈t/2⌉` messages (Dolev–Reischuk with predictions). * `n_om`: `⌈n/4⌉` messages in a fault-free execution. * `message_lower_bound`: **Theorem 14**, `n + t² ≤ 8 · #messages + 1`. ## Differences with the paper's proof The paper proves the bound for Byzantine *broadcast* and transfers it to agreement; we prove it directly for Byzantine agreement (strong unanimity).
