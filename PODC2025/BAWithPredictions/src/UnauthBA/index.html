import Papers.PODC2025.BAWithPredictions.UnauthPhase import Papers.PODC2025.BAWithPredictions.RoundModel /-! # Unauthenticated Byzantine agreement with classification (Section 7.3) **Algorithm 5** of [BDEG25] as a CSLib round algorithm `alg5 k`, and **Theorem 5**. Process `p_i` gets as input its proposal `x_i` and its classification vector `c_i` (the output of Algorithm 2, `classify`). The first `(2k+1)(3k+1)` positions of `π(c_i)` are split into `2k+1` blocks of `3k+1` positions; in phase `φ` (0-indexed here, `φ = 0, …, 2k`) `p_i` listens to the processes in block `φ` (`Lset k c_i φ`). Each phase has 5 rounds: | round `5φ + t` | `t = 0` | `t = 1` | `t = 2` | `t = 3` | `t = 4` | |----------------|---------------|---------------|--------------|---------------|---------------| | Algorithm 5 | line 6, GC r1 | line 6, GC r2 | line 7–8 | line 9, GC r1 | line 9, GC r2, lines 10–14 | The honest `p_i` sends (to everybody, including itself) only in the phase with `i ∈ L_i`; the message is always the pair `(value, L_i)` (the set is only used by conciliation). **Deviation from the paper (no early return).** In the paper a process that decided in phase `φ < 2k+1` takes part in phase `φ + 1` and then returns (line 10); here processes keep running until the end of phase `2k+1`. This only adds honest participation, does not change the decision (the decision is fixed at line 12) and does not change the message bound (an honest process sends only in the phase in which it belongs to its own listening set). The output (`decide`) is `decision_i`: it is set when the second graded consensus of a phase first returns grade `1` (line 12), or, for a process that has not decided, to its current value at the end of phase `2k+1` (line 14). After round `5(2k+1)` nobody sends and states do not change.
