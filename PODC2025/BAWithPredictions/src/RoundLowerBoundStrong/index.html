import Papers.PODC2025.BAWithPredictions.RoundLowerBoundChain /-! # The Byzantine early-deciding bound `min (f + 2) (t + 1)` and Theorem 13, unconditionally `RoundLowerBound.lean` reduces Theorem 13 to the early-deciding lower bound of Dolev–Reischuk–Strong for algorithms *without* predictions (`EarlyDecidingLB`, the paper's citation [21]); `RoundLowerBoundChain.lean` proves the classical `f + 1` part. Here we prove the full Byzantine bound: for `f < t`, deciding by round `f + 1` in all executions with at most `f` Byzantine processes is impossible (`earlyDecidingLB_strong`), and hence Theorem 13 holds as stated (`theorem13`), for every value type with at least two values. **The extra round.** The chain argument of `RoundLowerBoundChain.lean` (send-omission runs with at most `f` omitters) is run with decision round `K = f + 1`. Changing the round-`(K - 1)` messages into one receiver `b` used to require silencing `b` in round `K` (one more omitter). Instead we use the `(f + 1)`-st fault allowed by `f < t` as a **Byzantine** `b` that, in round `K`, sends to one honest process `q` what it sends in the second run and to everybody else what it sends in the first run (`hybrid`, `sameVal_hybrid`): then `q` sees the second run and another honest process sees the first one, so Agreement in the hybrid execution identifies the two decisions. This equivocation is exactly what makes the bound `f + 2` hold for Byzantine (but not for crash) failures. -/ set_option linter.unusedSectionVars false namespace BAWithPredictions open
