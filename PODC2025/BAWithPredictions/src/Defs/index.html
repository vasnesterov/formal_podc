import Mathlib /-! # Byzantine Agreement with Predictions — basic definitions Ben-David, Dzulfikar, Ellen, Gilbert, *Byzantine Agreement with Predictions*, PODC 2025 (arXiv:2505.01793). Section 3 ("Model"). * A **classification prediction** of process `i` is a vector `a i : P → Bool`; `a i j = true` means "`p_j` is predicted to be honest", `false` means "predicted faulty". * `wrongBits F a`: the paper's `B = B_F + B_H`, the number of incorrect bits in the predictions given to *honest* processes (processes outside `F`); the bits given to faulty processes are not counted. * `correctPred F`: the correct classification `ĉ` (`ĉ j = true ↔ j ∉ F`). -/ namespace BAWithPredictions open Finset variable {P : Type*} [Fintype P] [DecidableEq P] /-- The correct classification `ĉ` when `F` is the set of faulty processes. -/ def correctPred (F : Finset P) : P → Bool := fun j => decide (j ∉ F) /-- The number of incorrect bits of the prediction vector `ai` (of one process) when `F` is the faulty set. -/ def wrongBitsOf (F : Finset P) (ai : P → Bool) : ℕ := (univ.filter fun j => ai j ≠ correctPred F j).card /-- **The paper's `B`**: the total number of incorrect prediction bits given to honest processes (Section 3: `B = B_F + B_H`). -/ def wrongBits (F : Finset P) (a : P → P → Bool) : ℕ := ∑ i ∈ univ.filter (· ∉ F), wrongBitsOf F (a i) /-- `B_F`: bits that predict a faulty process to be honest. -/ def wrongBitsF (F : Finset P) (a : P → P → Bool) : ℕ := ∑ i ∈ univ.filter (· ∉ F), (F.filter fun j => a i j = true).card /-- `B_H`: bits that predict an honest process to be faulty. -/ def wrongBitsH (F : Finset P) (a : P → P → Bool) : ℕ := ∑ i ∈ univ.filter (· ∉ F), ((univ.filter (· ∉ F)).filter fun j => a i j = false).card omit [Fintype P] in @[simp] theorem
