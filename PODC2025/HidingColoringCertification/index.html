Strong and Hiding Distributed Certification of k-Coloring — PODC 2025

Augusto Modanese, Pedro Montealegre, Martín Ríos-Wilson. Brief Announcement: Strong and Hiding Distributed Certification of k-Coloring. PODC 2025. DOI 10.1145/3732772.3733546. The proofs are in the full version the BA cites, arXiv 2502.13854 v1 (Feb 2025). We formalize the BA's statements, using the v1 definitions and proofs. Numbering: BA Theorems 4.1–4.4 = v1 Theorems 1.1–1.4. We also checked the corrected statements of v3 (Feb 2026, retitled "…of Bipartiteness", co-author B. Jauregui). Copy of the paper: paper.pdf.

Verdict: ❌ Intent lost. The paper's main result, Theorem 4.2 ("no strong and hiding r-round LCP for 2-colouring on classes containing an r-forgetful graph that is neither an even cycle nor of minimum degree 1, no matter the certificate size, even if not anonymous"), is false. It fails already for r = 1, for anonymous LCPs with O(log n)-bit certificates, and even on a one-graph class, and the authors' corrected v3 version (Theorems 2(1), 3(1), 4) is also false. The upper bounds hold, Theorem 4.1 and Lemma 3.2 as stated and Theorems 4.3 and 4.4 as existence statements, but the shatter-point decoder is not strongly sound and the watermelon decoder is not even sound.

Mistakes in the paper

❌ Theorem 4.2 (no strong and hiding LCP for 2-colouring)

Theorem 4.2 is false already for r = 1: a counter modulo M > 2N gives a strong, hiding, anonymous LCP with O(log n)-bit certificates for all bipartite graphs, hidden on the 1-forgetful graph θ(5,5,5) (baTheorem42_false).

Impact. The main lower bound falls, even on the one-graph class {θ(5,5,5)}, which also refutes the authors' corrected v3 statement (v3Theorem4_false). The same LCP is anonymous, so it refutes v1 Thm 1.5 (order-invariant) too.

Details

Each node gets a counter ℓ(v). With M = 5(2N+1) (odd, and larger than twice the number of nodes; nodes know N in the paper's model), a node accepts iff every neighbour's counter is ℓ(v) ± 1 (mod M).

  • Complete: a proper 0/1 colouring is accepted on every bipartite graph.

  • Strongly sound on every graph: along a closed walk through accepting nodes, the integer displacement z satisfies M | z, |z| ≤ L and z ≡ L (mod 2). A walk of length L < 2n < M therefore has even length, and short closed walks suffice for bipartiteness.

  • Hiding, even against identifier-aware extraction algorithms: use θ(5,5,5), i.e. three paths of length 5 between two endpoints. It is bipartite, connected, 1-forgetful under both the BA and v3 definitions, has minimum degree 2, and is not a cycle. Label it t + height (t ∈ ZMod M), with identifiers rotating mod 5 on five nodes. Then node 2's view for t equals node 1's view for t+1: identifiers, ports, labels and degrees all agree. Nodes 1 and 2 are adjacent, so a successful extractor would flip its output at node 1 with every step t ↦ t+1. This is impossible since M is odd.

The proof's gap: Lemma 5.3 (v3: Lemma 21) needs the odd closed walk in V(D,n) to have at most √(N/Δʳ) views, and this is never checked. Here every odd cycle of V(D,n) has length ≥ M > 2N. This refutes BA Thm 4.2 for H = all bipartite graphs (baTheorem42_false) and v3's corrected statement for the class {θ(5,5,5)} (v3Theorem4_false).

❌ Theorem 4.2 for anonymous constant-size LCPs (unjustified restriction of the class)

Theorem 4.2 fails even for anonymous constant-size LCPs: the paper's own LCP of Lemma 4.1 is complete on all bipartite graphs, strongly sound, and hiding through P₆ ⊔ K₂ (baTheorem42Anon_false).

Impact. A second refutation of the main lower bound, caused by a false step of its proof; the authors concede the quantifier issue in v3 §2.2.4 and add G ∩ H = ∅.

Details

v1 §5.2 says: "without restriction H only consists of r-forgetful graphs …, since a strong and hiding LCP for H is one for every subclass". This is false, because hiding only needs one hard instance. So the counterexample works for H = all bipartite graphs.

✏️ Slips

  • Definition of r-forgetful (BA, used in Theorem 4.2): it requires every w ∈ Nʳ(u) to move away along the path, which is unsatisfiable for r ≥ 2 (take w = v₁: the distance drops from 1 to 0), so BA Theorem 4.2 is vacuous for r ≥ 2 as written (not_isForgetful_of_two_le). v3 Definition 22 fixes this, and for r = 1 both definitions hold for θ(5,5,5).

  • Lemma 4.1 (δ = 1, part of Thm 4.1), rule "all other neighbours of ⊤ are labelled β ∈ {0,1}": the rule works only if β is the same for all neighbours; if each neighbour may carry its own colour, a 5-cycle with a pendant node is accepted everywhere (literalLCP_not_sound). We prove the lemma with the uniform reading (theorem_4_1).

  • k-col is defined with colours {0,…,k} (k+1 colours).

  • In Lemma 3.2's proof, "proper 2-coloring" should read "k-coloring".

🛠️ Theorem 4.3 (shatter-point decoder is not strongly sound)

The paper's decoder accepts a 5-cycle: two type-1 nodes u, u' attached to the same (rejecting) type-0 node can carry different colour vectors (0,0) and (0,1) (shatterLCP_not_stronglySound).

Impact. The protocol claim is false, but the theorem holds as an existence statement: graphs with a shatter point include P₆ and P₆ ⊔ K₂, so the counter LCP (hiding against all algorithms) and the constant-size LCP of Lemma 4.1 (anonymous hiding) both work (theorem_4_3).

Details

u – w – u' – z' – z – u is an accepted 5-cycle, with w in component 0 and z, z' in component 1. The proof's step "by 2(c), all neighbours of a type-1 node share the same colour" is false.

🛠️ Theorem 4.4 (watermelon decoder is not sound)

The paper's decoder accepts every node of a 5-cycle, because rule 2(b) only asks that some entry of a path node records the endpoint's port (watermelonLCP_not_sound).

Impact. The protocol claim is false, but the theorem holds as an existence statement, because the counter LCP is hiding on the watermelon θ(5,5,5) (theorem_4_4).

Details

A path node never checks the entry facing an endpoint. On a 5-cycle with endpoints v₁, v₂, path node a stores in its v₂-entry the port number that v₁ uses towards a. So v₁ reads the colour of the wrong edge, and every node of the 5-cycle accepts.

🔧 Lemma 4.1 (δ = 1, part of Thm 4.1): soundness argument

The soundness argument ("since C is odd, then u ∈ V(C)") proves nothing.

Impact. Statement true (degOneLCP_stronglySoundAll, theorem_4_1).

Repair

Strong soundness follows from an explicit 2-colouring: a ⊤ node gets 1-β and a ⊥ node gets the β of its ⊤.

🔧 Lemma 4.1 (δ = 1, part of Thm 4.1): Fig. 4

Fig. 4's odd cycle in V(D,4) uses an edge between the views of nodes 3 and 4 that would need a triangle 2-3-4 (fig4_edge_not_compatible).

Impact. Statement true (degOneLCP_anonHiding, theorem_4_1).

Repair

Hiding uses three labellings of P₆ ⊔ K₂.

🔧 Lemma 4.2 (even cycles), hiding argument

The hiding argument mixes C₄ and C₆, whose views differ in N, so the claimed odd cycle is not in any V(D,n) of the paper's own model.

Impact. Statement true (lemma_4_2).

Repair

A single C₄ with reflection-symmetric ports suffices: two adjacent nodes get identical anonymous views (lemma_4_2).

The formalizationmodel, Lean names of the results, trust

Model.

  • Network and verifier. One-round LCPs (r = 1) on finite simple port-numbered graphs (ports 0..deg-1, injective), with injective identifiers < N and N = bound n known to every node. bound is arbitrary; all results hold for every choice. The model is deterministic, with no failures. The prover is an adversary that picks arbitrary labels in the soundness properties.

  • Views. A view is N, the node's own identifier, label and degree, and the multiset of neighbour records (port here, port there, identifier, label, degree). This contains the paper's radius-1 view, plus neighbour degrees. The extra degrees only strengthen extraction algorithms, hence strengthen our hiding results. Anonymous algorithms factor through View.anon.

  • Properties. We formalize completeness, soundness, strong (promise) soundness, hiding (some hard instance per algorithm) and anonymous hiding as in v1 §2. Extraction algorithms are arbitrary functions; the paper requires computable ones, which is weaker. Certificate sizes are sets sz n of admissible labels: constant size = a finite label type; the counter LCP uses labels < 5(2N+1).

  • Not covered. General r is not formalized. Thm 4.2 is refuted at r = 1, which suffices since it is stated for every r ≥ 1.
