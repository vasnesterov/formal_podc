import Papers.PODC2025.HidingColoringCertification.Model import Papers.PODC2025.HidingColoringCertification.Graph /-! # An anonymous, strongly sound LCP for 2-colouring with counters modulo `M(N)` Not in the paper: this is the LCP that refutes Theorem 4.2 (see `Theorem42.lean`). Every node gets a counter `ℓ v ∈ ℕ`. With `M = modulus N = 5 (2N + 1)` (odd, and `> 2N ≥ 2n`), a node accepts iff the counter of each of its neighbours is `ℓ v ± 1 (mod M)`. * Completeness: a proper 2-colouring (`0/1`) is accepted on every bipartite graph. * Strong soundness on every graph and for every labelling (`counterLCP_stronglySoundAll`): along a walk through accepting nodes the counter moves by `±1` per step, so a closed walk of length `L < M` has an integer displacement `z` with `|z| ≤ L`, `z ≡ L (mod 2)` and `M ∣ z`, hence `z = 0` and `L` is even. Closed walks of length `< 2n ≤ 2N < M` suffice for bipartiteness (`colorable_two_of_even_short_loops`). * The decoder ignores identifiers (`counterLCP_anonymous`); certificates are `< M`, i.e. `O(log N) = O(log n)` bits. The point is that the verifier knows `N ≥ n` (as in the paper's model) and can therefore choose a modulus larger than the length of any cycle, while the accepting neighbourhood graph contains odd cycles of length `≥ M` (`Theta.lean`). -/ namespace Podc.HidingColoringCertification open SimpleGraph /-- The modulus used by the counter LCP: odd, divisible by `5`, larger than `2N`. -/ def modulus (N : ℕ) : ℕ := 5 * (2 * N + 1) instance (N : ℕ) : NeZero (modulus N) := ⟨by unfold modulus; omega⟩ lemma modulus_odd (N : ℕ) : Odd (modulus N) := by unfold modulus; exact Odd.mul (by decide) (by exact odd_two_mul_add_one N) /-- Two counters are compatible modulo `M`. -/ def CounterStep (M a b : ℕ) : Prop := (b : ZMod M) = a + 1 ∨ (b : ZMod M) = a - 1 instance (M a b : ℕ) : Decidable (CounterStep M a b) := by unfold CounterStep; infer_instance /-- The counter LCP.
