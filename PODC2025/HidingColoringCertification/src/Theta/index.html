import Papers.PODC2025.HidingColoringCertification.ModCounter /-! # The theta graph `θ(5,5,5)` and hiding of the counter LCP `thetaG` is the graph on `Fin 14` made of three internally disjoint paths of length 5 between the endpoints `4` and `5` (a watermelon graph): `4–0–1–2–3–5`, `4–6–7–8–9–5`, `4–10–11–12–13–5`. It is bipartite, connected, has minimum degree 2, is not a cycle, and has girth 10. `thetaPG s N` equips it with a port numbering (inner path nodes: port 0 towards `4`, port 1 towards `5`; endpoints: port `j` to path `j`) and identifiers that *rotate* on `{0,…,4}`: node `i < 5` gets identifier `(s + i) mod 5`, the other nodes keep their index. `thetaLabel t` (for `t : ZMod M`) is the counter labelling `v ↦ t + h v`, where `h` is the "height" (`-1` at node 4, positions `0..3` on the paths, `4` at node 5). Key fact (`view_shift`): the view of node `2` for the parameter `t` equals the view of node `1` for the parameter `t + 1` — including identifiers, ports, labels and degrees. Since `1` and `2` are adjacent, an extraction algorithm `A` that succeeds everywhere satisfies `A(view_{t+1} 1) ≠ A(view_t 1)` for all `t ∈ ZMod M`, impossible for odd `M` (`counterLCP_hiding`).
