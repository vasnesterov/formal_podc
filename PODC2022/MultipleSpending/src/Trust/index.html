import Mathlib /-! # Trust graphs and the inconsistency number §2–3 of J. P. Bezerra, P. Kuznetsov, *How to Tame Multiple Spending in Decentralized Cryptocurrencies* (PODC 2022, full version arXiv:2205.14076). * `TrustModel P`: a quorum map `Q : P → Set (Finset P)` and a fault model `F : Set (Finset P)`; the paper's standing assumptions are the separate predicates `SelfMem` (`p ∈ Q` for every quorum `Q` of `p`) and `DownClosed` (inclusion-closed fault model). * `trustGraph F S`: the graph `G_{F,S}` on the correct processes `Π − F`, with an edge `p — q` iff `S p ∩ S q ⊈ F`. * `IsIndep F S C`: `C` (a set of processes) is an independent set of `G_{F,S}`; `card_le_indepNum`, `exists_isIndep_card_eq_indepNum` relate it to Mathlib's `SimpleGraph.indepNum`. * `inconsistencyNumber T` (Definition 3.4): the largest independence number over all graphs `G_{F,S}`, `F ∈ T.F`, `S` a quorum map. -/ namespace Podc.MultipleSpending open Finset variable {P : Type*} /-- A trust model `(Q, F)`: a quorum map and a fault model. -/ structure TrustModel (P : Type*) where /-- `Q p` is the set of quorums of `p`. -/ Q : P → Set (Finset P) /-- The fault model (adversary structure): the sets of processes that may be faulty. -/ F : Set (Finset P) namespace TrustModel variable (T : TrustModel P) /-- Every process belongs to each of its quorums (standing assumption of §2). -/ def SelfMem : Prop := ∀ p, ∀ Q ∈ T.Q p, p ∈ Q /-- The fault model is inclusion-closed (standing assumption of §2). -/ def DownClosed : Prop := ∀ F ∈ T.F, ∀ F' ⊆ F, F' ∈ T.F /-- Every process has at least one quorum (implicit in §3: otherwise there is no quorum map). -/ def HasQuorums : Prop := ∀ p, (T.Q p).Nonempty /-- The family `𝒮` of quorum maps: `S p ∈ Q p` for every process `p`. -/ def QuorumMaps : Set (P → Finset P) := {S | ∀ p, S p ∈ T.Q p} /-- `p` is live in `F`: it has a quorum without faulty processes. -/ def Live (F : Finset P) (p : P) : Prop := ∃ Q ∈ T.Q p, Disjoint Q F theorem quorumMaps_nonempty (h : T.HasQuorums) : T.QuorumMaps.Nonempty := ⟨fun p => (h p).some, fun p => (h p).some_mem⟩ end TrustModel /-- A set all of whose finite subsets have at most `k` elements has at most `k` elements. -/ theorem encard_le_of_finset {α : Type*} {s : Set α} {k : ℕ} (h : ∀ D : Finset α, ↑D ⊆ s → D.card ≤ k) : s.encard ≤ k := by by_contra hlt push Not at hlt have : ((k + 1 : ℕ) : ℕ∞) ≤ s.encard := by rw [Nat.cast_add, Nat.cast_one];
