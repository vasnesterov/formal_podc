import Papers.PODC2022.BluntingAdversary.Moves /-! # Removing the unused preamble iterations (`O^k` versus `O`) Fix, for every process, the index `J p` of the preamble iteration that the current invocation of `p` will use. Then every execution of `P(O^k)` corresponds to an execution of `P(O)`: drop all iterations except the chosen one, and delay the invocation to the start of the chosen iteration (paper, proof of Lemma 4.3, `remRedundant`). Since preambles are effect-free (they only apply read-only primitives), dropping iterations does not change the memory. `Rel J sk so` relates a configuration `sk` of `P(O^k)` to the configuration `so` of `P(O)` obtained this way; `InvK` collects invariants of the reachable configurations of `P(O^k)`. Every move of `P(O^k)` is matched by at most one move of `P(O)` (`step_det`, `step_rand_client`), except the object random step, which only fixes `J p` (`step_rand_obj`). The main consequence (`opt_le_avg`): the value of `P(O^k)` is at most the average, over the uniformly random choices `J`, of the values of `P(O)` from the corresponding configurations. This is the *correct* way to compare `P(O^k)` with `P(O)`: the object random choices are independent of everything the adversary can observe before they are made, so they can be sampled in advance; the paper instead lets the simulating adversary pick the "best" choice afterwards, which is not a valid (causal) adversary. -/ set_option linter.unusedSectionVars false namespace
