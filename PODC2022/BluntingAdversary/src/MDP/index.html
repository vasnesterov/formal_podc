import Mathlib /-! # Finite-horizon games against a strong adversary A small generic layer used to define "the probability that a program reaches a set of outcomes" (paper: `Prob[P(O) → B]`, Section 2.4) as the value of a game between a full-information (strong) adversary and the random choices of the system. * `MDP Q S`: in every state `s`, every process `q : Q` has one `Move`: none (`stop`), a deterministic step, or a step that picks one of `m + 1` successors uniformly at random. * `MDP.val pay n s`: the optimal expected payoff with at most `n` steps (the adversary picks the process that moves; a run that has not terminated after `n` steps pays `0`; a terminal state pays `pay s`). * `MDP.opt pay s = ⨆ n, val pay n s`: the optimal expected payoff of a terminating run. Since the adversary sees the whole state, this is the supremum over all (history-dependent) strong adversaries; `MDP.valS σ` is the value of a fixed positional adversary `σ`. Main tools: `val_le_of_super` (a *supersolution* bounds the value), `opt_det`, `opt_rand` (lower bounds along the adversary's moves), `opt_add_le`, `opt_mono`. -/ set_option linter.unusedSectionVars
