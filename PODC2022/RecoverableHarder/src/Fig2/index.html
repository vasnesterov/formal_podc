Objects live at the nodes `π : List Bool` of the tournament tree (`Idx`): two registers `R_A = (π, false)`, `R_B = (π, true)` with values `Option Bool` (initially `⊥ = none`) and one object `O = π` of the readable type `S` (initially `q₀`). `fig2 rd π u team o` is the code of Figure 2 for processes `Fin k` with teams `team` (`false` = A, `true` = B), operations `o` and initial value `u = q₀`, *assuming* `q₀ ∉ Q_B` (the paper swaps the teams otherwise); `rd` is the read operation of `S`. Program counters (`PC`): `wr` (line 4/16, write the input to the team's register), `rd1` (line 5/17, read `O`), `chk` (line 19, `|B| = 1`: read `R_A`), `upd` (line 8/22, apply `op_i`), `rd2` (line
