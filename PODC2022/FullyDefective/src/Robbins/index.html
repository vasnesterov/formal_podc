It is grown by ears: given an asymmetric relation, strongly connected on a vertex set `S`, take an edge `xy` leaving `S`; since `xy` is not a bridge there is a path from `y` back to `x` avoiding `xy`; orient `x → y` and this path up to its first return to `S` (`ear_step`). The remaining edges are oriented by a well-order.
