States carry the node's identifier, so the set of neighbour states determines the multiset of neighbour values. Global knowledge (as assumed in the paper): `Δ` (an upper bound used to initialise packing values; we instantiate it with the maximum degree), `ε`, and the number of iterations `r` (a function of `Δ`, `α`, `ε`). Local input: the node's weight. Rounds (`T = 2r + 2` in total): * round `0`: compute `τ_v` (minimum weight in `N⁺_v`), a node `pick_v ∈ N⁺_v` of weight `τ_v`, and `x_v = τ_v/(Δ+1)`; * rounds `2i+1`, `2i+2` (`i < r`): iteration `i` of Lemma 4.1 — first `X_v` is computed and `v` joins `S` if `X_v ≥ w_v/(1+ε)`; then `v` learns whether it is dominated and, if not, multiplies `x_v` by `1+ε`; * round `2r+1`: `v` joins the output if it is in `S` or was picked by an undominated node of `N⁺_v`. Every message is the sender's state: an identifier, a weight, `τ`, an identifier, a packing value `x = τ (1+ε)^j/(Δ+1)` with `j ≤ r` (`Inv`), and three bits — i.e. `O(1)` numbers of the input size (we do not formalize bit complexity). Main result: `run_out_eq_detDS` — after `2r+2` rounds the set of nodes with `out = True` is exactly `detDS G α ε w`; together with `theorem_1_1` and `numIter_detLam_le` this gives Theorem 1.1: a
