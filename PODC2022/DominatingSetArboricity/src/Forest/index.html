import Papers.PODC2022.DominatingSetArboricity.Basic /-! # Observation A.1: dominating sets in forests Observation A.1 of the paper: "taking all non-leaf nodes" is a single-round 3-approximation of the minimum (unweighted) dominating set on graphs of arboricity 1. * `obsA1_proof_alg_fails_K2`: the algorithm used in the proof ("take all non-leaf nodes") fails on the forest consisting of a single edge (`K₂`): both nodes are leaves, so the output is empty and dominates nothing. (We read "non-leaf" as "degree `≠ 1`", the reading most favourable to the paper; with "degree `≥ 2`" isolated vertices are missed too.) The observation itself — *some* single-round 3-approximation exists — is true: see `observation_A_1_fixed`. * `observation_A_1_fixed`: the repaired algorithm — take every node of degree `≠ 1`, and in every `K₂` component the endpoint with the larger identifier (one round: a node needs its degree, its neighbours' degrees and identifiers) — is a dominating set of size at most `3 · |D|` for every dominating set `D`. The proof (the paper's parent/grandparent charging) only needs an orientation with out-degree `≤ 1`, so it holds for pseudoforests as well. -/ set_option linter.unusedSectionVars false namespace DominatingSetArboricity open Finset SimpleGraph variable {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj] /-- The paper's output: all non-leaf nodes (here: all nodes of degree `≠ 1`). -/ def nonLeaves : Finset V := univ.filter fun v => G.degree v ≠ 1 /-- The repaired output: nodes of degree `≠ 1`, plus the larger endpoint of every `K₂` component. -/ def leafFix [LinearOrder V] : Finset V := univ.filter fun v => G.degree v ≠ 1 ∨ ∃ u, G.Adj v u ∧ G.degree u = 1 ∧ u < v /-- The algorithm of the proof of Observation A.1 fails on `K₂`: the single edge is a forest (arboricity `1`) whose set of non-leaf nodes is empty, hence not dominating. -/ theorem obsA1_proof_alg_fails_K2 : (⊤ : SimpleGraph (Fin 2)).ArboricityLE 1 ∧ ¬ IsDominating ⊤ (nonLeaves (⊤ : SimpleGraph (Fin 2))) := by refine ⟨⟨fun _ => ⊤, fun _ => le_rfl, fun _ => IsAcyclic.of_card_le_two (by simp), fun _ _ h => ⟨0, h⟩⟩, fun h => ?_⟩ obtain ⟨u, hu, -⟩ := h 0 revert hu fin_cases u <;> decide variable {G} theorem leafFix_isDominating [LinearOrder V] : IsDominating G (leafFix G) := by intro v by_cases hv : G.degree v = 1 · obtain ⟨u, hu, huniq⟩ := degree_eq_one_iff_existsUnique_adj.1 hv by_cases hdu : G.degree u = 1 · rcases lt_or_gt_of_ne hu.ne with h | h · refine ⟨u, ?_, mem_cnbr.2 (Or.inr hu)⟩ simp only [leafFix, mem_filter, mem_univ, true_and] exact Or.inr ⟨v, hu.symm, hv, h⟩ · refine ⟨v, ?_, self_mem_cnbr v⟩ simp only [leafFix, mem_filter, mem_univ, true_and] exact Or.inr ⟨u, hu, hdu, h⟩ · exact ⟨u, by simp [leafFix, hdu], mem_cnbr.2 (Or.inr hu)⟩ · exact ⟨v, by simp [leafFix, hv], self_mem_cnbr v⟩ theorem cnbr_eq_singleton {v : V} (h : G.degree v = 0) : cnbr G v = {v} := by rw [cnbr_eq_insert, ← card_neighborFinset_eq_degree, card_eq_zero] at * rw [h];
