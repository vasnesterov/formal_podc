In iteration `i` of a phase, every node of `Γ = {u ∉ S ∪ S' : X_u ≥ w_u/γ}` (where `X_u` sums the packing values of the still *undominated* vertices of `N⁺_u`) joins `S'` with probability `p_i = min(γ^i/(Δ+1), 1)`. Between phases the packing values are multiplied by `γ`. ## Probability model Synchronous rounds with private randomness: in step `k` every node flips an independent coin with success probability `p_k`; the next state is a deterministic function of the current state and of the vector of coins `c : V → Bool`. The probability of a coin vector is the product weight `coinProb p c = ∏_u (if c u then p else 1 - p)`, and the expectation of a function of the final state is the finite backward recursion `expect` (the expectation under the product of the step-wise product measures). A node sampled with probability `p_k ≥ 1` is sampled regardless of its coin. ## Proof of the expectation bound The paper bounds the expected cost of a phase by a worst-case sequence of "degrees" `d_i`, which ignores that the process is adaptive. We use instead the potential (`Phi`) `Φ_i(s) = γ ∑_{v undominated} x_v (p_i d_v(s) + γ)`, `d_v = |N⁺_v ∩ Γ|`, and show that `(sampled weight) + Φ_{i+1}` does not increase `Φ_i` in expectation (`coinExpect_bound_mid`), using `w_Γ ≤ γ ∑ x_v d_v` (`wt_Gam_le`), `p_{i+1} ≤ γ p_i` and `(1 + p d)(1-p)^d ≤ (1-p²)^d ≤ 1` (`key_ineq`). At the start of a phase `Φ_0 ≤ γ(γ+1) w(D)` by weak duality, because the packing restricted to undominated vertices is feasible (`RInv`, preserved since `p = 1` in the last iteration of every phase).
