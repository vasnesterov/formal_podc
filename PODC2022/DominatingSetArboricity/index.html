Distributed Dominating Set in Bounded Arboricity Graphs — PODC 2022

Michal Dory, Mohsen Ghaffari, Saeed Ilchi. Near-Optimal Distributed Dominating Set in Bounded Arboricity Graphs. PODC 2022. DOI 10.1145/3519270.3538437. Formalized version: arXiv 2206.05174 v1 (full version with the appendix); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The main results hold: the deterministic (2α+1)(1+ε)-approximation for weighted MDS (Theorem 1.1; Theorem 3.1 for unit weights), the randomized α + O(α/t) approximation (Theorem 1.2), the general-graph bound of Theorem 1.3 and the combinatorial reduction behind the lower bound (Theorem 1.4); the KMW bound itself is external and not checked. Apart from the slips below, no stated result is false. Three places in the proofs need local repairs: Theorem 1.3's arithmetic fails for large k, where a different algorithm covers that regime; the algorithm in the proof of Observation A.1 fails on K₂; and Lemma 4.7's bound for adaptive processes is not justified.

Mistakes in the paper

✏️ Slips

  • Lemma 4.6 at λ = 1: the lemma only says "for λ > 0". Read literally with λ = 1, there are ⌈log_γ λ⁻¹⌉ = 0 phases, so S' is empty and S ∪ S' need not dominate, e.g. for a single vertex with w = x = 1 and S = ∅ (lemma_4_6_false_lam_one). The lemma's input is "the output of Lemma 4.1", which forces λ < 1, but this is not stated. We assume λ < 1, which every application satisfies (lemma_4_6_dominating).

  • Lemma 4.6 writes E[w_{S'}] = … where ≤ … is meant.

  • Lemma 4.1 and Theorem 1.1 need α ≥ 1: for α = 0 the parameter λ = 1/((2α+1)(1+ε)) violates λ < 1/((α+1)(1+ε)). Arboricity-0 graphs are edgeless and the theorem is trivial there. We assume α ≥ 1.

  • The round bound O(log(Δ/α)/ε) should be O(1 + log(Δ/α)/ε).

Typos

  • Section 3 reuses the symbol λ for α/((2α+1)(1+ε)), which differs from the λ of Section 4.

Proof gaps in true statements (3)Theorem 1.3 · Observation A.1 · Lemma 4.7

🔧 Theorem 1.3 (arithmetic for large k)

The proof uses Lemma 4.6 with γ = Δ^{1/k}, whose factor γ(γ+1)⌈log_γ(Δ+1)⌉ is ≤ Δ^{1/k}(Δ^{1/k}+1)(k+1) only if (Δ+1)^k ≤ Δ^{k+1} (and γ > 1 needs Δ ≥ 2); for Δ = k = 2, ⌈log_{√2} 3⌉ = 4, so the proof gives about 13.7 instead of the claimed 10.2 (logb_gap).

Impact. Statement true: in the uncovered regime the claimed factor is at least Δ + 1, and the trivial one-round algorithm "every node picks a lightest node of N⁺_v" achieves Δ + 1 (claimed_factor_ge, trivial_approx; combined statement theorem_1_3_full).

🔧 Observation A.1 (the algorithm of the proof fails on K₂)

The algorithm of the proof, "take all non-leaf nodes" (also stated in the introduction for trees), outputs nothing on a single edge K₂, since both nodes are leaves (obsA1_proof_alg_fails_K2).

Impact. Statement true: the observation claims only that some single-round 3-approximation exists on graphs of arboricity 1 (observation_A_1_fixed).

Details

If "non-leaf" means "degree ≥ 2", isolated vertices are missed too.

Repair

Also output the larger-ID endpoint of every K₂ component; this is still one round. The paper's parent/grandparent charging then gives the factor 3. It needs only an orientation of out-degree ≤ 1, so pseudoforests are covered too.

🔧 Lemma 4.7 (adaptive degrees)

The proof bounds E[c_v] via "the sequence d_1 ≥ … ≥ d_r that maximizes E[c_v]", but the d_i are random and depend on earlier coin flips, and the proof does not explain why a bound for every fixed sequence bounds the expectation.

Impact. Statement true; a standard argument closes the gap, since the coins are fresh in every iteration (lemma_4_6_expect).

Repair

We prove Lemmas 4.7 and 4.8 together by backward induction with the potential γ ∑_{v undominated} x_v (p_i d_v + γ), using (1-p)^d (1+pd) ≤ 1.

The formalizationmodel, Lean names of the results, trust

Model.

  • Graphs are finite simple graphs SimpleGraph V with nonnegative real weights. "Arboricity ≤ α" is G.ArboricityLE α: the edges are covered by α forests. The algorithmic theorems assume the weaker hypothesis G.OutOrientation α, an orientation with out-degree ≤ α, as allowed by footnote 2 of the paper. Observation 3.5 (ArboricityLE.hasOutDegLE) connects the two. The orientation is used only in the analysis.

  • Deterministic algorithm (Theorem 1.1). The model is synchronous LOCAL with unique identifiers: CSLib's Cslib.LocallyIterative, where a node's new state is a function of the round number, its own state, and the set of its neighbours' states, which include their IDs. Nodes know Δ, α, ε, as in the paper. We prove that the run outputs exactly the set detDS of the centralized description after 2r + 2 rounds, and we bound r. CONGEST message sizes are not formalized; each message holds O(1) numbers (see Distributed.lean).

  • Randomized algorithm (Lemma 4.6, Theorems 1.2, 1.3). This is a centralized round-by-round description in which nodes flip independent Bernoulli(p_k) coins in each step. The expectation is the exact finite expectation over all coin vectors, computed by backward recursion. Domination is proved for every coin outcome.

  • Lower bound (Theorem 1.4). The KMW lower bound for fractional vertex cover is external and not formalized. We formalize the combinatorial reduction: the construction, arboricity ≤ 2, the degrees, both directions of the approximation transfer, and the locality of the simulation.

The asymptotic form of Theorem 1.2 assumes α ≥ 2: for α = 1 the condition t ≤ α/log α is undefined, and the extension cost grows like log t. The explicit bound theorem_1_2 holds for all α ≥ 1.

Not formalized.

  • The KMW lower bound itself, and the transformation of an R-round algorithm on H into one on G. Only the fact that the simulation map does not increase distances is proved.

  • Remarks 4.4 and 4.5 (unknown Δ or α).

  • CONGEST bit complexity.

  • A locally-iterative implementation of the randomized algorithm.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. Non-vacuity:

  • every graph has an orientation with out-degree ≤ Δ (trivialOrientation), and forests are covered via Observation 3.5;

  • the hypotheses of Lemma 4.6 are met by the output of Lemma 4.1 (theorem_1_2) and by the trivial packing (theorem_1_3);

  • the lower-bound graph satisfies everything that is claimed of it.
