import Papers.PODC2022.PPLeadersStateComplexity.Model import Mathlib.Data.Fintype.Pi import Mathlib.Data.ENat.Lattice /-! # Protocols, stable computation and interaction-width (Sections 2–4 of Leroux) A protocol `(P, →*, ρ_L, I, γ)` has a finite set of states `P`, an *additive preorder* `→*` on `P`-configurations (agents may be created and destroyed), a configuration of leaders `ρ_L`, a set of initial states `I` and an output function `γ : P → {0, ★, 1}`. It *stably computes* a predicate `φ : ℕ^I → {0, 1}` if every configuration reachable from an initial configuration `ρ_L + ρ|_P` can reach a `φ(ρ)`-output stable configuration. The interaction-width of an additive preorder `R` is the least `m` such that every `(α, β) ∈ R` is realised by a word of transitions of `R` of width `≤ m`. A protocol of finite width is the reachability relation of the finite Petri net `{t ∈ R | |t| ≤ m}` (`Protocol.reach_iff`). ## Model choices * `ℕ^I` is represented by the `P`-configurations vanishing outside `I`; `ρ|_P` is then `ρ`. * The predicate is a `Bool`-valued function on such configurations. * `HasWidthLE R m` is "width `≤ m`"; `Protocol.width` is the paper's `width` as an `ℕ∞`. -/
