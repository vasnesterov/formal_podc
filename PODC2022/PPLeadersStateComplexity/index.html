State Complexity of Protocols With Leaders — PODC 2022

Jérôme Leroux. State Complexity of Protocols With Leaders. PODC 2022. DOI 10.1145/3519270.3538421. Formalized version: arXiv 2109.15171 v2 (March 2022); numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. The main result holds as printed: Theorem 4.3 is proved for every protocol of finite interaction-width, n ≤ (4 + 4·width + 2|ρ_L|)^(|P|^((|P|+2)²)), and so are Corollary 4.4 (the Ω((log log n)^h) lower bound for h < 1/2) and Examples 4.1 and 4.2. The proof of Lemma 7.3, on which Section 8 rests, is broken: it took a new argument, which gives Lemma 7.3 only with a weaker constant (the weak Pottier bound instead of Pottier's), and re-derived constants in Section 8, which are still enough for Theorem 4.3's bound. Lemmas 5.2–5.4, 6.2, 7.1, 7.2 and Theorem 6.1 are proved as stated, Lemma 6.2 with a short repair of its proof.

Mistakes in the paper

🛠️ Lemma 7.3 (Pottier step)

The proof reads the variables β(a) of system (1), one per displacement a ∈ A of a simple cycle, as counts β(e) of edges e, so the claim "#Θ'(e) > 0 if #Θ(e) ≥ k" is not established, and the length bound misses a factor |S|.

Impact. Proved with a weaker constant (the weak Pottier bound), which is still enough for Theorem 4.3's bound (lemma_7_3). The lemma with the paper's constant is neither proved nor refuted (see Not formalized.).

Details

The proof reads β(e) for edges ("Σ_H β(e) = #Θ(e)") and builds Θ' with "#Θ' = β'". That is a type error: different cycles with the same displacement are merged, so the system no longer knows which edges a solution uses. The length is also off: |Θ'| counts edges, but ‖β'‖₁ counts cycles. Each cycle has up to |S| edges, so the proof gives |Θ'| ≤ |S|·(|E|+d)(1+2|S|‖T‖)^(d(d+1)), not the stated bound without the factor |S|.

Repair

We prove Lemma 7.3 with variables indexed by the cycles themselves. This works with the weak Pottier bound (Cslib.exists_small_decomposition), whose constant does not depend on the number of variables. The constant becomes K = (2|S|M)^(2^d−1), with k > ‖Δ(Θ)|_Q‖₁·|S|·M·K and |Θ'| ≤ (|E|+d)·|S|·K. Section 8 goes through with this constant (ℓ = h^(2^d+2d+4), k = d·h^(2^d+1), threshold h^(2d+5)·ℓ). The final exponent still fits under |P|^((|P|+2)²), so Theorem 4.3 is unaffected. (lemma_7_3)

✏️ Slips

  • Section 8: Theorem 6.1 is applied to P' = P \ {i}, so it gives (d−1)‖α‖∞ ≤ b, not d‖α‖∞ ≤ b. The weaker bound suffices, because the sum is over R' ⊆ P'.

  • Section 8: "Δ(Θ)(p) = μ(p) − η'(p) − Δ(π)(p)" should read α'(p) instead of η'(p). The following estimate only works with α'.

  • Section 8: "α'(i) = ρ_L(i) + (n−1) − Δ(σ)(i)" has the wrong sign; the bound ≥ n − h holds anyway.

  • Section 8: Lemma 7.3 is used with its hypothesis ‖T‖∞ > 0 without checking it. We avoid the issue with M = 1 + ‖T‖∞.

  • Lemma 7.3's proof: Pottier's decomposition is a multiset, not a "set H".

Typos

  • Section 8 writes "d = |Q|" (meaning |P|), "the (n > i) predicate" (meaning (i ≥ n)) and "a cycle θ on x|_Q" (meaning α|_Q).

  • The proof of Lemma 7.3 writes Δ(Δ) for Δ(Θ) and swaps α'/β' in one sentence.

Proof gaps in true statements (3)Lemma 6.2 · Section 8, "#Θ(e) ≥ ℓ for every e" · Section 8, final estimate

🔧 Lemma 6.2 (bound on the restricted reachability set)

In the case where every β reachable from ρ_n has β(p) < λ_{n+1} on R_n, the proof asserts that the T|_{Q'}-reachability set of ρ_n|_{Q'} has at most sλ_{n+1}^{d−n} elements, but the case hypothesis is about the full net T.

Impact. Statement true; repaired (lemma_6_2_step).

Details

In the restricted net T|_{Q'} the places p_1, …, p_n are unconstrained, so the case hypothesis does not apply directly.

Repair

Suppose an R_n-place reaches λ_{n+1} in T|_{Q'}. A shortest such path stays in a set of at most sλ_{n+1}^{d−n} configurations, so it is that short. It then lifts to T by Lemma 5.2, since ρ_n(p_j) ≥ λ_n ≥ sλ_{n+1}^{d−n}‖T‖. That contradicts the case hypothesis. (lemma_6_2_step)

🔧 Section 8, "#Θ(e) ≥ ℓ for every e"

The decomposition of a path into a multicycle Θ and an elementary path π gives #Θ(e) ≥ ℓ − 1 (or ≥ ℓ − |S| for a short path), not #Θ(e) ≥ ℓ.

Impact. One constant changes, and the ample slack of ℓ over k absorbs it (Sec8.main_bound).

🔧 Section 8, final estimate

The proof claims r ≤ d^(d²+d+3), but the factors 2(d−1)^(d−1) ≤ d^d, 1+(2+(d−1)^(d−1))^d ≤ d^(d²) and 5d²+2d+4 ≤ d^5 only give d^(d²+d+5).

Impact. That is still ≤ d^((d+2)²), so the theorem is unaffected (Arith.final).

The formalizationmodel, Lean names of the results, trust

Model.

  • Configurations are vectors P → ℕ; ρ|_Q is modelled inside ℕ^P (zero outside Q). A protocol (Protocol) has an arbitrary additive preorder R (agents may be created and destroyed), a leader configuration, initial states I and outputs in {0, ★, 1}. S₀, S₁ and "stably computes" are the paper's definitions, word for word. Inputs ρ ∈ ℕ^I are the configurations vanishing outside I, and include ρ = 0. No fairness or scheduler is involved: stable computation is the paper's reachability definition. Everything is deterministic and there is no randomness.

  • Interaction-width: HasWidthLE R m means "width ≤ m", and width R : ℕ∞ is the paper's width. Section 3's "finite width ⇒ Petri-net reachability" is Protocol.reach_iff, with the finite net widthNet R m.

  • Theorem 4.3 is stated for every m that bounds the width (theorem_4_3), and for width(→*) itself (theorem_4_3'). The paper's n > 0 is not needed.

  • Section 6 is proved relative to a set U of active places, so that Section 8 can use P \ {i}. The paper's statement is the case U = P.

Trust. No sorry. All listed theorems use only propext, Classical.choice and Quot.sound.
