Honest `P₀`, `P₁` have inputs `0`, `1`; `P₂` is Byzantine. In the `Π_rBC` instance with sender `P₂`, `P₂` mounts the attack of `RBC.lean` (`propose 0` to `P₀` and `propose 1` to `P₁`, both arriving at `2Δ`, and votes for both), so at `3Δ` `P₀` obtains `(0, P₂)` and `P₁` obtains `(1, P₂)`; the honest instances deliver `(0, P₀)`, `(1, P₁)` to both. `P₂` then reports to each honest party exactly that party's own `O`, so `P₂` is a witness for both (each honest party has the witnesses `{itself, P₂}`, `n - tₛ = 2`), and both terminate at `4Δ + 1` with `O₀ = {0, 1, 0}` and `O₁ = {0, 1, 1}`. Discarding `max(tₐ, k) = 1` value at each end gives the outputs `0` and `1`: the honest parties do not get closer at all, `|0 - 1| = 1 > ε`. (With `S > 1` iterations the same attack can be repeated in every iteration.) The run is computed with Boolean values (by `decide`, `Run.st_eq_simStates`) and transferred to real values with `Run.st_map` (`Π_oBC` only compares values for equality, `Map.lean`).
