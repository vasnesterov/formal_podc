Both Byzantine algorithms start with the same layer: * send `⟨echo, x⟩` (own input); * upon `⟨echo, v⟩` from `t + 1` parties, send `⟨echo, v⟩` (amplification); * upon `⟨echo, v⟩` from `n − t` parties, add `v` to `approvedVals` and, if no `echo2` was sent yet, send `⟨echo2, v⟩`. `approvedVals` is not stored: `Approved t ib v` (`v` has `n − t` echoes) is read off the inbox. `IsEchoLayer t A` says that the guards of a protocol `A` for `echo`/`echo2` are exactly these.
