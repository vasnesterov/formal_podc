import Papers.PODC2022.DynamicRootedTrees.Defs /-! # Exact broadcast times `t*(𝒯ₙ)` for small `n`, computed in the kernel A verified exhaustive search. A relation on `Fin n` is encoded as a bit mask `m : ℕ` (bit `x * n + y` set iff `x → y`, i.e. row `x` is the `x`-th block of width `n`); all operations are on `ℕ` via `Nat.land`/`Nat.lor`/`Nat.shiftRight`/…, which the kernel evaluates with GMP. * `trees n`: masks of all rooted trees with self-loops on `Fin n` (enumerated as root + parent list, filtered by a decidable "reaches the root within `n` steps" test, deduplicated). `exists_mem_trees`/`rel_mem_of_mem_trees`: it encodes exactly `treesWithLoops n`. * `frontier n k`: `F₀ = {id} \ B`, `F_{k+1} = dedup {P ∘ E | P ∈ F_k, E ∈ trees n} \ B`, where `B` are the broadcast states. Composition `P ∘ E` uses a precomputed table `S ↦ ⋃_{z ∈ S} E(z)` of `E` (`tab`, `compT`); deduplication uses a bit set (`dedupAux`). * `frontier_sound`: if `G₁, G₂, … ∈ 𝒯ₙ` has not broadcast after `k` rounds, then the mask of `G₁ ∘ ⋯ ∘ G_k` is in `frontier n k`. Hence `frontier n K = []` gives `t*(𝒯ₙ) ≤ K` (`advBroadcastTime_le_of_frontier`); explicit sequences give lower bounds (`le_advBroadcastTime_of_seq`). ## Main results `advBroadcastTime_trees_one/two/three/four`: `t*(𝒯ₙ) = 0, 1, 2, 4` for `n = 1, 2, 3, 4` (frontier sizes for `n = 4`: `1, 60, 528, 48, 0`; the kernel check takes ≈ 15 s). An (unverified) Python search gives `t*(𝒯₅) = 5` (frontier sizes `620, 94380, 119640, 12360, 0`), which is out of reach of this kernel computation (≈ 1.4 · 10⁸ compositions). -/ namespace
