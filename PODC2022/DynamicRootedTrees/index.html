Broadcasting Time in Dynamic Rooted Trees — PODC 2022

Antoine El-Hayek, Monika Henzinger, Stefan Schmid. Brief Announcement: Broadcasting Time in Dynamic Rooted Trees is Linear. PODC 2022, pp. 54–56. DOI 10.1145/3519270.3538460. Formalized version: the brief announcement (BA, arXiv:2211.11352) states the result. The proofs come from the full version (FV), Asymptotically Tight Bounds on the Time Complexity of Broadcast and its Variants in Dynamic Networks, ITCS 2023, arXiv:2211.10151v2. The lower bound is due to Zeiner, Schwarz and Schmid (DAM 2019) and appears as FV Figure 5. Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. Both bounds of BA Theorem 3.1, ⌈(3n−1)/2⌉ − 2 ≤ t*(𝒯ₙ) ≤ ⌈(1+√2)n − 1⌉, are proved for all n, and there are no false statements. The BA's upper bound is one round sharper than what FV's proof gives, and a recount of FV's pigeonhole recovers that round. FV's proofs also have small slips.

Mistakes in the paper

✏️ Slips

  • FV Lemma 3.3 is stated for t₁ ≤ t₂ but used in Lemma 3.5 with t₁ = t₂ + 1 (round 1). That extra case is trivial (lemma_3_3).

Typos

  • In FV Lemma 3.5, the in-degree formula has x where r_t is meant.

  • The final comparison in FV Lemma 3.5 is not the actual pigeonhole threshold, although the inequality used is still sufficient.

  • FV Lemma 3.2 (ii) carries an unnecessary hypothesis t ≤ t'.

Proof gaps in true statements (1)BA Theorem 3.1

🔧 BA Theorem 3.1 (upper bound ⌈(1+√2)n − 1⌉)

BA Theorem 3.1 (and FV's abstract) states ⌈(1+√2)n − 1⌉, but FV Theorem 3.6 only proves the bound ⌈(1+√2)n⌉, one round weaker.

Impact. Statement true; the same argument proves it after a recount of the pigeonhole in FV Lemma 3.5 (theorem_3_1, theorem_3_6).

Details

The pigeonhole in FV Lemma 3.5 has slack. Take R = n + m − 1 rounds with m = ⌈√2 n⌉. The edge count is at least m(m+1)/2 + (n−1)m, and this exceeds the threshold (n−1)(n+m−1) iff m(m+1) > 2(n−1)².

Repair

Optimizing m gives the slightly sharper m + n − 1 for the least m with m(m+1) > 2(n−1)², about (1+√2)(n−1) (advBroadcastTime_trees_le_of_sq_lt).

Full list of differences (including modelling choices and minor imprecisions): differencies.md.

The formalizationmodel, Lean names of the results, trust

Model.

  • n processes, synchronous rounds, no failures and no randomness. Communication is full-information flooding.

  • An oblivious message adversary picks each round's communication graph from 𝒯ₙ: rooted out-trees on Fin n with a self-loop at every node (treesWithLoops). A tree is a root plus parent pointers reaching it (RootedTree); every CSLib rooted spanning tree (SimpleGraph.RootedTree) of a graph on Fin n is one (RootedTree.ofGraphRootedTree).

  • Information flow after t rounds is the relational product G₁ ∘ ⋯ ∘ Gₜ. Broadcast has happened when some process reaches all others.

  • broadcastTime is an sInf and advBroadcastTime is a ⨆. Their junk values (0 if never or unbounded) are harmless:

    • the upper bound is also stated per sequence (broadcasts_trees: every sequence of trees has broadcast by then);

    • the lower bound is witnessed by an explicit sequence that has not yet broadcast.

  • The empty product is the identity. This only matters for n = 1, where t* = 0.

Small cases. Exhaustive search gives t*(𝒯ₙ) = 0, 1, 2, 4, 5, 7 for n = 1..6, which equals the lower bound for n ≥ 2. The upper bound gives 2, 4, 7, 9, 12, 14. Only n ≤ 4 is kernel-checked in Lean; n = 5, 6 come from unverified Python/C searches.

Trees are not needed. The upper-bound proof only uses a self-loop at every node and a root that reaches everybody in each round. (broadcasts_of_rooted)

The lower bound is only a figure in FV (Figure 5), with no proof. Our reading of the figure:

  • first, the path 1 → ⋯ → n for ⌊(n−1)/2⌋ rounds;

  • then the tree rooted at n with two branches, up to round n − 2;

  • then a rotated path.

With this reading the construction is correct for every n ≥ 2. (lbSeq, lbSeq_not_broadcasts)
