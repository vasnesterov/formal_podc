Spiegelman. *Make Every Word Count: Adaptive Byzantine Agreement with Fewer Words.* PODC 2022; full version arXiv:2202.09123v2, Section 7 and Appendix C. ## Model * Processes `p_1, …, p_n`, `n = 2t + 1`, are `Fin (2t+1)`; `p_i` is index `i - 1`, so the leader `p_1` is `0`. A static set `F` of Byzantine processes, `|F| ≤ t`. Algorithm 5 is deterministic, so an adaptive adversary corrupting processes during the run is no stronger than one choosing the same set `F` up front (the run is a function of the adversary's choices). * Signatures and threshold signatures are ideal and *symbolic*. Unforgeability is a validity condition on the adversary (`AdvValid`): the adversary may use the round-1 signature `⟨v⟩_p` of a correct `p` (it is sent in round 1; we let the adversary see every message, also those sent to a correct leader), so `QC_propose(v)` is available iff `t + 1` processes are Byzantine or correct with input `v` (`QCproposeAvail`); `QC_decide(v)` is available iff every correct process has sent `⟨decide, v⟩` (Byzantine shares are always available) (`QCdecideAvail`). * **Rounds 1–5** are lock-step. A Byzantine leader delivers to each process at most one valid propose message (`Adversary.r2`) and at most one decide certificate (`Adversary.r4`). Reading of line 7: a correct process sends `⟨decide, v⟩` for at most one `v` (the first valid propose it accepts); if it accepted several, the adversary could equally have sent only the accepted one, so "at most one propose per receiver" loses no generality. A correct leader checks `v = 0` first (any fixed tie-break works). * **Fallback hand-off (lines 16–28)** in real, discrete time `ℕ`: round 5 ends at time `0` for all correct processes (synchronised clocks), and fallback messages received earlier are processed at time `0`. Each correct process sends exactly one fallback message, at its *first-hearing time* `fbTime p`: time `0` if undecided after round 5 (line 17), otherwise the first time it receives a fallback message (line 26). The adversary fixes the delay `d p q ∈ [0, δ]` of the (unique) fallback message from `p` to `q`, and sends Byzantine fallback messages to anyone at any time, carrying a valid `QC_decide(v)` (only if available) or no proof.
