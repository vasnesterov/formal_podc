import Papers.PODC2022.InternetComputerConsensus.Basic /-! # The global invariant of ICC0 `Inv π F s` collects the facts about reachable states used by all three main properties. The key ones are: * `pool_avail`: honest pools only contain available messages (unforgeability); * `share`: an honest notarization share for a round-`k` block was cast while in round `k`, after the block was echoed (its authenticator was broadcast by an honest party); * `fshare`: an honest party that cast a finalization share for `B` cast no notarization share for another block of the same round (this is what makes Property P2 hold); * `auth_unique`: an honest party authenticates at most one block per round; * `D_spec`: a disqualified rank has two distinct echoed blocks. -/ namespace
