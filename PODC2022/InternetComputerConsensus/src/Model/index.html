import Mathlib import Cslib.Computability.Distributed.Byzantine.Certificate /-! # Protocol ICC0 (Internet Computer Consensus): the model Camenisch, Drijvers, Hanke, Pignolet, Shoup, Williams. *Internet Computer Consensus.* PODC 2022. Sections 3.4–3.5, Figures 1 and 2. We model Protocol ICC0 (Tree Building Subprotocol, Figure 1, and Finalization Subprotocol, Figure 2) as an asynchronous interleaving transition system with discrete global time and idealized cryptography. * **Parties.** A finite type `P` of `n = Fintype.card P` parties; a static set `F` of corrupt parties (chosen before the execution). Only honest parties (`p ∉ F`) take protocol steps; corrupt parties are modelled by what the adversary can inject into honest pools (`Avail`). * **Blocks.** Collision resistance of `H` is idealized: a block contains its parent block itself (`Block.mk k α parent payload`), so "`phash = H(B_p)`" is "`parent = B_p`". * **Signatures.** Idealized: - an authenticator for a block of party `α` can be injected by the adversary iff `α` is corrupt or an honest party has broadcast it; - a notarization (finalization) share of `q` iff `q` is corrupt or `q` has broadcast it; - a notarization (finalization) for `B` iff at least `n - t` parties have signed it, where corrupt parties count as having signed everything (the ideal `(t, n - t, n)`-threshold signature, `Cslib.Byzantine.Certified`); - a random-beacon share of `q` iff `q` is corrupt or `q` broadcast it. The beacon value is unique, so the permutation of round `k` is a fixed function `rank k : P → ℕ`. * **Network.** Every broadcast message of an honest party is added to the global set `sent` and to the sender's own pool; the adversary delivers any available message to any honest pool at any time (asynchrony; eventual delivery and synchrony are properties of runs, see `Liveness.lean`). Pools only grow. * **Time.** A global discrete clock `now`; each honest party records the start time `t0 k` of each round `k` it entered (the paper's `t₀ ← clock()`). A `tick` advances time. In `UStep` (used for liveness) a tick is allowed only when no honest party has an enabled clause: this is the paper's "wait for" semantics (a clause is executed as soon as its condition holds). -/
