Lemma 4.5 of the paper states that the identifiers written in neighbouring registers always differ. The paper proves the stronger claim `X_p(t) ∉ {X_q(t), X̂_q(t)}` for neighbours `p, q` (here `X̂_q` is the value in the register `R_q`) by a case analysis on who moves at time `T + 1`; the case where a neighbour's register is stale is handled through the counters `r`. We prove (for every cycle length, every schedule and every proper input colouring): * `alg3_X_proper`: `X_p(t) ≠ X_{p+1}(t)`; * `alg3_X_ne_reg`: `X_p(t) ≠ X̂_q(t)` for both neighbours `q` of `p`; * `lemma_4_5`: `X̂_p(t) ≠ X̂_{p+1}(t)` (Lemma 4.5). ## The invariant Call a step of `p` *changing* if it changes `X_p`. A changing step of `p` from `x` to `x'`, having read the values `a`, `b` in its neighbours' registers, is of one of two kinds (`StepChange`): * (M, line 15) `min a b < x < max a b` and `x' = f(x, min a b) < min a b`; * (L, line 19) `x < a, b` and `x' = mex {f(a, x), f(b, x)} < x`. In both cases `x'` is below both values read. Besides the three claims above, the invariant `Alg3Proper.Inv` contains: * (`reg_r`) the register of `p` holds an earlier state of `p`: `r̂_p ≤ r_p`, and `r̂_p = r_p` implies `X̂_p = X_p` (`X` changes only together with `r`, and `r` only increases); * (`last`) if the last step of `q` was changing (`X_q ≠ X̂_q`) then, for each neighbour `p` of `q`, `R_p ≠ ⊥`, `r̂_q ≤ r̂_p` (the gate of line 11), and, **if `r̂_q = r_p`, then that step was a changing step from `X̂_q` in which `q` read the current value `X_p` in `R_p`.** The key step: when `p` makes a changing step at counter `k` and reads `X̂_q`, the gate gives `k ≤ r̂_q`; if the last step of `q` was changing then `r̂_q ≤ r̂_p ≤ r_p = k` by `last` and `reg_r`, so `r̂_q = k` and `q` computed its current `X_q` from `X̂_q` while seeing exactly `X_p`. A short case analysis (`StepChange.ne`) using Lemma 4.3 (`f(x, y) ≠ f(y, z)` for `x > y > z`) then shows that the new values of `p` and `q` differ. Simultaneous moves of `p` and `q` are the special case where each reads the other's current state.
