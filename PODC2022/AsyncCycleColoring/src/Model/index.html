import Mathlib.Data.ZMod.Basic import Mathlib.Data.Finset.Card import Mathlib.Order.Interval.Finset.Nat /-! # The asynchronous cycle with local immediate snapshots Fraigniaud, Lambein-Monette, Rabie, *Fault Tolerant Coloring of the Asynchronous Cycle* (PODC 2022 brief announcement; full version arXiv:2207.11198), Section 2. The `n` processes sit on the nodes `ZMod n` of the cycle `C_n`; the neighbours of `p` are `p - 1` and `p + 1`. Every process `p` owns a single-writer register `R_p`, initially `⊥` (`none`). A *round* of `p` (an activation) is a local immediate snapshot: `p` writes its current local state into `R_p`, reads the registers of its two neighbours and performs a local computation, which either yields a new local state or makes `p` return an output (and stop). A *schedule* `σ : ℕ → Finset (ZMod n)` gives the set `σ t` of processes activated at time `t ≥ 1`. Processes activated at the same time behave as in an immediate snapshot: first all of them write, then all of them read (Section 2.1). Activating a process that has already returned has no effect. Crashes are modelled by schedules that stop activating a process; nothing forces a schedule to be fair. Since the model has no consistent orientation, an algorithm should treat its two neighbours symmetrically; the algorithms of the paper do, but the model does not need this. We store the full local state in the register (the paper's algorithms write all their variables).
