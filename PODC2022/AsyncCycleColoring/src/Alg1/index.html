Code for process `p` with neighbours `q`, `q'`: ``` Input: X_p ∈ ℕ; Initially c_p = (a_p, b_p) ← (0, 0) Forever: write(X_p, c_p) and read((X_q, c_q), (X_q', c_q')) if c_p ∉ {c_q, c_q'} then return(c_p) else a_p ← min ℕ ∖ { a_u | u ∼ p, X_u > X_p } b_p ← min ℕ ∖ { b_u | u ∼ p, X_u < X_p } ``` A neighbour whose register is still `⊥` contributes nothing.
