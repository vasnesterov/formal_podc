import Cslib.Foundations.SocialChoice.Aggregation import Papers.PODC2022.ArrowTopology.SignModel /-! # Three alternatives: profiles ↔ consistent sign triples For a type of alternatives `X = {x, y, z}` (three distinct elements, `ThreeAlts X`), the three pairs are `pr 0 = (x, y)`, `pr 1 = (y, z)`, `pr 2 = (z, x)` (the paper's `AB, BC, CA`). * `sig1 r j`: the sign of preference `r` on the pair `pr j` (`true` = first ranked above second); `sig R j i = sig1 (R i) j` is the signature of a profile: the triangle of `N_I` it spans. * `sig1_outTri`, `sig_consistent`: signatures are consistent (no cyclic preference). * `exists_sig1_eq`, `exists_sig_eq`: every consistent sign triple is realised. * `sig1_injective`, `sig_injective`: a preference (profile) is determined by its signature. * `P_iff`: every comparison `r.P a b` is read off the signature. -/ namespace Podc.ArrowTopology open Cslib.SocialChoice /-- Three distinct alternatives exhausting `X`. -/ structure ThreeAlts (X : Type*) where x : X y : X z : X hxy : x ≠ y hyz : y ≠ z hxz : x ≠ z cover : ∀ w, w = x ∨ w = y ∨ w = z namespace ThreeAlts variable {X ι : Type*} (T : ThreeAlts X) /-- The three pairs `AB, BC, CA`. -/ def pr : Fin 3 → X ×
