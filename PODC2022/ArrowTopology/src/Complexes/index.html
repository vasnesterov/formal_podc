import Mathlib import Cslib.Foundations.SocialChoice.Aggregation import Cslib.Foundations.Combinatorics.SimplicialComplex.Nerve /-! # The complexes `N_I`, `N_O` and simplicial aggregation maps (Section 2.3) Following Baryshnikov and Section 2.3 of the paper, for any set of alternatives `X` and voters `ι`: * `U a b σ` (`σ : ι → Bool`, `true = +`) is the set of profiles in which voter `i` ranks `a` above `b` iff `σ i`; `Uo a b s` is the set of preferences ranking `a` above `b` iff `s`. Note `U a b σ = U b a (¬σ)` (`U_swap`). * The vertices of the input complex `N_I` are the *sets* `U a b σ` (`a ≠ b`), `VI ι X`; those of the output complex `N_O` are the sets `Uo a b s`, `VO X`. In both complexes a finite set of vertices is a simplex iff the sets intersect (`NI`, `NO`: nerves). * A map `f : VI ι X → VO X` is *chromatic* if it maps `U^σ_{ab}` to some `U^s_{ab}`, *unanimous* if `f (U^{(+,…,+)}_{ab}) = U^+_{ab}`, and a *projection* if `f (U^σ_{ab}) = U^{σ k}_{ab}`. * `Induces F f`: `F` maps every profile of a vertex `v` into the vertex `f v`. Results: * `prop_3_forward`, `prop_3_backward` (Proposition 3 of the full version): IIA aggregation maps induce chromatic simplicial maps `N_I → N_O`, and conversely. * `prop_4_unanimity`, `prop_4_dictator` (Proposition 4 of the full version): for corresponding `F, f`, `F` is unanimous iff `f` is, and `F` is dictatorial iff `f` is a projection. * `isChromatic_of_unanimous`: a unanimous simplicial map is automatically chromatic. This is why the PODC statement of Theorem 2.2 (which omits "chromatic", unlike the full version) is still correct. -/ namespace Podc.ArrowTopology open Cslib.SocialChoice PreAbstractSimplicialComplex
