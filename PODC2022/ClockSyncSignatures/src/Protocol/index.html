A signature token `(d, j, v)` is `d`'s signature on "my value in iteration `j` is `v`" (the iteration number prevents replaying old signatures). `alg f K` runs `K` iterations of APA; iteration `j` takes rounds `2j` and `2j + 1` and runs `n` crusader-broadcast instances in parallel, one per dealer: * round `2j` (CB step 1): every node `p` signs its current value `val_j(p)` and sends `init (p, j, val_j(p))` to all; * round `2j + 1` (CB step 2): every node forwards to all, for every dealer `d`, the token it received from `d` in round `2j` (`echo`); * after round `2j + 1`, node `w` computes the output of the instance of dealer `d` (`cbOut`): `⊥` if the token received from `d` is not a valid signature of `d` on iteration `j`, or if some echo contains a valid signature of `d` on iteration `j` with a different value; otherwise the signed value. Then (APA) `val_{j+1}(w) = apaOut f (cbOut …)` (`APA.lean`). After `2K` rounds every node decides `val_K`. ## Main results * `cb_isCrusader`: in every iteration, the CB outputs satisfy validity and crusader consistency (Definition 6) for any number of corrupted nodes. * `theorem_9`: `alg f 1` (with `f = ⌈n/2⌉ - 1`) is an `(ℓ, ℓ/2, ⌈n/2⌉ - 1)`-secure two-round protocol for approximate agreement, for every `ℓ`. * `corollary_2`: `K = ⌈log₂(ℓ/ε)⌉` iterations give an `(ℓ, ε, ⌈n/2⌉ - 1)`-secure protocol running in `2K` rounds. -/ open Cslib.Byzantine Cslib.Byzantine.LockStep set_option linter.unusedSectionVars false noncomputable section open Classical
