import Papers.PODC2022.ConsensusFromSwap.Alg1Defs /-! # Algorithm 1: obstruction-freedom (Lemma 8) Lemma 8 of Ovens, *The Space Complexity of Consensus from Swap* (PODC 2022): Algorithm 1 is obstruction-free; more precisely, a process running solo from **any** configuration (reachable or not) decides within `8 * N` of its own steps (`N = n − k` is the number of swap objects), which is the paper's bound `8(n − k)` (`lemma8_bound`). In a solo run of `p` only the local state of `p` and the objects change, so we abstract a solo step as a function `OF.sstep` on pairs (local state of `p`, memory) (`OF.run_solo_eq`). Proof structure (as in the paper): * `OF.sweep`: from any state poised on object `i`, after `N − i` steps `p` has finished the current iteration; after a full iteration started at object `0`, every object holds `p`'s identifier and a lap counter dominated by `p`'s counter (`OF.Good`); * `OF.iter_exact`: from a `Good` state the next iteration does not change `U`; the result is the `⟨U, p⟩`-total configuration `OF.tot`, or a lap if the state was already total; * from `tot me U` at most three laps (each lap followed by a conflicting iteration) lead to a decision: `5N` steps; hence `N + N + N + 5N = 8N` in total. -/ namespace ConsensusFromSwap.Alg1 open ConsensusFromSwap set_option linter.unusedSectionVars false variable {P : Type} [DecidableEq P] {m N : ℕ} [NeZero m] [NeZero N] namespace OF
