import Mathlib import Cslib.Computability.Distributed.SharedMemory.Spec import Cslib.Computability.Distributed.SharedMemory.Objects.Swap /-! # The Space Complexity of Consensus from Swap — the model Sean Ovens, *The Space Complexity of Consensus from Swap*, PODC 2022 (arXiv 2305.06507). A self-contained model of the standard asynchronous shared-memory model of the paper (Section 2) for one-shot tasks in which **processes start with their inputs** (k-set agreement, consensus): * processes `P` (any type), deterministic; process `p` with input `x` starts in local state `A.init p x`; * shared objects indexed by `ι`; object `i` has a deterministic sequential specification `T i : ObjSpec` (CSLib); the algorithm fixes their initial values `A.mem₀` (`ObjSpec.init` is ignored); * a local state either *outputs* (decides) a value (`Act.out v`, an output state; output states are final, a step taken in an output state is a no-op) or is *poised* to apply operation `o` to object `i` and continue with `k r` on response `r` (`Act.access i o k`). Every step that is not a no-op is exactly one operation on one object (local computation is folded into the continuation); * the scheduler picks the next process (`Cfg.step C p`); since everything is deterministic, a finite execution from a configuration is its list of processes (`run C α`). Correctness of a k-set agreement algorithm for the inputs in a set `S` (`SolvesSetAgreement`): * **k-agreement**: in every finite execution from an initial configuration (all inputs in `S`) at most `k` distinct values are decided (`decSet`); * **validity**: every decided value is the input of some process. **Obstruction-freedom** (`ObstructionFree`): from every reachable configuration, every process running solo decides after finitely many steps. (Nondeterministic solo-termination coincides with this for deterministic algorithms; randomization is not modelled.) -- CSLib candidate: a generalization of `Cslib.SharedMemory.Recoverable` (no crashes, arbitrary -- processes and input values). -/ namespace ConsensusFromSwap open Cslib.SharedMemory set_option linter.unusedSectionVars false section Defs variable {ι : Type} (T : ι → ObjSpec)
