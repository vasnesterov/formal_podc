Instead of the paper's "first non-dominating swap on each object" argument we prove a forward invariant (`destrInv`): every object whose lap counter does not dominate `V` is assigned a "destroyer" (the process that first swapped a non-dominating counter over a dominating one), the assignment is injective on such objects, and every destroyer's lap counter dominates `V`. -/ namespace
