Its proof assumes that every update operation (every operation other than a read) must update some base object. This fails for objects whose updates stop changing the state, e.g. test-and-set (TAS is an update, but only the first TAS changes the state). `tasAlg`: a persistent TAS from one word (`k = 1`): ``` CAS(&A[0], false, true) -- win iff it succeeds Flush(&A[0]) return (not won) ``` The word is written back to persistent memory at most once in every execution, whatever the number of invocations.
