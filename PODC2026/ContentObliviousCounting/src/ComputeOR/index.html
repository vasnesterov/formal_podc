The input of a node is `(isLeader, bool)`. **Encoding of the pseudo-code.** A node has a program counter `pc` = number of blocking receives completed so far: `pc = 0` is the receive of line 7, `pc = 1` the second receive (line 11 or 18 for the leader, line 22 for a non-leader with `bool = true`, line 26 for a non-leader with `bool = false`), `pc = 2` the barrier receive (line 32 or 34), and `pc = 3` means "returned". Port-specific receives are modelled by `ready` (lines 11, 18: port 1; line 22: port `1 - q`; lines 32, 34: port 0); the receives of lines 7 and 26 accept any port. Each reception executes the code up to the next receive (sends and assignments of `q` and `ans`). **Proof method.** In every reachable configuration, node `v` has completed `π v` receives, and the ports of these receives are those of a fixed *role* `typ v` (which depends only on the inputs and on the position of `v`; e.g. in the all-false case every node receives on ports `1, 1, 0`).
