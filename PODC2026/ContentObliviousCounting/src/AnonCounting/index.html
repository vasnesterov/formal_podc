Asynchronous, fully defective (content-oblivious) channels, adversarial scheduler, no failures, deterministic anonymous nodes. The only input is the leader flag (`true` at exactly one node). See `Cslib/Computability/Distributed/ContentOblivious/Model.lean`. ## Encoding of the pseudo-code Each blocking `receive` of Algorithms 1–4 is a program counter (`PC`); a port-specific receive is `ready` only on that port, "receive a message on port `q`" is ready on both ports. Each reception executes the code up to the next `receive`. `NonLeader` at line 2 with `q = 1` executes lines 13–14 and then either becomes the new leader (lines 15–16) or waits at line 20. * The leader's initial record has `counted = true`, `relayed = 0`
