Both are one procedure `proc`. **Encoding of the pseudo-code.** States `loop` (Alg. 7, while loop, lines 12–18), `wait` (Alg. 7 after line 19: the leader waits on port 0 only, line 21; a non-leader runs the repeat loop of lines 23–30 and reads any port), `relay` (Alg. 8, loop of lines 4–11, any port) and `ret` (returned, with the result: the decoded bit for an active node, `none` for a relay). Each reception executes the code up to the next receive. **Proof method** (all interleavings). For each node `v` let `P v = r₀ - s₀` and `Q v = s₁ - r₁` (pulses received/sent on `Port0`/`Port1`).
