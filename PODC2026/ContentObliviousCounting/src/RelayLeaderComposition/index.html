By Theorem 9 it could then be followed by any procedure. Counterexample: ring of 3 processes, process `0` is the leader and a relay, processes `1` and `2` are active. Every process runs two CCW bit rounds back to back (round 1: both active processes send `⊥`; round 2: process `1` sends `0`, process `2` sends `⊥`). Process `2`'s clockwise active neighbour is `1`, so it should obtain `[⊥, 0]`. There is an execution (16 deliveries) that ends in a final, quiescent configuration in which process `2` has obtained `[0, ⊥]`: the relay leader, still in round 1, consumes a round-2 pulse of process `1`, which then is counted as part of round 1.
