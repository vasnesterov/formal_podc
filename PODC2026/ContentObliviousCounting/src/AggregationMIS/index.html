The synchronous ring algorithm `misAlg op2` (a `SyncAlg`, to be run by the simulator of Theorem 14 on the virtual ring of the active processes) does, with `lam` = common bound on the bit length of the IDs: * rounds `0 … lam-1` (*Cole–Vishkin colour reduction*): every node sends its colour, written with `wd lam r` bits, to its clockwise neighbour; a node of colour `c` whose counter-clockwise neighbour has colour `p ≠ c` takes the colour `2i + bit_i(c)`, `i` = lowest bit where `c` and `p` differ. Colours start as the IDs (`< 2^lam`); widths follow `w ↦ size (2w - 1)`, so after `lam` rounds the colouring is proper with colours `< 8`; * rounds `lam … lam+7` (*MIS*): the leader starts in the MIS; in round `lam + i` the nodes of colour `i` that have no neighbour in the MIS join it (1-bit messages); * round `lam + 8`: neighbours exchange their MIS bit; * round `lam + 9` (*aggregation*): a node outside the MIS sends `true :: w` to its clockwise neighbour if that neighbour is in the MIS, otherwise to its counter-clockwise neighbour; a node in the MIS combines its value `w` with the received values (`op2` on encoded values). The run is computed explicitly (`run_cv`, `run_mis`, `run_ex`, `run_agg`); the combinatorial properties hold on any virtual ring with at least two nodes (`RingAx`). -/ namespace
