Every node runs a driver (`aggDriver`) whose stages are either a `ComputeOR` (procedure `OR`) or a simulation (Theorem 14) of `misAlg` (Lemma 26 + one aggregation round) on the virtual ring of the currently active nodes. The driver implements: 1. *λ-preprocessing*: `ComputeOR(size(ID) ≥ i)` for `i = 1, 2, …` until the outcome is false; then `lam = i - 1` is the maximal ID length; 2. *phases*: loneliness test `ComputeOR(active ∧ ¬leader)`; if true, simulate `misAlg` on the active nodes (MIS + aggregation); the MIS stays active; 3. *dissemination*: the leader broadcasts the bits of the final aggregate, one bit per `ComputeOR` (`ComputeOR(leader ∧ more bits)`, then `ComputeOR(leader ∧ bit)`). `simStage` is the simulation procedure with the number of rounds computed from the initial state (`Proc.precomp`), so that no stage returns at start-up. -/ namespace Cslib.ContentOblivious namespace Proc variable {I I' R : Type*} (P : Proc I R) (g : I' → I) /-- Precomposition of the input of a
