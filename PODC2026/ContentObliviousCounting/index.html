Efficient Counting and Simulation in Content-Oblivious Rings — PODC 2026

Jérémie Chalopin, Yi-Jun Chang, Giuseppe Antonio Di Luna, Haoran Zhou. Efficient Counting and Simulation in Content-Oblivious Rings. PODC 2026. DOI 10.1145/3796701.3815917. Formalized version: arXiv 2603.28260 v1 (full version; numbering follows it). Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. Lemma 16 / Theorem 17 (bit sending has the composable ending property) is false when the leader is a relay, a case the paper explicitly covers: two rounds run back to back produce swapped outputs, so the simulator's logical rings are proved only with an active leader. The counting bounds and the rest hold: Theorems 1, 4, 5, 13, 14, 22 (with an active leader), Corollary 2, and the lower bound Theorem 3 (even per execution), although the distance output of the §5 counting algorithm is off by one. Theorems 6 and 7 were not checked.

Mistakes in the paper

❌ Lemma 16 / Theorem 17 (bit sending with a relay leader)

Bit sending with a relay leader is not composable: on 3 processes (relay leader 0, active 1, 2), two CCW rounds run back to back can end in a final, quiescent configuration in which 2 has obtained [0, ⊥] instead of [⊥, 0] (BitSending.relay_leader_composition_wrong, BitSending.not_composable_relay_leader).

Impact. Each single round is correct, and Theorems 14 and 22 hold with an active leader. Theorem 14 assumes it; Theorem 22 as stated does not, and its proof does not cover a relay leader; neither does §9.2's use of relays, which may contain the leader.

Details

Lemma 16 explicitly covers a relay leader (Algorithm 8's lines 2–3 and 6 exist only for it) and Theorem 17 claims the composable ending property for it. But after forwarding the termination wave, the relay leader still reads any port, so it can consume a pulse that its already-returned clockwise neighbour sends in the next procedure. In the counterexample 1 sends ⊥ then 0, 2 sends ⊥ twice; an execution of 16 deliveries ends with the round-2 bit attributed to round 1.

🔧 Section 5, p. 9 (distance formula of the counting algorithm)

For every process probed in a completed phase (myPhase < i, including the last leader) the formula myPhase(myPhase+1)/2 − k − 1 gives its clockwise distance minus one, e.g. for n = 2 the non-leader computes 0, the leader's own distance (AnonCounting.paperResult_off_by_one, paperResult_wrong, paperResult_two).

Impact. The algorithm is correct with the corrected formula: it computes n and all distances (Theorem 4, anonCount_final).

Details

The formula is also undefined for the original leader, whose myPhase is never set.

Repair

The correct value is myPhase(myPhase+1)/2 − k (and 0 for the leader). (anonCount_final)

✏️ Slips

  • Algorithm 10: while phase < len(bits) loops over the process's own input length, so processes with longer inputs call ComputeOR more often than the others and the calls no longer match. The loop bound must be the common minimum length B (as the text suggests). Fixed in the formalization (Theorem 5).

  • "Self-decomposable for disjoint multisets" (Theorem 1) literally excludes counting ({1} ⊎ {1}); disjoint sets of processes are meant.

  • Lemmas 11–12 say the last phase is ⌈√n⌉; there are about √(2n) phases (n = 40 has 9).

  • Lemma 10's premise has p₀ uncounted and calls the per-phase invariant "immediate".

Typos

  • Theorem 4 writes d ∈ [0, n].

  • Algorithm 5's comments say phase > len for ≥.

  • Section 10: I_t = (v, …, v+t) has t + 1 processes.

Proof gaps in true statements (2)Theorem 1 · Theorem 3

🔧 Theorem 1 (λ-preprocessing pseudo-code)

With the input "ID length ≤ i" and "stop at the first false", the loop stops at i = 1 (unless some ID has one bit) and "the largest index with outcome true" does not exist; the input must be "ID length ≥ i".

Impact. Theorem 1 holds with this one condition changed; fixed in the formalization (Aggregation.theorem1_concrete).

🔧 Theorem 3 (splicing in Lemma 28)

The splicing in Lemma 28 ("replay O verbatim") cannot be literal: events of the removed part must be dropped and the kept interval's events rescheduled.

Impact. The statement is true. We use a precise crossing-sequence merge (Cslib.ContentOblivious.splice).

Repair

We prove more than stated: n⌊log₂ n⌋ ≤ 14M + 4n for every execution with M pulses in which the leader has counted. (Counting.count_lower_bound, Counting.theorem3, Cslib.ContentOblivious.splice)

The formalizationmodel, Lean names of the results, trust

Model.

  • Content-oblivious oriented rings on ZMod n, every n ≥ 1 (n = 1 self-loop, n = 2 double link) from Cslib/Computability/Distributed/ContentOblivious/Model.lean. Pulses carry nothing; a channel is a counter (equivalent to the paper's FIFO assumption). Asynchronous: at each step the adversary delivers any pulse in transit to a process willing to read that port (blocking receives on a given port or on any port). No failures; deterministic processes; all start at time 0.

  • Exactly one leader. Inputs (leader flag, IDs, bits, messages, values) are node inputs of a Prog I. Anonymous where the paper is (Theorems 4, 5); distinct IDs for Theorems 1, 3, Cor. 2.

  • "Quiescently terminating" = a bound on the pulses of every execution (so every execution is finite) and, in every final configuration (no step possible), all processes have returned and nothing is in transit. Pulse bounds hold for every reachable configuration.

  • Composition (Theorem 9, Definition 8) is formalized semantically: Proc.Composable = bounded + quiescent termination + clean (a process that has not returned and waits on a link whose other end has returned has a pulse of the current procedure in transit). A general theorem runs any sequence of such procedures chosen by the processes' local states (loops included) and adds their pulse counts (Cslib/Computability/Distributed/ContentOblivious/Staged.lean); all composite algorithms of the paper (Algorithms 5, 6, 10, the simulator and Theorem 1's algorithm) are built this way.

Not formalized.

  • Theorem 6 (multiset computation) and §9.2, which run counting on a virtual ring that need not contain the leader, although Theorem 14 needs an active leader.

  • Theorem 7 and §7 (2-edge-connected networks: relies on results of Censor-Hillel et al. and Alon–Tarsi).

  • Theorem 22 with a relay leader. Only its proof relies on the false Theorem 17; as a statement it may be true: random testing of Algorithms 5–6 with a relay leader found no error.

  • Lemma 16's claim that a relay segment is equivalent to a link for non-leader relays. It is asserted without proof; we bypass it and prove the outputs, termination and 6n bound of Theorem 17 directly.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. All composite results are instantiated with the formalized Algorithms 7–9 (no hypotheses left). Non-vacuity: the lower bound's hypothesis is met by the counting algorithm of Theorem 4 (Counting.countingCorrect_anonCount, LowerBoundNonVacuity.lean), whose O(n^1.5) bound sits above the Ω(n log n) bound. A bounded model check of the paper's pseudo-code (modelcheck/) found no errors beyond those listed above. Generic infrastructure (upstreamed to CSLib) is in Cslib/Computability/Distributed/ContentOblivious/: Prog, Compose, Staged, Hom, Mirror, Splice, VirtualRing.
