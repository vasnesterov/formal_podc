import Papers.PODC2026.ForgetIT.Spec import Cslib.Computability.Distributed.Byzantine.PartialSync.Sim /-! # Forget-IT as a timed algorithm (CSLib partially synchronous model) `forgetIT prm K` is Algorithms 1–3 as an `Algorithm` of CSLib's partially synchronous Byzantine model (`Cslib.Byzantine.PartialSync`) on processes `Fin n`: discrete time, every correct process takes one step per tick, authenticated channels without signatures, at most `f` Byzantine processes, and between correct processes every message sent at time `τ` is delivered by `max τ GST + δ`. One step of a process: 1. append the delivered messages (with their senders) to `rcv`; 2. run `K` *passes* over the rules: each pass computes, from the received messages, a list of candidate rule instances (`cands`) and executes, in this order, every candidate that is enabled (`En`) at the moment it is examined (`tryAct`); 3. advance the local clock; the messages broadcast in this step form the outbox `out`, which is sent to every process (including itself) at the next tick. The timers are the local clock: `vote-2` on timeout (line 45) once `3Δ` ticks have elapsed since the last active view entry, the view-change timer (line 65) once `4Δ` ticks have elapsed since the last view entry. Every executed rule is an enabled rule of `Defs.lean`, so every run of this algorithm is an execution of the asynchronous system of `Spec.lean` (see `Refinement.lean`). -/ namespace Podc.ForgetIT open
