import Papers.PODC2026.ForgetIT.Invariant /-! # Agreement of Forget-IT (Theorem 2, safety part) The proof follows the paper's sketch (Section 4.2.1, "Agreement"), made precise as an invariant. Fix a view `V₀ ≥ 1`, a value `v₀`, and a set `L` of at least `f + 1` correct processes, each of which, if it broadcasts a `vote-2` message for `V₀` at all, broadcasts one with lock `v₀` (`Hyp`). This is the situation after a decision of `v₀` in `V₀`. Then (`Concl`): * every correct process guards `v₀` (or nothing) in every view `> V₀`; * every echo slot of a correct process for a view `≥ V₀` holds `v₀`, and no second (`SAFE`) echo is ever sent for such a view; * every `vote-1` of a correct process in a view `> V₀` is for `v₀`; * every `vote-2` of a correct process in a view `> V₀` carries guard `v₀`. The base case is the observation that every quorum of accepted `vote-2` messages for `V₀` contains a member of `L` (`base`): hence `decision_alert[V₀]` can never become `false` and `potential_decision[V₀]` can only be `v₀`. Note that `Hyp` is "anti-monotone" in time (it only gets harder as more messages are sent), so `Hyp` in the final state gives `Hyp` in all earlier states, and `Concl` is proved by induction along the execution (`concl_reach`). Remark on the paper's sketch: it states that a decision implies that "at least `2f + 1` correct processes broadcast" the deciding `vote-2`; only `f + 1` correct ones are guaranteed, which suffices
