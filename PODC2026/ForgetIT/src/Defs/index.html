Conventions. * Views are natural numbers; the protocol uses views `1, 2, …`. The pseudocode also touches views `V - 2` and `V - 1` when entering view `V`, i.e. the nonexistent views `-1` and `0` when entering view `1`; with truncated subtraction both are view `0` here (a dummy view). * `GV Val` is `Value ∪ {SAFE}`; `⊥` is `none`. * The guard field of a `vote-2` message has type `Option (GV Val)` (the pseudocode copies `guard_i[view_i]`, which is never `⊥` for a correct
