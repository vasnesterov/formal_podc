import Papers.PODC2026.ForgetIT.Refinement /-! # Good-case latency of Forget-IT (Theorem 1 / Theorem 3, non-robust good-case latency) The paper's good-case family `F_gc`: the leader of the first view is correct and GST = 0. We prove that in every such run of `forgetIT prm K` (with `n = 3f + 1`, at most `f` Byzantine processes, any delivery times allowed by `Run.Valid f δ`, `Δ ≥ δ + 1` ticks, and `K ≥ 1` rule passes per tick) every correct process decides the leader's proposal by time `3(δ + 1)` (`good_case_latency`). In CSLib's model a message produced in the step at time `τ` is sent at `τ + 1` and delivered by `τ + 1 + δ`, where it is processed; so one message delay ("round") is `δ + 1` ticks and the bound `3(δ + 1)` is the paper's `3δ`: prepare → vote-1 → vote-2 → decide. The proof: up to time `3δ + 3` nothing disturbs view 1 (`LGood`, `good_run`): no timer has expired, no correct process sends an echo message for a view `≥ 1` (so no view change or view entry can happen), all correct `vote-1`s are for the leader's value `w`, all correct locks are on `w`. Then the leader's `prepare` is delivered by time `δ`, all correct processes `vote-1` by time `δ + 1`, lock by `2δ + 2` and decide by `3δ + 3` (`progress`). -/ set_option linter.unusedSectionVars false
