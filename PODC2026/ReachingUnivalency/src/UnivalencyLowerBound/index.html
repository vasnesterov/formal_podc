So a process crashing at time `τ` sends an arbitrary subset of its time-`τ` messages and nothing afterwards, as in the paper. (Crashed processes keep computing states in `OmExec`; this is irrelevant since nobody receives from them.) The paper composes a protocol `P₁` (univalency) that ends at time `t*` with a dissemination protocol `P₂`. We model the composition as a single deterministic algorithm `A` with binary inputs and outputs whose first phase consists of the times `< t*`: * `CrashBA f A` : `A` solves binary Byzantine Agreement with at most `f` crash faults; * `ReachesUnivalency A f t*` : for every admissible execution `E`, all correct processes decide the same value `v` in *every* admissible execution that agrees with `E`
