In particular the hypotheses of Theorems 25 and 30 are not contradictory in themselves: the restriction on the base objects is essential. All three implementations are *single-access* (every operation applies one primitive), so we use `OneAccess` (CSLib) with a deterministic refinement `ctObj P f` of the long-lived contest (`decide` returns `f` of the vector of `compete` counts, `f` = sum or maximum) and transfer the result to the nondeterministic specification `llSpec` (`IsNLinearization.of_ctObj`) and to the object type `llObj P` (`implL`, a relabelling of the object type; `implL_nStronglyLinearizable`, `implL_waitFree`). The base objects are atomic (the paper allows strongly linearizable implementations of them, which needs a composition theorem not available here). -/ set_option linter.unusedSectionVars false
