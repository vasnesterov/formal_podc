For `b ∈ {0,1}`, instance `L` of schedule `b` occupies the window `[k_b L, k_b L + R]`; it collides with schedule `1-b` (shifted by `o`) if the window meets `{k_{1-b} L' + o | L' ∈ ℤ}`.
