import Papers.PODC2026.AgreementDCK.Dynamic /-! # Necessity of dynamic common knowledge (Theorems 1.2, 1.5 and Corollary 1.6) David–Moses, *Brief Announcement: What is Agreement About if not Common Knowledge?*, PODC 2026. A protocol is represented by the interpreted system `S` of its runs together with its decision facts `dec i v` (`decideᵢ(v)`: process `i` decides `v` at the point). The paper's standing assumption that a protocol decides "based on the local state of a process" is `DecLocal`. The core of the section is one general lemma (`CN_of_precondition`): under `AoN(v)`, every precondition `φ` for a nonfaulty process deciding `v` is dynamic common knowledge w.r.t. the profile `𝛅(v) = (decide₁(v), …, decideₙ(v))` in every run in which all nonfaulty processes decide `v`; by knowledge of preconditions, a nonfaulty process deciding `v` has nonfaulty knowledge of this (`KN_CN_of_precondition`). Theorem 1.5 and both parts of Corollary 1.6 are instances. -/ open Cslib.Knowledge Cslib.Knowledge.RunFact Cslib.Knowledge.System namespace Podc.Knowledge namespace Decisions variable {ι R V : Type*} /-- The protocol satisfies the validity condition `valid` (a run fact for every value): `⊨ i ∈ N ∧ decideᵢ(v) → valid(v)` for every `v`. -/ def Validity (valid : V → R → Prop) : Prop := ∀ v,
