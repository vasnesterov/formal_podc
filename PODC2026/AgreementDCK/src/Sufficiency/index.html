The paper gives no proof; the construction and proof here are ours. Given run facts `θ v` and local profiles `ψ v` satisfying Θ-Validity, Θ-Exclusivity and Θ-Epistemic Sufficiency, the *extended protocol* `P_A` runs `P` unchanged (same system of runs and local states) and adds the decision rule `newDecᵢ(v) := ψᵢ(v) ∧ K_i (i ∈ N → θ_v)`, i.e. process `i` decides `v` when it is in its trigger state `ψᵢ(v)` and believes `θ_v` (nonfaulty knowledge without the conjunct `i ∈ N`, which is not local). This rule is local, so it is a legitimate decision rule (`theorem_1_7`, part `DecLocal`). We prove: * `P_A` satisfies AoN for every value, Agreement and `A`'s validity condition; * decisions are *conscious* in the paper's sense: once a nonfaulty process decides it keeps satisfying its decision condition (`newDec_stable`; this is where the memory hypothesis is used); * if the run has a nonfaulty process, the nonfaulty processes decide `v` iff `θ_v` (`allDecide_newDec_iff`); without any nonfaulty process this "iff" of the paper is false (`theorem_1_7_iff_false_without_nonfaulty`); * if `⊨ ⋁_v θ_v` then `P_A` satisfies Decision.
