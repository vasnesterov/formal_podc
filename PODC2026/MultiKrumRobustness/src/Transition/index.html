Write `C = cKrum = (√2+1)²`, `s = √C = √2 + 1`, `A = √(n - 2f) + √(2f)` (`amp n f`) and `x = √m`. Then `κ^>_2(m) = ((A x + f) / x²)²`, so `κ^>_2(m) = C` iff `s x² = A x + f`, whose unique positive root is `x = (A + √(A² + 4 s f)) / (2 s)`. Hence * `exists_unique_transition` — `m†` exists and is unique (for `0 ≤ f`, `2f < n`); * `transition_eq` — `m† = mDagger n f` (closed form); * `mDagger_mul_div` — `m† · C / n = gT (f / n)` *exactly*, where `gT` is continuous, `gT 0 = 1`; * `theorem_2`, `theorem_2_tendsto` — Theorem 2 (ε-δ and filter forms). ## The paper's proof The paper squares `s m = A √m + f` to `C m² = A² m + 2 A f √m + f²` and bounds the middle term by `0 ≤ 2 A f √m ≤ A² m + f²`, obtaining `(A² + √(A⁴ + 4Cf²)) / (2C) ≤ m† ≤ (A² + √(A⁴ + 2Cf²)) / C` (`transition_ge_paper`, `transition_le_paper`, both true) and claims that "both bounds reduce to `n/C (1 + o(1))`".
