Blink's thresholds `4f + 1` / `2f + 1` are tied to `n = 5f + 1`: with `n = 5f + 2` Agreement fails, even though `dep` satisfies Validity, Agreement and Integrity. Run for `f = 1`, `n = 7`, Byzantine server `6`: * servers `0–3` propose `true`, servers `4, 5` propose `false`; * server `0` receives `true` from `0, 1, 2, 3` and from the Byzantine `6`: `5 = 4f + 1` matching suggestions, so it fast-decides `true`; * server `4` receives `false` from `4, 5, 6` and `true` from `0, 1`: `5 = 4f + 1` suggestions with `3 = 2f + 1` for `false`, so it proposes `false` to `dep`; * `dep` decides `false` at server `4` (a correct server proposed `false` to `dep`), and server `4` decides `false`. * To show that the run is a prefix of a run where `dep` also terminates, we complete it: every correct server proposes to `dep` and `dep` decides `false` at every correct server (`cexRun_complete`).
