import Mathlib import Cslib.Computability.Distributed.Local.OnlineLocalLocality /-! # Proof labeling schemes: the model Basic notions for *Near-Resolution of the Tradeoff Conjecture in Distributed Proof Labeling Schemes* (A. Filtser, O. Fischer, PODC 2026). * The node set is a fixed finite type `V`; its elements are the node identifiers. A configuration is a graph `G : SimpleGraph V` together with inputs `I : V → ι`; a configuration family is a set of graphs `𝒢` together with all input assignments (the paper's `(𝒢, ℐ)`). * Labels are bit strings (`Label = List Bool`); the cost of a label is its length. * `ViewEq R G I ℓ G' I' ℓ' v`: the two labelled configurations look the same from `v` within radius `R` — the edges incident to nodes at distance `< R` agree (`GAgree`), and inputs and labels agree on all nodes at distance `≤ R` (`viewEq_iff`). This is exactly what `v` learns in `R` rounds of the LOCAL model; for `R = 1` it is the classical PLS view (own and neighbours' identifiers, inputs and labels). It is the shared `Cslib.Local.ViewEq` (`Cslib/Computability/Distributed/Local/OnlineLocalLocality.lean`) for the labelling `u ↦ (I u, ℓ u)`. * `IsLocal R f`: `f G I ℓ v` only depends on the `R`-view of `v` (`isLocal_iff`); again the shared `Cslib.Local.IsLocal` for the paired labelling. * `PLS 𝒢 P R`: an `R`-PLS (Definition 1), with prover, verifier, locality, completeness and soundness; `PLS.CostLE` bounds the cost on yes-instances. * `loc G v R` and `mask G v R f` (shared, `Cslib.Local`): the part of a configuration that `v` sees within radius `R`. Defining a verifier as a function of `loc`/`mask` makes it local by construction (`viewEq_loc_eq`, `viewEq_mask_eq`); `ver_loc_mask` transfers a local function between the full configuration and the localized one. -/ namespace PLSTradeoff open SimpleGraph open Cslib.Local (GAgree loc mask mask_of_le mask_comp viewEq_loc) /-- Labels (certificates) are bit strings. -/ abbrev Label := List Bool
