import Papers.PODC2026.PLSTradeoff.Basic /-! # Two-separated partitions and cluster-degeneracy (Section 3) * `TSPartition G t ε` (Definition 2): a partition of `V` (given by the cluster map `cl`, with `v ∈ cl v` and `u ∈ cl v → cl u = cl v`) and a separating set `X`, such that every walk between non-`X` nodes of different clusters contains two consecutive `X` nodes, every cluster has weak diameter `≤ t`, and every cluster has cost ratio `|C ∩ X| / |C| ≤ ε`. * `TSPartition.sep`: the two-separation property is equivalent to "non-`X` nodes of different clusters are at distance `> 2`" (`twoSep_iff`). * `ClusterDegenerate`, `WeaklyBounded` (Definition 3) for an ordered partition given by a cluster index `idx : V → ℕ`, and Lemma 3.1 (`TSPartition.ofDegenerate`). * Lemma 3.3 (`exists_ball_subset`), Lemma 3.4 (`hset_disjoint`). * `TSOut`, `TSOut.Correct`, `TSCert` (Definition 4): a PLS that certifies and outputs a TS partition. -/ namespace PLSTradeoff open SimpleGraph abbrev TSOut (V : Type*) := (V → Set V) × Set V /-- The output `o` of node `v` is correct for `ts` (Definition 4 (1),(2)): `v` knows the cluster `C_u` of every node `u` at distance `≤ 2` from its own G ℓ v = none` means that `v` rejects; `some o` means that it accepts with output `o`. Completeness: on graphs admitting a TS partition, all nodes accept the honest labels. Soundness: if all nodes accept, there is a TS partition for which all outputs are correct. -/ structure TSCert (𝒢 : Set (SimpleGraph V)) (t : ℕ) (ε : ℝ) (R : ℕ) where prov : SimpleGraph V → V → Label ver : SimpleGraph V → (V → Label) → V → Option (TSOut V) isLocal : IsLocal (ι := Unit) R (fun G _ ℓ v => ver G ℓ v) complete : ∀ G ∈ 𝒢, Nonempty (TSPartition G t ε) → ∀ v, (ver G (prov G) v).isSome sound : ∀ G ∈ 𝒢, ∀ ℓ : V → Label, (∀ v, (ver G ℓ v).isSome) → ∃ ts : TSPartition G t ε, ∀ v o, ver G ℓ v = some o → o.Correct ts v /-- The cost of a TS certification scheme is at most `c`. -/ def TSCert.CostLE {𝒢 : Set (SimpleGraph V)} {t : ℕ} {ε : ℝ} {R : ℕ} (S : TSCert 𝒢 t ε R) (c : ℕ) : Prop := ∀ G ∈ 𝒢, ∀ v, (S.prov G v).length ≤ c end PLSTradeoff
