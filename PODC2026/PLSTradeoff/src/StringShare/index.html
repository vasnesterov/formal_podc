import Papers.PODC2026.PLSTradeoff.Tradeoff import Cslib.Foundations.Combinatorics.SimpleGraph.Ball /-! # Sharing a string with `O(1)` bits per node (Lemma 5.6) On a connected graph, the prover can make every node output the same string `S ∈ {0,1}^r` with `O(1 + r/n)` bits per node and verification radius `2r + 1` (the paper: `4r + 2`), in such a way that whenever all nodes accept, they all output the same string. * **Lemma B.1** (`exists_clusterFam`): for `r ≥ 1` and a connected graph there is a family `𝒞` of pairwise non-adjacent node sets ("0-clusters"), each inducing a connected subgraph with exactly `s = min r n` nodes (hence of induced diameter `≤ s - 1 ≤ r - 1`), such that every node is within distance `r` of one of them. The proof is an extremal argument (add, around a node at distance `> r` from all clusters, a connected set of `s` nodes inside its `(r-1)`-ball) instead of the paper's iterative procedure; it is the same construction. * The prover (`shareLabel`) marks the nodes of the clusters (bit `InU = 0`) and gives the node of rank `i` (by identifier) in its cluster `C` the `i`-th block of length `⌈r/|C|⌉` of `S`. * The verifier (`shareVer`) of `v` works with *bounded* 0-clusters: `zball H Z r u` is the set of nodes reachable from `u` by a walk of length `≤ r` through marked nodes, and `dec` decodes the blocks stored on it. Node `v` checks that there is a marked node within distance `r`, and that all marked nodes within distance `r + 1` decode the same string; it outputs that string. * Soundness (Lemmas B.2/B.3) is replaced by a direct argument: for adjacent `a, b`, the marked node chosen by `b` is within distance `r + 1` of `a`, so `a` checked that it decodes the same string as its own; by connectivity all nodes output the same string. ## Deviations from the paper * The paper's verifier recognizes maximal 0-clusters inside `B_{4r+1}(v)` and checks their size. Using bounded clusters (`zball`), neither maximality nor size checks are needed for the property of Lemma 5.6 (agreement of all outputs), and radius `2r + 1` suffices; Lemmas B.2 and B.3 are not needed. The stated theorem keeps the paper's radius `4r + 2` (`exists_stringShare`); `exists_stringShare_sharp` has radius `2r + 1`. * Lemma B.1 assumes `|V| > r`; for `n ≤ r` we use one cluster `V` of size `n` (this is what the construction gives with `s = min r n`), with `⌈r/n⌉` bits of `S` per node. The paper claims `O(1)` bits for every `r`, which is impossible when `n · O(1) < r` (counting); the cost here is `2⌈r/n⌉ + 6` (`= O(1)` when `n ≥ r`). * `r = 0` is handled separately (every node
