The nodes are processed in increasing identifier order; node `w` has a radius index `R w` and radius `rad K (R w) = 2K + 2 + 2 R w`. When `w` is processed, the alive set is `alive w` (the nodes not yet clustered); if some alive node is within distance `2K` of `w` (`NearAlive`) and the ball of radius `r = rad K (R w)` is not expanding, `t |B_r(w) ∩ A| ≤ (t+1) |B_{r-2}(w) ∩ A|` (`Ok`), then `w` is *taken* and its cluster is `B_r(w) ∩ A`. Rather than simulating the loop, `taken` is defined by well-founded recursion on the identifier order, and the cluster of `u` is described by its centre `cen u`, the least taken `w` with `d(w, u) ≤ rad K (R w)` — exactly the paper's `FindMyCluster` (Lemmas 5.8/5.9 become the characterization `cen_eq_iff`).
