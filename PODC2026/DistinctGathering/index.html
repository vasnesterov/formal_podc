Distinct Gathering under Round-Robin — PODC 2026

Fabian Frei, Koichi Wada. Distinct Gathering and the Virtue of Self-Consistency. PODC 2026, pp. 239–246. DOI 10.1145/3796701.3815962. Formalized version: the 8-page proceedings version. The announced full arXiv version (ref. [17], "arXiv:xxxx.xxxxx") could not be found, so the proceedings version is all there is; it gives only proof sketches.

DOI · PDF · All differences · Lean source · GitHub

Verdict: ✏️ Slip. Only the impossibility results were checked, and they are correct: Theorem 4 (no algorithm gathers 3 robots from distinct positions under Round-Robin) and Theorem 1 (no algorithm gathers n ≥ 3 robots from arbitrary positions, even with a shared unit length) are proved in Lean, in a stronger form that also holds with rigid movement and a common chirality. The one mistake is that Conjecture 3 is printed with "Gathering" instead of "Distinct Gathering". The paper's main positive results, Theorem 5 (n ≥ 4) and Theorems 6 and 7 (self-consistency), were not checked, because their algorithms and proofs appear only in the unavailable full version.

Mistakes in the paper

✏️ Slips

  • Conjecture 3 (§3) is printed as "every algorithm that solves Gathering under RoundRobin is a rapid-gathering algorithm", which by the paper's own Theorem 1 is vacuously true for every n ≥ 3, so the claim in §1 and §4.1 that Theorem 5 disproves it fails as printed (conjecture_3_as_stated). Distinct Gathering is meant: §3 states Conjecture 3 after Défago et al., Conj. 1, the sentence before it speaks of "any algorithm solving this problem", meaning Distinct Gathering, and Definition 5 starts from distinct positions. For n = 3 the intended version holds vacuously by Theorem 4 (conjecture_3_distinct_three), which agrees with the paper's remark "confirming Conjectures 2 and 3 in this case". The disproof for n ≥ 4 rests on Theorem 5 together with Défago et al., Thm. 16, and was not checked.

The formalizationmodel, Lean names of the results, trust

Model (Podc/Computability/Distributed/MobileRobots/Model.lean, namespace Cslib.MobileRobots).

  • n point robots in the plane ℂ. They are oblivious, anonymous and uniform, and the algorithm is deterministic. An algorithm is any function from the snapshot to a trajectory (Finset ℂ → (ℝ → ℂ), target = value at 1). The snapshot is the set of robot positions in the robot's local frame, with the robot at the origin, so there is no multiplicity detection.

  • Variable disorientation: at every activation an adaptive adversary picks the frame, a similarity v ↦ a·v or v ↦ a·conj v with a ≠ 0 (scale, rotation, mirror). The theorems take a frame restriction frameOK. Theorem 4 needs only that all orientation-preserving similarities are allowed. Theorem 1 needs only that all rotations with the true unit length are allowed.

  • Scheduler: centralized, one robot per step, so each Look-Compute-Move cycle is atomic. IsRoundRobin means a fixed order of all n robots, repeated forever; every order is allowed.

  • Movement: an abstract Movement model fixes which stopping points the adversary may choose. The only requirement is that reaching the target is always allowed. Instances are Movement.rigid and Movement.nonrigid δ: stop at any point once the travelled arc length (eVariationOn) is at least δ. Both impossibility theorems hold for every movement model, which covers the paper's default (non-rigid, with δ known or unknown).

  • Problem: Solves n A sched frameOK M init means every legal execution from an initial configuration satisfying init eventually stays gathered. Gathering uses init = True; Distinct Gathering uses init = Injective. The counterexample executions never gather, not even for a moment.

Proof ingredients are in TwoPoint.lean. exists_fixed_view shows that some view {0, w} is answered by jumping onto the other point. step_normFrame covers the normalizing frames. run_cycle is the swapping execution, with the closed form "robot σ i is at v at time t iff [i = 1] xor [⌊t/n⌋ odd] xor [i < t mod n]".

Not formalized.

  • Theorem 5 (n ≥ 4, the nine-phase algorithm), and with it the disproof of Conjectures 2 and 3 for n ≥ 4, and Theorems 6 and 7 (n = 3 with a self-consistent unit length or compass), with the "paradox" discussion. Their algorithms and proofs appear only in the unavailable full version.

  • Theorem 4's proof sketch. The paper defers the rigorous proof to the full version, and its sketch only mentions the last 3→2-point transition and "the fact that the algorithm does not revert to a three-point configuration multiple times". We did not try to check the sketch; this is a missing proof, not an error. The theorem itself is true as stated: a short complete proof exists, it works under rigid movement, and it does not need non-rigid movement (theorem_4).

    1. The step that first gathers is a lone robot jumping onto the point of the other two. The adversary can rotate and scale every two-point view to the same view {0, w}, so every robot seeing a two-point configuration jumps onto the other point.

    2. Robots starting at distinct positions must eventually collide. So in some distinct configuration C, some robot x jumps exactly onto some robot y.

    3. Start from C with the Round-Robin order x, y, z. After x joins y, the activated robot is always accompanied, and the robots swap between the two points forever.

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity check: twoAlg solves (Distinct) Gathering of two robots in the full default model (variable disorientation, non-rigid movement with unknown δ > 0, any schedule), so Solves is satisfiable.
