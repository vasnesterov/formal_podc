import Podc.Computability.Distributed.MobileRobots.Model /-! # Two-point configurations and the swapping execution Common core of the impossibility proofs of Theorems 1 and 4 of [Frei–Wada, *Distinct Gathering and the Virtue of Self-Consistency*, PODC 2026]. * `exists_fixed_view`: if an algorithm gathers in *some* execution with the global frame, then for some `w ≠ 0` a robot seeing the view `{0, w}` moves exactly to `w`, i.e. onto the other point. * `step_normFrame`: in a configuration on two points `u ≠ v`, an adversary that rotates and scales the frame so that the other point is seen at `w` makes the activated robot jump onto the other point. With `‖v - u‖ = ‖w‖` the frames are pure rotations (consistent unit length). * `run_cycle`: the "swapping" execution. Under the Round-Robin order `σ 0, σ 1, …, σ (n-1)` with `n ≥ 3`, starting from `σ 1` alone at one point and everyone else at the other, the robots keep swapping sides forever; the activated robot is never alone, so the configuration always has two points (`cfg_not_gathered`).
