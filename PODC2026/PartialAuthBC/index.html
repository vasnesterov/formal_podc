Byzantine Consensus in the Partially Authenticated Setting — PODC 2026

Christoph Lenzen, Julian Loss, Kecheng Shi, Benedikt Wagner. Byzantine Consensus in the Partially Authenticated Setting. PODC 2026. DOI 10.1145/3796701.3815929. Formalized version: the proceedings version (pp. 282–292); numbering follows it. The full version (ePrint 2026/470) was not used. Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The main positive result holds: the gradecast Π_GC works against any number of corruptions and has the special grade-1 property (Theorem 3.9, Lemma 3.10), the broadcast Π_BC for a registered sender tolerates t ≤ s + ⌈(n−s)/3⌉ − 1 given the black-box BA among the unregistered parties (Theorem 3.13), and Theorems 3.14 and 5.1 hold. All of this needs the right reading of an ambiguous step in Figure 1, and the lower bound (Theorem 4.1, Corollary 4.2) holds for deterministic protocols once two missing hypotheses are added: an unregistered sender, and n ≥ 3 for broadcast (n ≥ 2 for agreement). The randomized lower bounds, the communication complexity and the multivalued protocol were not checked.

Mistakes in the paper

🔧 Theorem 4.1 for n = 2 and Corollary 4.2 for n = 1

For n = 2 broadcast is solvable against any number of faults although max{⌈s/2⌉, ⌈2/3⌉} = 1 ≤ t = 1, and for n = 1 agreement is trivial (theorem41_false_card_two, corollary42_false_card_one).

Impact. One condition saves the bounds: we prove Theorem 4.1 for n ≥ 3 and Corollary 4.2 for n ≥ 2 (theorem41, corollary42). The "if and only if" of the abstract inherits the n = 2 exception for broadcast.

Details

  • For n = 2, the sender sends its value and the other party outputs what it receives.

  • The cover proof needs three nonempty groups for broadcast (two for agreement).

✏️ Slips

  • Theorem 4.1 omits "the sender is unregistered". As printed it says broadcast is impossible whenever t ≥ max{⌈s/2⌉, ⌈n/3⌉}, which contradicts the paper's own Theorem 3.14: with n = s = 3, a registered sender and t = 2, broadcast is solvable (theorem41_false_registered_sender). The surrounding text makes clear that an unregistered sender is meant, and with this hypothesis the theorem holds (theorem41).

  • Figure 1, Phase 2 does not say whether the two rules for an unregistered party receiving a valid Extension, "if v = 0, set v = 1 and echo" and "if v = 1 and g = 0, set g = 1 and echo", run in sequence or exclude each other. The proof of Lemma 3.10 uses the sequential reading ("set v = 1; now v = 1 and g = 0, so set g = 1"): after a valid Extension the party is in (1, 1). We formalize this reading, and under it all lemmas hold. If the rules exclude each other, a party in state (0, 0) ends in (1, 0), and Lemma 3.10 and Theorem 3.13 are false (Exclusive.lemma310_fails_exclusive, Exclusive.theorem313_fails_exclusive):

    • Example with n = 4, S = {0 = sender, 1}, and Byzantine parties {0, 3}. In super round 1, party 3 sends party 2 an Echo2 with the 1-chain [0]; party 2 sets g = 0 and sends Echo3, so the honest registered party 1 accepts [0]. In super round 2, party 1 extends the chain, and party 2 sets v = 1 but keeps g = 0. So party 2 outputs grade 0 although an honest registered party exists.

    • Theorem 3.13 breaks too. Take as Π_unau among N = {2, 3} the protocol "AND of the exchanged values", which is a valid BA when nobody in N is faulty. Party 3 sends 0, so party 2 outputs 0 while party 1 outputs 1, with t = 2 ≤ s + ⌈(n−s)/3⌉ − 1.

  • Theorem 5.1 implicitly needs Π_auth to have a known round bound.

Typos

  • Three different versions of the small-N result appear: t ≤ s + 1, "any number of corruptions" (Theorem 3.14), and t ≤ n − 2 (Lemma 6.1). We prove the strongest one: for n − s ≤ 2, every Byzantine set.

Proof gaps in true statements (2)Lemma 3.3 · Lemmas 3.4 and 3.7

🔧 Lemma 3.3 (unforgeability step)

"Every P_j with v_j = 0 accepts the extended chain" requires P_j not to be on the chain, and the unforgeability argument for this is skipped.

Impact. The statement is true; a short signature-origin observation fills the step (emit_origin, signed_v).

Details

If P_j is on the chain, it signed it, so it already has v_j = 1.

Repair

We prove a general origin lemma: a signature of an honest registered i seen by an honest party is c ++ [i], for the chain c that i accepted. (emit_origin, signed_v)

🔧 Lemmas 3.4 and 3.7 (effect of an Echo2)

Their proofs say that an unregistered party receiving an Echo2 "sets v = 1", but it only sets g = 0.

Impact. The statements are true: the contradiction still follows through the grade.

The formalizationmodel, Lean names of the results, trust

Model.

  • Base model. CSLib's synchronous lock-step Byzantine model (Cslib.Byzantine.LockStep):

    • deterministic history-based protocols on the complete graph;

    • reliable channels;

    • a static, rushing, eavesdropping adversary.

    For deterministic protocols, the paper's adaptive adversary is equivalent. Lower bounds against a static adversary are stronger.

  • Signatures. Ideal signatures are CSLib's abstract tokens (unforgeability via Protocol.Unforging and Scenario.AuthValid). Partially authenticated means that every token has a registered signer (RegisteredSigners, SolvablePA in Model.lean). This matches F_sign^{S,N}.

  • Π_GC (binary). A chain is the list of its signers. The signature tokens are the prefixes of the chain that end in a registered signer. Super round k is rounds 4(k−1)..4k−1, and the output is at round 4s.

  • Π_BC. Π_GC is followed by a black-box unauthenticated BA ba on the subtype N = Regᶜ. The black box must tolerate every B ⊆ N with 3|B| < |N|. No fixed round count is needed.

  • Lower bounds quantify over all deterministic protocols, message types and token types (the paper does not restrict Theorem 4.1 to deterministic protocols; randomized ones are not covered).

Trust.

  • No sorry. All listed theorems use only propext, Classical.choice and Quot.sound.

  • Non-vacuity:

    • theorem313_small and theorem314 are unconditional: the black box is discharged by the OR exchange orBA.

    • orBA_boundedAuthBA gives an instance of Theorem 5.1's hypothesis (only for s ≤ 2, where 2t < s forces t = 0; theorem51_unreg_small uses it with arbitrarily many Byzantine unregistered parties).

    • The lower bounds come with matching positive instances (theorem314_solvable, bb_solvable_card_two).

  • Where the model comes from. CSLib provides Byzantine/LockStep (Basic, Auth, Cover, Agreement). The shared library Cslib/Computability/Distributed/Byzantine/LockStep provides the threshold structure atMost and the history/FirstSome helpers (Basic.lean), the sequential composition Protocol.seq used for Π_BC and Π_SBA (Sequential.lean) and the committee simulation Protocol.extend / Scenario.restrict used for the black boxes among N and S (Restrict.lean). Gradecast is the shared Problem.BinaryGradecast (Cslib/Computability/Distributed/Byzantine/Specs.lean); gradecast_iff gives Definition 2.3 verbatim.

  • CSLib candidates: CoverSystem.scenario_authValid_pa, the cover lemma for partial authentication (Model.lean).
