import Cslib.Computability.Distributed.Byzantine.LockStep.Parallel import Cslib.Computability.Distributed.Byzantine.Specs import Mathlib /-! # The partially authenticated setting (Lenzen–Loss–Shi–Wagner, PODC 2026) We use CSLib's synchronous lock-step Byzantine model (`Cslib.Byzantine.LockStep`) on the complete network `⊤`, with ideal signatures given by abstract tokens (`Auth`). The *partially authenticated* setting with registered parties `Reg` is the restriction that **only registered parties can sign**: every token that occurs in a message has a registered signer (`RegisteredSigners`). Unregistered parties may still put arbitrary data into messages, but anybody (in particular the adversary) can produce such data, so it carries no authentication. * `SolvablePA Reg Z spec`: some unforging protocol whose tokens all have registered signers solves `spec` against every unforgeability-respecting adversary corrupting a set in `Z`. * `Gradecast snd`: Definition 2.3 of the paper (termination, validity, graded consistency), the shared binary gradecast `Cslib.Byzantine.Problem.BinaryGradecast`; `gradecast_iff`. * `CoverSystem.scenario_authValid_pa`: the FLM covering adversary respects unforgeability as soon as every node listened to is an honest lift, a copy of a Byzantine party, or a copy of an *unregistered* party (unregistered parties never create tokens). -- CSLib
