Note `t ≥ ⌈s/2⌉ ∧ t ≥ ⌈n/3⌉ ⇔ s ≤ 2t ∧ n ≤ 3t`. ## The cover The parties are split into three groups `A` (label `0`), `B` (label `1`), `C` (label `2`), each of size `≤ t`, with `B`, `C` nonempty, `A` free of registered parties, and (for broadcast) the sender in `A` (`exists_lab`). The covering system lives on `P × Bool` (`φ = Prod.fst`) and uses only the copies `A₀ = A × {false}`, `A₁ = A × {true}`, `B₀`, `C₀`, arranged on the line `A₀ — B₀ — C₀ — A₁` (`A₀` and `A₁` are complete inside themselves; a node listens to nobody for the missing edges, e.g. `A₀` does not hear `C`, `A₁` does not hear `B`). Inputs: `A₀`, `B₀` get `v₀`; `C₀`, `A₁` get `v₁`. * Byzantine `C`, honest `A₀ ∪ B₀`: all honest inputs `v₀` (sender included), so `B₀` decides `v₀`. * Byzantine `B`, honest `A₁ ∪ C₀`: all honest inputs `v₁`, so `C₀` decides `v₁`. * Byzantine `A`, honest `B₀ ∪ C₀`: agreement between `B` and `C` is violated. The covering adversaries respect unforgeability: every node listened to is an honest lift, a copy of a Byzantine party, or a copy of an `A`-party, which is unregistered and hence never signs (`CoverSystem.scenario_authValid_pa`). Registered parties occur only in `B ∪ C`, each with a single copy, which is why `s ≤ 2t` is the relevant bound. ## Degenerate cases Without a lower bound on `n`, both statements fail for tiny `n`: for `n = 2` broadcast is trivially solvable (`bb_solvable_card_two`, `theorem41_false_card_two`), and for `n = 1` agreement is (`ba_solvable_card_one`, `corollary42_false_card_one`). -/ namespace PartialAuthBC open Cslib.Byzantine.LockStep namespace LowerBound variable {P V : Type*} /-! ### The partition into three groups -/ /-- Splitting the parties into groups `0` (unregistered, containing `S0`), `1`, `2`, each of size `≤ t`, groups `1` and `2` nonempty. -/ lemma exists_lab [Fintype P] {Reg : Set P} {t : ℕ} (S0 : Finset P) (hS0 : ∀ p ∈ S0, p ∉ Reg) (hs : Reg.ncard ≤ 2 * t) (hn : Fintype.card P ≤ 3 * t) (ht : S0.card ≤ t) (h2 : 2 + S0.card ≤ Fintype.card P) : ∃ lab : P → Fin 3, (∀ p, lab p = 0 → p ∉ Reg) ∧ (∀ z, {p | lab p = z}.ncard ≤ t) ∧ (∃ b, lab b = 1) ∧ (∃ c, lab c = 2) ∧ ∀ p ∈ S0, lab p = 0 := by classical set n := Fintype.card P with hn_def set k := max (max Reg.ncard (n -
