Here we discharge all of these assumptions for the concrete LOCAL model of Section 3 (`concreteModel Δ c k` in `Concrete.lean`), so that only the genuinely problem-specific hypotheses remain (computable locality `T`, computable `f`, computable validity check). * `PNet` is `Primcodable` (as a tuple), well-formedness is a primitive recursive predicate (`PNet.wfb`, `PNet.primrecPred_WF`), hence `Net Δ c k` is `Primcodable` (subtype). * Views are coded injectively by natural numbers (`VTree.code`, `VTree.code_injective`); `concreteModelN Δ c k` is the concrete model with coded views, distinguishing exactly the same views (`concreteModelN_view_eq_iff`, `critical_code_iff`), and with the same solvable problems for arbitrary algorithms (`exists_solves_iff`, `exists_solvesWith_iff`). * Views are computed by dynamic programming over the radius (`PNet.viewCode`, primitive recursive), giving `computable_size` and `computable_view`. * `netsN Δ c k N` enumerates all well-formed networks with at most `N` nodes (`mem_netsN`, `primrec_netsN`), by brute force over raw networks followed by a well-formedness filter. * End-to-end corollaries: `concrete_classII`, `concrete_uncomputable_iff_computable`, `concrete_classIII`, `concrete_critical_decidable`, `concrete_critical_decidable'`.
