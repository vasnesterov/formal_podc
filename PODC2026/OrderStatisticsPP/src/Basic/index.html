A dynamics is a finite Markov chain `T` on configurations (a row-stochastic matrix, see `Cslib.Probability.Markov`). The *fixation probability* of `x` from `c` is `lim_{t → ∞} (T ^ t) c (const x)` (consensus configurations are absorbing, so this is the probability that the process is eventually forever in consensus on `x`). Instead of the paper's rank-ancestry process (Lemmas 4.2–4.5, 4.7) we use a *threshold* argument: for every lower set `D` of opinions, the number `cnt D c` of agents whose opinion lies in `D` performs a birth–death walk, and `cumul π (cnt D c) = ∑_{k ≤ cnt D c} π k` is a harmonic function as soon as the up- and down-probabilities are balanced by `π` (`harmonic_of_balance`).
