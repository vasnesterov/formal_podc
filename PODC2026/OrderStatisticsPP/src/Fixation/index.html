lower set `D` the function `c ↦ cumul π (cnt D c)` is harmonic, then the probability of fixation on `x` is `∑ π k` over the ranks `k` of `x` (`#{u | c u < x} < k ≤ #{u | c u ≤ x}`). * decreases]`, `m = cnt D c`. * `reach_const_of_step`: consensus is reachable if a non-maximal agent can always adopt the maximum with positive probability. -/ set_option linter.unusedSectionVars false
