import Papers.PODC2026.SinklessOrientation.Basic /-! # Theorem 2.1: a `k`-sinksparse orientation from the smallest identifier within distance `k` Every node `v` learns `m_v`, the smallest identifier in its inclusive distance-`k` neighbourhood (`minId`), and its distance `d_v` to the node with that identifier (`minDist`; that node is `leader`). An edge `uv` is oriented towards the endpoint with the smaller key `(m, d, ID)` (lexicographically, `keyLt`). This is `minIdOrientation`. ## Main results * `minIdOrientation_not_isSink`: a node `v` with `ID_v ≠ m_v` is not a sink. * `minIdOrientation_isSinkSparse` (**Theorem 2.1**, correctness): the orientation is `k`-sinksparse — distinct sinks are at distance `> k`. No finiteness is needed. * `minIdOrientation_isLocal` (**Theorem 2.1**, locality): the orientation of an edge `uv` only depends on the radius-`(k+1)` view of `u`, i.e. it is computed in `k + 1` LOCAL rounds. The explicit `k`-round flooding algorithm (with `O(log n)`-bit states, i.e. CONGEST broadcast) is in `MinIdRun.lean`. -/ namespace SinklessOrientation open SimpleGraph open Cslib.Local (GAgree)
