At the end of the `k` rounds, each node knows the smallest identifier in its inclusive distance-`k` neighborhood. It also knows its distance to that node, which is simply the round in which it learned the identifier." We implement this as a CSLib locally-iterative algorithm (`Cslib.LocallyIterative.Algorithm`): the state of a node is `(ID, m, d)` (own identifier, smallest identifier known so far, round in which it was learned). In every round a node only uses the *set* of its neighbours' states, so the algorithm is a broadcast algorithm. ## Main results * `minId_succ`: `m_{t+1}(v) = min (m_t(v), min_{w ∈ N(v)} m_t(w))`. * `floodAlg_run`: after `t` rounds, node `v` is in state `(ID_v, m_v, d_v)` for radius `t`. * `floodAlg_orientation`, `theorem_2_1` (**Theorem 2.1**): after `k` rounds, the orientation `minIdOrientation` of an edge is obtained by comparing the final states of its endpoints (one more exchange), and it is `k`-sinksparse.
