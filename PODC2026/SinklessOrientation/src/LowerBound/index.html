import Papers.PODC2026.SinklessOrientation.Basic /-! # Tightness of Theorem 2.1: a lower bound for sinksparse orientations After Theorem 2.1 (a `k`-sinksparse orientation in `O(k)` rounds), Nolin remarks that this is "obviously tight, even in LOCAL", by a standard indistinguishability argument. We formalize it: * `sinkSparse_lower_bound`: every `T`-round LOCAL orientation algorithm with `2 * T + 2 ≤ k` fails to be `k`-sinksparse on some path with `k + 1` nodes (plus isolated nodes), provided there are at least `2 * T + 2 + 3 * k` node identifiers. * `sinkSparse_rounds_ge`: hence an algorithm that is `k`-sinksparse on all graphs needs `T > (k - 2) / 2` rounds (`k < 2 * T + 2`). ## Proof In a path on `k + 1` nodes all distances are `≤ k`, so a `k`-sinksparse orientation has at most one sink; an interior *source* (both incident edges outgoing) would produce two sinks, one on each side. Let `a₀, …, a_{2T+1}` be fixed identifiers. We consider the sequence of positions `a₀ … a_{2T+1} | k fillers | a_{2T+1} … a₀ | k fillers | a₀ … a_{2T+1} | k fillers` (`seq`), and the paths `win S k j` through the positions `j, …, j + k` (*windows*); repeated identifiers are more than `k` positions apart, so every window is a genuine path. By locality the orientation of the edge between positions `p` and `p + 1` is the same in all windows containing `[p - T, p + T]`; call it `dirAt p` ("points right"). The absence of sources forces `dirAt` to be antitone. But the edge `a_T a_{T+1}` is seen identically (radius `T` around `a_T`) in the three blocks, so it points right in blocks 1 and 3 iff it points left in block 2 — contradicting antitonicity. -/
