Colors live in an arbitrary type `Col` with decidable equality; labels (bras, kets) in `Fin k`. An agent stores its initial color `ic`, a leader bit `ld`, an ordering state `os ∈ {U, I, CL, CLW}`, a braket `⟨bra|ket⟩` and an output color `out`. Initially `ld = 1`, `os = U`, `⟨0|0⟩`, `out = ic`. ## Interpretation of the transition function (initiator `a`, responder `b`) *Re-initializing* `a` for a label `l` sets `⟨l|l⟩`, `os = U`, `out = ic` (`reinit`). `a` is *pending* if `os_a = CL`, *unstable* if `os_a ∈ {I, CLW}`, *consistent* if `bra = ket`. The steps are applied in sequence: 1. (`step1`) If `a`, `b` are leaders of the same color, `a` stops being a leader. Then, if `b` is the leader of `a` (same color, `b` leader, `a` not), `bra_a ≠ bra_b` and `a` is not pending, `os_a := CLW`. Then, if `a`, `b` are leaders of different colors with the same bra and `os_b = U`, `os_a := I`. (`step1_eq_seq` shows that our closed form is this sequential reading.) 2. (`step2`) If `a` or `b` is pending (after step 1): if `a` is pending, `b` is a leader and they have the same color, `a` re-initializes for `bra_b`. *Pending agents do not take part in the other steps*: the interaction ends here. 3. If `a` is unstable and inconsistent and `ket_b = bra_a`, `a` and `b` exchange their kets. 4. If `a` is unstable and consistent: if `os_a = I`, `a` re-initializes for `bra_a + 1 mod k`; if `os_a = CLW`, `os_a := CL`. (Steps 3, 4: `step34`.) If `a` became pending, the interaction ends here (pending agents do not take part in Circles). 5. (`step5`) Circles: the agents exchange kets iff profitable; then, if exactly one of the two brakets is diagonal `⟨i|i⟩`, both agents set `out` to the *initial color* of that agent. The output of an agent is `out`. ## Results * `ordCircles_ordering` (**Lemma 8.13**) and `ordCircles_correct` (**Theorem 5.2**): with at most `k` colors, under weak fairness for *ordered* pairs (`Execution.OrderedFair`), eventually all agents are in ordering state `U`, two agents have the same bra iff they have the same color, and, if a unique majority color `μ` exists, all agents output `μ` forever. * `ordCirclesSymm_correct`: the symmetrized protocol under (unordered) weak fairness. * `ordCircles_not_weaklyFair`: Theorem 5.2 fails under weak fairness for unordered pairs. *
