import Papers.PODC2026.RankingOpinions.Dynamics import Mathlib.Tactic.Ring /-! # The Ranking protocol (Section 6): states, rules, basic invariants Breitkopf, Dallot, El-Hayek, Schmid, *Ranking Opinions with Few States in Population Protocols*, PODC 2026 (arXiv:2605.18707), Section 6. A state is `⟨i, 𝔦 | 𝔧, j⟩` plus a token bit: bra color `i = bc`, bra ranking `𝔦 = br`, ket ranking `𝔧 = kr`, ket color `j = kc`, token `tok` (the token "for color `j`" sits on the ket `|𝔧, j⟩`). So there are `2 · k⁴` states. ## Interpretation of the rules * "If multiple cases apply, select the first case that does not leave the agents unchanged": the cases are the bullets of rules (2)–(7), in order. A case "`X` meets `Y`" is tried with `(X, Y) = (initiator, responder)` and then with `(X, Y) = (responder, initiator)`; the first (case, orientation) that changes something is applied. * Rankings are incremented modulo `k` (rule (3)). * **Fix (self-synchronisation).** After every interaction, an agent holding the token for its own bra color (`tok ∧ bc = kc`) copies its ket ranking into its bra ranking (`br := kr`). Without this the protocol is wrong: the token holder cannot "broadcast" (rule (4)) the new ranking to its own bra, see `RankingCounterexample.lean`. -/ set_option linter.unusedSectionVars false first bullet: `⟨i,𝔦|𝔧,j⟩*` meets `⟨u,𝔲|𝔧',j⟩` (no token): `𝔧' ← 𝔧`. -/ def r4a : Rule k := fun X Y => if X.tok ∧ Y.tok = false ∧ X.kc = Y.kc then (X, {Y with kr := X.kr}) else (X, Y) /-- Rule (4), X Y => if X.tok = false ∧ X.bc = X.kc ∧ X.br = X.kr ∧ Y.tok ∧ Y.kc = X.kc ∧ Y.kr = X.kr then ({X with tok := true}, {Y with tok := false}) else (X, Y) /-- Rule (6), second bullet: `⟨j,𝔧|𝔦,i⟩` meets `⟨ℓ,𝔩|𝔦,i⟩*` with `j ≠ i`, `ℓ ≠ i`, `𝔧 < 𝔩`: the token moves to the former. -/ def r6b : Rule k := fun X Y => if X.tok = false ∧ Y.tok ∧ X.kc = Y.kc ∧ X.kr = Y.kr ∧ X.bc ≠ X.kc ∧ Y.bc ≠ Y.kc ∧ X.br < Y.br then ({X with tok := true}, {Y with tok := false}) else (X, Y) /-- Rule (7), first bullet: `⟨i,𝔦|𝔦,i⟩*` meets `⟨u,𝔲|0,v⟩*` with `v ≠ i`, `𝔦 ≠ 0`: the former becomes `⟨i,0|0,i⟩*`, the latter `⟨u,𝔲|𝔦,v⟩*`. -/ def r7a : Rule k := fun X Y => if X.tok ∧ Y.tok ∧ X.bc = X.kc ∧ X.br = X.kr ∧ Y.kr = 0 ∧ Y.kc ≠ X.bc ∧ X.br ≠ 0 then ({X with br := 0, kr := 0}, {Y with kr := X.br}) else (X, Y) /-- Rule (7), second bullet: `⟨i,𝔦|𝔧,j⟩*` meets `⟨i,𝔦|𝔩,ℓ⟩*` with `j, ℓ ≠ i`: they exchange their ket rankings. -/ def r7b : Rule k := fun X Y => if X.tok ∧ Y.tok ∧ X.bc = Y.bc ∧ X.br = Y.br ∧ X.kc ≠ X.bc ∧ Y.kc ≠ Y.bc then ({X with kr := Y.kr}, {Y with kr := X.kr}) else (X, Y) /-- The cases of rules (2)–(7), in order. -/ def rules : List (Rule k) := [r2, r3, r4a, r4b, r5, r6a, r6b, r7a, r7b] end
