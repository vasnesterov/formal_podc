(tie detection) an agent `⟨i|i⟩` that decays into `⟨i|j⟩`, `i ≠ j`, goes to `tie_spreader`; 2. (tie spreading) an agent at `tie_spreader` sets to `tie` any encountered agent `⟨i|j⟩`, `i ≠ j`; 3. (tie correction) an agent `⟨i|i⟩` sets any encountered agent to `no_tie`. Output: `out` if at `no_tie`, "tie" otherwise.
