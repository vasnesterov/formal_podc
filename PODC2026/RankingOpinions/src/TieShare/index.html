On top of the braket part of Circles (rule (1): ket exchange; Circles' own `out` rule (2) is dropped), every agent stores an output color `out` and a `status ∈ {winner_spreader, winner, loser}` (initially `winner`). After the ket exchange, the status rules (1)–(7) and the output rules (i), (ii) of the paper are applied *in this order*, each rule in both orientations `(a, b)` then `(b, a)`; all brakets are the ones after the ket exchange. Interpretation choices (the paper is informal on these points): * modulo range: `[x, y]_k = {x, x+1, …, x + ((y - x) mod k)}` (so `[i, i]_k = {i}`), i.e. `z ∈ [x, y]_k ↔ (z - x) mod k ≤ (y - x) mod k` (`inRng`); * `[x, y]_k ⊆ [x', y']_k` is set inclusion plus the paper's extra condition `x ≠ y' ∨ y ≠ x'` (`RSub`); `⊊` is `⊆` together with "the two sets differ" (`RSSub`); * the conditions of the rules read the *current* statuses, already updated by the previous rules of the same interaction (`pre = false`, the "sequential reading"). With `pre = true` all conditions of rules (4)–(7) and (ii) read the statuses *before* the interaction; for this reading Theorem 4.2 is false (`tieShare_pre_counterexample`); * output map: an agent at `winner_spreader`/`winner` outputs its own color (its bra), a `loser` outputs its `out` variable (`tsOut`).
