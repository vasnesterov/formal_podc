The proof of Lemma 6.3 (Case 2) concludes `τ_shaded > W_{r-1}(m, z)` from `score(m) < τ_shaded`, forgetting that Byzantine replicas also contribute to `W(m, z)`. Instance: `n = 7` replicas, `f = 2` (replicas `5, 6` Byzantine), `γ = 1` (`n = 7 > (2γ+1)f/(2γ−1) = 6`), so `τ_dec = τ_shaded = 5/2`, `τ_solid = 5`. Two transactions `z = 0`, `m = 1`. * Honest replicas `0, 1` receive `m, z`; honest replicas `2, 3, 4` receive `z, m`. * Round 1: replicas `0, 1` commit `[m, z]`, replicas `2, 3, 4` commit `[z]`, the Byzantine replicas commit `[m, z]`. Then `score(z) = 5` (solid), `score(m) = 2` (blank), and `W₁(m, z) = 4 > W₁(z, m) = 3 ≥ τ_dec`, so the pair is decided: `cmp_T(z, m) = False`. FEAT inserts `z` alone: `FO₁ = [z]`. * Round 2: replicas `2, 3, 4` commit `m`; `score(m) = 5`, `m` is newly solid, `RO₂ = [m]`, and FEAT finalizes `FO₂ = [z, m]`. FEAT never compares `z` with `m`, yet `cmp_T(z, m) = False`: `FO₂` violates Adjacent-Comparator Consistency (Theorem 6.4), the boundary pair `(z, m)` violates Lemma 6.3, and `FO₂` is not comparator-based γ-Batch-Order-Fair (Theorem 6.6): `{z}` and `{m}` are different batches but `z` is output first although `cmp_T(z, m) = False`. (The γ-precedence clause is not violated: no pair is received in the same order by all honest replicas.)
