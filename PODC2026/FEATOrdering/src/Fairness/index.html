import Mathlib.Data.List.SplitBy import Mathlib.Logic.Relation /-! # Comparator-based γ-Batch-Order-Fairness (§4.2–4.3 of the FEAT paper) Dinh, Kang, Sadoghi. *FEAT: Fair and Efficient Adversarial Transaction Ordering.* PODC 2026. A *comparator* is a Boolean function `c : α → α → Bool`; `c a b = true` means "fairness requires `a` before `b`". It is a *tournament* on a set `T` if for distinct `a, b ∈ T` exactly one of `c a b`, `c b a` is `true` (we only need "at least one", `Total`). A final ordering is a list `FO`; the transaction set is the set of its elements. Batches are the strongly connected components of the comparator graph restricted to the elements of `FO`. * `AdjConsistent c FO` — Definition 4.3 (Adjacent-Comparator Consistency). * `GammaInduced c G FO` — Definition 4.2, for an abstract "γ-fraction of honest replicas receive `a` before `b`" relation `G` (instantiated concretely in `FEAT.lean`). * `BatchOrderFair c G FO` — Definition 4.1 (comparator-based γ-Batch-Order-Fairness). * `theorem_4_4` — Theorem 4.4: ACC + γ-induced ⇒ comparator-based γ-Batch-Order-Fairness. -/ namespace Podc.FEATOrdering open scoped List variable {α : Type*} /-- **Definition 4.3 (Adjacent-Comparator Consistency).** Every pair of adjacent transactions of `FO` is ordered as the comparator requires. -/ def AdjConsistent (c : α → α → Bool) (FO : List α) : Prop := FO.IsChain (fun a b => c a b = true) /-- The comparator is a tournament on the elements of `FO`: for distinct `a, b`, at least one of `c a b`, `c b a` holds (the paper also requires at most one, which we never need). -/ def Total (c : α → α → Bool) (FO : List α) : Prop := ∀ a ∈ FO, ∀ b ∈ FO, a ≠ b → c a b = true ∨ c b a = true /-- The edge `a → b` (`cmp(a, b) = True`) of the γ-Batch-Order-Fairness).** `FO` is the concatenation of non-empty contiguous blocks `B₁, …, B_k`, each of which is exactly a batch (an `∼`-class of the transactions of `FO`), such that 1. (*linear batch partition*) for `i < j`, `T ∈ Bᵢ`, `T' ∈ Bⱼ`: `cmp(T, T') = True`; 2. (*γ-precedence respect*) if `G T T'` then `batch(T) ≤ batch(T')`, i.e. never `T ∈ Bⱼ`, `T' ∈ Bᵢ` with `i < j`. -/ def BatchOrderFair (c : α → α → Bool) (G : α → α → Prop) (FO : List α) : Prop := ∃ B :
