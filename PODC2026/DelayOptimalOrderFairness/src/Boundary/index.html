The paper's construction, made exact for a finite number of nodes. Nodes are `Fin n`, the first `hc` of them honest. With `d = Δ/k` and a cycle of `m = (k+1)(n+1)` transactions `0 → 1 → ⋯ → m-1 → 0`: * honest node `i` stamps transaction `j` at `((j + i) mod (k+1)) · d` (offsets `0, d, …, k d = Δ` rotating with period `k + 1`: on each edge all honest groups but one move forward by `d ≥ θ`); * Byzantine node `i` stamps `j` at `((j + m - 1 - i) mod m) · d`: it supports every edge except `i → i+1`, so each edge loses at most one Byzantine supporter. Hence every edge has at least `n - ⌈hc/(k+1)⌉ - 1` supporters (`theorem_5_2_finite`). As `n → ∞` with honest fraction `h` this exceeds `φ n` for every `φ < 1 - h/(k+1)` (`theorem_5_2`). For a fixed `n` the statement can fail (`theorem_5_2_fixed_n_false` in `Feasible.lean`).
