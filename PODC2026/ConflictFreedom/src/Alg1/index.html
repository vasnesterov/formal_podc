Algorithm 1 is written as a CSLib implementation `Alg1.impl A n : Impl A (Alg1.base A n) (Fin n) (Alg1.Loc A n)` of an arbitrary sequential object `A` for `n` processes. The GCA objects `GCA_r` (`r ≥ 1`) are *flattened*: each is Algorithm 2 run on its own pair of atomic snapshot objects `Obj.A r`, `Obj.B r` (CSLib has no composition theorem, so we inline the implementation); `Obj.S j` are the atomic registers `S[j]` (initially `(0, ε)`). * Commands are triples `(op, i, seq)` (`Cmd A n`); two commands conflict iff their operations do (`CmdConflict`), which is the conflict relation of the object `A_c` of the paper. * Traces are Mazurkiewicz traces of duplicate-free command schedules (`Tr A n`), the GCA domain. * Local state `Loc`: the phase (`idle`; `readS j best` = reading `S[j]` at line 5, `best` being the pair with the largest round read so far; `gca g` = executing `GCA_r.propose` with local state `g` of Algorithm 2, `r` the current round; `writeS` = line 13; `done` = line 14), the local variables `seq`, `cmd`, `r`, `s` of the paper, and *ghost* variables that never influence the behaviour: `hist` (the final local GCA states of the rounds the process has completed), `cr` (the commit round of each operation). * Line 5 reads the `n` registers one at a time (a collect, not a snapshot). * `ret*(cmd, s)` is `retT s cmd`: the response of `cmd` in the execution of a representative of `s` from the initial state (well defined by Lemma 4.1). -/ namespace Podc.ConflictFreedom open Cslib.SharedMemory Cslib.Mazurkiewicz Classical namespace Alg1 variable (A : ObjSpec) (n : ℕ) /-- Commands `(op, i, seq)`. -/ abbrev Cmd : Type := A.Op × Fin n × ℕ /-- The sequential specification `A_c` on commands: a command executes its operation. -/ def cmdδ (q : A.State) (c : Cmd A n) : A.State × A.Resp := A.δ q c.1 /-- The conflict relation on commands, inherited from the operations. -/ def CmdConflict : Cmd A n → Cmd A n → Prop := Conflict (cmdδ A n) instance : Std.Symm (CmdConflict A n) := inferInstanceAs (Std.Symm (Conflict (cmdδ A n))) /-- Traces of duplicate-free command schedules. -/ abbrev Tr : Type := NTrace (CmdConflict A n) variable {A n} lemma cmdConflict_iff (c c' : Cmd A n) : CmdConflict A n c c' ↔ A.Conflicting c.1 c'.1 := Iff.rfl variable (A n) /-- Operations of an `n`-component atomic snapshot object over `V`. -/ inductive SnapOp (V : Type) where | upd (i : Fin n) (v : V) | snap /-- An `n`-component atomic snapshot object over `V` (components initially `⊥ = none`);
