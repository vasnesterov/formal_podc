import Mathlib import Cslib.Foundations.Data.Finset.Quorum import Cslib.Computability.Distributed.Byzantine.Specs /-! # Algorithm 4 of [AFW26]: connected consensus from gather (and approximate agreement) Formalization of Sections 4.2 and 5 of > H. Attiya, I. Flam, J. L. Welch. *Why Canonical-Round Algorithms Fail for Optimal Byzantine > Resilience.* PODC 2026. This is the *positive* side of the paper: Algorithm 4 solves `R`-connected consensus for `n > 3f` using a gather subroutine `G` and (for `R ≥ 2`) an approximate agreement subroutine `AA` with `ε = 1`, and it preserves the binding property of gather. ## Modelling * The subroutines are **black boxes given by their specifications**: an execution of Algorithm 4 is abstracted to the family of all local variables of all processes (`Run`): the inputs `x`, the outputs `S` of the first gather (line 1), the branch `v₁` of line 2, the outputs `T` of the second gather (line 4), the branch `v₂` of line 5, the AA input `r` (line 6) and the AA output `y` (line 7). A run is *admissible* (`Phase1`, `Phase2`) when the gather outputs satisfy `GatherSpec`, the AA outputs satisfy `AASpec`, and the local variables are computed according to lines 2, 5, 6. The decisions are then a function of the run (`decision`, lines 3 and 8). * "if some `v ∈ V` appears `θ` times in `S` then `vᵢ ← v` else `vᵢ ← ⊥`" is modelled as a **relation** (`Line2`, `Line5`) admitting *every* choice of `v` the code allows (no choice function). "appears `θ` times" is read as "at least `θ` times". `⊥` is `none : Option V`. * Processes `P` form a finite type, `n = Fintype.card P`; the Byzantine processes form a set `F` with `F.card ≤ f`. Nothing is assumed about the local variables of faulty processes. * Grades are integers (`ℤ`), `gᵢ = ⌈yᵢ⌉` (`Int.ceil`); we prove `0 ≤ gᵢ ≤ R`. * **Termination** is not modelled: Algorithm 4 consists of (at most) three subroutine calls and local computation, so it terminates whenever the subroutines do (as the paper says in Theorems 14 and 18). Only the safety properties (agreement, validity, decisions in `D`) are proved. * **Binding** (Theorem 19): the execution prefix `α` ending when the first correct process returns from the first gather is abstracted by the common core `SC` of the first gather that the binding property of gather fixes at the end of `α`; an "extension" of `α` is any admissible run whose first-gather outputs (of correct processes) all contain `SC`. We prove that the non-`⊥` branch of every correct decision in every extension is one value `v*` determined by `SC` alone. ## Notes on the paper (see `differencies.md`) * Gather agreement must also hold for `i = j` (equivalently, a correct process's output contains at most one pair per process id). This is used (only) in validity (ii) ("all elements of `Sᵢ` for correct processes, of which there are at least `|Sᵢ| - f`").
