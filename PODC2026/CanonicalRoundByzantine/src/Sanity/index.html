import Cslib.Computability.Distributed.Byzantine.CanonicalRounds.Liveness import Papers.PODC2026.CanonicalRoundByzantine.Problems import Cslib.Foundations.Data.Finset.Quorum /-! # Non-vacuity: one-round crusader agreement for `n > 5f` [AFW26] H. Attiya, I. Flam, J. L. Welch. *Why Canonical-Round Algorithms Fail for Optimal Byzantine Resilience.* PODC 2026. The paper shows that for `3f < n ≤ 5f` no canonical-round algorithm solves a nontrivial convergence problem (e.g. crusader agreement) with a bounded number of rounds (Theorems 1 and 7), and remarks (abstract, Section 6) that bounded canonical-round algorithms *do* exist for `n > 5f`. This file checks that remark in our model (`Cslib.Byzantine.CanonicalRounds`), which guards the impossibility results against being vacuously true there (e.g. because of an over-restrictive notion of admissibility or of round complexity), and shows that the resilience threshold `5f` of Theorems 1/7 is sharp for crusader agreement. `caAlg n f` is a deterministic, communication-closed, one-round canonical-round algorithm: every process sends its input in round 1; once the communication-closed view of its history contains round-1 messages from `n - f` senders, it decides `(w, 1)` if some value `w` was received (in round-1 messages) from at least `n - 2f` senders, and `(⊥, 0)` otherwise. * `caAlg_commClosed`: it is communication-closed (Section 3.2). * `caAlg_safe`: for `n > 5f` it is safe for crusader agreement (`connectedConsensusSpec 1`). Agreement uses exactly `n > 5f`: two different non-`⊥` decisions would need `2(n - 2f - |F|)` correct processes among `n - |F|`. * `caAlg_allDecideBy`, `caAlg_rounds`, `caAlg_expRounds`: in every admissible execution every correct process decides in its round `1` (for every `n`, `f`), so the (expected) round complexity is at most `1` for every adversary and every tape distribution. * `rrAdv_admissible` (in `Cslib/Computability/Distributed/Byzantine/CanonicalRounds/Liveness.lean`) provides admissible adversaries for any faulty set of size `≤ f`, so these statements are not vacuous; `caAlg_allDecide_rrAdv`. * `exists_bounded_crusader`: the summary statement contrasting Theorems 1/7. Design choice: a value `w` is counted for a sender `q` if *some* round-1 message of `q` in the view carries `w` (`valSenders`); a Byzantine sender may thus be counted for several values, which does
