Algorithm 3 is only correct for `n > 4f` (Theorem 9), so this proof covers only `4f < n ≤ 5f`. The statement is nevertheless true, for **every** `n > f ≥ 1`, by a direct argument already hinted at in the introduction of the paper: in canonical rounds the adversary can let every process hear `n - f` processes other than the (correct) sender in each of the first `K` rounds. Then no other process has any information about the sender's input by round `K`, but validity forces it to accept that input.
