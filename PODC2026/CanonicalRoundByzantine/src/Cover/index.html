import Cslib.Computability.Distributed.Byzantine.CanonicalRounds.Schedule import Papers.PODC2026.CanonicalRoundByzantine.Problems /-! # The executions `α₀`, `α₁`, `α₂` of Theorem 1 of [AFW26] The processes are split into five groups `A, B, C, D, E` (`Groups`): `|B| = |D| = f` and `|A|, |C|, |E| ≤ f` (this handles every `2f ≤ n ≤ 5f`; the paper assumes `n = 5f` "for simplicity"). * `α₂` (configuration `C₂`): `E` Byzantine; `B, C` have input `x₀` and hear `A B C E`; `A, D` have input `x₁` and hear `A C D E`; `E` pretends to `B C` to be correct in `α₀` and to `A D` to be correct in `α₁` (two-faced). * `α₀` (configuration `C₀`): `A` Byzantine, behaving towards everybody as in `α₂`; `B C D E` correct with input `x₀`, all hearing `A B C E` (the messages of `D` are late). * `α₁` (configuration `C₁`): `C` Byzantine, behaving as in `α₂`; `A B D E` correct with input `x₁`, all hearing `A C D E` (the messages of `B` are late). All three are described by one *cover*: a round-level system with two copies of `E` (`cov τ r b p`: history after round `r` of process `p` in copy `b`; copy `false` hosts `B, C, E₀`, copy `true` hosts `A, D, E₁`). Lemmas `clean₂_eq`, `clean₀_eq`, `clean₁_eq` are the paper's Lemmas 3 and 4 (and their analogue for `α₂`): the round-level histories of the correct processes coincide with the cover histories.
