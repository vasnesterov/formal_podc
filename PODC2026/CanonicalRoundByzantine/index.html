Canonical-round algorithms and optimal Byzantine resilience — PODC 2026

Hagit Attiya, Itay Flam, Jennifer L. Welch. Why Canonical-Round Algorithms Fail for Optimal Byzantine Resilience. PODC 2026. DOI 10.1145/3796701.3815948. Formalized version: the PODC proceedings version; all theorem numbers below follow it. The full version, arXiv 2510.04310 (v2, titled Why Canonical Rounds Fail for Optimal Byzantine Resilience), numbers the results differently. Copy of the paper: paper.pdf.

Verdict: 🛠️ Hard fix. The lower bounds (Theorems 1 and 7, Corollaries 6 and 8, and their Section 3.3 and Corollary 15 consequences) are proved, for the whole range 2f ≤ n ≤ 5f rather than only n = 5f, and the positive results of Section 5 are proved. The paper's proof of the broadcast impossibility (Corollary 10) covers only 4f < n ≤ 5f, and saving the claim took a new, direct adversary argument.

Mistakes in the paper

🔧 Abstract ("sharp boundary at 5f" for broadcast)

Right after naming reliable broadcast and gather, the abstract says bounded canonical-round algorithms "for these problems exist when n > 5f", but for broadcast none exists for any n > f ≥ 1 (corollary10).

Impact. The boundary at 5f is irrelevant for broadcast. The paper never claims or uses a bounded broadcast algorithm for n > 5f.

Repair

Restrict "these problems" to the convergence problems that Section 6 names. For crusader agreement the boundary is proved: a one-round algorithm exists for n > 5f (exists_bounded_crusader). For the other problems the n > 5f algorithms are cited.

✏️ Slips

  • Read literally, "n ≤ 5f" in Theorems 1 and 7 and Corollaries 6, 8, 10 and 15 includes n = 1, f = 1, where the single process decides its input in round 0, so Theorem 1 and Corollary 6 fail (literal_theorem1_fails_n1). The paper's setting is 3f < n ≤ 5f, and our proof needs only 2f ≤ n.

Typos

  • The introduction defines communication closure as discarding early and late messages, while Section 3.2 discards only late ones; we follow Section 3.2.

Proof gaps in true statements (1)Corollary 10

🛠️ Corollary 10 (broadcast; the proof covers only 4f < n ≤ 5f)

The proof goes through Algorithm 3 (crusader agreement from n consistent broadcasts), which is correct only for n > 4f, so it says nothing about 3f < n ≤ 4f.

Impact. Statement true for every n > f ≥ 1 by a direct argument (corollary10, corollary10_commClosed).

Details

Corollary 10 claims that reliable/consistent broadcast has unbounded round complexity for canonical-round algorithms with n ≤ 5f. Algorithm 3 needs n > 4f because Theorem 9 needs two sets of n − 2f senders to intersect.

Repair

The direct argument, which the introduction hints at: in the first K rounds, let every process hear n − f processes other than the correct sender (for communication-closed algorithms, deliver the sender's messages one round late). The others then have no information about the sender's input, yet validity forces them to deliver it. (corollary10, corollary10_commClosed)

Model (CSLib, Cslib/Computability/Distributed/Byzantine/CanonicalRounds/).

  • Asynchronous message passing, n processes, reliable FIFO links, static Byzantine faulty set of size ≤ f. Byzantine processes send arbitrary messages with arbitrary round labels.

  • A canonical-round algorithm sends its round-r message to all and advances once it holds round-r messages from n − f distinct senders. Each message may be any function of the history; the paper sends the full history. A larger class of algorithms makes the impossibilities stronger. The first some of the decision function is the irrevocable decision.

  • Randomness: a tape with one random number per process and round, under an arbitrary probability measure. Deterministic algorithms correspond to a fixed tape.

  • The adversary is full-information and adaptive: a function of time and the current configuration, including all random numbers drawn so far. It is non-anticipating by construction, a subclass of the paper's adversaries, so the impossibilities are again stronger. Admissible means at most f faults, every correct process wakes up, and every link into a correct process is served infinitely often.

  • Safety is required at every prefix of every admissible execution, for every tape. Round complexity is the smallest round by which all correct processes decide; the expected value is the integral over the tape measure.

  • Communication-closed (CommClosed): messages and decisions factor through a view that drops late messages.

  • The adversary of Theorems 1 and 7 works tape by tape: it forces round complexity > K (resp. non-termination) for every tape, not just in expectation.

Proof remarks. In the proceedings version, Theorem 7's proof is only a sketch ("see [8]"; the arXiv full version gives it in full); it is fully formalized here. Theorem 18 uses |⌈a⌉ − ⌈b⌉| ≤ 1 for |a − b| ≤ 1 without proof, and the paper does not show that decisions lie in {1, …, R} (both proved). The proof of Theorem 14 (crusader agreement from gather, Algorithm 4) uses that an output contains at most one pair per process id, i.e. gather agreement for i = j. The paper's agreement property ("if p_i and p_j are correct") does not exclude i = j, so it covers this step, and we require agreement for all correct i, j. If agreement is required only between distinct correct processes, validity (ii) fails: n = 4, f = 1, a correct output with two different pairs of the faulty process (Gather.validity_fails_without_self_agreement).
