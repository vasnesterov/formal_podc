A closed walk *follows* a pairing `π` if it leaves every node through the port paired with the one it entered by, including at the closing node (`Pairing.Follows`). For every dart `d` the walk `π.circuitWalk d` starts with `d` and follows `π` until it first returns to `d`. We show: * `circuitWalk d` is a circuit (a closed trail, `Walk.IsCircuit`) that follows `π`, and its edge set is the class `π.circuitEdges d`; * these classes partition the edges of `G` (`Pairing.circuits_partition`);
