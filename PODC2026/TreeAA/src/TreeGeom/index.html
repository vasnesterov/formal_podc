import Mathlib /-! # Geodesic geometry of graphs and trees * `Btw G a w b`: `w` lies on a shortest path between `a` and `b` (`d(a,w) + d(w,b) = d(a,b)`). * `hull G S`: the shortest-path convex hull of the paper (Section 2): the union of all shortest paths between pairs of vertices of `S`. * For a tree `T` (`hT : T.IsTree`): the unique path `tpath hT a b`, with `mem_tpath_iff` (its vertices are exactly the `w` with `Btw T a w b`), the "tripod" property `btw_or`, convexity of hulls (`hull_convex`) and the **gate lemma** `btw_of_isMin` (the vertex of a convex set closest to `v` lies on the path from `v` to every vertex of the set). * Root paths `rpath hT r u` (the vertex list of the path from the root `r` to `u`): prefixes, indices (`dist_rpath_getElem`), and the betweenness of their entries. CSLib candidates (generic tree geometry). -/ namespace TreeAA open SimpleGraph variable {V : Type*} /-! ### Betweenness and hulls in a graph -/ section General variable (G : SimpleGraph V) /-- `w` lies on a shortest path between `a` and `b`. -/ def Btw (a w b : V) : Prop := G.dist a w + G.dist w b = G.dist a b /-- The (shortest-path) convex hull `⟨S⟩` of a vertex set: the union of all shortest paths between pairs of vertices of `S`. -/ def hull (S : Set V) : Set V := {w | ∃ a ∈ S, ∃ b ∈ S, Btw G a w b} variable {G} lemma Btw.symm {a w b : V} (h : Btw G a w b) : Btw G b w a := by unfold Btw simp [Btw] lemma btw_right (a b : V) : Btw G a b b := by simp [Btw] lemma subset_hull (S : Set V) : S ⊆ hull G S := fun a ha => ⟨a, ha, a, ha, btw_left a a⟩ lemma hull_mono {S S' : Set V} (h : S ⊆ S')
