We implement the protocol in CSLib's lock-step model on the complete network and verify it (`bdhGradecast_solves`). Protocol `bdhGradecast t snd` (the history length is the current round number): * round 0: the sender sends its input `v` to everybody; * round 1: everybody echoes the value it received from the sender (the sender echoes `v`); * round 2: a party that saw some `w` echoed by at least `n - t` parties (counting its own echo) sends `w` ("ready"), otherwise nothing; * after round 2 (history of length 3): if some `w` has `≥ n - t` readies (counting its own), output `(w, 2)`; else if some `w` has `≥ t + 1` readies, output `(w, 1)`; else output `(x, 0)` (`x` is the own input, a dummy value). A party does not receive its own messages on `⊤`; the counts use `gcView`, which inserts the own message into the inbox. -/ namespace TreeAA open Cslib.Byzantine.LockStep section BDH variable {P :
