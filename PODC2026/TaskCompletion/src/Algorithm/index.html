Algorithm 1 proceeds in iterations; iteration `j` of the algorithm consists of a *task phase* of `2BR` rounds (line 11: node `v` completes the tasks of `U_{j,v}` one after the other, each taking `R` rounds, so it completes all of them iff it does not crash during the phase and `|U_{j,v}| ≤ 2B`) followed by one *broadcast round* (lines 12–17). We model one iteration as one step; the round count is `2BR + 1` per iteration. The (adaptive, deterministic-algorithm) crash adversary is a function of the node: `crashIter v` is the (global) iteration in which `v` crashes (`none`: never); if `v` crashes in iteration `c`, `fin v` says whether it survived the task phase of iteration `c` (so it completed its tasks and sends its bit), and `reach v` is the set of nodes that receive its broadcast bit in iteration `c` (an arbitrary subset, as in the paper's crash model: a node crashing during a round sends an arbitrary subset of its messages of that round). A node crashed in an earlier iteration does nothing. Since the algorithm is deterministic, quantifying over all such functions is the same as quantifying over all adaptive adversaries. The run starts at global iteration `s` (to compose batches, Section 4.3); `j` is the local iteration index. All nodes agree on the families `F k` (the `(k,B,ε)`-load balancing covering families of line 7, a parameter of the algorithm, existing by Lemma 3.1). * `C j v` — `C_{j,v}`, the tasks `v` knows to be complete at the start of local iteration `j`; * `Done j` — tasks *actually* completed during the first `j` iterations. We only count the tasks of `U_{j,u}` for nodes `u` that complete their whole list (an under-approximation of the completed tasks; the theorems say that all tasks are in `Done`, so this only strengthens them). * `FV j t` — `t` is *fully verified* at the start of iteration `j`; `N j` — number of tasks not fully verified (`N_j` of the paper).
