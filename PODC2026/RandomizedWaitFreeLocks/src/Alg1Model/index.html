import Papers.PODC2026.RandomizedWaitFreeLocks.Trace /-! # Algorithm 1 (constant-space randomized TryLock): the model ``` Shared: FAID C (= 0), register R, CAS object L (R, L = dummy descriptor, isDone() = True) HelpAndPromote() TryLock(D) 1 w ← L.Read() 5 b ← C.FAI() + 1 2 w.execute() 6 with probability 1/(7 b log²(b+1)) do R.Write(D) 3 d ← R.Read() 7 for i ∈ {1,2} do HelpAndPromote() 4 L.CAS(w, d) 8 if L.Read() = D then D.execute() 9 C.FAD() 10 return D.isDone() ``` **Model.** Asynchronous shared memory; one atomic step per time point; processes `P` (any number, possibly infinite); descriptors `D`, the dummy descriptor is `none : Option D` (its thunk does nothing and is never reported as an event; `isDone = true`). Every descriptor has a unique owner `own : D → P`, the only process that may call `TryLock` on it, and it may do so again only if no earlier `TryLock` on it returned `True`. * Steps are chosen by an adversary (`Act`): `invoke p δ` starts `TryLock(δ)` of an idle process `p` (this step is the `C.FAI()` of line 5, the call's first shared-memory step); `sched p` lets `p` execute its next line. Each step also receives a coin (`Bool`), used only at line 6 (`true` = write). The probability of the coin is attached in `Alg1Prob.lean`; the safety results hold for every sequence of coins. * Line 6 with coin `false` is a step without shared-memory access (the paper fuses it with the read of line 1; separating them gives the adversary more interleavings, so all our results apply to the paper's model). * `w.execute()` is two steps: its invocation (`exS w`) and its response (`exE w`), which sets the `isDone` register of `w`; the thunk's own steps touch only other memory and are omitted (any number of other steps may be interleaved between the two). * Invalid actions only advance the clock. Ghost state (does not influence the algorithm): the clock `T`, the times of the last write to `R` and of the last change of `L`, the time `eT δ` at which `δ` first became the value of `L` (`0` = never), the set `act` of processes between lines 5 and 9, `started`, `retT δ` (some `TryLock(δ)` returned `True`), `failed p k` (the `k`-th call of `p` returned `False`), and per process the times of
