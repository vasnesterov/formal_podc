import Mathlib /-! # Local propagation arguments for edge-consistent distance-2 colourings Generic part of the proof of (our repaired) Theorem 5.1 of *It does not matter how you define locally checkable labelings* (Cruciani, Das, Raevskaya, Suomela; PODC 2026). For a graph `G` and a colouring `χ`: * `IsDist2 G χ`: `χ` is injective on every closed neighbourhood (condition 1 of Theorem 5.1); * `IsCons G χ`: `χ` is (globally) edge-consistent: if `χ v' = χ v` then for every neighbour `u` of `v` some neighbour `u'` of `v'` has `χ u' = χ u`. `BlockFacts G pv p0 p1 p2 p3 p4 p5 nx` records the local structure of one A-gadget `p0, …, p5` with its outside neighbours `pv` (before `p0`) and `nx` (after `p5`). The lemmas below are the local case analyses: the colour of `pv` differs from those of `p3`, `p4` (`ne_pv_p3`, `ne_pv_p4`; this is the content of the paper's Lemma 5.2 / Figure 2), an original vertex never shares its colour with a vertex in a triangle (`ne_of_triangle`, the paper's Lemma 5.9 / Corollary 5.10), and colours propagate rigidly through a gadget (`block_step`, the induction step of the paper's Lemma 5.12 / 5.13). -/ namespace Podc.LCLDefinitions variable {α C : Type*} /-- `χ` is a distance-2 colouring: injective on every closed neighbourhood. -/ def IsDist2 (G : SimpleGraph α) (χ : α → C) : Prop := ∀ v a b, (a = v ∨ G.Adj v a) → (b = v ∨ G.Adj v b) → a ≠ b → χ a ≠ χ b /-- `χ` is edge-consistent: vertices of the same colour see the same colours around them. -/ def IsCons (G : SimpleGraph α) (χ : α → C) : Prop := ∀ v u, G.Adj v u → ∀ v', χ v' = χ v → ∃ u', G.Adj v' u' ∧ χ u' = χ u variable {G : SimpleGraph α} {χ : α → C} lemma IsDist2.ne_adj (h : IsDist2 G χ) {a b : α} (hab : G.Adj a b) : χ a ≠ χ b := h a a b (Or.inl rfl) (Or.inr hab) hab.ne lemma IsDist2.ne_common (h : IsDist2 G χ) {a b c : α} (ha : G.Adj c a) (hb : G.Adj c b) (hab : a ≠ b) : χ a ≠ χ b := h c a b (Or.inr ha) (Or.inr hb) hab lemma IsDist2.eq_of_common (h : IsDist2 G χ) {a b c : α} (ha : G.Adj c a) (hb : G.Adj c b) (he : χ a = χ b) : a = b := by by_contra hab; exact h.ne_common ha hb hab he lemma IsCons.step (h : IsCons G χ) {x y x' : α} (hxy : χ y = χ x) (hx : G.Adj x x') : ∃ y', G.Adj y y' ∧ χ y' = χ x' := h x x' hx y hxy /-- The local structure of an A-gadget `p0, …, p5` (in our numbering: path `p0 … p5` plus chords `p0 p2`, `p1 p4`, `p3 p5`) together with its outside neighbours `pv` and `nx`. -/ structure BlockFacts (G : SimpleGraph α) (pv p0 p1 p2 p3 p4 p5 nx : α) : Prop = p1 ∨ y = p3 ∨ y = p5 n5 : ∀ y, G.Adj p5 y → y = p3 ∨ y = p4 ∨ y = nx d03 : p0 ≠ p3 d04 : p0 ≠ p4 d13 : p1 ≠ p3 d24 : p2 ≠ p4 d25 : p2 ≠ p5 dv1 : pv ≠ p1 dv2 : pv ≠ p2 dn3 : nx ≠ p3 dn4 : nx ≠ p4 IsDist2 G χ) (hC : IsCons G χ) : χ p0 ≠ χ p5 := by intro h -- `p5` must see the colours of `p1` and `p2`; only `nx` is available for both obtain ⟨z, hz, hz1⟩ := hC.step h.symm bf.a01 obtain ⟨z', hz', · rfl have e2 : z' = nx := by rcases bf.n5 z' hz' with rfl | rfl | rfl · exact absurd hz2 (hD.ne_adj bf.a23.symm) · exact absurd hz2 (hD.ne_common bf.a14 bf.a12 bf.d24.symm) · rfl subst e1 e2 exact hD.ne_adj bf.a12 (hz1.symm.trans hz2) /-- The vertex before an A-gadget and its vertex `p4` get different colours (paper: an original vertex and the vertex `5` of its first gadget; Lemma 5.2, Figure hy0 · exact hD.ne_common bf.a23 bf.a02.symm bf.d03.symm hy0 · exact bf.ne_p0_p5 hD hC hy0.symm /-- The vertex before an A-gadget and its vertex `p3` get different colours. -/ lemma ne_pv_p3 (hD : bf.a14 bf.a01.symm bf.d04.symm hy0 · exact bf.ne_p0_p5 hD hC hy0.symm end BlockFacts /-- An "original" vertex `o` (every neighbour of `o` is the first vertex of an A-gadget hanging at `o`) never has the colour of a vertex in a triangle (paper: Lemma 5.9 and Corollary 5.10). -/ lemma ne_of_triangle (hD : IsDist2 G χ) (hC : IsCons G χ) {o c c1 c2 : α} (hO : ∀ y, G.Adj o y → ∃ p1 p2 p3 p4 p5 nx, obtain ⟨z, hz, hzc⟩ := hC.step ho1c h12 obtain ⟨p1, p2, p3, p4, p5, nx, bf⟩ := hO o1 ho1 rcases bf.n0 z hz with rfl | rfl | rfl · exact hD.ne_adj h2 (h.symm.trans hzc) · -- `p1` has the colour of
