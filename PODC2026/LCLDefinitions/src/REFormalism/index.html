import Papers.PODC2026.LCLDefinitions.PNView /-! # From PN-checkable problems to the RE formalism (Section 6) Formalization of Section 6 of *"It does not matter how you define locally checkable labelings"* (Cruciani, Das, Raevskaya, Suomela; PODC 2026, arXiv 2602.18188): a PN-checkable problem `D` of radius `r + 1` on 3-regular graphs is encoded as a problem `E` in the RE formalism (Definition 6.1), and solutions are lifted in both directions (Lemmas 6.2–6.4). ## Model * Graphs: simple graphs `G : SimpleGraph V` (locally finite); problem `E` is only considered on 3-regular graphs (`∀ v, G.degree v = 3`). The instances of `D` and `E` are the same graph (the paper's `G_E ≅ G_D`). * RE formalism (Section 2.2): a half-edge labelling is `λ : V → V → Λ`, where `λ v u` is the label of the half-edge at `v` on the edge `{v, u}` (values at non-edges are irrelevant). It is valid if the multiset of the half-edge labels around every node is in `C_V`, and the multiset of the two half-edge labels of every edge is in `C_E`. * PN-views are canonical labelled rooted trees (`View`, see `PNView.lean`), so `≅` is `=`. ## Modelling choices (differences from the paper) * The checking radius is written `r + 1` (`r_D ≥ 1`; the construction needs the depth-`r` subtrees `(T, v → w)`). * `Σ_E = View Σ (r+1) × Fin 3` instead of `C_D × [3]`; the node constraint only admits `a ∈ C_D`, so labels outside `C_D × [3]` never occur in a valid solution. * The node constraint additionally requires that the root of `a` has exactly 3 children (an implicit assumption of the paper: on 3-regular graphs, PN-views in `C_D` whose root does not have 3 children are never used, and the `I_fit` definition via `ζ : [3] → N(v)` presupposes it). * The enumeration `ζ` of the children of the root is fixed as `Multiset.toList` (`child`); `γ` is the induced index map `N(v) → Fin 3` chosen in Lemma 6.4 (`enumIdx`). * `I_fit` (`Fit`) is formulated via the canonical trees: `(T_{v→u}) ≅ (T'_{v' \ u'})` becomes `child a x = prune b (child b y)`. -/ namespace Podc.LCLDefinitions open View universe u w /-! ### The RE formalism -/ /-- A problem in the RE formalism (Section 2.2): node constraint `CV` (multisets of the three half-edge labels around a node) and edge constraint `CE` (multisets of the two half-edge labels of an edge). -/ structure REProblem (Λ : Type*) where /-- Node constraint. -/ CV : Set (Multiset Λ) /-- Edge constraint. -/ CE : Set (Multiset Λ) section RE variable {V : Type w} (G : SimpleGraph V) [G.LocallyFinite] {Λ : Type*} /-- A half-edge labelling `lam` (`lam v u` = label of the half-edge at `v` on the edge `{v, u}`) is valid for the RE problem `P` (Section 2.2). -/ def REProblem.Valid (P : REProblem Λ) (lam : V → V → Λ) : Prop := (∀ v, (G.neighborFinset v).val.map (lam v) ∈ P.CV) ∧ ∀ v u, G.Adj v u → ({lam v u, lam u v} : Multiset Λ) ∈ P.CE end RE /-! ### Enumeration of children -/ section Enum variable {Sig : Type u} {r : ℕ} /-- The `x`-th child subtree of the root of `a` (the paper's `ζ`), using the fixed enumeration `Multiset.toList` of the children;
