For `n = 2` every directed `3`-regular graph has adjacency matrix `[[c, 3-c], [3-c, c]]`. Any path from `a` to `b` uses the arc `(a, b)`; a path from `a` to `a` uses `(a, a)` or `(a, b)`; a path from `b` to `b` uses `(b, b)` or `(a, b)`.
