We prove `NegCorrChernoff`: if `X₁, …, X_t` are `0/1` random variables on a finite probability space with `P(Xₖ = 1) = xₖ` and negatively correlated zeros, `P(∀ k ∈ S, Xₖ = 0) ≤ ∏_{k ∈ S} (1 - xₖ)`, and `aₖ ∈ [0, 1]`, then for `μ = ∑ₖ aₖ xₖ` and `δ ∈ [0, 1]`, `P(∑ₖ aₖ Xₖ ≤ μ(1 - δ)) ≤ exp(-μδ²/2)`. Proof (exponential moment method): 1. Markov: `P(S ≤ c) ≤ e^{δc} · E[e^{-δS}]`. 2. `e^{-δ aₖ Xₖ} = uₖ + vₖ (1 - Xₖ)` with `uₖ = e^{-δaₖ}`, `vₖ = 1 - e^{-δaₖ} ≥ 0`; expanding the product over subsets and using negative correlation of zeros, `E[e^{-δS}] ≤ ∏ₖ (uₖ + vₖ(1 - xₖ)) = ∏ₖ (1 - xₖvₖ) ≤ exp(-∑ₖ xₖvₖ)`. 3.
