sets `R[a,b]` to `R[a,b] ∨ ∃ k, R[a,k] ∧ R[k,b]` and leaves the other coordinates unchanged; initial state `R₀[a,b] = 1 iff (a,b) ∈ E ∨ a = b`. * `isLeast_rtc`: the least common fixed point above `R₀` is the reflexive–transitive closure of `E`; * `tc_interleaving`, `tc_parallel` (Algorithm 1), `tc_distributed` (Algorithm 3): each execution model computes it; * `tc_parallel_rounds`: Section 3.1's round bound: if all `n²` threads run in every round, `R_t` contains every pair joined by a path of length `≤ 2^t`, so `R_t` is the closure as soon as `n - 1 ≤ 2^t`, i.e. after `⌈log₂ (n-1)⌉` rounds.
