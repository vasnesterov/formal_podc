import Mathlib /-! # The hedged auction (§9 of [Xue–Herlihy 2021]; Lemmas 7, 8) Y. Xue, M. Herlihy, *Hedging Against Sore Loser Attacks in Cross-Chain Transactions*, PODC 2021 (arXiv:2105.06322), §9. Alice (`A`, auctioneer) auctions tickets to the bidders Bob (`B`) and Carol (`C`). There are two chains, `coin` (bids) and `ticket`. Alice holds two secrets, one per bidder (`s_B` to be used if Bob wins, `s_C` if Carol wins). A *hashkey* for a secret carries a path `q` of signers (outermost signer first, Alice last). ## Model * Synchronous, discrete time `ℕ` in units of `Δ`, lock-step parties: a reaction to an event visible at time `t` takes effect at `t + 1`; deadlines are inclusive. Phases: bidding `[0, 1]`, declaration `[1, 2]`, challenge `[2, 5]`, commit at `5`. * **Timeouts.** The paper says a hashkey with path `q` "times out after time `|q|Δ`". Measured from the start of the protocol, Alice's own key `(A)` would time out at `Δ`, before the declaration phase ends at `2Δ`; so we measure from the start of the declaration phase (time `1`): a key with path `q` is accepted iff it arrives at time `t ≤ 1 + |q|` (`(A)` until 2, `(B, A)` until 3, `(C, B, A)` until 4, all before the end of the challenge phase at 5). * An execution `Exec` records the bids (amounts) and, for each secret `X` and chain `c`, the **first accepted** hashkey `pub X c = some (t, q)` (arrival time and path), `none` if none was ever accepted. The contracts' settlement depends only on whether a key was received. * `Exec.Valid`: acceptance rule (valid path, before its timeout); binds everyone. * Unforgeability of signatures is folded into the compliance predicates: a key whose path contains a compliant party `Y` with suffix `Y :: q₂` exists only if `Y` signed exactly that, which the protocol allows only in the situations described by `BidderCompliant.signs` / `AliceCompliant.signs`. Deviating parties are otherwise arbitrary. * Compliant bidder `Y` (challenge phase): when a key `(t, q)` for `X` is the first one on chain `c` and the other chain has no key by time `t`, `Y` sends `Y :: q` to the other chain at `t + 1`. We record this as "the first accepted key on the other chain arrives no later than `t + 1`", conditional on `Y`'s submission being acceptable, and *prove* that it is (`forward_accepted`). * Compliant Alice publishes the winner's key `(A)` on both chains at time `2` and never releases the other secret. The winner is given by a parameter `WinnerRule` (the paper leaves ties unspecified; we only require that the winner, if any, submitted a highest bid). ## Commit rules (§9.1 (4)) * coin: if it received the actual winner's key and not the other one, the winner's bid goes to Alice and the other bid is refunded; otherwise all bids are refunded; * ticket: exactly one key received ⇒ tickets to that bidder; zero or two ⇒ refund to Alice. The paper's proof of Lemma 7 uses a length argument ("if `q` has no compliant party then `|q| ≤ 2`"); in this model it is unnecessary: the forwarded key `Y :: q` is one signature longer, hence has one
