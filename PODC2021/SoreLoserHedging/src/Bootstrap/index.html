import Mathlib /-! # Bootstrapping premiums (§6 of [Xue–Herlihy 2021]) Y. Xue, M. Herlihy, *Hedging Against Sore Loser Attacks in Cross-Chain Transactions*, PODC 2021 (arXiv:2105.06322), §6, Figure 2. A premium of `v / P` (`P > 1`) is considered acceptable to protect an escrowed value `v`. In the hedged swap of §5.2 with principals `A` (Alice) and `B` (Bob), the leader deposits `B⁽¹⁾ = (A + B) / P` and the follower `A⁽¹⁾ = A / P`. A bootstrapping round is a hedged swap of the next round's premiums (with the roles swapped), so with `A⁽⁰⁾ = A`, `B⁽⁰⁾ = B`: `B⁽ᵏ⁺¹⁾ = (A⁽ᵏ⁾ + B⁽ᵏ⁾) / P`, `A⁽ᵏ⁺¹⁾ = A⁽ᵏ⁾ / P`. The paper claims that with `r` rounds of premium exchanges the initial premiums are `(rA + B) / P^r` and `A / P^r` (`premiums_closed_form`). Indexing: Figure 2 ("2 rounds of premium deposits") deposits `B⁽²⁾, A⁽²⁾` and then `B⁽¹⁾, A⁽¹⁾`, i.e. the `r` rounds *include* the premium round of the hedged swap itself; the number of genuinely additional bootstrapping rounds is `r - 1`. The paper's numeric example ("with 1% premiums and $4 initial lock-up risk, 3 bootstrapping rounds are enough to hedge a $1,000,000 swap") matches `r = 3` in this indexing with `A = B = 10⁶` (`example_one_million`): `B⁽³⁾ = 4`, `A⁽³⁾ = 1`. So "3 bootstrapping rounds" there counts the hedged swap's own premium round, and a "$1,000,000 swap" means each principal is worth `$10⁶`. With `A + B = 10⁶` (`A = B = 5·10⁵`) one gets `B⁽³⁾ = 2`, `A⁽³⁾ = 1/2` (`example_half_million`); with `r = 4` (three rounds on top of the hedged swap's own) and `A = B = 10⁶`, `B⁽⁴⁾ = 1/20`.
