import Mathlib /-! # Upward-closed sets of star configurations are determined by a cutoff Abstract configurations of a star are pairs `X = (centre state, leaf state count)` in `Q × (Q → ℕ)`. The order `StarLE X Y` (claim (2) in the proof of Lemma 3.5): same centre, `X.2 ≤ Y.2` pointwise, and the same support. By Dickson's lemma this order is a well-quasi-order, so every upward-closed set has finitely many minimal elements; hence it is determined by cutting the counts off at some `m` (`exists_cutoff_of_upward_closed`). -/ namespace Podc.WeakAsyncDecisionPower variable {Q : Type*} /-- The order on abstract star configurations used in the proof of Lemma 3.5. -/ def StarLE (X Y : Q × (Q → ℕ)) : Prop := X.1 = Y.1 ∧ (∀ q, X.2 q ≤ Y.2 q) ∧ (∀ q, X.2 q = 0 ↔ Y.2 q = 0) lemma StarLE.refl (X : Q × (Q → ℕ)) : StarLE X X := ⟨rfl, fun _ => le_rfl, fun _ => Iff.rfl⟩ lemma StarLE.trans {X Y Z : Q × (Q → ℕ)} (h₁ : StarLE X Y) (h₂ : StarLE Y Z) : StarLE X Z := ⟨h₁.1.trans h₂.1, fun q => (h₁.2.1 q).trans (h₂.2.1 q), fun q => (h₁.2.2 q).trans (h₂.2.2 q)⟩ /-- Cutting off the leaf counts at
