Verdict: 🔧 Easy fix. Only Section 3 was checked, not the paper's main point, the characterizations of Sections 4–6. In Section 3 all the impossibility results hold: Lemmas 3.1, 3.2, 3.4 and 3.5 and Corollaries 3.3 and 3.6, which we prove directly for all three selection constraints (liberal, exclusive, synchronous). The one heavy repair concerns the explicit cutoff β + 1 of Lemma 3.4 for exclusive automata, which nothing else depends on (Proposition C.3 uses only some cutoff, and the paper's class-level results go through [16]); the rest is local.

Mistakes in the paper

✏️ Slips

  • Lemma 3.5's proof concludes that "K := m(|Q|−1) + 2 is a valid cutoff", but its argument needs L_G(q) ≥ (m−1)|Q| + 2, the bound printed one line earlier, and K is smaller than (m−1)|Q| + 2 whenever m > |Q|. The proof shows that adding a leaf with label q preserves acceptance when L_G(q) ≥ (m−1)|Q| + 2, which is what the pigeonhole step needs. The lemma only claims that some K exists, so it is unaffected. We use K = B + 3 with B = max(m_Y, m_N)·|Q| + 1 (lemma_3_5).

  • In Lemma 3.5's proof, "the fact that MinPre*(C) is upward-closed" should read Pre*(C).

Typos

  • In Lemma 3.4's induction step, "⌈Q_{G(t+1)}⌉_β" should be ⌈·⌉_{β+1}.

  • In Lemma 3.2's proof, "C_t(v) = C_t(f(v))" should be C'_t(v) = C_t(f(v)).

  • In Lemma 3.5's proof, states and labels are identified ("L_G(q)" for a state q).

  • The definition of a covering does not say that H must be connected and have at least three nodes. This is implicit in the graph convention.

Proof gaps in true statements (2)Lemmas 3.1, 3.2, 3.4 · Lemma 3.5

🛠️ Lemmas 3.1, 3.2, 3.4 (exclusive selection)

The paper "generally assumes exclusive selection", but the proofs of Lemmas 3.1, 3.2 and 3.4 use non-exclusive schedules and rely, for exclusive selection, on the selection-independence theorem of [16], which does not give the explicit cutoff β + 1 of Lemma 3.4.

Impact. Statements true; we prove all three lemmas directly for every selection constraint, including Lemma 3.4 with the cutoff β + 1 for exclusive selection (lemma_3_1, lemma_3_2, lemma_3_4).

Details

The non-exclusive schedules:

  • the proofs of Lemmas 3.2 and 3.4 run the automaton synchronously (as a DA$ automaton);

  • the proof of Lemma 3.1 selects all copies of the nodes chosen by ρ_G and ρ_H at the same time.

None of these is an exclusive schedule. The theorem of [16] relates classes of automata, so on its own it does not give the explicit cutoff β + 1 of Lemma 3.4 for an exclusive automaton.

Repair

  • Lemma 3.1 alternates G-steps and H-steps. Every lifted selection is then the set of copies of a single node, which is independent and can be executed one node at a time. Sequentialising the paper's simultaneous selection would also work, since it only changes states at the junction nodes, which the distance argument already discards.

  • Lemma 3.2 executes the fibre f⁻¹(v) one node at a time.

  • Lemma 3.4 uses stars instead of cliques, with the schedule "all leaves (one at a time), then the centre".

🔧 Lemma 3.5 (stable acceptance)

"An analogous argument shows that the same holds for acceptance" requires a second cutoff m', for the set of configurations that can reach a non-accepting configuration.

Impact. Statement true; we take max(m, m') (lemma_3_5).

The formalizationmodel, Lean names of the results, trust

Model (Podc/Computability/Distributed/DistributedAutomata/, staged for CSLib).

  • Input graphs. LGraph Λ is a finite labelled simple graph. Admissible k encodes the paper's convention (connected, at least 3 nodes) plus a degree bound k : ℕ∞, where k = ⊤ means arbitrary graphs.

  • Machines. A Machine has a counting bound β ≥ 1. Its transition function δ q N is applied to neighbourhood counts cut off at β (view). It has accepting and rejecting states Y, N. Halting means that Y ∪ N is absorbing.

  • Steps and schedules. In step, the selected nodes move simultaneously. A schedule is ℕ → Set V.

  • Selection and fairness. The selection constraint is liberal, exclusive or synchronous. Fairness is adversarial or pseudo-stochastic, exactly as in §2: every node is selected infinitely often, and under pseudo-stochastic fairness every finite sequence of permitted selections occurs infinitely often.

  • Acceptance. Acceptance is by stable consensus. Consistent k is the consistency condition on admissible graphs. Accepts means that some fair run accepts. IsLabelling means that the decided property depends only on label counts.

  • Classes. The classes xyz appear as hypotheses: M.β = 1 (d), M.Halting (a), A.fair = .adversarial (f). Where the proof allows it, a theorem is stated without the hypothesis, which makes it stronger:

    • Lemma 3.1 holds for every halting automaton (any β, any fairness), which covers DaF.

    • Lemma 3.5 holds for every non-counting automaton (any fairness), which covers dAF and dAf.

    • Every result holds for all three selection constraints.

    The paper's reduction to one selection type ([16]) is not needed and not formalized.

  • States. Q need not be finite except in Lemma 3.5 and Corollary 3.6. There it must be finite, and a Type.

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity (NonVacuity.lean): the flooding automaton flood κ φ is non-counting and not halting. For every selection, fairness and degree bound it satisfies the consistency condition and decides the non-trivial labelling property "some node is labelled a" (flood_decides, flood_isLabelling). So the hypotheses of Lemmas 3.2–3.5 are met by non-trivial automata. The hypotheses of Lemma 3.1 are met by the constant accepting automaton (acceptAll_halting, acceptAll_consistent). The model is staged in Podc/ (CSLib candidate). It uses CSLib's ωSequence.flatten and Mathlib's Set.PartiallyWellOrderedOn (Dickson's lemma).
