Syst. 50 (2012)): *any population protocol solving SSLE has `≥ n` states and is strongly nonuniform.* * `card_le_card_states`: a protocol solving SSLE on `n` agents has at least `n` states. The proof is the *closed-set argument* of Cai–Izumi–Wada: starting from the `n - 1` followers of a stably correct configuration (which can never generate a leader state), repeatedly either find a state the current sub-configuration cannot generate, or drop one agent and find such a state; after `|Q| - #leader-states` rounds a nonempty sub-configuration cannot generate any state. * `not_solvesSSLE_two_sizes`: no protocol (same states, transitions and leader output) solves SSLE for two population sizes `n₁ < n₂` (the argument sketched in the paper after Theorem 2.1: a leaderless sub-population of size `n₁` of a stably correct size-`n₂` configuration would create a second leader).
