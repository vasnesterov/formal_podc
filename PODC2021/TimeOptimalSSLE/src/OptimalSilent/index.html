An agent brought in by line 2 therefore decrements its fresh `delaytimer = Dmax` (line 9). * Line 10 ("`b.role ≠ Resetting`") is read as "the *other* agent is not Resetting". * Decrements are truncated at `0`; triggered agents get `delaytimer = Dmax` (unused while propagating). ## The off-by-one Line 9 of Protocol 3 only recruits when `2 · i.rank + i.children < n`. Since new ranks are only created by `Reset` (rank `1`) and by recruitment (rank `2 · rank + children`), **no agent can ever obtain rank `n`** unless it already had it: from any configuration without a settled agent of rank `n` (e.g. all agents `Unsettled`) a correctly ranked configuration is never reachable (`asWritten_never_ranked`), so the protocol as printed does not solve SSR for any `n ≥ 2` (`asWritten_not_selfStabilizes`).
