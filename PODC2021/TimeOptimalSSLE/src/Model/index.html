import Cslib.Computability.Distributed.PopulationProtocols.Nondet import Mathlib.Data.Fintype.CardEmbedding /-! # Population protocols with randomized transitions: model and problem statements Burman, Chen, Chen, Doty, Nowak, Severson, Xu, *Time-Optimal Self-Stabilizing Leader Election in Population Protocols*, PODC 2021 (arXiv:1907.06068v5), Section 2. The paper allows *probabilistic* transitions `T : S × S → Dist(S × S)`. All statements we formalize about self-stabilization "with probability 1" only depend on the **support** of the transition distributions (finite state space, uniformly random ordered pair; see `RandomScheduler.lean` for the Markov-chain bridge). We therefore model a protocol by its support relation `δ p q ⊆ Q × Q` (`NProtocol`, the shared model `Cslib.PopulationProtocol.NProtocol` of `Cslib.Computability.Distributed.PopulationProtocols.Nondet`). Deterministic CSLib protocols embed via `NProtocol.ofProtocol`. * `NProtocol.Step`, `NProtocol.Reachable`: one interaction of an ordered pair of distinct agents (the complete interaction graph). * `NProtocol.StablyCorrect good C`: every configuration reachable from `C` is `good` (`Cslib.TransitionSystem.StablyIn`). * `NProtocol.SelfStabilizes good`: from every configuration a stably correct one is reachable (`Cslib.TransitionSystem.SelfStabilizes`). For a finite state space and the uniform random scheduler this is *equivalent* to "from every configuration a stably correct configuration is reached with probability 1" (`RandomScheduler.lean`). * `SolvesSSLE` (one agent with `leader = true`), `SolvesSSR` (ranks form a bijection onto `Fin n`). * Sub-population runs (`StepIn`/`ReachIn`), silence (`Silent`) and the embedding of a run of a sub-population (`exists_reachIn_of_embedding`) are the shared notions of `Cslib.Computability.Distributed.PopulationProtocols.Nondet`. -/ open Cslib.PopulationProtocol Cslib.TransitionSystem namespace
