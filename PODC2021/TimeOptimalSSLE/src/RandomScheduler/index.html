import Papers.PODC2021.TimeOptimalSSLE.Model import Cslib.Computability.Distributed.PopulationProtocols.RandomScheduler import Cslib.Computability.Distributed.SelfStabilization.Markov /-! # The uniformly random scheduler: "with probability 1" versus reachability The paper's semantics (Section 2): at each step an ordered pair of distinct agents is chosen uniformly at random and the (possibly randomized) transition is applied. A protocol *self-stabilizes* if from every configuration a stably correct configuration is reached with probability 1. For a finite state space this is a finite Markov chain on configurations. We prove, for **any** row-stochastic kernel whose positive entries are exactly the protocol's steps: * `tendsto_not_stablyCorrect`: if `SelfStabilizes good` (from every configuration some stably correct configuration is reachable), then from every configuration the probability of not being in a stably correct configuration after `t` steps tends to `0` (stabilization with probability 1); * `prob_stablyCorrect_eq_zero`: conversely, if from `C` no stably correct configuration is reachable, then the probability of being in a stably correct configuration is `0` at all times. So `NProtocol.SelfStabilizes` is exactly the paper's "with probability 1" notion. Both are instances of the generic bridge `Cslib.TransitionSystem.SelfStabilizes.tendsto` / `Cslib.TransitionSystem.prob_eq_zero_of_not_reach` (`Cslib.Computability.Distributed.SelfStabilization.Markov`). The kernel of a deterministic protocol under the uniform random scheduler is `Cslib.PopulationProtocol.uniformKernel` (`uniformKernel_pos_iff`). -/ open Cslib.PopulationProtocol
