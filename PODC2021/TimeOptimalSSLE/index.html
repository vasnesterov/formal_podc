Time-Optimal Self-Stabilizing Leader Election in Population Protocols — PODC 2021

Janna Burman, Ho-Lin Chen, Hsueh-Ping Chen, David Doty, Thomas Nowak, Eric Severson, Chuan Xu. Time-Optimal Self-Stabilizing Leader Election in Population Protocols. PODC 2021. DOI 10.1145/3465084.3467898. Formalized version: arXiv 1907.06068 v5 (29 Nov 2021); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The paper's time bounds, its main point, and Section 5 (Sublinear-Time-SSR) were not checked. What was checked holds apart from one typo and a by-product: SSLE needs ≥ n states and exact knowledge of n (Theorem 2.1, proved here), Silent-n-state-SSR solves ranking (Lemmas 2.2, 2.3, Theorem 2.4), Observation 2.5 holds, and Optimal-Silent-SSR, which as printed never stabilizes, is correct with the evidently intended guard ≤ n (from every valid configuration a silent, correctly ranked configuration is reachable, for Rmax, Dmax ≥ 2, which the paper's choices satisfy). Only the explicit tail bound of Observation 2.6 is lost, and nothing depends on it.

Mistakes in the paper

⚠️ Observation 2.6 for n = 2 and n = 3 (explicit tail bound)

The claim "for any α > 0, probability ≥ ½ n^{-3α} to require ≥ α n ln n convergence time" fails for n = 2, where Silent-n-state-SSR is correctly ranked after the first interaction (obs26_n2_counterexample), and for n = 3 with large α.

Impact. The paper uses only the Ω(n) expected time of the observation, which is fine. The claim holds for n ≥ 4 with the exact success probability 2/(n(n−1)), but this was checked by hand, not in Lean. In Lean we have the two-leader core and the geometric tail, for deterministic protocols.

Details

With two agents, Silent-n-state-SSR is correctly ranked after the first interaction from every configuration, under every schedule, so its convergence time is at most 1/2 < 2 ln 2. The proof has a wrong estimate: (1 − 3/n²)^{α n² ln n} ≥ ½ e^{−3α ln n} is false for large α (e.g. n = 10, α = 7), and 1/C(n,2) < 3/n² needs n ≥ 4. Also, "expected time ≥ n/3" fails for n = 2. For n = 3 the claim fails e.g. for α = 10 (checked numerically, not in Lean). The deterministic core and the geometric tail are obs26_null_of_ne, obs26_two_leaders, obs26_stay_prob.

✏️ Slips

  • Protocol 3 (Optimal-Silent-SSR), line 9, and Theorem 4.3: the guard 2 · i.rank + i.children < n should be ≤ n. As printed, the protocol never stabilizes. New ranks are created only by Reset (rank 1) and by recruitment (rank 2·rank + children), so no agent can ever obtain rank n unless it already had it. Hence from the all-Unsettled configuration, or from any configuration after a complete reset, no correctly ranked configuration is ever reached, for every n ≥ 2 and all Rmax, Dmax, Emax; the protocol stabilizes with probability 0 (OptimalSilent.asWritten_never_ranked, asWritten_not_selfStabilizes). Figure 1 (rank 12 assigned for n = 12) shows that ≤ n is meant, and with it we prove Theorem 4.3's correctness for Rmax, Dmax ≥ 2 (OptimalSilent.fixed_selfStabilizes).

  • Proof of Lemma 2.2: ∑_{j=1}^{n−1} m_j = n should start at j = 0, and S_k − S_{k−r+1} should be S_{k−r−1}, S_{−1} = 0.

  • Proof of Theorem 2.4: the slow initial configuration is "m_1(C_0) = 2" but should be m_0(C_0) = 2.

Typos

  • Under-specified pseudocode of Protocols 2–4. The field list of Protocol 3 omits resetcount = 0; Propagate-Reset(a, b) is written for a Resetting a but called also when only b is Resetting; the leader bit of agents brought into Resetting is not set (the text says L); "just became 0" and line 10's b.role ≠ Resetting (for i = b) are ambiguous. We fixed one reading (differencies.md, item 21); the off-by-one does not depend on it, and the model checker finds the fixed protocol correct under the alternative reading of line 10 too.

Model.

  • Population protocols on the complete graph with labelled agents (A → Q, |A| = n), ordered pairs of distinct agents. Randomized transitions S × S → Dist(S × S) are modelled by their support (NProtocol); deterministic CSLib protocols (Cslib.PopulationProtocol.Protocol) embed into this.

  • Self-stabilization "with probability 1" (uniformly random scheduler) is formalized as: from every configuration a stably correct configuration is reachable. RandomScheduler.lean proves that this is equivalent to the paper's notion: for any Markov kernel whose positive entries are exactly the protocol's steps (e.g. the uniform scheduler, uniformKernel), it implies absorption with probability 1, and unreachability implies probability 0.

  • Lower bounds (Theorem 2.1) assume only this reachability property (the weakest, "positive probability" reading) and allow randomized transitions and arbitrary sets of leader states.

  • For Silent-n-state-SSR we additionally prove deterministic statements for arbitrary schedulers (at most n(n−1) non-null interactions in every execution) and weakly fair schedulers (CSLib Execution.WeaklyFair).

  • Optimal-Silent-SSR: explicit state type (roles with their fields) and the interaction as the composition of the pseudocode blocks, with a flag selecting the printed (<) or the fixed (≤) recruitment guard. Its Lean transition function agrees with the Python model checker tools/oss.py on all state pairs (checked for n = 3). Its state type has unbounded ℕ fields, so the probability-1 bridge applies to the finite set of valid states; it is not instantiated for this protocol in Lean.
