The success time `succTime P ω ∈ {1, 2, …, ⊤}` is one plus the first round in which exactly one participant of `P` transmits; `expTime (D a) P` is its expectation. * *Collision detection.* A player's behaviour is a random *strategy* `List Bool → Bool` (transmit or not, given the common collision history); the execution for a fixed choice of strategies is the deterministic execution of `Model.lean`. The lower bounds of the paper reduce to the lower bound of [18] (Newport 2014) for randomized algorithms without advice and without collision detection, which we take as a hypothesis (`NewportBound n c`: every algorithm without advice has a participant set with expected time `≥ c log₂ n`). * `theorem_3_6_lower`: with `|A|` advice values the worst-case expected time is `≥ c log₂ n / |A|` (the paper's "try all advice strings in parallel", made precise by round-robin interleaving). * `expTime_simulation_le`: the paper's simulation of a collision-detection algorithm without collision detection (one round per possible history) gives expected time `≤ E[2^T]`, where `T` is the success time of the simulated algorithm. Combined with the interleaving, `theorem_3_7_lower_exp` gives `E[2^T] ≥ c log₂ n / 2^b` for some participant set.
