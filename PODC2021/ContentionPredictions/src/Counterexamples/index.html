import Papers.PODC2021.ContentionPredictions.LowerBounds /-! # Counterexamples around Theorem 3.3 1. **The proof step "`F = {V(s)}` is `(n, n)`-strongly selective" is false.** A non-interactive algorithm only guarantees that *some* participant of `P` is isolated by the first-round transmitter set `V(f P)`, not that *every* participant is isolated by some set. For `n = 2` and one bit of advice, the sets `V(0) = {0}`, `V(1) = {0, 1}` solve non-interactive contention resolution, but no set isolates `1` inside `Z = {0, 1}` (`not_stronglySelective_example`). Theorem 3.3 itself is true (`theorem_3_3`, via a parity argument instead of Theorem 3.2). 2. **Theorem 3.3 is false if "at most `b` bits" allows advice strings of different lengths**, as the definition of `b(n)`-non-interactive contention resolution says ("the advice `f_A(P)` contains no more than `b(n)` bits"). With the three strings `ε, 0, 1` of length `≤ 1`, three players can be told who transmits, but `1 < log₂ 3` (`theorem_3_3_false_variable_length`).
