We repair it: * **Markov**: with `M = 2t`, a block of `K = 2^M - 1` simulated rounds (one per history of length `< M`) fails only if the CD execution needs more than `M` rounds, which has probability `≤ t / (2t + 1) ≤ 1/2` (`mul_measure_blockFail_le`). * **Independent restarts**: each player draws a sequence of independent strategies (`Measure.infinitePi`) and runs the blocks one after another (`restartSched`). After swapping the product over players and copies (`pi_infinitePi_map_swap`), the block failures are independent, so the expected time is `≤ K ∑ 2^{-j} ≤ 2^{2t+1}` (`expTime_restart_le`).
