import Mathlib.Data.Fintype.BigOperators import Mathlib.Data.Fintype.Sigma import Mathlib.Data.Vector.Basic import Mathlib.Algebra.Ring.GeomSum import Mathlib.Analysis.SpecialFunctions.Pow.Real import Mathlib.Analysis.SpecialFunctions.Log.Base -- CSLib candidate: radio-channel model (see wiki/library-map.md) /-! # Deterministic contention resolution with perfect advice (Section 3.1 of the paper) Gilbert, Newport, Vaidya, Weaver. *Contention Resolution with Predictions.* PODC 2021. **Model.** `n` potential players `Fin n` share a single-hop synchronous channel. An adversary picks a nonempty set `P` of participants; every participant receives the same advice `f P` from an advice function `f` with perfect knowledge of `P`. In each round each participant transmits or listens; the problem is solved in the first round in which exactly one participant transmits. If two or more transmit, all messages are lost: with collision detection (`cd = true`) every player, including the transmitters, detects the collision; without collision detection every unsuccessful round sounds like silence to everybody. Hence, before the problem is solved, all participants have observed the same channel feedback, a list of bits (one per completed round, `true` = collision), and a deterministic algorithm is a function `advice → feedback history → id → transmit?` (`DetAlg`). Without collision detection the history before success is always a list of `false`s. `SolvesIn cd alg f t`: for every nonempty `P`, the execution with advice `f P` is solved in one of the rounds `0,
