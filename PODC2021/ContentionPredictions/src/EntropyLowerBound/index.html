A *uniform* algorithm is a sequence of probabilities `p 0, p 1, …` (`UniformAlg`): in round `r` (counted from `0`) every participant transmits independently with probability `p r`. Without collision detection every unsuccessful round sounds like silence, so the behaviour cannot depend on feedback; with `k` participants round `r` succeeds (exactly one transmitter) with probability `succProb k (p r) = k · p r · (1 - p r)^(k-1)`, independently over rounds. Hence `surv A k m = ∏_{r < m} (1 - succProb k (p r))` is the probability that rounds `0, …, m-1` all fail, and the expected number of rounds until success is `expTime A k = ∑_{m ≥ 0} Pr[T > m]` (an element of `ℝ≥0∞`; it is `⊤` if the algorithm does not terminate almost surely). The number of participants is drawn from a distribution `X` on `{2, …, n}` (the paper assumes sizes `≥ 2`, footnote 4); `tX A X n = ∑_k X k · expTime A k` is the expected running time. The condensed distribution `c(X)` aggregates `X` over the geometric ranges `(2^(y-1), 2^y]`, `y = 1, …, ⌈log n⌉` (the range of `k` is `Nat.clog 2 k`), and `entropyBits X n = H(c(X))` is its Shannon entropy in bits. **Main result** (`theorem_2_4`): there is a universal constant `C > 0` such that for every `n ≥ 4`, every size distribution `X` on `{2, …, n}` and every uniform algorithm `A`, `t_X ≥ C · 2^H(c(X)) / log log n`, i.e. `t_X = Ω(2^H(c(X)) / log log n)`. We get `C = 1/(88 e)` (`theorem_2_4_explicit`). **Proof route.** The paper's proof (Lemmas 2.5–2.7) is repaired as follows. * Lemma 2.6 analogue (`le_mul_of_good`, `mul_le_of_good`): if a round succeeds with probability at least `ε` for `k ≥ 2` participants, then `ε ≤ k p ≤ 8/ε`. * Per-size bound (`expTime_ge`): if rounds `0, …, R-1` all succeed with probability `< ε` and `R ε ≤ 1/2`, then `E[T] ≥ (R+1)/2` (Weierstrass product inequality; this replaces the paper's incorrect "mean ⇒ median" step). * A *guess index* `guess` on ranges (essentially the first round that is good for some size in the range) has fibers of size `O(log log n)` (`card_fiber_guess_le`) and `E[T_k] ≥ (guess (range k) + 1)/4` (`expTime_ge_guess`). * Guesswork / Gibbs lemma (`sum_negMulLog_le_of_card_fiber_le`): for a distribution `q` and an index `h` with fibers of size `≤ K`, `H(q) ≤ log K + log (E[h+1] + 1) + 1` (nats).
