import Papers.PODC2021.WakeUpMatching.Radio import Mathlib.Analysis.SpecialFunctions.Log.Basic /-! # Theorem 1.1 in the corner case `Δ = 1` Dani, Gupta, Hayes, Pettie, PODC 2021 (arXiv:2104.09096v2), Theorem 1.1: `P(M is a maximal matching and every node used energy ≤ 2C (log n)(log Δ)) ≥ 1 − 1/n²`. Energy per round (Section 2.3: one unit per send or listen): a recruiter sends and listens (`2`), plus one send if it matched; an acceptor listens (`1`), plus a send and a listen if it heard a recruiter (`2`); sleeping and matched nodes spend nothing (`energyRound`). For `Δ = 1` (a legal parameter: "any upper bound on the maximum degree") the energy bound is `2C (log n)(log 1) = 0`, but a node can only get matched in a round in which it participates. So on every graph with an edge, the event of Theorem 1.1 is *empty* for every execution (`theorem_1_1_delta_one`): the literal statement fails for `Δ = 1`.
