import Mathlib.Analysis.SpecialFunctions.Log.Basic import Mathlib.Analysis.SpecialFunctions.Exp import Mathlib.Algebra.Order.BigOperators.Ring.Finset import Mathlib.Algebra.BigOperators.Intervals /-! # The participation schedule of Algorithm 1 Dani, Gupta, Hayes, Pettie, *Wake up and join me! An energy-efficient algorithm for maximal matching in radio networks*, PODC 2021 (arXiv:2104.09096), Algorithm 1. In round `t` of Algorithm 1 every node participates with probability `r(t) = 1 / (2 + 3 (1 - (t-1)/T) Δ)`, where `T` is the number of rounds and `Δ` the degree bound. This file proves the elementary analytic facts about this schedule used in the analysis: * positivity and monotonicity of `r` on `t ≤ T + 1`; * the bounds `r(t) ≤ 1/2`, `r(1) < 1/(3Δ)` and `r(t) < 1/(2Δ)` for `t ≤ 1 + T/3`; * `sum_rate_ge`: the lower bound `∑_{t=a+1}^{b} r(t) ≥ (T / (3Δ)) · log (r(b) / r(a))`, which replaces the paper's Riemann-sum / integral estimate. It follows from the fact that `1/r(t)` is affine with slope `-3Δ/T`, so each summand dominates a telescoping logarithmic increment (`log (1 + x) ≤ x`); * `prod_one_sub_le_exp`: `∏ (1 - g t) ≤ exp (-∑ g t)` for `0 ≤ g t ≤ 1`.
