For a sequence of partner states `s 0, s 1, …` produced by rounds of the protocol, `Δ(t)` is the maximum residual degree (`maxRes`), round `t` is *good* if `Δ(t−1) r(t) < 1/2` (`Good`), and `Z(v, t)` holds if `t` is good, `v` is unmatched after round `t` and `3 r(t) d(v, t) ≥ 1` (`LostOpp`). If some round is bad, let `t` be the first bad round and `v` a vertex witnessing it; then `Z(v, t')` holds for every `t' < t` with `3 r(t') > 2 r(t)` (`exists_first_bad`). -/ set_option linter.unusedSectionVars false namespace Podc.WakeUpMatching open Finset variable {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj] /-- `Δ(t)`: the maximum residual degree of the state `s` (`0` if every vertex is matched). -/ def maxRes (s : V → Option V) : ℕ := (univ.filter fun u => s u = none).sup fun u => #(resN G s u) /-- Definition 5.3: round `t` is good if `Δ(t − 1) r(t) < 1/2`. -/ def Good (r : ℕ → ℝ) (s : ℕ → V → Option V) (t : ℕ) : Prop := (maxRes G (s (t - 1)) : ℝ) * r t < 1 / 2 /-- Definition 5.5: `Z(v, t) = 1` — round `t` is good, `v` is unmatched after it, and `d(v, t) ≥ 1/(3 r(t))`. -/ def LostOpp (r : ℕ → ℝ) (s : ℕ → V → Option V) (v : V) (t : ℕ) : Prop := Good G r s t ∧ s t v = none ∧ 1 ≤ 3 * r t * (#(resN G (s t) v) : ℝ) /-- The rounds `t' ∈ [1, t − 1]` with `3 r(t') > 2 r(t)` (the interval `I` of the paper). -/ noncomputable def lostSet (r : ℕ → ℝ) (t : ℕ) : Finset ℕ := (Icc 1 (t - 1)).filter fun t' => 2 * r t < 3 * r t' variable {G} /-- States produced by rounds of the protocol. -/ def IsRoundSeq (s : ℕ → V → Option V) : Prop := ∀ t, ∃ ρ, s (t + 1) = round G (s t) ρ theorem IsRoundSeq.mono {s : ℕ → V → Option V} (hs : IsRoundSeq (G := G) s) {t t' : ℕ} (h : t ≤ t') {v w : V} (hv : s t v = some w) : s t' v = some w := by induction h with | refl => exact hv | step _ ih => obtain ⟨ρ, hρ⟩ := hs _ rw [hρ];
