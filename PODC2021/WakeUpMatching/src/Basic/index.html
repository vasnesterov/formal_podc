import Mathlib.Combinatorics.SimpleGraph.Matching import Mathlib.Data.Fintype.Card /-! # Neighbor assignment functions and matching covers Dani, Gupta, Hayes, Pettie, *Wake Up and Join Me! An Energy-Efficient Algorithm for Maximal Matching in Radio Networks*, PODC 2021 (arXiv:2104.09096v2), Section 6. * `IsNAF G f` — Definition 6.1: `f : V → V` with `{v, f v} ∈ E` for every `v`; * `inDeg f v = |f⁻¹(v)|`, `load f = max_v |f⁻¹(v)|`, `minNAFLoad G` (Definition 6.1); * `IsMatchingCover G M` — `k` matchings (Mathlib `Subgraph.IsMatching`) whose vertex sets cover `V`; `matchingCoverNumber G = mc(G)` (Definition 6.2); * `PMatching H` — a matching encoded by *partner variables* (as in the paper's algorithms), with the bridges to Mathlib matchings. Minima are `sInf` of sets of naturals; they are only meaningful when the sets are nonempty, which for both quantities means that `G` has no isolated vertex (see `Theorem63.lean`). -/ set_option
