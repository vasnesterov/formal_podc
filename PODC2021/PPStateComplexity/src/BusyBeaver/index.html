import Papers.PODC2021.PPStateComplexity.Leaderless import Papers.PODC2021.PPStateComplexity.Examples /-! # Busy beaver functions and counterexamples * Definition 1: `BB n` (leaderless busy beaver function). Theorem 5.9 gives `BB n ≤ 2^((2n+2)!)` (`BB_le`), i.e. `STATE(η) ∈ Ω(log log η)`; Example 2.1 gives `2^k ≤ BB (k+1)` (`le_BB`). * `BB_L` (protocols *with leaders*) is **under-specified**: with unboundedly many leaders, four states decide `x ≥ η` for every `η` (`not_bddAbove_BBLSet`). So the paper's claims "an upper bound on the busy beaver function `BB_L(n)`" (Section 4) and "the state complexity of `x ≥ η` with leaders is the inverse of a non-elementary function" (abstract, conclusion) need the evidently intended fixed number `ℓ` of leaders; Theorem 4.5 itself correctly depends on `ℓ`. * With configurations read as arbitrary multisets (the paper requires `≥ 2` agents,
