import Podc.Computability.Distributed.PopulationProtocols.Multiset.PotentialReach /-! # Population protocols with leaders deciding `x ≥ η` (Section 2 of Czerner–Esparza–Leroux) The model of Section 2.2: a protocol `P = (Q, T, L, {x}, I, O)` with a single input variable `x` (we store the input state `I(x)` as `P.x`), a *leader multiset* `L`, transitions `T ⊆ Q² × Q²` (total: every pair of states has a transition) and outputs `O : Q → Bool`. Configurations are multisets of states (CSLib/Podc multiset model `Cslib.PopulationProtocol`). The initial configuration of input `i` is `IC(i) = L + i · x`; inputs have at least two agents (`2 ≤ i`). An execution is fair if every configuration reachable infinitely often is visited infinitely often: this is CSLib's *global fairness* `Cslib.TransitionSystem.Run.GloballyFair`. The protocol computes `x ≥ η` (`Protocol.ComputesGe`) if every fair execution from `IC(i)`, `i ≥ 2`, eventually stays in consensus `decide (η ≤ i)`. ## Main statements * `Protocol.computesGe_iff`: the reachability characterization stated after Definition 2: `P` computes `x ≥ η` iff every configuration reachable from `IC(i)` can reach a `decide (η ≤ i)`-stable configuration. * Monotonicity of reachability (`MReach.add_right`, `MReach.add`, `MReach.nsmul`). -/ namespace Podc.PPStateComplexity open Cslib Cslib.PopulationProtocol Cslib.TransitionSystem Filter variable {Q : Type*} [DecidableEq Q] /-!
