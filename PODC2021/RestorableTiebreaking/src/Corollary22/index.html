The weights are `r(u, v) = sgn(u, v) · ρ({u,v})` with `ρ(e) = i(e) / (2 n W)` and `i(e)` uniform in `{-W, …, W}` (so `r(u, v) = (i/W) · 1/(2n)` as in the paper). * `corollary22` — counting form: the number of `i ∈ {-W, …, W}^{Sym2 V}` for which `rOf ρ_i` is **not** an `f`-ATW function, times `2W + 1`, is at most `n² · N_f · |E| · (2W + 1)^{|Sym2 V|}`, where `N_f` is the number of edge sets of size `≤ f`. So the failure probability is at most `n² N_f |E| / (2W + 1)`. * `paper_count_false` — the paper's union bound counts "`≤ n^{f+2}` possible choices of `s, t, F`"; already for `K₄` and `f = 1` there are `16 · 7 = 112 > 4³` choices with ordered pairs `(s, t)` (`84 > 64` excluding `s = t`). In general `N_f ≈ |E|^f` is up to `≈ n^{2f}`, so with the paper's choice `W = n^{f+4+c}` the union bound only gives `≈ n^{f-c}`; `W = n^{2f+4+c}` gives the claimed `n^{-c}` (still `O(f log n)` bits).
