import Mathlib import Cslib.Foundations.Combinatorics.SimpleGraph.ShortestWalks /-! # Restorable shortest path tiebreaking — definitions Bodwin–Parter, *Restorable Shortest Path Tiebreaking for Edge-Faulty Graphs*, PODC 2021 (arXiv:2102.10174v4), Sections 2–3. **Model.** `G` is a finite undirected unweighted graph (`SimpleGraph V`, `[Fintype V]`). A fault set is a finset `F` of unordered pairs (`Sym2 V`); `G \ F` is `G.deleteEdges F`. Paths are walks of `G` (type `G.Walk s t`, so selected paths for different fault sets live in the same type); "a shortest path of `G \ F`" is `p.IsShortestIn F` (it avoids `F` and has length `d_{G \ F}(s, t)`; such walks are automatically paths, `IsShortestIn.isPath`). Distances are `edist` (`ℕ∞`, `⊤` for disconnected pairs). * `Scheme G` — a replacement path tiebreaking scheme `π(s, t | F)`: an optional selected walk for every fault set and ordered pair (`none` plays the role of the paper's `π(s, t) := ∅`). * `IsRPTS G f π` (Definitions 12, 15), `IsSymmetric` (13), `IsConsistent` (14), `IsStable` (16), `IsRestorable` (17, with the connectivity hypothesis that the paper's Definition 17 omits; the literal version is `IsRestorableLiteral`). * `IsMinWalk G r A p`, `IsATW G f r` (Definition 18) and the generated scheme `atwScheme G r`. -/ open Finset
