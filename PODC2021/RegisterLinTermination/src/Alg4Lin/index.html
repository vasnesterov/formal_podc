import Papers.PODC2021.RegisterLinTermination.Alg4 import Podc.Computability.Distributed.SharedMemory.MWMRRegister import Mathlib.Order.Prod.Lex.Basic /-! # Theorem 12: Algorithm 4 is linearizable Hadzilacos, Hu and Toueg, *On Register Linearizability and Termination*, PODC 2021, Section 5 and Appendix D. We prove `alg4_linearizable`: for every value type `V`, initial value `v₀` and number `n ≥ 1` of processes, Algorithm 4 (`alg4 V v₀ n`) is a linearizable implementation of an MWMR register. ## Proof We apply the reads-from criterion for MWMR registers (`MWMRReadsFrom.isLinearization`) to * `ws` = the writes that have already written their cell `Val[k]`, sorted by timestamp (`sortWs`), and * `rf x` = `0` if the read `x` returned a cell with sequence number `0` (the initial value), and otherwise `1 +` the position in `ws` of the write whose timestamp `x` returned (`rfOf`). The real-time conditions of the criterion are the paper's Corollary 58 and Lemmas 59–61; they are derived from an invariant `Inv` of all executions, proved by induction over the execution (`exists_inv`). The invariant carries a ghost list `W` of the writes that have written to `Val[-]` and a ghost map `tok` giving the timestamp of each such write and the timestamp returned by each read. Its main clauses: * `Val[k]` holds a timestamp with process id `k`, and the timestamp of every write of `p_k` in `W` is at most that of `Val[k]` (timestamps in `Val[k]` only grow: `own_wr`); distinct writes have distinct timestamps (`W_inj`, the paper's Observation 51); * every cell (in memory, or kept by a reader) holds either the initial value with sequence number `0`, or the value of the write in `W` with this timestamp (`Good`, Observations 52, 53); * `prec`: if `a` precedes `b` in real time then the timestamp of `a` is *covered* by `b`: if `b` is a completed or written write then `tok a < tok b`, if `b` is a completed read then `tok a ≤ tok b`, and while `b` is still scanning `Val[-]`, `tok a` is below what `b` has seen or below a register `b` has still to read (`CoveredBy`). This is the paper's Lemma 50 and the core of Lemmas 59–61 ("timestamps in `Val[-]` are non-decreasing"). -/ namespace Podc.RegisterLinTermination.Alg4 open Cslib.SharedMemory List set_option
