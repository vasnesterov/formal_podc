import Podc.Computability.Distributed.SharedMemory.WriteStrongLin import Mathlib.Tactic.FinCases /-! # Algorithm 4: an MWMR register from SWMR registers with Lamport clocks Hadzilacos, Hu and Toueg, *On Register Linearizability and Termination*, PODC 2021, Section 5. ``` Shared: Val[i], i = 1..n: SWMR register, initially (0, ⟨0, i⟩) write(v) by p_k: for i = 1..n: (v_i, ts_i) ← Val[i] new_sq ← max{ts_1.sq, …, ts_n.sq} + 1 Val[k] ← (v, ⟨new_sq, k⟩); return done read(): for i = 1..n: (v_i, ts_i) ← Val[i] return v_j with ts_j the lexicographic maximum ``` ## Modelling * Processes and registers `Val[i]` are indexed by `Fin n`; a timestamp is a pair `(sq, pid)` compared lexicographically (`tsLt`). The registers `Val[i]` are base registers of CSLib's shared-memory model; they are single-writer by the code (only `p_k` writes `Val[k]`). * One base-object access per step. The implemented object is `register V v₀`; a `write v` returns `v` (CSLib's dummy write response), a `read` returns the value. * The read keeps the best cell seen so far, starting from `(v₀, (0, 0))`, which is below every timestamp (the paper takes the maximum of the `n` cells read; this is the same). ## Theorem 13 `alg4_not_writeStronglyLinearizable`: for `n = 3` processes and values in `ℕ` (initially `0`), Algorithm 4 is not write strongly-linearizable. The histories `G`, `H₁` (Case 1) and `H₂` (Case 2) are exactly those of the paper's proof: `w₁ = write 1` by `p₁` reads `Val[1]`, `Val[2]`; `w₂ = write 2` by `p₂` runs to completion. In `H₁`, `w₁` completes and a read returns `2`, forcing `w₁` before `w₂`; in `H₂`, `p₃` first writes `3`, then `w₁` completes and a read returns `1`, forcing `w₂` before `w₁`.
