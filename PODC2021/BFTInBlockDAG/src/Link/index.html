import Papers.PODC2021.BFTInBlockDAG.Interpret /-! # Executions of a protocol over authenticated perfect point-to-point links The paper's Theorem 5.1 transfers every property that holds for `P` "using the reliable point-to-point link abstraction" (Lemma 4.3, which claims the properties of an *authenticated perfect point-to-point link* of Cachin–Guerraoui–Rodrigues, Module 2.5: reliable delivery, no duplication, authenticity). We model the safety part of this abstraction for one protocol instance (label `ℓ`) in the asynchronous model with Byzantine servers `Byz`. An execution is a finite list of events `(s, inp)`: correct server `s` handles input `inp` (a request from the user, or the delivery of a message). Byzantine servers have no events; the messages they send are arbitrary (any message with a Byzantine sender may be delivered). `exec P ℓ tr` replays the events: the process states, the messages sent so far (with their senders) and the interface trace (requests and indications, with the server). * `LinkSafe`: every event is at a correct server, a delivered message is addressed to the receiving server, and (APL3, authenticity) a delivered message whose sender is correct was previously sent by that sender. * `NoDup` (APL2, no duplication): no correct server delivers the same message twice. * `NoDupCorrect`: the same, restricted to messages with a correct sender. * `HoldsOverAPL P ℓ Byz Φ`: the interface trace of every execution over authenticated perfect links satisfies `Φ`. -/ -- CSLib
