import Papers.PODC2021.BFTInBlockDAG.Shim /-! # Liveness of gossip (Lemmas 3.6, 3.7, A.8, 4.3 (1), A.17) Runs of the asynchronous system of `Gossip.lean` and the fairness assumptions under which the liveness lemmas of the paper hold. A **run** is an infinite sequence of states `st 0 = Sys.init, st 1, …` and events `ev t` with `Step Byz (st t) (ev t) (st (t+1))`. A run is **fair** (`Run.Fair`) if * (Assumption 1, reliable delivery) every message sent from a correct server to a correct server is received at least once (`deliver`). This is weaker than the paper's assumption, which is per send event; * (weak fairness of lines 6–9 and 10–11 of Algorithm 1) if `validate s B` (resp. `askFwd s B' B`) is continuously enabled from some time on, it eventually happens (`validate`, `askFwd`). The timeout `Δ_B'` of line 10 is abstracted away: lines 10–11 may fire at any time while the guard holds; * (Algorithm 3, lines 10–11) every correct server calls `disseminate()` infinitely often (`disseminate`, the weak fairness of the always-enabled event `disseminate s`). The user's requests and the Byzantine servers are not constrained. Main results (for a fair run `ρ` and correct servers): * Lemma A.8 (`lemma_A_8`): every block of `G_s` is eventually referenced by an own block of `s`; * Lemma 3.6 (1) (`lemma_3_6_1`): a block of `G_s` is eventually received by every correct server; * Lemma 3.6 (2) (`lemma_3_6_2`): a block of `G_s` is eventually in `G_{s'}` of every correct `s'`; * Lemma 3.7 (`lemma_3_7`): eventually `G_s ∪ G_{s'} ⊆ G'_s` (and `G'_s` is a block DAG with `toGraph (G_s ∪ G_{s'}) ≤ toGraph G'_s`); * Lemma 4.3 (1) (`lemma_4_3_1`): reliable delivery of the link implemented by the interpretation; * Lemma A.17 (`lemma_A_17`): a request to a correct server `s` eventually appears in a block of `s` in the block DAG of every correct server. Non-vacuity: `FairExample.run_fair` (a fair run with one correct server). The only invariant needed beyond `Inv` is `Live.FwdOK`: a forwarding request `FWD B` between correct servers is only sent to a server that has `B` in its block DAG; so a single delivery of `FWD B`
