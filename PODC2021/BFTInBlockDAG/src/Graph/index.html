A directed graph is a pair `(V, E)` of a vertex set and an edge set `E ⊆ V × V`. We keep the well-formedness condition `E ⊆ V × V` as a separate predicate `DGraph.WellFormed`. * `DGraph.Acyclic`: `v ⇀⁺ v'` implies `v ≠ v'`. * `DGraph.le` (`G₁ ≤ G₂`, the paper's `G₁ ⩽ G₂`): `V₁ ⊆ V₂` and `E₁ = E₂ ∩ (V₁ × V₁)`. * `DGraph.insert` (Definition 2.1): `insert(G, v, E) = (V_G ∪ {v}, E_G ∪ E)`. * Lemma 2.2 (1)–(3): `DGraph.insert_eq_self`, `DGraph.le_insert`, `DGraph.acyclic_insert`,
