import Papers.PODC2021.BFTInBlockDAG.Shim /-! # The interpretation of a block DAG is an execution over authenticated links This file proves what *does* hold of the embedding (safety part of Lemma 4.3 and Theorem 5.1). Fix a reachable state, a correct server `s` and a label `ℓ`. Replaying, in the order in which `s` inserted them into its block DAG `G_s`, the events of every block built by a correct server (its requests for `ℓ`, then its delivered messages `B.Ms[in, ℓ]` in the order `<_M`) gives a list of events `traceOf` with: * `trace_linkSafe`: it is an execution over authenticated links (`LinkSafe`): every event is at a correct server, every delivered message is addressed to its receiver, and a delivered message from a correct sender was sent before by that sender (Lemma 4.3 (3), authenticity); * `trace_exec`: the process states, the sent messages and the interface (requests and indications) of this execution are those of the interpretation of `G_s` (so in particular `shim(P)` at a correct server `a` indicates exactly what process `a` indicates in this execution, and process `a` is requested exactly what is written in `a`'s blocks); * `lemma_4_3_2_correct`: deliveries of messages with a *correct* sender are not duplicated, if the protocol never sends the same message twice (Cachin et al.'s convention that messages are unique). For Byzantine senders no duplication fails (`Counterexample.lean`). Other ingredients: the insertion order of `G` is topological (`reachable_topo`); a correct server's blocks form a chain (`own_chain`); Lemma 4.3 (3) at the block level (`lemma_4_3_3`). -/ set_option
