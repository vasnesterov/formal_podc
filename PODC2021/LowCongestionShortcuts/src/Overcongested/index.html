Tree edges are identified with their lower endpoints (`v ↔ s(v, parent v)`, `v ≠ root`), so a set of tree edges is a `Finset V`. * `Below T O v w`: `w` is a descendant of `v` in the forest `T \ O` (the path from `w` up to `v` uses no edge of `O`). * `parts T P O v` (`I_e` in the paper): the parts meeting the `T \ O`-subtree of `v`. * `exists_stable`: the paper's greedy (processing tree edges bottom-up, an edge `e` is *overcongested* and added to `O` iff `|I_e| ≥ c`) produces a set `O` with `v ∈ O ↔ v ≠ root ∧ c ≤ |I_v(O)|`; this fixed-point property is all the proof uses. * `exists_rep`: the representative `r_{(e, P_i)}` of a pair `(e, P_i)` of the bipartite graph `B`, chosen *topmost* in `P_i` (the paper says "some representative"; topmost is needed). * `shortcut`: the shortcut `H_i` of case (I) — all ancestor edges of `P_i` in `T \ O` — with its congestion (`card_filter_mem_shortcut_le`), block (`numBlocks_shortcut_le`) and `BlocksMeetPart` (`blocksMeetPart_shortcut`) properties.
