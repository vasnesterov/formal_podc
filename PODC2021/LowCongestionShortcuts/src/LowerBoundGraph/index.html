import Mathlib.Combinatorics.SimpleGraph.Metric import Cslib.Foundations.Combinatorics.SimpleGraph.Ball /-! # The lower-bound graph of Lemma 3.2: its diameter can exceed `D'` Ghaffari–Haeupler, *Low-Congestion Shortcuts for Graphs Excluding Dense Minors*, PODC 2021 (arXiv 2008.03091), Section 3.2, proof of Lemma 3.2. To show that shortcut quality `Ω̃(δ D)` is sometimes necessary, the proof sets `δ = δ' - 2`, `k = ⌊D'/(2δ)⌋`, `D = kδ`, and builds the following graph: * a path `p_1, …, p_{(δ-1)k+1}` (the "top path"); * for each `i ∈ [(δ-1)D+1]` a path `v_{i,1}, …, v_{i,(δ-1)D+1}` (the rows); * for each `j ∈ [δ]`, the nodes `v_{1,(j-1)D+1}, …, v_{(δ-1)D+1,(j-1)D+1}` form a path (the columns); * for all `j, j' ∈ [δ]`, the node `v_{(j'-1)D+1,(j-1)D+1}` is adjacent to `p_{(j-1)k+1}`. The paper then claims that the diameter is at most `1.5 D + 1 ≤ D'`; the computation given is really an eccentricity bound from a central node, not a bound on the diameter. We define the graph faithfully (`lbGraph δ k`, 0-indexed) and show that for `δ' = 5`, `D' = 12` (so `δ = 3`, `k = 2`, `D = 6`; 174 vertices) the nodes `v_{3,3}` and `v_{10,11}` are at distance exactly `15 > 12 = D'` (`paperGraph_dist_eq`, `paperGraph_not_diam_le`). This is a counterexample to the **diameter claim inside the proof** of Lemma 3.2, not to the statement of Lemma 3.2 (which is existential). Numerically (Python BFS, small parameters) the diameter of this construction is about `3D`, and choosing e.g. `k = ⌊(D' - 2)/(3δ)⌋` instead gave diameter `≤ D'` in all tested cases, so the proof is repairable up to constants (not formalized). The lower bound on the distance uses a 1-Lipschitz potential certificate (`SimpleGraph.Reachable.le_add_dist_of_lipschitz`): the BFS distances from `v_{3,3}`, checked edge by edge by `decide`. -/
