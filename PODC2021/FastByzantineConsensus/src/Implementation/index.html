import Papers.PODC2021.FastByzantineConsensus.ProtocolSafety import Papers.PODC2021.FastByzantineConsensus.TwoStep import Cslib.Computability.Distributed.Byzantine.PartialSync.Gossip /-! # A concrete implementation of the protocol in the partially synchronous model We implement the generalized protocol of Kuznetsov–Tonkikh–Zhang (Section 3 + Appendix A) as an `Algorithm` of the shared model `Cslib.Byzantine.PartialSync`, with ideal signatures: * messages are tokens `Tok P V` (signed statements); `auth`: the signer of a message is `Tok.signer`, and a message carries exactly itself as signature token; * every process keeps the finite set `known` of all tokens it has received or emitted and **gossips** it to everybody at every time step (so certificates travel with the votes/requests that need them, and a forwarded vote carries its evidence); * views are driven by the (perfectly synchronized) local clock: view `v` is the time interval `[vL, (v+1)L)` (the paper's unspecified view synchronizer; `L` is a parameter, `6δ + 12` suffices); the leader of view `v` is `pr.leader v`; * at every step, after adding the received tokens, a process performs in order: vote when entering a new view (`actVote`); as leader of view `v > 0`, sign `CertAck` for its own selection (`actLeaderCA`, which plays the role of `CertReq`); as verifier, sign `CertAck(x, v)` for a value the leader certified on a valid vote set (`actVerify`); as leader, propose a certified value (`actPropose`; the leader of view `0` proposes its input in its initial state); acknowledge the first valid proposal of the view (`actAck`); send `Commit` on a commit certificate of the view (`actCommit`). A process decides `x` as soon as its `known` contains a fast (`n − t` acks) or slow (`⌈(n+f+1)/2⌉` commits) quorum for `x`. Main results: `algo_gossips` (with `Cslib.Computability.Distributed.Byzantine.PartialSync.Gossip`), `algo_unforging`, `algo_agreement` (via the refinement `reachable_absState` into the transition system of `Protocol.lean` and `Protocol.consistency`), `algo_validity` (weak validity), `algo_twoStep` (for `δ ≥ 2`), `algo_termination`, hence `algo_fastConsensus`: the protocol is an `f`-resilient `t`-two-step consensus protocol for `n ≥ 3f + 2t − 1`; with `LowerBound.lean` this gives the tight bound `tight_bound`. -/ set_option linter.unusedSectionVars false namespace
