(4)). `load α j` is the paper's `nⱼ`, the number of parties connected to source `j`. * A *source stream* `ω : ℕ → Fin k → Bool`: `ω s j` is the bit produced by source `j` in round `s + 1` (rounds are numbered from `1` in the paper, from `0` here). Party `i` receives `ω s (α i)`. * Full-information protocols: the knowledge `K ω t i` of party `i` at time `t` (the paper's `Kᵢ(t)`, Eqs. (1), (2)) is given by a `FullInfoModel`; the two concrete models are in `Blackboard.lean` and `MessagePassing.lean`. * A symmetry-breaking task is a set `O` of output vectors (the facets of the output complex); `Solves O κ` (Definition 3.1) says that a global state `κ : Fin n → Kn` (a facet of `P(t)`) admits a name-independent decision map `f : Kn → Out` with `f ∘ κ ∈ O`. * `probSolves M O t` is `Pr[P(t) solves O | α]` (Eq. (7)): the fraction of the `2^{kt}` equiprobable source realizations of length `t` whose global state solves `O`. * `EventuallySolvable` is Definition 3.3: this probability tends to `1`. -/ open Finset Filter Topology namespace Podc.RandomizedSymmetryTopology /-! ### Randomness configurations and source streams -/ /-- The number `nⱼ` of parties connected to source `j` under the configuration `α`. -/ def load {n k : ℕ} (α : Fin n → Fin k) (j : Fin k) : ℕ := (univ.filter fun i => α i = j).card /-- A realization of all `k` sources over infinitely many rounds: `ω s j` is the bit of source `j` in round `s + 1`. -/ abbrev Stream (k : ℕ) : Type := ℕ → Fin k → Bool /-- A realization of the `k` sources during the first `t` rounds (the paper's `R₁(1..t), …`). -/ abbrev Window (k t : ℕ) : Type := Fin t → Fin k → Bool /-- Extend a finite realization by `false` bits (the extension is irrelevant at time `t`, see `FullInfoModel.isLocal`). -/ def ext {k t : ℕ} (r : Window k t) : Stream k := fun s => if h : s < t then r ⟨s, h⟩ else fun _ => false theorem ext_of_lt {k t : ℕ} (r : Window k t) {s : ℕ} (h : s < t) : ext r s = r ⟨s, h⟩ := by simp [ext, h] /-- The stream seen from round `s` on. -/ def shiftStream {k : ℕ} (ω : Stream k) (s : ℕ) : Stream k := fun v => ω (s + v) /-! ### Full-information models -/ /-- A synchronous full-information model with `n` parties fed by `k` randomness sources: the knowledge `K ω t i : Know t` of party `i` at time `t` under source stream `ω`, with the three structural properties the paper uses: * `isLocal`: knowledge at time `t` only depends on the first `t` rounds of randomness; * `prev`: knowledge is cumulative (`Kᵢ(t)` contains `Kᵢ(t-1)`); * `shift`: running the same bits from a later starting point yields a refinement — the knowledge at time `s + u` determines the knowledge at time `u` of the run that starts with the bits of rounds `s+1, …, s+u` (this is what the proof of Lemma 3.2 uses when it says that the event `E_s` makes the system reach a solving state). -/ structure FullInfoModel (n k : ℕ) where /-- Knowledge values at time `t`. -/ Know : ℕ → Type /-- Knowledge of party `i` at time `t`. -/ K : Stream k → (t : ℕ) → Fin n → Know t /-- Knowledge at time `t` depends only on the first `t` rounds. -/ isLocal : ∀ ω ω' t, (∀ s < t, ω s = ω' s) → K ω t = K ω' t /-- Knowledge is cumulative. -/ prev : ∀ t, ∃ g : Know (t + 1) → Know t, ∀ ω i, K ω t i = g (K ω (t + 1) i) /-- Shifted runs are coarser. -/ shift : ∀ ω s u, ∃ g : Know (s + u) → Know u, ∀ i, K (shiftStream ω s) u i = g (K ω (s + u) i) /-! (7), equivalently Eq.
