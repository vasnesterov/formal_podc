import Papers.PODC2021.RandomizedSymmetryTopology.MessagePassing import Cslib.Computability.Distributed.PortNumbering.Basic /-! # Lemma 4.3 and Corollary 4.4 in the standard port-numbering model Fraigniaud, Gelles, Lotker, PODC 2021, Section 4.2, restated in CSLib's standard (two-sided) port-numbering model `Cslib.PortNumbering`: the parties form the clique `Kₙ` with ports `0, …, n - 2` at every party, a party may send different messages on different ports, and the receiver learns the port number at the sender's end (`PNGraph.rport`). Algorithms are deterministic, synchronous, with unbounded states and messages. Randomness: party `v` is connected to source `α v`, and gets as its local input the whole random stream `x (α v)` of its source (`x : Fin k → I`). This is stronger than the paper's model (an algorithm may even look at future bits), which only strengthens the impossibility results. ## Main results * `lemma_4_3_standard`: if `g > 0` divides every load `nⱼ`, then there is a port numbering of `Kₙ` such that, for every algorithm, every input assignment `x` of the sources and every round `t`, every class of parties in the same state has size divisible by `g`. * `corollary_4_4_standard`: if `gcd(n₁, …, n_k) > 1`, there is a port numbering of `Kₙ` under which no algorithm ever elects a unique leader, for any realization of the sources. ## Proof Since `g` divides every load, the parties can be arranged as `Fin g × Fin m` so that the source depends only on the second coordinate (`exists_equiv_prod`). Placing party `(q, r)` at position `r + m q` of the *circulant* clique on `ℤ/n` (port `i` of `a` leads to `a + i + 1`, arriving at port `n - 2 - i`), the rotation `a ↦ a + m` is an automorphism (`isCovering_rotate`) preserving the sources. Hence by `Algorithm.state_covering` it preserves all states, so every state class is rotation-invariant, and all orbits of the rotation have size `g`. -/ open Finset Cslib.PortNumbering namespace
