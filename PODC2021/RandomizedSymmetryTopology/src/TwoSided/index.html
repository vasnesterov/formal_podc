import Papers.PODC2021.RandomizedSymmetryTopology.MessagePassing /-! # Theorem 4.2 ("if" direction) in the standard port-numbering model Fraigniaud, Gelles, Lotker, PODC 2021, Section 4.2. In the standard port-numbering model a party may send different messages on different ports, so a full-information protocol sends, on port `p`, its whole history together with `p`. The receiver then learns the port number at the sender's end. Knowledge becomes `Kᵢ(t) = (Kᵢ(t-1), Xᵢ(t), ((q₁, K_{πᵢ(1)}(t-1)), …, (q_{n-1}, K_{πᵢ(n-1)}(t-1))))`, where `q_p` is the port of `πᵢ(p)` leading back to `i` (`backPort`). This is Eq. (2) with the back-ports added. Main result: * `theorem_4_2_if_twoSided`: if `gcd(n₁, …, n_k) = 1`, leader election is eventually solvable for every port numbering. Together with `corollary_4_4_standard` this is Theorem 4.2 in the standard model, the model used by the full version's proof (procedure CreateMatching). ## Proof Run the sources so that, after `k` rounds, parties on different sources have different bits. The partition of the parties into knowledge classes only gets finer, so within `n + 1` further rounds there is a round `t` where it does not change. At such a round, two parties in the same class `C` see, behind each port `p`, parties of the same class `D` with the same back-port `q`. Hence `c ↦ πc(p)` maps `C` injectively into `D` (its left inverse is `d ↦ πd(q)`), and all classes have the same size `m` (`card_class_le`).
