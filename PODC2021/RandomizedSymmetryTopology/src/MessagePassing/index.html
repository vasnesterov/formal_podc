The parties form a clique `Kₙ`; every party `i` numbers its `n - 1` incident channels by a bijection `π i : Fin (n - 1) ≃ {j // j ≠ i}` (`PortNumbering`). Knowledge (Eq. (2)): `Kᵢ(t) = (Kᵢ(t-1), Xᵢ(t), K_{πᵢ(1)}(t-1), …, K_{πᵢ(n-1)}(t-1))`: a party learns the knowledge of the neighbour behind each of its ports, but nothing about the port number at the other end (in a full-information protocol every party sends the same message — its whole history — on every port). Main results: * `mpK_eq_of_equitable`: an *equitable* partition of the parties (constant source on each class, and parties of the same class see the same classes behind the same ports) is never refined. * `swapPorts`: for every configuration `α`, a port numbering for which parties connected to the same source see the same sequence of sources behind their ports; then parties with the same source always have the same knowledge (`mpK_swapPorts_eq`). * `lemma_4_3`: for this numbering, every consistency class (facet of `π̃(ρ)`) has size divisible by `g = gcd(n₁, …, n_k)`. * `corollary_4_4` (the "only if" direction of Theorem 4.2): if `gcd > 1`, some port numbering makes leader election impossible. * `worstCase_iff`: the correct characterization for the model of Eq.
