import Papers.PODC2021.RoundEfficientBA.Protocol /-! # The paper's `t < n/3` protocol fails for `n = 5`, `t = 1` (Corollaries 3.3 and 3.8) With the paper's threshold `n - 2t` (here `3`), `n = 5` parties and one Byzantine party, the 3-round protocol `Prox_9` violates consistency, and the resulting BA protocol (Corollary 3.8 with `κ = 3`: 3 Proxcensus rounds + one coin uniform in `[1, 8]`) fails with probability `3/8` instead of the claimed `2^{-3} = 1/8`. Run (found by exhaustive search): inputs `0, 0, 0, 1` for the honest parties `0, 1, 2, 3`; party `4` is Byzantine and echoes, to the receivers `0, 1, 2, 3`, * round 1: `(1,0), (0,0), (0,0), (0,0)`, * round 2: `(0,1), (0,0), (0,0), (0,1)`, * round 3: `(0,1), (0,1), (0,2), (0,0)`.
