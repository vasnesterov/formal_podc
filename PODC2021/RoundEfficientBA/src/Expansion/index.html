import Papers.PODC2021.RoundEfficientBA.Proxcensus /-! # The expansion step `Prox_s → Prox_{2s-1}` for `t < n/3` (Section 3.3.1, Lemmas 3.1, 3.2) One round of the protocol `Prox_{2s-1}`: every party echoes its `Prox_s` output `(z, h)`, and computes its new output from the multiset of echoes it received. This file treats the step abstractly: a receiver is described by its counting function `cnt A` = the number of received echoes satisfying the predicate `A`; for an honest receiver, `cnt A` lies between the number of honest echoes satisfying `A` and that number plus `f` (the number of Byzantine parties). ## The output rule We index the conditions of the paper's output determination by a *half-level* `m ∈ [b, 2G]` (`s = 2k + b`, `G = ⌊(s-1)/2⌋`). On the *ray* of a value `z` the old slots are the levels `L = 0, …, G` (`OnRay`; for odd `s`, level `0` is the common grade-0 slot of all values, which is the paper's set `S₀`). Then * odd `m = 2g+1`: `|S_{z,g} ∪ S_{z,g+1}| ≥ n-t ∧ |S_{z,g+1}| ≥ θ` (paper: grade `2g+2-b`; for odd `s` and `g = 0` this is line 7 of the protocol), * even `m = 2g < 2G`: `|S_{z,g} ∪ S_{z,g+1}| ≥ n-t ∧ |S_{z,g}| ≥ θ` (paper: grade `2g+1-b`), * `m = 2G`: `|S_{z,G}| ≥ n-t` (paper: line 17, grade `2G+1-b`), and the new grade of condition `m` is `m + 1 - b`. The paper's loop overwrites the output with every satisfied condition in increasing order of grade, so the output is the condition with the largest `m` (`expandOut`). The paper uses the threshold `θ = n - 2t`. ## Results * `expand_isProx` (**Lemmas 3.1 and 3.2, corrected**): with `θ = t + 1`, if the honest old outputs form an `s`-slot Proxcensus, the new outputs form a `(2s-1)`-slot Proxcensus, for every `n > 3t`. * `expand_isProx_paper`: for `n = 3t + 1` the paper's threshold `n - 2t` equals `t + 1`, so the paper's protocol is correct in that case. * `lemma32_counterexample`: for `n = 5`, `t = 1` (so `n > 3t + 1`) the paper's threshold `θ = n - 2t = 3` breaks consistency: from four honest `Prox_5` outputs `(0,1),(0,1),(0,2),(0,2)` two honest receivers obtain grades `3` and `0` in `Prox_9`. -/ namespace RoundEfficientBA variable {D : Type*} /-! ### Definitions -/ /-- The echoed pair `e` lies on the ray of `z` at level `L`: it has grade `L`, and value `z` unless `s` is odd and `L = 0` (the grade-0 slot of odd `s` is common to all values). -/ def onRay [DecidableEq D] (s : ℕ) (z : D) (L : ℕ) (e : D × ℕ) : Bool := decide (e.2 = L ∧ (e.1 = z ∨ (s % 2 = 1 ∧ L = 0))) /-- The echoed pair lies on the ray of `z` at level `L` or `L + 1`. -/ def onPair [DecidableEq D] (s : ℕ) (z : D) (L : ℕ) (e : D × ℕ) : Bool := onRay s z L e || onRay s z (L + 1) e /-- The condition with half-level `m` for value `z` (see the module docstring);
