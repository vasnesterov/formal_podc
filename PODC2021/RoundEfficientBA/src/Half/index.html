import Papers.PODC2021.RoundEfficientBA.Proxcensus import Cslib.Foundations.Data.Finset.Quorum /-! # Proxcensus for `t < n/2` with threshold signatures (Section 3.3.2, Lemmas 3.4–3.6) Protocol `Prox_{2r-1}` (`r ≥ 3` rounds) with an `(n-t)`-out-of-`n` unique threshold signature scheme, treated as an ideal primitive. ## Model Values in a finite domain `D`; parties `P`, `n = |P|`. A certificate `Σ` on `v` is formed from `n - t` signature shares on `v`, a certificate `Ω` on `v` from `n - t` shares `ω` on `v`. Since signatures are unique, a set `{(v, Σ)}` of valid certificates is represented by the set of certified values (`Finset D`); invalid certificates are discarded by the receiver (`I_k` in the paper), so the adversary can only send certificates it can *form*. Adaptive corruption at round granularity: `A.cr q` is the round from which `q` is corrupted (`q` follows the protocol in the rounds `k < A.cr q`; a party with `A.cr q > r` is honest at the end). In a round in which `q` is corrupted the adversary chooses `q`'s messages (strongly rushing: this includes replacing the message of a party it corrupts in that round). It may use * in round 1: signature shares of corrupted parties on any values (`A.sh1 q i`); * in round 2: shares `ω` of corrupted parties on any values (`A.wsh q i`), and certificates `Σ` (`A.sig 2 q i`); * in rounds `k ≥ 2`: certificates `Σ` on values `v` with at least `n - t` shares available (`consSig`: shares sent in round 1 by parties honest in round 1, plus the keys of all parties corrupted by round `k`), and in rounds `k ≥ 3` certificates `Ω` likewise (`consOm`). The protocol (paper's pseudocode): * round 1: send a share on the input; `S¹ = {v | ≥ n-t shares on v received}`; * `ω` is a share on the own input `x`, sent in round 2 iff `S¹ = {x}`; * round 2: send `S¹` and `ω`; `S² = ⋃ received S¹`; `Ω² = {x}` if `≥ n-t` shares `ω` on `x` were received (`Ω` is only formed on the own input, lines 11–12), else `∅`; * rounds `k = 3 … r`: send `S^{k-1}`, `Ω^{k-1}`; `S^k`, `Ω^k` = unions of the received sets; * output: `(z, j)` for the largest `j ∈ [1, r-1]` with `z ∈ S^{r-j}`, `z ∈ Ω^{r-j+1}` and `S^{j+1} ⊆ {z}`; otherwise `(d₀, 0)` (the paper's default `0`). Every party sends to itself, so the sets of a party honest in round `k+1` grow from round `k` to round `k+1`. ## Results * `half_validity` (**Lemma 3.5**) and `two_run_cons` (**Lemma 3.6**), together `half_isProx` (**Lemma 3.4**): for `2t < n`, `r ≥ 3` and at most `t` corruptions, the outputs of the parties honest at the end form a `(2r-1)`-slot Proxcensus. -/ namespace RoundEfficientBA.Half variable {P D : Type*} [Fintype P] [DecidableEq P] [Fintype D] [DecidableEq D] /-- The adversary's choices (see the module docstring). -/ structure Adv (P D : Type*) where /-- `q` follows the protocol in the rounds `k < cr q`. -/ cr : P → ℕ /-- Round 1: values on which the corrupted `q` gives signature shares to `i`. -/ sh1 : P → P → Finset D /-- Round `k ≥ 2`: values with a certificate `Σ` sent by the corrupted `q` to `i`. -/ sig : ℕ → P → P → Finset D /-- Round 2: values on which the corrupted `q` gives shares `ω` to `i`. -/ wsh : P → P → Finset D /-- Round `k ≥ 3`: values with a certificate `Ω` sent by the corrupted `q` to `i`. -/ om : ℕ → P → P → Finset D variable (n t : ℕ) (x : P → D) (A : Adv P D) /-- `S¹` of party `i`: the values with at least `n - t` shares received in round 1. -/ def S1 (i : P) : Finset D := Finset.univ.filter fun v => n - t ≤ (Finset.univ.filter fun q => (1 < A.cr q ∧ x q = v) ∨ (A.cr q ≤ 1 ∧ v ∈ A.sh1 q i)).card /-- Party `q` sends the share `ω` (on its input) in round 2: its `S¹` is exactly `{x q}`. -/ def SignsOm (q : P) : Prop := S1 n t x A q = {x q} instance (q : P) : Decidable (SignsOm n t x A q) := by unfold SignsOm;
