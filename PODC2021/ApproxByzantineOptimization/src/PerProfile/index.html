Every pair of agents has `arg min = {0}`, so the constant algorithm `0` is `(1, 0)`-resilient (exactly fault-tolerant). But `arg min Q₀ = {a}` is at distance `a` from `arg min (Q₀ + Q₁) = {0}`, so the costs are not `(2, ε)`-redundant for `ε < a`.
