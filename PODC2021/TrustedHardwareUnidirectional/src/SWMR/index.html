Every access is one atomic step; the scheduler interleaves steps arbitrarily. Byzantine processes (set `F`, any size) may overwrite their own object with anything at any time. Fairness: every correct process takes infinitely many steps. **Protocol** (the paper's, from Aguilera et al.). In round `r`, process `p` 1. appends `(r, m)` to `o_p` (one write of the whole list); 2. reads `o_q` for every `q` (one atomic read per object, in the order `ord`), recording `m'` if it finds some
