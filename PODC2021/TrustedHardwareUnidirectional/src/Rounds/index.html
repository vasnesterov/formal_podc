import Mathlib -- CSLib candidate: generic model (SRB systems / round-layer spec), see README. /-! # Unidirectional rounds: the specification (Definition 2) Ben-David and Nayak (PODC 2021, BA; arXiv 2105.10566) call a system *unidirectional* if it can implement rounds such that for any two correct processes `p ≠ q` that both send in round `r`, `p` receives `q`'s round-`r` message before `p` starts round `r + 1`, or `q` receives `p`'s before `q` starts round `r + 1`. We state "a system implements unidirectional rounds" for an abstract transition system (`RoundSystem`) whose round layer exposes, for every process `p`, the list `rounds c p` of its *completed* rounds: entry `r` is the function `q ↦ (q's round-r message, if received by p before p ended round r)`. The messages are chosen by an arbitrary *client* (`Client`): the message of `p` for round `r` may depend on everything `p` received in rounds `0, …, r - 1`. `RoundSystem.ImplementsUnidirectional` asks for * `prefix_of_step`: completed rounds are never changed; * `unidirectional`: Definition 2; * `integrity`: a message received from a correct `q` in round `r` really is `q`'s round-`r` message (without it, "receiving" could be faked); * `live`: in every fair execution every correct process completes every round. Concrete systems: sequenced reliable broadcast (`SRB.lean`) and SWMR shared memory (`SWMR.lean`). -/ namespace Podc.TrustedHW /-- A client of the round layer: the message a process sends in round `r`, as a function of the results of its rounds `0, …, r - 1` (a list of length `r`). -/ abbrev Client (P V : Type) := List (P → Option V) → V /-- An abstract system implementing rounds: configurations, initial configurations, steps, a fairness condition on executions, and the output of the round layer: `rounds c p` is the list of rounds completed by `p`, entry `r` mapping each `q` to the round-`r` message of `q` received by `p` before `p` ended round `r` (if any). -/ structure RoundSystem (P V : Type) where /-- Global configurations. -/ Config : Type /-- Initial configurations. -/ Init : Config → Prop /-- One atomic step. -/ Step : Config → Config → Prop /-- Fairness of infinite executions. -/ Fair : (ℕ → Config) → Prop /-- The completed rounds of each process. -/ rounds : Config → P → List (P → Option V) namespace RoundSystem variable {P V : Type} (S : RoundSystem P V) /-- Configurations reachable from an initial one. -/ def Reachable (c : S.Config) : Prop := ∃ c₀, S.Init c₀ ∧ Relation.ReflTransGen S.Step c₀ c /-- An infinite execution: it starts in an initial configuration and each transition is a step or a stutter. -/ def IsExec (e : ℕ → S.Config) : Prop := S.Init (e 0) ∧ ∀ t, S.Step (e t) (e (t + 1)) ∨ e (t + 1) = e t /-- **Definition 2** (unidirectional communication), for the correct processes `correct` and the clients `cl`.
