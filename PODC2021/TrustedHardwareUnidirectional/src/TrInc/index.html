import Mathlib /-! # Theorem 1: SRB implements the TrInc interface (Algorithm 2) The implementation in the proof of Theorem 1: `Attest(c, m)` SRB-broadcasts `(c, m)`; a checker `p` processes the messages of `q` in SRB order and *stores* `(k, c, m)` (the `k`-th message of `q`) iff `C[q] < c`, where `C[q]` is the largest counter stored so far (initially `0`). `CheckAttestation((k, c, m), q)` returns whether `(k, c, m)` is stored. SRB delivers to every correct checker a prefix `L` of one common sequence `lq` (the log of `q`; see `SRB.lean`), so the stored set at `p` is `accepted L`. We prove the properties of TrInc for these stored sets: * `accepted_prefix`: checkers agree — the stored lists of two correct checkers are prefixes of one another (consistency; "a Trinket does not produce two valid attestations …" holds globally); * `accepted_counter_strictMono`: stored counters strictly increase, so no two valid attestations of `q` carry the same counter (non-equivocation); * `accepted_sound`: a valid attestation `(k, c, m)` is the `k`-th message `q` broadcast (paper's property (2): `CheckAttestation(a, q)` is false unless `q` attested `a`; for correct `q`, SRB property 4); * `accepted_complete`: if `q` is correct and attests with strictly increasing positive counters, every message of `q` delivered by `p` is valid at `p` (paper's property (1), with SRB property 1 giving the eventual delivery); * `accepted_prev`: the stored attestations form a chain: each one's predecessor in the stored list is the previous attestation (`prev` of Algorithm 2). -/ namespace Podc.TrustedHW namespace TrInc variable {M : Type} /-- The stored attestations `(k, c, m)` after processing `L`, starting at index `k₀` with stored maximum `C`. -/ def acceptedFrom : ℕ → ℕ → List (ℕ × M) → List (ℕ × ℕ × M) | _, _, [] => [] | C, k, (c, m) :: L => if C < c then (k, c, m) :: acceptedFrom c (k + 1) L else acceptedFrom C (k + 1) L /-- The stored attestations after processing the delivered prefix `L` (initially `C[q] = 0`). -/ def accepted (L : List (ℕ × M)) : List (ℕ × ℕ × M) := acceptedFrom 0 0 L /-- The value of `C[q]` after processing `L`. -/ def maxFrom : ℕ → List (ℕ × M) → ℕ | C, [] => C | C, (c, _) :: L => maxFrom (max C c) L lemma acceptedFrom_append (C k : ℕ) (L L' : List (ℕ × M)) : acceptedFrom C k (L ++ L') = acceptedFrom C k L ++ acceptedFrom (maxFrom C L) (k + L.length) L' := by induction L generalizing C k with | nil => simp [acceptedFrom, maxFrom] | cons a L ih => obtain ⟨c, m⟩ := a simp only [List.cons_append, acceptedFrom, maxFrom, List.length_cons] split_ifs with h · rw [ih, max_eq_right h.le, show k + 1 + L.length = k + (L.length + 1) by omega];
