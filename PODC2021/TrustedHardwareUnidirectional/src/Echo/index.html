import Papers.PODC2021.TrustedHardwareUnidirectional.SRB /-! # Sequenced reliable broadcast implements unidirectional rounds whenever `n > 2f` This file refutes the Claim of Section 4.1 of Ben-David–Nayak ("Sequenced reliable broadcast cannot implement unidirectionality in a system with `n > 2f` and `f > 1`"). **The echo protocol** (`echoProtocol f`). In round `r`, process `p` 1. SRB-broadcasts its signed round-`r` message `val r w`; 2. whenever it delivers `val r w` from some `s`, it SRB-broadcasts `echo r s w` (a relay of `s`'s signed message); 3. ends round `r` as soon as it has delivered, from `n - f` distinct senders, an echo of its own round-`r` message. Its round-`r` result is everything it has delivered so far: `p` has received `q`'s round-`r` message if it delivered `val r w` from `q` or any `echo r q w`. **Why it works.** If `p` and `q` both end round `r`, the sets of senders whose echoes they counted have `n - f` elements each, so (as `n > 2f`) they share a sender `s`, possibly Byzantine. SRB delivers `s`'s messages to `p` and to `q` as prefixes of *one* sequence; whichever of `echo r p _`, `echo r q _` comes first in that sequence was delivered by both. So `q` delivered `echo r p _` before ending its round, or `p` delivered `echo r q _` before ending its own. Signatures guarantee that relayed messages are genuine. Liveness: the `≥ n - f` correct processes echo every message of `p`. The flaw in the paper's proof: in its Scenario 1 the processes of `C₂` need not end the round while their messages to `Q` are delayed — here they wait for echoes from `Q`. -/ namespace Podc.TrustedHW namespace Echo variable {P V : Type} /-- Messages of the echo protocol. -/ inductive Msg (P V : Type) where /-- The sender's own (signed) round-`r` message. -/ | val (r : ℕ) (w : V) /-- A relay of `q`'s signed round-`r` message `w`. -/ | echo (r : ℕ) (q : P) (w : V) deriving DecidableEq /-- Local state: delivered messages per sender, and snapshots of the deliveries at the end of each completed round. -/ structure State (P V : Type) where /-- Messages delivered so far, per sender. -/ hist : P → List (Msg P V) /-- `done[r]` = `hist` at the moment round `r` ended. -/ done : List (P → List (Msg P V)) open Classical /-- The senders from which an echo of `p`'s round-`r` message has been delivered. -/ noncomputable def echoers (H : P → List (Msg P V)) (r : ℕ) (p : P) [Fintype P] : Finset P := Finset.univ.filter fun s => ∃ w, Msg.echo r p w ∈ H s /-- The round-`r` message of `q` received, according to the deliveries `H`. -/ noncomputable def recv (r : ℕ) (H : P → List (Msg P V)) (q : P) : Option V := if h : ∃ w, Msg.val r w ∈ H q ∨ ∃ s, Msg.echo r q w ∈ H s then some h.choose else none /-- The round results from the snapshots. -/ noncomputable def results (d : List (P → List (Msg P V))) : List (P → Option V) := d.mapIdx fun r H => recv r H /-- The echo produced when delivering `m` from `s`. -/ def echoOut (s : P) : Msg P V → List (Msg P V) | .val r w => [.echo r s w] | .echo .. => [] /-!
