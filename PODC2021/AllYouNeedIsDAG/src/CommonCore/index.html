import Papers.PODC2021.AllYouNeedIsDAG.Ordering /-! # DAG-Rider: the common core of a wave (Lemma 2) Keidar, Kokoris-Kogias, Naor, Spiegelman, *All You Need is DAG*, PODC 2021 (arXiv:2102.08325v2), Lemma 2: "Let `p_i` be a correct process that completes wave `w`. Then there is a set `V ⊆ DAG_i[round(w,1)]` and a set `U ⊆ DAG_i[round(w,4)]` s.t. `|V| ≥ 2f+1`, `|U| ≥ 2f+1` and `∀ v ∈ V, ∀ u ∈ U: strong_path(u, v)`." The paper argues via the common-core abstraction. We prove a stronger, *robust* version that is what the probabilistic argument (Claim 6, see `Coin.lean`) really needs: * `core f C w E3` is the set of sources `s` such that the round-`(w,1)` vertex of `s` is strongly reached by at least `f + 1` of the round-`(w,3)` vertices with sources in `E3`. It only depends on the strong past of these round-`(w,3)` vertices (`core_congr`), so it is fixed as soon as `2f + 1` vertices of round `(w,3)` exist — before the coin of wave `w` is revealed. * `core_card`: `|core| ≥ 2f + 1` (double counting, `n ≤ 3f + 1`). * `sPath_of_mem_core`: **every** vertex of round `(w,4)` with `≥ 2f + 1` strong edges, created by anybody at any later time, strongly reaches all vertices of the core. * `commit_of_mem_core`: if the coin of wave `w` lands in the core, the commit rule (line 36 of Algorithm 3) holds in every closed, valid local DAG with `2f + 1` vertices of round `(w,4)`. * `lemma2`: the paper's Lemma 2. Throughout, `n = |P| ≤ 3f + 1` (the paper has `n = 3f + 1`).
