The ordering layer of a process is a deterministic function of the local DAGs it holds at the moments `wave_ready(w)` is signalled (`w = 1, 2, …`; the spurious initial call `wave_ready(0)` of Algorithm 2 never commits anything and is omitted). A *snapshot sequence* `D : ℕ → Finset (Vtx P)` gives, for every wave `w`, the local DAG `DAG_i` when wave `w` became ready. * `wround w k = 4(w-1) + k` is the `k`-th round of wave `w`. * `leader coin D w` is `get_wave_vertex_leader(w)`: the vertex of round `wround w 1` of the coin-chosen process `coin w` (global perfect coin: one value per wave), if it is in `D`. * `commitCount C D v w` counts the vertices of `D` of round `wround w 4` with a strong path to `v` (commit rule: `≥ 2f + 1`, line 36). * `chain` is the loop of lines 39–43, `deliverAll` is `order_vertices` (lines 51–57), where the "some deterministic order" is an arbitrary function `sortV : Finset (Vtx P) → List (Vtx P)` listing each finite set without repetitions (`SortSpec`). * `waveReady` is the handler `upon wave_ready(w)`
