import Papers.PODC2021.ScannableBinaryObjects.Defs import Cslib.Computability.Distributed.SharedMemory.LinPoints /-! # Implementation 1 of Ovens (PODC 2021): the algorithm Implementation 1 (Section 4.1) is a lock-free `s`-scanner, `u`-updater implementation of the scannable binary object `[O 0, …, O (k-1)]` from `s + k` one-bit base objects: * `k` base objects `B i` of the same type as the components (`Obj O Sc (.inl i)`), * one binary *handshaking* register `R j` per scanner `j ∈ Sc` (`Obj O Sc (.inr j)`). `Update(i, op)`: write `1` to every handshaking bit, one at a time, then apply `op` to `B i` and return its response. `Scan` by `p`: collect `B 0, …, B (k-1)` into `b`, write `0` to `R p`, then repeatedly collect `B 0, …, B (k-1), R p`; return `b` after `u + 1` consecutive such collects that read `b` and `0`; restart as soon as some `B i` differs from `b i` or `R p` reads `1`. The paper assumes the components are *readable*; we make this explicit: `BitObj.Readable O` provides an invocation `rd` that does not change the value and whose response determines it. Local states (`Loc`): `idle`; `upd i o rest` (update, handshaking bits in `rest` still to be written; with `rest = []` the next step applies `o` to `B i`); `scan1 m b` (first collect, next read is `B m`; for `m ≥ k` the next step writes `0` to `R p`); `scan2 c m b` (validation phase, `c` successful collects so far, next read `B m`, or `R p` for `m ≥ k`); `done r` (return `r`). The initial values of the handshaking bits are a parameter `h₀` (the proofs never use them). -/ set_option linter.unusedSectionVars false namespace Cslib.SharedMemory.Scannable open Cslib.SharedMemory /-- A *readable* 1-bit object: the invocation `rd` does not change the value and its response determines the value (`val`).
