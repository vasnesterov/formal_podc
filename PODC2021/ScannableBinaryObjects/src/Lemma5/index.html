import Papers.PODC2021.ScannableBinaryObjects.Exec /-! # Lemma 5 of Ovens (PODC 2021), relativized to a stage The paper proves Lemma 5 for an implementation `I` and then (Lemma 7) simulates a smaller implementation `I'` with one component, `h` processes and `h` base objects fewer. We avoid building `I'`: instead we prove Lemma 5 for a *stage* of `I` — a reachable configuration `X` (reached by `ε`), a set `A` of *active* processes (containing the updater `p₀`), a set `F` of *frozen* base objects and a number `k'` of *live* components such that * all active processes are idle in `X`, the components `≥ k' - 1` are `0` in `X`, and * no execution from `X` by active processes that only updates live components changes `F`. The initial configuration with all processes active, no frozen object and `k' = k` is a stage. The paper's executions of `I'` are exactly the restricted executions (`Lim A k'`) of `I` from the stage, so Lemma 5 for stages is Lemma 5 for `I'`. `vec k' t` (`t < 2^(k'-1)`) are distinct vectors with `1` in the top live component `k' - 1` and `0` above it (paper: `V_{t+1}`);
