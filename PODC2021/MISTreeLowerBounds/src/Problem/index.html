import Mathlib /-! # Problems in the round-elimination formalism and the operators `R`, `R̄` (§2.2–2.3) A problem on `Δ`-regular graphs (§2.2) is given by * a set of *node configurations* `node : Set (Fin Δ → Λ)` (a node writes one label on each of its `Δ` incident half-edges; the paper's configurations are unordered words, i.e. `node` is meant to be permutation invariant, but nothing below needs this), and * a symmetric *edge constraint* `edge : Λ → Λ → Prop` (the unordered edge configurations). The alphabet of a problem is the whole label type `Λ`. The operators of §2.3: * `P.R` (the paper's `R(Π)`): labels are nonempty sets of labels; edge configurations are the *maximal* pairs `A₁A₂` such that every `a₁a₂ ∈ A₁ × A₂` is an edge configuration of `P` (`edgeMax`); the alphabet `Σ_{R(Π)}` consists of the sets occurring in these configurations (`alphR`); node configurations are the tuples of sets of `Σ_{R(Π)}` admitting a choice in `P.node`. * `P.Rbar` (the paper's `R̄(Π)`): node configurations are the *maximal* tuples `B₁ … B_Δ` of nonempty sets such that every choice lies in `P.node` (`nodeMax`); the alphabet consists of the sets occurring in these configurations (`alphRbar`); `A₁A₂` is an edge configuration iff both sets are in the alphabet and some choice is an edge configuration of `P`. Since node constraints are universal in `R̄`, a set containing a label outside `Σ_{R(Π)}` never occurs in a node configuration of `R̄(R(Π))`, so taking all nonempty sets of `Finset Λ` instead of `2^{Σ_{R(Π)}}` gives the same problem. We also define 0-round reductions (`ZeroRoundReduction`): "`Π'` can be solved in 0 rounds given a solution of `Π`" in the port-numbering model in which the port numbers are the colours of a given `Δ`-edge colouring (the model of `Model.lean`): each node maps its own `Π`-configuration (indexed by colours) to a `Π'`-configuration, and the edge of colour `c` joins the half-edges of colour `c` of
