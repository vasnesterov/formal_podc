Instead it introduces a problem `Π_rel` whose labels are the six sets `MUBQ, XMOUABPQ, PQ, OUABPQ, ABPQ, UBPQ` of labels of `R(Π_Δ(a, x))` (in the renaming `L8` of Lemma 6) and which is `Π⁺_Δ(a, x)` after renaming `M, X, P, O, A, C` to these sets (`toRel8`, `toRel`). The argument has two parts: * every node configuration of `R̄(R(Π_Δ(a, x)))` can be *relaxed* to a node configuration of `Π_rel` (Definition 7), i.e. each set of the configuration is contained in the corresponding set of a configuration of `Π⁺` (`lemma_8_relax`; we choose the `Π⁺`-label per position, which absorbs the permutation of Definition 7); * the edge constraint of `Π_rel` is obtained from the edge constraint of `R(Π_Δ(a, x))` by the method of §2.3 (two sets are compatible iff they contain an edge configuration of `R(Π_Δ(a, x))`), and after renaming it is the edge constraint of `Π⁺` (`toRel_edge`). Hence replacing each set by the chosen superset is a 0-round reduction (`lemma_8_reduction`). The relaxation part works with the sets `Y8 i ⊆ L8` corresponding to the sets `Y i` of a node configuration of `R̄(R(Π))`: they are nonempty, right-closed for the inclusion order of the renamed sets (Observation 4, Figure 5) and every choice satisfies the node constraint `N8` of `R(Π_Δ(a, x))` (Lemma 6).
