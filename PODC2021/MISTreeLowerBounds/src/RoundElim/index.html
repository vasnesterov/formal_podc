import Papers.PODC2021.MISTreeLowerBounds.Model /-! # Round elimination (forward direction of Theorem 3) Theorem 3 of the paper (Brandt's round elimination theorem, [13, Theorem 4.3]) says that if `Π` can be solved in `T ≥ 1` rounds on (high-girth) `Δ`-regular graphs, then `R̄(R(Π))` can be solved in `T - 1` rounds. We prove this in the model of `Model.lean`: the infinite `Δ`-regular tree with a `Δ`-edge colouring (port numbers = colours) and an arbitrary edge orientation as input (`Problem.SolvableIn.Rbar_R`, `Problem.SolvableIn.Rbar_R_sub`). Since the tree is infinite and the orientation is completely free, no independence assumption is needed: the views of the two endpoints of an edge, and the views of the branches of a node, can be glued freely. ## Proof Let `A` be a `(t+1)`-round algorithm solving `Π`, and look at the root `1` and its edge `e_c = {1, gen c}` of colour `c`. 1. *Edge step.* Let `K_c` (`edgeBall t c`) be the nodes within distance `t` of `e_c`. The set `rawSet` of outputs `A J c` over all inputs `J` agreeing with `I` on `K_c` is the set of labels the root might output on `e_c`, knowing only the `t`-neighbourhood of `e_c`. Every label of `rawSet I c` is edge-compatible with every label of `rawSet (I.shift (gen c)) c` (the set of the other endpoint): the two inputs can be glued along `e_c` (`glue`). Extending the pair to a maximal one (`maxPair`), with the orientation of `e_c` breaking the symmetry, gives the half-edge labels `halfLabel I c`, which form an edge configuration of `R(Π)` along every edge. 2. *Node step.* The set `nodeSet I c` of the possible `halfLabel J c` over all inputs `J` with the same radius-`t` view as `I` depends only on that view. Every choice of one label in each `nodeSet I c` is realized by a single input obtained by gluing the branches of the root (`branchGlue`), so it is a node configuration of `R(Π)`: `nodeSet I` satisfies the universal node condition of `R̄(R(Π))`. Extending it to a maximal configuration (`maxNode`) gives a `t`-round algorithm for `R̄(R(Π))`. -/ -- CSLib candidate (round elimination on the oriented Δ-edge-coloured Δ-regular tree) namespace
