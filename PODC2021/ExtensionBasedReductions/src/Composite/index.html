import Podc.Computability.Distributed.NIS.Model /-! # Composing an IS protocol with an NIS protocol Brusse–Ellen, PODC 2021, Section 6 (special case "`A₁` is an IS protocol") and Section 7. Let `A₁` (decision function `δ₁`) be an IS protocol in which every process terminates exactly after its `t`-th scan (`IsIS δ₁ t`), and `A` (decision function `δA`) any NIS protocol whose inputs are the outputs of `A₁`. The composition `A ∘ A₁` (here with an additional local post-processing `h` of the outputs of `A`) is the full-information protocol in which a process first runs `A₁` on the objects `S₁, …, S_t` and then runs `A`, with input its output from `A₁`, on `S_{t+1}, S_{t+2}, …`: object `S_{t+ℓ}` plays the role of the `ℓ`-th object of `A`. Its decision function `compP` reads the state in `A` off the full-information state (`toAS`). Main facts: * `Ycfg C₁ CA`: the configuration of `A ∘ A₁` determined by an `A₁`-configuration `C₁` (states up to round `t`) and an `A`-configuration `CA` (states of the processes that finished `A₁`); * `stepY_A1`, `stepY_A`: a step of the composition is a step of `A₁` or a step of `A`; * `reach_decomp`: every reachable configuration of `A ∘ A₁` is of this form. -/ namespace
