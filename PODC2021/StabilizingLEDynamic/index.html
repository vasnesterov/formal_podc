Stabilizing Leader Election with Weak Assumptions on Network Dynamics — PODC 2021

Karine Altisen, Stéphane Devismes, Anaïs Durand, Colette Johnen, Franck Petit. On Implementing Stabilizing Leader Election with Weak Assumptions on Network Dynamics. PODC 2021. The PODC numbering (Theorem 2.1, Lemma 3.2, Theorems 3.3–3.11, 4.1) is in the docstrings. Copy of the paper: paper.pdf.

Verdict: 🔧 Easy fix. All main results are proved after local changes: the class hierarchy (Theorem 1), all impossibility results (Theorems 2–5, Corollaries 1–3) and the correctness of Algorithm LE (Corollary 6), with the speculative 6Δ + 2 bound of Theorem 7. The false Lemma 7 needs one added condition, and the proofs of Lemmas 12 and 16 and of Theorem 1 need small repairs. The self-stabilizing algorithms cited from the authors' ICDCN 2021 paper were not checked.

Mistakes in the paper

🔧 Lemma 7 and Lemma 16 (own relayed records)

Lemma 7 says that if p receives a record whose map contains id ≠ id(p), then id ∈ Gstable(p) for the next Δ configurations; this fails when the record is p's own relayed record, because line 12 skips records with id = id(p), and the proof of Lemma 16 overlooks the same thing.

Impact. Every use of Lemma 7 has id ≠ id(p), and we add this hypothesis (lemma_7). Lemma 16's statement is true.

Details

Lemma 7:

  • Setup: 0-indexed rounds, Δ = 2, V = {p, a, k}, empty initial maps.

  • Edges: k → p in round 1, p → a in round 3, a → p in round 4.

  • In round 4, p receives its own record ⟨p, {p, k}, 1⟩ back, and it is skipped. The entry of k expired at configuration 4, so k ∉ Gstable(p) at configuration 5.

Lemma 16: the proof takes the last round in which q received any record mentioning id(p) and assumes that line 17 refreshed Gstable(q)[id(p)] in that round, but line 12 skips q's own relayed records.

Repair

Restricting Lemma 16's proof to records with id ≠ id(q) fixes it; Lemma 5's proof already does so. (lemma_5, lemma_16)

✏️ Slips

  • Theorems 2–5, identifier domain IDSET: the paper only says IDSET is "an arbitrary totally ordered domain", but the impossibilities fail when |IDSET| = n: every system is then the whole of IDSET, there are no fake identifiers, and "lid := min IDSET" is self-stabilizing in every class (constAlg_selfStab). Every impossibility proof swaps a process for a fresh one, so it needs more identifiers than processes. We assume an infinite identifier domain, and all impossibilities hold.

  • An intermediate claim of Lemma 8's proof is wrong: "no record tagged with a fake ID in any msgs after Δ rounds" fails at γ_{Δ+1}. An initial record can still be there with timer 0, but it is never sent. Lemma 8 itself (for i > 4Δ) holds. (lemma_8a_imprecise, fake_G)

  • Lemma 10's proof considers rounds i > 2Δ + 1 but concludes t_r ≤ 2Δ + 1. The argument does work from 2Δ + 1. (lemma_10)

🔧 Lemma 12 (quantifiers in the third case)

In the third case the distance d = d̂_i(r, q) depends on i, yet the proof concludes "∀ i ≥ t_p + d + 1".

Impact. Choosing the source round as (target − Δ) fixes it. (lemma_12)

🔧 Theorem 1 (proof for two vertices)

The proof works inside "a set V of n > 1 vertices", but with n = 2 the per-V hierarchy collapses (theorem_1_false_card_two, J_src_eq_snk_of_card_two, not_theorem_1_card_two).

Impact. Classes range over all vertex sets, so Theorem 1 itself holds (theorem_1_classes). It follows from the per-V version for n ≥ 3 (theorem_1).

Details

With n = 2 the per-V hierarchy collapses in two ways.

  • "Recurrent" equals "quasi-timely": the direct edge must appear infinitely often.

  • "Has a source" equals "has a sink": the out-star witness G(1S) has a sink.

Full list of differences (including modelling choices and minor imprecisions): differencies.md.

The formalizationmodel, Lean names of the results, trust

Theorem 4 needs n ≥ 3, as the paper says. For n = 2, LE is pseudo-stabilizing in J^B_{*,1}(Δ) (theorem_4_card_two).

Model.

  • Dynamic graphs. ι is the identifier domain (processes = identifiers), infinite. A system is V : Finset ι with |V| = n. A dynamic graph is a sequence of loopless digraphs on V (G t p q: edge p → q in round t, 0-indexed).

  • Journeys and classes. Journeys Reach are the shared Cslib.DynNet.Journey, and tdist (Cslib.DynNet.tdist, Cslib/Computability/Distributed/DynamicNetworks/Journey.lean) is d̂. The nine classes J k τ Δ V transcribe Table 1 and are proved suffix-closed (J_shift).

  • Communication. Synchronous, deterministic, full-information rounds (CSLib Cslib.HeardOf). Every process broadcasts its whole state to its current out-neighbours, and receivers know the senders. Codes may depend on the process. Each algorithm is designed for a fixed n and Δ and does not know V (the paper's well-formedness). Full information only strengthens the impossibilities.

  • No failures besides transient ones. The initial configuration is arbitrary, and so are all local states, including the initial msgs of Algorithm LE (finite maps, timers in {0, …, Δ}).

  • Stabilization. For each vertex set V with |V| = n, the executions execs A C V (all dynamic graphs of the class, all initial configurations) form a class of executions, and the definitions are the shared execution-class notions of Cslib/Computability/Distributed/SelfStabilization/Defs.lean. SelfStab is Definition 1 (SelfStabilizing: legitimate set, convergence, correctness). PseudoStab is Definition 2 (PseudoStabilizing: every execution has a suffix satisfying SP_LE). PseudoStabWithin T (PseudoStabilizingWithin) bounds the pseudo-stabilization phase by T. The unfolded forms are selfStab_iff, pseudoStab_iff, pseudoStabWithin_iff.

  • Weaker than the paper. There is one state type for all processes, while the paper allows a set per process. This is equivalent up to a tagging reduction, which is not formalized; see differencies.md.

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice, Quot.sound. The hypotheses are satisfiable:

  • LE is a concrete algorithm, and the classes are nonempty (e.g. K_mem_J1sB, PK_mem_J1sB).

  • The impossibilities hold for every nonempty state type over any infinite identifier domain.

The dynamic-graph model reuses CSLib's Cslib.HeardOf (conf, conf_agree, conf_splice).

CSLib candidates. The nine timeliness classes (Model.lean, Classes.lean) would fit next to Cslib.DynNet (journeys and temporal distance are already shared, Cslib/Computability/Distributed/DynamicNetworks/). Finite maps with finite support (LE.FMap) are too ad hoc.
