Given a (deterministic) synchronous SA algorithm `Π` with state set `Q`, the synchronizer `Π*` has state set `Q × Q × Turn k`: a state `(q, q', ν)` consists of the current simulated `Π`-state `q`, the previous simulated `Π`-state `q'` and an AlgAU turn `ν`. Every node runs AlgAU on the third coordinate; when AlgAU performs an AA transition (the only transitions that advance the clock, from the able turn `ν` to the able turn `ν' = φ(ν)‾`), the node moves from `(q, q', ν)` to `(p, q, ν')`, where `p = δ_Π(q, S)` and `S` is the *simulated signal*: the set of `r` such that the node senses some `Π*`-state `(r, ·, ν)` or `(·, r, ν')`. Otherwise the first two coordinates are kept. The output of `(q, q', ν)` is `ω(q)` if `ν` is able (and `q` is an output state of `Π`). The state space has `|Q|² (4k - 2) = O(D |Q|²)` states. ## Main results * `synchronizer`, `synchOutput`: the construction. * `synchronizer_isRun_auPart`: the third coordinate of an execution of `Π*` is an execution of AlgAU. * `allGood_stab`: the configuration of AlgAU is good from time `R(N(D))` on (extracted from the proof of Theorem 1.1). * `corollary_1_2_general`, `corollary_1_2`: **Corollary 1.2 of [EK21]** for deterministic `Π` and *static* tasks (outputs eventually constant): if `Π` synchronously stabilizes within `f` rounds, then `Π*` stabilizes under every fair schedule within `N(D) + D + f` rounds, to an output vector that `Π` would also produce. ## Proof After `T = R(N(D))` the AlgAU component is good forever.
