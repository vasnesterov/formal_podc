import Cslib.Computability.Distributed.SelfStabilization.StoneAge import Mathlib /-! # Corollary 1.2 of [EK21] fails for arbitrary (non-static) tasks Corollary 1.2 claims that *every* task with a synchronous self-stabilizing SA algorithm on `D`-bounded diameter graphs has an asynchronous one. Counterexample for `D = 1` (complete graphs), task "all nodes output the same value at all times, and the outputs change infinitely often": * `toggle_sync`: the synchronous algorithm `δ(b, S) = ¬(true ∈ S)` solves it on every complete graph (after one round all nodes agree, then they toggle together). (It does not work on, e.g., `P₃`; the counterexample only needs the class of complete graphs, i.e. `D = 1`.) * `no_async_alg`: on `K₂`, under any schedule activating at most one node per step (e.g. the fair round-robin schedule, `no_async_alg_roundRobin`), no deterministic SA algorithm solves it: the first output change after the outputs agree makes them disagree. The synchronizer of Section 4 is correct for static tasks (`Synchronizer.lean`). -/ namespace ThinUnison open Cslib.StoneAge theorem signal_top {V Q : Type*} (C : V → Q) (v : V) : signal (⊤ : SimpleGraph V) C v = Set.range C := by ext q simp only [mem_signal, SimpleGraph.top_adj, Set.mem_range] constructor · rintro ⟨u, -, rfl⟩;
