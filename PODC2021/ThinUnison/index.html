A Thin Self-Stabilizing Asynchronous Unison Algorithm — PODC 2021

Yuval Emek, Eyal Keren. A Thin Self-Stabilizing Asynchronous Unison Algorithm with Applications to Fault Tolerant Biological Networks. PODC 2021, pp. 93–102. DOI 10.1145/3465084.3467922. Formalized version: the full version, arXiv:2102.12787v2 (18 May 2021). Copy of the paper: paper.pdf.

DOI · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. Theorem 1.1 is correct and fully proved, with explicit constants: AlgAU with k = 3D + 2 (12D + 6 states) is a self-stabilizing asynchronous unison on graphs of diameter ≤ D, and it stabilizes within 70(D+1)³ rounds. Corollary 1.2 (the synchronizer) is false for arbitrary tasks, as stated; it holds for static tasks such as LE and MIS, which are the paper's applications, and we prove that for deterministic Π. The randomized LE and MIS results (Theorems 1.3, 1.4) were not checked.

Mistakes in the paper

⚠️ Corollary 1.2 (the synchronizer Π*, arbitrary tasks)

Corollary 1.2 is false for tasks constrained at every time instant: with D = 1, the task "all nodes output the same bit at all times, and the outputs change infinitely often" is solvable synchronously but by no asynchronous stone-age algorithm, Π* included (toggle_sync, no_async_alg_roundRobin).

Impact. Theorem 1.1 is unaffected. The construction is correct for static tasks (eventually fixed legal outputs), which covers the paper's applications LE and MIS; we prove that version, for deterministic Π, with the bound f + N(D) + D rounds (corollary_1_2).

Details

The synchronizer Π* does not make the nodes simulate one global synchronous execution. Each node shows the synchronous execution at its own simulated round, and neighbouring rounds may differ by 1. Tasks constrained at every time instant therefore cannot be transferred.

  • Synchronously the task is solved on every complete graph within one round by δ(b, S) = ¬(true ∈ S).

  • On K₂ under the fair round-robin schedule, no deterministic stone-age algorithm (Π* included) solves it. A node that is not activated keeps its output, so the first output change after agreement breaks agreement.

🔧 Lemma 2.19 (the constant k(k−1))

The proof of the bound k(k−1) charges one application of Lemma 2.13 per level, which does not cover all moves, so the constant is unestablished (lemma_2_19 proves 4(k−1)²).

Impact. Still O(k²); the final O(D³) of Theorem 1.1 is unaffected. We did not decide whether k(k−1) itself holds.

Details

The argument ignores three things:

  • both endpoints of an edge may move;

  • a node may have several non-protected edges that resolve one after another;

  • edges {k, −k} may become non-protected in the meantime.

Repair

We prove 4(k−1)² in two phases. The node first moves inwards until it is protected or at ±1; then every neighbour reaches ∓1 or becomes protected. (lemma_2_19)

🔧 Lemma 2.13 for |ℓ| = 1

The proof needs the endpoint at level ℓ to make an AF move, but levels ±1 have no faulty turn, so for |ℓ| = 1 the lemma is unestablished (lemma_2_13_edge is proved for |ℓ| ≥ 2).

Impact. The lemma is used only with |ℓ| ≥ 2, so we prove it under that hypothesis. Whether the |ℓ| = 1 case is false is open.

Details

A non-protected node at level ±1 is stuck.

✏️ Slips

  • Lemma 2.13's time bound has t' for t.

  • Obs 2.9 requires |λ_v^s| < k − d also for s = t', and with that the application in Lemma 2.20 at d = D fails, because v is at level exactly k − D at t'. Obs 2.9 needs the bound only for s < t', and the paper's proof only uses s < t'. (AURun.obs29, lemma_2_20)

Proof gaps in true statements (2)Lemma 2.22 · Obs 2.8

🔧 Lemma 2.22 (the potential argument)

The potential argument re-chooses x_t at every time, so "the distance decreases or v becomes grounded" does not follow literally.

Impact. Repaired (lemma_2_22_aux, lemma_2_22).

Details

When the node to which Lemma 2.19 was applied becomes protected, x_t may already be a different node at the same distance.

Repair

Fix the walk at the start of each phase and recurse on its length.

🔧 Obs 2.8 (window of D + 1 levels)

The proof omits a short extremal-point step: pairwise distances ≤ D imply a window of D + 1 levels only because 2k > 3D.

Impact. Statement true; replaced in Lean by an integer lifting along walks (AURun.exists_offsets).

The formalizationmodel, Lean names of the results, trust

Model.

  • Finite simple graph with G.ediam ≤ D (Mathlib), which implies connectivity.

  • Stone-age model: anonymous deterministic finite-state nodes that sense the set of states in their closed neighbourhood. The paper's model allows randomized transitions, but AlgAU is deterministic.

  • Schedule: an adversarial asynchronous daemon A : ℕ → Set V, which may also activate the empty set. It is fair, i.e. every node is activated infinitely often. Rounds are measured by the paper's operator ϱ.

  • Faults: arbitrary initial configuration, no other faults.

  • AU specification: clocks in ZMod (2k); neighbours differ by at most 1; clocks change only by +1; at least i ticks in [t, ϱ^{d+i}(t)).

  • The AlgAU transition rules (Table 1) are formalized as written. An explicit-state model checker (tools/algau.py, on K₂, K₃, P₃, C₄) was used to sanity-check this reading.

  • Lemma 2.11 compares levels cyclically (presentation only).

  • Lemma 2.14's inner induction needs strong induction on the remaining distance.

Trust. No sorry; the listed theorems use only the axioms propext, Classical.choice, Quot.sound. For non-vacuity, Main.lean instantiates Theorem 1.1 on K₃ under the synchronous schedule.
