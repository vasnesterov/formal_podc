import Papers.PODC2021.GoodCaseLatencyBB.Basic /-! # Degenerate cases and non-vacuity: the "echo" protocol The broadcaster `s` keeps sending its input; every other process commits the first value it receives from `s`; `s` commits its own input at time `0`. * `n = 2`: the echo protocol solves Byzantine reliable broadcast for every `f` (one honest non-broadcaster has nobody to disagree with) and commits after **one** message delay. Hence Theorems 4 and 8 (and Theorem 9) of the paper are false for `n = 2`; our versions assume `n ≥ 3` (`theorem_4_false_two`, `theorem_8_false_two`; the latter commits by time `δ ≤ 2δ − 1 ≤ Δ + δ − 1`, so it refutes Theorems 8 and 9 for `n = 2`). * `n = 1`: the echo protocol solves partially synchronous BB for every `f` with good-case latency `0` rounds, so the literal statements of Theorems 6 and 7 (`f ≥ (n+2)/5`) fail for `n = 1`; this forces `f ≥ n`, outside the paper's implicit `f < n` (out of range, not an error) (`theorem_7_false_one`). * Non-vacuity: for `f = 0` the echo protocol solves partially synchronous BB for every `n` (`echo_psyncBB_zero`), so `IsPsyncBB` is satisfiable. -/ set_option linter.unusedSectionVars false namespace GoodCaseLatencyBB open Cslib.Byzantine.PartialSync Finset variable {P V : Type*} [DecidableEq P] /-- The echo protocol with broadcaster `s` (messages are values;
