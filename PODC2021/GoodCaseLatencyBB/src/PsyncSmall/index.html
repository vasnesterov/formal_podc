Run `Rₐ`: `s` faulty and silent, `GST = 0`: by termination `p` commits some `w`. Run `R_b`: `p` faulty and silent, `s` has input `v ≠ w`: by validity `s` commits `v`. Run `R_c`: nobody faulty, `GST = T + 1` and the messages between `s` and `p` are delayed until `T + 1`: up to `T`, `p` behaves as in `Rₐ` and `s` as in `R_b`, so agreement fails. * `n = 3`, `P = {s, p, q}`. `R₁`: `q` faulty and silent, `s` has input `a`: `p` commits `a`. `R₂`: `p` faulty and silent, `s` has input `b`: `q` commits `b`. `R₃`: `s` faulty, it replays its `R₁`-messages to `p` and its `R₂`-messages to `q` until `T`; messages between `p` and `q` are delayed until `T + 1 = GST`. Then `p` behaves as in `R₁` and `q` as in `R₂`. Both `R_c` and `R₃` are the library run `Run.merge` of the two silent runs. Consequently Theorems 6 and 7 hold for all `n ≥ 2` (`theorem_6_all`, `theorem_7_all`); for `n = 1` they are false (`theorem_7_false_one` in `SmallCases.lean`). -/ set_option linter.unusedSectionVars false namespace GoodCaseLatencyBB open Cslib.Byzantine.PartialSync Finset variable {P M S V K : Type*} [DecidableEq P] variable [Fintype P] {A : Algorithm P M S V V} {Au : Auth P M K} /-- Partially synchronous BB is impossible for `n = 2` and `f ≥ 1` (for every algorithm: all runs used are canonical, so unforgeability is not needed). -/ theorem psyncBB_impossible_two {s : P} {f D : ℕ} (hf : 1 ≤ f) (h2 : Fintype.card P = 2) {a b : V} (hab : a ≠ b) : ¬ IsPsyncBB Au A s f D := by intro hA obtain ⟨p, hps⟩ := Fintype.exists_ne_of_one_lt_card (by omega) s have hall : ∀ x, x ≠ s → x = p := fun x hx => two_cases h2 hx hps let Ra := Run.quiet (M := M) {s} (fun _ => a) obtain ⟨w, Ta, hTa⟩ := hA.termination Ra (Run.quiet_valid (by simpa using hf) _) Run.quiet_authValid p (by simp [Ra, Run.quiet, hps]) obtain ⟨v, hvw⟩ : ∃ v, v ≠ w := by classical exact if h : a = w then ⟨b, fun e => hab (h.trans e.symm)⟩ else ⟨a, h⟩ let I : P → V := Function.update (fun _ => a) s v let Rb := Run.quiet (M := M) {p} I obtain ⟨Tb, hTb⟩ := hA.validity Rb (Run.quiet_valid (by simpa using hf) _) Run.quiet_authValid rfl (by simp [Rb, Run.quiet, hps.symm]) s (by simp [Rb, Run.quiet, hps.symm]) -- `R_c`: merge `Rₐ` (seen by `p`) and `R_b` (seen by `s`);
