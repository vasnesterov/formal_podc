import Papers.PODC2021.GoodCaseLatencyBB.Unsync import Papers.PODC2021.GoodCaseLatencyBB.BRBProtocol /-! # Theorem 10 fails for `n = 3` Abraham–Nayak–Ren–Xiang, PODC 2021, Theorem 10 claims: every BRB protocol for the unsynchronized-start model (delays `≤ Δ`, clock skew `≤ δ/2`) resilient to `f > n/3` faults has good-case latency at least `Δ + 1.5δ`. Its proof (`Thm10.theorem_10`) needs `n ≥ 4`. For `n = 3` (and any `f`, in particular `f = 2, 3 > n/3`) the statement is false: the protocol below solves BRB in the unsynchronized-start model with **any** number of faults and **any** clock skew, and has good-case latency `Δ + δ`. ## The protocol ("wait `Δ`, then commit; confirm via commit certificates") Processes: the broadcaster `s` and two others. Tokens: `prop v` signed by `s`, `commit v` signed by the committer. Every process gossips the set of all tokens it knows at every step. * `s` knows `prop(input)` and decides its input at its start. * A non-broadcaster `x` records the local time `tf` at which it first knows a `prop` token. While undecided, at local time `tf + Δ`, if it knows exactly one proposed value `v`, it decides `v` and creates `commit v` (*fast commit*); otherwise, as soon as it knows two different proposed values and a `commit v` token signed by the third process, it decides `v` (*confirm*). Why it works. Two honest fast commits agree: if `p` fast-commits `v` at global time `T_p` and `q` fast-commits `w` at `T_q ≤ T_p`, then `q` knew `prop w` at `T_q − Δ`, so `p` knows it at `T_q ≤ T_p` and `v = w` (`fast_agree`). A confirmation copies the fast commit of the only other non-broadcaster, which (when honest) is the sender of the `commit` token (`cert_dec`). With an honest broadcaster no honest process ever sees two proposed values. Termination: an honest fast commit is gossiped, and the receiver either fast-commits or detects the equivocation and confirms (`progress`). ## Main results * `unforging`: the protocol (through the late-start wrapper) respects unforgeability. * `three_brb`: BRB in `unsyncRuns f Δ σ` for `n = 3`, any `f`, any skew `σ`. * `three_latency`: good-case latency `Δ + δ` (all correct start at `0`, delays `≤ δ`). * `theorem_10_false_three`: for `n = 3` the conclusion of `Thm10.theorem_10` fails under all its other hypotheses; `theorem_10_n4_necessary`: the hypothesis `4 ≤ n` cannot be dropped. -/
