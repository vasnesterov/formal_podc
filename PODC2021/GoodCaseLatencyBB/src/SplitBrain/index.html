The three proofs are the same argument: a Byzantine broadcaster sends `a` to some honest `x` and `b` to another honest `y`; before any message sent *after* receiving the proposal arrives, `x` (resp. `y`) cannot distinguish this from the good-case execution with input `a` (resp. `b`). We prove one generic statement (`split_brain`) for an arbitrary fixed delivery schedule `dl` in which nothing is processed before time `Q` and everything sent from time `Q` on is processed after time `H`; in the runs used, Byzantine processes behave like correct processes with some input before time `Q` and are silent afterwards (`templateRun` of CSLib's `RoundOne`). * Lock-step schedule (`dl = nextRound D`): `Q = D + 1`, `H = 2D` — Theorems 4 and 6. * Uniform effective delay `δ` (`dl = τ + δ − 1`): `Q = δ`, `H = 2δ − 1` — Theorem 8.
