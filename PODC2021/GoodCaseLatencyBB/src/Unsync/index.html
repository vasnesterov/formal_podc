import Papers.PODC2021.GoodCaseLatencyBB.Basic import Cslib.Computability.Distributed.Byzantine.PartialSync.Auth /-! # Unsynchronized start Abraham–Nayak–Ren–Xiang, PODC 2021, Section 2 ("Clock synchronization") and Section 5.4. In the *unsynchronized start* model every party starts the protocol (and its local clock) at its own time; correct parties start at most `σ` apart. We model this on top of the CSLib model: a protocol is an ordinary `Algorithm P M S V V` (a state machine that, once started, takes one step per time unit, so it knows its *local* time), and it is run through the wrapper `lateStart A`, whose input is a pair `(v, k)`: proposal `v`, start time `k`. Before its start a process sends nothing, takes no steps and drops what it receives (`UValid` forbids correct processes' messages to arrive before the receiver has started). Generic tools (CSLib candidates): * `Run.st_shift_eq`: indistinguishability with a per-process **time shift** and a per-process deadline (two runs in which process `p` starts at different times, but sees the same messages at the same *local* times). * `Run.inbox_of_const`: inboxes on links with a constant (effective) delay. * (the replay lemma for a causally closed set of events is the shared `Run.tokens_replay_rel`, `Cslib/Computability/Distributed/Byzantine/PartialSync/Auth.lean`). -/ set_option linter.unusedSectionVars false namespace GoodCaseLatencyBB open Cslib.Byzantine.PartialSync Finset variable {P M S V K : Type*} [DecidableEq P] /-- The late-start wrapper: input `(v, k)` = proposal `v`, start time `k`. -/ def lateStart (A : Algorithm P M S V V) : Algorithm P M ((V × ℕ) ⊕ S) (V × ℕ) V where init p iv := if iv.2 = 0 then .inr (A.init p iv.1) else .inl iv step p st ib := st.elim (fun vk => if vk.2 ≤ 1 then .inr (A.init p vk.1) else .inl (vk.1, vk.2 - 1)) (fun x => .inr (A.step p x ib)) send p st q := st.elim (fun _ => []) (fun x => A.send p x q) decide p st := st.elim (fun _ => none) (fun x => A.decide p x) /-- Start time of `p` in a run of `lateStart A`. -/ def ustart (R : Run P M (V × ℕ)) (p : P) : ℕ := (R.inp p).2 section lateStart variable {A : Algorithm P M S V V} {R : Run P M (V × ℕ)} theorem lateStart_st_before (p : P) : ∀ τ, τ < ustart R p → R.st (lateStart A) τ p = .inl ((R.inp p).1, ustart R p - τ) := by intro τ hτ induction τ with | zero => simp only [Run.st_zero, lateStart, ustart] at hτ ⊢ rw [ite_eq_right (by omega)];
