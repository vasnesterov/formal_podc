We split the processes into three groups `A = {g = 0}`, `B = {g = 1}`, `C = {g = 2}` of size `≤ f` each, with the broadcaster `s ∈ C` and `A`, `B` nonempty. The three executions of the paper: * **Ex1** = `(world … a).enlarge A {g = 1}`: `B` is Byzantine but behaves honestly in a world where every link touching `B` has effective delay `Δ` (all other links `δ`); `s` has input `a`. It is a synchronous run with delay bound `δ`, so some `x ∈ A` commits `a` before `Δ + δ`. * **Ex2**: the mirror image (`A` Byzantine, `s` has input `b`, some `y ∈ B` commits `b`). * **Ex3** (`ex3`): `C` is Byzantine and replays, up to time `Δ + δ - 1`, to `A` what it sent in Ex1 and to `B` what it sent in Ex2; the `A`–`B` links have delay `Δ`, all others `δ`. It is a synchronous run with delay bound `Δ`. `A` cannot distinguish Ex3 from Ex1 before `Δ + δ` (`side_st`): messages from `B` arriving before `Δ + δ` were sent before `δ`, when `B` has received nothing in both runs. Unforgeability of the replay in Ex3 follows from `Run.tokens_replay_dl` (`side_tokens`).
