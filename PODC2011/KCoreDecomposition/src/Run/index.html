import Papers.PODC2011.KCoreDecomposition.Algorithm /-! # Synchronous runs of Algorithm 1 and the time / message bounds (§4.2, §4.3) The synchronous model of §4.2: "during one round, each node receives all messages addressed to it in the previous round (if any), computes a new coreness estimate and broadcasts a message to all its neighbors if the estimate has changed with respect to the previous round. At round 1, each node broadcasts its current estimate (equal to its degree) to all its neighbors." No optimizations. `run G order n` is the configuration at the end of round `n + 1`: the node states and the set of nodes that broadcast in round `n + 1`. In each round a node processes the messages it received with the handler `receive` of Algorithm 1, **in an arbitrary order** given by `order` (any list enumerating its neighbours; duplicates allowed). The results hold for every such order. * `run_spec` — the run produces exactly the trajectory `traj` of `Trajectory.lean`; * `execTime` — the paper's execution time: the number of rounds in which at least one node broadcasts; `execTime_eq` — `execTime = stab + 1` (for a nonempty graph); * `theorem_2`, `theorem_3` — safety and liveness of the synchronous run; * `theorem_4` — `execTime ≤ 1 + Σ_u (d(u) − k(u))`; * `theorem_5` — `execTime ≤ N`;
