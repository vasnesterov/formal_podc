import Mathlib import Podc.Foundations.InformationTheory.MDSCode import Cslib.Computability.Distributed.Byzantine.Specs /-! # Algorithm 1 (one generation) and the multi-generation algorithm Liang–Vaidya, *Error-Free Multi-Valued Consensus with Byzantine Failures*, PODC 2011 (arXiv:1101.3520), Section 3, Algorithm 1. ## Model Synchronous, fully connected network of `n` processors `Fin n`; a static set `F` of at most `t` Byzantine processors (the adversary is omniscient and the algorithm deterministic, so the paper's adaptive corruption reduces to a static `F` = the processors that are ever corrupted). The processors run Algorithm 1 once per *generation*; the only state carried between generations is the **diagnosis graph** `G`, which is common knowledge of the fault-free processors. All communication except the point-to-point symbols of step 1(a) goes through the black box `Broadcast_Single_Bit` (error-free Byzantine broadcast). We use its specification: every fault-free processor receives the same value, and this value is the source's value if the source is fault-free. Hence a broadcast value of a faulty source is simply chosen by the adversary, and the value of a fault-free source is the one prescribed by the algorithm. This is how every broadcast quantity is modelled below (`M`, `Detected`, `R#`, `Trust`). The adversary's choices for one generation are an `Adv`: the symbols sent by faulty processors to each processor (step 1(a)), the broadcast values of faulty processors, and the choice of the sets `P_match` and `P_decide` among the valid ones ("Find a set …" in steps 1(e), 3(h)). Letting the adversary pick these sets is more general than any fixed deterministic selection rule. `⊥` (step 1(b)): processor `i` ignores the symbol of an untrusted processor. The consistency check `R_i/P_match ∈ C₂ₜ` of step 2(a) and the decoding of step 2(c) are therefore done on the trusted members of `P_match` (`Gen.X`), as in the paper's proof of Lemma 4 (case 2(a)). The code `C₂ₜ` is an abstract `Cslib.MDSCode n (n - 2t)`: any `n - 2t` symbols determine the data (staged in `Podc/Foundations/InformationTheory/MDSCode.lean`, with the Reed–Solomon instance). ## The two variants The pseudo-code lets *every* processor outside `P_match` announce `Detected` (step 2(b)), even a processor whose vertex has already been isolated in the diagnosis graph. With this literal reading (`Variant.literal`) an isolated faulty processor can force the diagnosis stage in every generation (see `Counterexample.lean`). The prose says that isolated processors are no longer communicated with; `Variant.repaired` implements this: the `Detected` announcements of processors without any edge in the diagnosis graph are ignored. -/ namespace Podc.ErrorFreeMultivaluedBC open Finset Cslib noncomputable section /-!
