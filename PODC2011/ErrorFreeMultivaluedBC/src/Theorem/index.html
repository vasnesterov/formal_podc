The `L`-bit value is split into `N = L/D` parts of `D` bits; part `g` is the input of generation `g`. We abstract a `D`-bit part as an element of the data type `α` of the code, so an `L`-bit value is a vector `Fin N → α` (the input of `i` is `fun g => r.inp g i`). * `Run.goodClique_graph`: the fault-free processors always trust each other (Lemma 4). * `Run.theorem_1_consensus`: the decisions of the `N` generations solve consensus on the `L`-bit values (termination is built in: every processor decides in every generation). * `Run.theorem_1_numDiag`: in the repaired algorithm the diagnosis stage is performed in at most `t(t+1)` generations, however many generations are run. (For the literal pseudo-code this is false, see `Counterexample.lean`.) The counting argument: the potential of a faulty vertex `f` is `0` once `f` is isolated, and `t + 1 - min(removed f, t)` before.
