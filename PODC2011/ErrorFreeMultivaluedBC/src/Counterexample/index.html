In Algorithm 1 as printed, *every* processor `P_j ∉ P_match` broadcasts `Detected_j` (step 2(b)), and the diagnosis stage is entered as soon as one of them is `true` (step 2(c)). This includes a faulty processor whose vertex has already been isolated in the diagnosis graph. Such a processor is never in `P_match` (the fault-free members of `P_match` do not trust it), so it can announce `Detected = true` in every generation; the diagnosis stage then removes nothing, because the processor has no edge left (case 2(a) of the proof of Lemma 4 overlooks this). The run: `n = 4`, `t = 1`, processor `3` faulty, all fault-free inputs equal to `w`, any MDS code. Processor `3` sends correct symbols, broadcasts `M_3 = false…false` (so it is in no matching set), `Detected_3 = true`, correct `R#[3]` and `Trust_3 = true…true`. Generation 0 isolates vertex `3` (step 3(f)); from then on the diagnosis graph is constant and every generation still runs the diagnosis stage. So the literal algorithm performs the diagnosis stage in all `N` generations, `N > t(t+1) = 2` as soon as `N ≥ 3` (`literal_numDiag`, `literal_not_theorem_1`). The repaired algorithm, run against the same adversary, performs it once (`repaired_numDiag`).
