Error-Free Multi-Valued Consensus — PODC 2011

Guanfeng Liang, Nitin Vaidya. Error-Free Multi-Valued Consensus with Byzantine Failures. PODC 2011. DOI 10.1145/1993806.1993809. Formalized version: arXiv 1101.3520 v1; numbering follows it.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. Algorithm 1 achieves consensus on L-bit values for 3t < n (Lemmas 1–3 and 5 and the correctness part of Theorem 1 hold). The claim that the diagnosis stage runs at most t(t+1) times (Lemma 4, and thus the complexity bound) is false for the pseudo-code as printed: an already isolated faulty processor can trigger the diagnosis stage in every generation. It holds once announcements of isolated processors are ignored, as the paper's prose intends.

Mistakes in the paper

🔧 Lemma 4 and Theorem 1's t(t+1) bound (Algorithm 1 as printed)

An already isolated faulty processor can announce Detected = true in every generation, so the diagnosis stage runs forever without removing an edge: with n = 4, t = 1 there are already 3 > t(t+1) diagnosis stages in 3 generations (Counterexample.literal_not_theorem_1, Counterexample.literal_lemma_4_false).

Impact. Only the complexity bound is affected, and only for the printed pseudo-code: ignoring the Detected bits of isolated processors, as the prose intends, restores Lemma 4 and the t(t+1) bound (Run.theorem_1_numDiag). Correctness holds for both versions.

Details

In Algorithm 1, every P_j ∉ P_match broadcasts Detected_j, and the diagnosis stage starts as soon as one of these bits is true. A faulty processor whose vertex is already isolated is never in P_match: the fault-free members do not trust it. Take n = 4, t = 1, P₃ faulty, all inputs equal. P₃ behaves correctly except that it broadcasts M₃ = false…false and Detected₃ = true. In generation 1, step 3(f) isolates vertex 3. From then on the diagnosis stage runs in every generation and removes nothing, since vertex 3 has no edge left. Case 2 of the proof of Lemma 4 assumes that step 3(f) removes some edge at j, and misses the case where none is left. So Lemma 4 is false ("at least one edge … will be removed") and so is the t(t+1) bound; with 3 generations there are already 3 > 2 diagnosis stages. This is a false statement about the printed algorithm. The intended algorithm is clear from the prose: §3.3 says of an isolated processor that "the fault-free processors will not communicate with it anymore", and the proof of Theorem 1 argues that once all faulty processors are identified "the diagnosis stage will not be performed any more".

Repair

Ignore the Detected bits of isolated processors. For this repaired algorithm we prove Lemma 4 and the t(t+1) bound. (Run.theorem_1_numDiag)

✏️ Slips

  • ⊥ in the checking stage (steps 2(a), 2(c)): read literally, a received vector with a ⊥ entry is never in C₂ₜ, so a fault-free processor that distrusts a faulty member of P_match always reports a detection, and step 3(f) can then isolate this fault-free processor. Untrusted senders give R_i[j] = ⊥, and "R_j/P_match ∈ C₂ₜ" is defined by equality with a codeword. The prose of §3.2 ("checks whether the symbols received from the trusted processors in P_match are consistent") and the proof of Lemma 4 (case 2(a)) state the intended reading, which we formalize: ⊥ entries are ignored, and the check and decoding use the trusted members of P_match. The literal reading's failure, a 2-generation scenario with n = 4, is described in differencies.md but not proved in Lean.

  • Lemma 3 should assume that no processor announces a detection, not that none detects one.

  • "v_i(g), represented by n − t symbols" in §3.1 should be n − 2t.

Typos

  • "Detected_i" in §3.2 should be Detected_j.

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous, fully connected network of n processors with a static set F of |F| ≤ t Byzantine processors and 3t < n. The paper's adaptive corruption is equivalent to this: the algorithm is deterministic and the adversary omniscient.

  • Each generation is computed at the level of Algorithm 1's steps. Broadcast_Single_Bit is a black box with its specification: all fault-free processors get the same value, which is the source's value if the source is fault-free. So the broadcast values of faulty sources (M_j, Detected_j, R#[j], Trust_j) are adversary choices. The point-to-point symbols of step 1(a) are explicit, and a faulty sender may send a different symbol to each receiver.

  • The adversary also picks P_match and P_decide among the valid sets. This covers every deterministic selection rule.

  • The code C₂ₜ is an abstract code with the MDS property: any n − 2t symbols determine the data. A D-bit part is a data word, and an L-bit value is a vector of N = L/D data words. A Reed–Solomon instance shows that the hypotheses are satisfiable.

  • The diagnosis graph is a SimpleGraph (Fin n), complete at the start and common to all fault-free processors.

  • Two variants: Variant.literal (pseudo-code as printed) and Variant.repaired (Detected bits of processors without edges are ignored).
