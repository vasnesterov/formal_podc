Let `U₀, U₁` be disjoint sets of further processes. Then it is impossible that, for both `i ∈ {0, 1}`, some `Uᵢ`-only execution from `πBᵢ(C)` contains a complete `getTS` and leaves the memory outside `R` unchanged. We state the lemma in the form used by the paper: the complete `getTS` is by a process `qᵢ ∈ Uᵢ` that is idle (no pending operation) in `C`, invokes exactly one operation (a `getTS`) in the `Uᵢ`-only execution `βᵢ` and has returned at its end. Instead of "does not write outside `R`" we only assume that the memory outside `R` at the end of `βᵢ` equals that of `C` (a weaker hypothesis, hence a stronger lemma). Proof: the executions `C; πB₀ β₀ πB₁ β₁ πB₂` and `C; πB₁ β₁ πB₀ β₀ πB₂` end in the *same* configuration (block writes obliterate everything inside `R`). After it, `q₀` runs `compare(t₀, t₁)` solo. In the first execution `getTS(q₀) → getTS(q₁)`, so the answer must be `true`; in the second `getTS(q₁) → getTS(q₀)`, so it must be `false`. -/ set_option linter.unusedSectionVars false namespace
