import Papers.PODC2011.TimestampSpace.Moves /-! # Theorem 1.2: the one-shot lower bound Any one-shot timestamp implementation from read/write-like base objects satisfying (non-deterministic) solo termination, for `n ≥ 3` processes, uses at least `⌊√(2n)⌋ - ⌈log₂ n⌉ - 2` base objects (`theorem_1_2`). The proof follows Section 4 of the paper (the "grid" construction), with the bookkeeping made explicit through the invariant `Inv m n α C R ℓ` (with `m = ⌊√(2n)⌋`, `j = |R|`): * `full`: every object of `R` is covered by at least `ℓ - j` processes; * `sparse`: no nonempty set `S` of objects outside `R` has all its objects covered by at least `ℓ + 1 - j - |S|` processes (in the paper's grid picture: no new column reaches the diagonal); * `nbound`: the number of processes that are not idle and do not cover an object outside `R` is at most `∑_{c=1}^{j} (m - c)` (this replaces the paper's "association" argument); * `idleb`: `(#idle - 1) · 2^(m-ℓ) < n` (each decrease of `ℓ` halves the idle processes); * `ℓ ≤ m` and `m - ℓ ≤ ⌈log₂ n⌉`. One step (`step`) applies Lemma 4.1 and stops at the *first* move after which a new set `Q` of columns reaches the diagonal (`HasFull`); then `R := R ∪ Q` and `ℓ` decreases by one only in the paper's "Case 2". The construction stops when `ℓ < j + 3`, giving `j ≥ m - ⌈log₂ n⌉ - 2`. Idle processes never run out (`idle_ge_two`), which is the paper's claim that `|idle(C_last)| ≤ 1` is impossible. -/ set_option linter.unusedSectionVars false namespace Cslib.SharedMemory.Timestamp
