import Papers.PODC2011.TimestampSpace.Defs /-! # Algorithms 3 and 4 (Section 6): the model The upper bound of Helmi, Higham, Pacheco, Woelfel (PODC 2011, Section 6): timestamps are pairs `(rnd, turn) ∈ ℕ × ℕ`, `compare` (Algorithm 3) is the lexicographic order and accesses no shared memory, `getTS` is Algorithm 4. **Memory.** The paper treats the `scan` of line 13 as atomic ("Since scan is linearizable, we treat it as atomic"). A CSLib `Impl` accesses one base object per step, so the whole register array `R[1], R[2], …` (unbounded; `R[0]` is never accessed) is *one* base object `memObj P` with three primitives: * `read i` (returns the view of `R[i]` only), * `write i v` (writes `R[i]`), * `scan k` (atomic snapshot of `R[1..k]`; Algorithm 4 only uses `r[1..myrnd+1]` of its scan, so it scans exactly these registers). `MOp.idx` is the largest register index a primitive touches; the space bound says that all accesses have index `≤ ⌈2√M⌉`. **Register contents.** `⊥` (`none`) or `⟨seq, rnd⟩` (`Val`), `seq` a list of getTS-ids. The getTS-id of an operation of process `p` is `(p, c)` where `c` is the number of operations `p` completed before (i.e. its CSLib `OpId`); processes count their operations in their local state (`Loc.cnt`). **Program.** One base-object access per local state (`PC`): * `wh j v` — line 1 (while loop): read `R[j]`; `v` is the value read from `R[j-1]` (= `r[j-1]`; the paper's line 2 copies it, we do not re-read). When `R[j] = ⊥`: `myrnd = j - 1`. * `loop k i v s` — iteration `i` of the for loop (line 5), `myrnd = k`, `r[myrnd] = v`, at line `s`: `s6` reads `R[k+1]`, `s7` reads `R[i]` and compares `r[k].seq[i]` with `last(R[i].seq)`, `s8` writes `R[i]` and returns `(k, i)`, `s10` reads `R[i]` again (line 10 is a separate read, as in the paper's proof of Claim 6.13), `s11` writes `R[i]`. * `scan k` — line 13–14, `fin k w` — line 15 (`w = ⟨last(r[1].seq), …, last(r[k].seq), id⟩`), `done r` — about to return `r`. -/ set_option linter.unusedSectionVars false namespace Cslib.SharedMemory.Timestamp.Alg4
