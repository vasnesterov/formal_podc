import Papers.PODC2011.TimestampSpace.EFR /-! # Paused solo segments Building blocks of the covering construction of Section 4 (Lemma 4.1): a process `p` invokes `getTS` and runs solo until it either returns or is *poised to change a base object outside a set `R`* (`WritesOut R`). The resulting label list is `seg R p Z`. If the segment ends with `p` poised to write outside `R` we say that `p` is *paused* (`Paused`); for read/write-like base objects it then covers an object outside `R`. A list of processes run one after the other in this way gives `segMoves R Z L` (a list of "moves": process and its labels). `AllPaused R Z L` says that every process of `L` pauses. Everything only depends on what the moving processes can observe (`AllPaused_agreeOn`). -/ set_option linter.unusedSectionVars false namespace Cslib.SharedMemory.Timestamp open Cslib.SharedMemory Impl
