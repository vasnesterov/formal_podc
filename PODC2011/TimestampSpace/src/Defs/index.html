Registers (`register V v₀`, of arbitrary — also unbounded — value types) are the main example (`rwLike_register`). * **Implemented object.** `tsObj T`: operations `getTS` and `compare t₁ t₂` over an arbitrary timestamp universe `T`; responses `Sum.inl t` (a timestamp) or `Sum.inr b` (a Boolean). The specification is not sequential: `TSCorrect α` says that whenever a `getTS` instance `g₁` returning `t₁` happens before a `getTS` instance `g₂` returning `t₂`, then every `compare(t₁, t₂)` invoked after `g₂` returned returns `true` and every such `compare(t₂, t₁)` returns `false`. * **Long-lived vs one-shot.** `Adm oneShot α`: if `oneShot` then every process invokes `getTS` at most once in `α` (`compare` is unrestricted). * **Progress.** `SoloTerm I oneShot`: from every configuration reached by an admissible execution, a pending process running solo returns (for deterministic processes this is the paper's "non-deterministic solo-termination", i.e. obstruction-freedom).
