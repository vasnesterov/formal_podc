(CSLib's `WaitFree` quantifies over all infinite executions; with unboundedly many `getTS` calls the algorithm is not wait-free — the while loop can chase an ever-growing prefix of written registers — which is why the paper fixes `M` in advance.) * `alg4_soloTerm`: from every reachable configuration a process running solo returns (obstruction-freedom, for any number of `getTS` calls). -/ set_option
