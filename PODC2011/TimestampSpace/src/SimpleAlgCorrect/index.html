import Papers.PODC2011.TimestampSpace.SimpleAlg import Cslib.Computability.Distributed.SharedMemory.History import Cslib.Computability.Distributed.SharedMemory.Model /-! # Lemma 5.1: correctness of the simple one-shot timestamp algorithm Invariant-based proof of Lemma 5.1 of Helmi, Higham, Pacheco, Woelfel (PODC 2011): in every one-shot execution of Algorithms 1 and 2 (`SimpleTS.alg`), * every register only takes values in `{0, 1, 2}` and never decreases (`mem_le_two`, `mem_mono`); * if a `getTS` returning `t₁` precedes a `getTS` returning `t₂` then `t₁ < t₂`, hence the history satisfies `TSCorrect` (`correct`). Proof idea (the paper's): register `R[j]` is only written by its two owners, each at most once (one-shot), with `r + 1` where `r` was read before; `r ≤ 1` and `r = 1` only if the partner has already written, so writes never decrease `R[j]`. A `getTS` that started after another one finished reads every register at least at the value the earlier one used, and its own register strictly above. The invariant `Inv` makes this precise with an upper bound `UB` (the partial sum is at most the sum of the current values of the registers read so far) and, for pending `getTS` operations, a lower bound `LB` on the eventually returned value (partial sum + current values of the registers still to be read + 1 for the pending increment). -/ set_option linter.unusedSectionVars false namespace Cslib.SharedMemory.Timestamp.SimpleTS open Cslib.SharedMemory /-! ### Sums of register values -/ section Sums variable {n : ℕ} /-- Register values as a function on `ℕ` (`0` beyond the last register). -/ def ext (M : Fin ((n + 1) / 2) → ℕ) (j : ℕ) : ℕ := if h : j < (n + 1) / 2 then M ⟨j, h⟩ else 0 /-- Sum of `R[0..i-1]`. -/ def pre (M : Fin ((n + 1) / 2) → ℕ) (i : ℕ) : ℕ := ∑ j ∈ Finset.range i, ext M j /-- Sum of `R[i..]`. -/ def suf (M : Fin ((n + 1) / 2) → ℕ) (i : ℕ) : ℕ := ∑ j ∈ Finset.Ico i ((n + 1) / 2), ext M j /-- Sum of all registers. -/ def tot (M : Fin ((n + 1) / 2) → ℕ) : ℕ := suf M 0 variable {M M' : Fin ((n + 1) / 2) → ℕ} lemma pre_succ (i : ℕ) : pre M (i + 1) = pre M i + ext M i := Finset.sum_range_succ _ _ lemma suf_of_lt {i : ℕ} (h : i < (n + 1) / 2) : suf M i = ext M i + suf M (i + 1) := Finset.sum_eq_sum_Ico_succ_bot h _ lemma suf_of_ge {i : ℕ} (h : (n + 1) / 2 ≤ i) : suf M i = 0 := by simp [suf, Finset.Ico_eq_empty_of_le h] lemma ext_of_ge {i : ℕ} (h : (n + 1) / 2 ≤ i) : ext M i = 0 := by simp [ext, show ¬ i < (n + 1) / 2 by omega] lemma pre_add_suf (i : ℕ) : pre M i + suf M i = tot M := by induction i with | zero => simp [pre, tot] | succ i ih => rw [pre_succ] rcases lt_or_ge i ((n + 1) / 2) with h | h · rw [suf_of_lt h] at ih;
