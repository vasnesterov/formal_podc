import Papers.PODC2011.LocallyCheckableProofs.LocalTools /-! # The spanning-tree certificate of Korman–Kutten–Peleg (Section 5.1) "Any spanning tree `T` can be equipped with a proof of size `O(log n)` that, for each vertex `v`, consists of (i) the identity of a particular vertex `a`, the root, and (ii) the distance from `v` to `a` in `T`." We also give every node a parent pointer (the identifier of its parent), which makes the tree explicit; all three numbers are `O(log n)`-bit identifiers or distances. `TreeOK G H rt d par v` is the radius-1 check at `v`: all `G`-neighbours agree on the root `rt`; `d v = 0` iff `v` is the root; a non-root `v` has its parent `par v` among its `H`-neighbours (`H ≤ G` is the graph of allowed tree edges: the whole graph, or the marked edges `I.S`) with `d (par v) + 1 = d v`. * `treeOK_sound`: on a connected instance, if all nodes accept then there is a root `r ∈ V`, all nodes know `r`, and every node `v` has an `H`-walk of length `d v` to `r` (following parents). * `treeOK_complete`: if every node reaches `r ∈ V` in `H`, then the root `r`, the distances `H.dist · r < n` and suitable parents in `V` are accepted everywhere. * `isAcyclic_of_treeEdges` / `treeEdges_complete`: with the extra check `TreeEdges` (every `H`-edge at `v` is a tree edge `{v, par v}` or `{u, par u}`), acceptance certifies that `H` is acyclic, and every acyclic connected `H` passes it. * Counters along the tree (`childSum`, `count_root`, `count_le_root`, `exists_count`): if every node checks `cnt v = 1 + Σ_{children u} cnt u`, then `cnt root = n` (no acyclicity needed: each non-root node is the child of exactly one node), so every node can be convinced of `n`. -/ namespace
