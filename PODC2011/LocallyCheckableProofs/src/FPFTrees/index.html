import Papers.PODC2011.LocallyCheckableProofs.Star /-! # Theorem 6.3: fixed-point-free symmetry of trees requires proofs of size `Ω(n)` A graph has a *fixed-point-free symmetry* if some automorphism moves every node (`HasFPFSym`). The paper glues two rooted trees by a path, as in Theorem 6.1, and uses that there are `2^Θ(k)` rooted trees on `k` nodes. We use an explicit family instead: for a word `w ∈ {0,1}^m`, the caterpillar `cat m w` on `Fin (5m)` has the spine `0 — 1 — ⋯ — (2m-1)` (rooted at `0`) and three leaves `2m+3i, 2m+3i+1, 2m+3i+2` for every `i < m`, attached to `2i`, to `2i` or `2i+1` (according to `w i`), and to `2i+1`. So the spine node `2i` has two leaves iff `w i`. In `cat w ⊛ cat w'` (path of even length `p ≥ 2`) the non-leaf nodes form one long path (spine of the first copy, the connecting path, spine of the second copy). An automorphism without fixed points must reverse this path (`StarCons.PathEnum`), so it maps the spine node `2i` of the first copy to the spine node `2i` of the second copy, and `w i = w' i`. Conversely, the swap of `cat w ⊛ cat w` has no fixed point when `p` is even. Note: a tree with a fixed-point-free automorphism has an even number of nodes (the automorphism flips the central edge), so only even `n` matter; we prove the lower bound for all large even `n` (and
