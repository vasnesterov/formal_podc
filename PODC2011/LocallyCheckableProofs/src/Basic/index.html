import Mathlib /-! # Locally checkable proofs: the model (Section 2 of Göös–Suomela) M. Göös, J. Suomela. *Locally Checkable Proofs in Distributed Computing.* Theory of Computing 12(19), 2016 (journal version of the PODC 2011 paper *Locally Checkable Proofs*). * `Inst L`: a (labelled) graph instance. Nodes **are** their identifiers: the node set is a `Finset ℕ` and the graph lives on `ℕ` (edges only between nodes). An instance carries node labels `lab : ℕ → L` (the paper's "colors, labels") and a set of marked edges `S ≤ G` (edge labels in `{0,1}`, used for graph problems such as spanning trees and matchings, Section 2.3). For graph properties of unlabelled graphs take `L = Unit` and `S = ⊥` (`Inst.Plain`). * A *proof* is a function `ℕ → List Bool` (only its values on the nodes matter). * `ball I v r`: the nodes within distance `r` of `v` (the paper's `V[v,r]`). * `ViewEq r I P I' P' v`: `v` has the same radius-`r` view in `(I,P)` and `(I',P')`: the same ball, the same induced edges and marked edges on it (`G[v,r]`), the same labels and proof labels on it (`P[v,r]`). * `IsLocal r A`: the verifier `A` has local horizon `r`, i.e. its output at `v` depends only on the radius-`r` view of `v`. This is equivalent to the paper's `A(G,P,v) = A(G[v,r],P[v,r],v)`. * `AdmitsLCP F P s` (Definition 2.2): `P` admits locally checkable proofs of size `s` on the family `F`, i.e. `P ∈ LCP(s)`. `AdmitsWeakLCP` is the weak proof labelling scheme of Section 2.3 for graph problems (we may choose the solution); it is implied by `AdmitsLCP` (`AdmitsLCP.weak`). -/ namespace Podc.LocallyCheckableProofs open SimpleGraph Finset /-- A labelled graph instance whose nodes are their identifiers. -/ @[ext] structure Inst (L : Type*) where /-- The nodes (= identifiers). -/ V : Finset ℕ /-- The graph. -/ G : SimpleGraph ℕ /-- Edges only join nodes. -/ sub : ∀ ⦃u v⦄, G.Adj u v → u ∈ V /-- Marked edges (edge labels `1`), e.g. a claimed solution of a graph problem. -/ S : SimpleGraph ℕ S_le : S ≤ G /-- Node labels (auxiliary local input). -/ lab : ℕ → L /-- A proof: a bit string for every node. -/ abbrev Proof := ℕ → List Bool /-- A verifier: `A I P v` is the output of node `v`. -/ abbrev Verifier (L : Type*) := Inst L → Proof → ℕ → Bool namespace Inst variable {L : Type*} /-- The number of nodes `n(G)`. -/ def n (I : Inst L) : ℕ := I.V.card lemma sub' (I : Inst L) {u v : ℕ} (h : I.G.Adj u v) : v ∈ I.V := I.sub h.symm /-- An unlabelled instance: no marked edges (and, for `L = Unit`, no labels). -/ def Plain (I : Inst L) : Prop := I.S = ⊥ /-- The instance is connected (and nonempty). -/ def Conn (I : Inst L) : Prop := I.V.Nonempty ∧ ∀ u ∈ I.V, ∀ v ∈ I.V, I.G.Reachable u v /-- Identifiers are in `{1, …, n^c}` (the paper: `V(G) ⊆ {1, …, poly(n(G))}`). -/ def IdBound (c : ℕ) (I : Inst L) : Prop := ∀ v ∈ I.V, 1 ≤ v ∧ v ≤ I.n ^ c /-- Same underlying graph (possibly different labels / solutions). -/ def SameGraph (I J : Inst L) : Prop := I.V = J.V ∧ I.G = J.G end Inst variable {L : Type*} /-- The ball `V[v,r]`: nodes joined to `v` by a walk of length `≤ r`. -/ def ball (I : Inst L) (v : ℕ) (r : ℕ) : Set ℕ := {u | ∃ p : I.G.Walk v u, p.length ≤ r} lemma mem_ball_self (I : Inst L) (v r : ℕ) : v ∈ ball I v r := ⟨Walk.nil, by simp⟩ /-- `v` has the same radius-`r` view in `(I, P)` and in `(I', P')`. Proof labels may be of any type `Λ` (bit strings `List Bool` in the paper's definition). -/ structure ViewEq {Λ : Type*} (r : ℕ) (I : Inst L) (P : ℕ → Λ) (I' : Inst L) (P' : ℕ → Λ) (v : ℕ) : Prop where ball_eq : ball I v r = ball I' v r adj : ∀ x ∈ ball I v r, ∀ y ∈ ball I v r, (I.G.Adj x y ↔ I'.G.Adj x y) sadj : ∀ x ∈ ball I v r, ∀ y ∈ ball I v r, (I.S.Adj x y ↔ I'.S.Adj x y) mem : ∀ x ∈ ball I v r, (x ∈ I.V ↔ x ∈ I'.V) lab : ∀ x ∈ ball I v r, I.lab x = I'.lab x prf : ∀ x ∈ ball I v r, P x = P' x /-- A verifier with local horizon `r` (its output at `v` only depends on the radius-`r` view). -/ def IsLocal {Λ : Type*} (r : ℕ) (A : Inst L → (ℕ → Λ) → ℕ → Bool) : Prop := ∀ I P I' P' v, ViewEq r I P I' P' v → A I P v = A I' P' v /-- The proof has size at most `k` on the nodes of `I`. -/ def SizeLE (I : Inst L) (P : Proof) (k : ℕ) : Prop := ∀ v ∈ I.V, (P v).length ≤ k /-- All nodes accept. -/ def AllAccept (A : Verifier L) (I : Inst L) (P : Proof) : Prop := ∀ v ∈ I.V, A I P v = true /-- **Definition 2.2.** `P` admits locally checkable proofs of size `s` on the family `F` (`P ∈ LCP(s)`): a local verifier such that every yes-instance has a proof of size `≤ s(n)` accepted by all nodes (completeness), and every no-instance of `F` rejects every proof at some node (soundness). For a graph problem (labelled instances) this is a *strong* proof labelling scheme. -/ def AdmitsLCP (F P : Set (Inst L)) (s : ℕ → ℕ) : Prop := ∃ (r : ℕ) (A : Verifier L), IsLocal r A ∧ (∀ I ∈ F, I ∈ P → ∃ Pf : Proof, SizeLE I Pf (s I.n) ∧ AllAccept A I Pf) ∧ (∀ I ∈ F, I ∉ P → ∀ Pf : Proof, ∃ v ∈ I.V, A I Pf v = false) /-- Weak proof labelling scheme (Section 2.3): for every graph of `F` that has some correct solution, *some* correct solution (labelling of the same graph) has an accepted proof of size `≤ s(n)`; incorrect labellings are rejected. -/ def AdmitsWeakLCP (F P : Set (Inst L)) (s : ℕ → ℕ) : Prop := ∃ (r : ℕ) (A : Verifier L), IsLocal r A ∧ (∀ I ∈ F, (∃ J ∈ F, J ∈ P ∧ I.SameGraph J) → ∃ J ∈ F, J ∈ P ∧ I.SameGraph J ∧ ∃ Pf : Proof, SizeLE J Pf (s J.n) ∧ AllAccept A J Pf) ∧ (∀ I ∈ F, I ∉ P → ∀ Pf : Proof, ∃ v ∈ I.V, A I Pf v = false) /-- A strong scheme is a weak scheme. -/ lemma AdmitsLCP.weak {F P : Set (Inst L)} {s : ℕ → ℕ} (h : AdmitsLCP F P s) : AdmitsWeakLCP F P s := by ⟨J, hJF, hJP, ‹I.SameGraph J›, Pf, hPf, hacc⟩ /-- Monotonicity in the proof size. -/ lemma AdmitsLCP.mono {F P : Set (Inst L)} {s t : ℕ → ℕ} (h : AdmitsLCP F P s) (hst : ∀ n, s n ≤ t n) : AdmitsLCP F
