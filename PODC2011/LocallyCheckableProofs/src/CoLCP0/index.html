import Papers.PODC2011.LocallyCheckableProofs.SpanningTree /-! # Complementing in LCP(0) (Section 7.3) On connected graphs (with identifiers in `{1, …, n^c}`), if `P ∈ LCP(0)` then its complement `F \ P` is in LogLCP: the proof is a spanning tree rooted at a node `a` that rejects the input under the LCP(0) verifier `A` with the empty proof `ε`; the root checks `A(G, ε, a) = 0`. Locality: the new verifier at `v` runs the tree check (radius 1) and, if `v` claims to be the root, simulates `A` on the *empty* proof, i.e. it ignores the actual proof labels inside its radius-`r` ball; this is a function of the radius-`max(r,1)` view (`ViewEq.restrict_radius`).
