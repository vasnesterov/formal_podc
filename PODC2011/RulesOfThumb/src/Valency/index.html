import Papers.PODC2011.RulesOfThumb.Model /-! # Valency of histories The *stable coloring* of Appendix F (Definition F.10): a history `h`, together with a set `P` of nodes that are already scheduled for the next time step (the pending reactions of the "act-and-tell" model of Appendix F.6), is coloured by the set `F.lims h P` of action profiles to which some fair dynamics from `h`, whose next activation set contains `P`, converges. We prove the basic facts used in the valency argument: * colours shrink along transitions (`lims_anti`, `lims_step_subset`, `lims_run_subset`); * histories with the same length and the same `k` most recent profiles have the same future (`Equiv`, `lims_eq_of_equiv`), for `k`-recall reaction functions; * two histories that differ only in the actions of one node `j` become equivalent after `j` is activated alone `k` times (`equiv_run_single`), for self-independent `k`-recall reaction functions; so (in a convergent system) their colours intersect (`lims_inter_nonempty`). -/ namespace
