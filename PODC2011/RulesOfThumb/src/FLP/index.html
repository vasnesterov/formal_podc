import Papers.PODC2011.RulesOfThumb.Valency /-! # The act-and-tell model and the FLP-style extension lemma (Appendix F) Appendix F.6 converts the simultaneous activations of Section 3 into sequential events: `e_j` (node `j` computes its reaction, invisible to the others) and `W` (all computed reactions are revealed: one time step). A state of this *act-and-tell* model is a history together with the set `P` of nodes that have already reacted in the current time step. We model `e_j` by `some j` and `W` by `none`; `W` is only enabled when `P` is nonempty, so every time step activates a nonempty set, as Section 3 requires. The colour of a state is `F.lims h P` (`Valency.lean`). The main result, `exists_bivalent_after`, is the FLP-style extension lemma (the content of Lemmas F.8 and F.12): in a convergent system with self-independent `k`-recall reaction functions, from every bivalent state and for every event `e` some extension that avoids `e` and then performs `e` reaches a bivalent state. The proof does not need stationarity: both paths through each "diamond" of Fig. 3 take the same number of time steps, as Appendix F.7 observes. `exists_segment` packages two applications into a statement about schedules: from a bivalent history, for every node `i`, some finite schedule segment that activates `i` leads to a bivalent history. -/ -- CSLib candidate (with the rest of the
