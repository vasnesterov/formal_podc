import Mathlib /-! # Distributed computing with adaptive heuristics: the model (Section 3) Jaggard, Schapira, Wright, *Distributed Computing with Adaptive Heuristics* (PODC 2011 title: *Distributed computing with rules of thumb*), arXiv 0910.1585v2, Section 3. There are finitely many computational nodes `i : ι`, node `i` has action space `A i`. A *history* `h ∈ H_w` (`w ≥ 1`) is a nonempty sequence of action profiles; we store it as the current profile `h.cur` and the earlier profiles `h.past`, **most recent first**, so `h.time = w` is the number of recorded time steps. A (deterministic) *reaction function* of node `i` is a sequence of functions `f(i,t) : H_{t-1} → A i`; here `F.f i t h` (only applied to histories with `h.time = t - 1`). A schedule `σ : ℕ → Finset ι` activates the nonempty set `σ t` at time step `t`. The `(s⁰, σ)`-dynamics starts with the history `s⁰ ∈ H_w` at time `w + 1`; at time `t` the nodes in `σ t` simultaneously apply `f(i,t)` to the history so far, the other nodes keep their action. ## Main definitions * `System.step`, `System.run`: the dynamics. * `IsSchedule`, `Fair`: nonempty activation sets; every node activated infinitely often. * `ConvergesTo`, `Convergent`, `IsStableState`: convergence of the dynamics, convergent systems (all initial states, all fair schedules), stable states (limits of fair dynamics). * `SelfIndependent`, `HasRecall`, `Stationary`: restrictions 2–4 of
