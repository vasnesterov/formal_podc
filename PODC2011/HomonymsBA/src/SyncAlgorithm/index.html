import Papers.PODC2011.HomonymsBA.Basic import Papers.PODC2011.HomonymsBA.ClassicalBA /-! # Proposition 2: synchronous BA is solvable with innumerate processes if `ℓ > 3t` The transformation `T(A)` of Figure 3 of the paper. Given a classical synchronous Byzantine agreement algorithm `A` for `ℓ` processes with unique identifiers (here: an algorithm of CSLib's classical model `Cslib.Byzantine.PartialSync` with lock-step runs, `gst = 0`, `δ = 0`), the processes with identifier `i` (the *group* `G(i)`) cooperatively simulate process `i` of `A`. Each phase has three rounds: * *selection* (`rnd ≡ 0 mod 3`): send the simulated state; adopt a deterministic choice among the states received from identifier `i` (`pick`); * *deciding* (`rnd ≡ 1`): send the (latched) decision of the simulated process; decide `v` if `(j, v)` was received from `t + 1` different identifiers `j` (`decRule`); * *running* (`rnd ≡ 2`): send `A`'s message of the selected state; from each identifier keep the message only if it is the unique one received from it (`filt`); take `A`'s step. The algorithm depends on the received pairs only through membership: innumerate. Correctness (`TA_solves`): from a run `α_H` of `T(A)` we build a run `α_S` of `A` (`simRun`) in which identifier `i` is correct iff its group is correct, the correct groups' selected states are the states of `α_S` (`st_simRun`) and the Byzantine simulated processes deliver what the selected process of the receiving group kept from them. Deviations: `A` may send different messages to different identifiers (the paper assumes broadcast WLOG); the decision of the simulated process is latched (`lat`) so that a correct group keeps announcing it; a process decides at most once (`out` is latched).
