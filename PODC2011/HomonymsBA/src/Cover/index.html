-- CSLib candidate: Cslib/Computability/Distributed/Homonyms/Cover.lean import Papers.PODC2011.HomonymsBA.Basic /-! # Covering systems for homonymous systems A *covering system* is a run of an algorithm on a set `Q` of processes with an arbitrary communication relation `adj` (`adj c' c`: `c` hears `c'`) and no Byzantine process (`coverRun`). Given an `n`-process system `P`, a set of correct processes mapped into the cover by `e`, such that (1) the correct processes hear each other in the cover, and (2) every other cover node a correct process hears carries the identifier of a Byzantine process, the Byzantine processes can deliver to each correct `p` exactly what `e p` hears from outside the image of `e` (`scenario`). Then every correct `p` has the state of `e p` (`st_scenario`). The delivered multiset may be post-processed by `g`: `g = id` for numerate algorithms (unrestricted Byzantine processes) and `g = dedup` for innumerate algorithms; in the latter case the Byzantine processes are *restricted* as soon as the cover nodes outside the image that a correct process hears with a common identifier are in the same state (`restricted_scenario_dedup`).
