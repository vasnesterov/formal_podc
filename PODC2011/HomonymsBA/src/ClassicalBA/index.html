We take the classical model of CSLib (`Cslib.Byzantine.PartialSync`, synchronous runs `gst = 0` with delay bound `δ = 0`, i.e. lock-step rounds) and obtain such an algorithm from CSLib's interactive consistency for `n > 3t` (Pease–Shostak–Lamport) and the containment-condition reduction (Civit et al.): Byzantine agreement validity (`baValidity`, "if all correct processes propose `v`, only `v` may be decided") satisfies the containment condition for `n > 2t`. Main result: `classicalBA_exists`. -/ namespace Podc.HomonymsBA open Cslib.Byzantine.PartialSync Finset variable {P V : Type*} [Fintype P] [DecidableEq P] /-- Byzantine agreement validity: if all processes of `π(c)` propose `v`, only `v` is admissible. -/ def baValidity (P V : Type*) : ValidityProperty P V V := fun c => {w | ∀ v, (∀ p, c p ≠ none → c p = some v) → w = v} open Classical in /-- `baValidity` satisfies the containment condition for `n > 2t`: decide the value proposed by at least `n - t` processes of the configuration (if any). -/ theorem baValidity_containment [Nonempty V] {t : ℕ} (hn : 2 * t < Fintype.card P) : (baValidity P V).ContainmentCondition t := by refine ⟨fun c => if h : ∃ v, Fintype.card P - t ≤ (univ.filter fun p => c p = some v).card then Classical.choose h else Classical.arbitrary V, ?_⟩ intro c _ c' hc' hcont v hv -- the procs of `c'` all propose `v` in `c` have hsub : c'.procs ⊆ univ.filter fun p => c p = some v := by intro p hp rw [Config.mem_procs_iff_ne_none] at hp simp only [Finset.mem_filter, Finset.mem_univ, true_and] rw [hcont p hp];
