We fix the system `P = Fin n` in which processes `k < ℓ` are Byzantine and have identifier `k` (one Byzantine process per identifier, `ℓ ≤ t` of them), and all `n - ℓ ≥ 2` correct processes have identifier `0`. Runs are synchronous, without losses, and the Byzantine processes deliver at most one message per identifier, recipient and round (`AdvOK`, restricted). * `Dec inp adv k`: the decisions of correct processes in admissible runs that agree with `adv` before round `k` (the decisions reachable from the configuration at round `k`); `Multi` = at least two different reachable decisions (multivalent). * **Lemma 17** (`exists_common_dec`): if two runs give the same states to all correct processes except `p` up to round `k`, some decision is reachable from both. The Byzantine process `0` (identifier of `p`) impersonates `p` with the other run's state (`simCfg`, `simCfg_swap`). * **Lemma 21** (`exists_multi_init`): some initial configuration is multivalent. * **Lemma 22** (`exists_multi_succ`): every multivalent configuration has a multivalent successor. * `prop16`: an infinite run of multivalent configurations, in which no correct process decides. -/
