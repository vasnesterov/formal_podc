import Papers.PODC2011.CoordinatedConsensusDynamic.StaticPathDefs /-! # Theorem 6.8: a static graph of diameter `D` on which deciding takes `Ω(nD/Δ)` rounds The paper only sketches the proof and never specifies the graph `H`. We take * the path `0 — 1 — ⋯ — (n-1)`, * a *left star*: node `a` is joined to every node `x < a`, * a *right star*: node `b` is joined to every node `y > b`, with `b - a = D - 2`, so `H` has diameter `≤ D` (`hGraph_walk`): every node is within one hop of the segment `[a, b]`, whose ends are `D - 2` apart. All round graphs we use are the path plus a subset of the two stars, so they are connected. `ex n a b σ p q` is the execution (inputs `σ`) whose round-`r` graph is the path, plus the left star if `r ≤ p`, plus the right star if `r ≤ q`. `ex σ t t` is "static `H` up to time `t`, then static path"; `ex σ 0 0` is the static path. With `T` the time at which indistinguishability is measured and `h = b - a + 1`: * (`stepL`) deleting the left star from the rounds `(p', p]` is invisible to node `n - 1` at time `T` provided the right star is only present up to round `q ≤ p' + h` and `T ≤ n - 1 - a`: information leaving the left star in round `> p'` travels along the path at speed `1` and reaches the right star at node `b` only after its last round `q`; * (`stepR`) symmetrically, deleting the right star from rounds `(q', q]` is invisible to node `0` provided `p ≤ q' + h` and `T ≤ b`. Alternating the two steps (each moves the higher of `p, q` to `(the lower) - h`) reaches the static path in `⌈t/h⌉ + 1` steps (`walk_to_path`); two more steps flip the inputs of the two halves of the path (`flipHi`, `flipLo`), which requires `2T + 2 ≤ n`. Lemma 6.4 then gives: no node decides by time `t` as soon as `t + (⌈t/(D-1)⌉ + 3) Δ ≤ n/2 - 1` (`theorem_6_8`), i.e. already for `t (D - 1 + Δ) + 4Δ(D - 1) ≤ (D - 1)(n/2 - 1)` (`theorem_6_8'`), which is `Ω(nD/Δ)` for `D = O(Δ)` (and `Ω(n)` for `D ≥ Δ`).
