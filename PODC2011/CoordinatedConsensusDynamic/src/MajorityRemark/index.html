We prove that this rule solves consensus in the system `BoundN` (any valid bound `N ≥ n`), is comparison-based, and, for every `3 ≤ n ≤ N ≤ 2n - 3`, decides before hearing from everybody in the static line with all inputs `0`, and also with all inputs `1`. -/ namespace CoordCons open DGraph Relation Function Classical open Cslib.DynNet (Journey) /-- The majority protocol with an upper bound `N` on the count. -/ noncomputable def majRule : Decision Bool := fun G u t => if G.N / 2 + 1 ≤ heard G u t true then some true else if G.N / 2 + 1 ≤ heard G u t false then some false else if G.N ≤ t + 1 then some (decide (heard G u t false < heard G u t true)) else none theorem majRule_local : Local majRule := by intro G H u t h simp only [majRule, heard_congr h, h.N_eq] theorem heard_mono {G : DGraph Bool} {u t t' : ℕ} (h : t ≤ t') (b : Bool) : heard G u t b ≤ heard G u t' b := Finset.card_le_card (Finset.filter_subset_filter _ (past_mono_left h)) /-- In `BoundN`, every decision of `majRule` is the majority value. -/ theorem majRule_eq {G : DGraph Bool} (hG : BoundN G) {u : ℕ} (hu : u ∈ G.V) {t : ℕ} {v : Bool} (h : majRule G u t = some v) : v = majority G := by have hsum := cnt_add G have hN := hG.2 have h1 := heard_le_cnt (G := G) u t true have h2 := heard_le_cnt (G := G) u t false simp only [majRule] at h unfold majority split_ifs at h with ha hb hc · cases h;
