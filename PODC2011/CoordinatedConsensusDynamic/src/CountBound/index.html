For `i ∈ {0,1}` the signature `σ_{V,i}` gives input `i` to everybody and the bound `N = 2n`. **Theorem 4.1 (as stated).** For any comparison-based algorithm there is an `i ∈ {0,1}` such that in *any* execution `(V, E, σ_{V,i})`, no node `u` decides at time `t` unless `past(u,t)(0) = V`. The quantifier order makes this false: the bit `i` may have to depend on `n`. The algorithm `cexRule` ignores UIDs; with bound `N` it is biased towards `bias N` (= `0` iff `⌊N/2⌋` is even): decide `bias N` as soon as an input `bias N` has been heard, otherwise decide `¬ bias N` at time `N - 1`. It solves consensus in `BoundN` (`cexRule_consensus`), is comparison-based (`cexRule_comparisonBased`), and violates the literal statement for both `i` (`theorem_4_1_literal_false`: `n = 2` all zeros, `n = 3` all ones, decision at time `0`). The paper's proof (stitching two executions with disjoint UIDs and giving everybody the bound `2n`) works when both executions have the same size `n`, i.e. for the corrected statement "for every `n`
