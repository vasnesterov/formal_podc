import Papers.PODC2011.CoordinatedConsensusDynamic.Coordination /-! # Cycles, paths and executions for the static-line lower bound (Section 6.1) Nodes are `u_0, …, u_{n-1}` (UIDs `0, …, n-1`, indices mod `n`). * `cyc n` is the cycle `C = u_0, u_1, …, u_{n-1}, u_0`. * `path n k` is the path `P_k = u_{k+1}, …, u_{k+n}`, i.e. `C` minus the edge `{u_k, u_{k+1}}`. It is defined through the *position* `pos n k x` of `x` on `P_k` (`u_{k+1}` has position `0`, `u_k` has position `n - 1`), so that all reasoning about it is linear arithmetic. * `exec n σ g` is the execution with node set `{0, …, n-1}`, inputs `σ`, `N = n` and communication graph `g r` in round `r`; `IsCP n g` says that every round graph is `C` or some `P_k`. Such executions are admissible in the system `KnownN n` when `n ≥ 3`. We also record the generic tools used for the "speed of information" arguments: a forward invariant principle for causal chains (`reach_inv`) and padding of walks in the similarity graph. -/ namespace pos (n k x : ℕ) : ℕ := (x + (n - 1 - k % n)) % n /-- The cycle `C = u_0, …, u_{n-1}, u_0`. -/ def cyc (n : ℕ) (x y : ℕ) : Prop := x < n ∧ y < n ∧ (x + 1 = y ∨ y + 1 = x ∨ (x = 0 ∧ y + 1 = n) ∨ (y = 0 1 = pos n k x) /-- Every round graph is the cycle or one of the paths. -/ def IsCP (n : ℕ) (g : ℕ → ℕ → ℕ → Prop) : Prop := ∀ r, g r = cyc n ∨ ∃ k, g r = path n k /-- The execution on `{u_0, …,
