Two statements are proved by a joint induction on `k`: * `HideP k` ("hiding", the paper's induction claim): for every `t ≥ k`, every set `X ⊆ V` with `|X| + k + 1 ≤ n` and every `u ∉ X`, we can move inside the similarity component of `(G, t)` to an execution `G'` that agrees with `G` on the inputs and on all rounds `r ≤ t - k`, and in which no node of `X` at time `t - k` causally influences `(u, t)`. * `FreeP k` ("freedom"): if `k + 2 ≤ n`, any two executions with the same inputs that agree on rounds `1, …, t - k` are in the same similarity component at time `t`. `FreeP (k+1)` follows from `FreeP k` and `HideP k` by changing round `t - k` one edge at a time: to add or remove the edge `{a, b}` we first hide `{a, b}` at time `t - k` from some third node (this is where the paper's "remove edges by first hiding both endpoints" is made precise; it needs `k + 3 ≤ n`). `HideP (k+1)` follows from `FreeP (k+1)` and `HideP k` exactly as in the paper's sketch, except that we replace round `t - k` by a star centred at a fresh node `w` (any connected graph in which `X` only talks to `X ∪ {w}` works). -/ namespace CoordCons open Relation open Cslib.DynNet (Journey) variable {α : Type*}
