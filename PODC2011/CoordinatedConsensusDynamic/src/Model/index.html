import Mathlib import Cslib.Computability.Distributed.DynamicNetworks.FullInfo import Cslib.Computability.Distributed.Knowledge.Basic /-! # The dynamic-network model of Kuhn–Moses–Oshman (PODC 2011) Synchronous rounds; round `r ≥ 1` takes place between time `r - 1` and time `r`. In every round the adversary picks an undirected communication graph on the (fixed, finite) node set `V` which must be connected (1-interval connectivity); every node broadcasts to its current neighbours. * Nodes are their UIDs: `V : Finset ℕ`. Different executions may have different node sets, which is needed for the "unknown `n`" results. * `input : ℕ → α` is the input assignment (only its values on `V` matter), `N : ℕ` is the a-priori information given to every node (exact count, upper bound on the count, or a dummy `0` when nothing is known). Together these form the paper's *signature* `σ`. * `adj r x y`: `{x, y} ∈ E(r)`. Causality: `G.Reach v s u t` is the paper's `(v, s) ↝_G (u, t)` (reflexive-transitive closure of `(u, t) → (v, t + 1)` iff `u = v` or `{u, v} ∈ E(t + 1)`), i.e. a journey (`Cslib.DynNet.Journey`) in the dynamic network whose graph between times `k` and `k + 1` is `adj (k + 1)`; `G.past u t s` is `past_{(G,u,t)}(s)`. Views / indistinguishability: rather than building the view object of Definition 1, we define the relation "same full-information view" `Indist G H u t` (the paper's `(G, t) ∼_u (H, t)`) recursively: at time `0` a node sees its UID, input and `N`; at time `t + 1` it additionally sees the identities of its round-`t+1` neighbours and their views at time `t`. This is the full-information indistinguishability `Cslib.HeardOf.FIIndist` with the initial views above (`Indist.zero_iff`, `Indist.succ_iff` restate the recursion). `Protocol.state_eq_of_indist` shows that the local state of *every* deterministic protocol is a function of this view, so lower bounds proved for view-local decision functions apply to all protocols. -/ namespace CoordCons open
