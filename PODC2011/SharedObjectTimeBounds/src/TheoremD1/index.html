Then in a system with `n ≥ k` processes, `ε`-bounded clocks and delays in `[d - u, d]`, `|OP| ≥ (1 - 1/k) u`. The proof shifts the run `R₁` (all `op_i` invoked simultaneously by `p_0, …, p_{k-1}`, delays `d - ((i - j) mod k) u / k`) by `x_i = (-(k-1)/2 + ((z - i) mod k)/k) u` (a typo for `-(k-1)/(2k)`, as the later text "`p_z` is shifted by `-[(k-1)/2k] u`" shows), where `z` is the last operation of "the" linearization of `R₁`. Two problems: * the shifted run has clock skew `(1 - 1/k) u`, so the theorem needs `ε ≥ (1 - 1/k) u` (the thesis assumes the optimal skew `ε = (1 - 1/n) u` in the proof); * Step 1.1 claims a single permutation `π` that determines the results of *every* later sequence of operations; correctness does not give this (an algorithm may decide the order lazily). We replace the non-equivalence hypothesis by `LastRevealing`: one fixed sequence of later invocations `α` whose results determine the last element of the permutation (for a register: one read; for a stack: one pop; for a queue: `k` dequeues). For `k = 2` the thesis hypothesis implies it (`theorem_D1_two`). Proof as in the thesis, with the following details: `p_0` first runs `ρ` sequentially (times `0, g, 2g, …`), the `op_i` start once `ρ` is over, and `α` is run by `p_0` after all `op_i` responded. The shift is normalised so that `p_0` is not moved (`x' = x - x_{p_0}`; a uniform shift changes neither delays nor skews), so the `ρ`- and `α`-invocations are the same in `R₁` and `R₂` and both runs return the same results for `α` (same local histories).
