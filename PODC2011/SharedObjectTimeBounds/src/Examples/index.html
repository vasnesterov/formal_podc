(`stack_push_peek_not_E1`); * the "test-and-reset" register (`TR`): writes satisfy the thesis's own hypothesis of Theorem D.1 (permutations with different last writes are not equivalent, `tr_nonEquiv`) but no fixed query sequence reveals the last write in the way the runs of the thesis's proof need: for every query sequence there are answers compatible, for every `z`, with a
