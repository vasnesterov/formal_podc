import Mathlib import Cslib.Computability.Distributed.Local.Locality -- CSLib candidate: `Alg`, `res`, `Stage`, `Pruning` and the alternating-algorithm machinery -- (target e.g. `Cslib/Computability/Distributed/Local/Terminating.lean`). /-! # The model of Korman–Sereni–Viennot, PODC 2011 (Section 2 and Section 3.2–3.3) A. Korman, J.-S. Sereni, L. Viennot, *Toward More Localized Local Algorithms: Removing Assumptions Concerning Global Knowledge*, PODC 2011 / Distributed Computing (arXiv:1512.03306). We work in the LOCAL model with unique identifiers, in the extensional style of `Cslib.Computability.Distributed.Local.Locality`: the identifiers are the elements of a fixed type `V`; an *instance* is a pair `(G, x)` of a graph `G : SimpleGraph V` and an input labelling `x : V → Option α`, whose node set is `supp x = {v | x v ≠ none}` and whose graph is `res G x` (the subgraph of `G` induced by `supp x`). This lets us speak about the induced subgraphs produced by pruning without changing the vertex type. * `Problem V α β`: a problem `Pb` (a predicate on triples `(G, x, y)`) which only looks at the induced instance `res G x` and at the outputs of nodes of the instance, and which contains the empty instance. * `Family V α`: a collection `F` of instances (we require `res G x = G` for its members). * `Alg V α β`: a (uniform, deterministic) local algorithm with termination: `A.out t G x v` is the output of node `v` after `t` rounds (`none` = not terminated yet); it is a `t`-local function of the instance, and outputs are final. `Alg.SolvesWithin A Pb G x T`: after `T` rounds all nodes of the instance have terminated, and their outputs form a solution. * `Stage V α β`: an algorithm that runs for a fixed number `rad` of rounds and produces an output at every node (e.g. `Alg.restrict`, "algorithm `A` restricted to `t` rounds"). * `Pruning Pb F`: a pruning algorithm (Section 3.2): a constant-time uniform algorithm which, given a tentative output `ŷ`, prunes a set of nodes and possibly changes the inputs of the others; it satisfies *solution detection* and *gluing*. `Pruning.Monotone P p`: `P` does not increase the parameter `p`. * `Pruning.alg P phases`: the alternating algorithm (Section 3.3) for a sequence of stages, given as a sequence of finite *phases* (lists of stages); nodes output at the end of the phase in which they are pruned. ## Main results * `Pruning.solvesWithin_of_runList_empty` (Observation 3.4 + running time): if all nodes are pruned after the first `s` phases, the alternating algorithm solves the instance within `max s (duration of the first s phases)` rounds. * `Pruning.act_runList_eq_none_of_mem`: progress — if a stage of a list solves every instance reachable during the run, all nodes are pruned at the end of the list. -/ open Cslib.Local SimpleGraph namespace Podc.UniformLocalAlgorithms variable {V α β γ : Type*} /-!
