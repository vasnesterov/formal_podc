import Podc.Foundations.GameTheory.NeverBestResponse /-! # First-price cost-sharing games (Section 3.2 of [NSVZ]) N. Nisan, M. Schapira, G. Valiant, A. Zohar, *Best-Response Mechanisms* (ICS 2011; brief announcement at PODC 2011), Section 3.2: Theorem 3.3 and the bid rule of Theorem 3.4. Users `i : ι` (finitely many) have cost shares `c i S` (for `i ∈ S`), nonnegative and cross-monotonic (`i ∈ S ⊆ T → c i T ≤ c i S`), and private values `v i`. In the first-price cost-sharing game every user bids `b i : ℝ≥0`; the *serviced set* for `b` is the maximum-cardinality set `S` with `c j S ≤ b j` for all `j ∈ S`; a serviced user gets `v i - b i`, others get `0`. ## Main definitions * `CostSharingRule`: cross-monotonic cost shares. * `CostSharingRule.serviced`: the serviced set (the union of all feasible sets), with the bridge `serviced_unique_maxCard`: it is *the unique* feasible set of maximum cardinality (so the paper's lexicographic tie-breaking among such sets is never used). * `CostSharingRule.game`: the game, with the (repaired) tie-breaking "prefer bids strictly closer to `v i`, at equal distance the lower bid". * `CostSharingRule.gameLit`: the game with the *literal* tie-breaking of the paper (`|s - vᵢ| ≤ |t - vᵢ| → t ≺ᵢ s`, reflexive), see `gameLit_isNBR`. * `CostSharingRule.outcome` (`s*`): users in `R_v = serviced v` bid `c j R_v`, the others `v i`. * `CostSharingRule.moulinSet`: Moulin's mechanism. * `CostSharingRule.mechBid`: the bid prescribed by the mechanism of Theorem 3.4. ## Main statements * `theorem_3_3` (Theorem 3.3): NBR-solvability by the explicit 3-step elimination `elimSeq`; `s*` is the unique outcome and a PNE; its serviced set is the set chosen by Moulin's mechanism (`moulinSet_eq`), each serviced user pays its Moulin cost share `≤ vⱼ`; `s*` is a clear outcome (`clearWitness`, player-specific order with witness index `1`); `e_G ≤ n` for *every* `n` (`elimParam_le_card`; `n = 1, 2` need 1 resp. 2 steps) and `e_G ≤ 3`. * `isBR_mechBid` (Theorem 3.4's bid rule is a tie-broken best response; `mechBid_eq_bestBid` identifies it with `min (price) vᵢ`), `hasBR`. * `gameLit_isNBR`, `gameLit_solves`: with the literal (reflexive) tie-breaking rule every bid is NBR in every subgame, so every profile is a one-step outcome. The paper's assumption `vᵢ > 0` is never used. -/ open Set Function Cslib.GameTheory open scoped NNReal namespace Podc.BestResponseMechanisms.CostSharing /-! ### A generic criterion for elimination steps -/ section Generic variable {ι : Type*} {S : ι → Type*} {R : Type*} [DecidableEq ι] [LinearOrder R] {G : TieBreakGame ι S R} -- CSLib candidate /-- If the tie-breaking orders are total and `br i s` is a tie-broken best response of `i` to `s`, then passing from `H` to `H' ⊆ H` is an NBR-elimination step as soon as every best response to a profile of `H` lies in `H'`. -/ theorem elimStep_of_isBR (htot : ∀ i (x y : S i), x ≠ y → G.prec i x y ∨ G.prec i y x) (br : ∀ i, (∀ j, S j) → S i) (hbr : ∀ i s, G.IsBR i (br i s) s) {H H' : Subgame S} (hsub : ∀ i, H' i ⊆ H i) (hmap : ∀ i (s : ∀ j, S j), (∀ j, j ≠ i → s j ∈ H j) → br i s ∈ H' i) : G.ElimStep H H' := by refine ⟨hsub, fun i y _ hy' s hs => ⟨br i s, hsub i (hmap i s hs), ?_⟩⟩ have hne : br i s ≠ y := fun h => hy' (h ▸ hmap i s hs) have hnb := hbr i s y unfold TieBreakGame.Beats at hnb ⊢ rcases lt_trichotomy (G.utility i (update s i y)) (G.utility i (update s i (br i s))) with h | h | h · exact Or.inl h · rcases htot i _ _ hne with h' | h' · exact absurd (Or.inr ⟨h.symm, h'⟩) hnb · exact Or.inr ⟨h, h'⟩ · exact absurd (Or.inl h) hnb -- CSLib candidate /-- `e_G ≤ r` as soon as some elimination of length `r` solves the game. -/ theorem elimParam_le {E : ℕ → Subgame S} {r : ℕ} {s : ∀ i, S i} (h : G.Solves E r s) : G.elimParam ≤ r := Nat.sInf_le ⟨E, s, h⟩ end Generic /-!
