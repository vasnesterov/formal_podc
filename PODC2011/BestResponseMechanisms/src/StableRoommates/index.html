Students `i : ι`; student `i` may propose to any *acceptable* partner `j` (`acc i j`, a symmetric irreflexive relation; the paper's game has `acc = (· ≠ ·)`, the bipartite intern–hospital repair has `acc i j ↔ side i ≠ side j`). `α i j > 0` is the rank of `j` for `i` (larger = better, injective on acceptable partners). Student `i` proposing to `j` gets `α i j` iff no other student proposing to `j` is ranked by `j` above `i`, and `0` otherwise. ## Main results * `theorem_3_1`: in a cycle-free game (with strict total tie-breaking orders) there is an NBR elimination of length `≤ n` ending at a profile `s` that is a clear outcome, a pure Nash equilibrium, the outcome of every NBR elimination, and whose matching (mutual proposals) is stable. Corollaries: `nbrSolvable`, `elimParam_le`, `hasClearOutcome`. * `cycleFree_of_correlated`, `theorem_3_1_correlated`: correlated markets. * `cycleFree_of_bipartite`, `theorem_3_1_internHospital`: intern–hospital markets with a common hospital ranking, where interns propose only to hospitals and vice versa (bipartite repair). * `internHospital_counterexample`: in the paper's game (`acc = (· ≠ ·)`), an intern–hospital market (three interns with cyclic preferences, one hospital) is *not* NBR-solvable for any irreflexive tie-breaking and has no stable matching. Engine: `not_nbrSolvable_of_isBR`. * `exists_two_nash`: without tie-breaking the PNE is not unique (odd `n`). * `mechanism_isBR`: the announcement rule of the mechanism of Theorem 3.2 is a tie-broken best response. ## Proof structure A *schedule* `(t, s)` fixes every student `i` at time `t i` to strategy `s i`, either as a pair of mutual favourites among the students not fixed before (`Paired`) or as a student with no acceptable partner left (`Dead`, `s i` = its tie-breaking favourite). `solves_of_good`, `clearWitness_of_good`, `isStable_of_good` analyse the elimination sequence `elimSeq t s` of a good schedule; `exists_good` builds one (≤ `n` steps) using `exists_mutual_favourites`, the "follow your favourite" argument of the paper. -/ open Set Function Cslib.GameTheory Cslib.GameTheory.TieBreakGame namespace Podc.BestResponseMechanisms.StableRoommates variable {ι : Type*} /-! ### The model -/ /-- The strategies of student `i`: its acceptable partners. -/ abbrev Strat (acc : ι → ι → Prop) (i : ι) := {j : ι // acc i j} /-- The utility of student `i` in the stable-roommates game: `α i j` if `i` proposes to `j` and no other student proposing to `j` is ranked higher by `j`; `0` otherwise. -/ def util [Fintype ι] [DecidableEq ι] (acc : ι → ι → Prop) (α : ι → ι → ℕ) (i : ι) (s : ∀ j, Strat acc j) : ℕ := if ∀ k, k ≠ i → (s k).1 = (s i).1 → ¬ α (s i).1 i < α (s i).1 k then α i (s i).1 else 0 /-- The stable-roommates game with tie-breaking rule `prec`. -/ @[reducible] def game [Fintype ι] [DecidableEq ι] (acc : ι → ι → Prop) (α : ι → ι → ℕ) (prec : ∀ i, Strat acc i → Strat acc i → Prop) : TieBreakGame ι (Strat acc) ℕ where utility := util acc α prec := prec /-- A ranking cycle `r 0, r 1, …, r (k-1)` (`k > 2`, distinct students, indices mod `k`): each `r (i+1)` ranks `r (i+2)` higher than `r i`.
