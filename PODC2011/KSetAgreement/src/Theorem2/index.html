import Papers.PODC2011.KSetAgreement.Restrict /-! # Theorem 1 in the asynchronous model, Theorem 2 and Corollary 5 `theorem1_async` is the paper's Theorem 1 (reduction of `k`-set agreement to consensus in a subsystem) instantiated for the asynchronous crash model, with the hypotheses in the concrete form in which the paper verifies them in Section V: * `k - 1` pairwise disjoint nonempty groups `Dg i` (the paper's `D_i`) whose solo runs (everybody else never takes a step, the group is correct) are admissible — this gives `(dec-D)` and `(B)`; * a set `Dbar` (the paper's `D̄`) with `|Dbar| ≥ 2`, disjoint from all `Dg i`, whose runs with everybody outside `Dbar` initially dead and at most one crash inside `Dbar` are admissible — this is `(D)` (and `(A)`); * `(C)` is CSLib's FLP theorem (`Cslib.FLP.Consensus.one_not_exists`): no consensus algorithm for `≥ 2` processes tolerating one crash. The proof builds, from a `k`-set agreement algorithm `A`, the CSLib binary consensus algorithm `(A.restrict Dbar).alg (fun _ b => c b) δ` (inputs `c false`, `c true` for the bits, decisions decoded by `δ`), and proves that it solves consensus with one crash: agreement by merging an execution of `Dbar` with the solo runs of the `Dg i` (which decide `k - 1` further distinct values; this is the paper's Fact 1), validity and termination by lifting executions of the restricted algorithm to executions of `A` in which the processes outside `Dbar` are initially dead.
