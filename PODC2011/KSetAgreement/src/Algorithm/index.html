import Papers.PODC2011.KSetAgreement.Basic import Papers.PODC2011.KSetAgreement.SourceComponents /-! # The k-set agreement algorithm for initially dead processes (Section VI of [BRS11]) The two-stage protocol of Fischer, Lynch and Paterson for initially dead processes, as generalized in Section VI of the paper, with `L = n - f` and `δ = L - 1 = n - f - 1` (the parameter `d` below): * **Stage 1.** Upon waking up, a process sends a stage-1 message (its id) to all others and waits for stage-1 messages from `d` other processes; the set of these senders is its *in-list*. * **Stage 2.** Having chosen its in-list `I`, it sends `(x_p, I)` to all others, and records all stage-2 messages it receives (`know`). The in-lists define the digraph `G` with edges `u → r` iff `u ∈ I_r`. * **Decision.** As soon as `know` is *closed* (it contains `p` and, for every recorded `r`, all members of `I_r`), `p` knows all its ancestors in `G` together with their in-lists. It decides the input of `m`, the minimum *root* ancestor of `p` (a root is a vertex of a source component).
