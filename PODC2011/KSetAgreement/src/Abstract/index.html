import Mathlib /-! # Theorem 1 in the paper's model-agnostic form Theorem 1 of [BRS11] is stated for an arbitrary "system model" `M` (any set of admissible runs for each algorithm) and a restricted model `M' = ⟨D̄⟩`. We formalize this generic setting abstractly: a model gives, for every algorithm, a set of runs; a run gives every process a *view* (its sequence of local states until it decides, Definition 2), from which the process' input and decision are read off; a run says which processes are correct; and the model says, for every run, whether the processes of `D̄` receive no message from `D` before all of `D̄` have decided (property `(dec-D̄)`). * `Theorem1Statement` is Theorem 1 exactly as stated (conditions (A)–(D)). * `theorem1_statement_false`: read literally, it fails in a model that fixes an input value (outside the paper's problem definition, where inputs are arbitrary and admissibility does not depend on them; there the missing hypothesis (E) holds, so this is an under-specified statement). In the paper's proof, Fact 1 ("in each run of `R(D̄)` all processes of `D̄` decide on a common value") is derived from (B) and `k`-agreement alone, and the consensus algorithm `A|D̄` is claimed to satisfy validity in `M'`; both silently assume that the processes of `D̄` can only decide values proposed in `D̄`. Counterexample: `n = 3`, `k = 2`, `D = D₁ = {0}`, `D̄ = {1, 2}`, `V = Fin 4`; in `M` the processes never communicate and process `0`'s input is always `0`; `A` = "decide `0`" solves (even) consensus in `M`, while all of (A)–(D) hold with `M'` = `D̄` without communication, inputs in `{1, 2, 3}`. * `condB_fails`: with the values `v₁, …, v_{k-1}` fixed in advance, condition (B) fails as soon as a run of `R(D̄)` has a process of `D̄` proposing some `v i` — which is always the case in the paper's applications, where the inputs are arbitrary distinct values. * `theorem1_corrected`: Theorem 1 holds with the missing hypothesis (E) (processes of `D̄` decide only values proposed in `D̄` in the runs of `R(D̄)`), with run-dependent values in (B), with (D) strengthened to provide runs in `R(D̄)` (the paper's "clearly `ρ ∈ R(D̄)`" does not follow from indistinguishability *until decision*, which says nothing about a process of `D̄` after it has decided while another one has not) that preserve correctness of the processes of `D̄` (needed for termination of `A|D̄`, which the paper's proof does not address), and with (C) only for the algorithm `A|D̄`. Condition (A) is not needed. In the paper's applications (Theorem 2 / Corollary 5) all extra hypotheses hold; see `KSetAgreement.theorem1_async` for the concrete asynchronous version, proved from CSLib's FLP. -/ namespace
