import Mathlib import Cslib.Foundations.Combinatorics.Digraph.Walk /-! # Source components of finite digraphs (Lemmas 6 and 7 of [BRS11]) Biely, Robinson, Schmid, *Easy Impossibility Proofs for k-Set Agreement in Message Passing Systems*, PODC 2011 (arXiv 1103.3671v2), Section VI. A digraph is a relation `E : α → α → Prop` on a finite type (`E u v` = edge `u → v`). A *source component* is a strongly connected component with no incoming edges from outside (`IsSourceComponent`, the library notion `Digraph.IsSourceComponent` of `Cslib.Foundations.Combinatorics.Digraph.Walk` for the digraph `⟨E⟩`); equivalently (`isSourceComponent_iff`) a nonempty, strongly connected set of vertices closed under in-neighbours. * `IsRoot E v`: every ancestor of `v` is a descendant of `v` (the shared `Digraph.InSourceComponent`); the source components are exactly the ancestor sets `anc E v` (`Digraph.ancestors`) of roots `v` (`isSourceComponent_anc`, `IsSourceComponent.eq_anc`). * Every vertex has a root ancestor (`Digraph.exists_inSourceComponent`). * `exists_sourceComponent` (**Lemma 6**) and `exists_sourceComponent_anc` (**Lemma 7**). * `IsSourceComponent.eq_or_disjoint`, `card_sourceComponents_le`: distinct source components are disjoint, so there are at most `⌊n / (δ + 1)⌋` of size `≥ δ + 1`. -/ -- CSLib candidate: the counting lemmas (the rest is the library theory of -- `Cslib.Foundations.Combinatorics.Digraph.Walk`, specialized to finsets of vertices). namespace KSetAgreement.SourceComp open Relation Finset variable {α : Type*} (E : α → α → Prop) /-- `C` is a *source component* of the digraph `E`: a strongly connected component with no incoming edges from outside, i.e. a source of the condensation DAG (`Digraph.IsSourceComponent` for the digraph with arcs `E`).
