The paper proves this only for the border case `k * n = (k + 1) * f`, by a partitioning argument, and otherwise refers to Theorem 2 — which however is about a *different* failure model (`f - 1` initially dead processes plus one crash during the execution), stronger than initial crashes only, so its impossibility does not transfer. The paper's partitioning argument works verbatim for all `k * n ≤ (k + 1) * f`: split the processes into `k + 1` disjoint groups of size `n - f`; in the run where only group `i` takes steps (everybody
