import Papers.PODC2011.CCvsDSMSeparation.Trace /-! # Stability and regular histories (Definitions 6.3–6.6, 6.8) The paper's regularity (Definition 6.6), relative to the set `B` of *active* processes (the participants outside `B` are the *finished* ones, which are idle and never move again): 1. (`NoSee`) no process reads a value last written by another active process; 2. (`NoTouch`) no process accesses a variable in the module of another active process; 3. (`SoleW`) for every variable `v`: if the last write to `v` is by an active process `q`, then after erasing `q` the last write to `v` is not by an active process. Condition 3 is **weaker** than the paper's ("if `v` is written by more than one process and the last write is by `p`, then `p` is finished"). The paper's condition is not preserved by its own construction (an unstable process kept in the erasing case may write a variable previously written by a finished process), while the weaker one is, and it is all the proof needs: erasing any set of active processes reverts every variable to a value written by a finished process (or to its initial value). -/ namespace Podc.CCvsDSMSeparation variable {N : ℕ} {V Val S : Type*} /-- The (optional) process `w` is not an active process other than `p`. -/ def OkW (B : Finset (Fin N)) (p : Fin N) (w : Option (Fin N)) : Prop := ∀ q, w = some q → q ∈ B → q = p lemma OkW.mono {B B' : Finset (Fin N)} {p : Fin N} {w : Option (Fin N)} (h : OkW B p w) (hB : B' ⊆ B) : OkW B' p w := fun q hq hqB => h q hq (hB hqB) @[simp] lemma okW_none (B : Finset (Fin N)) (p : Fin N) : OkW B p none := by intro q hq;
