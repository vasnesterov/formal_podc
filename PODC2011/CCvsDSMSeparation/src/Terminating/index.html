import Papers.PODC2011.CCvsDSMSeparation.Trace /-! # The paper's notion of termination (Section 2) An *infinite history* is a sequence of events all of whose finite prefixes are executions. It is *fair* if every participating process takes infinitely many steps or eventually terminates (stays idle forever; stopping in the middle of a call would be a crash). An algorithm is *terminating* if in every fair infinite history (with at most one call to `Signal()`) every call completes after finitely many steps of its process. (Finite fair histories end with all participants terminated, so all their calls are complete.) `Terminating.soloTerminating`: this implies the solo form `SoloTerminating` used in the lower bound proof. -/ namespace Podc.CCvsDSMSeparation variable {N : ℕ} {V Val S : Type*} /-- The first `n` events of an infinite history. -/ def pre (h : ℕ → Ev N V Val) (n : ℕ) : List (Ev N V Val) := (List.range n).map h namespace Algorithm variable (A : Algorithm N V Val S) /-- An infinite history of `A`. -/ def InfExec (h : ℕ → Ev N V Val) : Prop := ∀ n, A.Valid (pre h n) /-- Fairness (Section 2): every participant takes infinitely many steps or terminates. -/ def Fair (h : ℕ → Ev N V Val) : Prop := ∀ p, (∃ n, (h n).p = p) → (∀ n, ∃ m ≥ n, (h m).p = p) ∨ ∃ n, (∀ m ≥ n, (h m).p ≠ p) ∧ A.Idle (pre h n) p /-- **Terminating** (Section 2): in every fair history without crashes (and with at most one call to `Signal()`), each call to a procedure completes after finitely many steps. -/ def Terminating : Prop := ∀ h : ℕ → Ev N V Val, A.InfExec h → (∀ n, signals (pre h n) ≤ 1) → A.Fair h → ∀ n o, (h n).op = .inv o → ∃ m > n, (h m).p = (h n).p ∧ ∃ b, (h m).op = .ret b /-! ### From the paper's termination to solo termination -/ lemma lstep_busy_cases {p : Fin N} {c : LState S} {s' : S} {o : Proc} {op : Op V Val} (h : A.lstep p c op = some (s', some o)) : (op = .inv o ∧ c.2 = none) ∨ (op.isAccess = true ∧ c.2 = some o) := by rcases c with ⟨s, _ | o'⟩ · cases op with | inv o' => simp only [lstep, Option.some.injEq, Prod.mk.injEq] at h left;
