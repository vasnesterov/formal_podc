import Papers.PODC2011.CCvsDSMSeparation.Trace /-! # Termination cannot be dropped (Corollary 6.14 as stated) Corollary 6.14 is stated for "any deterministic algorithm" that solves the signaling problem (the word *terminating* of Theorem 6.2 is missing in the statement, although its proof assumes it). Without termination the claim is false: in `spinAlg`, `Poll()` spins forever on a variable in the caller's own module and `Signal()` returns at once. Specification 4.1 only constrains calls that *return*, so `spinAlg` solves the signaling problem, yet no execution has a single RMR in the DSM model (`spinAlg_solves`, `spinAlg_rmr`). The algorithm uses only reads, hence it is also an algorithm "using atomic reads and writes, and either CAS or LL/SC". -/ namespace Podc.CCvsDSMSeparation /-- Local states of `spinAlg`. -/ inductive SpinLoc | idle | spin | sigDone /-- `Poll()` busy-waits forever on the caller's own variable;
