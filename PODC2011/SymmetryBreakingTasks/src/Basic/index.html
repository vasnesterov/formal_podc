Numbering follows the full version. A GSB task `⟨n, m, ℓ⃗, u⃗⟩` is *inputless*: its set of legal output vectors does not depend on the input vector (the identities). An output vector is a map `O : Fin n → Fin m` (process ↦ decided value; the paper's values `1..m` are `0..m-1` here), and it is legal iff every value `v` is decided by at least `ℓ v` and at most `u v` processes (Definition 2). ## Main definitions * `cnt O v` — `#_v(O)`, the number of processes deciding `v`; * `gsb n ℓ u` — the output vectors of the asymmetric `⟨n, m, ℓ⃗, u⃗⟩`-GSB task; * `sgsb n m ℓ u` — the symmetric `⟨n, m, ℓ, u⟩`-GSB task; * instances: renaming `⟨n,m,0,1⟩`, perfect renaming `⟨n,n,1,1⟩`, `k`-WSB, `k`-slot, election. ## Main statements * `lemma_1` — corrected Lemma 1: feasible iff `ℓ v ≤ u v` for all `v` and `∑ ℓ ≤ n ≤ ∑ u`; * `lemma_1_false` — Lemma 1 as stated (without `ℓ v ≤ u v`) is false; * `lemma_2` — symmetric feasibility `m ℓ ≤ n ≤ m u`; * `lemma_4`, `lemma_5` —
