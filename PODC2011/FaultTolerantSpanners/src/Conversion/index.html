A *`k`-spanner algorithm with size bound `f`* (`SpannerAlg G w k f`) is modelled by its outputs on the induced subgraphs `G[S]` (`G.deleteVerts Sᶜ` in CSLib's same-vertex-type convention): a subgraph `run S ≤ G[S]` with `d_{run S}(u, v) ≤ k · d_{G[S]}(u, v)` for `u, v ∈ S` and at most `f |S|` edges. These are the only graphs the conversion ever runs the algorithm on. **Algorithm.** Repeat `α` times independently: every vertex joins `J` with probability `1 - 1/m` (realised as a uniform label in `Fin m`, label `0` = survives, see `Sampling.lean`); run the algorithm on `G \ J = G[surv]`. Output the union `ftUnion A ω` of the `α` spanners. **Results.** * `isWeightedVFTSpanner_ftUnion` — deterministic core: if for every fault set `F` (`|F| ≤ r`) and every edge `uv` of `G \ F` some iteration has `u, v` surviving and `F ⊆ J`, the union is an `r`-fault-tolerant `k`-spanner. * `uprob_good` — that event has probability exactly `(1/m)² (1 - 1/m)^{|F|}` per iteration. * `uprob_not_isVFT_le` — union bound: `Pr[not an r-FT k-spanner] ≤ (n+1)^r n² (1 - q)^α`, with `q = (1/m)² (1 - 1/m)^r`. * `ncard_ftUnion_le`, `uprob_size_fail_le` — if every iteration keeps `≤ 2n/m` vertices then `|E(H)| ≤ α f(⌊2n/m⌋)`; this fails with probability `≤ α e^{-n/(3m)}`. * `conversion_explicit` — both together. -/ open Finset SimpleGraph Cslib.Probability open scoped ENNReal NNReal
