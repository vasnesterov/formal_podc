Model (`Model.lean`): asynchronous message passing between one writer, `R = card Rd` readers and `S = card Obj` storage objects, at most `t` of which are malicious; no authentication; round-based operations (a round terminates once `S - t` objects replied); deterministic protocols with a fixed number `K` of write rounds and `N` of read rounds; atomicity of the SWMR register (§2.2). * `proposition1`: if `S ≤ 4t` and `R > 3`, no implementation has two-round reads. * `lemma1`: with `3 t_k + 1` objects, `t_k` faults and `k` readers there is no implementation with `k`-round writes and three-round reads (`t_{-1} = t_0 = 0`, `t_k = t_{k-1} + 2 t_{k-2} + 1`). * `lemma2`: optimal resilience `S ≤ 3t + 1`: with three-round reads, writes need more than `min {R, ⌊log ⌈(3t+1)/2⌉⌋}` rounds. * `proposition2`: `S ≤ 3t + ⌊t / t_k⌋`: with three-round reads, writes need more than `min {R, ⌊log ⌈(3t_k+1)/2⌉⌋} = min {R, k}` rounds. * `tseq_closed_form`: `t_k = (2^{k+2} - (-1)^k - 3) / 6`. -/ namespace Podc.RobustAtomicStorage open Classical variable {Obj Rd V Msg Rep : Type} [Fintype Obj] [DecidableEq Obj] [Fintype Rd] [DecidableEq Rd] [DecidableEq V] /-- An injection of `Fin n` into the readers when `n ≤ R`. -/ lemma exists_readers {n : ℕ} (h : n ≤ Fintype.card Rd) : ∃ rd : Fin n → Rd, Function.Injective rd := ⟨fun i => (Fintype.equivFin Rd).symm (Fin.castLE h i), fun _ _ hij => Fin.castLE_injective h ((Fintype.equivFin Rd).symm.injective hij)⟩ /-- **Proposition 1** of [DGMSV11] (read lower bound): if `S ≤ 4t` and `R > 3`, then no implementation of a SWMR atomic register (with writes of any number `K ≥ 1` of rounds) has all reads complete in two rounds. -/ theorem proposition1 (P : Proto Obj Rd V Msg Rep) (t : ℕ) (hS : Fintype.card Obj ≤ 4 * t) (hR : 3 < Fintype.card Rd) (hK : 1 ≤ P.K) (hN : P.N = 2) (bot : V) (hV : ∃ v : V, v ≠ bot) : ¬ P.Atomic t bot := by obtain ⟨blk, hblk⟩ := exists_four_blocks t hS obtain ⟨rd, hrd⟩ := exists_readers (n := 4) hR obtain ⟨v₁, hv⟩ := hV exact ReadLB.read_lb P hK hN t Finset.univ.toList (Finset.nodup_toList _) (fun s => Finset.mem_toList.2 (Finset.mem_univ s)) blk hblk rd hrd v₁ bot hv /-- Readers `rd 1, …, rd k` (distinct) from `k ≤ R`. -/ lemma exists_readers' {k : ℕ} (hk : 1 ≤ k) (h : k ≤ Fintype.card Rd) : ∃ rd : ℕ → Rd, ∀ i j, 1 ≤ i → i ≤ k → 1 ≤ j → j ≤ k → rd i = rd j → i = j := by obtain ⟨e, he⟩ := exists_readers h refine ⟨fun i => e ⟨(i -
