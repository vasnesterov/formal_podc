import Papers.PODC2011.RobustAtomicStorage.Label import Papers.PODC2011.RobustAtomicStorage.Blocks /-! # Lemma 1: the write lower bound (§4), block form The objects are partitioned into the blocks `B₀, …, B_{k+1}`, `C₁, …, C_k` (`Blocks.lean`); the hypothesis `Fits k t blk` bounds every set of objects that is malicious in a run, or skipped by a terminated round, by `t`. Writes take `k ≥ 1` rounds, reads three rounds; read `l` (`1 ≤ l ≤ k`) is performed by reader `rd l` (instance `ri l`, one read per reader, `instN`). Read `l`: rounds 1, 2 skip `M_{l-2} ∪ P_{l+1}` (`H12 l` is the set they hear); round 1 reaches `P_l` already in `prinit` (`pinit`, `rdInit`) and the rest `R1 l` later; round 3 skips `M_{l-2} ∪ 𝒞_{l+1}` (`l < k`) or `M_{k-2} ∪ P_{k+1}` (`l = k`) and is delivered in two batches, `Q3a l` (objects that processed rounds 1, 2) and `Q3b l = P_{l+1}` (three pending messages). The phases are `inc2` (round 1 terminated, round 2 reaches `𝒞_j`), `inc3` (rounds 1, 2 terminated, round 3 reaches `Q3a`), `full` (complete read); before round 1 of read `j` the malicious objects of `B_{j-1}`, `C_{j-1}` forge `σ^r_{j-1}` (`hook`). The partial write `wr^{k-i}` (`wrP i`) reaches `B₀` and the `B_j` with `j ≢ i (mod 2)` in its last round (`wc i X` write rounds at block `X`). Correspondence with the runs of the paper (all are label runs, checked canonical by `cexec`): * `prC_one` = `pr_1^C`: `prinit` with read 1 replaced by the forging of `P_1`, the complete write, then read 1, where `P_1` forges its `prinit` state, receives round 1 and forges `σ*` (`rdStart`); malicious set `P_1`. Read 1 succeeds the write, so it returns `v₁`. * `prC_succ l` = `pr_l^C` (`2 ≤ l ≤ k`): `prinit` with read `l` replaced by forging, `wr^{k-l+1}`, reads `1..l-3` incomplete (`inc2`), read `l-2` incomplete (`inc3`), read `l-1` complete, read `l` complete (started by `rdStart`); malicious set `M_{l-3} ∪ P_l` (`FC l`). Read `l` succeeds read `l-1`, so it returns `v₁` if read `l-1` does. * `dpr` = `Δpr_k`: `prinit`, no write, reads `1..k-1` incomplete (`inc2`), read `k` complete; malicious set `M_{k-1}`. There is no write, so read `k` returns `⊥`. The paper's `pr_l` and `Δpr_l` for `l < k` are not needed: every read `l` sees the canonical transcript `T (ri l, ·)` in each run where it occurs, so it returns the same value `cv l` in all of them (`Sim.lean`). `refLog L X` is the state of block `X` (of index `≥ L`) at the end of the paper's `Δpr_L`, i.e. `σ^r_L` (and `σ*_{k-L-1}` for the blocks of `P_{L+1}`); `pre`, `cr` are the labels of `prinit` and of the incomplete reads.
