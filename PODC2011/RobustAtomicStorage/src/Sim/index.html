import Papers.PODC2011.RobustAtomicStorage.Model /-! # Label runs and canonical interpretation The lower-bound proofs of the paper compare many runs of an *arbitrary* protocol `P`. All of them have the following property, which we exploit: every operation instance occurring in several runs receives exactly the same replies in each of its terminated rounds in all of them (the instances are numbered globally, one instance per read of the construction). We therefore run the constructions with the *label protocol* `LP`, a concrete protocol-independent instance of the model whose messages are labels `(instance, round)` and whose replies record the label and the log (as labels) of the replying object. A label run that is **canonical** — each terminated round of an instance `i` saw exactly the transcript `T (i, q)` — maps to a run of `P` with the same schedule (`sim`): the label `(i, q)` is interpreted as the canonical message `M (i, q)` of `P`, which is well defined (`exists_isCanon`) as soon as transcripts only mention earlier labels.
