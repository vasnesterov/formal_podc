import Papers.PODC2011.RobustAtomicStorage.Model /-! # Non-vacuity of the round model: an atomic protocol with one object and `t = 0` The main theorems of this folder say `¬ P.Atomic t bot` under hypotheses such as `S ≤ 4t`. To check that `Proto.Atomic` is not an unsatisfiable predicate of the model of `Model.lean`, we exhibit an atomic protocol for parameters outside those bounds: one object (`Obj := Unit`, so `S = 1`), `t = 0`, any readers, any values. The protocol `proto bot N`: messages are `Option V` (the writer sends `some v`, readers send `none`); the object replies with its current value (the last `some v` it processed, or `bot`); writes take one round and reads `N` rounds (any `N`; for `N = 0` reads never return); a read returns the value replied in its first round. Main result: `atomic_one_object`. The proof is an invariant (`Inv`) of the reachable (configuration, history) pairs relating the history to the object's log; it contains the four properties of `AtomicHist`. -/ namespace
