import Papers.PODC2011.UnboundedConcurrency.Swap.Tree import Podc.Computability.Distributed.SharedMemory.Arrival.Basic import Cslib.Computability.Distributed.SharedMemory.Objects.FetchAdd import Cslib.Computability.Distributed.SharedMemory.Objects.TestAndSet /-! # Algorithm 1 of Afek–Morrison–Wertheim (PODC 2011): unbounded-concurrency swap The model is `Cslib.SharedMemory.Arrival`: asynchronous shared memory with infinitely many processes `ℕ`, each a deterministic state machine whose every step is one atomic operation on one base object (local computation is folded into the continuations). Every process performs exactly **one** `swap(x p)` operation (in the unbounded-concurrency model of the paper every new invocation is performed by a new process): its first step is the invocation, entering an output state (`Act.out`) is the response. A schedule is a list (or sequence) of process ids; *unbounded concurrency* means that every infinite schedule is admissible (`infArrival`). Base objects (all atomic; the paper relies on [2], [10] for wait-free implementations of the unbounded fetch-and-add and the unbounded snapshot from 2-consensus objects / registers, which we do not formalize): * `max_depth`: a fetch-and-add object over `ℕ`, initially `1` (`Obj.maxDepth`); * `accessed`: an unbounded single-writer snapshot (`Obj.accessed`): cell `d` holds the last node posted by the process of depth `d` (`update_d(v)`), `scan` returns the whole array (a function `ℕ → Option Node`, `none` = never written); * for every node `v` of the tree: an atomic register `v.reg` (`Obj.reg v`, values `Option V`, initially `none`) and a test-and-set object `v.tst` (`Obj.tst v`; the operation sets the bit and returns its old value, so the paper's `T&S` "wins" iff it returns `false`). The local states follow the pseudocode line by line (`Loc`).
