import Papers.PODC2011.UnboundedConcurrency.IteratorStack import Mathlib.Data.Set.Card /-! # Algorithm 2 of Afek–Morrison–Wertheim (PODC 2011): bounded-concurrency consensus from an iterator stack Section 5.2. Shared objects: a register `result` (initially `⊥ = none`) and an iterator stack. Code of `propose(value)`: ``` 1: if result ≠ ⊥ then return result 2: itr := IteratorStack.write(value) repeat 3: last := cur 4: cur := IteratorStack.read(itr) until cur = ⊥ 5: result := last 6: return result ``` Every shared access is one step (local computation is folded into the continuation). One process performs one `propose` invocation (a new invocation is a new process). ## Main definitions * `Obj`, `objs`, `Loc`, `act`, `alg2`: the algorithm; * `active`, `BoundedConcurrency`, `BCWaitFree`: the paper's *bounded concurrency model*: in an infinite execution, the number of processes that have started and not yet returned is bounded by some `n` (not known to the algorithm, depending on the execution). ## Main statements * `agreement`, `validity`: safety at any concurrency (all finite schedules); * `bcWaitFree`: every process taking infinitely many steps of an infinite execution with bounded concurrency returns; * `theorem_12`: Theorem 12 (Algorithm 2 is a wait-free bounded-concurrency consensus algorithm); * `solvesCons_boundedBy`: consequence: for every `n`, Algorithm 2 solves `n`-process consensus (the iterator stack has consensus number `∞`); * `not_waitFree_infArrival`: Algorithm 2 is not wait-free under unbounded concurrency. -/ namespace Podc.UnboundedConcurrency.Alg2 open Cslib.SharedMemory Cslib.SharedMemory.Arrival set_option linter.unusedSectionVars false /-! ### The bounded concurrency model (generic) -/ section BC variable {ι : Type} [DecidableEq ι] {T : ι → ObjSpec} {X Y : Type} -- CSLib candidate (with `Cslib.SharedMemory.Arrival`) /-- The *active* processes after the finite schedule `σ`: those that took a step and are not in an output state. -/ def active (A : Alg T ℕ X Y) (x : ℕ → X) (σ : List ℕ) : Set ℕ := {p | p ∈ σ ∧ ∀ v, ¬ (A.exec x σ).Out p v} /-- The infinite schedule `s` (with inputs `x`) has *bounded concurrency*: there is a bound `n` (depending on the execution) on the number of active processes at every time. -/ def BoundedConcurrency (A : Alg T ℕ X Y) (x : ℕ → X) (s : ℕ → ℕ) : Prop := ∃ n, ∀ t, Set.ncard (active A x (pre s t)) ≤ n /-- Wait-freedom in the bounded concurrency model: in every infinite execution with bounded concurrency, every process that takes infinitely many steps eventually outputs. -/ def BCWaitFree (A : Alg T ℕ X Y) : Prop := ∀ x s, BoundedConcurrency A x s → ∀ p, InfOften s p → ∃ t v, (A.exec x (pre s t)).Out p v /-- In the model `Mⁿ₁` (`boundedBy n`: only `p₀, …, p_{n-1}` take steps), the concurrency is bounded by `n`. -/ lemma boundedConcurrency_of_boundedBy (A : Alg T ℕ X Y) (x : ℕ → X) {n : ℕ} {s : ℕ → ℕ} (hs : boundedBy n s) : BoundedConcurrency A x s := by refine ⟨n, fun t => ?_⟩ calc Set.ncard (active A x (pre s t)) ≤ (↑(Finset.range n) : Set ℕ).ncard := by apply Set.ncard_le_ncard _ (Finset.finite_toSet _) rintro p ⟨hp, -⟩ obtain ⟨u, -, rfl⟩ := mem_pre.1 hp simpa using hs u _ = n := by rw [Set.ncard_coe_finset, Finset.card_range] lemma BCWaitFree.waitFree_boundedBy {A : Alg T ℕ X Y} (h : BCWaitFree A) (n : ℕ) : WaitFree A (boundedBy n) := fun x s hs => h x s (boundedConcurrency_of_boundedBy A x hs) end BC /-!
