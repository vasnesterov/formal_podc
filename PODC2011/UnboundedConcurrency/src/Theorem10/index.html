import Papers.PODC2011.UnboundedConcurrency.Common /-! # Theorem 10: `n`-consensus objects for all `n` do not give unbounded-concurrency consensus Afek, Morrison, Wertheim, *From Bounded to Unbounded Concurrency Objects and Back*, PODC 2011, Theorem 10: there is no unbounded concurrency wait-free implementation of consensus from read/write registers and `n`-consensus objects for all `n`. Model (`Cslib.SharedMemory.Arrival`): processes `ℕ`, deterministic, each starting with its binary input; asynchronous, every infinite schedule is allowed (unbounded concurrency: infinitely many processes may arrive and stay active); the algorithm may use any (possibly infinite) family of atomic base objects, initialized arbitrarily. A `c`-consensus object "can be accessed by at most `c` processes": we require of the algorithm that in every execution at most `c` distinct processes apply an operation to it (`AccessBounded`). We prove the more general `no_consensus_of_rwLike_or_accessBounded`: every base object is either read/write-like (every operation is read-only or a blind overwrite, e.g. a register) or is accessed by a bounded number of processes — whatever its sequential specification. Theorem 10 (`theorem_10`) is the special case of registers and consensus objects. The proof is the paper's: from an `n`-critical execution (critical w.r.t. the processes `p₀, …, p_{n-1}`), all of `p₀, …, p_{n-1}` are poised on one object `O` that is not a register, hence `O` admits `c ≥ n` processes; the execution is `(c+1)`-bivalent and has a `(c+1)`-critical extension, in which `p₀, …, p_c` are poised on an object `O'` admitting `c' ≥ c + 1` processes, so `O' ≠ O` and `p₀` took a step.
