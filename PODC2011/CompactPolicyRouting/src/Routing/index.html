import Papers.PODC2011.CompactPolicyRouting.Paths /-! # Policy routing functions and local memory (Section 4.2, Definition 4.5) A *policy routing function* on a graph `G` (after Fraigniaud–Gavoille) consists of * injective node labels `L_V : V → ℕ` (the address of a node, bounded by `n ^ c`, i.e. `c log n` bits), * local port labels `L_E(u, ·)`: a bijection from the neighbours of `u` onto `{1, …, δ(u)}`, * local routing functions `R_u : ℕ → ℕ × ℕ`, mapping a header `h` to a new header and an outgoing port. A packet for `t` starts with header `L_V(t)` at `s`; `Generates R h p` says that the walk `p` is the one produced by the successive application of the local routing functions. `R` *implements* `A` on `(G, wt)` if for every pair `s ≠ t` joined by a traversable path the generated walk is a preferred path. The memory needed to store a local routing function is measured by an arbitrary function `mem : (ℕ → ℕ × ℕ) → ℕ∞` (e.g. the length of the shortest description with respect to a fixed decoder, `⊤` for functions without a finite description); the paper says "the minimum number of bits needed to encode `R_u`" without fixing the encoding. The value `⊤` is needed: there are uncountably many functions `ℕ → ℕ × ℕ`, so no `ℕ`-valued measure can have fewer than `2^b` functions of size `< b` (see `not_codeLength_of_ne_top`). All statements below hold for every `mem`; where a counting argument needs that few functions have short codes we assume `CodeLength mem`. `memReq A mem c n` is Definition 4.5: the maximum over connected weighted graphs on `n` nodes of the minimum over routing functions implementing `A` of the maximum local memory. -/ namespace Podc.CompactPolicyRouting open SimpleGraph RoutingAlgebra Filter
