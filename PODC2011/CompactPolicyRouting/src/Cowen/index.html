import Papers.PODC2011.CompactPolicyRouting.Paths /-! # Stretch-3 compact routing on regular algebras (Section 4.4.1, Theorem 4.14) Cowen's landmark scheme, generalized to regular routing algebras. * `lemma_4_16`, `lemma_4_16_paper`: the algebraic core `w(p*_{u,l_v}) ⊕ w(p*_{l_v,v}) ⪯ w(p*_{u,v})³` for `v ∉ C(u)` (regular `A`). * `lemma_4_15`: monotone `A`; the next hop on a preferred path towards `t` stays inside the ball of `t`. * **Consistent next hops** (gap of the paper, which silently assumes that "the preferred path" can be followed hop by hop). Subpaths of preferred paths need not be preferred unless `A` is strictly monotone, so an arbitrary choice of preferred paths can create forwarding loops. `exists_isHO` proves (Dijkstra-style) that for regular `A` on a finite connected graph every node has a *hereditarily preferred* walk to `t` (every suffix is preferred), and `exists_inTree` turns these into an `InTree`: next hops with a strictly decreasing rank such that `w(x, nh x) ⊕ w(p*_{nh x, t}) = w(p*_{x,t})`. * `Scheme`: an abstract landmark scheme (in-trees, landmark map, which node stores which destination) with the four properties the correctness proof needs. `Scheme.next` is the forwarding decision of a node computed only from its local table (`Scheme.lookup`) and the packet header (`Scheme.label`). `Scheme.delivers` (regular `A`, connected `G`): every packet reaches its destination along a *path* of stretch 3, including the "mixed" routes (towards `l_v` until the first node storing `v`, then on the in-tree) that the paper does not analyse. * `paperScheme`: the paper's literal balls `B(v) = {x : w(p*_{v,x}) ⪯ w(p*_{v,l_v})}` (with consistent in-trees) is a `Scheme`; but `paperScheme_table_eq_univ`: for every monotone selective algebra (e.g. widest path) and constant edge weights, every table contains *all* `n` destinations, whatever the landmark set. * `refinedScheme`: balls defined by the strict key `(w(p*_{x,v}), rank of x in the in-tree to v, x)` (lexicographic). `theorem_4_14`: delivery with stretch 3, tables `C(u) ∪ L`, and each ball `B(v)` is contained in the set of nodes whose key is below that of any landmark (`refinedBall_subset`), which is the combinatorial input to Cowen's landmark selection (left as a hypothesis, see `card_table_le`).
