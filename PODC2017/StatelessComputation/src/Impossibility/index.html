import Papers.PODC2017.StatelessComputation.Model /-! # Theorem 3.1: two stable labelings rule out label (n-1)-stabilization Dolev, Erdmann, Lutz, Schapira, Zair, *Stateless Computation*, PODC 2017, Section 3. **Theorem 3.1.** No stateless protocol with at least two distinct stable labelings is label `(n-1)`-stabilizing. We follow the paper's valency argument on the space of states `(ℓ, c)` (labeling, countdown vector), restricted to the subspace `H` of countdowns whose increasing rearrangement dominates `(1, 2, …, r-1, r, r)` (`r = n - 1`). The paper's proof needs repairs (see `differencies.md`): * valency ("attractor regions") is taken with respect to paths *inside* `H`; then Lemma 3.2's single-node activation (which leaves `H`) is replaced by an application of Lemma 3.3; * the paper claims that the `H`-successors of a state are *all* activation sets `T` with `|T| ≥ 2` (containing the node with countdown `1`); this is false (e.g. `r = 4`, countdowns `(2,2,4,4,4)`, `T` = two of the nodes with countdown `4`). What is true, and suffices, is that the admissible sets are **upward closed** (`Good.mono`, `cd_mono_set`), so any two of them are connected through `univ` by single-node insertions; * Lemma 3.3 is stated with valency w.r.t. `H`-paths, which every `r`-fair execution from an arbitrary labeling with a countdown `≤ r` is (`hpath_fair`). The countdown `c v` is the number of steps within which node `v` must still be activated. `Good r c` encodes "sorted `c` dominates `(1, …, r-1, r, r)`" as `∀ k < r, #{v | c v ≤ k} ≤ k` (plus `c ≤ r`).
