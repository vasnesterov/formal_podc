import Papers.PODC2017.StatelessComputation.Basics /-! # Proposition 2.3: every function is computable with labels of `n + 1` bits in `2n` rounds Dolev, Erdmann, Lutz, Schapira, Zair, *Stateless Computation*, PODC 2017, Prop. 2.3 / A.3. On a strongly connected digraph fix a root, an in-tree `T₂` (parent `p2`, arcs `v → p2 v`) and an out-tree `T₁` (parent `p1`, arcs `p1 v → v`). Labels are pairs `(z, b) ∈ {0,1}ⁿ × {0,1}`. Along `T₂` every node sends to its parent its own input (at its own coordinate) OR-ed with the `z`-vectors received from its `T₂`-children; the root applies `f` to the resulting vector and sends the result down `T₁` in the `b`-bit; every node outputs the `b`-bit received from its `T₁`-parent. This is the paper's protocol. We prove it for arbitrary rank-certified trees (`Trees`) with explicit time bounds, and construct BFS trees with ranks `≤ n - 1` in strongly connected digraphs. -/ namespace StatelessComputation
