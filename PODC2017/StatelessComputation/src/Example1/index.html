The protocol on the complete digraph `Kₙ` (no self-loops) with label space `{0,1}`: every node sends `1` on all its outgoing arcs iff some incoming arc carries `1` (and outputs the same bit). It has two stable labelings (all `0`, all `1`), so by Theorem 3.1 it is not label `(n-1)`-stabilizing; Example 1 claims that it is label `(n-2)`-stabilizing. ## Main results * `allTrue_stable`,
