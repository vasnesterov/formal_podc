import Mathlib import Cslib.Computability.Distributed.SelfStabilization.Daemon /-! # Stateless computation: the model Dolev, Erdmann, Lutz, Schapira, Zair, *Stateless Computation*, PODC 2017 (arXiv 1611.10068v1), Section 2. A network is a directed graph `G` (Mathlib's `Digraph V`) on a finite node set `V`. Every node `i` has a private input `x i : X` and a *reaction function* `δ i : (labels of the incoming arcs of i) → X → (labels of the outgoing arcs of i) × Y`. Nodes have no other state: the global state is the *labeling* `ℓ : Arc G → L` of all arcs (and the current outputs). A *schedule* `σ : ℕ → Finset V` activates, at step `t + 1`, the nodes in `σ t`; an activated node applies its reaction function to its current incoming labels and overwrites its outgoing labels and its output. The paper calls the label space `Σ`; here it is the type `L` (`Σ` is Lean syntax). ## Main definitions * `Arc G`, `inLab ℓ i`: arcs and the incoming labels of a node. * `Protocol G L X Y`: a stateless protocol (the vector of reaction functions). * `step`, `run`, `outputs`: executions under a schedule. * `IsRFair r σ`: every node is activated in every window of `r` consecutive steps (and every step activates a nonempty set, as in the paper). * `IsStable P x ℓ`: `ℓ` is a fixed point of every reaction function (a *stable labeling*). * `OutputStabilizing r P`, `LabelStabilizing r P`: the paper's output / label r-stabilization. * `syncRun`, `syncOut`: the synchronous execution (Part II of the paper). -/ -- CSLib candidate: the stateless-protocol model with r-fair schedules (this file). namespace StatelessComputation variable {V : Type*} {L X Y : Type*} /-- The arcs of the digraph `G`: pairs `(i, j)` with `G.Adj i j` (an arc from `i` to `j`). -/ abbrev Arc (G : Digraph V) := {p : V × V // G.Adj p.1 p.2} /-- In-neighbours of `i`. -/ abbrev InNbr (G : Digraph V) (i : V) := {u : V // G.Adj u i} /-- Out-neighbours of `i`. -/ abbrev OutNbr (G : Digraph V) (i : V) := {w : V // G.Adj i w} /-- A labeling of the arcs of `G` by labels from `L`. -/ abbrev Labeling (G : Digraph V) (L : Type*) := Arc G → L /-- The labels on the incoming arcs of node `i`. -/ def inLab {G : Digraph V} (ℓ : Labeling G L) (i : V) : InNbr G i → L := fun u => ℓ ⟨(u.1, i), u.2⟩ /-- A stateless protocol on `G` with label space `L`, inputs `X` and outputs `Y`: one reaction function per node, mapping incoming labels and the private input to outgoing labels and an output value.
