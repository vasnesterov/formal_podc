with `head = θ₀·p₁`, `tail = θ₀·p₂` and weight `wt(F) = L(p₁) − U(p₂)`. * `IsZigzag γ r Z θ θ'` — `Z = (F₁, …, F_c)` is a zigzag pattern from `θ` to `θ'` in `r` (Definition 6): `tail(F₁) = θ`, `head(F_c) = θ'`, and the head of each fork and the tail of the next one are on the same process, the head not later than the tail. * `wtZ` — `wt(Z) = Σ wt(F_k) + S(Z)`, where `S(Z)` counts consecutive forks that are not joined (head and next tail are different basic nodes). * `zigzag_sufficiency` — **Theorem 1**. * `Visible` — σ-visible zigzag patterns (Definition 7). -/ set_option where /-- The base `θ₀`. -/ base : GNode P S M E /-- The continuation from the base to the head. -/ p1 : List P /-- The continuation from the base to the tail. -/ p2 : List P namespace Fork /-- U(p₂)` (the paths start at the process of the base). -/ def wt (N : Net P) (F : Fork P S M E) : ℤ := N.Lp F.base.proc F.p1 - N.Up F.base.proc F.p2 /-- The trivial fork `⟨θ, θ, θ⟩` (weight `0`). -/ def E) [Finite P] /-- The fork is a fork *in `r`*: its nodes appear in `r`. -/ def ForkIn (F : Fork P S M E) : Prop := γ.appearsG r F.head ∧ γ.appearsG r F.tail /-- `θ` and `θ'` correspond to nodes of the -/ theorem prec_adj {θ θ' : GNode P S M E} (h : γ.Adj r θ θ') : γ.Prec r θ (γ.gap r θ θ') θ' := by obtain ⟨σ, σ', h1, h2, hp, ht⟩ := h refine ⟨σ, σ', h1, h2, ?_⟩ simp only [gap, h1, h2] split_ifs with
