import Papers.PODC2017.ZigzagCausality.Coordination /-! # Theorem 3 fails for full-information protocols that do not flood Theorem 3 is stated for an arbitrary protocol; its proof uses Lemma 3 (full information) and Lemma 4, whose proof uses flooding. Here is a full-information protocol (every message carries the sender's whole local state) that implements `Late⟨a --0--> b⟩` but for which the conclusion of Theorem 3 fails: `B` learns that `C` received `μ_go` from the *absence* of a message. Processes `D = 0`, `C = 1`, `A = 2`, `B = 3`; channels `D → C`, `D → B`, `C → A`, `C → B` with exact delays `1, 2, 1, 1` (`L = U`). External messages `e_D = 0`, `μ_go = 1`, `e' = 2`. * `D`, when activated, sends to `C` and `B`; * `C`, when activated, sends to `A` if `μ_go` is in its current batch ("go"), and to `B` otherwise ("no go yet"); * `B` performs `b` when it receives a message from `D` and, in the same batch, none from `C`. If `D` sends at time `t`, `C` is activated at `t + 1` and its reply (if any) reaches `B` exactly together with `D`'s direct message at `t + 2`. So `b` at `t + 2` implies that `C` received `μ_go` at `t + 1`, hence `a` happens at `t + 2`: the protocol implements `Late⟨a --0--> b⟩` (`implementsLate`). In the run `r₁` (`D` gets `e_D` at time 1, `C` gets `μ_go` at time 2) `B` performs `b` at `σ = (B, r_B(3))`, and `C` sends "go" at `σ_C = (C, r_C(2))`. But in the run `r₂` where `C` gets `e'` together with `μ_go`, `B` has the same local state while `σ_C` does not appear, so `K_σ(σ_C·A --0--> σ)` fails (`theorem_3_false_for_FIP`).
