import Podc.Computability.Distributed.SharedMemory.Unnamed import Papers.PODC2017.MemoryAnonymousCoordination.ImpRenaming /-! # Figure 3 of Taubenfeld, *Coordination Without Prior Agreement* (PODC 2017): the algorithm A memory-anonymous symmetric obstruction-free adaptive perfect renaming algorithm with `2n − 1` registers: ``` Code of process i Shared: p.i[1..2n-1]: registers (id, val, round, history), initially (0, 0, 0, ∅) myround := 1; myhistory := ∅ 1 repeat 2 mypref := i 3 repeat 4 for j = 1 to 2n-1 do myview[j] := p.i[j] od 5 if ∃ j ∃ v : (i, v) ∈ myview[j].history 6 then return(v) fi 7 mytemp := max_j myview[j].round 8 if mytemp > myround then 9 j := an arbitrary index k with myview[k].round = mytemp 10 mypref := myview[j].val 11 myhistory := myview[j].history 12 myround := myview[j].round fi 13 if ∃ v ≠ 0 appearing in at least n of the val fields of the entries of myview whose round field equals myround 14 then mypref := v fi 15 j := an arbitrary index k with myview[k] ≠ (i, mypref, myround, myhistory) 16 p.i[j] := (i, mypref, myround, myhistory) 17 until ∀ j : myview[j] = (i, mypref, myround, myhistory) 18 if mypref = i then return(myround) fi 19 myhistory := myhistory ∪ {(mypref, myround)} 20 myround := myround + 1 21 until myround = n 22 return(n) ``` ## Modelling * `m` registers (the paper: `m = 2n − 1`). A register value is `Option (P × St P)`: `none` is the initial value `(0, 0, 0, ∅)`, `some (q, s)` is the record `(id, val, round, history) = (q, s.val, s.rd, s.hist)`. Identifiers are arbitrary (`P` is any type with decidable equality); rounds are natural numbers (the initial round field `0` is never a real round). * Local state: the triple `St` `(mypref, myround, myhistory)` and a program counter (`Loc`). * Granularity: each read of the collect (line 4) is one atomic step, the write (line 16) is one step, the returns (lines 6, 18, 22) are the response of the renaming operation; the local computations of lines 5–15 are folded into the last read (`finish`), lines 17–21 and 2 into the write (`afterWrite`). * Line 5: the name `v` is chosen by classical choice (it is unique in every execution). * Lines 9 and 15 are parameters (`Sel`); the correctness proofs only assume `Sel.OK`: line 9 picks an entry whose round is the maximum, line 15 an entry different from the own record whenever one exists. In the iteration that exits the loop all entries equal the own record and no such entry exists; the write of line 16 is still performed (it rewrites the own record). * Process code is written in local register names; the memory-anonymous execution is `(alg n S).unnamed π` for an arbitrary adversarial numbering `π`. -/ set_option linter.unusedSectionVars false namespace
