import Podc.Computability.Distributed.SharedMemory.Unnamed import Cslib.Computability.Distributed.SharedMemory.Mutex /-! # Figure 1 of Taubenfeld, *Coordination Without Prior Agreement* (PODC 2017): the algorithm A memory-anonymous symmetric deadlock-free mutual exclusion algorithm for two processes with `m` registers (`m` odd, `m ≥ 3`): ``` Code of process i Shared: p.i[1..m]: atomic registers, initially 0 1 repeat 2 for j = 1 to m do if p.i[j] = 0 then p.i[j] := i fi od 3 for j = 1 to m do myview[j] := p.i[j] od 4 if i appears in less than ⌈m/2⌉ of the entries of myview[1..m] then 5 for j = 1 to m do if p.i[j] = i then p.i[j] := 0 fi od 6 repeat 7 for j = 1 to m do myview[j] := p.i[j] od 8 until ∀ j : myview[j] = 0 9 fi 10 until ∀ j : myview[j] = i 11 critical section 12 for j = 1 to m do p.i[j] := 0 od ``` ## Modelling * Registers hold `Option P`: `none` is `0`, `some q` is the identifier of `q`. * Granularity: every shared-memory access is one atomic step. In particular line 2 and line 5 are a *read* followed (if the test succeeds) by a *separate write* step to the same register (`scan j` / `scanW j`, `rst j` / `rstW j`); every read of the collects of lines 3 and 7 is one step; line 12 (`unlock`) is `m` unconditional writes of `0`. `lock()` returns when the test of line 10 succeeds; the critical section is the time between the response of `lock()` and the invocation of `unlock()`. * The view `myview` of line 3 is kept as the list `vs` of the values read so far (`coll vs`, about to read local register `vs.length`). The wait loop of lines 6–8 only keeps the flag `z` "all values read so far in this pass were `0`" (`wait j z`). The tests of lines 4, 8 and 10 are folded into the continuation of the last read of the corresponding loop. After the wait loop the test of line 10 fails (the view is all `0`), so the process restarts at line 2. * Positions are natural numbers `j < m` (an invariant), the access to local register `j` is the access to physical register `π p ⟨j, _⟩` of `Impl.unnamed`. * The code of process `p` only uses `some p` (to write it and to compare register values with it), so the algorithm is symmetric in the sense of the paper. -/ namespace Podc.MemoryAnonymousCoordination.Mutex open Cslib.SharedMemory /-- Local state (program counter and the relevant local variables) of a process. -/ inductive Loc (P :
