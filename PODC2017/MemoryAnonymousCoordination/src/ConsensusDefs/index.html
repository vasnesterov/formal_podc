import Podc.Computability.Distributed.SharedMemory.Unnamed import Cslib.Computability.Distributed.SharedMemory.Consensus /-! # Figure 2 of Taubenfeld, *Coordination Without Prior Agreement* (PODC 2017): the algorithm A memory-anonymous symmetric obstruction-free consensus algorithm with `2n − 1` registers: ``` Code of process i with input in_i Shared: p.i[1..2n-1]: registers (id, val), initially all fields 0 1 mypref := in_i 2 repeat 3 for j = 1 to 2n-1 do myview[j] := p.i[j] od 4 if ∃ value ≠ 0 which appears in at least n of the val fields of myview 5 then mypref := value fi 6 j := an arbitrary index k with myview[k] ≠ (i, mypref) 7 p.i[j] := (i, mypref) 8 until ∀ j : myview[j] = (i, mypref) 9 decide(mypref) ``` ## Modelling * `m` registers (the paper: `m = 2n − 1`), register values `Option (P × V)`; `none` is the initial value "`(0, 0)`", `some (q, v)` the record `(id, val) = (q, v)`. Inputs range over `V`, so no process can have the input `0` (with an input equal to the initial `val`, agreement fails). * Granularity: each read of the collect (line 3) is one atomic step, the write (line 7) is one step, the decision (line 9) is the response of the consensus operation; lines 4–6 and the test of line 8 are local and folded into the continuation of the last read / of the write. * Line 4 is `adopt n view mypref`: a value occurring in at least `n` val fields (unique when `m < 2n`), if any. * Line 6 is a parameter `sel p mypref myview : Fin m`; the correctness proofs only assume that it returns an entry different from `(p, mypref)` whenever one exists. In the last iteration all entries equal `(p, mypref)` and no such index exists (contrary to "Clearly, such an arbitrary entry exists"); we still perform the write of line 7 to the register `sel …` (it rewrites `(p, mypref)` there, which is harmless). * Process code is written in local register names;
