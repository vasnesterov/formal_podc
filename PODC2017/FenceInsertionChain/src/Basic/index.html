import Mathlib /-! # Fence insertions for straight-line programs: the abstract setting A straight-line program has `n` operations `0, …, n-1` (the paper numbers them `1, …, n`); gap `k` is the place right after operation `k`. A set `ord` of *required orders* `x = (i, j)`, `i < j`, must be preserved by fences placed in gaps `k` with `i ≤ k < j`. * `IsIns ord need f` — a *multi-type* fence insertion `f : Fin n → Finset κ` (`f k` = the fences put in gap `k`) for fence instructions `κ`; order `x` needs a fence of type `c` for every `c ∈ need x` (`need x = none`: the order is provided by the memory model for free). `size f = ∑ₖ |f k|`. * `IsIns1 ord F` — a *single-type* fence insertion `F ⊆ {gaps}` (Definition 2.2). * `IsOptIns`, `IsOptIns1` — minimum-size insertions (`OptFI`); they exist (`exists_isOptIns`, `exists_isOptIns1`). ## Main statements The abstract form of **Lemma 2.1** ("independence of fence types"): when every required order needs fences of only one instruction, the problem decomposes into independent single-instruction problems. * `isOptIns_biUnion` — the gap-wise union of optimal insertions of the restricted instances `restrict ord need c` is an optimal insertion of the whole instance. * `IsOptIns.subset_singleton` — an optimal insertion of `restrict ord need c` uses only fence `c`. * `IsOptIns.size_eq_sum` — the minimum size is the sum of the minimum sizes of the restrictions. * `isOptIns_of_isOptIns1` — the same with single-type optima, as the paper uses the lemma. -/ set_option linter.unusedSectionVars false namespace Podc.FenceInsertionChain open Finset variable {n : ℕ} {κ : Type*} [DecidableEq κ] /-- A multi-type fence insertion: `f k` is the set of fences put right after operation `k`; every required order `x ∈ ord` gets, for the fence type `c ∈ need x` it needs, a fence of type `c` in a gap `k` with `x.1 ≤ k < x.2`. -/ def IsIns (ord : Finset (Fin n × Fin n)) (need : Fin n × Fin n → Option κ) (f : Fin n → Finset κ) : Prop := ∀ x ∈ ord, ∀ c ∈ need x, ∃ k, x.1 ≤ k ∧ k < x.2 ∧ c ∈ f k instance (ord : Finset (Fin n × Fin n)) (need : Fin n × Fin n → Option κ) (f : Fin n → Finset κ) : Decidable (IsIns ord need f) := by unfold IsIns; `OptFI`). -/ def IsOptIns (ord : Finset (Fin n × Fin n)) (need : Fin n × Fin n → Option κ) (f : Fin n → Finset κ) : Prop := IsIns ord need f ∧ ∀ g, IsIns ord need g → size f ≤ size g /-- The required some c /-- **Definition 2.2** (single-type fence insertion): a set `F` of gaps such that every required order `x` has a gap `k ∈ F` with `x.1 ≤ k < x.2`. -/ def IsIns1 (ord : Finset (Fin n × Fin n))
