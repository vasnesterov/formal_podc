The choice of `U` (line 7) is an arbitrary *rule* (`Rule G`): any function of the current weights returning an independent set of positive-weight vertices, nonempty whenever `pos w` is (otherwise `SeqLR` does not terminate; the paper leaves this implicit). The paper's two distributed algorithms are instances: Algorithm 3 picks the local colour maxima (`Coloring.lean`). Main results: * `seqLR_isApprox` — for every rule, `SeqLR` returns an `r`-approximate maximum-weight independent set whenever every picked `U` satisfies the local bound `r` (Lemma 2.2 + induction). *
