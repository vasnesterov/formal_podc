import Papers.PODC2017.MaxISLocalRatio.Distributed /-! # 2-approximate maximum-weight matching via the line graph (Section 2.4, Theorem 2.10) A matching of `G` is an independent set of the line graph `L(G)` (Mathlib's `G.lineGraph`, whose vertices are the edges of `G`). The key observation of Section 2.4: in `L(G)` every independent set (matching) meets the closed neighbourhood of an edge `e = {a, b}` in at most `2` edges (at most one matching edge contains `a`, at most one contains `b`). Hence Lemma 2.2 holds with `r = 2` instead of `Δ(L(G))`, and Algorithm 1, run on `L(G)` with edge weights, returns a 2-approximate maximum-weight matching for **every** choice rule. * `matching_localBound` — the local bound `2` in `L(G)`. * `seqLR_lineGraph_isApprox` — Algorithm 1 on `L(G)` is a 2-approximation for max-weight matching. * `theorem_2_10_det` — deterministic half of Theorem 2.10, at the level of the line graph: Algorithm 3 run on `L(G)` with a black-box proper colouring of `L(G)` with `k` colours (an edge colouring of `G`) terminates after `3k` rounds of `L(G)` and outputs a 2-approximate maximum-weight matching. `lineGraph_degree_le`: `L(G)` has maximum degree `≤ 2Δ - 2`, so `k = 2Δ - 1` colours suffice (as in the paper).
