import Papers.PODC2017.MaxISLocalRatio.SeqLR /-! # Weight layers: the removal stage of Algorithm 2 (Section 2.2, Lemma A.1, deterministic part) Algorithm 2 splits the vertices into layers `Lᵢ = {v | 2^{i-1} < w(v) ≤ 2^i}` and, in each phase, computes a maximal independent set of the top layer (nodes wait while they have a neighbour in a higher layer). The randomized MIS black box is out of scope; we formalize the deterministic part of Lemma A.1 and Theorem 2.3: if, in every phase, the chosen set `U` contains a maximal independent set of the top layer, then the top layer is emptied, and with integer weights in `[1, W]` the removal stage ends after `⌈log₂ W⌉ + 1` phases. `IsTopMIS R`: whenever all remaining weights are at most `2^m`, every vertex with weight in `(2^{m-1}, 2^m]` is in `U` or has a neighbour in `U` with weight in that range (if `m` is the top layer, this says that `U ∩ L_top` is a maximal independent set of `G[L_top]`; for larger `m` it is vacuous). * `top_layer_drops` — Lemma A.1 (deterministic): one phase halves the weight bound. * `removal_stage` — after `⌈log₂ W⌉ + 1` phases no vertex remains. -/ set_option
