Distributed approximation of MaxIS and maximum matching — PODC 2017

Reuven Bar-Yehuda, Keren Censor-Hillel, Mohsen Ghaffari, Gregory Schwartzman. Distributed Approximation of Maximum Independent Set and Maximum Matching. PODC 2017. DOI 10.1145/3087801.3087806. Verdict: ✏️ Slip. The local-ratio theorem (Thm 2.1), Lemma 2.2, the Δ-approximation of the sequential meta-algorithm (Algorithm 1) for every choice of independent sets, the colouring-based Algorithm 3 (a Δ-approximation in O(Δ) rounds after a (Δ+1)-colouring), the layer argument of Lemma A.1, and the 2-approximation for maximum-weight matching via the line graph (Thm 2.10, deterministic half) all hold. They need closed neighbourhoods and Δ ≥ 1, and line 11 of Algorithm 1, read literally, breaks the approximation, while the text of Section 2.1 has the correct rule. Only this deterministic core of Section 2 was checked: the randomized results, the CONGEST simulation on the line graph and the O(log Δ/log log Δ) matching algorithms of Section 3 were not.

Mistakes in the paper

✏️ Slips

  • Algorithm 1, line 11 (weight reduction overwrites). Read literally, line 11 sets w₁(v) = w(v) − w(u) inside foreach u ∈ U, foreach v ∈ N(u), so a vertex keeps only the reduction of the last u and Algorithm 1 is not a Δ-approximation (LiteralLine11.literal_line_11_fails). The text before Lemma 2.2 defines the sum w₂[v] = ∑_{u∈U∩N(v)} w[u], and with w₁(v) = w₁(v) − w(u) everything is correct. Counterexample (Δ = 2): edges a₁v, a₂v, a₁b, weights w(a₁)=3, w(a₂)=1, w(v)=2, w(b)=3, U = {a₁, a₂} processed in this order (loop over the closed neighbourhoods N[u], see the next item). Then v keeps weight 1 (a₁, a₂, b drop to 0), the recursion can only return {v}, and line 13 adds nothing. The output {v} has weight 2 while {v, b} has weight 5 > 2·2.

  • Section 2.1, Lemma 2.2, Algorithm 1 (N(v) must be closed). The proof of Lemma 2.2 uses w₂[u] = w[u] for u ∈ U and "at most |N(u)| − 1 vertices of N(u) are independent". Both hold only for N[u] = N(u) ∪ {u}. Algorithms 2 and 3 already use closed neighbourhoods (w(v) = 0 after reducing).

  • Lemma 2.2, Algorithms 1 and 3 (Δ ≥ 1). The correct bound on |I ∩ N[u]| for an independent I is max(1, deg u), not deg u, so the Δ-approximation needs Δ ≥ 1; an edgeless graph (Δ = 0) is the counterexample. We prove Lemma 2.2 for closed neighbourhoods and every factor r that bounds |I ∩ N[u]|. This gives r = Δ for Δ ≥ 1 and r = 2 on line graphs (lemma_2_2, card_inter_cl_le, localBound_of_degree_le).

  • Algorithm 1, line 7. Algorithm 1 terminates only if U ≠ ∅ while vertices remain; our choice rules require U ≠ ∅ (algorithm_1).

  • Algorithm 3, lines 8, 13, 16. An earlier candidate waits forever unless removed/addedToIS go to all neighbours in G: if the messages go only to the current N(v), it never learns the decision of a later candidate neighbour. Our model sends to all G-neighbours, and with this reading the algorithm is correct (algorithm_3).

  • Section 2.2, Theorem 2.3, Lemma A.1. There are ⌈log₂ W⌉ + 1 weight layers, not log W.

Typos

  • In the proof of Lemma 2.2 several indices are swapped (w₂[u]x*[u] for w[u]x*[v], x'[u] for x'[v], |N(v)|−1 for |N(u)|−1).

  • §2.3 says "removal stage" for the addition stage.

  • §2.4 says "weighted nodes" for weighted edges.

The formalizationmodel, Lean names of the results, trust

Model.

  • Finite simple graph G, arbitrary real vertex weights (nonpositive vertices are removed). For matchings, the line graph G.lineGraph of Mathlib with edge weights.

  • Algorithm 1 has the graph fixed and the current vertex set = positive-weight vertices. The independent set of line 7 is an arbitrary rule (a function of the current weights: independent, positive vertices, nonempty while vertices remain). Every result is proved for every rule.

  • Algorithm 3 runs in CSLib's synchronous locally-iterative (SET-LOCAL) model Cslib.LocallyIterative.Algorithm. It is deterministic with no failures. Every node reads the set of its neighbours' states (= messages); states carry identifiers, so sums over neighbours are exact. The round number is known. The (Δ+1)-colouring is a black box: any proper colouring c with c v < k is part of the input. One iteration of the paper takes two rounds: "select" (local colour maxima among remaining nodes become candidates) and "reduce". Candidates decide in every round (lines 12–17).

  • Algorithm 2 is covered only abstractly. If each phase picks a maximal independent set of the top weight layer, the removal stage has ⌈log₂ W⌉ + 1 phases. The randomized MIS black box, the waiting rule and the probability bound are not modelled.

Trust. No sorry. The listed theorems use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity (Main.lean): every finite graph has a proper colouring with |V| colours (exists_proper_coloring), so algorithm_3 applies to all graphs and weights. singletonRule (classical sequential local ratio) and topMISRule (a maximal independent set of the top layer, satisfies IsTopMIS) are admissible rules.
