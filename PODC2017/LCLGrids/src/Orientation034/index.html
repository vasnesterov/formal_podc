Its third bullet claims: if `2 ∉ X`, `{1,3,4} ⊄ X` and `{0,1,3} ⊄ X`, then no solution exists for infinitely many `n`. For `X = {0,3,4}` all three conditions hold, but we construct a `{0,3,4}`-orientation of the `n × n` torus for **every** `n ≥ 3`. ## Construction Coordinate `0` is east, coordinate `1` is north. Vertices are grouped into diagonal classes `cls v = v 1 - v 0 ∈ ZMod n` (the construction is invariant under `v ↦ v + (1,1)`). With the sequence `t034 : ZMod n → ℕ` (`0, 2, 0, 2, …`, ending with `1` at `n - 1` when `n` is odd): * the east edge `u — u + e₀` is directed `u → u + e₀` iff `t (cls u - 1) ≤ 1`; * the north edge `u — u + e₁` is directed `u → u + e₁` iff `1 ≤ t (cls u)`.
