import Mathlib import Papers.PODC2017.LCLGrids.TorusGraph /-! # No edge `2d`-colouring of an odd torus (Theorem 21) Theorem 21 of Brandt et al., *LCL Problems on Grids* (PODC 2017): for odd `n`, the `d`-dimensional torus `(ℤ/n)^d` has no proper edge colouring with `2d` colours. An edge colouring is a vertex colouring of the line graph (`SimpleGraph.lineGraph`). ## Proof Every vertex has degree `2d`, so in a proper edge `2d`-colouring every vertex sees every colour exactly once: each colour class is a perfect matching. By the handshake lemma the number of vertices `n ^ d` is then twice the number of edges of colour `0`, which is impossible for odd `n`. The general counting step is `even_card_of_lineGraph_coloring`: a `k`-regular finite graph (`k ≥ 1`) whose edges are properly `k`-coloured has an even number of vertices. -/ namespace Podc.LCLGrids open Finset SimpleGraph section General variable {V : Type*} {G : SimpleGraph V} {α : Type*} /-- The spanning subgraph of the edges of colour `c` under an edge colouring `C` of `G`. -/ def colourClass (C : G.lineGraph.Coloring α) (c : α) : SimpleGraph V where Adj v w := ∃ h : G.Adj v w, C ⟨s(v, w), h⟩ = c symm := ⟨fun v w ⟨h, hc⟩ => ⟨h.symm, by have e : (⟨s(w, v), h.symm⟩ : G.edgeSet) = ⟨s(v, w), h⟩ := Subtype.ext Sym2.eq_swap rw [e]; exact hc⟩⟩ loopless := ⟨fun v ⟨h, _⟩ => G.loopless.irrefl v h⟩ /-- In a proper edge colouring, the edges at a vertex `v` get pairwise distinct colours. -/ lemma coloring_injective_at (C : G.lineGraph.Coloring α) {v u u' : V} (hu : G.Adj v u) (hu' : G.Adj v u') (h : C ⟨s(v, u), hu⟩ = C ⟨s(v, u'), hu'⟩) : u = u' := by by_contra hne refine C.valid ?_ h rw [lineGraph_adj_iff_exists] refine ⟨fun e => hne ?_, v, Sym2.mem_mk_left _ _, Sym2.mem_mk_left _ _⟩ exact Sym2.congr_right.1 (congrArg Subtype.val e) variable [Fintype V] [DecidableRel G.Adj] {k : ℕ} /-- In a proper edge `k`-colouring of a `k`-regular graph, every vertex has exactly one incident edge of each colour. -/ lemma existsUnique_colourClass_adj (hG : G.IsRegularOfDegree k) (C : G.lineGraph.Coloring (Fin k)) (c : Fin k) (v : V) : ∃!
