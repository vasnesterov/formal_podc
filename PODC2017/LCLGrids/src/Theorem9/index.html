import Papers.PODC2017.LCLGrids.Invariant import Papers.PODC2017.LCLGrids.QSum /-! # 3-colouring toroidal grids needs `Ω(n)` rounds (Theorem 9) Section 9 of Brandt et al., *LCL problems on grids* (PODC 2017). **Model.** The toroidal `n × n` grid `Pos n` with a consistent orientation (every node knows which of its edges points north, east, south, west) and unique identifiers `I : Pos n → ℕ`, all `< B`; the nodes know `n`. A deterministic `T`-round LOCAL algorithm (for this `n`) is a map `A : (ℤ × ℤ → ℕ) → Col` that only depends on the identifiers at the offsets `d` with `|d₁| + |d₂| ≤ T` (`GridLocal T A`): thanks to the orientation, this is exactly the information in the radius-`T` neighbourhood. Node `v` outputs `A (gview I v)`, `gview I v d = I (v + d)`. `Colours3 n B A`: `A` properly 3-colours every `n × n` torus with identifiers in `[0, B)`. **Theorem 9** (`theorem9`, `theorem9_not_isLittleO`): for odd `n`, an algorithm that 3-colours all `n × n` tori with identifiers in `[0, 8n²)` runs in at least `n/8 - 1` rounds; so 3-colouring is not solvable in `o(n)` rounds. **Proof (as in the paper).** From a grid algorithm `A` with `T` rounds we build a `(T+1)`-round cycle algorithm `cycAlg A`: node `x` of a directed `n`-cycle with identifier `id x` simulates the column `x` of a horizontal strip of `2T + 3` rows (identifiers `id x * n + y`) of a torus whose other rows carry fixed identifiers (`gridOf`), and outputs the label `ℓ(x, 0)` of Lemma 14. The outputs sum to the row sum `s` of row `0`; by Lemma 12 this equals the row sum of a row far from the strip, which does not depend on the cycle identifiers, so all cycles have the same sum `Q`, and `Q` is odd with `|Q| ≤ n/2` (Lemma 14). Theorem 10 (`QSum.theorem10_of_solves`) then gives `n ≤ 8(T + 1)`. **Lemma 13** (`lemma13`): the row sum is the same for all identifier assignments of the torus (identifiers in `[0, B)`, `B ≥ 3n²`) if `4(T + 2) ≤ n`;
