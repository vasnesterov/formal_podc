import Papers.PODC2017.LCLGrids.Basic /-! # Lemma 12: the intersection number of a cycle of `H` is the same for all rows Section 9 of Brandt et al., *LCL problems on grids* (PODC 2017). A directed cycle of `H` is modelled as a closed walk `γ : ZMod m → Pos n`: position `i` has predecessor `γ (i - 1)` and successor `γ (i + 1)`. Position `i` is a *northbound intersection* on row `r` if `γ (i - 1)`, `γ i`, `γ (i + 1)` lie on rows `r - 1`, `r`, `r + 1`, and *southbound* if they lie on rows `r + 1`, `r`, `r - 1`. The intersection number is `crossing γ r = northCount γ r - southCount γ r`. ## Main results * `crossing_eq_of_rows`: for any closed walk that moves one row up or down at every step, `crossing γ r` does not depend on `r`; * `lemma12`: in particular this holds for closed walks along edges of `H` (Lemma 12). ## Proof `crossing γ r` equals the net number of steps from row `r - 1` up to row `r` (pointwise: a visit of row `r` that arrives from below and leaves downwards contributes `1 - 1`), and the difference of the net numbers for consecutive rows `r - 1 → r` and `r → r + 1` telescopes to `∑ i, ([γ (i + 1) on row r] - [γ i on row r]) = 0`.
