import Mathlib import Cslib.Foundations.Combinatorics.SimpleGraph.Orientation import Papers.PODC2017.LCLGrids.TorusGraph /-! # No `{1,3}`-orientation of an odd 2-dimensional torus (Lemma 24) Lemma 24 of Brandt et al., *LCL Problems on Grids* (PODC 2017): for odd `n`, the 2-dimensional torus `(ℤ/n)^2` has no orientation in which every vertex has in-degree `1` or `3`. We use CSLib's `SimpleGraph.Orientation` (every edge gets exactly one direction). ## Proof In a `k`-regular finite graph, in-degree plus out-degree is `k` at every vertex and the in-degrees and out-degrees have the same sum, so `2 · Σ indeg = k · |V|` (`two_mul_sum_inDeg`). For the `n × n` torus (`n ≥ 3`, `k = 4`) this gives `Σ indeg = 2 n²`, which is even; but a sum of `n²` odd numbers is odd for odd `n`. For `n = 1` the torus has no edges, so all in-degrees are `0`. -/ namespace Podc.LCLGrids open Finset SimpleGraph section General variable {V : Type*} {G : SimpleGraph V} /-- The in-degree of `v` under the orientation `o`: the number of edges oriented towards `v`. -/ noncomputable def inDeg (o : G.Orientation) (v : V) : ℕ := {u | o.out u v}.ncard variable [Fintype V] {k : ℕ} lemma inDeg_eq_sum (o : G.Orientation) (v : V) [DecidablePred (o.out · v)] : inDeg o v = ∑ u, if o.out u v then 1 else 0 := by rw [inDeg, ← card_filter] convert Set.ncard_coe_finset (univ.filter (o.out · v)) ext;
