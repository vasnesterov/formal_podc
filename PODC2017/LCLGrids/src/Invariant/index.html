import Papers.PODC2017.LCLGrids.Basic /-! # The row invariant `s` of a proper 3-colouring (Lemmas 12 and 14) For a colouring `c` of the toroidal `n × n` grid, `rowSum c r = ∑_x ℓ(x, r)` is the sum of the labels of Lemma 14 along row `r`. The paper writes `s(G) = ∑_{C ∈ 𝒞} i_r(C)` for a decomposition `𝒞` of `H` into directed cycles and observes `s(G) = ∑_v ℓ(v)` ("directly by definitions"). * `rowSum_eq_flux`, `rowSum_succ`, `rowSum_eq`: for a proper colouring, `rowSum c r` is the net number of `H`-edges crossing from row `r - 1` to row `r`, hence independent of `r` (the corollary of Lemma 12; `H` is Eulerian by `indeg_eq_outdeg`); * `rowSum_cast_two`, `odd_rowSum` (Lemma 14, parity): `rowSum c r ≡ n (mod 2)`, so it is odd for odd `n`; * `two_mul_abs_rowSum_le` (Lemma 14, bound): `|rowSum c r| ≤ n / 2`. None of these needs the colouring to be greedy (the paper first makes it greedy by a constant-round post-processing step); properness suffices. -/ namespace Podc.LCLGrids open Finset variable {n : ℕ}
