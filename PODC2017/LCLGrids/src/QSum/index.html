import Mathlib /-! # The `q`-sum coordination problem on directed cycles (Theorem 10) Section 9 of Brandt et al., *LCL problems on grids* (PODC 2017). **Model.** A directed cycle with `n` nodes `ZMod n` (node `v` knows its successor `v + 1` and predecessor `v - 1`) and unique identifiers `id : ZMod n → ℕ`, all `< B`. A deterministic `T`-round LOCAL algorithm (for this `n`, which the nodes know) is a map `f : (ℤ → ℕ) → ℤ` that only depends on the identifiers at offsets `-T, …, T` (`IsLocal T f`); node `v` outputs `f (view id v)`, where `view id v j = id (v + j)`. In the `q`-sum coordination problem, every node outputs `ℓ(v) ∈ {-1, 0, 1}` and `∑_v ℓ(v) = q(n)` (`Solves`). **Theorem 10.** If `q(n)` is odd for odd `n` and `|q(n)| ≤ n/2`, then `q`-sum coordination needs `Ω(n)` rounds. We prove a sharper and more general statement by a different argument than the paper's: if `8T < n` and identifiers may range over `7n` values, then *any* algorithm whose outputs always sum to the same integer `Q` on `n`-cycles (any output alphabet) has `Q = n·δ` for some integer `δ` (`sum_eq_mul`). For odd `Q` with `2|Q| ≤ n` this is impossible, so `n ≤ 8T` (`theorem10_of_solves`, `theorem10`). **Proof idea.** Words are lists of identifiers; `wsum w` is the sum of the outputs of the nodes of `w` whose whole radius-`T` window lies in `w`. For blocks `F, G` of length `K = 2T` and a middle word `X`, `α_{FG}(|X|) = wsum (F X G)` only depends on `|X|` (complete `F X G` to two `n`-cycles `F X G Y`, `F X' G Y`), and `wsum (F P H R G) = wsum (F P H) + wsum (H R G)`. With three blocks `F, G, H`, these identities force all `α` to be affine with a common slope `δ`, and then the two-block cycle identity `α_{FG}(L) + α_{GF}(n - 2K - L) = Q` gives `Q = n δ` (`alg`). -/
