import Cslib.Probability.Finite.Bernoulli import Mathlib.Combinatorics.SimpleGraph.Basic import Mathlib.Order.LiminfLimsup import Mathlib.Data.ENat.Lattice import Mathlib.Basic.Real.ENatENNReal import Mathlib.Order.Filter.AtTopBot.Basic import Mathlib.Topology.Order.LiminfLimsup import Mathlib.Topology.Instances.ENNReal.Lemmas -- CSLib candidate: noisy radio network model (synchronous radio networks with random sender or -- receiver faults, routing and coding schedules, throughput). /-! # The noisy radio network model (Section 3 of the paper) Censor-Hillel, Haeupler, Hershkowitz, Zuzic. *Broadcasting in Noisy Radio Networks.* PODC 2017. **Radio networks.** A topology is a finite simple graph `G` on the nodes `V` with a source `s`. Time proceeds in synchronous rounds. In each round every node either listens or broadcasts a packet. A node `u` *hears* `w` in a round if `u` listens, `w` is a neighbour of `u` that broadcasts, and `w` is the only broadcasting neighbour of `u` (`Hears`). There is no collision detection: a collision, silence and noise all sound the same. **Faults.** Every round, every node flips an independent coin that is *clean* (`true`) with probability `1 - p` and *faulty* with probability `p`. In the *receiver faults* model a node that hears `w` receives `w`'s packet iff its own coin is clean; in the *sender faults* model iff `w`'s coin is clean (a faulty sender transmits noise, which still collides). A run is driven by a coin sequence `ω : ℕ → V → Bool` (`ω r u` is the coin of `u` in round `r`). The *faultless* model is the run with all coins clean. **Routing.** There are `k` messages `Fin k`, initially known only to the source. A node broadcasts one message it knows (routing). The knowledge state is `K : V → Finset (Fin k)`. An *adaptive routing schedule* (Definition 14) is a sequence of functions, one per round, mapping the current knowledge state (all pairs `(u, i)` such that `u` has received `mᵢ`) to an action of every node: silent (`none`) or broadcast `mᵢ` (`some i`). As in the paper, a node directed to broadcast a message it does not know stays silent (`effective`). A non-adaptive (*static*) schedule is one that ignores the knowledge state; in the faultless model this is the paper's notion of routing schedule. **Coding.** Messages and packets are drawn from a finite alphabet `A` (in the paper both have `O(log (n k))` bits; we use the same alphabet for both). In a coding schedule each node's action (silent or a packet) in round `r` is an arbitrary function of its own history of received packets (and, for the source, of the messages); after the last round every node decodes the messages from its history. **Success and throughput** (Definition 1). A schedule *succeeds* with probability at least `1 - 1/k` within `R` rounds if, under the product law of the coins of rounds `0, …, R - 1`, every node knows (decodes) all `k` messages after round `R - 1` with probability at least `1 - 1/k` (for coding: for every message vector). `routingRounds`/`codingRounds` is the least such `R` (`⊤` if none exists) and the throughput is `limsup_{k → ∞} k /
