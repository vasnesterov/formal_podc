### Non-vacuity: an admissible alphabet family -/ /-- Messages and packets for `k` messages: the field with `2^(2 ⌊log₂ k⌋ + 2)` elements, i.e. `O(log k)` bits, within the paper's `O(log (n k))`-bit message and packet size. -/ def galoisAlphabet (k : ℕ) : Type := GaloisField 2 (2 * Nat.log 2 k + 2) noncomputable instance (k : ℕ) : Field (galoisAlphabet k) := inferInstanceAs (Field (GaloisField 2 (2 * Nat.log 2 k + 2))) noncomputable instance (k : ℕ) : Fintype (galoisAlphabet k) := @Fintype.ofFinite _ (inferInstanceAs (Finite (GaloisField 2 (2 * Nat.log 2 k + 2)))) noncomputable instance (k : ℕ) : DecidableEq (galoisAlphabet k) := Classical.decEq _ theorem card_galoisAlphabet (k : ℕ) : k ^ 2 ≤ Fintype.card (galoisAlphabet k) := by rw [Fintype.card_eq_nat_card] change k ^ 2 ≤ Nat.card (GaloisField 2 (2 * Nat.log 2 k + 2)) rw [GaloisField.card 2 (2 * Nat.log 2 k + 2) (by omega)] have : k < 2 ^ (Nat.log 2 k + 1) := Nat.lt_pow_succ_log_self (by norm_num) k calc k ^ 2 ≤ (2 ^ (Nat.log 2 k + 1)) ^ 2 := Nat.pow_le_pow_left this.le 2 _ = 2 ^ (2 * Nat.log 2 k + 2) := by rw [← pow_mul]; ring_nf /-- Theorem 17 for the concrete alphabets `galoisAlphabet` (the hypotheses are satisfiable). -/ example {p : ℝ} (hp0 : 0 < p) (hp1 : p < 1) : ∃ c₁ > 0, ∃ c₂ > 0, ∃ n₀ : ℕ, ∀ n ≥ n₀, ENNReal.ofReal (c₁ * Real.log n) ≤ codingThroughput (star n) none .receiver p galoisAlphabet / routingThroughput (star n) none .receiver p ∧ codingThroughput (star n) none .receiver p galoisAlphabet / routingThroughput (star n) none .receiver p ≤ ENNReal.ofReal (c₂ * Real.log n) := theorem17 hp0 hp1 galoisAlphabet card_galoisAlphabet end Podc.NoisyRadioBroadcast
