Suppose that in step `r` an adaptive procedure chooses an index `σ r y ∈ I` that depends only on `y₀, …, y_{r-1}` (`Causal`) and never chooses the same index twice (`FreshUpTo`). Then the sequence `y` has the same law as the sequence obtained by reading, in step `r`, the coordinate `z (σ r ·)` of an i.i.d. array `z : I → B` (`couple σ b₀ z`). This is the coupling behind "the `j`-th transmission of message `i` uses its own coin" arguments: it turns the round-indexed faults of an adaptive schedule into faults indexed by (message, number of
