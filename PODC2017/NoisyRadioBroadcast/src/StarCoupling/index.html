import Papers.PODC2017.NoisyRadioBroadcast.Prob /-! # Routing on the star: the per-message coupling For an adaptive routing schedule on the star `star n` (source `none`), the `j`-th transmission of message `i` by the source is coupled with its own column of coins `z (some i, j) : V → Bool` (`sel`, an adaptive fresh selection in the sense of `Coupling.lean`). On the coupled coin sequence `couple (sel …) z`, a leaf knows `mᵢ` before round `r` only if one of its coins `z (some i, j)`, `j < cnt i r`, is clean (`know_leaf_imp`), where `cnt i r` is the number of rounds `< r` in which the source broadcasts `mᵢ`; if the leaves never broadcast this is an equivalence (`know_leaf_iff`). -/ namespace Podc.NoisyRadioBroadcast open Finset variable {n k : ℕ}
