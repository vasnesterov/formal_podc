import Papers.PODC2017.RegisterEmulationSpace.Algorithm2WaitFree /-! # Algorithm 2 is safe in sequential runs (Lemmas 6–8, Corollary 4, restricted to sequential runs) Hypotheses on the write sets `R` (`Layout`): clients outside `Wr` have no registers; the registers of every write set are on distinct servers; and the paper's capacity condition: if `R c` meets the write sets of `m` other writers, then `m f + 2f + 1 ≤ |R c|` (for the paper's partition into sets `R_j` shared by `w_j` writers this says `w_j ≤ ⌊(|R_j| - (f+1))/f⌋`). The invariant `SInv` of sequential runs, with `T` = number of completed writes and `u` = the value of the last one: * every timestamped value in the system (registers, pending writes, `tsVal`s, maxima of collects) has timestamp `< T`, or is `(T, u)`, or is `(T + 1, v)` of the write `v` in its writing phase; * (`quorum`, Lemma 7) if `T > 0`, there is a set `Q` of registers on `≥ f + 1` servers that are *protected* at level `T`: their value and every pending or queued write on them has timestamp `≥ T`; a collect that has heard from a register of `Q` has a maximum `≥ T`; * (`count`, Observation 3 and Lemma 6) during the writing phase of `c` with `(T + 1, v)`: `|Sp| + Σ_{d ∈ Nb c} |U d| ≤ |Nb c| f`, where `U d` = registers covered or queued by `d` and `Sp` = registers of `wrSet` that were overwritten by an older write and are no longer covered. When the write completes, `wrSet` has `≥ |R c| - f` registers, so at least `|R c| - f - |Nb c| f ≥ f + 1` of them hold `(T + 1, v)` and are protected: the new `Q`. -/ set_option
