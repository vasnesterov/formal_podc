import Papers.PODC2017.RegisterEmulationSpace.Runs /-! # Algorithm 2 (Section 3.3, Appendix D): the upper bound Base registers store pairs `(timestamp, value)`, initially `(0, v₀)`. Every client `c` has a *write set* `R c` of registers (the paper's `R_j`, `j = ⌊i/z⌋`; `R c = ∅` for clients that never write). * `collect()`: trigger a read on every register (in parallel — the paper scans the registers of a server sequentially, which only delays responses) and wait until every register of some `n - f` servers has responded; the result is the pair with the highest timestamp read. * `write(v)`: collect, take `ts := max + 1`; registers of `R c` that still have a pending write of `c` (from earlier writes) form `coverSet`; trigger `write(ts, v)` on all other registers of `R c` and wait until `|wrSet| ≥ |R c| - f`. When a pending write on a register `b ∈ coverSet` responds, `b` is removed from `coverSet` and rewritten with the *current* `(ts, v)` (lines 29–34), also after the write has returned. * `read()`: collect and return the value of the highest timestamp. Local state (`Loc`): `ts, val` (`tsVal`); `pw` = registers with a pending write of the client (a ghost-free mirror of the pending low-level writes); `cov` (`coverSet`); `wr` (`wrSet`); `q` = registers to be (re)written with the current `tsVal` (a write is triggered only in a step, so the re-trigger of line 32 and the triggers of line 10 are queued here); the mode; and the state of the current collect (`rq` = registers not yet read, `got` = registers that responded, `best` = maximum read so far). -/ set_option linter.unusedSectionVars false namespace Podc.RegisterEmulationSpace.Alg2 open
