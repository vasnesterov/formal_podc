Chockler, A. Spiegelman, *Space Complexity of Fault-Tolerant Register Emulations*, PODC 2017 (arXiv 1705.07212). **Theorem 2.** For all `k > 0`, any algorithm implementing a wait-free `k`-writer max-register from a collection of wait-free MWMR atomic base registers uses at least `k` base registers. The paper derives Theorem 2 from its fault-tolerant Theorem 1 (run `2f + 1` copies of the algorithm and multi-writer ABD on top). We prove it **directly by a covering argument**: * Stage `j ≤ k` (`Stage`): a reachable configuration in which writers `w 0, …, w (j-1)` each have a pending `writeMax` and cover `j` *distinct* registers, while the other writers and the reader `q` have never invoked anything. * Step (`Stage.succ`): let `w j` run `writeMax (j+1)` solo until it is about to write a register outside the covered set or returns (`exists_solo_until`). If it returned, a block write by `w 0, …, w (j-1)` hides all its writes (`blockWrite_agreeOn`), and a subsequent solo `readMax` by `q` returns the same value `r` as in the execution where `w j` did nothing. Linearizability forces `r ≥ j + 1` in the first execution (the `writeMax (j+1)` precedes the read) and `r ≤ j` in the second (only values `≤ j` were written), a contradiction. Only obstruction-freedom and linearizability **on `k`-writer executions** (`WriterExec`: every `writeMax` is invoked by one of the writers) are used. ## Main declarations * `theorem2` — Theorem 2 with the weakest hypotheses (linearizability and obstruction-freedom on `k`-writer executions); `theorem2_of_waitFree` — the paper's form (linearizable, wait-free). * `Stage`, `Stage.succ`, `exists_stage` — the covering construction. * `le_resp_of_precedes`, `resp_le_of_ops` — facts about every linearization of a max-register history. The reader `q` must be distinct from the writers: with a single process (`k = 1`, no reader) zero registers suffice, since the writer can keep the maximum in its local state. The theorem also holds (trivially) for `k = 0`. -/ namespace Podc.RegisterEmulationSpace.MaxRegLB open Cslib.SharedMemory Cslib.SharedMemory.Impl set_option linter.unusedSectionVars false /-! ###
