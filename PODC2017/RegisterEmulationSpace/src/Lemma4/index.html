import Papers.PODC2017.RegisterEmulationSpace.Runs /-! # The indistinguishability argument of Lemma 4 Core of Lemma 4 of the paper (Appendix C), in the form we use: let `X₀` be the configuration after a sequential run (all clients idle) and let a new writer `a` perform a complete write of a value `v ≠` (the current value), with only `a` taking steps and only `a`'s operations responding. Then the registers that are not covered at `X₀` and whose value changed span more than `f` servers. Proof (as in the paper): otherwise crash these `≤ f` servers. Let the covering writes pending at `X₀` take effect (one per covered register, `flush`), both after `X₀` (run `r'`) and after `a`'s write (run `r''`), and run a reader solo. Both configurations agree on the reader and on every register of a correct server, so the reader returns the same value in both runs (`SoloRel`), it returns by obstruction freedom, and sequential safety forces the old value in `r'` and `v` in `r''`. Unlike the paper's Lemma 4 we do not need the adversary here: the statement holds for every schedule of `a`'s write in which only `a` acts. -/ set_option linter.unusedSectionVars false namespace
