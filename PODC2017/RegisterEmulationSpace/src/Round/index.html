The adversary freezes (never lets respond) all operations of `a` on the servers of `zSet Q Wd = Q ∪ G`, where * `Q` (the paper's `Q_i`): the set `covF` of servers outside `F` holding a register outside `K` covered by `a`, as long as this set has at most `f` elements, and frozen afterwards; * `fr = frSet Wd` (the paper's `F_i`, restricted to `F`): servers holding a register outside `K` written in this round; * `G = F \ fr` as long as `|Q| < |fr ∩ F|`, else `∅` (a simplification of the paper's `G_i = M_i`: we freeze all of `F \ F_i`, not only the servers with a covered register). Invariants (the paper's Lemma 2): `Q ⊆ covF`, `|Q| ≤ f`, `|fr ∩ F| ≤ |Q| + 1`, `|Q| < f → Q = covF ∧ fr ⊆ F`, `Q ∩ fr = ∅`. Hence at most `f` servers are frozen (Claim 1), the frozen set is eventually constant, so the strategy run is fair with these servers crashed and `a` returns (Lemma 3). By `fresh_resp` (Lemma 4) `|fr| > f` at the return, hence `|Q| = f` (Corollary 2): `f` servers outside `F` keep a fresh register covered by `a`. Unlike the paper's `Ad_i`, our adversary also freezes the *reads* of `a` on frozen servers, so that the strategy run itself is fair (in the paper, reads on `Q_i ∪ M_i` keep responding, and the crash run of Lemma 3 must crash these servers only at the stabilization time, not "immediately after `r`"). -/ set_option linter.unusedSectionVars false namespace Podc.RegisterEmulationSpace variable {C B V W L S : Type*} [DecidableEq C] [DecidableEq B] [DecidableEq S] [Fintype B] open Function section Defs variable (δ : B → S) (F : Finset S) (a : C) (K : Finset B) open Classical in /-- Registers outside `K` covered by a pending write of `a`. -/ noncomputable def fcov (X : Cfg C B V W L) : Finset B := Finset.univ.filter fun b => b ∉ K ∧ ∃ p ∈ X.pend a, p.reg = b ∧ p.op.IsWrite /-- Servers outside `F` holding a register of `fcov`. -/ noncomputable def covF (X : Cfg C B V W L) : Finset S := (fcov a K X).image δ \ F open Classical in /-- Servers holding a register outside `K` written in the round (`F_i` of the paper, on all servers). -/ noncomputable def frSet (Wd : Finset B) : Finset S := (Wd.filter (· ∉ K)).image δ /-- The frozen servers. -/ noncomputable def zSet (Q : Finset S) (Wd : Finset B) : Finset S := Q ∪ (if Q.card < (frSet δ K Wd ∩ F).card then F \ frSet δ K Wd else ∅) /-- The register written by an event (if it is the response of a write). -/ def written (X : Cfg C B V W L) : Ev C V → Finset B | .resp c n => match (X.pend c).find?
