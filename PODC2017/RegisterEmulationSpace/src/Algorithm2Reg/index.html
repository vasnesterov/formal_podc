import Papers.PODC2017.RegisterEmulationSpace.Algorithm2SeqSafe /-! # Write-sequential regularity (WS-Regularity, Section 2 and Appendix A.3) A history is *write-sequential* if no two high-level writes overlap. Since writes are then totally ordered by real time, the `t`-th write (`t ≥ 1`, in invocation order) has a well-defined value `valOf v₀ wv t` (`valOf v₀ wv 0 = v₀`). A complete read is *regular* if it returns `valOf t` for some `t` with `D ≤ t ≤ I`, where `D` is the number of writes that completed before the read was invoked and `I` the number of writes invoked before the read returned. This is exactly the paper's condition "there is a linearization of the read and all the writes": the writes must be linearized in their real-time order, the read after the `D` writes that precede it and before the writes invoked after its return, and it must return the value of the last write linearized before it. `hscan` computes, by one pass over the history, the write values, the number of completed writes, the pending operations with the number of completed writes at their invocation, and the two properties `ws` (writes are sequential) and `reg` (every completed read is regular). -/
