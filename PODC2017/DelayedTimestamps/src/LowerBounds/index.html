An online algorithm (`IsOnlineTimestamping G A`) assigns to each event, when it occurs, a vector `Fin s → α` (componentwise partial order `<` of Section 3), distinct for distinct events, with `e → f ↔ τ(e) < τ(f)` on every execution over the communication graph `G`. The algorithm may use the whole prefix of the execution (global knowledge), so the bounds hold a fortiori for distributed algorithms. * `card_le_of_online` (general form of Lemmas 1, 3, 4, any linear order `α`): if for every `k ∈ X` all other processes of `X` can reach a common process `r ≠ k` without passing through `k`, then `s ≥ |X|`. * `card_lt_of_online_int` (general form of Lemma 2, integer entries): if moreover all of them reach the same `c ∉ X`, then `s ≥ |X| + 1`. * Corollaries: `lemma_1` (star graph: `s ≥ n − 1`), `lemma_2` (star graph, integers: `s ≥ n`), `lemma_3` (vertex connectivity `≥ 2`: `s ≥ n`), `lemma_4` (non-cut vertices `X`: `s ≥ |X|`), `two_le_of_ne` (two processes: `s ≥ 2`). The proof follows the paper: each process of `X` takes one step first; their timestamps are fixed before the adversary chooses whose information is delayed. For each `k`, the execution gathers the information of `X \ {k}` at `r` (`gather`), and the final event `e` of `r` satisfies `τ(x) ≤ τ(e)` for all `x ∈ X \ {k}` but not `τ(a_k) < τ(e)`; so some coordinate of `τ(a_k)` is a strict maximum (`exists_coord_gt`), and different `k` give different coordinates. -/ namespace Podc.DelayedTimestamps set_option linter.unusedSectionVars false open Cslib.Causality /-!
