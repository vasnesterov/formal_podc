Vectors are indexed by the processes other than `c` (`n − 1` entries). Each process keeps a vector `v` (initially `0`); at each event it merges the vector piggybacked on a received message (pointwise max) and then applies `update`: * a process `p_k ≠ c` sets `v[k] := ⌊v[k] + 1⌋` (the next integer); * the cut vertex `c` replaces every `v[j]` by "any value in the open interval `(v[j], ⌊v[j] + 1⌋)`" — modelled by an arbitrary choice function `pick` (which may depend on the position of the event, the coordinate and the old value) with `x < pick x < ⌊x⌋ + 1`. The paper omits the correctness proof ("straightforward").
