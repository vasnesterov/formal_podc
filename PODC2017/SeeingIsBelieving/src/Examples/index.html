import Papers.PODC2017.SeeingIsBelieving.Hierarchy import Papers.PODC2017.SeeingIsBelieving.SnapshotIsolation /-! # Examples * **Write skew** (Section 1, Figure 1(r), and Section 5.1, Figure 3): two transactions read both keys `x`, `y` from the initial state and write different keys. They satisfy the state-based definition of snapshot isolation but not of serializability (`writeSkew_SI`, `writeSkew_not_Ser`); this also shows that the hypotheses of the theorems are satisfiable. * **The version order must be quantified** (`blindWrites_*`): two blind-writing transactions satisfy `CT_SER` (hence `CT_RU`), yet for the version order `x₀ ≪ x₁`, `y₁ ≪ y₀` the history exhibits G0 (and G1c). So Theorems 1–4 are false if "¬G1 ∧ ¬G2" (etc.) refers to a fixed history with its own version order; the right-hand sides must read "for some version order". -/ namespace Podc.SeeingIsBelieving open Relation /-! ### Write skew -/ /-- Keys: `false` is `x`, `true` is `y`. Transaction `0` reads `x, y` and writes `x`; transaction `1` reads `x, y` and writes `y`. -/ def writeSkew : TxnSet Bool (Fin 2) where ops T := [.read false none, .read true none, .write (T = 1 : Bool)] committed := Finset.univ lemma writeSkew_wellFormed : writeSkew.WellFormed where read_other T _ k X h hX := by simp [writeSkew] at h read_own T _ m k h := by rcases m with _ | _ | _ | m <;>
