The implementation is computable (bitmasks and lists), so that concrete runs can be evaluated in the kernel (`decide +kernel`); `Alg.run_eq_cconf` identifies `Alg.run` with the computable mirror `cconf` for patterns given by a Boolean adjacency function. Rounds: our round index `t` (graph `ρ t`) is the paper's round `t + 1`; inside the step function, `r = round + 1` is the paper's current round number. In round `r` the Alg. 1 step is executed before the Alg. 4 step, and Alg. 4 uses the Alg. 1 state at the end of round `r` (paper, Sec. 7.3). Messages are the senders' full states at the beginning of the round (full-information form). ## Representation * Process `j : Fin n` is the number `j.val`; a set of processes is a bitmask `R : ℕ`; the edge `(u → w)` (`w` received `u`'s message) is bit `u * n + w`. * Alg. 1: `A : List ℕ` with `A.getD t 0` = bitmask of the edges whose label set `T` contains the round `t` (so `A_p|t` of line 13 is `A.getD t 0`). * Alg. 4: a lock `(V(R), v, τ_create)` is `Lock`. The lock history `hist_i[j][r']` is stored as a list of pairs `(L, e)` with `e.getD j none = some r'` the *earliest* round `r'` such that `L ∈ hist_i[j][r']` (`none`: `L` in no entry of row `j`). Algorithm 4 only ever reads `⋃_{r'' ≤ r'} hist_i[j][r'']` (line 26), which is determined by these earliest rounds, and the updates of lines 13–15 and 20 translate into `min` (see I4). ## Interpretation choices * **I1** `A_p|t` (Alg. 1, line 13) has vertex set `{p} ∪ {endpoints of edges labelled t}` (with the edge-induced graph only, a deaf singleton could never detect itself, contradicting Lemma 13). * **I2** `C_p|t` (line 14) is the strongly connected component of `p` in `A_p|t` if no edge of `A_p|t` enters it from outside, and empty otherwise (sound and complete version of line 14; literally, "`A_p|t` if strongly connected", Lemma 13 and Corollary 2 fail as soon as processes outside the root report edges leaving it). * **I3** `InStableRoot(I)` is empty if `I` contains a round `t < 1` (no graph exists there). * **I4** Line 15 (`hist_i[i] := hist_i \ hist'_i`): every lock that newly appears in some entry `hist_i[x][r']` is added to `hist_i[i][r]`; since the own row always contains every lock of the other rows, this means: a lock not yet in row `i` gets earliest round `r` in row `i`. Lines 13–14 copy all rows `x ≠ i` (pointwise `min` of earliest rounds). * **I5** The multiset `S` of line 26: the multiplicity of `L` is the number of `j ∈ R` with `L ∈ ⋃_{r'' ≤ r'} hist_i[j][r'']` ("the number of members of `R` who got to know `L` by round `r − 2D`", p. 32). * **I6** `mfrq_latest` exactly as line 27: `{x ∈ mfrq(S) | ∀ y ≠ x ∈ mfrq(S), x.τ > y.τ}`; the fallback of line 32 is the maximum value over *all* of `S`. * **I7** `τ_create` of a new lock is the current round `r` (lines 30, 32); locks are compared as triples. * **I8** Lines 8–9: if several decisions are received, the smallest one is adopted. * **I9** The `else if` chain of lines 17/21/23 is evaluated once per round after the history update; `lock` is the value set in line 19. * **I10–I14** concern the message adversary and are listed in `MajInf.lean`.
