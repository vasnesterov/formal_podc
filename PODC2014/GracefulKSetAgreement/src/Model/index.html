import Mathlib import Cslib.Computability.Distributed.DynamicNetworks.HeardOf import Cslib.Computability.Distributed.DynamicNetworks.Journey /-! # The model of Biely–Robinson–Schmid–Schwarz–Winkler (Section 3) A fixed finite set `P` of processes with unique identifiers runs in synchronous lock-step rounds. In round `t + 1` an omniscient message adversary chooses the directed communication graph `ρ t` (`Cslib.HeardOf.Graph`: `ρ t q p` means that `p` receives the round-`t+1` message of `q`; every process always "hears" itself). A message adversary (Definition 2) is a set of communication patterns `ρ : ℕ → Graph P`; inputs are arbitrary and independent of the pattern. **Algorithms.** We use the full-information form: every process broadcasts its whole state and applies a deterministic transition function (`Cslib.HeardOf.StepFn`) to the vector of received states. The paper's algorithms (a sending function `M_p` and a transition function `T_p`) are the special case where the state is post-processed by `M_p`; impossibility results for full-information algorithms therefore cover every algorithm of the paper's model. A process' identifier is an argument of `init` and `step`, and the algorithm may depend on `P` (it knows `n`) and on any parameter of the adversary. Decisions are irrevocable (`dec_stable`, the paper's "decided states are closed under the transition function"). **Problems** (Definitions 3 and 4). `SolvesKSet A k Adv`: for every input vector and every pattern of `Adv`, at most `k` different values are decided, every decision is some input, and every process decides. Consensus is `k = 1`. **Graph notions** (Definitions 5–10, 12, 15, 16), with round indices starting at `0` (the paper's round `t + 1` is our index `t`; the paper's interval `I = [a, b]` of rounds has the same length `b − a + 1`): * `IsRootComp G R`: `R` is a root component (= source component, CSLib's `Digraph.IsSourceComponent`) of `G`. * `IsVSRC ρ R a b`: `R` is a vertex-stable root component in the rounds `a..b`. * The causal distance bound `cd_x(p, q) ≤ k` (Definition 7, `k ≥ 1`) is the journey `Journey ρ x p (x + k) q` (CSLib `Cslib.DynNet.Journey`, from time `x` to time `x + k`). * `DBounded`, `HNetBounded` (Definitions 9 and 10), the message adversaries `VSRCd` (Def. 12), `VSRCk`, `VSRCkInf` (Def. 15, finite and infinite stability window) and `SigmaMaj` (Def. 16). -/ namespace
