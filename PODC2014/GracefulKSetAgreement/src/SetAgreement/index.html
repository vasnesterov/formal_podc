import Papers.PODC2014.GracefulKSetAgreement.Model /-! # Set agreement under `Σ_{n−1}-MAJ` (Section 7.1, Algorithm 3, Theorem 10) Algorithm 3 of the paper, for `n` processes `Fin n` (the algorithm knows `n`). Process `p_i` keeps a proposal `v_i` (initially its input `x_i`) and a decision `y_i` (initially `⊥ = none`); both are broadcast every round. In round `r`, with `N` the set of *other* processes heard: ``` 5: v_i := max {v_i, v_j : j ∈ N} 6: if ∃ j ∈ N : y_j ≠ ⊥ ∧ y_i = ⊥ then 7: y_i := y_j 8: if N = ∅ ∧ y_i = ⊥ then 9: y_i := v_i 10: if r = n ∧ y_i = ⊥ then 11: y_i := v_i ; terminate ``` In the full-information model of `Model.lean` the received states are the senders' states at the beginning of the round. The state carries the number `r` of completed rounds (the paper's round number is `r + 1`). When several heard processes have decided, line 7 adopts the decision of a fixed (choice-function-selected) one of them: the paper says "some `p_j`", and the proof works for any choice. After round `n` the processes keep running, but their decisions are frozen (`terminate`). ## Main results * `alg3_decided_at_n`: every process has decided at time `n` (after `n` rounds), for every communication pattern. * `theorem10`: Algorithm 3 solves `(n − 1)`-set agreement under `SigmaMaj` (Definition 16), for every `n` (for `n ≤ 1` the adversary `SigmaMaj` is empty, since it asks for two distinct processes) and every linearly ordered value set `V` (`Inhabited` only to fill the unreachable branch of the transition function). * `complete_mem_sigmaMaj`: non-vacuity for `n ≥ 2`. The proof follows the paper's induction, organised as follows. If `n` different values are decided, the decision map `D` is injective (hence a permutation of the inputs, which are then distinct), and no process ever adopts a decision (it would duplicate one). By strong induction on the rank of the input, every process `p` decides its own input `x_p`, in the round where it first decides, which is at most its rank; hence that round is one in which `p` is deaf (Line 9; for the maximal input, Line 11 can only fire in a deaf round as well). These `n` singleton root components, applied to Definition 16, yield a causal chain from one deciding process (after its decision) to another one (before its decision); decisions propagate along
