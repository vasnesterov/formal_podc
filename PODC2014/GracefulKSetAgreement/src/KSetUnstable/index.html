All other processes are never in a group. Given phase boundaries `0 = T 0 ≤ T 1 ≤ … ≤ T γ` and words `w g`, the communication graph of round `t` (`phaseG`) is: * group `g` is a **lossy link** with letter `w g t` in rounds `t < T g`, * group `g` is **deaf** (both members hear nobody) in rounds `T g ≤ t < T (g + 1)`, * afterwards, and always for the processes outside the groups, a process is **released**: it hears everybody. In phase `j` (rounds `T j ≤ t < T (j + 1)`) the root components are `{a j}`, `{b j}` and one root component per lossy group `g > j`: at most `|group 0| + γ - 1 ≤ ⌈k/2⌉ + 1` of them, every one a clique of size `≤ 2` (so every vertex-stable root component is `D`-bounded for every `D ≥ 1`). From round `T γ` on the graph is complete: a single root component, `H`-network-bounded for every `H ≥ 1` (`phaseG_good`, `mem_thm9Adv`). The words and boundaries are chosen group by group (`pair_cover`): for horizon `L = T g`, the finite-horizon lossy-link lemma (`exists_lossy_disagree`, Lemma 17) yields a word of length `L` after which the two members, deaf from `L` on, decide two different values; validity forces these to be their two inputs, and `T (g + 1)` is the time by which both have decided. Since group `g` is closed until `T (g + 1)`, its members behave exactly as in the lossy-link pattern (`conf_eq_of_family`), so all `k + 1` inputs are decided in the final run. The paper's proof uses Lemma 17 in its "∃ r'" form; this does not give a bad run *of the required length* `L = T g` (fixed by the earlier phases).
