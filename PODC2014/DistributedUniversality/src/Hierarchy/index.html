import Papers.PODC2014.DistributedUniversality.SCfromUC /-! # Section 4.4: `(k, k − p)`-SC solves `(p + 1)`-set agreement Raynal, Stainer, Taubenfeld, *Distributed Universality* (PODC 2014), Section 4.4 and Figure 3. The reduction: process `i` proposes the constant vector `[v_i, …, v_i]` to a `(k, k − p)`-SC object, obtains `k − p` pairs, and decides the maximum of the `k − p` values it obtained. The paper's argument ("for any process `p_i`, at most `p` values among the `k` values proposed are greater than the value decided by `p_i`") is correct; we verify it combinatorially, for an arbitrary set of deciding processes and an arbitrary linearly ordered value type (`setAgreement_of_SC`). We also record the two "extreme cases" of Section 4.4: `(k, k)`-SC solves consensus (decide the value of entry `0`, `consensus_of_SC_kk`), and a vector of `k` consensus decisions is a `(k, k)`-SC outcome (`SC_kk_of_consensus`). That `(k, 1)`-SC is `k`-SC holds by definition (`IsSCOutcome` with `ℓ = 1` is exactly the `k`-SC specification), so it is not restated. -/ namespace Podc.DistributedUniversality.Abstract variable {P V : Type*} /-- **`m`-set agreement** among the deciding processes `S` (with proposals `v`): at most `m` distinct decisions, each of them proposed by some process. -/ def IsSetAgreement [DecidableEq V] (m : ℕ) (S : Finset P) (v : P → V) (out : P → V) : Prop := (S.image out).card ≤ m ∧ ∀ i ∈ S, ∃ j, out i = v j /-- The maximum of the decided values of a `(k, ℓ)`-SC outcome exists when `ℓ ≥ 1`. -/ lemma IsSCOutcome.exists_isGreatest [LinearOrder V] {k ℓ : ℕ} {S : Finset P} {prop : P → Fin k → V} {D : P → Finset (Fin k)} {d : P → Fin k → V} (h : IsSCOutcome k ℓ S prop D d) (hℓ : 0 < ℓ) {i : P} (hi : i ∈ S) : ∃ o, IsGreatest (d i '' ↑(D i)) o := by have hne : (D i).Nonempty := Finset.card_pos.1 (by rw [h.card_eq i hi]; exact hℓ) obtain ⟨x, hx, hmax⟩ := Finset.exists_max_image (D i) (d i) hne exact ⟨d i x, ⟨x, hx, rfl⟩, by rintro _ ⟨y, hy, rfl⟩; exact hmax y hy⟩ /-- **Section 4.4, "From `(k, k − p)`-SC to `(p + 1)`-set agreement"** of [Raynal–Stainer–Taubenfeld, PODC 2014].
