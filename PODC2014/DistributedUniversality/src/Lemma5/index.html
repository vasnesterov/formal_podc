import Papers.PODC2014.DistributedUniversality.NonVacuity /-! # Lemma 5: in every round, some operations are committed Lemma 5 of Raynal–Stainer–Taubenfeld (PODC 2014) states, for the construction of Figure 1, that in every round `r` some process obtains `(commit, op)` from the adopt-commit object of an object `op` was decided for by `kSC[r]`. The proofs of Theorem 2 (Figure 2) and Theorem 4(a) (Section 4.3, `(k, ℓ)`-SC objects) reuse its argument in the generalized form: in every round at least `ℓ` objects have an operation committed by some process (or, in the contention-aware variant, all `k` objects, when some process skipped lines 2M–4M). The proof is by the inductive invariant `NonVacuity.Inv`: the first process `p` to finish its adopt-commit invocations on its `ℓ` decided objects (ghost `firstL r`) got commit on all of them, because before that moment every invocation of these adopt-commit objects comes from a process still in its decided block, which proposes the value agreed by `SC[r]`, so the no-conflict property applies. -/ namespace Podc.DistributedUniversality.Lemma5 open Podc.DistributedUniversality NonVacuity variable {n k : ℕ} {M : Mode} /-- Process `p` has completed the adopt-commit part (lines N1–4 / N1–4M) of round `r`. -/ def DoneAC (s : St n k) (p : Fin n) (r : ℕ) : Prop := r < (s.loc p).r ∨ (r = (s.loc p).r ∧ ((∃ q, (s.loc p).pc = .collect q) ∨ (s.loc p).pc = .loc ∨ (∃ m, (s.loc p).pc = .upd m) ∨ (s.loc p).pc = .write)) theorem past_of_doneAC {s : St n k} (hI : Inv M s) {r : ℕ} (hr : 1 ≤ r) {p : Fin n} (hd : DoneAC s p r) : Past M s p r := by have h := hI.proc p rcases hd with hd | ⟨rfl, hd⟩ · exact h.past _ hr hd · have hp := h.pc rcases hd with ⟨q, hq⟩ | hq | ⟨m, hq⟩ | hq <;> rw [hq] at hp · exact hp.2.2 · exact hp.2 · exact hp.2.2 · exact hp.2 /-- **Lemma 5, generalized form (used in the proofs of Theorem 2 and Theorem 4(a)).** Assume `1 ≤ ℓ ≤ k`.
