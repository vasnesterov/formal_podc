import Mathlib /-! # Segment schedules: the model of Section 2 of Miller–Pelc (upper bounds) All three algorithms of Section 2 of [Miller, Pelc, *Time versus cost tradeoffs for deterministic rendezvous in networks*, PODC 2014] (Cheap, Fast, FastWithRelabeling) have the same shape: the agent's time is cut into *segments* of `E` rounds, and in segment `i` the agent either executes the procedure EXPLORE (which visits every node of the graph within `E` rounds, from any start) or waits `E` rounds. Such an algorithm is a bit list (`true` = explore), the *segment schedule*; after the list is exhausted the agent stays where it is. **Model.** For the upper bounds of Section 2 no graph structure is needed: the network is an arbitrary type `V` of nodes and EXPLORE is abstracted by `Explore V E`, a family of walks `walk v t` (position after `t` rounds of EXPLORE started at `v`) visiting every node within `E` rounds. EXPLORE always takes exactly `E` rounds (it waits at the end), so its position after `t` rounds is `walk v (min t E)`. Executions are synchronous and deterministic. The adversary wakes agent `A` at time `δA` and agent `B` at time `δB`, with `δA = 0 ∨ δB = 0` (time is counted from the wake-up of the earlier agent). A sleeping agent sits at its starting node, where it can be found. Both agents stop upon meeting. * `pos X a r` : position of agent `a` at time `r` (after `r` rounds); * `MeetsAt X A B r` : both agents are at the same node at time `r`; * `meetTime X A B` : the first such time (rendezvous time, counted from the earlier wake-up); * `cost X A B` : the number of rounds before the first meeting in which `A` changes its position, plus the same for `B` (the edge traversals of both agents before rendezvous). -/ namespace Podc.RendezvousTimeCost.Upper /-- `omega` after expanding products `(a + b) * E` into multiples of the atoms `x * E`. -/ macro "rtc_omega" : tactic => `(tactic| ((try simp only [add_mul, mul_assoc, one_mul] at *) <;> omega)) /-- An exploration procedure with time bound `E` on a network with node set `V`: `walk v t` is the position after `t` rounds of EXPLORE started at `v`, and every node is visited within `E` rounds.
