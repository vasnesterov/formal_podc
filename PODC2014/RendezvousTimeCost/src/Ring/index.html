import Mathlib /-! # Rendezvous in the oriented ring with simultaneous start (Section 3 of Miller–Pelc) The lower bounds of [Miller, Pelc, *Time versus cost tradeoffs for deterministic rendezvous in networks*, PODC 2014] are proved in the oriented ring of known size `n` (exploration bound `E = n - 1`), with simultaneous start. In this setting an agent learns nothing before meeting (every node has degree 2, and its entry port is determined by its own last move), so a deterministic algorithm is the same as a *behaviour vector* per label: `V x j ∈ {-1, 0, 1}` is the move of agent `x` in round `j + 1` of its solo execution (`1` = clockwise = port 0, `-1` = counterclockwise, `0` = idle). The paper works with behaviour vectors throughout Section 3. Nodes are `ZMod n`, numbered clockwise (for the analysis only). * `disp v t` : displacement after `t` rounds; `moves v t` : number of edge traversals. * `Meets n V x px y py t` : in execution `α(x, px, y, py)` both agents are at the same node at the end of round `t` (they follow their solo behaviour until they meet). * `meetTime` : the first such round `|α(x, px, y, py)|`; `execCost` : the cost of the execution (edge traversals of both agents before rendezvous). * `IsRendezvous`, `TimeLE`, `CostLE` : correctness and worst-case time / cost bounds of an algorithm, over all pairs of distinct
