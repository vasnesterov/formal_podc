import Papers.PODC2014.RendezvousTimeCost.Ring /-! # Theorem 3.2 of Miller–Pelc: fast rendezvous is expensive (repaired proof) Theorem 3.2 of [Miller, Pelc, *Time versus cost tradeoffs for deterministic rendezvous in networks*, PODC 2014]: in the oriented ring of size `n` (`E = n - 1`) with simultaneous start, every deterministic rendezvous algorithm for `L` labels with time `O(E log L)` has cost `Ω(E log L)`. ## The repair The paper cuts the ring into 6 sectors of size `n/6` and time into blocks of `n/6` rounds, and encodes each agent by the sequence of sectors visited at block boundaries (its "progress vector"). Its Fact 3.11 claims that two agents with the same progress vector, started at antipodal nodes, never meet. This is false: knowing the sector of an agent only at block boundaries does not confine it mid-block (an agent at the end of `P_{j+1}` may enter `P_{j+2}` mid-block and come back), so the two agents can meet. We use a repaired argument with more slack, entirely in terms of displacements on `ℤ` (no sector arithmetic mod 6; any `n ≥ 10` works): * blocks and sectors have length `s = n / 10`; the *sector walk* of agent `x` is `σ_x(k) = ⌊d_x(k s) / s⌋`, where `d_x` is the trimmed displacement `tdisp` (it moves by at most one sector per block); * the progress vector `J_x ∈ {-1, 0, 1}^K` records the jumps of a greedy anchor that follows `σ_x` with hysteresis 2 (`LBTime.anc`, `LBTime.jmp`); the anchor is `2 * Σ_{i<k} J_x(i)`, so equal progress vectors give `|σ_x(k) - σ_y(k)| ≤ 2` at all block boundaries; * hence two agents with equal progress vectors stay within distance `< 5 s ≤ n / 2` of each other's (relative) start for the whole time `K s ≥ T`, so started at distance `n / 2` they do not meet: distinct labels have distinct progress vectors; * every jump costs at least `s + 1` edge traversals (the displacement since the last jump changes by more than `s`); * there are few vectors with fewer
