Initially a node knows its degree and its input; in round `t + 1` it sends a message to every port, receives one from every port, gets **one random bit** `β v t` and moves to a new state. `out : State → Option O`; outputs are **irrevocable**: the output of a node is the first `some` it produces (`decided`). `IsDeterministic`: `recv` ignores the random bit. * `Problem In Out`: a set of input instances (labelled graphs) and, for each, the valid output labellings. * `Solves A Π` (Las Vegas): on every instance and every simple port numbering of it, (termination) every finite prefix of random bits can be extended to an assignment under which all nodes output, and (validity) whenever all nodes have output, the output labelling is valid. See `Measure.lean` for the equivalence of validity with "every output labelling obtained with positive probability is valid" and the implication "termination with probability 1 ⇒ termination as above". * `decision Y`: the decision problem `Δ_Y`; `GRAN`; `colored Π`: the 2-hop coloured variant `Πᶜ`. The *locality lemma* `decided_local`: with the colour-sorted port numbering, the state of a node after `t` rounds is determined by its view of tree depth `t + 1` (i.e. `L_{t+2}`) labelled with inputs, colours and the first `t` random bits. (One more level than rounds, because the port number at the far end of an edge depends on the colours around the far end.)
