import Papers.PODC2014.RandomizationTwoHop.Graphs -- CSLib candidate (paper-local for now; see README) /-! # Local views §1.1 of the paper: the depth-`d` local view `L_d(v, G)` is the rooted tree with `L_1(v)` a single vertex marked `ℓ(v)`, and `L_{d+1}(v)` obtained by hanging `L_d(u)` below the root for every `u ∈ Γ(v)`. We never build the trees; we only need *equality* of views, which we define by recursion (`TEq`): two rooted unordered marked trees are equal iff the root marks agree and there is a bijection between the children matching equal subtrees. * `TEq G lG H lH k u v`: `L_{k+1}(u, G) = L_{k+1}(v, H)` (tree depth `k`). * `ViewEq X u Y v d`: the paper's `L_d(u, X) = L_d(v, Y)` (`d ≥ 1`), `ViewEqInf`: `L_∞(u) = L_∞(v)` (equality of all finite truncations; for the finitely branching trees at hand this is equality of the infinite trees). * `lang G lG v`: the set of label sequences of walks starting at `v`. For a 2-hop coloured graph siblings in a view tree carry different marks, so the tree is determined by this set of words (`teq_iff_trunc_lang`): `lang` is the canonical representation of `L_∞(v)` that we use for the infinite view graph and the infinity model. * `IsLocalIso.teq`, `IsLocalIso.lang_eq`: **Fact 1** (local isomorphisms preserve views). -/ namespace Podc.RandomizationTwoHop open
