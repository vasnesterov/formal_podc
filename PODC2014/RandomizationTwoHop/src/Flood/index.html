import Papers.PODC2014.RandomizationTwoHop.AStar -- CSLib candidate (paper-local for now; see README) /-! # Full-information flooding algorithms A deterministic anonymous algorithm that floods truncated walk languages: after `t` rounds node `v` knows `trunc t (⟪X⟫ v)` (its view of tree depth `t`, i.e. `L_{t+1}(v)`), and in round `t` it outputs `F t (trunc t (⟪X⟫ v))` if this is `some` and it has not output before. This turns any "view-based" output rule `F` into a genuine port-numbering algorithm (`floodAlg`), for every port numbering (ports are only used to receive the neighbours' languages). -/ namespace Podc.RandomizationTwoHop open SimpleGraph Cslib.PortNumbering variable {L O : Type} /-- The first output of the rule `F` on the truncations of `T` up to depth `t`. -/ def firstOut (F : ℕ → Set (List L) → Option O) (T : Set (List L)) : ℕ → Option O | 0 => F 0 (trunc 0 T) | t + 1 => (firstOut F T t).or (F (t + 1) (trunc (t + 1) T)) /-- The flooding algorithm with output rule `F`. exact hw' refine ⟨mem_lang_iff.2 (Or.inr ⟨_, w', ?_, hw2.1, rfl⟩), by simp; have := hw2.2; omega⟩ rw [← hPG]; exact P.adj_nbr hP hi · rintro ⟨hw, hl⟩ rcases mem_lang_iff.1 hw with rfl | ⟨u, w', hu, hw', rfl⟩ · exact Or.inl rfl · right rw [← hPG] at hu obtain ⟨i, hi, rfl⟩ := P.exists_port_of_adj hu refine ⟨i, trunc t (⟪X⟫ (P.nbr v i)), w', by simp only [hi, ↓reduceIte, ih];
