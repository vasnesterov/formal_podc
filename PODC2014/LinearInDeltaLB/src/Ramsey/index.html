A *shape* is a finite set `X ⊆ F_k` (the radius-`t` neighbourhood of a node of a PO-view, re-rooted at `1`). For a set `S ⊆ ℕ` with `|S| = |X|`, `labelOf X S` is the order-preserving identifier assignment `X → S`; `satColour A X S` records whether `A` saturates the root of `X` labelled by `S` (the saturation indicator `A*` of the paper).
