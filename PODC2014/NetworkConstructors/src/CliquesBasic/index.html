States (for `c ≥ 3`): * `l i` = `l_i` (`0 ≤ i ≤ c − 2`): leader of a partial component with `i` followers; * `fi j` = `f_j` (`1 ≤ j ≤ c − 2`): former leader, now a follower, still releasing `j` followers; * `f`: follower of a partial component; * `lbar i` = `l̄_i` (`0 ≤ i ≤ c − 2`): leader of a component of order `c` that has already numbered `i` of its followers; * `lead` = `l`: leader of a completed component; * `num k` = `k` (`1 ≤ k ≤ c − 1`): numbered follower of degree `k`; * `lp k` = `l'_k` (`1 ≤ k ≤ c − 1`): numbered follower of degree `k` currently visited by its leader; * `r`: leader whose token is visiting one of its followers.
