Given pairwise disjoint sets `Y i` of `M = m²` identifiers (`i < r`), `asgEquiv` assigns the identifiers of `Y i` to block `i` *in increasing order by rows* (node `(i m + a, b)` gets the `(b m + a)`-th smallest element of `Y i`), as in the paper. For an internal node `v` of block `i` (`T ≤ a < m - T`, `T ≤ b < m - T`), the `k × k` region around it (`k = 2T + 1`) lies in block `i`, and its identifiers are again placed in increasing order by rows: `view_asg_internal` shows that `view T σ v = placement X` for the set `X ⊆ Y i` of identifiers in the region, where `placement X` puts the `K = k²` elements of `X` in increasing order by rows.
