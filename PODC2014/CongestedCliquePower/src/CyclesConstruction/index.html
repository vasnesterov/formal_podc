This is the paper's construction (the internal nodes `u_{i,j}` of `P_i` are the `(i, h)`, `0 < h < len i`). `lowerBoundGraph` shows that `G0 len F` is a `(C_ℓ, F)`-lower bound graph whenever * every path has length `≥ 1`; * `len i + len j + 2 = ℓ` for every edge `{i, j}` of `F` (so the intended cycle `A i – A j –P_j– B j – B i –P_i– A i` has length `ℓ`); * `ℓ ≤ len i + len j + 3` for all `i ≠ j`; * `F` is `C_ℓ`-free. The heart of the proof (condition II) is `exists_fitsSeq`: we follow a copy of `C_ℓ` as a cyclic sequence. Internal path vertices have degree two, so the cycle traverses every path it enters (`up_forced`, `down_forced`); it must use a path since `F` is `C_ℓ`-free; after normalizing the copy so that it starts with `A i → (i, 1)`, it goes up `P_i`, makes `r ≥ 1` steps in `F_B`, goes down a path `P_j` (`j ≠ i`), and makes `s ≥ 1` steps in `F_A` back to `A i` (`core`).
