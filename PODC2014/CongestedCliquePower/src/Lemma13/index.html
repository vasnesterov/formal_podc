Given an `(H, F)`-lower bound graph `G'` on the node set `V` (`|V| = n`), Alice's input `x` and Bob's input `y` are subsets of `E_F`; the input graph `famG x y` is `G'` with the edges `φA(e)`, `e ∉ x`, and `φB(e)`, `e ∉ y`, removed. By Observation 11, `famG x y` contains `H` iff `x ∩ y ≠ ∅`. Alice simulates every node outside `V_B`, Bob the nodes of `V_B`. * `lemma_13_bcast`: a deterministic `T`-round CLIQUE-BCAST algorithm with `b`-bit messages detecting `H` gives `|E_F| ≤ T · n · b + 2` (the paper's `Ω(|E_F| / (n b))`), using the proved bound `CC(DISJ_K) ≥ K`. * `lemma_13_bcast_rand`: the same for randomized algorithms with error `ε`, given as hypothesis that private-coin protocols for `DISJ_K` with error `ε` need `C` bits (Kalyanasundaram–Schnitger / Razborov: `C = Ω(K)` for constant `ε < 1/2`; not formalized). * `lemma_13_congest`, `lemma_13_congest_rand`: CONGEST-UCAST on the input graph, for a `δ`-sparse lower bound graph: `|E_F| ≤ T · 2 · ⌊δ n⌋ · b + 2` (the paper's `Ω(|E_F| / (δ n b))`).
