This holds only for `N` large enough. Smallest failure: `ℓ = 5`, `N = 4`. Every graph on `4 < 5` vertices is `C₅`-free, so the only extremal `C₅`-free graph on `4` vertices is `K₄` (`eq_top_of_isExtremal`), and there is **no** `(C₅, K₄)`-lower bound graph on any vertex set (`no_lowerBoundGraph_C5_K4`): * for an edge `{u, v}` of `K₄`, the copy of `C₅` given by condition I has exactly four vertices `A_u, A_v, B_u, B_v` in `V_A ∪ V_B`; going around the cycle, two of them that are consecutive lie on different sides, so `G'` has an edge `A_x B_y` with `x, y ∈ {u, v}` (`exists_cross_edge`); * doing this for the disjoint edges `{0, 1}` and `{2, 3}` gives edges `A_x B_y` and `A_p B_q`, and then `A_x – A_z – A_p – B_q – B_y – A_x` (`z ∉ {x, p}`) is a copy of `C₅` with three vertices in `V_A`, contradicting condition II (which allows exactly two).
