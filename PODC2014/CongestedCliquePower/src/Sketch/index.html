IPDPS 2011 style) /-! # Reconstructing degenerate graphs from linear sketches The upper bound of Theorem 7 (Drucker–Kuhn–Oshman, PODC 2014) uses the one-round algorithm of Becker, Matamala, Nisse, Rapaport, Suchan, Todinca (IPDPS 2011, the paper's reference [2]): every node broadcasts `O(k log n)` bits, from which all nodes reconstruct the input graph if its degeneracy is at most `k`. We formalize a version of this algorithm with linear sketches over `𝔽₂`: * `exists_independent`: there is a matrix `M : V → 𝔽₂^m` with `m = 2k·⌈log₂(n+1)⌉ + 1` in which every nonempty set of at most `2k` columns has a nonzero sum (counting argument). * `sketch_injOn`: then the sketch `σ(S) = ∑_{v ∈ S} M v` is injective on sets of size `≤ k`. * `eq_of_sketch`: a `k`-degenerate graph `G₁` and any graph `G₂` with the same degrees and the same neighbourhood sketches are equal (peeling: a vertex of small degree has its neighbourhood determined by its sketch; remove it and update the sketches). -/
