import Mathlib /-! # Boolean circuits with `b`-separable gates (Section 2 of [DKO14]) [DKO14]: A. Drucker, F. Kuhn, R. Oshman, *On the power of the congested clique model*, PODC 2014. A circuit is a DAG of gates. Following the paper, the inputs of the circuit are gates without in-wires: a gate `h` with `src h = some i` reads the input bit `x i`; every other gate `h` computes a Boolean function `op h` (of unbounded fan-in) of the values of its in-neighbours `in(h) = {g | wire g h}`. There are no multi-wires (`wire` is a relation). Instead of the "longest path" we use a layering `rank` that strictly increases along wires; a circuit has depth at most `D` iff it admits such a layering with values `≤ D` (take `rank g` = the length of the longest path ending in `g`). ## Main definitions * `Circuit X C`: a circuit with inputs `X` and gates `C`; `Circuit.eval`. * `Separable b f` (Definition 1): `f` is `b`-separable. * `Circuit.numWires`, `Circuit.DepthLE`. ## Main statements * `separable_and`, `separable_or`: AND and OR are `1`-separable. * `andCircuit_eval`: a small concrete circuit (non-vacuity). * `heavy_count_counterexample`: with the paper's thresholds (weight `|in G| + |out G|`, heavy iff weight `≥ n * s` where `N = n² * s`) there can be more than `n` heavy gates, contradicting the first sentence of "Construction of I" in the proof of Theorem 2. -/ namespace Podc.CongestedCliquePower /-- A Boolean circuit with inputs indexed by `X` and gates `C`. -/ structure Circuit (X C : Type) = f x end Circuit /-- **Definition 1 of [DKO14].** `f : {0,1}^ι → {0,1}` is `b`-separable if for every partition of the inputs (given as a map `π : ι → κ` to the part index; empty parts are allowed) there are functions `g j : {0,1}^{π⁻¹(j)} → {0,1}^b` and `h : ({0,1}^b)^κ → {0,1}` with `f x = h (g j (x|π⁻¹(j)))_j`. -/ def Separable {ι : Type} (b : ℕ) (f : (ι → Bool) → Bool) : Prop := ∀ (κ : Type) => h.val = g.val + 1) /-- **The paper's heavy-gate count fails.** In the proof of Theorem 2 of [DKO14], with `N = n² s` wires, a gate is heavy iff `w(G) = |in G| + |out G| ≥ n s`, and it is claimed
