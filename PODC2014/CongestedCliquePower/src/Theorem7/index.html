Algorithm (paper: Claim 6 + the one-round reconstruction algorithm of Becker et al. [2], whose `O(k log n)`-bit messages are cut into `b`-bit chunks). With `k = ⌊4 ex(n, H)/n⌋`, every node broadcasts its degree and the `𝔽₂`-sketch of its neighbourhood (`Sketch.lean`), in total `L = ⌈log₂(n+1)⌉ + 2k⌈log₂(n+1)⌉ + 1` bits, in `⌈L/b⌉` rounds (`Bcast.oneShot`). Then every node checks whether some `k`-degenerate graph has these degrees and sketches. If yes, it is the input graph (`eq_of_sketch`) and the node answers whether it is `H`-free; if not, the input graph is not `k`-degenerate, hence contains `H` by Claim 6.
