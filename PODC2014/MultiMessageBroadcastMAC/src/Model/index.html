import Mathlib /-! # BMMB composed with a standard abstract MAC layer with unreliable links Model for Ghaffari, Kantor, Lynch, Newport, *Multi-Message Broadcast with Abstract MAC Layers and Unreliable Links* (PODC 2014, arXiv:1405.1671), Section 2 and §3.2.1–3.2.2. The network is a pair of graphs `G ≤ G'` on the nodes `V` (reliable and unreliable links). We model the system "BMMB protocol + abstract MAC layer" directly, as an event-driven transition system: * A node's BMMB state is its `log` (the messages it got, in order: this is the paper's `rcvd` set, and the order in which they were appended to `bcastq`) and its number `acks` of acknowledged broadcasts. The FIFO queue `bcastq` is `log.drop acks`; its head is the message currently being broadcast (BMMB broadcasts the head immediately, with no delay, whenever it is idle). The paper's sets are `R_i = log` and `C_i = log.take acks` (the "sent" set). * `heard v` records the receive events at `v`: `(u, m) ∈ heard v` iff `v` received `u`'s broadcast of `m`. A node broadcasts each message at most once, so `(u, m)` identifies a *message instance*. * Events (`Event`): `arrive i m` (the environment injects `m` at `i`; BMMB delivers it and appends it to its queue unless it already has it), `rcv u v` (`v` receives `u`'s current broadcast; only over `G'` edges, at most once per instance: *receive correctness*), `ack u` (only after every `G`-neighbour received the instance: *acknowledgment correctness*). A disabled event is a no-op. * An execution (`Exec`) is a sequence of events `ev` with times: event `n` happens at time `T (n + 1)`, configuration `n` exists from time `T n` on, `T 0 = 0`, `T` is monotone and diverges (admissibility). The *final state at time `t`* is configuration `last t`, the last one with `T n ≤ t`. * Time bounds: `AckBound F_ack` (every broadcast is acknowledged within `F_ack` of its start) and `ProgBound F_prog` (the progress bound of §3.2.1 for the closed fragments between the final states at two times; `connect` and `contend` are the paper's sets of message instances). -/ namespace Podc.MultiMessageBroadcastMAC open Filter variable {V M : Type*} /-- Events of the composed system. -/ inductive Event (V M : Type*) /-- The environment injects message `m` at node `i` (`arrive(m)_i`). -/ | arrive (i : V) (m : M) /-- Node `v` receives the current broadcast of node `u` (`rcv(m)_v`). -/ | rcv (u v : V) /-- Node `u` receives the acknowledgment of its current broadcast (`ack(m)_u`). -/ | ack (u : V) /-- No event (time passage only). -/ | skip /-- A configuration of the composed system. -/ @[ext] structure Config (V M : Type*) where /-- The messages node `i` got, in order (`rcvd`, in `bcastq` order). -/ log : V → List M /-- The number of acknowledged broadcasts of node `i`. -/ acks : V → ℕ /-- `(u, m) ∈ heard v`: node `v` received `u`'s broadcast of `m`. -/ heard : V → Set (V × M) namespace Config variable (c : Config V M) /-- The BMMB queue `bcastq`. -/ def queue (i : V) : List M := (c.log i).drop (c.acks i) /-- The message node `i` is currently broadcasting (the head of `bcastq`). -/ def head (i : V) : Option M := (c.log i)[c.acks i]?
