import Papers.PODC2014.SignatureFreeBA.Model /-! # Safety: Lemmas 1–4 and the safety half of Theorem 2 Mostéfaoui, Moumen, Raynal, PODC 2014, Section 4.3. All statements hold in every reachable state of the asynchronous system, for every coin sequence, against an adaptive Byzantine adversary that corrupts at most `t` processes, if `3t < n`. "Correct" processes are those of a set `H` that contains every corrupted process' complement (`σ.bad ⊆ Hᶜ`, `|Hᶜ| ≤ t`); in the paper's static model `H` is the set of correct processes. * `est_just`, `aux_just`, `aux_unique`, `est_unique`: what the guards guarantee. * `lemma_2`: two processes whose `values` in round `r` are singletons have the same value. * `est_coin_of_single`: if a process decides `v` in round `r` (singleton `values = {v}` and coin `v`), every process starts round `r + 1` with estimate `v` (proof of Lemma 4). * `lemma_1`: once all correct processes start a round with estimate `v`, no correct process ever broadcasts `B_VAL[r'](¬v)` or `AUX[r'](¬v)` in a later round, so all keep `v`. * `lemma_3` (BC-Validity) and `lemma_4` (BC-Agreement); `theorem_2_safety`. -/
