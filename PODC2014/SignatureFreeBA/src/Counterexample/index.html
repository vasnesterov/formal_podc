import Papers.PODC2014.SignatureFreeBA.Embed import Papers.PODC2014.SignatureFreeBA.Liveness /-! # Counterexample to Lemma 5 (termination) and Theorem 3 Mostéfaoui, Moumen, Raynal, PODC 2014, Lemma 5 ("each non-faulty process decides with probability 1"), Theorem 2 (BC-Termination) and Theorem 3 ("the expected decision time is … four rounds"). For `n = 4`, `t = 1`, inputs `0, 0, 1` and process `3` Byzantine we give an adversary `strat : ℕ → State → Ev`. It chooses the next event from the time and the current global state only. The global state contains the coins already used by some process (through the estimates they produced), and nothing about the other coins, so the adversary cannot see future coins. This is the adversary of the paper's model: it controls the message schedule and the Byzantine process, and the coin of a round becomes known once a correct process has obtained it (Section 4.1 asks only that the Byzantine processes cannot compute coins *in advance*). `counterexample`: for **every** coin sequence the generated execution is a weakly fair execution of the algorithm in which no process ever decides. So the probability of termination is `0` for every distribution of the coins (`prob_termination_eq_zero`). The round-by-round schedule is `Local.script` (checked by `decide` in `Local.lean`); here we glue the rounds together: `gen_eq` computes the whole execution in closed form. -/ namespace Podc.SignatureFreeBA.Attack open Cslib.Byzantine.AsyncBroadcast Podc.SignatureFreeBA Podc.SignatureFreeBA.Local /-!
