import Papers.PODC2014.LinialLowerBoundEasy.LogStar /-! # 3-colouring directed cycles: Linial's bound (1) Model of §2 of [Laurinharju–Suomela]: deterministic synchronous LOCAL algorithms on the directed `n`-cycle. Nodes are `ZMod n`, with edges `v → v + 1`; the nodes carry unique identifiers from `{1, …, n}` (`IdAssignment n`). After `T` rounds a node knows exactly the identifiers of the nodes `v - T, …, v + T` (in this order: the cycle is directed), so a `T`-round algorithm is a function `A` of the window `(id (v - T), …, id (v + T))` of `2T + 1` identifiers (`IdAssignment.window`). The algorithm finds a proper 3-colouring if for every identifier assignment and every node the colour is in `{1, 2, 3}` and differs from the colour of the successor (`Is3ColouringAlgorithm`). We also give the more extensional version: an algorithm is a function `f` of the whole view `j ↦ id (v + j)` (`j : ℤ`) that depends only on the offsets `|j| ≤ T` (`IsLocal T f`). ## Main statements * `algorithm_mem`, `algorithm_ne`: §2, the algorithm satisfies `A (x₁, …, x_{2T+1}) ∈ {1, 2, 3}` and `A (x₁, …, x_{2T+1}) ≠ A (x₂, …, x_{2T+2})` whenever the `xᵢ` are distinct identifiers. * `isColouringFunction_of_algorithm`: §3, it is a `(2T+1)`-ary 3-colouring function. * `linial_bound`: equation (1), `T ≥ log*(n)/2 - 1`; `linial_bound_local` for local view functions. -/ namespace
