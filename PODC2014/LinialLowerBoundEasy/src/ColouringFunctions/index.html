A *`k`-ary `c`-colouring function* is a map `A` from `k`-tuples of identifiers to colours such that * (2) `A (x₁, …, x_k) ∈ {1, …, c}` for all `1 ≤ x₁ < ⋯ < x_k ≤ n`; * (3) `A (x₁, …, x_k) ≠ A (x₂, …, x_{k+1})` for all `1 ≤ x₁ < ⋯ < x_{k+1} ≤ n`.
