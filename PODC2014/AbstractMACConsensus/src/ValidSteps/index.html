import Podc.Computability.Distributed.AbstractMAC.Sync /-! # Valid steps on a single-hop network (Section 3.1 of Newport, PODC 2014) On the clique `⊤`, the *next valid step* of a node `u` (`validStep c u`) is: nothing if `u` is crashed or idle; otherwise the delivery of its current message to some (deterministically chosen) node that has not received it yet; otherwise its acknowledgment. The paper fixes "the smallest such node"; any deterministic choice depending only on `got u` works, we use `Classical.choose`. Unlike the paper we do not assume that nodes always broadcast: the valid step of an idle node is a no-op. * `runV c vs`: valid steps of the nodes `vs`, in order; `eventsV` the corresponding events. * `Rel w c c'`: configurations that agree except for the local data of `w` and for whether `w` is crashed. Valid steps of nodes `≠ w` preserve it (`Rel.runV`). * `stepV_comm`: valid steps of two distinct broadcasting nodes commute up to `Rel w` for one node `w` (the node both steps affect, if any) — the case analysis of Lemma 3.1. * `fair_of_blocks`: executions whose blocks are valid steps of all non-crashed nodes are fair. -/ namespace Podc.AbstractMACConsensus open Cslib.AbstractMAC Filter variable
