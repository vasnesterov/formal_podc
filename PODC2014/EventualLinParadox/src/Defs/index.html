import Mathlib /-! # Histories, weak consistency and `t`-linearizability (Section 3) Guerraoui, Ruppert. *A Paradox of Eventual Linearizability in Shared Memory.* PODC 2014. We formalize the history-level notions of Section 3 for **finite and infinite** histories. * `ObjType Q Op Res`: a sequential specification `(Q, Q₀, INV, RES, δ)` with a transition *relation* `δ q op r q'` (possibly nondeterministic, possibly partial). `Deterministic`, `FiniteNondet`, `Total`. * `History P X Op Res := ℕ → Option (Ev P X Op Res)`: a *timed* history. Position `i` carries at most one event: an invocation `inv p x op` (process `p` invokes `op` on object `x`) or a response `res a r`, where `a` is the position of the matching invocation. **An operation is identified by the position of its invocation.** Positions without an event (`none`) are allowed; a gap-free history is literally the paper's sequence of events, and the paper's "first `t` events" are then the positions `< t`. Gaps make positions invariant under taking prefixes (`take`) and restricting to an object (`restrict`), and let an execution produce its history step by step (one position per step). * `SeqHist Res := ℕ → Option (ℕ × Res)`: a (finite or infinite) sequential history, an entry `(a, r)` meaning "operation `a` with response `r`", again with gaps allowed (only the order of the entries matters). `Legal spec H S`: every entry is an operation invoked in `H`, and for every object `x` there is a sequence of states `q₀ ∈ Q₀, q₁, …` following `δ` along the entries on `x`. * `WeaklyConsistent` (Definition 1), `IsTLin`/`TLinearizable` (Definition 2), `EventuallyLinearizable` (Definition 3), `Linearizable` (`0`-linearizable). -/ namespace Podc.EventualLinParadox /-- A sequential specification `(Q, Q₀, INV, RES, δ)` (Section 3). -/ structure ObjType (Q Op Res : Type) where /-- The possible initial states `Q₀`. -/ init : Set Q /-- The transition relation: `δ q op r q'`. -/ δ : Q → Op → Res → Q → Prop namespace ObjType variable {Q Op Res : Type} (T : ObjType Q Op Res) /-- For every state and operation there is a unique response and new state. -/ def Deterministic : Prop := ∀ q op, ∃! rq : Res × Q, T.δ q op rq.1 rq.2 /-- For every state and operation there are finitely many responses and new states. -/ def FiniteNondet : Prop := ∀ q op, {rq : Res × Q | T.δ q op rq.1 rq.2}.Finite /-- Every operation can be applied in every state. -/ def Total : Prop := ∀ q op, ∃ r q', T.δ q op r q' /-- The type initialized to the state `q₀` (an object of type `T` initialized to `q₀`). -/ def initAt (q₀ : Q) : ObjType Q Op Res := { T with init := {q₀} } lemma Deterministic.total {T : ObjType Q Op Res} (h : T.Deterministic) : T.Total := fun q op => let ⟨rq, hrq, _⟩ := h q op; ⟨rq.1, rq.2, hrq⟩ end (op : Op) | res (a : ℕ) (r : Res) /-- A (finite or infinite) timed history. -/ abbrev History (P X Op Res : Type) := ℕ → Option (Ev P X Op Res) /-- A (finite or infinite) sequential history: entries (q k) (q (k + 1)) /-- **Definition 1** (weak consistency). For each operation `a` with a response `r` (at position `j`) there is a legal sequential history that contains only operations invoked before `a` terminates, contains all operations of `a`'s process that precede `a`, and ends with `a` with response `r`. -/ def WeaklyConsistent (spec : X → ObjType Q Op Res) (H : History P X Op Res) : Prop := ∀ a j r, H j = some (.res a r) → ∃ S : SeqHist Res, S.Nodup ∧ Legal spec H S ∧ (∀ b, S.Mem b → b < j) ∧ (∀ b, SameProc H b a → Precedes H b a → S.Mem b) ∧ (∃ k, S k = some (a, r) ∧ ∀ k', k < k' → S k' = none) /-- **Definition 2** (`t`-linearization). `H'` is the part of `H` at positions `≥ t`. -/ structure IsTLin (spec : X → ObjType Q Op Res) (H : History P X Op Res) (t : ℕ) (S : SeqHist Res) : Prop where nodup : S.Nodup /-- `S` is legal (in particular each operation of `S` is invoked in `H`). -/ legal : Legal spec H S /-- Each operation completed in `H` is in `S`. -/ complete : ∀ a j r, H j = some (.res a r) → S.Mem a /-- Real-time order of `H'` is respected (for operations of `S`). -/ rt : ∀ a b j r, H j = some (.res a r) → t ≤ j → j < b → Invoked H b → S.Mem b → S.Before a b /-- Operations with a response in `H'` have the same response in `S`. -/ resp : ∀ a j r, H j = some (.res a r) → t ≤ j → ∃ k, S k = some (a, r) /-- `H` is `t`-linearizable. -/ def TLinearizable (spec : X → ObjType Q Op Res) (H : History P X Op Res) (t : ℕ) : Prop := ∃ S, IsTLin spec H t S /-- `H` is linearizable (`0`-linearizable, [Herlihy–Wing]). -/ def Linearizable (spec : X → ObjType Q Op Res) (H : History P X Op Res) : Prop := TLinearizable spec H 0 /-- **Definition 3** (eventual linearizability of a history). -/ def EventuallyLinearizable (spec : X → ObjType Q Op Res) (H : History P X Op Res) : Prop := WeaklyConsistent spec H ∧ ∃ t, TLinearizable spec H t /-- The **fetch&increment** type (Section 3.2): the state is a natural number, initially `0`; the single operation `fetch&inc` adds one and returns the old value. -/ def fai : ObjType ℕ Unit ℕ where init := {0} δ q _ r q' := r = q ∧ q' = q + 1 lemma fai_deterministic : fai.Deterministic := fun q _ => ⟨(q, q + 1), ⟨rfl, rfl⟩, fun ⟨r, q'⟩ ⟨h1, h2⟩ => by simp_all⟩ end Podc.EventualLinParadox
