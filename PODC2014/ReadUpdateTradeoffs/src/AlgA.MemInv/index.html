It contains * **Lemma 8** (every node value is non-decreasing), via the state invariant "an internal node holds at most the maximum of its children" (`MInv.nodeMax`) and the per-process facts `old ≤ max(left, right)` (`PInv`); `Frame.mono` is the monotonicity of a step; * the **double-refresh argument** behind Lemmas 9 and 11 (`Iter`, `Cond`): after a process has completed both refreshes of a node `n` whose child `c` on its path holds a value `≥ v`, the node holds a value `≥ v`. Hence a `WriteMax(v)` returns only when the root holds a value `≥ v` (`PInv` of `wDone`); * the facts used for linearizability: every node value is `0`, at most the root, or the operand of a `WriteMax` in progress (`Good`, `MInv.good`). `Cond C n c v` says: every process that is refreshing node `n` and whose `old` still equals the current value of `n` will compute a new value `≥ v` (it has read, or will read, the child `c` after `c` reached `v`).
