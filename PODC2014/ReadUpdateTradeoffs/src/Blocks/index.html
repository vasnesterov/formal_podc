import Podc.Computability.Distributed.SharedMemory.Awareness /-! # Write blocks of essential processes For the max-register lower bound (Section 4 of Hendler–Khait, PODC'14) we track, for every base object, the *block* of its history: the maximal top segment of value-setting entries written by *essential* processes (a set `E`). The invariant `BlockOK E h` says that the block of the history `h` was written by a single process (its *owner*). Then erasing any set of essential processes either leaves the top entry of `h` in place or uncovers the first entry written by a non-essential process — this is what the paper's proof of Lemma 4 implicitly assumes ("o's familiarity set may only be extended by …") and what fails without the invariant (erasing the last writer of an object *resurrects* older writes). -/ namespace Podc.ReadUpdateTradeoffs open Cslib.SharedMemory Cslib.SharedMemory.Awareness variable {P V : Type} [DecidableEq P] /-- The block of `h` w.r.t. `E`: the maximal top segment of entries written by `E`. -/ def block (E : Finset P) (h : List (Entry P V)) : List (Entry P V) := h.takeWhile (fun e => decide (e.proc ∈ E)) /-- All entries of the block of `h` w.r.t. `E` are written by one process. -/ def BlockOK (E : Finset P) (h : List (Entry P V)) : Prop := ∀ x ∈ block E h, ∀ y ∈ block E h, x.proc = y.proc @[simp] lemma block_nil (E : Finset P) : block E ([] : List (Entry P V)) = [] := rfl lemma block_cons_of_mem {E : Finset P} {y : Entry P V} {h : List (Entry P V)} (hy : y.proc ∈ E) : block E (y :: h) = y :: block E h := by simp [block, List.takeWhile_cons, hy] lemma block_cons_of_not_mem {E : Finset P} {y : Entry P V} {h : List (Entry P V)} (hy : y.proc ∉ E) : block E (y :: h) = [] := by simp [block, List.takeWhile_cons, hy] lemma mem_block {E : Finset P} {h : List (Entry P V)} {x : Entry P V} (hx : x ∈ block E h) : x ∈ h ∧ x.proc ∈ E := by induction h with | nil => simp at hx | cons y h ih => by_cases hy : y.proc ∈ E · rw [block_cons_of_mem hy] at hx rcases List.mem_cons.1 hx with rfl | hx · exact ⟨List.mem_cons_self, hy⟩ · exact ⟨List.mem_cons_of_mem _ (ih hx).1, (ih hx).2⟩ · rw [block_cons_of_not_mem hy] at hx;
