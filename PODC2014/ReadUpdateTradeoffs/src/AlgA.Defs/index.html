import Mathlib import Cslib.Computability.Distributed.SharedMemory.LinPoints import Cslib.Computability.Distributed.SharedMemory.Potential import Cslib.Computability.Distributed.SharedMemory.Objects.MaxRegister /-! # Algorithm A of Hendler–Khait (PODC 2014, Section 5): the model Algorithm A is a wait-free `N`-process max register from read/write/CAS base objects: ``` 1: function Read 2: return T.root.value 3: procedure Propagate(n) 4: while n.parent ≠ nil do 5: n ← n.parent -- paper: `n ← node.parent` (typo) 6: for i = 1 to 2 do 7: old_value ← n.value 8: new_value ← max(n.left_child.value, n.right_child.value) 9: CAS(n.value, old_value, new_value) 10: procedure Write_i(value) 11: if value < N then 12: L ← T_L.leaves[value] 13: else 14: L ← T_R.leaves[i] 15: old_value ← L.value 16: if value ≤ old_value then return 17: L.value ← value 18: Propagate(L) ``` ## Model CSLib's asynchronous shared-memory model (`Cslib.SharedMemory.Impl`): `N` deterministic processes `Fin N`, atomic base objects, executions as label lists, an arbitrary (adversarial) interleaving, no failures other than processes stopping to take steps (which wait-freedom covers). The high-level object is CSLib's `maxRegObj` (a max register over `ℕ`, initially `0`). * **Values.** The paper's node values are integers initialised to `−∞` and the operands are naturals. We use `ℕ` with initial value `0`; since `maxRegObj` also starts at `0`, a `WriteMax(0)` is a no-op in the specification and `0` plays the role of `−∞`. * **Tree.** The nodes are heap-indexed natural numbers: the root is `1`, the children of `n` are `2n` and `2n+1`, the parent of `n` is `n / 2`. Every natural number is a base object (a CAS object over `ℕ`, initially `0`); nodes outside the tree are never written and read as `0`, which is harmless for a max. The positions of the leaves are a parameter `Layout N` (`leaf (.inl v)` = the leaf of `T_L` for the value `v < N`, `leaf (.inr i)` = the leaf of `T_R` of process `i`); linearizability and wait-freedom hold for every layout in which the leaves are distinct positions `≥ 2` none of which is a proper ancestor of another. A concrete layout with `T_L` a `B₁`-like tree (leaf `v` at depth `2⌊log₂(v+1)⌋ + 2`) and `T_R` a complete tree is in `AlgA/Layout.lean`. * **`T_L` has `N` leaves** (one for every `v < N`); the paper says `N − 1` leaves but indexes them by all `v < N`. * Each line of the pseudo-code that accesses shared memory is one atomic step; line 8 is two reads (left child, then right child).
