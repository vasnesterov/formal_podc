import Cslib.Computability.Distributed.SharedMemory.History /-! # Histories obtained by projecting event lists A list of events `α : List E` of any type, together with a partial labelling `f : E → Option (Label P A)`, induces the CSLib history `α.filterMap f`. This file characterizes CSLib's notions on such a history (`Invoked`, `Completed`, `opOf`, `respOf`, `Precedes`) in terms of *positions* in `α`: `IsInv f α x e` says that event `e` of `α` is the invocation of the instance `x`, `IsRet f α x r` that event `r` is its response. Real-time order then becomes a comparison of positions (`precedes_of_lt`, `lt_of_precedes`). -- CSLib candidate: Cslib/Computability/Distributed/SharedMemory/Projection.lean -/ namespace
