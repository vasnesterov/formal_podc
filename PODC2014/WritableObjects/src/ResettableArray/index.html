The type `(k,b)`-Array (`kbArray k V v₀`) stores an array `S` of `k` entries with values in `V` (the `b`-bit values), all initially `⊥ = v₀`; `Read(i)` returns `S[i]`, `Write(i,x)` sets `S[i] := x`, `Reset()` sets every entry back to `v₀`. Implementation of Figure 4.15 (`resettableArray`), for any set of processes: a register `Ver : Fin k` (initially `0`) and registers `A[i] : V × Option (Fin k)` (initially `(⊥,⊥)`, the second `⊥` being `none`): * `SReset()`: `v := (Ver.Read() + 1) mod k; Ver.Write(v); A[v].Write(⊥,⊥)` * `Read(i)`: `(x,v) := A[i].Read(); ver := Ver.Read(); if v ≠ ver then x := ⊥; return x` * `Write(i,x)`: `ver := Ver.Read(); A[i].Write(x, ver)` Lemma 4.2: every execution in which no `Reset` instance overlaps any other instance (`ResetsIsolated`) is linearizable (`lemma_4_2`). The implementation uses `k + 1` base registers (`card_baseObjects`) and every operation performs at most 3 base-object accesses (`stepBound_invoke`, `stepBound_access`). ## Proof Linearization points: a `Read` at its read of `A[i]` (line 59), a `Write` at its write of `A[i]` (line 64), a `Reset` at its write of `A[v]` (line 58). The invariant (`Inv`) says that, except between lines 57 and 58 of a reset, the abstract state is decoded from the memory (`S[i] = x` if `A[i] = (x, some Ver)` and `⊥` otherwise) and the *wrap-around invariant* `WrapOK` holds: if `A[i]` carries version `v`, then `Ver` has advanced from `v` fewer times than it takes to reach index `i` (`(Ver - v) < (i - v)` in `Fin k`) unless `i = v`.
