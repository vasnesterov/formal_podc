import Papers.PODC2014.WritableObjects.Algorithm import Mathlib.Tactic.FinCases /-! # Lemma 4.8, part 1: the local queues of `recycle()` (Claims 4.9–4.13, 4.15) Invariants of the local queue system `QS` of a process `p` (`QOK`): all queues have length `2n+2` (Claim 4.11), `c_p[i]` is the number of occurrences of `i` in the queues (Claim 4.12), and only indices owned by `p` occur in the queues and in `free_p` (Claim 4.9). The *hold* of an index (`Hold`) replaces the interval reasoning of Claims 4.15–4.17: number the `updateQ` calls of `p` by *update times* `4r + o` (the update of queue `o` in the `r`-th `recycle()`); an occurrence at position `j` of queue `o`, when `U o` updates of that queue have been done, is dequeued at time `4 (U o + j) + o`. `Hold s U i γ` says that some occurrence of `i` is dequeued at time `≥ γ`; then `i` is not added to `free_p` by updates at times `< γ`. -/ namespace Podc.WritableObjects.WF variable {n : ℕ} /-- `x` if `p` owns it, else `⊥` (the value enqueued by `updateQ_p(·, x)`). -/ def ownF (p : Fin n) : Option (Idx n) → Option (Idx n) | some y => if y.1 = p then some y else none | none => none lemma enq_q (p : Fin n) (o : Fin 4) (x : Option (Idx n)) (s : QS n) : (enq p o x s).q = Function.update s.q o (s.q o ++ [ownF p x]) := by unfold enq ownF;
