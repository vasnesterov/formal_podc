import Papers.PODC2014.WritableObjects.Calls /-! # Timestamps order the operations on each base object The core of the proof of Lemma 4.5: on each base object `A[i]`, an operation whose call has a smaller timestamp key returns before any operation with a larger key is invoked (`ret_before_of_keyPos_lt`). Here the template's requirement that `A[f]` is not in use when `A[f].SWrite` is invoked is essential (see `Counterexample.lean`). -/ set_option linter.unusedSectionVars false namespace Podc.WritableObjects open Cslib.SharedMemory variable {P ι : Type} {T : ObjSpec} {W : Writable T} {owner : ι → P} {α : List (Ev P ι T)} {σ : P → ℕ → PSt ι T} [DecidableEq P] [DecidableEq ι] /-- The template requirement "`A[f]` is not in use when `A[f].SWrite` is invoked". -/ def NotInUse (α : List (Ev P ι T)) : Prop := ∀ t p f v, α[t]? = some (.swinv p f v) → ptrAt α t ≠ some f namespace IsCtrl variable (h : IsCtrl W owner α σ) (hC : CondC α) include h /-- The `SWrite` heading the group of an `Exec`: the `SWrite` of the `Write` whose write to `Ptr` is the last one before the chosen point `t*` (the paper's `W` in Claim 4.7, (4.4)). -/ lemma head_of_opinv (hC : CondC α) {t : ℕ} {q : P} {i : ι} {o : T.Op} (ht : α[t]?
