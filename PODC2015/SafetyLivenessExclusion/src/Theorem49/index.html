import Papers.PODC2015.SafetyLivenessExclusion.Lemmas /-! # Theorem 4.9 for reactive implementations (repaired proof) **Theorem 4.9** of Bushkov–Guerraoui (PODC 2015): if there is a strongest liveness property that does not exclude `S`, it is `Lmax`. We prove it for every class `𝓒` of *reactive* valid implementations (processes take steps only while executing an operation) that contains the two trivial implementations of the paper's proof: the silent implementation `I_t` (`silent`) and the one-shot responders `I_b` (`responder`). By `Setting.isStrongestNonExcl_iff` it suffices to show that every history that is fair for all implementations ensuring `S` lies in `Lmax` (`core_subset_Lmax`). The argument follows the paper: 1. `I_t` ensures `S` (all its histories are input-only, hence histories of any implementation), so a core history `h` has no response; it is finite and every process is pending or crashed at its end. 2. If every process crashed, `h` has no well-formed extension, so the assumption on `Lmax` puts `h` into `Lmax`. (The paper's proof misses this case.) 3. Otherwise some correct process `l₀` is pending on `inv l₀ x₀`. *Repair:* take a response `r₀` with `inv l₀ x₀ · res l₀ r₀ ∈ S` (the paper's assumption) and an implementation `I'` ensuring `S` with this history. The responder `I_b` (answers `r₀` to `l₀`'s first invocation `x₀`, nothing else) ensures `S`, because each of its histories is a history of `I'`: the other processes' invocations and crashes commute with `l₀`'s run in `I'` (frame lemma), *since reactive processes do not step while idle*. But `h` is not fair for `I_b`. The paper instead derives `inv_l · res_l ∈ S` from `h · res_l ∈ S`, which is unjustified (for consensus, `propose₂(1) · propose₁(0) · decide₁(1)` satisfies agreement and validity while `propose₁(0) ·
