import Mathlib /-! # `(l, k)`-freedom (Section 5) Definition 5.1 of Bushkov–Guerraoui (PODC 2015) only depends, for a fair execution, on three sets of processes: the correct ones, those taking infinitely many steps, and those making progress (infinitely many "good" responses). We call this triple a `Summary`; it satisfies `prog ⊆ inf ⊆ correct`. The order on `(l, k)`-freedom properties is implication on summaries (set inclusion of the execution sets). * `LKFree l k`: Definition 5.1. * `theorem_5_2`, `theorem_5_3`: the strongest non-excluded and weakest excluded `(l,k)`-freedom properties, for any safety property for which the cited (im)possibilities hold — consensus from registers ((1,1) implementable [20, 17], (1,2) excluded [5]) and TM with opacity ((1,n) implementable [9], (2,2) excluded [4]). The cited results are hypotheses. * `section_5_3`: if `(2,2)` and `(1,3)` exclude `S` but `(1,2)` does not (the paper's §5.3 property; Lemma 5.4 is the implementability of `(1,2)`), there is no weakest excluded `(l,k)`-freedom property. * `incomparable_1_3_2_2`: the example of §5.1. * `lf_union_of_not_iff`: the remark "`LF_l ∪ OF_k` is the set of executions ensuring `(l,k)`-freedom" is false (only `⊆` holds, `lkFree_imp_lf_or_of`). -/ namespace Podc.SafetyLivenessExclusion.LK /-- What Definition 5.1 sees of a fair execution: the correct processes, the processes taking infinitely many steps, and the processes making progress. -/ structure Summary (n : ℕ) where /-- Correct (non-crashed) processes. -/ correct : Finset (Fin n) /-- Processes taking infinitely many steps. -/ inf : Finset (Fin n) /-- Processes making progress. -/ prog : Finset (Fin n) inf_sub : inf ⊆ correct prog_sub : prog ⊆ inf variable {n : ℕ} /-- **Definition 5.1.** A fair execution ensures `(l, k)`-freedom if, whenever at most `k` processes take infinitely many steps, at least `l` processes make progress if at least `l` are correct, and all correct processes make progress otherwise. -/ def LKFree (l k : ℕ) (s : Summary n) : Prop := s.inf.card ≤ k → (l ≤ s.correct.card → l ≤ s.prog.card) ∧ (s.correct.card < l → s.correct ⊆ s.prog) /-- The admissible parameters: `1 ≤ l ≤ k ≤ n`. -/ def Adm (n l k : ℕ) : Prop := 1 ≤ l ∧ l ≤ k ∧ k ≤ n /-- `(l, k)`-freedom is stronger than `(l', k')`-freedom. -/ def Stronger (n l k l' k' : ℕ) : Prop := ∀ s : Summary n, LKFree l k s → LKFree l' k' s /-! ## Exclusion -/ variable {ι : Type*} (ens : ι → Prop) (sums : ι → Set (Summary n)) /-- `(l, k)`-freedom excludes the safety property: no implementation ensuring it (`ens`) has all its fair executions (`sums`) `(l,k)`-free. -/ def Excl (l k : ℕ) : Prop := ¬ ∃ I, ens I ∧ ∀ s ∈ sums I, LKFree l k s /-- Strongest `(l,k)`-freedom property that does not exclude the safety property. -/ def IsStrongestNonExcl (l k : ℕ) : Prop := Adm n l k ∧ ¬ Excl ens sums l k ∧ ∀ l' k', Adm n l' k' → ¬ Excl ens sums l' k' → Stronger n l k l' k' /-- Weakest `(l,k)`-freedom property that excludes the safety property. -/ def IsWeakestExcl (l k : ℕ) : Prop := Adm n l k ∧ Excl ens sums l k ∧ ∀ l' k', Adm n l' k' → Excl ens sums l' k' → Stronger n l' k' l k variable {ens sums} theorem Excl.mono {l k l' k' : ℕ} (h : Stronger n l k l' k') (hex : Excl ens sums l' k') : Excl ens sums l k := by rintro ⟨I, hI, hs⟩ exact hex ⟨I, hI, fun s hs' => h s (hs s hs')⟩ theorem stronger_refl (l k : ℕ) : Stronger n l k l k := fun _ h => h /-! ## The order -/ /-- `l`-lock-freedom (as a condition on a summary). -/ def LF (l : ℕ) (s : Summary n) : Prop := (l ≤ s.correct.card → l ≤ s.prog.card) ∧ (s.correct.card < l → s.correct ⊆ s.prog) theorem lf_mono {l l' : ℕ} (h : l' ≤ l) (s : Summary n) (hs : LF l s) : LF l' s := by obtain ⟨h1, h2⟩ := hs constructor · intro hl' by_cases hl : l ≤ s.correct.card · exact le_trans h (h1 hl) · exact le_trans hl' (Finset.card_le_card (h2 (by omega))) · intro hl' by_cases hl : l ≤ s.correct.card · omega · exact h2 (by omega) /-- `(l,k)`-freedom is stronger than `(l',k')`-freedom when `l' ≤ l` and `k' ≤ k`. -/ theorem stronger_of_le {l k l' k' : ℕ} (hl : l' ≤ l) (hk : k' ≤ k) : Stronger n l k l' k' := fun s hs hinf => lf_mono hl s (hs (le_trans hinf hk)) /-- `(1, n)`-freedom (lock-freedom) is stronger than every `(1, k)`-freedom. -/ theorem stronger_one_n (k : ℕ) : Stronger n 1 n 1 k := by intro s hs _ exact hs (le_trans (Finset.card_le_univ _) (by simp)) /-! omega) /-! ## Section 5.3 and the examples -/ section Witnesses variable (hn : 3 ≤ n) include hn /-- Three distinct processes. -/ def pa : Fin n := ⟨0, by omega⟩ /-- Three distinct processes. -/ def pb : Fin n := ⟨1, by omega⟩ /-- Three distinct processes. -/ def pc : Fin n := ⟨2, by omega⟩ /-- Two processes take steps, only one makes progress. -/ def s₁ : Summary n where correct := {pa hn, pb hn} inf := {pa hn, pb hn} prog := {pa hn} inf_sub := le_rfl prog_sub := by simp /-- Three processes take steps, none makes progress. -/ def s₂ : Summary n where correct := {pa hn, pb hn, pc hn} inf := {pa hn, pb hn, pc hn} prog := ∅ inf_sub := le_rfl prog_sub := by simp theorem card_s₁ : (s₁ hn).correct.card = 2 ∧ (s₁ hn).inf.card = 2 ∧ (s₁ hn).prog.card = 1 := by simp [s₁, pa, pb, Fin.ext_iff] theorem card_s₂ : (s₂ hn).correct.card = 3 ∧ (s₂ hn).inf.card = 3 ∧ (s₂ hn).prog.card = 0 := by have : ({pa hn, pb hn, pc hn} : Finset (Fin n)).card = 3 := by rw [Finset.card_insert_of_notMem, Finset.card_pair] <;> simp [pa, pb, pc, Fin.ext_iff] simp [s₂, this] theorem s₁_mem_1_3 : LKFree 1 3 (s₁ hn) := by obtain ⟨h1, h2, h3⟩ := card_s₁ hn intro _;
