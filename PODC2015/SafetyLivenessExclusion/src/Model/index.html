import Mathlib import Papers.PODC2015.SafetyLivenessExclusion.Abstract /-! # The shared-memory model of Section 2 (I/O automata with crashes) Model of Bushkov–Guerraoui, PODC 2015, §2–3. * `n` asynchronous processes `Fin n`; an object type is given by its invocations `Inv` and responses `Res` (the sequential specification plays no role in §3–4). * External actions `Ext`: `inv i x`, `res i r`, `crash i` (the paper's `ext(Tp)`). * Histories `Hist`: finite or infinite sequences of external actions. `U` is the set of *well-formed* histories: per process, invocations and responses alternate starting with an invocation, and nothing follows a crash. * An implementation `Impl` is the composition `A_{I_1} × … × A_{I_n} × A_B` of the paper: a local state per process (or `none` once crashed — the special state `s_crashed,i`), a state of the base objects, and transitions - `inv i x`, `res i r`: input/output actions of `A_{I_i}`, touching only the local state of `i`; - `crash i`: always enabled unless `i` crashed, leads to the crashed state; - `step i`: an internal action of process `i` (local computation or an access to the base objects, i.e. a hidden action shared by `A_{I_i}` and `A_B`); - `base`: an internal action of `A_B` alone. * Fair executions (§3.2): a finite execution is fair if no action other than a crash is enabled at its end; an infinite one is fair if every process either takes infinitely many actions or is infinitely often in a state where no action of it other than its crash is enabled. * `fairH I`: histories of fair executions (`fair(A_I)`); `EnsuresS I S`: every finite history of `I` is in `S`. * `Impl.Valid`: the paper's standing requirements — some initial state exists, every history is well-formed, and the implementation is input-enabled (an invocation by a process that is not pending is always enabled). * `Impl.Reactive`: processes take steps only while executing an operation (no step of a process that is not pending).
