import Papers.PODC2015.AlmostStableMatchings.Main /-! # A run in which a man becomes bad while inactive The proof of Lemma 4.4 in the paper charges every man who is bad at the end of `ASM` to the iteration `i` in which he became bad, and bounds those men with Lemma 4.5 applied to the active men of iteration `i`. But a man can become bad while he is *inactive*: he is matched when he leaves the active set and is later displaced by an active man. Lemma 4.5 says nothing about such men. (Lemma 4.4 itself is true; see `BadMen.lean`.) Instance (`P5`): 5 men, 5 women, 16 edges; `k = 2` quantiles, `ℓ = 1`, iterations `0, 1, 2`, and the greedy maximal matching (edges scanned in lexicographic order). In iteration 1 man 3 displaces man 0, who ends iteration 1 unmatched with `|Q| = 4`. In iteration 2 only man 0 is active; he proposes to woman 3 and displaces man 2, who is inactive (`|Q| = 3 < 4`) and remains unmatched with `Q = {1, 2}` forever. So man 2 is bad at the end, although he was matched when he left the active set and was never active again (`bad_while_inactive`). -/ namespace Papers.PODC2015.AlmostStableMatchings.Example open Prefs /-- The preferences of the example (lists favourite first). -/ def P5 : Prefs (Fin 5) (Fin 5) where man := ![[0, 3, 4, 1, 2], [2, 4, 1, 0], [3, 1, 2], [2, 3, 4, 0], []] woman := ![[3, 0, 1], [2, 0, 1], [2, 0, 1, 3], [0, 2, 3], [0, 3, 1]] nodup_man := by decide nodup_woman := by decide mem_iff := by decide /-- Greedy maximal matching: scan the edges in lexicographic order. -/ def greedyList (G : Fin 5 → Fin 5 → Bool) : List (Fin 5 × Fin 5) := ((List.finRange 5).flatMap fun m => (List.finRange 5).map fun w => (m, w)).foldl (fun acc e => if G e.1 e.2 && acc.all (fun e' => e'.1 != e.1 && e'.2 != e.2) then acc ++ [e] else acc) [] /-- The greedy matching in partner form. -/ def greedy (G : Fin 5 → Fin 5 → Bool) : BMatching (Fin 5) (Fin 5) := ⟨fun m => ((greedyList G).find?
