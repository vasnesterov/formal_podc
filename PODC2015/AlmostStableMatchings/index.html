Fast Distributed Almost Stable Matchings — PODC 2015

Rafail Ostrovsky, Will Rosenbaum. Fast Distributed Almost Stable Matchings. PODC 2015. DOI 10.1145/2767386.2767424. Formalized version: arXiv 1408.2782 v2; numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. Theorem 4.1 is true with the paper's constants: for every maximal-matching subroutine, the deterministic algorithm ASM outputs a matching with at most ε|E| blocking pairs, and all lemmas of §§3–4 hold. But the proof of Lemma 4.4, on which Theorem 4.1 rests, has a real gap: it overlooks men who become bad while inactive, and we closed it with a different charging argument that gives the same bound. Theorem 4.7 (O(ε⁻³ log⁵ n) rounds given an O(log⁴ n)-round subroutine) is also true, as an explicit round count (no CONGEST message semantics); the randomized variants were not checked.

Mistakes in the paper

✏️ Slips

  • Display (1) in Lemma 4.3 has the rank differences reversed (it should be P^m(p(m)) − P^m(w) < 2deg(m)/k).

  • Algorithm 3 has every processor test |Q| ≥ 2^i. Only the men can be meant, as §3.4 and §4.2 say: women and inactive men must still react to proposals and rejections.

  • Theorem 2.7 states log⁴ n rounds, while [6] gives O(log⁴ n), the form used in the proof of Theorem 4.7.

Typos

  • The proof of Lemma 4.2 ends with "ε-blocking" for "(2/k)-blocking".

  • In §3.1 the men's quantiles are described as sets of "men".

  • P^v(∅) = deg v + 1 in Definition 2.3 is introduced only inside the proof of Lemma 4.3.

Proof gaps in true statements (2)Lemma 4.4, proof · Lemma 4.5, proof

🛠️ Lemma 4.4, proof (men who become bad while inactive)

The proof bounds the men who end bad with Lemma 4.5, which counts only men active in the iteration, but a man can be displaced and become bad while inactive (Example.bad_while_inactive).

Impact. Statement true, with the paper's bound 4δ|E|; repaired by a different charging argument (sum_bad_card_le, lemma_4_4). Theorem 4.1 is unaffected.

Details

The proof charges each man who is bad at the end to the set B_i of men that became bad in outer iteration i with |Q^m| < 2^i. But a man can be matched when he leaves the active set and be displaced later. An active man proposes to his partner, she accepts the better proposal and rejects him. He then never proposes again and stays bad with a nonempty list. The application of Lemma 4.5 does not cover such men. The construction of the sets H_i and inequality (2) are not justified either.

Concrete run (5 men, 5 women, k = 2, ℓ = 1, iterations 0–2, greedy maximal matching):

  1. In iteration 1, man 3 displaces man 0, who ends the iteration unmatched with |Q| = 4.

  2. In iteration 2 only man 0 is active. He proposes to woman 3 and displaces man 2, who is inactive (|Q| = 3).

  3. Man 2 ends bad without ever having been bad while active.

We found no such run with the paper's parameters (ℓ = 16k/ε) by random search. Those parameters make bad active men rare, but the argument does not rule such runs out.

Repair

The number of unmatched men never increases. Hence the inactive men displaced in iteration j are at most the bad active men at the start of iteration j, i.e. at the end of iteration j − 1, and each has |Q| < 2^j. A per-man potential (2^j if matched, |Q^m| if not) shows that inactive men gain nothing else. This gives ∑_{m bad} |Q^m| ≤ ∑_i 2^{i+1} b_i, where b_i is the number of bad active men at the end of iteration i. With Lemma 4.5 this yields Lemma 4.4's bound 4δ|E| for every δ > 0 (the paper needs δ ≤ 1/2). (sum_bad_card_le, lemma_4_4)

🔧 Lemma 4.5, proof (monotonicity of good active men)

"The number of matched players can only increase, hence the number of good players can only increase" is applied to the active men, although individual active men can lose their partners.

Impact. Statement true; a small missing step (card_bad_act_le, lemma_4_5).

Repair

The count needs two facts: inactive men are never newly matched, and the number of matched men equals the number of matched women, which is monotone. (card_bad_act_le, lemma_4_5)

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous, deterministic, no failures. Men M and women W are arbitrary finite types with symmetric incomplete preference lists. The communication graph is the set E of mutually acceptable pairs.

  • The state is updated once per ProposalRound, through local rules. A man stores Q, p and A; a woman stores her partner. Each node's update depends only on its own state, one-bit PROPOSE/ACCEPT/REJECT messages from its neighbours, and its own partner in M₀. There is no formal CONGEST message-passing semantics.

  • MaximalMatching (Theorem 2.7) is a black box MMOracle: any function returning a maximal matching of every bipartite graph, with a round count. All results hold for every oracle, so for every deterministic subroutine.

  • The parameters are the paper's: k = ⌈8/ε⌉, ℓ = ⌈2k/δ⌉ with δ = ε/8, and outer iterations 0, …, ⌊log₂ n⌋, where n bounds the degrees. A general version holds for any k, ℓ, L. The paper does not give the rounding of the quantile sizes deg v / k; we use ⌈k · rank / deg⌉.

  • Theorem 4.7 is proved for an explicit round count: ASM is run with a round counter that charges 3 one-bit rounds per ProposalRound plus the subroutine's T rounds (local steps are free). The counter ends at (L+1) · ℓ · k · (3 + T) (stageC_asm), which is O(ε⁻³ log⁵ n) for T = O(log⁴ n). This is a cost accounting, not a CONGEST execution: message sizes and the subroutine's implementation are not modelled.
