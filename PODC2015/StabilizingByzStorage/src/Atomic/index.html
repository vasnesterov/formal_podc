import Papers.PODC2015.StabilizingByzStorage.Server /-! # Fig. 3: the practically stabilizing SWSR atomic register The writer, the reader and `n` servers, `B` the set of Byzantine servers (`#B ≤ t`). Sequence numbers live in `Fin m` (the paper: `m = 2^64 + 1`) and are compared with the clockwise-distance order `>cd`. The state of every process and every link is arbitrary at time `0` (transient failures end at `τ_no_tr = 0`); the step relation `Step` is the interleaving of: * server steps (deliver the head of one link, lines 19–23); Byzantine servers' states are irrelevant; * writer steps (`prac_at_write`, lines N1, 01M–06); * reader steps (`prac_at_read`, lines N2–N7, 07–18). A client step that waits for `n - t` acknowledgments picks a set `Q` of `n - t` servers; correct members contribute their recorded reply, Byzantine members arbitrary replies (`acks`/`reps` are arbitrary on `B`). When several values pass a `2t + 1` threshold (lines N4, 12, 14) the pseudo-code does not say which one is taken ("let `v` be this value"): any of them may be chosen. -/ namespace
