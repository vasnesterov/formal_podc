The state also carries **ghost** variables, which no guard of the algorithm reads; they only record the history needed to state and prove regularity: * `vals`: the values of the writes invoked so far (in order), `nDone`: how many of them completed; * `base`: the value of `nDone` when the current read was invoked (writes `0, …, base - 1` completed before it, `base - 1` is the last one); * per
