import Papers.PODC2015.DeterministicLoadBalancing.Model /-! # Theorem 4.1: round-fair balancers can have discrepancy `Ω(d · diam)` Berenbrink, Klasing, Kosowski, Mallmann-Trenn, Uznański, PODC 2015 (arXiv:1404.4344v4), Theorem 4.1 and its proof in Appendix C.1. The construction: fix `u, w` at distance `diam G`, let `b v = dist(u, v)`, let every node `v` send `min(b v, b y)` tokens to each neighbour `y` and `b v − 1` tokens over each self-loop. This flow is symmetric, so the loads `x* v` are a fixed point; it is round-fair, and `x* u = 0` while `x* w ≥ d⁺ (diam − 1)`. The paper's construction yields discrepancy `0` when `diam = 1` and `d = 1` (the graph `K₂`): we treat this case separately (one token in the system never becomes balanced on two nodes). We also provide a default round-fair (and fully self-preferring) rule `fairRule`, used for the loads that never occur in the constructed execution. -/ open Finset namespace
