import Papers.PODC2015.DeterministicLoadBalancing.Model /-! # The potentials `φ_t(c)` and `φ'_t(c)` of good `s`-balancers Berenbrink, Klasing, Kosowski, Mallmann-Trenn, Uznański, *Improved Analysis of Deterministic Load-Balancing Schemes*, PODC 2015 (arXiv:1404.4344v4), Section 3 and Appendix B. Graphs need not be regular: node `v` has `D v = deg v + dl` edges in `G⁺`, and the thresholds are `c · D v` per node (for `d`-regular graphs this is the paper's `c·d⁺`). All quantities are natural numbers, truncated subtraction playing the role of `max{·, 0}`. * `phi G dl c x = ∑_v max{x v − c·D v, 0}` (the paper's `φ_t(c)`), `drop` is the paper's `Δ_t(c, u)`; * `phi' G dl s c x = ∑_v max{c·D v + s − x v, 0}` (the paper's `φ'_t(c)`), `drop'` is `Δ'_t(c, u)`. ## Main results * `phi_step`, `lemma_3_5`: Lemma 3.5 (one-step drop of `φ`), `phi_antitone`. * `phi'_step`, `lemma_3_7`: Lemma 3.7 (one-step drop of `φ'`), `phi'_antitone`. * `observation_3_6_false`, `observation_3_8_false`: Observations 3.6 / 3.8 as printed (drop `∑ max{s, ·}`) are false, already for a good `2`-balancer on `K₂` with two self-loops per node. * `observation_3_6`, `observation_3_8`: the corrected versions (drop `∑ min{s, ·}`, which is what the paper uses in Appendix B.4). ## Proof technique Instead of the paper's token colouring we use a capacity argument. For `φ`: every sender `u` sends a fair share over each of its edges, so either all its edge values are `≥ c` (if `⌊x_u/D_u⌋ ≥ c`) or all are `≤ c`; hence `∑_{e out of u} (f_e − c)⁺ = (x_u − c D_u)⁺`. At a receiver `v`, `(x'_v − c D_v)⁺ ≤ ∑_{e into v} (f_e − c)⁺`, and self-preference yields the extra `min{s, x_v − c D_v}` on `v`'s own self-loops. For `φ'` the self-loops of a node are lumped into one edge of capacity `c·dl + s`, every original edge has capacity `c`, and the same bookkeeping is done with `(b_e − f_e)⁺`. -/ open Finset namespace Podc.DeterministicLoadBalancing variable {V : Type*} [Fintype V] [DecidableEq V] set_option linter.unusedSectionVars false /-! ### Definitions -/ section Defs variable (G : SimpleGraph V) [DecidableRel G.Adj] /-- The potential `φ_t(c) = ∑_v max{x_t(v) − c·d⁺, 0}` (Section 3), with the per-node threshold `c · D v`, `D v = deg v + dl`. -/ def phi (dl c : ℕ) (x : V → ℕ) : ℕ := ∑ v, (x v -
