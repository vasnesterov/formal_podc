import Mathlib /-! # Discrete diffusive load balancing on graphs: the model Berenbrink, Klasing, Kosowski, Mallmann-Trenn, Uznański, *Improved Analysis of Deterministic Load-Balancing Schemes*, PODC 2015 (arXiv:1404.4344v4), Section 1.3. * The network is a finite simple graph `G` (the paper's "original graph"); every node additionally has `dl` self-loops (the paper's `d◦`). A node `v` has `D v = deg v + dl` edges in the balancing graph `G⁺` (the paper's `d⁺`). * Time is synchronous. In every step every node `v` with load `x` (number of indivisible tokens) sends `out v s x w` tokens to each neighbour `w` and keeps `keep v s x` tokens (the tokens sent over its self-loops; the self-loops of a node only matter through their total, the distribution over individual self-loops is expressed by an explicit split `g : Fin dl → ℕ` in the fairness predicates below). `s` is the node's local state (e.g. a rotor), updated by `next`. * A `Balancer` is deterministic and local: node `v` decides from its own identity, state and load only. Stateless algorithms are those with `σ = Unit`. variable {G : SimpleGraph V} [DecidableRel G.Adj] /-- Round fairness with `dl` self-loops per node (the class of Rabani–Sinclair–Wanka [17]): a node with load `x` sends a fair share `⌊x/d⁺⌋` or `⌈x/d⁺⌉` over each of its `d⁺ = deg + dl` edges, including each self-loop (`g` is the split of the kept tokens over the self-loops). -/ def Balancer.RoundFair (dl : ℕ) (A : Balancer G) : Prop := ∀ v s x, (∀ w ∈ G.neighborFinset v, FairShare (G.degree v + dl) x (A.out v s x w)) ∧ ∃ g : Fin dl → ℕ, ∑ i, g i = A.keep v s x ∧ ∀ i, FairShare (G.degree v + dl) x (g i) /-- Definition 2.1: cumulative `δ`-fairness. In every execution and every step, every edge of `v` (including self-loops) receives at least `⌊x/d⁺⌋` tokens, and the cumulative flows `F_t` over any two original edges of a node differ by at most `δ`. -/ def Balancer.CumulativelyFair (dl δ : ℕ) (A : Balancer G) : Prop := ∀ x₀ t v, (∀ w ∈ G.neighborFinset v, A.load x₀ t v / (G.degree v + dl) ≤ A.flow x₀ t v w) ∧ (∃ g : Fin dl → ℕ, ∑ i, g i = A.kept x₀ t v ∧ ∀ i, A.load x₀ t v / (G.degree v + dl) ≤ g i) ∧ ∀ w₁ ∈ G.neighborFinset v, ∀ w₂ ∈ G.neighborFinset v, A.cumFlow x₀ t v w₁ ≤ A.cumFlow x₀ t v w₂ + δ /-- The one-step part of Definition 3.1: node `v` with load `x` sends a fair share over every edge (round fairness, conditions "receive `⌊x/d⁺⌋`" and 3.) and at least `min{s, e}` self-loops receive `⌈x/d⁺⌉ = ⌊x/d⁺⌋ + 1` tokens, where `e = x mod d⁺` (condition 2., `s`-self-preference). -/ def GoodStep (dl s : ℕ) (k : ℕ) (x : ℕ) (out : V → ℕ) (nbrs : Finset V) (keep : ℕ) : Prop := (∀ w ∈ nbrs, FairShare k x (out w)) ∧ ∃ g : Fin dl → ℕ, ∑ i, g i = keep ∧ (∀ i, FairShare k x (g i)) ∧ min s (x % k) ≤ #{i | g i = x / k + 1} /-- Definition 3.1: a good `s`-balancer (`1 ≤ s ≤ d◦`): cumulatively `1`-fair, round-fair and `s`-self-preferring. -/ def Balancer.IsGood (dl s : ℕ) (A : Balancer G) : Prop := 1 ≤ s ∧ s ≤ dl ∧ A.CumulativelyFair dl 1 ∧ ∀ v σ x, GoodStep dl s (G.degree v + dl) x (A.out v σ x) (G.neighborFinset v) (A.keep v σ x) end Fairness end Podc.DeterministicLoadBalancing
