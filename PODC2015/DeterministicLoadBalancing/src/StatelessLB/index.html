An *anonymous stateless deterministic* algorithm with `d` ports (`StatelessAlg d`) is given by two functions of the current load `x` of a node only: the number `keep x` of tokens kept (the paper's `p◦`, tokens sent over self-loops / kept as remainder) and the numbers `send x i` of tokens sent over port `i : Fin d` (the paper's `p₁, …, p_d`). The assignment of ports to the edges of a node (`port v : Fin d ≃ G.neighborFinset v`) is chosen by the adversary, as in the paper's proof. **Theorem 4.2.** For every even `n` and every `d < n` there is a `d`-regular graph on `n` nodes, a port numbering and an initial load vector such that the discrepancy stays `≥ d/3` forever. Proof (paper, with fixes): `G` is the circulant graph on `Fin n` with jumps `±1, …, ±⌊d/2⌋` and, for odd `d`, `n/2` (`lbGraph`). The nodes `C = {0, …, h}`, `h = ⌊d/2⌋`, form a clique. All nodes of `C` get load `h`, all others `0`. With `p = send h`, at most `h` ports carry a positive value; the port numbering of a clique node `v` maps the `k`-th such port to the clique node `(v + k) mod (h+1)`. Then every clique node receives exactly `∑ p = h - keep h` and every other node nothing, so the load vector is a fixed point with discrepancy `h ≥ d/3` (for `d ≥ 2`).
