import Papers.PODC2015.DeterministicLoadBalancing.RotorRouter /-! # Theorem 4.3: the ROTOR-ROUTER without self-loops has discrepancy `≥ d · ϕ` Berenbrink, Klasing, Kosowski, Mallmann-Trenn, Uznański, PODC 2015 (arXiv:1404.4344v4), Theorem 4.3 and Appendix C.3. Let `2ϕ + 1` be the odd girth of the `d`-regular graph `G`, fix a vertex `u` (the paper takes `u` on a shortest odd cycle; any vertex works) and let `b v = min(dist(u, v), ϕ)`. Two adjacent vertices with `b < ϕ` lie in consecutive BFS layers (otherwise there is an odd closed walk of length `< 2ϕ + 1`). With `L = ϕ + 1` we use the flow `f₀(v, w) = L ± (ϕ − min(b v, b w))` (`+` iff `b v` is even). It is symmetric (`f₀(v,w) + f₀(w,v) = 2L`) and at every node its values differ by at most one, so the rotor-router realises it periodically (`rotorRouter_periodic`); the load of `u` alternates between `d (L + ϕ)` and `d (L − ϕ)` while the average load is `d L`. **Repair of the paper's construction.** The paper sets `f₀(v₁, v₂) = L` as soon as `b(v₁) ≥ ϕ` **or** `b(v₂) ≥ ϕ`. Then a node in layer `ϕ − 1 ≥ 1` sends `L ± 2` to layer `ϕ − 2` and `L` to layer `ϕ`, contradicting the claim `|f_t(v, v₁) − f_t(v, v₂)| ≤ 1` (no rotor-router step does this), and for `ϕ = 1` all values are `L` and the discrepancy is `0`. The construction works with "and" in place of "or", i.e. with the offset `ϕ − min(b v₁, b v₂)` truncated at `0`, which is what we formalize. -/ open Finset Fin.NatCast namespace
