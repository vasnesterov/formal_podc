Verdict: 🔧 Easy fix. The one false statement, the constant in Observation 3.2, is saved by changing that constant (⌈d⁺/2⌉ − d for d⁺ − 2d), and the max printed in Observations 3.6 and 3.8 is a typo for min. All three lower bounds of Section 4 (Theorems 4.1–4.3) and Lemmas 3.5 and 3.7 are true, and the proofs of the lower bounds needed only local repairs. The paper's main upper bounds (the spectral Theorems 2.3 and 3.3, and Table 1, which rests on them) were not checked.

Mistakes in the paper

🔧 Observation 3.2 (SEND([x/d⁺]) is a good (d⁺ − 2d)-balancer)

SEND([x/d⁺]) is not a good (d⁺ − 2d)-balancer: for d = 1, d◦ = 4, x = 3 only two self-loops get ⌈x/d⁺⌉, where self-preference with s = 3 needs three (observation_3_2_false).

Impact. The correct value is about half the claimed one: it is a good s-balancer exactly for 1 ≤ s ≤ ⌈d⁺/2⌉ − d (sendRound_isGood_iff). That is still s ≥ 1 for d⁺ > 2d and s = Ω(d) for d⁺ ≥ 3d, which is all that Table 1 uses (the table also rests on Theorem 3.3, not checked).

Details

When x/d⁺ is rounded up, the d original edges use up d of the e = x mod d⁺ extra tokens. Only e − d self-loops then get ⌈x/d⁺⌉, but self-preference asks for min{s, e} of them. In the smallest case the original edge gets [3/5] = 1 token and the four self-loops share the remaining two, so two self-loops get ⌈3/5⌉ = 1. Self-preference with s = 3 needs min{3, 3} = 3. The paper does not fix the tie rule; the counterexample has no tie, so it refutes every reading.

Repair

We prove the exact characterisation: on a d-regular graph with d < d◦, SEND([x/d⁺]) is a good s-balancer iff 1 ≤ s ≤ ⌈d⁺/2⌉ − d. So, with halves rounded up, the paper's claim holds iff d◦ = d + 1. Because ⌈d⁺/2⌉ − d ≥ (d◦ − d)/2, this is enough for the uses in Table 1. (sendRound_isGood_iff)

✏️ Slips

  • Observations 3.6 and 3.8 print max instead of min: the bounds on the potential drop over [t, t'], ∑_{u∈U} max{s, x_t(u) − cd⁺} (respectively max{s, cd⁺ + s − x_t(u)}), are false already on K₂ (observation_3_6_false, observation_3_8_false). Take K₂ with two self-loops per node and the good 2-balancer SEND(⌊x/3⌋), c = 1 and loads (4, 0). Node 0 drops to load 3 = cd⁺ and φ(1) drops by only 1, but the printed bound demands max{2, 1} = 2. 3.8 fails the same way, with c = 0 and loads (1, 3). Appendix B.4 actually uses min{s, ·}, and we prove the min versions (observation_3_6, observation_3_8). Observation 3.8 also prints φ_t instead of φ'_t on the right-hand side.

  • Theorem 4.1 needs a connected graph (otherwise the diameter is infinite).

  • Theorem 4.2 needs d < n.

  • Proof of Theorem 4.2: the neighbour indices are written "mod d" where "mod |C|" is meant.

  • Proof of Theorem 4.2: the paper's offset set for the circulant graph contains 0, i.e. a self-loop.

Typos

  • The introduction says that removing self-loops yields Ω(d · diam) (Theorem 4.3). Theorem 4.3 gives Ω(d · ϕ), where 2ϕ + 1 is the odd girth. The two agree on odd cycles.

Proof gaps in true statements (3)Theorem 4.3 · Theorem 4.2 · Theorem 4.1

🔧 Theorem 4.3 (rotor-router lower bound, construction of Appendix C.3)

The flow f₀ of the construction is not a rotor-router execution: a node in layer ϕ − 1 ≥ 1 with a neighbour in layer ϕ sends L ± 2 towards layer ϕ − 2 and L towards layer ϕ, contradicting the claimed |f_t(v, v₁) − f_t(v, v₂)| ≤ 1.

Impact. Statement true; repaired by replacing "or" with "and" (theorem_4_3).

Details

Appendix C.3 sets f₀(v₁, v₂) = L as soon as b(v₁) ≥ ϕ or b(v₂) ≥ ϕ. Every node of the shortest odd cycle through u at distance ϕ − 1 from u is such a node. No rotor-router step produces this; for example, on the 5-cycle the neighbour of u sends L − 2 and L. For ϕ = 1 every value is L and the discrepancy is 0.

Repair

Replacing "or" by "and" fixes the construction, i.e. the offset becomes max{ϕ − min(b(v₁), b(v₂)), 0}. We also make two smaller fixes. The proof's "odd cycle u ⇝ v₁ → v₂ ⇝ u" is only an odd closed walk; we prove that an odd closed walk contains an odd cycle that is no longer. And u can be any vertex. (theorem_4_3)

🔧 Theorem 4.2 (stateless lower bound, d ≤ 3)

The paper's clique of ⌊d/2⌋ nodes with load ℓ = |C| − 1 gives discrepancy ⌊d/2⌋ − 1, which is 0 for d ≤ 3.

Impact. Statement true; repaired with a larger clique (theorem_4_2).

Details

The proof needs the stateless algorithm to be anonymous: every node uses the same p◦, p₁, …, p_d, and the adversary chooses the port numbering. We formalize the theorem in that model.

Repair

The clique {0, …, ⌊d/2⌋} is also present in the paper's circulant graph and gives discrepancy ⌊d/2⌋ ≥ d/3 for d ≥ 2. For d = 1 a single token suffices. (theorem_4_2)

🔧 Theorem 4.1 (K₂)

Theorem 4.1's construction gives discrepancy 0 on K₂ (d = diam = 1).

Impact. Statement true; that case needs a separate argument: one token on two nodes (theorem_4_1).

The formalizationmodel, Lean names of the results, trust

Model. (Model.lean)

  • Synchronous discrete diffusion on a finite simple graph G (usually d-regular) with dl = d◦ self-loops per node, d⁺ = deg + dl. No failures, no randomness.

  • A Balancer is deterministic and local. Node v in local state σ with load x sends out v σ x w tokens to each neighbour w, keeps keep v σ x tokens and moves to a new state; tokens are conserved. Stateless algorithms have σ = Unit.

  • Self-loops matter only through their total, which is the tokens kept. The fairness predicates require a split g : Fin dl → ℕ of the kept tokens over the individual self-loops.

  • RoundFair is the class of [17]: every edge, self-loops included, gets ⌊x/d⁺⌋ or ⌈x/d⁺⌉. CumulativelyFair is Definition 2.1, and IsGood is Definition 3.1. They quantify over all local states and loads, or over all executions.

  • disc x = max − min. "Cannot achieve discrepancy better than D" means: at every time step the discrepancy is ≥ D.

  • ROTOR-ROUTER (RotorRouter.lean, no self-loops): each node has a cyclic order of its edges and a rotor. The edge at position i gets ⌊x/d⌋ + [(i − ρ) mod d < x mod d] tokens, and the rotor advances by x mod d. Theorem 4.3 chooses the edge orders and the initial rotors, as the paper's proof does.

  • Stateless algorithms in Theorem 4.2 (StatelessLB.lean): StatelessAlg d is one function of the load, giving the kept amount and one amount per port, used at every node. The adversary chooses the graph, the port numbering and the loads.

  • Lemmas 3.5 and 3.7 are proved for arbitrary (also non-regular) graphs, with per-node threshold c·(deg v + dl). They use only the one-step part of Definition 3.1.
