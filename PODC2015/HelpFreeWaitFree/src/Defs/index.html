import Cslib.Computability.Distributed.SharedMemory.Solo import Cslib.Computability.Distributed.SharedMemory.Indist import Mathlib /-! # Help: decided-before order and help-freedom (Section 4.4 of [CPT15]) [CPT15]: K. Censor-Hillel, E. Petrank, S. Timnat. *Help!* PODC 2015. Numbering follows the full version, Chapter 4 of S. Timnat's PhD thesis (Technion, 2015). We work in CSLib's asynchronous shared-memory model (`Cslib.SharedMemory`): an implementation `I : Impl A B P L` of the type `A` from base objects `B`, its finite executions (label lists `h` with `I.Valid h`) form the paper's set of histories `H`, and operation instances are `OpId P = P × ℕ` (`(p, k)` is the `k`-th operation of `p`; this names future operations too). * `Prec S a b` — `a ≺ b` in the sequential history `S`: `a` occurs in `S` and `b` does not occur before it (it occurs later or not at all). Operations missing from a linearization are treated as coming after all others; this is the reading used by the paper's own proofs (Claim 4.8.1 and Claim 4.5.2), see `differencies.md`. * `DecidedBefore I f h a b` — Definition 4.4.2: no extension `s` of `h` has `b ≺ a` in `f s`. * `HelpFreeWith I f` — Definition 4.4.3: a pair becomes decided only at a step of the earlier operation by its owner; `HelpFree I` — some linearization function is help-free. * `OwnerOnlyWith I f` / `WeaklyHelpFree I` — the weaker requirement that the deciding step is taken by the *owner* of the operation (not necessarily inside that operation). The impossibility results are proved for this weaker notion, hence are stronger than the paper's. General facts: monotonicity and transitivity of the decided-before order, Observation 4.4.4, the backward-propagation principle of help-freedom ("steps of other processes cannot decide `a` before anything") and Claim 4.4.5. -/ set_option linter.unusedSectionVars false set_option linter.style.longLine false namespace Podc.HelpFreeWaitFree open Cslib.SharedMemory variable {P : Type} {A : ObjSpec} /-! ### Decided-before order and help-freedom -/ variable [DecidableEq P] {ι : Type} [DecidableEq ι] {B : ι → ObjSpec} {L : Type} variable (I : Impl A B P L) /-- **Definition 4.4.2** (decided operations order). For the linearization function `f`, the operation `a` is *decided before* `b` in the history `h` if no extension `s` of `h` (in the set of finite histories of `I`) has `b ≺ a` in `f (h ++ s)`. -/ def DecidedBefore (f : List (Label P A) → List (OpId P × A.Op)) (h : List (Label P A)) (a b : OpId P) : Prop := ∀ s, I.Valid (h ++ s) → ¬ Prec (f (h ++ s)) b a /-- **Definition 4.4.3** (help-free implementation), for a fixed linearization function `f`: whenever a single step `γ` after `h` makes `a` decided before `b`, the step `γ` is a step of the operation `a` taken by its owner. (A step of process `p` after `h` belongs to `p`'s current operation instance `curOp h p`: the pending one, or the one an invocation starts.) -/ def HelpFreeWith (f : List (Label P A) → List (OpId P × A.Op)) : Prop := ∀ h γ a b, I.Valid (h ++ [γ]) → DecidedBefore I f (h ++ [γ]) a b → ¬ DecidedBefore I f h a b → curOp h γ.proc = a /-- **Definition 4.4.3**: the implementation is help-free if some linearization function is help-free over its set of (finite) histories. -/ def HelpFree : Prop := ∃ f, I.IsLinFun f ∧ HelpFreeWith I f /-- Weaker than `HelpFreeWith`: a step that makes `a` decided before `b` is taken by the owner of `a` (possibly while executing another operation). -/ def OwnerOnlyWith (f : List (Label P A) → List (OpId P × A.Op)) : Prop := ∀ h γ a b, I.Valid (h ++ [γ]) → DecidedBefore I f (h ++ [γ]) a b → ¬ DecidedBefore I f h a b → γ.proc = a.1 /-- Weak help-freedom: some linearization function satisfies `OwnerOnlyWith`.
