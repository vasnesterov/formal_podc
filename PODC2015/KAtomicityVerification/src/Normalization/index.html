import Papers.PODC2015.KAtomicityVerification.Basic /-! # Theorem 3.5: the normalization procedure (Algorithm 1) Algorithm 1 of [Golab–Li–López-Ortiz–Nishimura] turns a history satisfying Assumptions 3.2–3.3 into one that also satisfies Assumption 3.4, preserving `k`-atomicity: for every value `v` such that the read `r(v)` of `v` with the earliest finish time finishes before `w(v)`, the response of `w(v)` is moved to the position immediately preceding the response of `r(v)`. ## Encoding Times are natural numbers, and we do not want to rely on the paper's convention that all event times are distinct. We therefore rescale: an invocation at time `t` goes to `4t`, a response at time `t` to `4t + 2` (so among events that were simultaneous the invocations come first, which preserves `<_H` exactly), and a moved response of `w(v)` goes to `4 f(r(v)) + 1`, i.e. *immediately* before the response `4 f(r(v)) + 2` of `r(v)` — no event can lie strictly between them. The paper processes the values one by one; since each iteration moves only the response of `w(v)`, and `r(v)` is computed in the input history `H` and is a read (whose events never move), the iterations do not interact and the simultaneous version below has the same result: the event order of `H` with each moved response placed immediately before the response of its `r(v)`. The trigger for moving `w(v)` is "some read of `v` finishes no later than `w(v)`" (`H.Moved v`); with distinct event times this is the paper's test `f(r(v)) < f(w(v))`. ## Results * `History.normalize_time_lt_iff`, `History.normalize_f_moved`: faithfulness to Algorithm 1. * `History.normalize_isKAtomicOrder_iff`: the `k`-atomic total orders of `H` and `H.normalize` coincide (for every history `H`, with no assumption at all). * `History.theorem_3_5`: Theorem 3.5. -/ namespace Podc.KAtomicityVerification variable {V R : Type*} namespace History variable (H : History V R) /-- The time of an event: `.inl o` is the invocation of `o`, `.inr o` its response. -/ def time (e : (V ⊕ R) ⊕ (V ⊕ R)) : ℕ := e.elim H.s H.f /-- The response of `w(v)` is moved by Algorithm 1: some read of `v` finishes no later than `w(v)` (with distinct times: the earliest-finishing read `r(v)` of `v` has `f(r(v)) < f(w(v))`). -/ def Moved (v : V) : Prop := ∃ r : R, H.val r = v ∧ H.f (.inr r) ≤ H.f (.inl v) /-- The finish time `f(r(v))` of the read `r(v)` of `v` with the earliest finish time (line 3 of Algorithm 1); junk value `0` if `v` is never read. -/ noncomputable def firstReadF (v : V) : ℕ := sInf {n | ∃ r : R, H.val r = v ∧ H.f (.inr r) = n} lemma firstReadF_le {r : R} {v : V} (h : H.val r = v) : H.firstReadF v ≤ H.f (.inr r) := Nat.sInf_le ⟨r, h, rfl⟩ lemma exists_firstRead {v : V} {r : R} (h : H.val r = v) : ∃ r₀ : R, H.val r₀ = v ∧ H.f (.inr r₀) = H.firstReadF v := Nat.sInf_mem (s := {n | ∃ r : R, H.val r = v ∧ H.f (.inr r) = n}) ⟨_, r, h, rfl⟩ open Classical in /-- The normalized history `H'` produced by Algorithm 1 (see the module docstring for the encoding of times).
