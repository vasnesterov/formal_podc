import Papers.PODC2015.KAtomicityVerification.Characterization /-! # Algorithm GPO ("greedy plus obligations"), Section 4 The algorithm constructs a `k`-atomic value order *from right to left*. It keeps the suffix `T` built so far, the set `U` of values not yet placed and obligation sets `B[1] ⊆ … ⊆ B[k-1]` (`B[i]` = values that must be placed within the next `i` positions). In each iteration: * if some `B[i]` is full (`|B[i]| = i`), pick from the smallest full `B[ℓ]` the value whose write has the largest finish time, otherwise pick such a value from `U` (lines 5–10); * prepend it to `T`, remove it from `U` (line 11); * `W` := unplaced values having a read that `w(v)` happens before (line 12), `W'` := unplaced values whose write some `w(v')`, `v' ∈ W`, happens before (line 13); * shift `B[j] := B[j+1] \ {v}`, `B[k-1] := (B[k-1] ∪ W ∪ W') \ {v}` (lines 14–17); * return NO if some `B[i]` is overfull (`|B[i]| > i`, lines 18–19). The loop `while U ≠ ∅` is modelled by `|V|` iterations of `step`, which is the identity once `U = ∅`. Ties between equal finish times (impossible in the paper's model with distinct event times) are broken by a linear order on `V`; the correctness proof does not depend on the tie-break. -/ set_option linter.unusedSectionVars false namespace Podc.KAtomicityVerification open Finset variable {V R : Type*} [Fintype V] [LinearOrder V] [Fintype R] /-- The state of GPO: the constructed suffix `T`, the unplaced values `U`, the obligation sets `B i` (only `1 ≤ i ≤ k - 1` are used). -/ structure GState (V : Type*) where T : List V U : Finset V B : ℕ → Finset V /-- Lines 1–3: the initial state. -/ def GState.init : GState V := ⟨[], univ, fun _ => ∅⟩ namespace History variable (H : History V R) instance : DecidableRel H.hb := fun a b => inferInstanceAs (Decidable (H.f a < H.s b)) instance : DecidableRel H.EW := fun _ _ => inferInstanceAs (Decidable (H.hb _ _)) /-- Finish time of the write of a value. -/ def wf (v : V) : ℕ := H.f (.inl v) /-- A value of `S` whose write has the largest finish time. -/ def pickMax (S : Finset V) (h : S.Nonempty) : V := (S.filter (fun v => ∀ u ∈ S, H.wf u ≤ H.wf v)).min' (by obtain ⟨v, hv, hmax⟩ := S.exists_max_image H.wf h exact ⟨v, by simp only [mem_filter];
