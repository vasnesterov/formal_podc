import Papers.PODC2015.DAPInvisibleReads.Scenario /-! # Theorems 1 and 2: no WDAP TM with wait-free read-only transactions ensures real-time order Peluso, Palmieri, Romano, Ravindran, Quaglia. *Disjoint-Access Parallelism: Impossibility, Possibility, and Cost of Transactional Memory Implementations.* PODC 2015, Section 3. Processes `a` (running `T₄`), `b` (running `T₂`) and `c` (running `T₃`), transactional objects `x ≠ y`. The execution `E` of Figure 1 is `E = R₄(y) · W₃(y) c₃ · W₂(x) c₂ · R₄(x) c₄`, each block run solo. The reads of `T₄` complete and `T₄` commits by WFRO; `T₃` and `T₂` commit by obstruction-freedom (Theorem 1) or, for Theorem 2, because they commit in the execution without `T₄`, which they cannot distinguish from `E` since `T₄`'s first read is invisible. The core of the argument (`core`) is an indistinguishability argument: by WDAP, the steps of `T₂` commute with those of `T₃` and with `T₄`'s first read (at the time of these steps the transactions are disjoint-access), so `E' = W₂(x) c₂ · R₄(y) · W₃(y) c₃ · R₄(x) c₄` is an execution in which `R₄(x)` returns the same value `w` as in `E`. By `LegalReads`, `w` is the initial value or `T₂`'s value. If it is `T₂`'s value, `E`'s history is `H_WRTO` and violates RTO; if it is the initial value, `E'` violates WRTO (and RTO), since `T₂` committed before `T₄` began. ## Main results * `theorem_1`: no WDAP TM with obstruction-free write transactions and wait-free read-only transactions ensures RTO. * `theorem_2`: no WDAP TM with weakly progressive write transactions (`IsolatedWritesCommit`) and wait-free invisible read-only transactions ensures RTO. * `theorem_1_wrto`, `theorem_2_wrto`: if such a TM ensures WRTO, it produces the history `H_WRTO` of Figure 1 (which satisfies WRTO but not RTO): this is the statement actually proved in the paper ("the TM cannot reject `H_WRTO`"); it contains the instance of Lemma 3 used there. -/ namespace Podc.DAPInvisibleReads open Cslib.SharedMemory
