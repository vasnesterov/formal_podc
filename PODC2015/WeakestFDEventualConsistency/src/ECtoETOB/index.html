import Papers.PODC2015.WeakestFDEventualConsistency.EquivBasic /-! # Theorem 1, direction EC → ETOB: the transformation `T_{EC→ETOB}` (Algorithm 1) Process `p` uses an EC black box (multivalued, values `List M`): its invocations `proposeEC_j(l)` are outputs `ecInv j l` of the transformation, its responses are input events `ecResp j l` scheduled by the adversary at `p`. The black box is constrained only by hypotheses on its history `ecHist`: well-formedness (responses after invocations, at most one response per instance) and EC whenever it is used properly. The application's `broadcastETOB(m)` are input events `bcast m`; the ETOB history `tobHist` has these broadcasts and the output variable `d_p` (a field of the local state). Instances are numbered from `0`; `count` is the number of instances invoked so far (the paper's `count_i`, with the paper's instances numbered from `1`). `toDeliver` is kept as a duplicate-free list and `NewBatch(d, toDeliver)` is `toDeliver` without the elements of `d` (in the order of reception).
