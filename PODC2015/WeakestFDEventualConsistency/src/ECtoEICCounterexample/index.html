import Papers.PODC2015.WeakestFDEventualConsistency.ECtoEIC /-! # Algorithm 6 does not satisfy the literal (uniform) EIC-Agreement A run of Algorithm 6 (`Alg6.driver`) with two processes, `true` (faulty: crashes at time `3`) and `false` (correct); each proposes its own name to every EIC instance. * `0`: `true` starts and invokes `proposeEC_0([true])`; * `1`: `false` starts and invokes `proposeEC_0([false])`; * `2`: EC returns `[true]` to `true`, which decides `true` for EIC instance `0` (and invokes `proposeEC_1([true, true])`); then `true` crashes; * `3 + 2j`: EC returns `false`'s own proposal `[false, …, false]` (length `j + 1`) to its instance `j`; `3 + 2j + 1`: `false` takes a time-out step. The EC black box satisfies EC (agreement from instance `1` on: only `false` gets responses to instances `≥ 1`) and the run is admissible, yet the faulty process's (last) decision for EIC instance `0` is `true` while the correct one's is `false` forever: the processes "return infinitely different values" to instance `0`, violating EIC-Agreement read literally ("no two processes"). Hence Lemma 4 of [DGKPS15] holds only with agreement among correct processes (`Alg6.lemma4`). -/ namespace Podc.WeakestFDEventualConsistency open Cslib.FailureDetectors namespace Alg6Counterexample open Driver /-- Each process proposes its own name. -/ def inp : Bool → ℕ → Bool := fun x _ => x /-- The schedule. -/ def sched : ℕ → Option (Bool × Choice Bool (ℕ × List Bool)) | 0 => some (true, .tick) | 1 => some (false, .tick) | 2 => some (true, .input (0, [true])) | t + 3 => if t % 2 = 0 then some (false, .input (t / 2, List.replicate (t / 2 + 1) false)) else some (false, .tick) /-- `true` crashes at time `3`. -/ def F : FailurePattern Bool where crashed t := if 3 ≤ t then {true} else ∅ mono a b h := by dsimp only split_ifs with h1 h2 h2 · exact le_rfl · omega · exact Set.empty_subset _ · exact le_rfl /-- The run. -/ def run : Run Bool Unit (ℕ × List Bool) := ⟨F, fun _ _ => (), sched⟩ /-- Algorithm 6 for this application. -/ abbrev D := Alg6.driver inp lemma sched_input {t : ℕ} {x : Bool} {j : ℕ} {v : List Bool} : sched t = some (x, .input (j, v)) ↔ (t = 2 ∧ x = true ∧ j = 0 ∧ v = [true]) ∨ (t = 3 + 2 * j ∧ x = false ∧ v = List.replicate (j + 1) false) := by match t with | 0 => simp [sched]; split_ifs at h <;> simp at h /-- The states of the correct process `false`. -/ lemma st_false (t : ℕ) : (D.alg Unit).st run false t = (t / 2, List.replicate (t / 2 - 1) false) := by induction t with | zero => rfl | succ t ih => match t with | 0 => rw [(D.alg Unit).loc_succ_of_ne run 0 false (by simp [run, sched])];
