import Papers.PODC2015.WeakestFDEventualConsistency.Specs /-! # Lemma 3 repaired: Algorithm 5 with sequence numbers on promotions implements ETOB from `Ω` `ETOBAlgorithm.lean` shows that Lemma 3 of [DGKPS15] is false: links are not FIFO, and a process adopts *every* promotion of its current leader, so a delayed older promotion can make `d_i` shrink infinitely often. Here we repair Algorithm 5 and prove that the repaired algorithm implements ETOB in every environment (with finitely many processes). **The repair.** The leader tags each promotion with a counter (the number of promotions it has sent so far, the current one included): on a time-out with `Ω_i = p_i`, `p_i` sends `promote(cnt_i + 1, promote_i)` and sets `cnt_i := cnt_i + 1`. Process `p_i` keeps `last_i : P → ℕ` (initially `0`) and, on reception of `promote(n, seq)` from `p_j`, adopts it (`d_i := seq`, `last_i[j] := n`) only if `Ω_i = p_j` **and** `last_i[j] < n`. Everything else is as in Algorithm 5. **Simplification.** Broadcasts carry no causal dependencies (`C(m) = ∅`), so the causality graph is a `Finset` of messages and `UpdatePromote` replaces `promote_i` by *some* duplicate-free sequence having `promote_i` as a prefix and containing exactly the messages of `CG_i`. As in `ETOBAlgorithm.lean`, the choice is an arbitrary function `upd` satisfying `UpdValid` (`exists_updValid` shows one exists); the theorem holds for every such choice. **The proof.** Let `ℓ` be the final leader and `T_Ω` the time from which every correct process trusts `ℓ`. Promotions of `ℓ` with larger counters were sent later, and `promote_ℓ` only grows by appending, so promotions of `ℓ` are prefix-ordered by their counters (`prefix_of_counter_le`). After `T_Ω`, a correct process only adopts promotions of `ℓ`, and only with increasing counters. Every correct process `p` adopts at least one promotion of `ℓ` at some time `≥ T_Ω` (`exists_good`): `ℓ` sends a promotion after `T_Ω` whose counter exceeds everything adopted from `ℓ` before `T_Ω`, and `p` receives it. From then on `d_p` is the payload of the promotion of `ℓ` with counter `last_p[ℓ]` (`Good`). The paper's `τ = τ_Ω + Δt + Δc` (which uses a "longest communication delay", which need not exist in an asynchronous run) is replaced by the maximum over the correct processes of these adoption times
