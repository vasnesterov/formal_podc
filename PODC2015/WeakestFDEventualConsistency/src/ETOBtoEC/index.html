import Papers.PODC2015.WeakestFDEventualConsistency.EquivBasic /-! # Theorem 1, direction ETOB → EC: the transformation `T_{ETOB→EC}` (Algorithm 2) Process `p` uses an ETOB black box: its broadcasts `broadcastETOB(m)` are outputs `tobBcast m` of the transformation, and every change of the black box's output variable `d_p` is an input event `tobDeliver l` (the new value `l` of `d_p`, stored in the local state). The black box is only constrained by the hypothesis that its history (`tobHist`) satisfies ETOB whenever its broadcasts are distinct. The application is folded into the algorithm: `inp p j` is the value `p` proposes to instance `j`; `p` invokes instance `0` at its first time-out and instance `j + 1` in the very step in which it returns its response to instance `j` (the usage assumption of EC). Invocations and responses are outputs `inv j v`, `resp j v`; they form the EC history `ecHist`. **Repair.** The paper broadcasts `(ℓ, v)`; two processes proposing the same value to the same instance then broadcast the same message, violating the ETOB usage assumption "broadcast messages are distinct". We broadcast `(p, ℓ, v)` instead; `First(ℓ)` is the value of the first message of the form `(_, ℓ, _)` in `d_p`. Instances are numbered from `0`.
