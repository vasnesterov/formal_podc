import Mathlib import Cslib.Probability.Finite.Uniform /-! # Fingerprinting: a one-way randomized protocol for equality (Lemma 3.3 of [BFP15]) M. Baruch, P. Fraigniaud, B. Patt-Shamir. *Randomized Proof-Labeling Schemes.* PODC 2015. Lemma 3.3 asks for a one-way protocol for `EQ`: a *sender* holding a bit string `a` sends a short random message, and a *decider* holding a bit string `b` decides `a = b` from it; equal strings are always accepted and distinct strings are rejected with probability `> 2/3`; the message has `O(log λ)` bits for `λ`-bit strings. We use polynomial fingerprints over the Galois field `𝔽 = GF(2^m)`, `m = fpBits |a|` with `2^m ≥ 3 (|a| + 1)`: * `bitPoly a = X^|a| + ∑ aᵢ Xⁱ` encodes the bit string `a` injectively (the leading monomial encodes the length); * `fpSend a x`, for a uniformly random `x ∈ 𝔽`, is the `2m`-bit string `enc x ++ enc (P_a(x))`; * `fpDecide b r` accepts iff `r = fpSend b x` for some `x`, i.e. iff `r` has `2 · fpBits |b|` bits and decodes to a pair `(x, y)` with `P_b(x) = y`. Our version is slightly more general than the paper's: `a` and `b` may have different lengths (the message then has `2 · fpBits |a|` bits). ## Main statements * `uprob_apply_eq` (marginal of a uniform product space; `CSLib candidate`). * `card_filter_eval_eq_le` (two distinct polynomials agree on few points; `CSLib candidate`). * `lemma_3_3`: Lemma 3.3 of [BFP15]. -/ namespace Podc.RandomizedPLS
