import Papers.PODC2015.RandomizedPLS.Crossing /-! # Restricting a configuration to a union of components The lower bounds of Section 5 apply the crossing tool to a *connected component* of the crossed configuration (proof of Theorem 5.1: "`σ₁(P) ∉ F`, but `C` is a connected component of `σ₁(P)` and `C ∈ F`"). This is sound because verification is local: a node of a set `U` closed under taking neighbours sees the same thing in `c` and in `c.restrict U`. * `accepts_restrict`: deterministic acceptance passes to `c.restrict U`. * `RScheme.accProb_le_restrict`: the acceptance probability can only grow (fewer nodes must accept;
