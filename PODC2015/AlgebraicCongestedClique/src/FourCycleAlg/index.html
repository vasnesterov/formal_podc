import Papers.PODC2015.AlgebraicCongestedClique.FourCycle import Podc.Computability.Distributed.CongestedClique.Routing /-! # Theorem 4: 4-cycle detection in `O(1)` rounds (Censor-Hillel et al., PODC 2015) The algorithm of Section 3.1, as a `Prog` on the congested clique with nodes `Fin n`. Node `v` starts with its neighbourhood `N(v)`; words are triples of natural numbers `≤ 64 n` (`O(log n)` bits). 1. every node broadcasts its degree (1 round); 2. every node `x` computes `|P(x,∗,∗)| = ∑_{y ∈ N(x)} deg(y)` and broadcasts whether it is `≥ 2n − 1`; if some node does, there is a 4-cycle and all further steps are idle (1 round); 3. (Lemma 12: every node computes the tiles `A(y) × B(y)` from the degrees.) Node `y` sends `N_A(y, a)` to every `a ∈ A(y)` (`≤ 8` words per link, 8 rounds); 4. node `a` sends `N_A(y, a)` to every `b ∈ B(y)` for the unique `y` with `(a, b)` in the tile of `y` (`≤ 8` words per link, 8 rounds); node `b` now knows `N(y)` for all `y` with `b ∈ B(y)` and computes `W(b)`; 5. node `b` sends each walk `(x, y, z) ∈ W(b)` to `x` (Lenzen's routing; every node sends `≤ 64 n` walks by Lemma 13 and receives `|P(x,∗,∗)| < 2n` walks; `2 + 128 · 16` rounds by `Prog.exists_routedBig`); node `x` now knows `P(x,∗,∗)` and checks whether `|P(x,∗,z)| ≥ 2` for some `z ≠ x`; 6. every node broadcasts the result of its check (1 round). -/ namespace Podc.AlgebraicCongestedClique open Finset SimpleGraph Cslib.CongestedClique noncomputable section /-- Words: triples of natural numbers. -/
