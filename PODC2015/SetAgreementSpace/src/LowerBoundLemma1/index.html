import Papers.PODC2015.SetAgreementSpace.Defs import Podc.Computability.Distributed.SharedMemory.Splice /-! # Lemma 1 of [DFKR15] from the wait-free set-agreement impossibility Lemma 1 of the paper derives from the impossibility of wait-free `(q-1)`-set agreement among `q` processes from registers (Borowsky–Gafni, Herlihy–Shavit, Saks–Zaharoglou) that an `m`-obstruction-free set-agreement algorithm has, for any `m` processes with `m` distinct inputs, an execution of these processes only in which all `m` inputs are output. We do not formalize the topological impossibility proof; it is the explicit hypothesis `BGImpossibility` (a true, standard theorem; see its docstring). * `Lemma1Prop I m` — the form of Lemma 1 used in the proof of Theorem 2: it is stated *from an arbitrary reachable configuration* `C` (not only from the initial one), for the first instance of repeated set agreement that nobody has invoked yet. * `lemma1` — `BGImpossibility` + validity + `m`-obstruction-freedom imply `Lemma1Prop I m`. The reduction restarts `I` from `C`, allowing only the processes of `Q` to propose, each its own input (`Cslib.SharedMemory.Impl.restrict`): the restarted algorithm is wait-free because at most `m` processes ever take steps, and satisfies validity because the instance is fresh. -/ namespace Podc.SetAgreementSpace open Cslib.SharedMemory variable {P V ι W L : Type} [DecidableEq P] [DecidableEq ι] [Inhabited V] {w₀ : W} /-- **Impossibility of wait-free set agreement** (Borowsky–Gafni, Herlihy–Shavit, Saks–Zaharoglou, references [2, 10, 11] of [DFKR15]), in the special case used by Lemma 1: no wait-free read/write algorithm in which exactly the processes of a nonempty set `Q` may propose, each its own fixed input `inp p` (pairwise distinct), solves `(|Q| - 1)`-set agreement (validity and `(|Q|-1)`-agreement on all one-shot executions). The initial memory and local states are arbitrary (they are part of the algorithm `J`). This is a true theorem; it is assumed here, not proved. -/ def BGImpossibility (P V ι W L : Type) [DecidableEq P] [DecidableEq ι] [Inhabited V] (w₀ : W) : Prop := ∀ (J : Impl (saObj V) (RegFamily ι W w₀) P L) (Q : Finset P) (inp : P → V), Q.Nonempty → Set.InjOn inp Q → (∀ p o, J.allowed p o ↔ p ∈ Q ∧ o = inp p) → J.WaitFreeOn OneShot → ¬ J.Solves (kSetAgreement P V (Q.card - 1)) /-- **Lemma 1 of [DFKR15]**, in the form used in the proof of Theorem 2. Then there is an execution fragment `β` from `C` in which only processes of `Q` take steps and in which all values `inp q`, `q ∈ Q`, are output: each by a process of `Q` that returns exactly once in `β` (i.e. in the `(s+1)`-th instance).
