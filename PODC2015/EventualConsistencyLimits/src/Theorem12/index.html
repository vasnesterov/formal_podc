The construction (Figure 4 of the paper). Writers `R_p` (`p < n'`) each write `⟨j, p⟩` to `x_p` and broadcast, for `j < k`. For `g : [n'] → [k]`, replica `a` (`R_{n-1}`) receives, for every `p`, the first `g p + 1` messages of `R_p`, reads `x_p`, then writes `y` and broadcasts `m_g`. Decoding: replica `b` (`R_n`) receives the first `g p + 1` messages of every `R_p` and `m_g`, and reads `y` and `x_i`. Our proof of the decoding step differs from the paper's (which delivers `R_i`'s messages one by one and is completed only in the full version): `b`'s state is final (it has heard everything in the sub-execution in which every `R_p` stopped after `g p + 1` rounds), so its reads return `{1}` and `{⟨g i, i⟩}`; if `m_g = m_{g'}` with `g i < g' i`, the same state of `b` occurs in an execution where
