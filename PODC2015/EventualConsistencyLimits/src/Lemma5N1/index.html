import Papers.PODC2015.EventualConsistencyLimits.Lemma5 /-! # Lemma 5 fails with a single replica Lemma 5 of [AEM15] does not assume that there are at least two replicas. With a single replica nothing ever needs to be sent: the store `D1` below (one replica, which keeps the last value written to each object and never sends anything) is eventually consistent, has invisible reads and op-driven messages, is highly available, and after the first write the replica has no message pending — contradicting the conclusion of Lemma 5 (all other hypotheses of Lemma 5 are vacuous for the empty prefix `α = []`).
