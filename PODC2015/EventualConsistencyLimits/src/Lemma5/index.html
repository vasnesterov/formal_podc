import Papers.PODC2015.EventualConsistencyLimits.Late /-! # Lemma 5: writes must be propagated **Lemma 5 of [AEM15]** (proved only in the full version): in an eventually consistent data store with invisible reads and op-driven messages, if the last event of `α` is a write `w` at `R`, and `R` has directly received everything that happened before `w`, then `R` has a message pending after `w`. We prove it (`lemma5`) under the following explicit form of the hypothesis "`e →hb w ⇒ e →rcv w`": no replica has a message pending at the end of `α` and `R` has received every message sent in `α` by another replica. We also need a second replica `R' ≠ R` (with a single replica the lemma is false: nothing ever needs to be sent) and that `w` writes a fresh value and the writes of `α` write pairwise distinct values (the paper assumes all written values distinct). Proof (ours). Let `δ` deliver every message of `α` to every replica other than `R` and the sender. If `R` had no message pending after `w`, then both `α δ` and `α r w δ` (with an invisible read `r` of `o` at `R` inserted before `w`) are quiescent. Appending reads forever (Lemma 3, `exists_late_ae`): in `α δ` the late reads at `R` and `R'` return the response `S` of `r`, which does not contain `w`'s value. In `α r w δ` the state of `R'` is the same, so late reads at `R'` again return `S`, and late reads at `R` return `S` too. But `w` is visible to them, so it is overwritten by a returned write `w₂ ∈ S`, i.e. `w →vis⁺ w₂`. Since `w₂ ∈ S = rval(r)`, `w₂ →vis r`, hence `w₂ →vis w` (Definition 4(2)) — a cycle. -/ namespace Podc.EventualConsistencyLimits variable {ι Obj V M St : Type*} [DecidableEq ι] namespace Store
