import Papers.PODC2015.EventualConsistencyLimits.Final /-! # Corollary 4: every execution has a quiescent extension **Corollary 4 of [AEM15].** In an eventually consistent data store with invisible reads and op-driven messages, every finite execution `α` can be extended to a quiescent execution `α β`; hence (Lemma 3) reads of the same object at any two replicas at the end of `α β` return the same response. Construction of `β`: first every replica that has a message pending sends it (`flushAll`; after a send nothing is pending, `SendClears`), then every message sent so far is delivered to every replica other than its sender (`deliverEvery`; receipts keep replicas non-pending, `OpDriven`). -/ namespace Podc.EventualConsistencyLimits variable {ι Obj V M St : Type*} [DecidableEq ι] namespace Store variable (D : Store ι Obj V M St) open scoped Classical in /-- The `send` of replica `j` at the end of `α`, if it has a message pending. -/ noncomputable def flush1 (α : List (ι × Ev Obj V M)) (j : ι) : List (ι × Ev Obj V M) := if h : ∃ m σ σ', D.state j α = some σ ∧ D.step j σ (.send m) = some σ' then [(j, .send h.choose)] else [] /-- Every replica of `l` that has a message pending at the end of `α` sends it. -/ noncomputable def flushAll (α : List (ι × Ev Obj V M)) (l : List ι) : List (ι × Ev Obj V M) := l.flatMap (D.flush1 α) /-- Deliver every message sent in `α` to every replica other than
