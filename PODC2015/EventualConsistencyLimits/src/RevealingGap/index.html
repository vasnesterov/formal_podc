import Papers.PODC2015.EventualConsistencyLimits.Theorem6 /-! # The "w.l.o.g. revealing" step of the proof of Theorem 6 fails Section 5.2.1 of [AEM15] claims that every OCC abstract execution `A` may be assumed revealing "by adding the appropriate `r_w` operations and vis edges": before every write `w` insert a read `r_w` of the same object at the same replica, with the same visibility as `w`. The resulting abstract execution need not be OCC, so the proof of Theorem 6 (which applies Lemma 11 to the added reads `r_w` in its induction) cannot be run on it. Counterexample (one object, replicas `0, 1, 2`, values `a = 0`, `b = 1`, `c = 2`): * `Gap.A`: replica 0 writes `a`, replica 1 writes `b`, replica 2 writes `c`; the writes of `a` and `b` are visible to the write of `c`. It has no reads, so it is trivially OCC. * `Gap.Arev`, its revealing extension: the added read `r_c` before the write of `c` sees the two concurrent writes of `a` and `b` and returns `{a, b}`. Definition 18 then requires writes `w₀'`, `w₁'` to *other* objects, which do not exist: `Gap.Arev` is not OCC. `A` itself is trivially realizable; this only shows that the justification of the w.l.o.g. step is wrong. -/ namespace Podc.EventualConsistencyLimits namespace Gap /-- The visibility relation of `Arev`, as a list of pairs. -/ def visL : List (ℕ × ℕ) := [(0, 1), (2, 3), (4, 5), (1, 4), (3, 4), (1, 5), (3, 5), (0, 4), (0, 5), (2, 4), (2, 5)] /-- The OCC abstract execution: three writes `a, b, c` of a single object at replicas `0, 1, 2`; `a` and `b` are visible to `c`. -/ def A : AE (Fin 3) Unit (Fin 3) where dom i := i < 3 rep i := ⟨i % 3, Nat.mod_lt _ (by norm_num)⟩ ev i := ⟨(), .write ⟨i % 3, Nat.mod_lt _ (by norm_num)⟩, .ok⟩ ord a b := a < b ∧ b < 3 vis a b := (a, b) ∈ [(0, 2), (1, 2)] /-- The revealing extension of `A`: event `2i` is the read `r_w` added before the write `w = 2i + 1` (the `i`-th write of `A`), at replica `i`.
