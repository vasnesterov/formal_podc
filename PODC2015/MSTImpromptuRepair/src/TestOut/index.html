import Papers.PODC2015.MSTImpromptuRepair.Cut import Cslib.Probability.Finite.Uniform /-! # `TestOut`: one-bit test for a leaving edge with an odd hash function (Section 2.1, Lemma 1) A random `h : U → {0, 1}` (drawn uniformly from a finite family `Ω`) is `ε`-*odd* on the key set `K` (`IsOdd`) if every non-empty `S ⊆ K` contains an odd number of keys hashing to 1 with probability at least `ε` (inequality (1)). `TestOut(x, j, k)` aggregates, up the tree, the local parities `∑_{e ∈ E(v), weight(e) ∈ [j, k]} h(e) mod 2` (`testOut`). * `testOut_eq_sum_cut` — the aggregate equals `∑_{e ∈ Cut(T, V \ T), weight(e) ∈ [j,k]} h(e) mod 2`. * `testOut_eq_zero_of_no_cut`, `exists_cut_of_testOut_eq_one` — **always correct if 1 is returned**: with no leaving edge in the weight range the answer is 0 for every `h`. * `testOut_prob` — with an `ε`-odd family, if a leaving edge has its weight in the range, the answer is 1 with probability `≥ ε`. * `thorupHash` — the paper's family `h(x) = [(a x mod 2^w) ≤ t]` (odd `a ∈ [1, 2^w]`, `t ∈ [1, 2^w]`) from [33]; that it is `1/8`-odd is cited, not proved. We check it for `w = 2, 3` on the key range `[1, 2^w]` (`thorup_odd_two`, `thorup_odd_three`) and note that it fails for the degenerate `w = 1` (`thorup_not_odd_one`). -/ namespace
