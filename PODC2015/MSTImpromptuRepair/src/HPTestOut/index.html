import Papers.PODC2015.MSTImpromptuRepair.Cut import Cslib.Probability.Finite.Uniform /-! # `HP-TestOut`: set-equality testing by polynomial fingerprints (Section 2.2) `HP-TestOut(x)` decides whether `E↑(T) ≠ E↓(T)` (Observation 1) by comparing the fingerprints `𝒫(D)(α) = ∏_{e ∈ D} (α - edge_number(e))` over `ℤ_p` at a uniformly random `α`. The fingerprint of `E↑(T)` is aggregated up the tree as a product of the local values `Local↑(y) = 𝒫(E↑(y))(α)` (`fp_Eup_eq_prod_local`). * `hpTestOut_false_of_no_cut` — if no edge leaves `T`, `HP-TestOut` always returns 0. * `card_hpTestOut_fail_le` — if an edge leaves `T` and the dart numbers are distinct in `ℤ_p`, at most `D - 1` values of `α` make `HP-TestOut` return 0, where `D = |E↑(T)|` is the sum of the degrees of the vertices of `T` (the paper's `B`, "by summing up the degrees of nodes in `T`"). * `hpTestOut_error_lt` — **inequality (2)**: with `p > maxEdgeNum` and `p > D / ε`, the error probability is `< ε`. * `fp_Eup_eq_fp_Edown_of_symm` — **the edge numbers must be ordered**: with the paper's literal edge number of an *undirected* edge ("concatenation of the IDs, smallest first"), the two fingerprints coincide for every `α`, so `HP-TestOut` never detects a leaving edge (`hpTestOut_symm_never`). -/ namespace Podc.MSTImpromptuRepair open Finset Polynomial
