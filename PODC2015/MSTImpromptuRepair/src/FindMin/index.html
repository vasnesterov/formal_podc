One iteration of steps 4–7 from the range `(j, k)`: * step 5: the `w` subranges `[j_i, k_i]`, `j_i = j + i ⌈(k-j)/w⌉`, `k_i = j + (i+1) ⌈(k-j)/w⌉ - 1`, are tested by `TestOut` (answers `ans i`, **one-sided**: `true` only if the subrange contains a leaving edge, `OneSided`); * step 6: `min` = the first subrange answering 1; `TestLow = HP-TestOut(0, j_min - 1)`, `TestInterval = HP-TestOut(j_min, k_min)`, modelled as **exact** (the w.h.p. event); * step 7: (a) `TestLow = 0 ∧ TestInterval = 1`: if `j_min < k_min` narrow to `(j_min, k_min + 1)`, else return `j_min`; (b) both `0`: return `∅`; otherwise repeat. When no subrange answers 1 (the paper does not say what happens) we repeat. `run` iterates at most `fuel` times (the paper's `Count` bound) and returns `∅` when it runs out. * `run_sound` — whatever the `TestOut` answers, a returned weight is the minimum of `L` (given exact `HP-TestOut`s);
