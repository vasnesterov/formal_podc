The case analysis of the paper (Claims B.6, B.7 and Cases 1–3) refutes all outcomes except those keeping `#S0 − #S1` invariant. We replay it as a *certified case tree* (`Tree`): every node splits on the outcome of one pair (all ten possible outcomes), every leaf either * refutes the current partial transition table by a certificate (`Cert`): - `b2`: two initial configurations of the same size with different numbers of `S0` reach a common configuration (contradicting Claim B.2); - `safe`: an initial configuration with majority `S i` reaches a closed set of configurations in which all agents output `!i` (contradicting the second correctness property); - `live`: an initial configuration with majority `S i` reaches a closed set of configurations none of which has all outputs equal to `i` (contradicting the third property); or * checks that the (now complete) table preserves `#S0 − #S1` (`inv`). `checkTree_sound` proves that a successful check implies `Invariant P` for every symmetric correct protocol agreeing with the starting table.
