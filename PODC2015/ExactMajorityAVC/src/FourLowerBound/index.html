Let `P` keep `#S0 − #S1` invariant in every interaction (`Invariant P`, which by `theorem_B_1_invariant` holds for every correct symmetric four-state protocol). Start with `#S0 − #S1 = D ≥ 0` (majority `S0`, `D = ϵn`) and at least one agent in the minority state `S1`. No configuration of `C_0` contains `S1`, so the convergence time is at least the first time `τ` at which no agent is in `S1`. We prove (`hitProb_le`) `P(τ ≤ t) ≤ t · 2(D + 1) / (n(n − 1))`, following the proof of Claim B.8: the number of `S1` agents never drops by two in one step, and it drops from `1` to `0` only if the unique `S1` agent meets one of the `D + 1` agents in `S0`. Consequently (`sum_tail_ge`) `∑_{t<K} P(τ > t) ≥ K − p·K(K−1)/2` with `p = 2(D+1)/(n(n−1))`; since `E[τ] = ∑_t P(τ > t)`, taking `K ≈ 1/p` gives `E[τ] ≥ n(n−1)/(4(D+1))` steps up to rounding, i.e. parallel time `Ω(1/ϵ)`. `P(τ ≤ t)` is defined by the first-step recursion `hitProb` (probability of having visited `Z = {no agent in S1}` within `t` steps). -/ namespace Podc.ExactMajorityAVC.Four
