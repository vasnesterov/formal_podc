With this condition a weak state meeting a state of *negative* value falls through to line 19, which leaves both states unchanged: `+0` never becomes `−0`. When `B` is the majority this can be fatal. Counterexample (`m = 1`, `d = 1`, i.e. the four-state protocol, `n = 3`): inputs `A, B, B`, i.e. states `1₁, −1₁, −1₁`. The interaction of the first two agents (line 15/17) produces `−0, +0`; the configuration `−0, +0, −1₁` is *silent* (every interaction leaves it unchanged), and agent `1` outputs the minority value `A` forever. Under the uniformly random scheduler this configuration is reached after one step with positive probability, so the probability of not having converged to the majority does not tend to `0` (`not_tendsto_literal`). The same happens for every `m` (the model checker finds `+3, −3, −3` for `m = 3`). The intended condition is evident from the prose ("if a node with 0 weight meets a node with non-zero weight, then it will adopt the sign of the interaction partner"); the corrected protocol `avc` is
