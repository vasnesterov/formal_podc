import Cslib.Computability.Distributed.PopulationProtocols.Basic import Mathlib.Tactic /-! # The Average-and-Conquer (AVC) protocol (Figure 1 of the paper) Alistarh, Gelashvili, Vojnović, *Fast and Exact Majority in Population Protocols*, PODC 2015 (full version MSR-TR-2015-13), Section 3, Figure 1. States carry a sign and a weight; the *value* is `sign · weight`: * `St.zero pos` — the weak states `+0` (`pos = true`) and `−0`; * `St.one pos j` — the intermediate states `±1_j` (level `j`, `1 ≤ j ≤ d`); * `St.strong v` — the strong states, `v` odd with `3 ≤ |v| ≤ m`. The transition function `update` follows the pseudocode of Figure 1 line by line. Line 12 is printed as `weight(x) · weight(y) = 0 and value(x) + value(y) > 0`; with that condition a weak state never adopts a *negative* sign, contradicting the prose ("if a node with 0 weight meets a node with non-zero weight, then it will adopt the sign of the interaction partner") and breaking the protocol when `B` is the majority (see `AVCLiteral.lean`). We formalize both versions: `avcLiteral d` (as printed) and `avc d` (line 12 with `weight(x) + weight(y) > 0`, i.e. "zero meets non-zero", as described in the prose). The transition function does not depend on `m`; `m` only bounds the valid states (`St.Valid m d`), and the set of valid states is closed under interactions (`valid_update`). ## Main statements * `value_update`: interactions preserve the sum of values (Invariant 4.3, local form); * `valid_update`: valid states stay valid; * `update_neg`: the corrected protocol is symmetric under negating all
