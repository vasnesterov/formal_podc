import Podc.Computability.Distributed.PopulationProtocols.Multiset.Basic import Cslib.Computability.Distributed.PopulationProtocols.Basic /-! # Four-state exact majority protocols: the model of Appendix B (Theorem B.1) The four states are `S0`, `S1` (the initial states for inputs `B`, `A`; the paper's `S0`, `S1`) and `X`, `Y`. A protocol is a CSLib deterministic protocol `P : Protocol Q4` (`δ p q = (p', q')`, Section 2 of the paper). Agents are anonymous, so we work with configurations as multisets of states (`Multiset Q4`); a step fires `P.δ p q` on two agents in states `p`, `q` (either can be the initiator). This is the Podc multiset model (`MStep`) for the transition set `trans P`. The output map is `γ : Q4 → Bool` (`false` = output `0`, `true` = output `1`); `S i` is the initial state for output `i` (`S false = S0`, `S true = S1`), and `cfg i a b` is the initial configuration with `a` agents in `S i` and `b` agents in `S (!i)`. The three correctness properties of Theorem B.1 (`Correct`), for every population size: * `nonempty`: for each output `i` and each `n ≥ 1`, the set `C_i` of absorbing configurations of size `n` (every reachable configuration has all outputs equal to `i`) is non-empty; * `safe`: from an initial configuration with a majority of `S i`, no configuration of `C_{1-i}` is reachable; * `live`: from every configuration reachable from an initial configuration with a majority of `S i`, some configuration of `C_i` is reachable. The proof of Theorem B.1 treats interactions as *unordered* ("`[S0, X]` is the same as `[X, S0]`", Appendix B); we make this explicit as the hypothesis `Symmetric P`: both orientations of a pair produce the same multiset of states. -/ namespace Podc.ExactMajorityAVC.Four -- CSLib candidate (tactic) /-- Prove an equality of multisets by comparing all counts. -/ macro "ms_eq" : tactic =>
