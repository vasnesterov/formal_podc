import Papers.PODC2015.ABADetection.Defs import Cslib.Computability.Distributed.SharedMemory.Atomic /-! # The paper's literal `WeakRead()/WeakWrite()` condition is not implied by linearizability Section 2 of the paper specifies `WeakRead()`/`WeakWrite()` by: *"a `WeakRead()` operation `r` by process `p` returns `True` if and only if there exists a `WeakWrite()` operation `w` such that `w` happens before `r` and every other `WeakRead()` operation by `p` happens before `w`"*, and claims that *"linearizability of an ABA-detecting register `R` guarantees that [`R.DRead()` and `R.DWrite()` used as `WeakRead()`/`WeakWrite()`] satisfy the correctness properties above"*. Read literally, this is false, for two independent reasons (`WeakSpecLiteral` is the literal condition): 1. `weakSpecLiteral_not_of_linearizable_concurrent`: a `DRead()` that is concurrent with a `DWrite()` and linearized after it returns flag `true`, although no write *happens before* it. 2. `weakSpecLiteral_not_of_linearizable_later_read`: in the sequential history `DWrite(); DRead() → true; DRead() → false`, the first read returns `true`, but "every other `WeakRead()` by `p`" includes the *later* read, which does not happen before the write. Both histories are executions of the trivial atomic implementation of the ABA-detecting register (`atomicImpl`, which is linearizable and wait-free), with writer `0` and reader `1`. The proofs of Section 2 only use the special cases of the condition that do hold for linearizable implementations (the reader's *last* previous read, and operations that are not concurrent): see `separates_aba` (Observation 1) in `Observation.lean`, which is proved directly from linearizability. The intended condition is presumably "… every *earlier* `WeakRead()` by `p` happens before `w`", for reads that are not concurrent with a write. -/ set_option linter.unusedSectionVars false namespace
