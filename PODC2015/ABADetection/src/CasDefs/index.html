import Papers.PODC2015.ABADetection.Common /-! # Implementations from bounded writable CAS objects: definitions (Section 2.2) All base objects are writable CAS objects `wcasObj V v₀` over one finite value type `V` (registers and non-writable CAS objects are writable CAS objects on which the implementation only uses `Read`/`Write`, respectively `Read`/`CAS`). * `poisedAcc I C q` — the access (object, primitive) `q`'s next step performs, if any. * `SOp s o` — `o` applied to an object with value `s` is a `Write` or a *successful* `CAS(x,y)` with `x ≠ y` (the paper assumes w.l.o.g. that `CAS(x,x)` is never used; we treat such a CAS as a read instead). * `Succ I C β` — the schedule `β` (one step per process) is *successful* for `C` (paper: `P`-successful): every step is a `Write` or a successful `CAS`. * `WCov I C R S`, `CCov I C R S` — the processes of `S` poised to `Write`, respectively to `CAS`, object `R` (paper: `WCov(C,R) ∩ S`, `CCov(C,R) ∩ S`). * `Budget I C q t` — from `C`, `q` takes at most `t` steps before returning (paper: "in no execution starting from `C`, `q` executes more than `t` shared memory steps before finishing"). -/ set_option linter.unusedSectionVars false
