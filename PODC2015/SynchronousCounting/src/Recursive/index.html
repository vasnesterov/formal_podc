Every intermediate counter counts modulo the `boostTime` required by the next level. * `theorem3`, `theorem3_asymptotic`: the varying-blocks construction of §4.3 (Theorem 3): resilience `f = n^{1-o(1)}`, stabilisation time `O(f)`, `O(log² f / log log f + log C)` state bits. * `theorem2`, `corollary2`: the fixed-blocks construction of §4.2 (Theorem 2, Corollary 2), with `h = 2^a`. Notes on the paper's computations (all asymptotic claims survive): * Theorem 1 costs `3(F+2)(2m)^k` per step; the proof of Corollary 1 writes `(3f+2)(2m)^k`, and the proof of Theorem 2 writes `h^k` (`h = k/2`) instead of `(2m)^k = k^k`. * In §4.3 the paper computes `n/f = 2^{2(2^P-1)}`, which corresponds to `R_p = 2·2^{P-p}` and drops the factor `4`; with the stated `R_p = 2k_p = 8·2^{P-p}` one gets `n/f = 2^{8·2^P-6}` (`thm3N`). * The constructions only produce the special network sizes `n = 3f+1`, `n = 4(2h)^L`, `thm3N P`. -/ namespace SynchronousCounting open Cslib.Byzantine.SyncCounting /-! ### The base case -/ /-- The trivial `c`-counter on a single node: the state is the counter value, incremented every round. -/ def trivialCounter (c : ℕ) (hc : 0 < c) : Algorithm (Fin 1) (Fin c) c where g i m := ⟨((m i : ℕ) + 1) % c, Nat.mod_lt _ hc⟩ h _ s := s /-- §4.1: the trivial `0`-resilient `c`-counter on one node, stabilising in `0` rounds and using `⌈log₂ c⌉` bits. -/ theorem achievable_one {c : ℕ} (hc : 0 < c) : Achievable 1 0 c 0 (Nat.clog 2 c) := by refine ⟨Fin c, inferInstance, ⟨⟨0, hc⟩⟩, trivialCounter c hc, ?_, ?_⟩ · simpa using Nat.le_pow_clog (by norm_num) c · intro F hF x hx have hF0 : F = ∅ := Finset.card_eq_zero.1 (Nat.le_zero.1 hF) subst hF0 refine ⟨x 0 0, fun r i _ => ?_⟩ have hi : i = 0 := Subsingleton.elim _ _ subst hi induction r with | zero => simp [trivialCounter, Nat.mod_eq_of_lt (x 0 0).isLt] | succ r ih => obtain ⟨m, hm, hstep⟩ := hx r 0 (Finset.notMem_empty _) have h0 := hm 0 (Finset.notMem_empty _) simp only [trivialCounter, zero_add] at ih ⊢ rw [hstep] simp only [trivialCounter, h0, ih] rw [← add_assoc, Nat.mod_add_mod] /-! ### Corollary 1: optimal resilience -/ /-- Corollary 1 (exact form): for `f ≥ 1` and `C > 1` there is an `f`-resilient `C`-counter on `3f + 1` nodes.
