For `n = 1`, `f = 0`, `k = 3` the hypotheses allow `F = 1 < 2 = (f+1)⌈3/2⌉`, i.e. a `1`-resilient counter on `N = 3` nodes, which does not exist (`Cslib.Byzantine.SyncCounting.not_isCounter_of_card_eq_three`).
