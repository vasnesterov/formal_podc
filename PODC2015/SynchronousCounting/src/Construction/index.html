import Mathlib import Cslib.Computability.Distributed.Byzantine.SyncCounting.Model import Papers.PODC2015.SynchronousCounting.Params import Papers.PODC2015.SynchronousCounting.Majority import Papers.PODC2015.SynchronousCounting.PhaseKing import Papers.PODC2015.SynchronousCounting.Pointers /-! # The boosted counter `B` of Theorem 1 (§3.2–§3.5) Nodes are pairs `(i, j) ∈ [k] × [n]` (node `j` of block `i`). The state of a node is `(x, a, d)`: a state `x` of the base counter `A` (run inside the node's block), the phase-king output register `a ∈ [C] ∪ {∞}` and the bit `d`. In every round node `v = (i, j)`, on the received state vector `msg`, 1. updates the `A`-state of its block: `x ← g_A(j, (msg (i, j')).x)_{j'}`; 2. computes the leader pointers `b_{i'} = majority {b[i', j'] | j'}`, the leader block `B = majority {b_{i'} | i'}` and its round counter `R = majority {r[B, j'] | j'}`; 3. executes the instruction set `I_R` of the phase king (instruction `R mod 3`, king `⌊R/3⌋`). The output is `a` (and `0` when `a = ∞`, which the paper leaves unspecified).
