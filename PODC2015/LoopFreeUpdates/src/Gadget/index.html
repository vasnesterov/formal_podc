import Papers.PODC2015.LoopFreeUpdates.Rounds /-! # The reduction of §3.2 is wrong: the variable gadgets always contain a cycle §3.2.2 replaces every variable `x` of the 3-SAT formula by copies `x₀, …, x_{pₓ}, x_l` and `x̄₀, …, x̄_{nₓ}, x̄_l` with *assignment* clauses `(x₀ ∨ x̄₀)`, *implication* clauses `xᵢ → xᵢ₊₁` (the last one `x_{pₓ} → x_l`) and an *exclusive* clause `(¬x_l ∨ ¬x̄_l)`. §3.2.3 turns every clause into a gadget: every copy is an `FF` node (white), updated in round 1 iff the copy is true; `BB` nodes (black) must be updated in round 2; helper nodes (grey) are of type `B·` and keep their old rule in round 2. * clause gadget: a vertical solid path `v₂ᴷ, …literal blocks…, v₁ᴷ` with the backward dashed edge `v₁ᴷ ⇢ v₂ᴷ`; * implication `xᵢ → xᵢ₊₁`: dashed `xᵢ ⇢ xᵢ₊₁^IN`, solid `xᵢ₊₁^IN → xᵢ₊₁ → xᵢ₊₁^BB`, dashed `xᵢ₊₁^BB ⇢ xᵢ^H`, solid `xᵢ^H → xᵢ^IN → xᵢ` (the block of a copy is `x^H, x^IN, x, x^BB` bottom-up); * exclusive clause: four solid paths; dashed `x̄_l ⇢ v₁`, `x_l ⇢ v₃`, solid `v₁ → v₂`, `v₃ → v₄`, dashed `v₂ ⇢ x_l^H`, `v₄ ⇢ x̄_l^H`. Theorem 2 of the paper claims that a satisfying assignment gives a cycle-free second round. It does not: whatever the assignment, the gadgets of a single variable contain a second-round cycle. For `x` true the cycle is the *ring* `x₀ ⇢ x₁^IN → x₁ ⇢ x_l^IN → x_l ⇢ v₃ → v₄ ⇢ x̄_l^H → x̄_l^IN → x̄_l → x̄_l^BB ⇢ x̄₀^H → x̄₀ → v₁ᴬ ⇢ v₂ᴬ → x₀^H → x₀` (true copies forward along dashed edges, the exclusive gadget, false copies backward along the implication `BB` edges, the assignment clause back to `x₀`); every other choice violates a clause and closes one of the paper's own cycles (`gadget_cycle`). The only unspecified detail is the order of the two blocks on the assignment path; both orders are covered (`o : Bool`).
