import Papers.PODC2015.AnonymousDynamicCounting.Kernel /-! # Dynamic bipartite labelled `k`-multigraphs `M(DBL_k)` (Section 4.1) and the lower bound (4.2) Di Luna, Baldoni, *Investigating the Cost of Anonymity on Dynamic Networks* (PODC 2015 brief announcement; full version arXiv:1505.03509v1). **Model.** Synchronous rounds `0, 1, 2, …`. A leader `v_l` and a finite set `W` of anonymous nodes. In round `r` the adversary joins every `w ∈ W` to the leader by between `1` and `k` edges with pairwise different labels in `{1, …, k}`; since parallel edges carry different labels, this is just a nonempty label set `L r w ⊆ Fin k` (`DBL`). Every process broadcasts one message per round (unbounded size) on all its edges and receives, with each message, the label of the edge it came over. A deterministic algorithm (`DAlgo`) consists of an initial state of the leader, a common initial state of all other nodes, a message function, a transition function from the state and the multiset of received `(label, message)` pairs, and the leader's output. The leader *counts* if its first output is `|W|` (Definition 2: it outputs `|W|` and terminates). **Leader's knowledge.** `hist M w t` is the node state `S(w, t)` of Definition 6 (the list of label sets of rounds `0, …, t-1`) and `view M t` is the multiset `C(v_l, t)` of Definition 7 (the pairs `(j, S(w, t))` with `j ∈ L t w`). `leader_eq_of_view_eq`: if two multigraphs give the same views in rounds `< t`, every algorithm has the same leader state after `t` rounds; `fullInfo` is an algorithm whose leader state is exactly `S(v_l, t) = [C(v_l, 0), …, C(v_l, t-1)]`. **Results.** * `lemma_5`: for `3^t ≤ 2n + 1` there are `M, M' ∈ M(DBL₂)` (`⊆ M(DBL_k)`, `k ≥ 2`) with `n` and `n + 1` nodes that no algorithm distinguishes during the first `t` rounds. * `lemma_5_sharp`: if `3^t > 2n + 1`, *any* two multigraphs of `M(DBL₂)` of sizes `n` and `n + 1` give different leader states `S(v_l, t)` — Lemma 5 is tight, and its printed bound `r ≤ ⌊log₃(2n+1)⌋` is off by one in the paper's own round indexing (`lemma_5_paper_indexing_false`). * `theorem_1`: every counting algorithm for `M(DBL_k)` (`k ≥ 2`) whose leader outputs by round `f |W|` has `2|W| + 1 < 3^(f |W|)`, i.e. `f |W| > log₃(2|W| + 1)`. -/ namespace Podc.AnonymousDynamicCounting /-- A dynamic bipartite labelled `k`-multigraph `M ∈ M(DBL_k)`: in round `r` node `w ∈ W` is joined to the leader by edges with the (nonempty) set of labels `L r w`. -/ structure DBL (k : ℕ) where /-- The non-leader nodes. -/ W : Type [fintype : Fintype W] /-- The labels of the edges between `w` and the leader in round `r`. -/ L : ℕ → W → Finset (Fin k) nonempty : ∀ r w, (L r w).Nonempty attribute [instance] DBL.fintype /-- `|W|`, the quantity the leader has to count. -/ def DBL.size {k : ℕ} (M : DBL k) : ℕ := Fintype.card M.W /-- A deterministic algorithm for `M(DBL_k)`: all non-leader nodes run the same code from the same initial state; the leader starts from its own state.
