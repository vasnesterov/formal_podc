import Papers.PODC2015.CrashConsensusDigraph.Graph /-! # Synchronous crash-prone message passing on a directed graph The system model of Sections 1.2 and 2 of Tseng–Vaidya (PODC 2015). * Nodes `V` (finite), static communication digraph `G`: `u` can send to `w` iff `G.Adj u w`. Links are reliable. Every node knows `G` and its own identity (the algorithm may depend on both). * A deterministic synchronous algorithm (`Algorithm V I M S O`): local state `S`, initial state from the input, in each round `r = 0, 1, …` node `u` sends `send u s w` (or nothing) to every out-neighbour `w`, then computes its new state from its old state and its *inbox* (`V → Option M`: the message received from each in-neighbour, if any). `out u s` is the (optional) output; the first output is the node's decision. * Crash faults (`Adversary`): `crash u = some c` means that `u` crashes in round `c`: it behaves correctly in rounds `< c`, in round `c` its message reaches only the out-neighbours `w` with `part u w` (an arbitrary subset), and from round `c + 1` on it sends nothing. At most `f` nodes crash (`Admissible`). The crash pattern is arbitrary (it may depend on the inputs). * `SolvesOn G f In alg` — *crash consensus* for inputs in `In`: for every admissible adversary and all inputs in `In`, every fault-free node decides (termination), fault-free nodes decide the same value (agreement), and every decision of a fault-free node is the input of some node (validity).
