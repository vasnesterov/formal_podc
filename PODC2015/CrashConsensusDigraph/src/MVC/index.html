import Papers.PODC2015.CrashConsensusDigraph.MinMax /-! # Algorithm MVC (multi-valued consensus): Theorem 4 Algorithm MVC of Section 2.3 for inputs in `[0, K]`. Every node keeps a tentative value `tᵢ` (initially its input) and a bit `vᵢ`. OUTER-LOOP `l = 0, …, K`: * STEP I: `vᵢ := 0` if `tᵢ = l`, else `vᵢ := 1`; * STEP II (INNER-LOOP = Min-Max with `2f + 2` phases of `D` rounds): broadcast `(vᵢ, tᵢ)`; with `Bᵢ` the received tuples (including one's own), set `vᵢ` to the max (odd phases) or min (even phases) of the first components, and if some received second component exceeds `l`, set `tᵢ` to the least such component; * STEP III: if `vᵢ = 0`, exit the OUTER-LOOP and output `l`. If the loop is never exited, output `K`. Encoding (`mvc f D K`): rounds are grouped into blocks of `blk f D = (2f + 2)·D + 1` rounds. Round `blk·l` is a *local* round (messages ignored): it performs STEP III of iteration `l − 1` (for `l ≥ 1`; at `l = K + 1` the output `K` after the loop) and STEP I of iteration `l`. Rounds `blk·l + 1 + j`, `j < (2f + 2)·D`, are the INNER-LOOP rounds of iteration `l`. `false` encodes `vᵢ = 0`. The first output is the decision; afterwards a node keeps running, which is harmless. **Theorem 4** (`theorem4`): MVC solves crash consensus for inputs in `[0, K]` in every graph with `f` CT node connectivity (and every `D` bounding the fault-tolerant diameter). The proof follows Appendix A: Claim 2 (all non-crashed nodes have the same `v` at the end of each INNER-LOOP) is `minmax_core`; Lemma 3 (`vᵢ = 1 ⇒ tᵢ > l` during iteration `l`) is `inv_iteration`; Claim 5 (`tᵢ` is always an input) is `t_input`; Claim 6 (exit at `l` ⇒ some node had `tⱼ = l` at the start of the iteration) is the first case of the validity proof. The paper's Lemma 4 case "no node exits the OUTER-LOOP" (output `K`) is shown to be impossible: by Lemma 3, all non-crashed nodes would have `tᵢ > K`, but `tᵢ` is an input `≤ K`. -/ open Finset
