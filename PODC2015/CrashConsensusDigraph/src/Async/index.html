import Cslib.Computability.Distributed.ApproxConsensus.Async.Replay import Cslib.Computability.Distributed.ApproxConsensus.DigraphConditions import Mathlib /-! # Asynchronous approximate consensus with crash faults: Theorem 6 and Lemma 1 Section 4. We use the asynchronous message-passing model on digraphs of `Cslib/Computability/Distributed/ApproxConsensus/Async/Model.lean` (event-driven deterministic algorithms, reliable FIFO links with adversarial finite delays, fairness = every non-empty link between correct nodes is eventually served, irrevocable outputs). * `CrashSolvesOn I A G f ε` — asynchronous approximate consensus tolerating `f` *initially dead* nodes: for every set `B` of at most `f` nodes that never take a step (crashed before the start), all inputs in `I`, and every event sequence without Byzantine events, outputs of fault-free nodes are within `ε` (ε-agreement), every output lies between two inputs (validity w.r.t. *all* inputs, as in the paper), and in fair executions every fault-free node outputs (termination). Initially dead nodes are a special case of crash faults, so an algorithm tolerating `f` crashes satisfies this; the impossibility below therefore holds for crash faults a fortiori. * **Theorem 6** (`theorem6`): if such an algorithm exists (for an input range containing two values more than `ε` apart), then for every partition `L, C, R` of `V` with `L, R ≠ ∅`, `L ∪ C → R` or `C ∪ R → L` (`f + 1` distinct nodes with edges into the other side). This is condition CCA (`Cslib.ApproxConsensus.CCA`), equivalent to 2-reach (`cca_iff_twoReach`). * **Lemma 1** (`lemma1`): under the condition of Theorem 6, `reachᵢ(Fᵢ) ∩ reachⱼ(Fⱼ) ≠ ∅` for all `Fᵢ ∌ i`, `Fⱼ ∌ j` of size `≤ f` — the key lemma of the sketched proof of Theorem 7. The paper's proof of Theorem 6 is the classical "nodes in `L` cannot wait for `O(L)`" argument; we make it precise by replaying executions (`exists_replay₂`, built on `sim_phase`): the nodes of `O(R)` (resp. `O(L)`) are initially dead in two auxiliary executions with all inputs `a` (resp. `b`), and their deliveries into `reach_v(·)` are replayed in one failure-free execution with mixed inputs. -/ open Finset set_option linter.unusedSectionVars false namespace CrashConsensusDigraph open Cslib.ApproxConsensus Cslib.ApproxConsensus.Async variable {V M S : Type*} [DecidableEq V] {A : Algorithm V M S} {G : Digraph V} [DecidableRel G.Adj] /-- **Asynchronous approximate crash consensus** (Section 4) for inputs in `I`, tolerating up to `f` initially dead nodes. -/ def CrashSolvesOn (I : Set ℝ) (A : Algorithm V M S) (G : Digraph V) [DecidableRel G.Adj] (f : ℕ) (ε : ℝ) : Prop := ∀ B : Finset V, B.card ≤ f → ∀ (inp : V → ℝ), (∀ w, inp w ∈ I) → ∀ (ev : ℕ → Event V M), (∀ t x y m, ev t ≠ .byz x y m) → -- ε-agreement (∀ t v u y z, v ∉ B → u ∉ B → (run A G B inp ev t).dec v = some y → (run A G B inp ev t).dec u = some z → |y - z| ≤ ε) ∧ -- validity: in the convex hull of all inputs (∀ t v y, v ∉ B → (run A G B inp ev t).dec v = some y → (∃ w, inp w ≤ y) ∧ ∃ w, y ≤ inp w) ∧ -- termination (Fair A G B inp ev → ∀ v ∉ B, ∃ t y, (run A G B inp ev t).dec v = some y) /-- Necessity of 2-reach for asynchronous approximate crash consensus. -/ theorem twoReach_of_crashSolvesOn [Fintype V] {f : ℕ} {ε : ℝ} {I : Set ℝ} {a b : ℝ} (ha : a ∈ I) (hb : b ∈ I) (hab : ε < b - a) (hA : CrashSolvesOn I A G f ε) : TwoReach G f := by classical intro Fu Fv u v hFu hFv hu hv by_contra hcon push Not at hcon set Rv : Finset V := univ.filter fun w => Reaches G Fv w v set Ru : Finset V := univ.filter fun w => Reaches G Fu w u have hdis : Disjoint Rv Ru := disjoint_left.mpr fun w h1 h2 => by simp only [Rv, Ru, mem_filter, mem_univ, true_and] at h1 h2;
