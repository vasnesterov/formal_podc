import Papers.PODC2015.CrashConsensusDigraph.Async /-! # Asynchronous crash-prone message passing on a digraph (crashes at arbitrary times) The model of Section 4 with general crash faults. We reuse the asynchronous model of `Cslib/Computability/Distributed/ApproxConsensus/Async/Model.lean` (deterministic event-driven algorithms, reliable FIFO links with adversarial finite delays, irrevocable outputs) with a *time-varying* set of crashed nodes: * a crash schedule `ct : V → Option ℕ`: `ct x = some c` means that `x` crashes at time `c`; `crashedAt ct t` is the set of nodes crashed at time `t`. Step `t` of the execution is the PODC 2020 step with faulty set `crashedAt ct t`: a crashed node takes no step (it processes no message, hence sends nothing new), messages to crashed nodes are dropped, but messages a node sent before crashing stay in the channels and may (or may not) be delivered. Since fairness is only required for links between nodes that never crash, this covers crashes in the middle of a broadcast. A node with `ct x = some 0` never starts (initially dead). * Event sequences contain no Byzantine events (`.byz`). * `FairC`: on every link between nodes that never crash, a non-empty channel is eventually served. * `CrashSolvesGenOn I A G f ε`: for every crash schedule with at most `f` faulty nodes, all inputs in `I` and every event sequence: ε-agreement and validity (outputs in the convex hull of all inputs) for the nodes that never crash, and termination in fair executions. `crashSolvesOn_of_gen`: this specializes to the initially-dead model `CrashSolvesOn` of `Async.lean` (constant schedule), so Theorem 6 holds in this model too (`theorem6_gen`). -/ open Finset set_option linter.unusedSectionVars false -- CSLib candidate (asynchronous crash-prone message passing on digraphs)
