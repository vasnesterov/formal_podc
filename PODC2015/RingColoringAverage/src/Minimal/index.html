import Papers.PODC2015.RingColoringAverage.Model /-! # Existence of minimal algorithms [Feuilloley, *Brief Announcement: Average Complexity for the LOCAL Model*, PODC 2015], §3, says "without loss of generality we prove the theorem only for minimal algorithms" without further argument. This file supplies the missing existence argument: every valid algorithm `A` (with a finite set of colours) has a minimal valid algorithm `B` below it, i.e. `B` uses at most the radius of `A` at every node of every ring (`Alg.exists_isMinimal_le`). The proof is by Zorn's lemma on radius functions `IdRing → ℤ → ℕ` (pointwise order). The key step is that a nonempty chain of radius functions of valid algorithms has a lower bound realised by a valid algorithm (`exists_valid_le_of_isChain`): * the new algorithm stops on a view `f` at the least radius at which some algorithm of the chain stops on `f` (`MinimalAux.chainAlg`); at ring nodes this is the pointwise infimum of the chain; * its output at radius `t` is `col (t, f|[-t,t])` for a colour table `col`; a table making the colouring proper exists by compactness (Tychonoff on `ℕ × (ℤ → ℕ) → C` with `C` discrete and finite): the sets of tables that are proper at all edges where a given member of the chain attains the infimum at both endpoints are closed, nonempty (use that member's own outputs) and directed, hence have a common point. -/ namespace Podc.RingColoringAverage
