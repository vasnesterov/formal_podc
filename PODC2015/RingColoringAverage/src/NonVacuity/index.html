We exhibit one, so the hypothesis is satisfiable. The algorithm `seeAll` ("see the whole ring"): at radius `r` with view `f`, a node stops as soon as it sees its own identifier again, i.e. `f p = f 0` for some `1 ≤ p ≤ r`. Then the least such `p` is the ring size `n` (`period`), and the node knows the whole ring. Let `i ∈ [0, n)` be the offset with `f (-i)` minimal among `f (-j)`, `j < n` (`minOffset`): the node is `i` steps to the right of the node with the smallest identifier. It outputs `i % 2`, except for `i = n - 1` with `n` odd, where it outputs `2` (`colourOf`). Going right, offsets increase by one modulo `n`, which makes the colouring proper.
