import Papers.PODC2015.RingColoringAverage.Model import Podc.Foundations.Combinatorics.ShiftGraph /-! # Linial's lower bound for colouring rings, in the variable-radius model Linial's `Ω(log* n)` lower bound, in the form needed for the paper's §3: for every valid colouring algorithm with colour set `C` and every set `S` of identifiers that is larger than `(2 ^ ·)^[2t] |C|`, some node of some ring with identifier set exactly `S` has radius `> t`. Proof: if all nodes of all rings with identifiers `S` stop within radius `t`, the output on the window `[-t, t]` defines a colouring of the `(2t+1)`-tuples of identifiers, and it is a proper colouring of the shift graph (two consecutive windows of a ring are adjacent nodes), so `Cslib.ShiftGraph.card_le_iterate_of_proper` bounds `|S|`. ## Main statements * `Alg.exists_lt_radAt`: the lower bound for an arbitrary colour set `C`. * `Alg.exists_lt_radAt_four`, `Alg.exists_lt_radAt_three`: the cases `C = Fin 4`, `C = Fin 3` with the bound `Nat.tower (2t + 2) < |S|`. -/ namespace
