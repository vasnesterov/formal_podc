For connected `G` this is the minimum over connected spanning subgraphs, which is the MST weight (an optimal subgraph can be chosen acyclic since weights are `≥ 0`; see `exists_isAcyclic_isSpanningSub` in `MSTTree.lean`). * `mstWeight_eq_of_forall_walk` — **exchange lemma**: if `H ≤ G` and every edge `uv` of `G` missing from `H` is bypassed in `H` by a walk of edges of weight `≤ w(uv)`, then `G` and `H` have the same MST weight (and the minimum for `G` is attained inside `H`). * `IsGreedySpanner.mstWeight_eq` — **Observation 2**: the greedy spanner `H` contains an MST of `G`, hence `w(MST(H)) = w(MST(G))` (from the shared `SimpleGraph.IsGreedySpanner.forall_walk`). -/ open Finset SimpleGraph open scoped ENNReal NNReal namespace GreedySpanner variable {V :
