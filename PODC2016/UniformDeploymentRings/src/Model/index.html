import Papers.PODC2016.UniformDeploymentRings.Defs /-! # Mobile agents with tokens in an asynchronous unidirectional ring (Section 2.1) -- CSLib candidate: Cslib/Computability/Distributed/MobileAgents/TokenRing.lean The model of [Shibata et al., PODC 2016], Section 2.1. * The ring has nodes `ZMod n`; agents move from `v` to `v + 1` only. * A node holds a number of tokens (`Local.tok`), the list of agents *staying* at it (`Local.stay`) and the FIFO queue of agents *in transit* towards it (`Local.queue`, its incoming buffer). * Agents are anonymous deterministic state machines (`Algorithm`). In one **atomic action** (`Local.act`) an agent at node `v` — either staying there or at the head of the incoming queue — receives all its messages, observes the number of tokens at `v` and the states of the other agents staying at `v`, computes, may release a token, may broadcast one message to the other agents staying at `v` (appended to their mailboxes), and then stays at `v` or leaves to the tail of the queue of `v + 1`. A halted agent (`Algorithm.halted`) never acts again. Agents carry an identifier `id` used only for the schedule; the algorithm never sees it. Observing the states of co-located agents is more than the paper grants (it only allows messages and seeing whether other agents are present), which only strengthens impossibility results and is not used by our algorithms beyond counting the agents. * A **schedule** is a sequence of agents `σ : ℕ → ι`; at time `t` agent `σ t` takes an atomic action if it can (it is staying somewhere or at the head of a queue), otherwise nothing happens (`step`, `exec`). It is **fair** if every agent appears infinitely often (`Fair`). * Initially (`initConfig`) no node has a token, all agents are in the initial state and each agent is in the incoming buffer of its home node, so it acts at its home before any other agent (the paper's assumption in Section 2.1). * `SolvesTD A n k home`: the uniform deployment problem with termination detection (Definition 1): in every fair execution all agents eventually halt, and whenever all agents are halted, no agent is in transit and the deployment is uniform. -/ namespace Podc.UniformDeploymentRings /-- The outcome of
