We prove Theorem 3 (correctness): in every fair execution from every initial configuration all agents halt, and then they are uniformly deployed (`theorem_3`). Each agent performs exactly `n + moves1 (D) < 3n` moves (`alg1_moves_lt`), so the total number of moves is `< 3kn = O(kn)`. The proof follows each agent along its (schedule-independent) trajectory `traj`: the only interaction is through tokens, and an agent reaching the home node of another agent always finds its token there, because every agent starts in the incoming buffer of its home node and links are FIFO (`Inv`, field `head`). -/ namespace Podc.UniformDeploymentRings open Function /-- States of Algorithm 1. -/ inductive A1State /-- initial state (at the home node, holding the token) -/ | init /-- selection phase: `dis` moves since the last token node, distances `D` recorded so far -/ | sel (dis : ℕ) (D : List ℕ) /-- deployment phase: `r` more moves after the current one -/ | dep (r : ℕ) /-- halt state -/ | halt deriving DecidableEq /-- One atomic action of Algorithm 1: the new state and whether the agent leaves, given whether the current node holds a token. -/ def a1next (k : ℕ) : A1State → Bool → A1State × Bool | .init, _ => (.sel 0 [], true) | .sel dis D, tk => if tk then if (D ++ [dis + 1]).length = k then if moves1 (D ++ [dis + 1]) = 0 then (.halt, false) else (.dep (moves1 (D ++ [dis + 1]) - 1), true) else (.sel 0 (D ++ [dis + 1]), true) else (.sel (dis + 1) D, true) | .dep r, _ => if r = 0 then (.halt, false) else (.dep (r - 1), true) | .halt, _ => (.halt, false) /-- Algorithm 1 for agents knowing the number `k` of agents.
