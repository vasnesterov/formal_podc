import Papers.PODC2016.UniformDeploymentRings.Defs /-! # Algorithm 1: the target nodes form a uniform deployment For a set `H` of `k ≥ 1` home nodes in the ring `ZMod n`, the agent of Algorithm 1 whose home is `h` ends its deployment phase at node `h + moves1 (distSeq H h)` (it first walks once around the ring, which adds `n ≡ 0`). We prove (Section 3.1 and 3.1.1 of the paper): * `alg1_targets` (`alg1_targets_injOn`, `alg1_targets_uniform`) : the target map `alg1Target H` is injective on `H` and its image is a uniform deployment; * `alg1_targets_injOn` : different agents choose different target nodes; * `alg1_targets_uniform` : the set of target nodes is a uniform deployment; * `moves1_lt` : the deployment phase takes fewer than `2n` moves. The proof unrolls the ring: for `h ∈ H`, `pos H h j` is the position (counted from `h` on the infinite unrolled line) of the `j`-th home node after `h`; `pos H h (j + k) = pos H h j + n`. The distance sequence of the `i`-th home node after `h` is `(distSeq H h).rotate i`. Choosing `h` with lexicographically minimal distance sequence, the rotations equal to it are exactly the multiples of the period `p`, so the agent `i` has rank `x < p` with `p ∣ i + x`, and its target is `h + (i + x) / p * N + offset x N p` where `N` is the length of a period. These targets are `h + G t`, `t < k`, for an explicit strictly increasing `G` with steps `⌊n/k⌋` or `⌈n/k⌉`. -/ namespace Podc.UniformDeploymentRings variable {n : ℕ} /-! ### Basic facts about `gap`,
