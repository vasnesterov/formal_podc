In a unidirectional ring an agent going from node `h` to node `t` makes at least `(t - h : ZMod n).val` moves (the forward distance). We consider the initial configuration in which the `k` agents occupy the block of nodes `0, 1, …, k-1` (agent `a` has home `a`), and an arbitrary assignment `f` of agents to final nodes that forms a uniform deployment. Every algorithm solving the problem from this configuration therefore makes at least `∑ a, (f a - a).val` moves in total. Main results (`T = ∑ a, (f a - a).val`, the final nodes `f a` forming a uniform deployment): * `theorem_1` : for `2 ≤ k` and `4k ≤ n`, `k·n ≤ 6·T` (the paper proves `16`); the constant `6` is optimal (`theorem_1_tight`: `n = 9`, `k = 2`). * `theorem_1_general` : for every `k ≥ 2`, `3·k·(n - k - 1)² ≤ 64·n·T`. * `theorem_1_of_le_mul` : for `p < 1`, `2 ≤ k ≤ p·n` and `(1 - p)·n ≥ 2`, `T ≥ 3(1-p)²/256 · k·n`, i.e. the paper's `Ω(kn)` for every constant `p < 1`.
