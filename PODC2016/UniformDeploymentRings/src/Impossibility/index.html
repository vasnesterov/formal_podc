Fix an algorithm `A` (the same for all rings: the agents know neither `k` nor `n`) and assume it solves the problem with termination detection in every ring. In the ring `R` with `n = 2` nodes and `k = 2` agents (one per node), the round-robin execution reaches a configuration at some time `T` where both agents are halted, one at each node. Consider the ring `R'` with `N = 4(q+1)` nodes, `q = T`, and `K = 2(q+1)` agents on the nodes `0, …, 2q+1`. We replay the execution of `R` in `R'`: every atomic action at node `v` of `R` is performed at every node `j ≡ v (mod 2)` of `R'` in the *window* `[t, 2(q+1))`, which shrinks by one node per step since only the node `0` of `R'` lacks a predecessor behaving as in `R` (Lemma 1 of the paper). At time `T` the nodes `2q` and `2q+1` of `R'` look like the two nodes of `R`: each holds a halted agent. Halted agents never move, but in `R'` uniform deployment requires the agents to be exactly `N / K = 2` apart — a contradiction.
