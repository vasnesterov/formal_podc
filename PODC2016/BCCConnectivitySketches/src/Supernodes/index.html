import Papers.PODC2016.BCCConnectivitySketches.Model /-! # Theorem 1: connectivity in `⌈1/ε⌉` rounds of `BClique[n^ε log n]` by merging supernodes Montealegre–Todinca, *Deterministic graph connectivity in the broadcast congested clique* (PODC 2016 BA; arXiv:1602.04095v3), Theorem 1. Protocol (`Supernodes.alg k`). Every node stores its input `N(v)` and the *announced graph* `A_t` (all edges broadcast so far; the same at every node). The supernodes of round `t` are the connected components of `A_t`. In round `t`, node `u` broadcasts `sel k A_t N(u) u`: neighbours lying in pairwise different components of `A_t`, none in `u`'s own component, `min(k, #foreign components adjacent to u)` of them. Then `A_{t+1} = A_t ⊔ {uw | w announced by u}`. A message is a set of at most `k` nodes, i.e. `k ⌈log₂(n+1)⌉` bits. Analysis. Call a component of `A_t` *open* if some edge of `G` leaves it (`IsOpenComp`). Since `A_t ≤ G`, a closed component is a component of `G` and never grows. Every open component of `A_{t+1}` contains at least `k+1` open components of `A_t` (`exists_fiber`), so `o_t (k+1)^t ≤ n` for the number `o_t` of open components (`card_openComps_mul_pow_le`). Once `n < (k+1)^T`, `A_T` has no open component, i.e. it has the same connected components as `G`, and every node outputs a spanning forest of `A_T` (`isSpanningForest_run`). The paper uses `k = n^ε`; with `k = ⌈n^ε⌉₊` and `T = ⌈1/ε⌉₊` we have `n ≤ k^T < (k+1)^T` (`theorem_1`). Remark on the paper's termination criterion. The proof sketch says that a supernode of round `t` is *active* if it contains at least `n^ε` supernodes of round `t-1`, and that the protocol stops when all supernodes are inactive. Taken literally, this test can need one round more than `⌈1/ε⌉`: for `ε = 1` and connected `G` the single supernode after round 1 contains `n ≥ n^ε` supernodes of round 0 and so is "active". The fixed-round protocol formalized here needs no termination test (nodes simply output after `⌈1/ε⌉` rounds), so Theorem 1 as stated holds. -/ namespace Podc.BCCConnectivitySketches open
