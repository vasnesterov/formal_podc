Protocol (Theorem 2): node `i` broadcasts `(dᵢ, f(aᵢ))` (its degree and the sketch of its row, Lemma 1). Every node then peels locally: it picks the least remaining node `k` whose current degree is `≤ d`, recovers `k`'s current neighbourhood from its current sketch (injectivity on `d`-sparse Boolean vectors), removes `k`, and updates the degrees and sketches of `k`'s neighbours (`(M¹ⱼ − 1, M²ⱼ − f(e_k))`, linearity). This is `peelStep`; after `n` steps nothing changes. Output: the pruning sequence and the set of edges incident to it (`theorem_2`). The message has `⌈log₂((n+1)·p)⌉ ≤ (2d+2)⌈log₂(n+1)⌉ + 1` bits (`pruneBits_le`). For `d`-degenerate graphs the sequence is the whole vertex set and the whole graph is reconstructed (`reconstruct_degenerate`). -/ namespace Podc.BCCConnectivitySketches open Finset
