import Mathlib.Data.Fintype.Card import Mathlib.Data.Fintype.Pi import Mathlib.Logic.Function.Basic /-! # The algorithm family `A_f` of Hendler (PODC 2016), Section 4 — a concrete step model We model Algorithm 1 ("Pseudo-code for reader-writer algorithm `A_f`") of D. Hendler, *On the Complexity of Reader-Writer Locks*, PODC 2016, as a deterministic interleaving transition system. ## Model * **Asynchronous shared memory, no failures.** A configuration is a `State`; a step is taken by a single process chosen by the scheduler (`Who`), and every step performs at most one shared-memory access, exactly as in the pseudo-code. The scheduler is arbitrary (`Reachable` quantifies over all interleavings). * **Shared objects.** `C[i]`, `W[i]` are counters with atomic `add` and `read` (as the paper assumes, line 1); `WSIG[i]` and `RSIG` are read/write/CAS registers holding pairs `(sequence number, tag)`. * **One writer.** The writers' lock `WL` (lines 6, 27) only provides mutual exclusion among writers (Observation 4); with a single writer it is a no-op and is omitted. Consequently `WSEQ` (line 3) is only accessed by the writer and is kept as a writer-local copy `wseq`. * **Groups.** Line 30 assigns reader `p` to group `⌊p/f(n)⌋` (the intended group is `⌊p/K⌋`, `K = ⌈n/f(n)⌉`). We allow an arbitrary static partition `grp : Fin n → Fin G` into `G = f(n)` groups, which covers both. * **Variants.** Two lines of the paper are parameters: - `ReadOrder` — the evaluation order of the two reads in line 51 (`if C[i].read() = W[i].read()`): `cw` (literal, left to right: `C` first) or `wc` (`W` first, the repaired version); - `Line47` — line 47 reads `else if op = WAIT` (`op`, literal: the opcode read in line 32 of the entry section) or `else if op' = WAIT` (`op'`, the opcode read in line 41; intended). * **Program counters.** `pc = cs` means "in the critical section"; the step taken from `cs` executes the first line of the exit section (line 25 for the writer, line 40 for a reader). The step taken from `rem` starts a passage (no memory access). Line 51 is split in two steps `l51a` / `l51b` (two reads); `ret36` records whether `HelpWCS` was called from line 35 (then it returns to line 36) or from line 48 (then the passage ends). -/ namespace
