import Papers.PODC2016.RWLockRMRTradeoff.Awareness /-! # Lemma 2: one step of every poised process at most triples the awareness sets Given a fragment `C ↪ E` and a set `T` of processes, each poised to access a register, the steps of `T` can be ordered (each process exactly once) so that `max_p |AW(p)|` grows at most by a factor 3. We schedule greedily: as long as some remaining step is not a value-changing CAS (w.r.t. the *current* value of its register), take it; otherwise take any remaining step. This keeps every familiarity set of size `≤ M`, or of size `≤ 2M` with all remaining CAS steps on that register bound to fail; so a reading step adds at most `2M` processes to an awareness set of size `≤ M`. The paper's proof (reads and trivial steps, then writes, then CAS) claims in its case 1 that after the writes "the value differs from the expected parameter of all CAS steps", which is false (a write may restore the expected value); the bound still holds because at most one of the CAS steps on a register succeeds.
