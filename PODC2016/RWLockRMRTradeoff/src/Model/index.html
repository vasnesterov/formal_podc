import Cslib.Computability.Distributed.SharedMemory.Mutex import Mathlib.Data.Fintype.Sum import Mathlib.Data.Finset.Lattice.Fold /-! # The model of Hendler, *On the Complexity of Reader-Writer Locks* (PODC 2016) * **Shared memory.** Asynchronous shared memory; processes are deterministic and communicate through registers supporting `read`, `write` and `CAS` (`rwcas`): `CAS(v, a, b)` sets `v` to `b` iff its value is `a`, and (as in the paper) returns the value of `v` before the step. Reader-writer lock algorithms are CSLib implementations (`Impl`) of the lock object `mutexObj` (operations `lock` / `unlock`) from such registers. Region bookkeeping (remainder, entry = `trying`, critical section, exit = `exiting`) is CSLib's `regionOf`. * **Processes.** `Proc n m = Fin n ⊕ Fin m`: readers `Sum.inl i`, writers `Sum.inr j`. * **Knowledge** (`Know`, `kstep`): the awareness sets `AW(p, C ↪ E)` and familiarity sets `F(v, C ↪ E)` of Definitions 1–2 of the paper, computed forward along an execution fragment (a *trivial* step, i.e. one that does not change the value of its register, never changes a familiarity set). * **Cache-coherent RMRs** (`CacheModel`): an abstract CC cache with three axioms; the write-back (`writeBack`) and write-through (`writeThrough`) protocols quoted in the paper are instances. * **Augmented runs** (`Ext`, `xrun`): configuration, knowledge and cache state together; `xcount` counts labels with a given property along a run. -/ namespace Podc.RWLockRMRTradeoff open Cslib.SharedMemory /-!
