Registers: `none` is the writer flag `W`, `some i` the flag of reader `i`; all initially `0`. * Reader `i`, `lock`: `r0` write `flag[i] := 1`; `r1` read `W`: if `0` enter the CS, else go to `r2`; `r2` write `flag[i] := 0`; `r3` read `W`: if `0` go to `r0`, else stay at `r3`. `unlock`: `rExit` write `flag[i] := 0`, return. * Writer, `lock`: `w0` write `W := 1`; then for `k = 0, …, n-1` (`wScan k`): read `flag[k]` until it is `0`; enter the CS. `unlock`: `wExit` write `W := 0`, return. A process returns from `lock` in local state `cs` and from `unlock` in local state `rem`.
