import Papers.PODC2016.MobileByzantineStorage.Model /-! # Lower bounds for a `2δ`-type read in the `(ΔS, CAM)` model (Theorems 3 and 5, repaired) Section 4.4 proves the lower bounds by exhibiting two executions `E₁` (register value `1`) and `E₀` (value `0`) of a read with no concurrent write in which "the reader collects the same set of replies". In the paper's executions the agents follow the *same* schedule, so the reader receives, e.g., `1` from `s₀` in `E₁` and `0` from `s₀` in `E₀`: only the multisets of values coincide, while communication is authenticated (Section 2) and the reader knows who sent what. We repair the argument: the two executions use different schedules, and the reader's whole view — the set of triples (sender, value, delivery time) — is the same. The model is the paper's lower-bound scenario (Section 4.4), with the paper's assumptions on correct servers and the most general adversary allowed by the system model: * the read is invoked at time `t`; the request reaches every server `s` at a time `req s ∈ (t, t+δ]`; * a server that is *correct* (neither faulty nor cured) when the request arrives replies once, with the register value, delay `dly s ∈ (0, δ]`; a faulty or cured server does not reply (the paper: "each cured server (in the CAM model) does not reply as long as it is cured"); a server is *cured* during `γ` time after its agent left (the constructions never use this: the silent servers are faulty when the request reaches them, so the results hold for every `γ`); * faulty servers send arbitrary replies (sender, value, sending time while faulty, delay in `(0, δ]`). `theorem3` (`n ≤ 5f`, `δ ≤ Δ < 2δ`) and `theorem5` (`n ≤ 4f`, `2δ ≤ Δ < 3δ`) hold for every read duration `D`, for every `γ`, and for every decision rule of the reader. Since correct servers reply only once, the views are equal as sets of all messages, so the duration does not matter; this is the paper's "waiting more does not bring any new way to break symmetry",
