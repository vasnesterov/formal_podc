import Papers.PODC2016.MobileByzantineStorage.Model /-! # The read operations of the paper's protocols can be fooled (Theorems 8/9 and 11/12 are false) The `read()` of the `(ΔS, CAM)` protocol (Fig. 24) broadcasts `read(i)`, waits `2δ`, and returns the pair chosen by `select_value(reply_i)`: among the pairs `⟨v, sn⟩` that occur (from distinct servers) at least `#reply_CAM` times in the set `reply_i` of triples `⟨j, ⟨v, sn⟩⟩` received during the wait, the one with the highest sequence number (Section 5.1). The `(ΔS, CUM)` read (Fig. 27) is the same with a `3δ` wait and threshold `#reply_CUM`. The paper bounds the number of servers that can send a wrong reply during a read `[t, t+2δ]` by `MaxB̃(t, t+2δ)`, "as if each message to/from them is delivered instantaneously" (Section 5.2). But a message sent by a faulty server at a time `τ ∈ (t - δ, t)` can be delivered at any time of `(τ, τ + δ]`, hence *during* the read. Counting these servers too, the adversary gets up to `(⌈3δ/Δ⌉ + 1) f` distinct liars against a CAM read, which reaches `#reply_CAM = (k+1) f + 1` for `2δ ≤ Δ < 3δ` (`k = 1`: `3f` liars) and for `δ ≤ Δ < 3δ/2` (`k = 2`: `4f` liars). They all report the same never-written pair with a sequence number larger than any written one, so `select_value` returns it. Model of a read (only what the counterexample needs): * `Reply`: a `reply` message to the reader, with its sender, sending time, delay and the set of pairs it carries; `collected M t D` is `reply_i` at the end of a read invoked at `t` that waits `D` (messages delivered in `(t, t + D]`); * `SelectValue thr R p`: `p` is a possible result of `select_value` (any tie-breaking); * `Schedule.ByzReply`: a reply that a faulty server may send (it is faulty at the sending time, and the delay is in `(0, δ]` as for every message of the round-free synchronous model, Section 2). The replies of the non-faulty servers are arbitrary (universally quantified); we only assume their sequence numbers are at most `N`, the number of writes so far. This holds in the counterexample executions because the faulty servers send nothing to the servers, so non-faulty servers only ever store written pairs (and `⟨⊥, 0⟩`). -/ namespace
