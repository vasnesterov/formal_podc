An infinite execution is a sequence `f : ℕ → Act Rep Op`; its finite prefixes are `pre f m` (`Encoding.lean`). It is well formed (`InfWF`) iff all its prefixes are. The history of `do` events and the visibility relation (happens-before) of the infinite execution are read off long enough prefixes (`histInf`, `visInf`); both are prefix-stable. * `SufficientlyConnected` is Definition 1 (eventual transmission, eventual delivery). * `RGA.theorem1_strong_inf`: the abstract execution `(histInf, visInf)` of every infinite execution of RGA with causal broadcast (and the user assumptions) is in `A_strong`, with one global list order: `lo a b` iff `[a, b]` is a subsequence of `s(Nall)` of some prefix (consistent by Lemma 6). * `RGA.theorem1_eventualVisibility`: if moreover the network is sufficiently connected, this abstract execution satisfies eventual visibility (Definition 9). This is Theorem 1, liveness part. * `RGA.def10_needs_connectivity`: Definition 10 as literally stated quantifies over *all* executions with causal broadcast, without the connectivity assumption of Definition 1; then no protocol that ever buffers messages guarantees eventual visibility. For RGA: replica 0 inserts and never sends, replica 1 reads forever; no abstract execution in `A_weak` with eventual visibility complies with it.
