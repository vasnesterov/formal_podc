import Papers.PODC2016.CollaborativeListSpec.Model /-! # Abstract executions and the list specifications (Section 3) * `AbsWF h vis` is Definition 4 (causal abstract execution) for the `do` events `h` of an execution, identified by their positions (the paper instruments events with unique ids; the execution and its abstract execution share them, which is how compliance, Definition 5, is built in). We do not require the linearization `H` itself: for finite executions an acyclic transitive `vis` containing the replica order always has one (a topological sort). On the hypothesis side (lower bound) this only makes the hypothesis weaker; on the conclusion side (RGA) we use `vis ⊆ <`, so `H` = the order of the execution works. * `ListCond`, `Strong`, `Weak` are Definitions 7 and 8; `EventualVisibility` is Definition 9. * `Satisfies` is Definition 6, relative to a class `Adm` of admitted executions (causal broadcast, user assumptions). `UserOK` collects the user assumptions of Section 3: inserted elements are unique, deleted elements occur in the response of the preceding operation of the same replica. * `PushBased` is Definition 13. -/ namespace Podc.CollaborativeListSpec /-- The list operations of Section 3. -/ inductive LOp (U : Type) where | ins (a : U) (k : ℕ) | del (a : U) | read deriving DecidableEq /-- `≤vis`. -/ def VisLe (vis : ℕ → ℕ → Prop) (i j : ℕ) : Prop := i = j ∨ vis i j /-- **Definition 4** (causal abstract execution), on positions. -/ structure AbsWF {Rep Op Val : Type} (h : ℕ → Option (Rep × Op × Val)) (vis : ℕ → ℕ → Prop) : Prop where dom : ∀ i j, vis i j → (h i).isSome ∧ (h j).isSome ro : ∀ i j a b, i < j → h i = some a → h j = some b → a.1 = b.1 → vis i j trans : ∀ i j k, vis i j → vis j k → vis i k irrefl : ∀ i, ¬ vis i i section Spec variable {Rep U : Type} (h : ℕ → Option (Rep × LOp U × List U)) (vis : ℕ → ℕ → Prop) /-- `elems(A)`. -/ def elems : Set U := {a | ∃ p r k w, h p = some (r, .ins a k, w)} /-- An insertion of `a` is `≤vis` the event at `p`. -/ def InsVis (p : ℕ) (a : U) : Prop := ∃ q r k w, VisLe vis q p ∧ h q = some (r, .ins a k, w) /-- A deletion of `a` is `≤vis` the event at `p`. -/ def DelVis (p : ℕ) (a : U) : Prop := ∃ q r w, VisLe vis q p ∧ h q = some (r, .del a, w) /-- Condition 1 of Definition 7. -/ def ListCond (lo : U → U → Prop) : Prop := ∀ p r op w, h p = some (r, op, w) → -- (a) (∀ a, a ∈ w ↔ InsVis h vis p a ∧ ¬ DelVis h vis p a) ∧ -- (b) w.Pairwise lo ∧ -- (c) (∀ a k, op = .ins a k → w[min k (w.length - 1)]? = some a) /-- **Definition 7** (strong list specification `A_strong`). -/ def Strong : Prop := ∃ lo : U → U → Prop, (∀ a b, lo a b → a ∈ elems h ∧ b ∈ elems h) ∧ ListCond h vis lo ∧ (∀ a b c, lo a b → lo b c → lo a c) ∧ (∀ a, ¬ lo a a) ∧ (∀ a ∈ elems h, ∀ b ∈ elems h, a ≠ b → lo a b ∨ lo b a) /-- **Definition 8** (weak list specification `A_weak`). -/ def Weak : Prop := ∃ lo : U → U → Prop, (∀ a b, lo a b → a ∈ elems h ∧ b ∈ elems h) ∧ ListCond h vis lo ∧ (∀ a, ¬ lo a a) ∧ ∀ p r op w, h p = some (r, op, w) → (∀ a ∈ w, ∀ b ∈ w, ∀ c ∈ w, lo a b → lo b c → lo a c) ∧ (∀ a ∈ w, ∀ b ∈ w, a ≠ b → lo a b ∨ lo b a) /-- **Definition 9** (eventual visibility). -/ def EventualVisibility : Prop := ∀ e r op w, h e = some (r, op, w) → op ≠ .read → {e' | (h e').isSome ∧ ¬ vis e e'}.Finite variable {h vis} theorem ListCond.mem_elems {lo : U → U → Prop} (hc : ListCond h vis lo) {p r op w} (hp : h p = some (r, op, w)) {a : U} (ha : a ∈ w) : a ∈ elems h := by obtain ⟨q, r', k, w', -, hq⟩ := (((hc p r op w hp).1 a).1 ha).1 exact ⟨q, r', k, w', hq⟩ /-- `A_strong ⊆ A_weak`. -/ theorem Strong.weak (hs : Strong h vis) : Weak h vis := by obtain ⟨lo, hdom, hc, htr, hirr, htot⟩ := hs refine ⟨lo, hdom, hc, hirr, fun p r op w hp => ⟨fun a _ b _ c _ => htr a b c, ?_⟩⟩ intro a ha b hb hab exact htot a (hc.mem_elems hp ha) b (hc.mem_elems hp hb) hab end Spec /-! ### Executions of list protocols -/ section Exec variable {Rep U Q M : Type} [DecidableEq Rep] (P : Protocol Rep (LOp U) (List U) Q M) /-- Inserted elements are unique (assumption of Section 3). -/ def UniqueIns (α : List (Act Rep (LOp U))) : Prop := ∀ (p q : ℕ) (r r' : Rep) (a : U) (k k' : ℕ), α[p]?
