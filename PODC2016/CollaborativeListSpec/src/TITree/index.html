import Mathlib /-! # Timestamped insertion trees (Section 4.1) A node `(a, t, p)` stores an element `a`, a timestamp `t` and the parent element `p` (`none` = the root `◦`). Timestamps are pairs `(x, i)` ordered lexicographically (`TS`). `s N` is the paper's read procedure: depth-first traversal from the root, parents before children, children in decreasing timestamp order. The paper defines the parent relation on a set of nodes; we represent a finite set of nodes by a list `N` (duplicates are excluded by `IsTITree.nodup`; for TI trees `s N` only depends on the set, `s_perm`). The traversal only descends to children with a larger timestamp than their parent; for TI trees this is no restriction (Definition 12 (3)), and it makes the traversal terminate on arbitrary lists. Main results: Lemma 6 (`s_sublist`: `A ⊆ B` TI trees ⇒ `s A` is a subsequence of `s B`) and the fact behind the insert procedure (`s_cons_max`: adding a node with the largest timestamp puts its element right after its parent). -/ namespace Podc.CollaborativeListSpec /-- Timestamps `(x, i)` with the lexicographic order. -/ abbrev TS := ℕ ×ₗ ℕ /-- A node `(a, t, p)` of a TI tree. -/ structure Node (U : Type) where a : U t : TS p : Option U deriving DecidableEq variable {U : Type} [DecidableEq U] /-- **Definition 12** (TI tree), for a duplicate-free list of nodes. -/ structure IsTITree (N : List (Node U)) : Prop where nodup : N.Nodup /-- (1) timestamps or symbols uniquely identify nodes. -/ uniq : ∀ n ∈ N, ∀ n' ∈ N, (n.t = n'.t ∨ n.a = n'.a) → n = n' /-- (2) all parents are present. -/ parent : ∀ n ∈ N, ∀ b, n.p = some b → ∃ n' ∈ N, n'.a = b /-- (3) parents are older than their children. -/ older : ∀ n ∈ N, ∀ n' ∈ N, n'.p = some n.a → n.t < n'.t /-- The children of `p` (with timestamp above `t`), in decreasing timestamp order. -/ def children (N : List (Node U)) (p : Option U) (t : WithBot TS) : List (Node U) := (N.filter (fun m => m.p = p ∧ t < (m.t : WithBot TS))).mergeSort (fun x y => decide (y.t ≤ x.t)) theorem mem_children {N : List (Node U)} {p : Option U} {t : WithBot TS} {m : Node U} : m ∈ children N p t ↔ m ∈ N ∧ m.p = p ∧ t < (m.t : WithBot TS) := by simp [children, List.mem_mergeSort] theorem countP_lt_countP {α : Type} {p q : α → Bool} {l : List α} {m : α} (hpq : ∀ x ∈ l, p x → q x) (hm : m ∈ l) (hq : q m) (hp : ¬ p m) : l.countP p < l.countP q := by induction l with | nil => simp at hm | cons y l ih => simp only [List.countP_cons] have h1 := List.countP_mono_left (fun x hx => hpq x (List.mem_cons_of_mem _ hx)) rcases List.mem_cons.1 hm with rfl | hm · simp [hq, hp];
