The static chopping graph `SCG(P)` has the pieces as vertices, successor/predecessor edges inside a program, and read-dependency, write-dependency and anti-dependency edges between pieces of different programs whose read and write sets intersect accordingly. A history is *produced by* `P` if its sessions correspond one-to-one to programs of `P` and the `j`-th transaction of a session only reads objects of the read set and writes objects of the write set
