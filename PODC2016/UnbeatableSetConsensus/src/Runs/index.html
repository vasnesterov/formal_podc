If `K` is alive at `M`, nothing changes before round `M + 1` (`modify_deliv_lt`); round `M + 1` is described by `modify_deliv_last`. * `chainRun r x L w u` (**Lemma 2** of the paper): given witnesses `w ℓ b` (`ℓ ≤ L`, `b ∈ ι`) hidden from `⟨x, m⟩`, the run in which `w 0 b` gets input `u b`, each `w ℓ b` (`ℓ < L`) crashes in round `ℓ + 1` sending only to `w (ℓ + 1) b` (the last column `w L b` crashes in round `L + 1` sending to nobody), and each `w ℓ b` receives in round `ℓ` exactly what `x` receives plus the message of `w (ℓ - 1) b`. Then `x` has the same view at `m` (`chainRun_sameView`), the value `u b` travels along column `b` (`chainRun_mem_vals`), the witnesses see nothing else that `x` does not see (`chainRun_vals_subset`), and the other columns stay hidden from them (`chainRun_hidden`). * `decided_mem_vals`: knowledge of preconditions for Validity — a process can only decide a value it has seen. -/ namespace
