import Papers.PODC2016.PowerLawLabeling.Defs /-! # Realizing a degree sequence around an induced subgraph (the construction of Theorem 3) The paper's Theorem 3 builds the power-law graph by greedily adding edges between "unprocessed" vertices (vertices whose degree is still below the target) in three phases. We replace every greedy loop by a *maximal* graph (`exists_maximal_fill`): among all graphs between `G₀` and `G₀ ⊔ P` respecting the degree targets, take one with the most edges; then no allowed pair of unsaturated vertices is non-adjacent. `realize`: given targets `t`, a graph `H₀` living on a set `A`, a set `B` of "middle" vertices (targets in `[1, T]`), a set `L` of leaves (target `1`), all other targets `0`, enough middle vertices and leaves, and an even target sum, there is a graph with degrees exactly `t` that induces `H₀` on `A`. The phases are: `A`–`B` edges (`bip_phase`), `B`–`B` edges (maximal fill, the remaining unsaturated `B`-vertices form a clique — the paper claims "at most one" remains, which is false in general), unsaturated `B`–`L` edges, and `L`–`L` edges; parity rules out a last unsaturated leaf. -/ namespace Podc.PowerLawLabeling open Finset SimpleGraph variable {V : Type*} [Fintype V] [DecidableEq V] /-- Allowed pairs between `X` and `Y`. -/ def bip (X Y : Finset V) : SimpleGraph V := SimpleGraph.fromRel fun a b => a ∈ X ∧ b ∈ Y /-- All pairs inside `Z`. -/ def clq (Z : Finset V) : SimpleGraph V := SimpleGraph.fromRel fun a b => a ∈ Z ∧ b ∈ Z theorem bip_adj {X Y : Finset V} {a b : V} : (bip X Y).Adj a b ↔ a ≠ b ∧ (a ∈ X ∧ b ∈ Y ∨ b ∈ X ∧ a ∈ Y) := by simp [bip] theorem clq_adj {Z : Finset V} {a b : V} : (clq Z).Adj a b ↔ a ≠ b ∧ a ∈ Z ∧ b ∈ Z := by simp only [clq, fromRel_adj];
