import Papers.PODC2016.ShortcutsNoEmbedding.Theorem2 /-! # Lemma 3 and Corollary 6 of [HIZ16]: verifying the block parameter Every node of a part must learn whether the part has at most `b₀` block components, in `O(b₀ (D + c))` rounds. On the supergraph `S` of the part (connected, one node per block) the paper's procedure is: min-flood IDs for `b₀` supersteps; every leader `r` builds a BFS tree of the nodes that believe `r` is the leader; neighbouring nodes in different trees report failure; otherwise the size of the tree is counted and broadcast. The paper's sketch overlooks that the nodes believing in leader `r` need not be connected to `r` inside this set (a node can be within distance `b₀` of `r` and of no smaller ID, while every path to `r` passes through nodes that see a smaller ID). Such nodes are in no BFS tree and cannot learn the outcome from it. The repaired procedure (all steps are `≤ b₀` supersteps of flooding / convergecast / broadcast): 1. `lead B`: min-flooding of IDs for `b₀` supersteps; 2. `Reached B`: multi-source BFS for `b₀` supersteps from the sources (`id s = lead s`) along edges whose endpoints have the same leader; `B` is reached iff the BFS from its leader's source arrives within `b₀` supersteps; 3. `Flag B`: `B` is not reached, or has a neighbour with another leader or not reached (one superstep); 4. convergecast over each BFS tree (depth `≤ b₀`) of the number of nodes and of the OR of flags, and broadcast of the result (`2 b₀` supersteps). An unreached node outputs "more than `b₀`". `verification_correct`: in a connected graph, every node outputs "at most `b₀`" (`Accept`) iff the graph has at most `b₀` nodes. `corollary_6`: applied to the supergraph of a part, the output is `blockParam P H ≤ b₀`, after `4 b₀ + 1` supersteps. -/ set_option linter.unusedSectionVars false namespace ShortcutsNoEmbedding open SimpleGraph Finset variable {β : Type*} [Fintype β] [DecidableEq β] (S : SimpleGraph β) [DecidableRel S.Adj] (id : β → ℕ) (b₀ : ℕ) /-- The leader believed by `B` after `b₀` supersteps of min-flooding. -/ noncomputable def lead (B : β) : ℕ := floodMin S id b₀ B /-- The edges between nodes believing in the same leader. -/ def regionGraph : SimpleGraph β where Adj B N := S.Adj B N ∧ lead S id b₀ B = lead S id b₀ N symm := ⟨fun _ _ h => ⟨h.1.symm, h.2.symm⟩⟩ loopless := ⟨fun _ h => S.loopless.irrefl _ h.1⟩ /-- `B` is reached by the BFS (within `b₀` supersteps) from the source of its leader: a node `s` with `id s = lead s = lead B`. -/ def Reached (B : β) : Prop := ∃ s, id s = lead S id b₀ s ∧ lead S id b₀ s = lead S id b₀ B ∧ WalkLE (regionGraph S id b₀) s B b₀ /-- Local failure detection. -/ def Flag (B : β) : Prop := ¬ Reached S id b₀ B ∨ ∃ N, S.Adj B N ∧ (lead S id b₀ N ≠ lead S id b₀ B ∨ ¬ Reached S id b₀ N) open Classical in /-- The BFS tree of `B`'s leader: the reached nodes believing in the same leader. -/ noncomputable def group (B : β) : Finset β := univ.filter fun B' => Reached S id b₀ B' ∧ lead S id b₀ B' = lead S id b₀ B /-- The output of node `B`: it is reached, no node of its BFS tree raised a flag (an OR convergecast), and the tree has at most `b₀` nodes (a sum convergecast). -/ def Accept (B : β) : Prop := Reached S id b₀ B ∧ (∀ B' ∈ group S id b₀ B, ¬ Flag S id b₀ B') ∧ (group S id b₀ B).card ≤ b₀ variable {S id b₀} theorem mem_group {B B' : β} : B' ∈ group S id b₀ B ↔ Reached S id b₀ B' ∧ lead S id b₀ B' = lead S id b₀ B := by classical unfold group;
