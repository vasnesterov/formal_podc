import Papers.PODC2016.VertexCoverLocalRatio.Correctness /-! # Number of iterations (Lemma 3.3) Key fact (first claim in the proof of Lemma 3.3, in exact form): if `v` keeps running after iteration `i`, then every neighbour that keeps running answered `v`'s request in full, so `w_i(v) - w_{i+1}(v) ≥ vault(v)·d_{i+1}(v)/d_i(v)` (`drop`). Counting (`count_bound`, pure real arithmetic): for every real `K > 1`, iterations with `d_{i+1} ≤ d_i/K` number at most `log d(v)/log K`, the others at most `K(1-θ)/a`. Hence (`active_bound`): if `v` is still running at the beginning of iteration `n`, then `n ≤ K(1-θ)/a + log d(v)/log K`. With the paper's parameters `(1-θ)/a = 2/ε`. `lemma_3_3_small` / `lemma_3_3_large`: the two cases of Lemma 3.3 with explicit constants, for `0 < ε ≤ E` (the paper's "`ε = O(1)`"). -/ set_option
