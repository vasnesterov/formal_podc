States carry the node's identifier, so a node can address an amount to a particular neighbour (field `out`) and pick out the amount addressed to itself. Local input of `v`: its identifier, its weight `w(v)` and its degree `d(v)`. Global knowledge: only `ε` (through `θ = a = ε'`) and the processing order of line 17; no knowledge of `n` or `Δ`. One iteration of Algorithm 1 takes three rounds (`t ≡ 0, 1, 2 mod 3`): * `respond` (lines 10–21): every running node sees `vault(u)/d_i(u)` of its running neighbours (their requests) and fixes its answers `budget_i(v,·)` (field `out`); * `deduct` (lines 13–14, 22–23, 26): every running node collects the answers addressed to it, updates `w_{i+1}(v)` and decides whether it returns `InCover` (field `cv`); * `notify` (lines 27–33): a node with `cv` returns `InCover`; the others drop the neighbours that returned `InCover` and return `NotInCover` if none is left. A node that has returned never changes its state again (`dist_frozen`).
