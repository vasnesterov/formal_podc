import Papers.PODC2016.ConcurrentDSU.Defs /-! # Parent-pointer forests ordered by node ids A parent function `m : E → E` is `Good` (w.r.t. the node ids `key`) if every node is a root (`m a = a`) or has a parent of larger id (Lemma 3.1: "if x is not a root, x < x.parent; if x is a root, x = x.parent"). Then following parents always reaches a root: `rootOf m a` (iterate `card E` times). Two nodes are in the same tree (`same m a b`) iff they have the same root. The two kinds of successful `Cas` of the algorithm: * `rootOf_update_split` — a `Find` replaces the parent of `u` by a node `w` of the same tree with larger id: roots are unchanged; * `rootOf_update_link` — `Unite` makes the root `u` a child of a node `v` with larger id: the tree of `u` is attached to the tree of `v`. `Legal m m'` collects what every memory change of the algorithm satisfies (used to show that local invariants of the other processes are stable). -/ set_option linter.unusedSectionVars false namespace Podc.ConcurrentDSU variable {E : Type} [Fintype E] [DecidableEq E] (key : E → ℕ) -- CSLib candidate (this file: parent-pointer forests ordered by ids) /-- Lemma 3.1 (shape): every node is a root or its parent has a larger id. -/ def Good (m : E → E) : Prop := ∀ a, m a = a ∨ key a < key (m a) /-- The root of the tree of `a` (follow parent pointers `card E` times). -/ def rootOf (m : E → E) (a : E) : E := m^[Fintype.card E] a /-- `a` and `b` are in the same tree. -/ def same (m : E → E) (a b : E) : Prop := rootOf m a = rootOf m b /-- Number of nodes with a larger id than `a` (a measure decreasing along parent pointers). -/ def hgt (a : E) : ℕ := (Finset.univ.filter (fun b => key a < key b)).card variable {key} lemma hgt_lt {a b : E} (h : key a < key b) : hgt key b < hgt key a := by unfold hgt apply Finset.card_lt_card refine Finset.ssubset_iff_of_subset ?_ |>.2 ⟨b, by simp [h], by simp⟩ intro c hc simp only [Finset.mem_filter, Finset.mem_univ, true_and] at hc ⊢ omega lemma hgt_le_card (a : E) : hgt key a ≤ Fintype.card E := by unfold hgt exact (Finset.card_filter_le _ _).trans (by simp) section Iter variable {m : E → E} lemma key_le_iterate (hg : Good key m) (a : E) (j : ℕ) : key a ≤ key (m^[j] a) := by induction j with | zero => simp | succ j ih => rw [Function.iterate_succ_apply'] rcases hg (m^[j] a) with h | h · rw [h];
