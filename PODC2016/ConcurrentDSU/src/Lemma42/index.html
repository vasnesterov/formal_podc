import Mathlib /-! # Lemma 4.2: the Chernoff step does not give the stated exponent Lemma 4.2 claims: the probability that a node `x` has an ancestor `y` of rank `< h` such that the path from `x` to `y` has `c·h` parent pointers is at most `1 / exp ((c/2 - 1)^2 h^2 / c)`. The proof: along the path there are fewer than `h` "good" links (links between nodes of different ranks), each of the `c·h` links is good with probability at least `1/2` independently of the others (Lemma 4.1), "and the lemma follows by a Chernoff bound". The Chernoff bound `P[X ≤ (1 - δ) μ] ≤ exp (-δ² μ / 2)` with `μ = c h / 2`, `(1 - δ) μ = h` gives `exp (-(c/2 - 1)^2 h / c)`: the exponent is linear in `h`, not quadratic. The quadratic exponent does not hold in the very model the proof reduces to: with fair coins (each link good with probability exactly `1/2`, which Lemma 4.1 allows), `c = 4`, `h = 6`, the probability of fewer than `6` good links among `24` is `55455 / 2^24 ≈ 3.3·10⁻³`, larger than the claimed bound `exp (-9) ≈ 1.2·10⁻⁴` (`chernoff_step_fails`). Whether the *statement* of Lemma 4.2 is nevertheless true for the actual union forest is not settled by this: we only show that its proof does not establish it. Corollary 4.2.1 and Theorem 4.3 survive with the linear exponent (choose `c` larger), but the second case (`d < 1`) of the proof of Theorem 5.1 uses the quadratic exponent (`n / 2^(h²/16)` middle nodes);
