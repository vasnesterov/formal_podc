import Papers.PODC2016.ConcurrentDSU.WaitFree import Cslib.Computability.Distributed.SharedMemory.Model /-! # Section 6: `SameSet` and `Unite` with early termination (Algorithms 6 and 7) The two finds of an operation are interleaved: the smaller of the current nodes `u < v` is advanced (with splitting), and the operation stops as soon as `u = v` (same set) or the smaller node `u` is a root (`SameSet`: different sets; `Unite`: link `u` below `v` by `Cas`). ``` loop if u = v then return true -- linearization point (both algorithms) if v < u then swap(u, v) SameSet: if u = u.parent then return false -- linearization point Unite: if Cas(u.parent, u, v) then return -- linearization point repeat k + 1 times: z ← u.parent; w ← z.parent; Cas(u.parent, z, w) u ← z ``` Algorithms 6/7 are `k = 1` (two tries, "do twice"); `k = 0` is the one-try variant mentioned in the paper. The test `u = v` is local; it is folded into the step that produced the new value of `u` (or into the invocation). Results: `et_linearizable` and `et_waitFree` (the paper does not state them as theorems; it presents the algorithms as correct implementations of `SameSet` and `Unite`).
