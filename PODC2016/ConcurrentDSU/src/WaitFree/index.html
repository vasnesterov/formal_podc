The proof uses a potential `Ψ p C = bnd · mpot C.mem + Φ (C.loc p) C.mem` where * `mpot` (`Forest.lean`) decreases with every change of the memory: every successful `Cas` moves one parent pointer to a node with a larger id, so there are only finitely many memory changes overall; * `Φ < bnd` is a potential of the local state of `p` *in a fixed memory*: every step of `p` that does not change the memory decreases it. The local potential `Φ` combines, lexicographically, the "positions" of `u` and `v` (twice the number of larger ids, plus one for a root, see `qv`), the phase of the loop body and the progress of the running `Find`. Positions are measured at the *roots* of `u` and `v` while a `Find` is running, and at `u`, `v` themselves at the checks of lines 7–10: a failing `Cas` / failing root test (`u` is not a root) then strictly decreases the position, which pays for the next iteration of the loop. * `Impl.waitFree_of_cfgPotential` (library, `Cslib/Computability/Distributed/SharedMemory/Potential.lean`): a configuration potential that never increases while `p` is pending and decreases with every step of `p` gives wait-freedom. * `waitFree` — Lemma 3.3 for all versions of `Find`. -/ set_option
