import Papers.PODC2016.ConcurrentDSU.Forest /-! # Local invariants of the concurrent DSU (Lemma 3.1 and the facts behind Lemma 3.2) `LInv C`: the memory is a `Good` forest (Lemma 3.1) and every process's local variables satisfy `LocInv`: the variable `u` of `SameSet(x, y)` / `Unite(x, y)` is always in the tree of `x`, `v` in the tree of `y` ("u is always in the same tree as x", proof of Lemma 3.2), and the variables of a running `Find` satisfy `FInv` (the value read as a parent is in the same tree and has a larger id, etc.). Main results: * `tauRes_spec` — one step of a process: the memory change is `Legal` (`Find` only shortcuts inside a tree, `Unite` links a root below a node with a larger id) and the invariant of the stepping process is preserved; * `LocInv.legal` — invariants of the other processes survive legal memory changes; * `linv_step`, `linv_of_run` — `LInv` holds in every reachable configuration. -/
