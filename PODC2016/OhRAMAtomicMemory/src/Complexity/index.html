import Papers.PODC2016.OhRAMAtomicMemory.Statements import Cslib.Computability.Distributed.MessagePassing.FairExec /-! # Message complexity of reads (Table 1, Sections 3.2, 4.2, 5.1.2, 5.2.2) The paper counts the messages of a read operation: `|S|` `readRequest`s, `|S|²` server-to-server `readRelay`s (`|S|² + |S|` with the relays to the reader in the revised protocol) and `|S|` `readAck`s, i.e. `|S|² + 2|S|` (OhSam, OhMam) or `|S|² + 3|S|` (OhSam', OhMam'). In the printed code the test of line 53 (`relays[r] = |S|/2 + 1`) is not nested in the `if` of line 51. A server whose counter for a *newer* read of `r` sits at `|S|/2 + 1` therefore answers every *stale* `readRelay` of an older read with one more `readAck` for the older read. With `|S| = 3`: two consecutive reads, each completed with the relays of `s₀, s₁`; the relays of `s₂` for the first read arrive afterwards and each of the three servers answers with a stale `readAck`. The first read then has `3 + 9 + 6 = 18 > 15 = |S|² + 2|S|` messages (`ohSam_read_msgs_gt`, `ohMam_read_msgs_gt`), resp. `3 + 12 + 6 = 21 > 18` in the revised protocol (`ohSam'_read_msgs_gt`,
