With at least `|S|/2 + 1` correct servers, `|rAck|` would exceed `|S|/2 + 1` while the read is pending, but it grows one by one and the read returns when it equals `|S|/2 + 1`. The fast path of the revised protocol is not needed. * Writes (`Liveness.Ex.write_terminates`): the same argument for the `discover` phase (MWMR) and the `writeRequest` phase.
