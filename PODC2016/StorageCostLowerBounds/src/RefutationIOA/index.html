In the paper's I/O-automaton model each send is a separate output action, so a server must keep its pending outputs in its state. `Stream.IOASends` formalizes this restriction (an input step of a server sends nothing, a spontaneous step at most one message). The streaming relay (`Stream.lean`) satisfies it and is atomic, live and gossip-free with **36 states per server**, independently of `|V|`.
