import Papers.PODC2016.StorageCostLowerBounds.Model /-! # The relay algorithm: zero bits of server storage A counterexample to Theorems 4.1, 5.1 and B.1 of the paper in the FIFO-channel model. Servers are **stateless relays**; the value is kept in the reader's incoming channels. * Write `t` (the `t`-th write, value `v`): the writer sends `W t v` to every server and returns once `qs` servers acknowledged (`A t`). * A server receiving `W t v` forwards `F t v` to the reader and sends `A t` to the writer; a server receiving the query `Q j` from the reader answers `D j`. Its local state never changes. * The reader records the largest write index `best` it has seen in an `F` message, with its value. Read `j` sends `Q j` to every server and returns the recorded value once `qs` servers answered `D j`. With `qs = n - f` and `2 f < n` the algorithm is atomic (`RelayInv.lean`) and live (`RelayLive.lean`). FIFO is essential: when the reader receives `D j` from a server, it has already received every `F` that server sent before. -/ namespace Podc.StorageCost.Relay open Cslib.ChannelFailures
