import Papers.PODC2016.StorageCostLowerBounds.Model /-! # Non-vacuity: a single-server register emulation The hypotheses of the storage-cost theorems are satisfiable: with one server (`n = 1`, `f = 0`) the obvious algorithm is an atomic (hence regular), live SWSR register emulation that does not gossip, in which servers reply only to the reader's messages, and whose server has exactly `|V|` states (`witness_hyps`). * Writer: on `write v` it records `v` and sends `W v` to the server; on the acknowledgement `A` it returns. * Server: it stores the value of the last `W v` it received and acknowledges it (`A`); on a query `Q` of the reader it answers `D` with the stored value. * Reader: on `read` it sends `Q` to the server and returns the value of the answer `D v`. Every node has a local state `(cur, stored) : V × V`; the writer uses `cur`, the server `stored`, the reader none. At most one message of each client is in flight, which gives a simple inductive invariant (`Inv`). -/ namespace Podc.StorageCost.Witness open Cslib.ChannelFailures Cslib.SharedMemory variable {V : Type} /-- Messages. -/ inductive Msg (V : Type) where /-- Writer to server: write `v`. -/ | W (v : V) /-- Server to writer: acknowledgement. -/ | A /-- Reader to server: query. -/ | Q /-- Server to reader: the stored value. -/ | D (v : V) /-- Local states `(cur, stored)`. -/ abbrev LSt (V : Type) := V × V /-- The only server. -/ abbrev s0 : Node 1 := .srv 0 /-- The transition function. -/ def handle : Node 1 → Input (Node 1) (RWOp V) (Msg V) → LSt V → LSt V × List (Node 1 × Msg V) × Option V | .wr, .invoke (.write v), l => ((v, l.2), [(.srv 0, .W v)], none) | .wr, .recv (.srv _) .A, l => (l, [], some l.1) | .rd, .invoke .read, l => (l, [(.srv 0, .Q)], none) | .rd, .recv (.srv _) (.D v), l => (l, [], some v) | .srv _, .recv .wr (.W v), l => ((l.1, v), [(.wr, .A)], none) | .srv _, .recv .rd .Q, l => (l, [(.rd, .D l.2)], none) | _, _, l => (l, [], none) /-- The single-server algorithm. -/ def alg (v₀ : V) : Algorithm (Node 1) (register V v₀) (Msg V) (LSt V) where init _ := (v₀, v₀) handle := handle /-! ### Static properties -/ lemma node_cases (x : Node 1) : x = s0 ∨ x = .wr ∨ x = .rd := by rcases x with i | _ | _ · left;
