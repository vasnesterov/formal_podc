While a write is pending and does not return, the stream stays fixed and every acknowledgement counter `ackc i` is monotone. For a correct server `i` with `ackc i < |strm|`, the outstanding bit is in transit (it is delivered, `Fair.delivered`, and sets `pa`), or pending at the server (`pa`; the server emits the forward and then the acknowledgement within a bounded number of its own ticks: the potential `potW`), or acknowledged in transit (delivered: `ackc i` increases). Hence every correct server eventually acknowledges the whole stream, which contradicts `Inv.wdone`. * Read. The outstanding query of a correct server `i` is in transit, pending (`pd`; answered within three ticks: the potential `potR`), or answered in transit; the answer is delivered. A stale answer makes the reader send a fresh query, whose answer puts `i` into `resp`.
