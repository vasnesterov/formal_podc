Notation: `S α` is the stream of bits of all invoked writes; `xW C i` is the number of bits server `i` has received. * Writer–server tokens (`TokW`): per server at most one bit is outstanding (sent, not yet acknowledged), and it is in exactly one place: in transit to the server, at the server (`pa`), or as the acknowledgement in transit. * Forwarded stream (`fstr`): the bits the reader received from server `i`, followed by the bits in transit and the pending one, are the first `xW C i` bits of `S α`. * Reader–server tokens (`TokQ`): per server at most one query is outstanding, in transit, pending at the server (`pd`), or answered in transit. * The current read (`CurOk`), the reads-from data (`RFOk`): as for the relay (`RelayInv.lean`), with the answer of a server of `G` preceded by
