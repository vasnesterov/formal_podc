The proof follows the paper. Fix an agent `i`, the preferences `v` (`i` prefers `1`, everybody else `0`), and the failure patterns where only `i` crashes. We order them linearly: `step s` lets `i` crash in round `⌊s/(n-1)⌋ + 1` reaching the first `s mod (n-1)` other agents (in a fixed enumeration). Consecutive patterns differ by one message from `i` to one agent `j` (`step_succ_deliv`). In `step 0` agent `i` is silent, so by validity the decision is `0` (`prob_step_zero`); for large `s` the decision is `1` with positive probability, by fairness in the failure-free context (`exists_prob_step_ne_zero`). At the first `s` where the probability of deciding `1` becomes positive, agent `j` gains by pretending not to have received `i`'s message (`outcome_deviate_step`). This replaces the paper's "minimal failure pattern `F*`" by the first index in a linear order; it also handles the identification of "crash in round `m + 1` reaching nobody" with "crash in round `m` reaching everybody", which the paper makes by convention.
