Analysis of the runs of `σ_cons` in which nobody deviates: * `recTab_H`: the status reports computed by the protocol are the records `ghost` of the failure pattern (`Records.lean`), so all nonfaulty agents agree on the decision set `NC` (`ghost_agree`); * `secret_H`: every nonfaulty agent reconstructs `x_l[t]` for every `l ∈ NC` — *provided* it gets a second share of `l`'s polynomial in round `f + 1` (`ShareCond`); * `decideVal_H`: all nonfaulty agents decide the preference of the same random dictator; fairness follows from `seedMeasure_dictator` (`Fairness.lean`). Results: `theorem_2` (Algorithm 1 as written: line 20 forwards `(y_li)_{l ≠ j}`, including the sender's own share `y_ii`; every `f + 1 < n`), `theorem_2_receivedOnly` (the prose reading "forward only the shares received", `f ≥ 1` and `f + 3 ≤ n`), `theorem_2_receivedOnly_false` (the prose reading fails for `n = f + 2` and for `f = 0`: some nonfaulty agent cannot interpolate and decides `⊥`). -/
