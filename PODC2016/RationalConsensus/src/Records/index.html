import Papers.PODC2016.RationalConsensus.Model /-! # Crash records of `σ_cons` in failure-only runs (combinatorial core of Theorem 2) In `σ_cons` every agent keeps, for every other agent `l`, the earliest round in which it knows that `l` crashed ("status reports" `SR[l]`, lines 23–37 of Algorithm 1): it records round `t + 1` if it receives no round-`t + 1` message from `l`, and it takes the minimum with the records reported by the agents it hears from. In runs where nobody deviates, the presence of messages is determined by the failure pattern, so these records are the function `ghost` of the context below (the protocol is shown to compute exactly `ghost` in `Theorem2.lean`). From the records at the end of round `f + 1`, an agent computes `NC R m = {l | m < R l}` (the agents it believes alive after round `m`), the first round `m ∈ [1, f + 1]` that *seems clean* (`NC m = NC (m - 1)`), and decides using `NC m`. Main result: `ghost_agree`: all nonfaulty agents compute the same first seemingly clean round and the same set `NC`. The paper's proof claims that the first round `m*` without crash seems clean to everybody; this is false (`not_clean_example`), so we prove agreement differently: a disagreement about an agent `l` at threshold `m` forces `l` to crash in round `m` and a chain of crashes in each of the rounds `m + 1, …, f + 1` (`crash_chain_of_disagree`); together with the `m - 1` agents witnessing that rounds `1,
