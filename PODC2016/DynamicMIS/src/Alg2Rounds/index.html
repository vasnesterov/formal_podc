import Papers.PODC2016.DynamicMIS.Alg2Basic /-! # Algorithm 2: the round bound (Lemma 11) Let `X` be a finite set containing every participating node that is ever outside `M`/`M̄` (for Algorithm 2 this will be the set `S` of influenced nodes). Then: * `C`-entries happen at times `t ≤ #{w ∈ X | w before v}` (`entry_le`): a `C`-entry at `t + 1` is triggered by an earlier-ranked node of `X` with a `C`-entry at `t`; * `R`-entries happen at times `≤ |X| + 1 + #{w ∈ X | w after v}` (`readyEntry_le`): an `R`-entry later than two rounds after the `C`-entry waits for a later-ranked neighbour's `R`-entry; * exits from `R` happen at times `≤ 2|X| + 1 + #{w ∈ X | w before v}` (`finalize_le`); * progress: after time `2|X|` no node is in `C` (the latest-ranked one would enter `R`), after time `3|X|` no node is in `R` (the earliest-ranked one would leave it): every participating node is in `M`/`M̄` at time `3|X|` (`isFinal_run_three_mul`) and the run is stable from then on (`stableFrom_three_mul`). The paper's bound `3|S| + 2` counts rounds from `1` with the initial `C`-changes in round `1`; our time `0` is the configuration after that round. -/ open Finset namespace DynamicMIS namespace Alg2
