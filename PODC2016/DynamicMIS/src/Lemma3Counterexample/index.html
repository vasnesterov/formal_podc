import Papers.PODC2016.DynamicMIS.Lemma2 /-! # Lemma 3 with "`= 1/|P|`" is false for edge changes Lemma 3 of the paper claims, for every `P ⊆ V`, `Pr[π(v*) = min π(P) | S′ = P ∧ π(v**) ≤ π(v*)] = 1/|P|`. For an edge change with `v** ∈ P` this conditional probability is `0` (the paper's proof notes this case and only concludes `≤ 1/|P|`, which suffices for Theorem 1). Instance: `H` = the path `0 – 1 – 2` (the graph without the changed edge `{0, 2}`), `v* = 2`, `v** = 0`. For the order `1 < 0 < 2` the set `S′` (influenced set of `v*` with `v*` moved to the front) is `{0, 1, 2}` and `π(v**) ≤ π(v*)`, so the conditioning event is non-empty, while `π(v*) = min π(P)` never holds on it. -/ open Finset SimpleGraph namespace DynamicMIS /-- The order `1 < 0 < 2` on `Fin 3`. -/ def ceOrder : Fin 3 ≃ Fin (Fintype.card (Fin 3)) := (Equiv.swap (0 : Fin 3) 1).trans (finCongr (Fintype.card_fin 3).symm) theorem ceOrder_influencedFirst : (pathGraph 3).influencedFirst Set.univ ceOrder 2 = univ := by have hr : ∀ v : Fin 3, moveFirst ceOrder 2 v = if v = 2 then 0 else if v = 0 then 2 else 1 := by intro v;
