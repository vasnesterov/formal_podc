import Papers.PODC2016.DynamicMIS.Alg2Rounds /-! # Algorithm 2: trigger chains, Lemma 12, and the number of state changes (Lemmas 8, 12) Every `C`-entry of a node `v` at time `t` is the end of a *trigger chain* `z = w₀, w₁, …, w_t = v` of rank-increasing nodes, `w_j` entering `C` at time `j` (`run_entry`); its *root* `z` is a node that is in `C` initially. We only record what the chain implies (`IsRoot`): * (`IsRoot.changing`) while `v` stays in `C` during `[t, T]`, the root stays in `C` during `[0, T + t]`: a node cannot leave `C` while a later-ranked neighbour that it triggered is in `C` (`changing_back`); * (`IsRoot.final`) if `v` is in `M`/`M̄` at time `τ ≥ t`, the root was in `M`/`M̄` at some time `τ₀ ≤ τ - t`: a node leaves `R` only after all its predecessors are in `M`/`M̄`. Consequences, valid for every network and every admissible initial configuration: * **Lemma 12 (first part)** (`entry_spacing`): if `v` enters `C` at times `t₁ < t₂`, then `t₂ ≥ 3 t₁ + 4` (the paper, counting rounds from `1`, states `t₂ ≥ 3 t₁ + 1`). * **Lemma 12 (second part)** (`card_entries_le_initC`): different `C`-entries of the same node have different roots, so a node enters `C` at most as many times as there are initially-`C` nodes. * **Lemma 8** (`changes_le`): the number of changes of the visible state of a node is at most three times its number of `C`-entries (`M`/`M̄` → `C` → `R` → `M`/`M̄`). * `card_le_log` turns the spacing of Lemma 12 into a logarithmic bound on the number of entries. -/ open Finset namespace DynamicMIS namespace Alg2 variable {V : Type*} {N : Net V} {c₀ : V → St} /-! ### Chains -/ /-- A node that has just changed to `C` and has a predecessor `v` in `C` during `[k + 1, T]` stays in `C` during `[k, T + 1]`. -/ theorem changing_back {u v : V} (hv : v ∈ N.part) (huv : N.Pred u v) {k T : ℕ} (hu : run N c₀ k u = .changing 0) (hvC : ∀ τ, k + 1 ≤ τ → τ ≤ T → (run N c₀ τ v).IsChanging) : ∀ τ, k ≤ τ → τ ≤ T + 1 → (run N c₀ τ u).IsChanging := by intro τ induction τ with | zero => intro h1 _;
