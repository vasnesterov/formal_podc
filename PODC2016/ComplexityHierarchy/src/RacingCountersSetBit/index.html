import Papers.PODC2016.ComplexityHierarchy.RacingCounters import Mathlib.Data.Nat.Bitwise import Mathlib.Algebra.BigOperators.Group.Finset.Piecewise /-! # `n`-consensus from one location with `read` and `set-bit` (Theorem 3.3 of [EGSZ16]) A single memory location storing a natural number (a bit string), initially `0`, supporting `read()` and `set-bit(x)` (set bit `x` to `1`), simulates an unbounded `m`-component counter for processes `Fin N`: the location is partitioned into blocks of `m · N` bits; process `i` increments `c_v` by setting bit `v · N + i` of block `b + 1`, where `b` is the number of times it previously incremented `c_v` (`bitIdx`). The count of `c_v` is the number of set bits belonging to `v` (`bitCnt`), so a single `read()` is a scan. This is the paper's construction with `n² = m · N` (the paper has `m = N = n`).
