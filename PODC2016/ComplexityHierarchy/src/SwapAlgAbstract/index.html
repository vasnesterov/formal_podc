Ellen, R. Gelashvili, N. Shavit, L. Zhu, *A Complexity-Based Hierarchy for Multiprocessor Synchronization*, PODC 2016 (arXiv 1607.06139), Section 8, Algorithm 1. This file contains the combinatorial core of the correctness proof of Algorithm 1: the algorithm with *atomic* scans of the `m` swap locations, as a transition system on abstract configurations `ACfg` (memory = `m` lap vectors, local states `ALoc`). The real algorithm (scans by double collect, `SwapAlg.lean`) is reduced to this one by a simulation argument. Values are `Fin k`, a *lap vector* is `Fin k → ℕ`. After a scan returning `a : Fin m → Laps k`, a process with local laps `l` and last swap result `s` computes `L = merge l s a` (Algorithm 1, line 5); if every location contains `L` it decides `v* = vstar L` (largest lap, ties to the smaller value) when `v*` is at least two laps ahead of every other value, otherwise it increments `L v*` and swaps into `X_1` (index `0`); if some location differs from `L` it swaps `L` into the first such location (`after`). ## Main result * `AInv`: an invariant of abstract configurations (existentially quantified ghost state) which holds initially (`aInv_init`) and is preserved by every step (`AInv.invoke`, `AInv.swap`, `AInv.scan`, the latter needs `|P| ≤ m + 1`); it implies agreement (`AInv.agree`) and validity (`AInv.valid`). ## The invariant (relation to the paper) The ghost state records the *floor* `F` = lap vector of the last scan that returned the same vector from every location ("all-equal scan", the scans `S` of Lemma 8.3), the set `wloc` of locations and the set `wproc` of processes involved in *stale* swaps since then (a swap by a process `p` with `¬ F ≤ l p`; these are the swaps of the set `W` in the proof of Lemma 8.3), and the first deciding all-equal scan `win` (Lemma 8.5). Lemma 8.3 ("every scan after an all-equal scan `S` sees laps `≥ ℓ(S)`") becomes `floor_le_merge`: locations outside `wloc` contain vectors `≥ F`; the counting part of the paper's proof becomes the inequality `|wloc| + |{q ∈ wproc stale with stale s}| ≤ |wproc|` together with a non-stale witness outside `wproc`, which gives `|wproc| ≤ |P| - 1 ≤ m`.
