import Cslib.Computability.Distributed.SharedMemory.Valency import Cslib.Foundations.Data.Nat.Descent /-! # Read and test-and-set: Lemma 9.1 and Theorem 9.2 of EGSZ'16 Ellen, Gelashvili, Shavit, Zhu, *A Complexity-Based Hierarchy for Multiprocessor Synchronization*, PODC 2016, Section 9: for `n ≥ 3` processes, obstruction-free binary consensus cannot be solved with finitely many memory locations supporting only `read()` and `test-and-set()`. ## Model * `tasLoc`: a location with value in `ℕ`; `read()` returns the value; `test-and-set()` returns the old value and sets the location to `1` if it was `0` (otherwise leaves it unchanged). The memory is `B := fun _ : ι => tasLoc` for a finite type `ι` of locations; initial values are arbitrary (`Impl.memInit`). * Binary consensus algorithms `I : Impl BinCons B P L` (see `Cslib/Computability/Distributed/SharedMemory/Valency.lean`), with weak validity (`weakConsensus`) and one-shot obstruction-freedom (`OneShotOF`) — both weaker than the paper's assumptions. Key facts about this memory: a nonzero location stays nonzero forever (`step_mem_ne_zero`), and a step that is not a test-and-set on a location with value `0` does not change the memory (`soloStep_mem_eq`). ## Main results * `exists_more_nonzero`: one round of the proof of Lemma 9.1. * `lemma_9_1` (**Lemma 9.1**): if all processes are bivalent from a reachable configuration, then for every `k` an execution reaches a configuration from which all processes are bivalent and in which at least `k` locations are nonzero. * `theorem_9_2` (**Theorem 9.2**): there is no such algorithm for a finite set of locations. ## The gap in the paper's proof of Lemma 9.1, and its repair Let `L` be the set of nonzero locations after `α_k ξ` (where `ξ` is given by Lemma 6.6: `p₀` decides `0` and `p₁` decides `1` in their solo runs), and let `z ∉ {p₀, p₁}`. The paper lets `β` be the shortest prefix of `z`'s solo execution `δ` from `Cα_kξ` ending with a test-and-set on a location `r ∉ L`, and then argues about the configurations `Cα_kξψβ` and `Cα_kξψψ'β`, where `ψ, ψ'` are steps of `p₀`/`p₁`. But the preliminary steps of `z` in `β` (reads, and test-and-sets on locations of `L`) may return different values after `ψ` (which may have set locations to `1`) or after `ψ'` (which may be a test-and-set on `r`), so `z` need not behave as in `β` there: the configurations the paper reasons about are not well defined in general. **Repair.** First run `z`'s preliminary steps `β⁻` (they change no memory, so `D' := Cα_kξβ⁻` agrees with `Cα_kξ` on `p₀`, `p₁` and the memory); now `z` is *poised* at `D'` to perform its test-and-set `τ_z` on `r` (with value `0`). Then: * if `z` returns before poising on such a location, its solo run changed no memory, hence is invisible to `p₀`, `p₁`, and the one of them deciding the opposite of `z`'s decision violates agreement; * if `{p₀, p₁}` is bivalent from `D'τ_z`, we are done (`r` is now nonzero); * otherwise there are `a ≠ b` in `{p₀, p₁}` and `x` such that `a` decides `x` from `D'τ_z` and `b` decides `!x` from `D'` (solo). Let `ψ` be the longest prefix of `b`'s solo run `γ` from `D'` such that `a` still decides `x` from `D'ψτ_z` (the full run does not qualify, by agreement), and let `ψ'` be `b`'s next step. Then `a` decides `!x` from `D'ψψ'τ_z`. Instead of the paper's case analysis on `ψ'`, we observe that **`τ_z` (a test-and-set) commutes with any single step of `b` as far as `a` and the memory are concerned** (`soloStep_comm_agree`: test-and-set is idempotent, reads do not change memory, steps on different locations commute). Hence `D'ψψ'τ_z` and `D'ψτ_zψ'` agree on `a` and on the memory, so `a` decides `!x` from `D'ψτ_zψ'` and `x` from `D'ψτ_z`: `{a, b}` is bivalent from `D'ψτ_z`, which has `r` and all of `L` nonzero. So the lemma and the theorem are correct; only the proof needed this repair. We prove the statement "at least `k` nonzero locations" (the paper: "`k` locations have been set to `1`"), which also holds for arbitrary initial memory contents. -/ set_option
