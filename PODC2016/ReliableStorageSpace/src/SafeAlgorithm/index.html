We define it in the black-box storage model of `Model.lean` (`alg`): * the code is abstract: piece `i` of value `v` is `enc i v : Fin (2 ^ ℓ)`, and any `k` pieces determine the value (`Decodable`); * timestamps are `⟨num, w⟩` with `w = (c, i)` the write's identifier, ordered lexicographically (the paper uses `⟨num, c⟩`; adding the operation index is harmless and makes timestamps unique per write); * an object stores `none` (initially: timestamp `0`, no block — the model requires objects to start without blocks, and the reader returns `v₀` instead of decoding pieces of `v₀`) or a chunk `⟨num, w, j⟩` holding the block `(w, j)`; * `readValue` triggers one read RMW per object and waits for `n - f` responses; a write then triggers `update` RMWs (overwrite iff the timestamp is bigger) and waits for `n - f` acknowledgements; a read returns the decoded value of the **largest** timestamp of which it has at least `k` pieces, and `v₀` if there is none.
