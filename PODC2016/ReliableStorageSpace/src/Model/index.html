import Mathlib /-! # Fault-prone shared memory with black-box coded storage (Sections 2 and 4) Spiegelman, Cassuto, Chockler, Keidar. *Space Bounds for Reliable Storage: Fundamental Limits of Coding.* PODC 2016 (arXiv 1507.05169v1). **System (Section 2.1).** Clients `C` access base objects `N` by arbitrary atomic read-modify-write operations (RMWs). A client *triggers* an RMW on an object; later the RMW *takes effect* on the object and its response is delivered to the client (event `exec`). A client may have several pending RMWs. Clients are deterministic state machines; they only act while they have an outstanding high-level operation (`read` / `write` of the emulated MWMR register). **Failures and fairness.** Failures are not events: a failure pattern `(Fc, Fo)` (crashed clients, crashed objects, `|Fo| ≤ f`) only enters fairness (`Alg.Fair`): crashed clients take finitely many steps, RMWs on crashed objects take effect finitely often, every correct client is scheduled infinitely often, and every RMW of a correct client on a correct object eventually takes effect. **Black-box storage model (the paper's "information-theoretic storage model").** Written values are opaque: write `w = (c, k)` (the `k`-th operation of client `c`) has value `val w` for a value assignment `val`, and the algorithm never sees it. What the algorithm stores and moves around are *blocks* `b = (w, j)`: block `j` of the value of `w`, whose contents is the `sz j`-bit string `enc j (val w)` (`enc` is the algorithm's code, e.g. an erasure code; replication is a block of `D` bits). All control flow and all metadata are independent of the values. Blocks only flow: an RMW can store blocks the client holds, a response can carry blocks the object holds, and a writer may create blocks of its own current write (`Alg.invoke_blk`, `Alg.act_blk`, `Alg.apply_blk`, `Alg.recv_blk`). A read returns `rdout c l (contents)` where the output may depend only on the contents of the blocks the reader holds (`Alg.rdout_congr`). Storage is counted in bits of blocks. This makes precise the paper's assumption (Section 4, after Theorem 1) that "each stored bit is associated with a particular write". The paper claims this is without loss of generality via Theorem 1; it is not (see `Coding.lean` and `differencies.md`), so the lower bound is proved for this class of algorithms. -/ noncomputable section namespace Podc.ReliableStorageSpace open Finset Classical /-- Operations of the emulated register.
