import Papers.PODC2016.ReliableStorageSpace.Solo /-! # The adversary `Ad` (Section 4, Definition 1, Observations 1 and 3, Lemma 3) For a write `w = (c, k)`, `Out X w` is the set of blocks of `w` stored outside its writer: in some base object, or held (in the local state or in a pending RMW) by another client. A client is *quiet* (`Quiet`, the paper's `C⁻`) if no block of any of its writes is outside it. The adversary `Ad`: 1. if some quiet client has a pending RMW on an object not in `F(t)` (`Full`), executes the oldest such RMW (it takes effect and responds); 2. otherwise schedules the next client in round-robin order (`rr`), so its next action (e.g. a trigger) happens without any RMW taking effect. `Inv` is the invariant behind Lemma 3: for every write, the blocks outside its writer are either none, or fewer than `D` bits, or all in a single object of `F(t)` (which `Ad` never touches again). It holds along every run of `Ad` (`inv_Ad`), and gives Lemma 3 (`lemma3`): objects outside `F(t)` never hold `D` bits of any single write. -/ noncomputable section namespace Podc.ReliableStorageSpace open Finset Classical variable {C N J V : Type} namespace Alg variable (A : Alg C N J V) [Fintype C] [Fintype N] [Fintype V] /-- Blocks of `w` outside its writer. -/ def Out (X : A.Config) (w : OpId C) : Finset (Blk C J) := ofW w ((univ.biUnion fun o => A.oblk (X.obj o)) ∪ (univ.filter (· ≠ w.1)).biUnion (A.held X)) theorem mem_Out {X : A.Config} {w : OpId C} {b : Blk C J} : b ∈ A.Out X w ↔ b.1 = w ∧ ((∃ o, b ∈ A.oblk (X.obj o)) ∨ ∃ c, c ≠ w.1 ∧ b ∈ A.held X c) := by simp [Out, mem_ofW, and_comm] /-- The paper's `C⁻`: no block of any write of `c` is stored outside `c`. -/ def Quiet (X : A.Config) (c : C) : Prop := ∀ k, A.Out X (c, k) = ∅ /-- All blocks of `w` outside its writer are in the single object `o₀ ∈ F(t)`. -/ def Frozen (X : A.Config) (w : OpId C) : Prop := ∃ o₀ ∈ A.Full X, (∀ o, o ≠ o₀ → ∀ b ∈ A.oblk (X.obj o), b.1 ≠ w) ∧ (∀ c, c ≠ w.1 → ∀ b ∈ A.held X c, b.1 ≠ w) /-- The invariant behind Lemma 3. -/ def Inv (X : A.Config) : Prop := ∀ w, A.Out X w = ∅ ∨ A.bits (A.Out X w) < D (V := V) ∨ A.Frozen X w /-- Candidates of rule 1 of `Ad`: pending RMWs of quiet clients on objects not in `F(t)`. -/ def cand (X : A.Config) (p : Pend C N A.R) : Bool := decide (A.Quiet X p.cl ∧ p.obj ∉ A.Full X) /-- Round robin over the clients. -/ def rr [Nonempty C] (i : ℕ) : C := (Fintype.equivFin C).symm ⟨i % Fintype.card C, Nat.mod_lt _ Fintype.card_pos⟩ /-- **The adversary `Ad`** (Definition 1). -/ def Ad [Nonempty C] (X : A.Config) : Event C := match X.pend.find?
