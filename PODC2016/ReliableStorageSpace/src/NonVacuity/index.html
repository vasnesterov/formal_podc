import Papers.PODC2016.ReliableStorageSpace.LowerBound /-! # Non-vacuity of Theorem 2: a lock-free, atomic register in the black-box storage model The hypotheses of `Alg.theorem2` (lock-freedom and weak regularity) are satisfiable together: with a single reliable base object (`f = 0`) holding the block of the last write, the trivial algorithm `atomicAlg` * **write `(c, k)`:** one RMW "put block `((c, k), .one)`" (the object is overwritten with it), wait for the acknowledgement, return; * **read:** one RMW "get" (the response carries the object's block), wait for the response, return the decoding of the block received (`v₀` if none); is lock-free with `f = 0` (`atomicAlg_lockFree`) and weakly regular (`atomicAlg_weakRegular`). The only block kind `Kind.one` has `|V|` bits and the code is injective (`dec_encV`). `theorem2_atomicAlg` instantiates `Alg.theorem2` on it (3 clients, Boolean values, `S = 2`). The weak regularity proof uses a ghost history `G` of the RMWs that took effect, in order, with the length `tau` of the history at the time each took effect (`Good`).
