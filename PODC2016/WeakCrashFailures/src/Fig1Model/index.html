import Papers.PODC2016.WeakCrashFailures.Failures import Mathlib.Data.Finset.Lattice.Fold import Mathlib.Order.Fin.Basic /-! # The consensus algorithm of Fig. 1 (one crash (n−1)-failure) G. Taubenfeld, *Computing in the presence of weak crash failures*, PODC 2016; full version *Weak Failures: Definitions, Algorithms and Impossibility Results*, Fig. 1. Model: `n` processes `Fin n`, asynchronous, atomic multi-writer registers `state[1..n]` (values `0..3`), `input[1..n]` (initial values immaterial: an arbitrary parameter `inr₀`) and `decision : Option ℕ` (`none` = ⊥). Inputs are natural numbers ("non-negative"). Every step of a process performs at most one shared-memory access (read or write) together with the local computation that follows it. Program counters carry the local variables (`round`, `j`, `counter`, `max`). Two reads of `decision` that follow each other without any other access of the process (lines 13–14, lines 22–23) are merged into one read; the result of the second read is determined by the first one (the register is never reset to ⊥), so this only removes stuttering. A process that decided is in `done v`; its later steps are no-ops, so it counts as a correct process in infinite schedules (see `Failures.lean`). * `PC.start` – line 1 (write `input[i]`). * `PC.scan r j cnt mx` – lines 4–6 of round `r`, about to read `state[j]` (`j < n`), or, for `j = n`, line 7 (`counter = n−1`: write `decision := max`, decide) or line 8 (write `state[i] := r`). * `PC.scanIn r j cnt mx` – line 6, about to read `input[j]`. * `PC.wait r j cnt mx` – lines 10–12, about to read `state[j]`; for `j = n` lines 13–14: read `decision`; if `≠ ⊥` decide it, else if `counter ≥ n−1` leave the loop (next round, or after round 3 line 16), else repeat. * `PC.chk j cnt mx` / `PC.chkIn j cnt mx` – lines 17–19; for `j = n` line 20. * `PC.fin j mx` – line 22, about to read `state[j]`; for `j = n` line 25. * `PC.finDec j mx b` – lines 22–23, about to read `decision` (`b`: `state[j] = 3` was read). * `PC.finIn j mx` – line 24, about to read `input[j]`. -/ namespace
