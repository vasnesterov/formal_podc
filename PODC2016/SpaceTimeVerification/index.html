Space-Time Tradeoffs for Distributed Verification — PODC 2016

Rafail Ostrovsky, Mor Perry, Will Rosenbaum. Space-Time Tradeoffs for Distributed Verification. PODC 2016 brief announcement by Mor Baruch, Rafail Ostrovsky, Will Rosenbaum. Formalized version: arXiv 1605.06814 v2 (full version); numbering follows it. Copy of the paper: paper.pdf.

Verdict: ⚠️ Weakened. The universal t-PLS (Theorem 1) and the acyclicity results hold: every t-round scheme needs labels of Ω(log n / t) bits (Theorem 7), and O(log n / t) bits suffice for every t ≥ 2 (Theorem 8). The general crossing tool, Proposition 4 and Theorem 5, a stated contribution, is false in the model with identifiers, where the paper says it holds: two-round verifiers can detect short cycles. It is true without identifiers, and the recursive O(log* n) scheme of Section 4.3 was not checked.

Mistakes in the paper

❌ Proposition 4 and Theorem 5 (crossing lower-bound tool, identifier model, t ≥ 2)

The lower-bound tool fails in the identifier model, where the paper (Sections 1.1 and 4) says it holds: for r disjoint triangles, t = 2, q = 3 and the predicate "every node lies on a triangle", all hypotheses hold, yet a 2-round verifier with empty labels decides the predicate (theorem_5_false, proposition_4_false).

Impact. The paper's application, Theorem 7 (a path), is unaffected; we prove it directly in the identifier model. Without identifiers the tool is true (proposition_4_view, theorem_5_anon). With identifiers we have no general replacement.

Details

Take e_i an edge of triangle i. The crossing of two triangles is a 6-cycle violating the predicate. But a node can check in 2 rounds whether two of its neighbours are adjacent. So the label size is 0, not Ω(log r), and Proposition 4's conclusion fails for every pair. The broken step is "every node of N_t(e_i) ∪ N_t(e_j) has the same t-neighbourhood in G and in C(e_i, e_j, G)", which fails when e_i lies on a cycle of length ≤ 2t+1.

Repair

In anonymous networks, where a node only learns its view tree, a triangle and a 6-cycle look alike and Proposition 4 is true; we prove it there (proposition_4_view, theorem_5_anon).

✏️ Slips

  • Proposition 16, condition 4 of correct block labels: it asks for a head at the start of an oriented path w_0, …, w_{k-1} = v with k < t vertices, which a tail (t vertices below its head) can never satisfy, so for t = 2 no graph with an edge, e.g. the acyclic path on two nodes, has a correct labelling (not_correctLiteral_path). With k ≤ t, as the proof of Lemma 17 and Fig. 1 intend, Proposition 16 holds for all t ≥ 2 (prop16).

  • Proposition 16 for t = 1: every node would have to be both head and tail, so no nonempty graph has a correct labelling (correct_one_isEmpty). Theorem 8 is then the classical 1-round scheme.

  • Theorem 1 says "t ∈ Ω(D)", but its scheme needs t ∈ O(D), as the introduction says (t ∈ O(diam)): the shares are spread over BFS distances 0, …, t/4 from one node, so that node needs eccentricity about t/4. We formalize the paper's scheme for t ≤ 2·diam + 2 (theorem1).

  • Theorem 1 tacitly needs P to be invariant under isomorphism, configurations to be connected and states to be pairwise distinct (theorem1).

  • Theorem 7: Ω((log n)/t) cannot hold uniformly in t, since for t ≥ n a verifier with empty labels sees the whole graph. The paper's range is t ≤ log n, and the exact bound is proved (theorem_7).

  • Algorithm 1, HEAD_CHECK: it starts false and only ancestors can set it, so a root always rejects at line 35. The proof of Lemma 17 gives the intended initial value, and we prove Lemma 17 for the radius-t predicate (lemma17).

  • Algorithm 1, relay loop: it runs t-1 times while the text uses the message of the t-th round (lemma17, check_isLocal).

Typos

  • "d(v) = mid otherwise" should be b(v) = mid (proof of Proposition 16).

  • "d(w) = b(v) + 1" should be d(w) = d(v) + 1 (before Definition 10).

Proof gaps in true statements (1)Proposition 4

🔧 Proposition 4 (counting labels)

The counting "|ℓ| < log r / q ⇒ fewer than r concatenations" is wrong for variable-length labels.

Impact. The exact threshold shifts by the +1 below, with the same asymptotics, in the anonymous-model version (where Proposition 4 holds) and in Theorem 7.

Repair

Counting label tuples gives log₂ r < q(|ℓ|+1) (proposition_4_anon, theorem_5_anon_length, lowerBound_card).

The formalizationmodel, Lean names of the results, trust

Model.

  • Configurations. A configuration is a graph on any vertex type V : Type, with states I : V → ι. A t-PLS (TPLS) has a prover and a verifier, and must be complete and sound on all finite configurations of the family. Deterministic, synchronous, no failures. The verifier does not know n.

  • Locality. The output of a node is a function of its labelled radius-t ball up to isomorphism (BallIso): the nodes at distance ≤ t with states and labels, and the edges at nodes at distance < t. This is what t rounds reveal when identifiers may be used but the output must not depend on them. This is the paper's rule in Section 2.1 and its model for the lower bounds.

  • Identifiers. For Theorem 1, identifiers are part of the states, so the verifier may use them.

  • Anonymous model. For the positive version of Proposition 4, views are anonymous broadcast view trees (Anonymous.lean).

  • Not modelled. Labels are bit strings (or finite data with an explicit bit size). Message size, memory and run time are not modelled.
