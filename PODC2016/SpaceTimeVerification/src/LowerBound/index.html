import Papers.PODC2016.SpaceTimeVerification.Basic import Cslib.Foundations.Combinatorics.SimpleGraph.Ball import Cslib.Foundations.Combinatorics.SimpleGraph.Arboricity /-! # Theorem 7: every `t`-PLS for acyclicity needs labels of size `Ω(log n / t)` The paper (Section 4.1) derives Theorem 7 from its general crossing tool (Theorem 5). That tool is false in the identifier-based model the paper claims for it (`Crossing.lean`), so we prove Theorem 7 directly, following the same construction. * `G` is the path `0 — 1 — ⋯ — (n-1)` (`pathGraph n`), labelled by an accepted labelling `ℓ`. The edges `e_i = (q·i, q·i+1)`, `q = 2t+2`, `1 ≤ i ≤ r = ⌊n/q⌋ - 1`, have pairwise disjoint `t`-neighbourhoods `[q·i - t, q·i + t + 1]` of `q` nodes. If the labels come from a set of size `< r^{1/q}`, two of these windows carry the same labels (pigeonhole). * `crossGraph n A B` is the edge crossing `C(e_i, e_j, G)` with `A = q·i < B = q·j`: the edges `(A, A+1)` and `(B, B+1)` are replaced by `(A, B+1)` and `(B, A+1)`. It is the path `0..A, B+1..n-1` plus the cycle `A+1..B`. * Every node of the crossed graph sees the same labelled `t`-ball as some node of the path, so it accepts (`crossGraph_accepts`). Far from the crossing the ball is unchanged; near it we compare with the path relabelled by a *block swap* `bswap` (exchange `[P, P+w)` with `[P+D, P+D+w)`, `D = B - A`), which leaves `ℓ` unchanged because the two windows carry the same labels, and which agrees with the crossed graph around the node (`key_high`, `key_low`; the width `w` of the swapped block depends on the node). * The cycle `A+1..B` is a connected component, it is a connected graph with a cycle, and all of its nodes accept: this contradicts soundness. Hence `⌊n/(2t+2)⌋ - 1 ≤ |labels|^(2t+2)` (`lowerBound_card`), i.e. labels of length `≤ L` need `log₂(⌊n/(2t+2)⌋ - 1) < (2t+2)(L+1)` (`theorem_7`). -/ namespace Podc.SpaceTimeVerification open
