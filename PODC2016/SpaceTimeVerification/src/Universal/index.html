import Papers.PODC2016.SpaceTimeVerification.Basic import Cslib.Foundations.Data.List.BitEncoding /-! # The universal `t`-PLS (Theorem 1, generic part) Section 3.1 of *Space-Time Tradeoffs for Distributed Verification*: from any injective binary code of configurations, a `t`-PLS whose labels are `|code| / k` bits plus an index of `log k` bits, where `k ≈ t / 2` is the number of shares. ## The scheme (`universal`) States are pairwise distinct (the states contain unique identifiers, Section 3.1). The prover fixes a node `v₀` of eccentricity `≥ k - 1` (`center`), writes the code `c` of the whole configuration (`toConf`, an enumeration of the nodes by `Fin n`), cuts it into `k` blocks of length `⌈|c|/k⌉` (`Cslib.BitEncoding.chunk`), and gives the node at distance `d` from `v₀` the label `lab k j (block j)` with `j = d mod k`. The verifier at `u` (`verify`) accepts iff there are strings `s 0, …, s (k-1)` such that 1. every index `j < k` occurs, with share `s j`, at some node within distance `2k - 2` of `u`; 2. every node within distance `2k - 1` of `u` carries a label `lab k j (s j)` with `j < k`; 3. the concatenation `s 0 ++ ⋯ ++ s (k-1)` is the code of a configuration `c` that is connected, has pairwise distinct states, satisfies `P` (`Legal`), and is consistent with the local view of `u`: `c` has a node with the state of `u` whose neighbours have exactly the states of the neighbours of `u` (`LocalOK`). Radius `2k - 1 ≤ t` suffices for locality (`verify_isLocal`, via `ballIso_edist`). * Soundness (`verify_sound`): by 1–2, adjacent nodes have the same shares, so (connectivity) all nodes decode the same configuration `c`; by 3 and distinctness of the states, `u ↦` (its node in `c`) is an isomorphism `G ≃g c` preserving states, and `P` is isomorphism invariant. * Completeness (`verify_complete`): a node at distance `d` from `v₀` finds every residue modulo `k` within distance `2k - 2`, on a shortest path to `v₀` or on a shortest path from `v₀` to a node at distance `≥ k - 1` (`exists_near_residue`). ## Deviations from the paper * The paper's verifier collects the shares by pipelining along the BFS layers (orientation labels `d mod 3`, "first in block" and "`v`-indication" bits, `t/4` shares, `t/2` rounds) and then compares `g(u)` with its neighbours in `t/2` more rounds. Our model only records what a node sees in `t` rounds (the labelled `t`-ball), so the verifier is a property of the ball; the share index `j < k` is written in the label (`⌈log₂ (k+1)⌉` bits) instead of the `O(1)` bits of orientation, and agreement with the neighbours is replaced by condition 2 (all shares with the same index in the `(2k-1)`-ball agree). Message size is not modelled. * The number of shares is a parameter `k` with `2k ≤ t + 1` (the paper: `t/4`). -/ namespace Podc.SpaceTimeVerification open SimpleGraph Cslib.BitEncoding namespace
