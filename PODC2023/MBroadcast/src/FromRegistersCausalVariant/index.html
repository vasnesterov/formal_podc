import Papers.PODC2023.MBroadcast.FromRegisters /-! # A causal variant of Algorithm 2 (causal-MBroadcast on top of atomic SWMR registers) Section 3 of the brief announcement states that the enriched variants of MBroadcast (fifo-, causal-, reliable-MBroadcast) do not change its computing power. Algorithm 2 (full version) implements fifo-MBroadcast but not causal-MBroadcast (`not_causalOrdering`). This file gives a variant (ours, not in the paper) that implements causal-MBroadcast on top of atomic SWMR registers, with any number of crashes: ``` shared: SENT[1..n]; SENT[i] = list of entries (m, h): m mbroadcast by pᵢ, h = the history of pᵢ (the list of its mdeliveries (sender, message), in order) when it mbroadcast m local: histᵢ (initially empty) operation mbroadcast(m): (1) SENT[i] ← SENT[i] ⊕ (m, histᵢ); (2) catch_up(); (3) mdeliver m from pᵢ periodically do catch_up(). catch_up(): for j from 1 to n, j ≠ i: L ← flattening of SENT[j] (each entry (x, h) gives h, then (j, x)); for (q, y) ∈ L in order: if (q, y) ∈ histᵢ: skip; else if q = i: stop processing L (it is the message of the current mbroadcast of pᵢ, which pᵢ mdelivers only at line 3); else mdeliver y from q. ``` The model is the one of `FromRegisters.lean` (the same phases and actions): one atomic step per register access, the local processing of the read list `L` (function `go`) in the same step.
