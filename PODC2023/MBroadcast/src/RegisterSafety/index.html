import Papers.PODC2023.MBroadcast.Register /-! # Theorem 2, safety: Algorithm 3 is linearizable Every history of Algorithm 3 whose MBroadcast trace satisfies the safety properties of MBroadcast is linearizable for an MWMR register (`alg3_linearizable`). The proof is the paper's (full version, App. A.2): the timestamp `ts(o)` of an operation is `⟨tᵢ, i⟩` for a write and `clockᵢ` at line 6 for a read; if `o₁` returns before `o₂` starts then `ts(o₁) ≤ ts(o₂)`, strictly if `o₂` is a write. The real-time fact comes from Property 1 between the last message of `o₁` and the `synch` message of `o₂`: mutual ordering forces the process of `o₂` to mdeliver the last message of `o₁` before its own `synch`, hence before line 2/5. We conclude with the timestamp criterion `Cslib.SharedMemory.TSLin`. The invariant `Inv` carries ghost data: the list `W` of writes that have chosen their timestamp (line 2) and the timestamp map `tok`. -/ set_option linter.unusedSectionVars false namespace
