Two trace invariants imply the safety properties of (fifo-)MBroadcast: * `PrefixInv tr`: in every prefix of the trace, the messages mdelivered by `q` from `p` form a prefix of the messages mbroadcast by `p`. With `UniqueBc`, it implies `Validity`, `NoDuplication` and `FifoOrdering`. * `MOInv tr`: when `p` mdelivers its own `m`, it has already mdelivered every message mbroadcast by another process before `p` mbroadcast `m`. It implies `MutualOrdering`. -/ namespace Podc.MBroadcast.FromRegisters variable {P M : Type} [DecidableEq P] [DecidableEq M] set_option linter.unusedSectionVars false /-- The messages mbroadcast by `p`, in trace order. -/ def bcs (tr : List (Ev P M)) (p : P) : List M := tr.filterMap fun | .bc q m => if q = p then some m else none | .dl .. => none /-- The messages mdelivered by `q` from `p`, in
