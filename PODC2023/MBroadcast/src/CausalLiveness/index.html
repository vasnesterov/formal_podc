import Papers.PODC2023.MBroadcast.CausalInv /-! # Algorithm 2: liveness (Theorem 1, Local termination and Global CS-termination) Infinite executions (`Exec`): sequences of configurations and actions, starting from `initCfg`, each configuration obtained from the previous one by a (successful) step. A process is *correct* if it never crashes. *Weak fairness* (`Exec.Fair`): every reception or own-delivery action that is enabled at all times from some point on is eventually taken. For receptions this is the reliability of the channels (a message to a correct process whose causal predecessors have been delivered is eventually delivered); for `own` it is the progress of a correct process whose `wait` condition holds. *Resilience* (`Exec.Resilient`): at most `t` processes crash. Main results: * `Exec.eventually_received`: every network message to a correct destination is eventually received (strong induction on its id: its causal predecessors have smaller ids); * `Exec.global_cs_termination`: if a correct process `p` invokes `mbroadcast(m)`, every correct process eventually mdelivers `m` from `p` (only the correctness of the receiver is needed for `q ≠ p`); * `Exec.local_termination`: if a correct process invokes `mbroadcast(m)`, it eventually mdelivers `m` itself, i.e. returns (at most `t` crashes; no assumption `t < n/2` is needed). -/ set_option
