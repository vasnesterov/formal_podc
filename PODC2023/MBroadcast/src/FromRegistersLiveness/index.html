import Papers.PODC2023.MBroadcast.FromRegistersPhases /-! # Algorithm 2: liveness (full version, Appendix A.1) An *execution* is an infinite sequence of configurations `cfg` and actions `act` starting from the initial configuration, each action being enabled (`step (cfg k) (act k) = some (cfg (k+1))`). A process is *correct* if it never crashes. The execution is *fair* if every correct process takes infinitely many local steps (`Act.tick`); since `tick p` is always enabled for an alive process, this is weak fairness. In particular every correct process executes `catch_up` infinitely often ("periodically do catch_up()"). * `localTermination`: a correct process that has mbroadcast `m` eventually mdelivers `m` itself (i.e. `mbroadcast(m)` returns). * `globalCFTermination`: if some process mdelivers `m` from `q`, every correct process eventually mdelivers `m` from `q`. * `globalCSTermination`: if a correct process mbroadcasts `m`, every correct process eventually mdelivers `m`. * `exampleExec`: fair executions in which a message is mbroadcast exist (the hypotheses of the theorems are not vacuous). -/ namespace
