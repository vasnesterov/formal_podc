import Mathlib.Data.List.Basic import Mathlib.Data.List.Count import Mathlib.Data.List.TakeDrop import Mathlib.Order.Basic import Mathlib.Tactic /-! # The MBroadcast abstraction (Déprés, Mostéfaoui, Perrin, Raynal, PODC 2023), Section 3 An *MBroadcast trace* is the list of the events of the abstraction, in real-time order: `bc p m` (`p` invokes `mbroadcast(m)`) and `dl p q m` (`p` mdelivers `m` from `q`). The safety properties of MBroadcast and of its enrichments are properties of finite traces: * `Validity`, `NoDuplication`, `MutualOrdering` (the defining properties); * `FifoOrdering`, `CausalOrdering` (fifo- and causal-MBroadcast). "`p` mdelivers `m` before `m'`" is read, as for the FIFO and causal ordering properties of the paper, as "when `p` mdelivers `m`, it has not mdelivered `m'`" (`DelivBefore`): this includes the case where `p` never mdelivers `m'`. This is the reading of the paper's message pattern `MP1` ("when a process delivers its own message, it has no information on the other one"), and it is the reading under which Property 1 and Theorem 2 hold. The literal alternative ("`p` mdelivers both, `m` first", `WeakMutualOrdering`) makes Property 1 false (`property1_false_weak`). The liveness properties (Local termination, Global CS- and CF-termination) depend on the notion of correct process of each model; they are stated in the model files. -/ namespace Podc.MBroadcast /-- Events of the MBroadcast abstraction. -/ inductive Ev (P M : Type) where /-- `p` invokes `mbroadcast(m)`. -/ | bc (p : P) (m : M) /-- `p` mdelivers `m` from `q`. -/ | dl (p q : P) (m : M) deriving DecidableEq variable {P M : Type} [DecidableEq P] [DecidableEq M] section Props variable (tr : List (Ev P M)) /-- **Validity.** If `p` mdelivers `m` from `q`, then `q` previously invoked `mbroadcast(m)`. -/ def Validity : Prop := ∀ i p q m, tr[i]? = some (.dl p p m) ∧ .dl p q m' ∉ tr.take i /-- **Mutual ordering.** For any processes `p`, `p'` and messages `m` (mbroadcast by `p`) and `m'` (mbroadcast by `p'`), it is not possible that `p` mdelivers `m` before `m'` and `p'` mdelivers `m'` before `m`. -/ def MutualOrdering : Prop := ∀ p m p' m', (p, m) ≠ (p', m') → ¬ (DelivBefore tr p m p' m' ∧ DelivBefore tr p' m' p m) /-- The safety part of MBroadcast. -/ structure Safe (tr : List (Ev P M)) : Prop where validity : Validity tr noDup : NoDuplication tr mutualOrd : MutualOrdering tr /-- **FIFO ordering.** If a process mbroadcasts `m` and then `m'`, no process mdelivers `m'` before `m`. -/ def FifoOrdering : Prop := ∀ (p : P) (m m' : M) (i j : ℕ), tr[i]? = some (.bc p m) → tr[j]? = some (.bc p m') → i < j → ∀ (q : P) (k : ℕ), tr[k]? = some (.dl q p m') → .dl q p m ∈ tr.take k /-- **Causal ordering.** If a process mdelivers `m` (from `q`) and then mbroadcasts `m'`, no process mdelivers `m'` before `m`. -/ def CausalOrdering : Prop := ∀ (p q : P) (m m' : M) (i j : ℕ), tr[i]? = some (.dl p q m) → tr[j]? = some (.bc p m') → i < j → ∀ (r : P) (k : ℕ), tr[k]? = some (.dl r p m') → .dl r q m ∈ tr.take k /-- The *literal* reading of mutual ordering: "`p` mdelivers both messages, `m` first". -/ def WeakDelivBefore (p : P) (m : M) (q : P) (m' : M) : Prop := ∃ i j : ℕ, i < j ∧ tr[i]? = some (.dl p p m) ∧ tr[j]? = some (.dl p q m') /-- Mutual ordering under the literal reading. -/ def WeakMutualOrdering : Prop := ∀ p m p' m', (p, m) ≠ (p', m') → ¬ (WeakDelivBefore tr p m p' m' ∧ WeakDelivBefore tr p' m' p m) end Props /-! ## Basic facts -/ section Basic variable {tr : List (Ev P M)} lemma mem_take_of_getElem?
