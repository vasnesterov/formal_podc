Let `n = m + 1 = 2^k` and let `A` be a single-send algorithm that elects a leader within `T` rounds for all ID assignments from `U`, where `|U| ≥ n log₂ n + n T^(log₂ n - 1)` (Lemma 3.14's assumption). Level `i` of the construction (Lemma 3.14) consists of many pairwise disjoint `2^i`-sets of IDs, each with a partial port mapping under which it runs in isolation up to a common round `R_i`, with *capacity* `2^(i-1) - 1` (every node still has that many unlinked nodes in its set) and at least `M_i` messages sent so far. * `absorb`: a set `X` of `2^i ≤ n/2` IDs from the pruned universe cannot run in isolation until round `T` (repaired Corollary 3.7), so the adversary connects the newly opened ports of `X` inside `X` as long as the capacity allows; the first round `ρ` in which this is impossible comes after at least `capacity + 1` further messages. * `merge`: two sets that both stop in round `ρ` are joined in round `ρ`: since every node opens at most one port per round, the new links form a perfect matching between them, which leaves capacity `2^i - 1` for the merged set. * `level_step`: pigeonhole over the stop round `ρ ∈ [0, T)` and pairing. `single_send_lower_bound` (Lemma 3.13): some execution sends at least `(n/2) log₂ n` messages.
