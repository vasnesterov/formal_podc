import Papers.PODC2023.LeaderTradeoffs.Model -- CSLib candidate /-! # From multicast to single-send algorithms (Lemma 3.12) Lemma 3.12 of Kutten, Robinson, Tan, Zhu, *Improved Tradeoffs for Leader Election* (PODC 2023): a multicast algorithm `A` sending `M(n)` messages in `T(n)` rounds can be turned into a *single-send* algorithm (at most one message per node per round) sending at most `M(n)` messages in at most `n · T(n)` rounds. **Construction** (`simulate`). Each round of `A` is simulated by `n = m + 1` sub-rounds. The simulating node keeps the `A`-state of the start of the simulated round, a sub-round counter `k ∈ {0, …, m}` and a buffer of the messages received so far, indexed by the receiving port. In sub-round `k < m` it sends `A`'s message for port `k` (and only that one) on port `k`; every received message is stored in the buffer. Sub-round `m` is idle; at its end the node applies `A.step` to its `A`-state and the buffer, and clears the buffer. Since `inbox` delivers `v`'s message for `u` along the single port `backPort p v u`, this message arrives exactly in the sub-round equal to that port. The simulation is therefore exact for *every* (even partial, non-well-formed) port map `p` (`run_simulate`), and every `A`-message is sent exactly once, so the message counts coincide exactly (`msgs_simulate`), not just up to `≤`. -/ open Classical Finset namespace LeaderTradeoffs variable {m : ℕ} /-- A *single-send* algorithm sends at most one message per round at every node (Lemma 3.12 of [Kutten, Robinson, Tan, Zhu, PODC 2023]). -/ def SingleSend (A : Algorithm m) : Prop := ∀ s, sendCount A s ≤ 1 /-- The single-send simulation of a multicast algorithm `A` (proof of Lemma 3.12).
