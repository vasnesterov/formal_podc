import Papers.PODC2023.DuraCAS.Spec /-! # Keyed linearization lists (helper for the A-level proof) The linearization of the A-level proof is built incrementally as a list of *keyed entries* `GE` sorted by key. A key `4 t + r` encodes the step `t` at which the entry takes effect and a rank `r` inside that step: `0` hitchhiking writes (inserted retroactively just before the installing write moved at step `t`), `1` the operation linearized at step `t` itself, `3` failing `CAS`es (inserted retroactively after step `t`); `2` is the rank of history events. This file proves the list facts: state/response bookkeeping (`RespOK`), the state `stAt L t` after step `t`, and invariance of both under *benign* insertions (a no-op entry, or a write immediately overwritten by another write on the same object). -/ namespace Podc.DuraCAS set_option linter.unusedSectionVars false variable {K V : Type} [DecidableEq K] [DecidableEq V] variable (K V) in /-- A
