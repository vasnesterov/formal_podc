import Papers.PODC2023.DuraCAS.AModel /-! # The DurEC invariant (Lemmas A.1–A.10 of the full version), stated on concrete/A-level pairs The refinement proof (`Refinement.lean`) is a forward simulation: the A-level state `a` is carried along as a ghost of the concrete state `s`, related by `Inv s a`. The ghost part proper is `a.ls` (the abstract `DETECT` value of each DurEC handle = the sequence number of its last *moved* install) and `a.ps p` (the A-level program counter, `.aft pc true` once the `ECSC` of `p` has been linearized by a move, and the *orphan* = an install of a crashed `ECSC` that is not moved yet). Vocabulary of the paper (Appendix A.1): an *install* is a successful `CAS` on `X` (line 10), a *move* a successful `CAS` on `Y` (line 18). An install on `o` is *pending* (`Pend`) iff `Y.seq < X.seq` (Lemma A.2: installs and moves alternate; an install makes `X.seq > Y.seq`, a move brings `Y.seq` up to `X.seq`). -/ set_option
