On the Validity of Consensus — PODC 2023

Pierre Civit, Seth Gilbert, Rachid Guerraoui, Jovan Komatovic, Manuel Vidigueira. On the Validity of Consensus. PODC 2023. DOI 10.1145/3583668.3594567. Formalized version: extended version arXiv:2301.04920v3 (numbering follows it). Copy of the paper: paper.pdf.

Verdict: 🔧 Easy fix. The classification of solvable validity properties (trivial ones for n ≤ 3t, those satisfying the similarity condition C_S for n > 3t) and the Ω(t²) message lower bound are proved, after one local repair of Lemma 3 for n < 2t. The sufficiency direction is unconditional, because we also verified a vector-consensus protocol for every n > 3t, which replaces the paper's black box, in a model without clock drift or sleeping processes. The O(n²) message complexity of Universal was not checked.

Mistakes in the paper

✏️ Slips

  • Theorem 3 claims a Turing-computable Λ, but the model allows arbitrary deterministic state machines, so solvability only yields some function Λ, not a computable one (similarityCondition_of_solvable). Computable algorithms are implied throughout. We prove both versions: any Λ for arbitrary algorithms, and a computable Λ (in Mathlib's sense) when the algorithm's transition functions are computable (similarityCondition_computable).

  • Theorem 1 fails when the proposal set is empty and V_O = ∅: then there are no executions and every algorithm vacuously solves consensus. The proposal set must be nonempty, which we assume.

Proof gaps in true statements (1)Lemma 3

🔧 Lemma 3 (proof of Theorem 1), case n < 2t

The proof builds a configuration in I_{n−t} from all t processes outside π(base) plus n − 2t processes of π(base), which is impossible for n < 2t (smallest instance n = 3, t = 2, allowed by 0 < t < n ≤ 3t).

Impact. Statement true; repaired (trivial_of_solvesConsensus_auth).

Details

For n < 2t, t processes do not fit into a configuration of size n − t, and n − 2t < 0.

Repair

Take min(t, n − t) processes outside π(base) and fill up from π(base). This configuration is compatible with base in the whole range. (trivial_of_solvesConsensus_auth)

The formalizationmodel, Lean names of the results, trust

Model. A shared partially synchronous Byzantine model (Cslib.Byzantine.PartialSync).

  • n processes; at most t are statically Byzantine with arbitrary behaviour. Algorithms are deterministic, links are authenticated point-to-point, and there is no randomness.

  • Discrete time with an unknown GST and a known δ. Correct processes step at every tick from time 0, so they have drift-free clocks and are always awake. "Waking up late" is simulated by delaying a process's messages.

  • Optional ideal signatures (unforgeable tokens, eavesdropping rushing adversary). All impossibility results are proved with signatures and specialized to the plain model.

  • Message complexity counts messages from correct processes to other processes after GST.

  • Effect on the results. The adversary is weaker than the paper's: it has no clock drift and no sleeping processes before GST. This makes the impossibilities (Theorems 1, 3, 4) stronger. The possibility side (vector consensus, Theorem 5, the full classification) is correspondingly weaker. Lifting it to the paper's model would need a view synchronizer, which is not formalized.

  • Solvability quantifies over algorithms whose state and message types are in Type.

Remarks.

  • Theorem 2 is formally trivial. "A finite procedure returning an always-admissible value" exists as soon as one always-admissible value exists, which Theorem 1 gives: return that constant. (alwaysAdmissible_computable)

  • "A correct process decides at most once" is stated in the paper (§3.2); our Agreement also covers p = q to encode it.
