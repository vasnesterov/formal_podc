Collaborative Tree Exploration with Breadth-First Depth-Next — PODC 2023

Romain Cosson, Laurent Massoulié, Laurent Viennot. Brief Announcement: Efficient Collaborative Tree Exploration with Breadth-First Depth-Next. PODC 2023. DOI 10.1145/3583668.3594568. Proofs are only in the full version, arXiv 2301.13307 v1 (Breadth-First Depth-Next: Optimal Collaborative Exploration of Trees with Low Diameter). We follow the numbering of the brief announcement (BA) and give the full-version numbering in brackets.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🛠️ Hard fix. Theorem 2.1 is true: BFDN explores any tree in 2n/k + D²(min{log Δ, log k} + 2) rounds, and Theorem 3.1 (the balls-in-urns game) and Proposition 4.2 (break-downs) are true too. But the reduction to the urn game behind the key Lemma 2 [full version] does not fit BFDN, and the lemma needed a new, direct allocation argument. Corollary 3.2 and Claim 1 are false as printed, and local changes repair both.

Mistakes in the paper

🔧 Corollary 3.2 (number of calls to Reanchor)

Corollary 3.2 bounds the number of calls to Reanchor by D(k·min{log k, log Δ} + k), but every robot standing at the root calls Reanchor in every round and gets the root as anchor, so one robot on a star with two leaves (D = 1, bound 1) already calls it twice (corollary_3_2_false).

Impact. All these calls return the root (depth 0), which is not a move of any urn game. What the analysis uses is a bound on anchor assignments at depths d ≥ 1, and the paper proves that only with the per-depth constant +2 (lemma_2).

Details

In the star example, Reanchor is called in rounds 0 and 2, and the exploration is still unfinished at round 2 (lines 6–7 of Algorithm 1). On a star with many leaves and any k, the calls grow like n, while the bound does not depend on n.

Repair

The statement the analysis needs is Lemma 2 [full version]: for each depth d ≥ 1, at most k(min{log k, log Δ} + 2) anchor assignments go to nodes of depth d. We prove that lemma. Note the +2: it is not +1, as the per-depth reading of Cor. 3.2 would suggest. (lemma_2)

🔧 Claim 1 [full version, proof of Theorem 1] (idle rounds)

Claim 1 says at most D + 1 rounds contain a robot that does not move, but it is false: with k = 3 robots on a 7-node tree of depth D = 4, 6 such rounds occur (claim_1_false).

Impact. Claim 1 is a step of a proof, not a stated result. The correct bound is 2D (card_idleRounds_le), which still fits in the slack of Theorem 2.1, so Theorem 2.1 is unaffected.

Details

The proof misses robots that are still on a breadth-first trip when the last dangling edge is taken. Such a robot first walks down to its (now closed) anchor and only then returns, while the others idle at the root for up to 2D − 1 rounds. Lean counterexample: the tree is a path 1–3–5–6 and a path 2–4 below the root, with lowest-index tie-breaking. In round 3 robot 2 is sent to node 5 at the moment robot 0 takes the last dangling edge there. The run ends after 9 rounds, and 6 of them contain an idle robot (> D+1 = 5).

✏️ Slips

  • Algorithm 1 (BA), line 14: with while not all robots are at the root, the algorithm stops with unexplored edges: one robot on the star with two leaves is on a leaf after round 0, back at the root after round 1, and the other leaf is never visited (algorithm_1_loop_stops_early). The prose of the BA and the full version use the right condition (while some robot changes position), and that is the one we formalize: we run until the tree is explored and all robots are back.

  • The strategy is written argmin_{i∈[k]\{a_1,…,a_t}} in the full version but a_0,…,a_t in the BA (a_0 must be included).

  • "If Δ ≥ k the game stops when all urns have been chosen" holds only for Δ > k: for Δ = k the game also stops with one unchosen urn holding all k balls.

Proof gaps in true statements (2)Lemma 2 [full version] · Theorem 3.1

🛠️ Lemma 2 [full version] (the per-depth bound behind Cor. 3.2)

The reduction to the urn game in Section 3.1 is a sketch, and the BFDN process is not literally a play of the game.

Impact. Statement true, and so is Theorem 2.1, which rests on it; proved by a different, direct argument (lemma_2).

Details

  • the load BFDN balances (#{j : v_j = v}) leaves out the robot exploring T(v), which is "formally re-anchored" only in the analysis;

  • a node stops being a candidate as soon as its dangling edges are taken, without any robot returning from it, so the player's argmin ranges over a subset of U_t;

  • several urns can disappear between two re-assignments;

  • the final "+k for the last d rounds" is off by one round, because robots leaving a node in the very round it closes can be re-assigned once more.

Repair

Open depth-d nodes are urns, and each holds its discoverer robot (Claim 5, proved as an invariant). Loads stay balanced. A robot anchored at an open node cannot come back. Removing an urn when u urns are alive frees at most min(Δ, ⌈k/u⌉) robots. These facts give at most S_k(Δ) = Σ_{u=1}^{k} min(Δ, ⌈k/u⌉) ≤ k(min{log Δ, log k} + 2) assignments. The log Δ part needs a careful window argument in the synchronous model. (lemma_2, lemma_2_urnSum, alloc_bound, sync_window)

🔧 Theorem 3.1 (urn game, final sum estimate)

The closing estimate takes the game length to be Σ⌈k/h⌉ and bounds it by k log k + k, but the sum-to-integral step drops a term: for k = 7, Δ > k the sum is 21 > 7 log 7 + 7 ≈ 20.6 (a hand check).

Impact. Statement true; we prove the bound by direct accounting: every play lasts at most S_k(Δ) − k + 1 steps (game_ends, urnSum_le).

Repair

Loads stay balanced, and each removal at size u frees at most min(Δ, ⌈k/u⌉) balls, so the paper's budget count gives the true length S_k(Δ) − k + 1.

The formalizationmodel, Lean names of the results, trust

Model.

  • The tree is a CSLib G.RootedTree T (root, parent pointers, depths) of a finite graph G. Robots walk along tree edges. An edge is identified with its lower endpoint, so "all edges traversed" is the same as "all nodes visited". n = |V|, D = maxDepth T, Δ = G.maxDegree. Only #children(w) + 1 ≤ Δ for non-root w is used, so the theorems apply to any G containing the tree (when G is a tree, T has exactly its edges). log is the natural logarithm.

  • Synchronous rounds, k ≥ 1 robots starting at the root, complete communication. Within a round the robots decide in index order (Reanchor, then BF or DN, as in Algorithm 1) and then all move at once. A configuration holds positions, anchors, the visited set and a flag "stack nonempty" (the stack is the path from the position to the anchor). The round is a relation (Round), so all results hold for every tie-breaking (which minimum-load anchor, which free dangling edge). Algorithm 1's decisions only read explored information, but the model does not enforce this by an information-hiding interface.

  • Runtime: the first time t at which the tree is explored and all robots are at the root (Terminal). This is exactly when the full version's loop while some robot changes position stops.

  • Break-downs (Prop. 4.2): round t is played with an arbitrary set act t of robots allowed to move. Blocked robots neither decide nor move, as in the full version. A(M) is (Σ'_t |act t|)/k ∈ ℝ≥0∞. The model of Theorem 2.1 is act t = univ.

  • The urn game: arbitrary adversary moves, the player's balancing strategy with arbitrary tie-breaking, and plays of any finite length that have not stopped.

Claim 3 [full version] counts "explored dangling edges" per trip; the accounting only needs the global inequality moves ≤ 2(n−1) + 2·Σ(anchor depths), and that is what we prove.
