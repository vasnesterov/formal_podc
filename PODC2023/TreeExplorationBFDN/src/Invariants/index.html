import Papers.PODC2023.TreeExplorationBFDN.Step /-! # Invariants of BFDN The invariant `Inv` collects the structural facts behind the claims of Section 2 of the paper: * the visited set is closed under taking parents; * a robot with a nonempty stack (`bf`) is strictly above its anchor, on the path to it, and not at the root; * a robot with an empty stack is inside the subtree `T(v_i)` of its anchor, or above it with the anchor already closed (on its way back to the root); * anchors are never deeper than an open node (anchors are assigned at minimum open depth, and the minimum open depth never decreases); * a robot anchored at an open non-root node is not at the root (it cannot have come back); * (Claim 5 of the full version) every open non-root node `w` hosts in its subtree a robot whose anchor is strictly above `w` (its discoverer). All facts hold for every set of robots allowed to move (`act`), hence both for Theorem 2.1 and for the break-down model of Proposition 4.2. -/ set_option linter.unusedSectionVars false namespace Podc.TreeExplorationBFDN open Finset SimpleGraph variable {V : Type*} {G : SimpleGraph V} {T : G.RootedTree} {k : ℕ} [DecidableEq V] variable (T) in /-- The invariant of BFDN executions. -/ structure Inv (c : Config V k) : Prop where root_vis : T.root ∈ c.vis parent_vis : ∀ v ∈ c.vis, T.parent v ∈ c.vis pos_vis : ∀ i, c.pos i ∈ c.vis anchor_vis : ∀ i, c.anchor i ∈ c.vis bf_spec : ∀ i, c.bf i = true → c.pos i ≠ T.root ∧ InSub T (c.pos i) (c.anchor i) ∧ T.depth (c.pos i) < T.depth (c.anchor i) dn_spec : ∀ i, c.bf i = false → InSub T (c.anchor i) (c.pos i) ∨ (InSub T (c.pos i) (c.anchor i) ∧ ¬ IsOpen T c (c.anchor i)) anchor_min : ∀ i x, IsOpen T c x → T.depth (c.anchor i) ≤ T.depth x off_root : ∀ i, c.anchor i ≠ T.root → IsOpen T c (c.anchor i) → c.pos i ≠ T.root disc : ∀ w, w ≠ T.root → IsOpen T c w → ∃ j, InSub T w (c.pos j) ∧ T.depth (c.anchor j) < T.depth w omit [DecidableEq V] in theorem inv_init : Inv T (init T k : Config V k) where root_vis := by simp [init] parent_vis := by intro v hv;
