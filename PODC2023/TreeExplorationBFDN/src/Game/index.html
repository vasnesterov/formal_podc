import Papers.PODC2023.TreeExplorationBFDN.UrnSum /-! # The balls-in-urns game (Section 3, Theorem 3.1) Cosson, Massoulié, Viennot, PODC 2023 (Brief Announcement), Section 3; full version arXiv:2301.13307, Section 3, Theorem 3. The board at time `t` is a load vector `n^t : Fin k → ℕ` (initially `n^0_i = 1`, so there are `k` balls in total). At time `t` the adversary picks a nonempty urn `a_t`, then the player picks an urn `b_t` and one ball moves from `a_t` to `b_t`. `U_t` is the set of urns never chosen by the adversary before time `t`. The game stops at the first time `t` with `n^t_i ≥ Δ` for all `i ∈ U_t`. The player's strategy: `b_t` minimizes `n^t_i` over `i ∈ U_{t+1} = [k] \ {a_0, …, a_t}` (if this set is empty the game is over at time `t + 1` anyway and `b_t` is arbitrary). A `GamePlay` records the whole (infinite) sequence of boards and moves; `IsPlay Δ p T` says that the first `T` moves are legal, follow the player's strategy, and the game has not stopped before time `T`.
