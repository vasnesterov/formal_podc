Population Protocols Decide Double-exponential Thresholds — PODC 2023

Philipp Czerner. Brief Announcement: Population Protocols Decide Double-exponential Thresholds. PODC 2023. DOI 10.1145/3583668.3594571. Formalized version: arXiv 2204.02115 v2 (full version with appendices); numbering follows it. Copy of the paper: paper.pdf.

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: 🔧 Easy fix. The main results hold: Theorem 1 says there are population protocols with O(n) states deciding x ≥ k for some k ≥ 2^(2^n), Theorem 2 says they are almost self-stabilising, and Theorem 3 (the succinct population program), Theorem 5 (programs to protocols), Lemma 4 and Propositions 14 and 16 are verified too. Lemma 11(c) is false: IncrPair is not i-robust, and the proof of Lemma 12(c) relies on it, but one short replacement step saves Lemma 12(c). The other proof steps that needed repairs, mostly in the constructions of Appendix B, take local changes.

Mistakes in the paper

🔧 Lemma 11(c) (IncrPair is j-robust for all j ≤ i)

Lemma 11(c) is false for j = i: with one level (n = i = 1, N₁ = 1), IncrPair(x̄₁, ȳ₁) on the 1-high configuration x₁ = 0, x̄₁ = 1, y₁ = 1, ȳ₁ = 0 returns a 1-proper configuration (lemma_11c_false).

Impact. The proof of Lemma 12(c) uses the false case; Lemma 12(c) is still true, for a different reason (large_robust_mid), and the main results (Theorems 1, 2, 3, 5) are unaffected.

Details

The lemma claims IncrPair(x, y) is j-robust for all j ≤ i, that is: called on a j-high configuration, every return is j-high again. The example is 1-high: it is not 1-proper, and both pair sums are 1. IncrPair(x̄₁, ȳ₁) increments the two-digit counter ctr = x̄₁·2 + ȳ₁ from 2 to 3. It returns x̄₁ = ȳ₁ = 1, x₁ = y₁ = 0, which is 1-proper, so not 1-high. The same happens at every level, starting one counter step before the proper value. The proof of 11(c) overlooks that lines 3 and 5–7 change the level-i registers. Lemma 12(c) ("Large is robust") needs exactly the false case: Large at level i calls IncrPair at level i − 1 on (i−1)-high configurations.

Repair

Only j < i holds, and we prove that (incr_robust_lt). Lemma 12(c) holds because the walk of Large never changes the pair sums of level i − 1. Once line 9 has passed, one of these sums exceeds N_{i−1}, so the configuration cannot become (i−1)-proper. We prove termination with the paper's own symmetry idea: one loop iteration can be undone by another. In Lean this is the explicit relation Iter and iter_symm. (large_robust_mid)

✏️ Slips

  • The proof of Theorem 3 says "N_{i+1} = (N_i+1)² and N₁ = 1, implying k ≥ 2^(2^n)" for k = 2 ∑ᵢ₌₁ⁿ Nᵢ, which fails already for n = 1, 2, 3 (k = 2, 10, 60; S_lt_claim). The bound in the theorem's own statement, k ≥ 2^(2^(n−1)), is correct (S_ge), and so is Theorem 1 (apply Theorem 3 with n + 1 levels).

  • In IncrPair, the title says "Decrement" and the "Effect" line says the counter "decreases by 1", but the procedure increments it (prose and Lemma 11(a) say so).

  • On p. 27, the last ⟨move⟩ rule should read v ∈ 𝓕_{V_y}.

Typos

  • Line 12 of Large calls CheckProper(i − 2), which should be AssertProper(i − 2).

  • In the proof of Theorem 3, "registers sum to i" should be "m", and the bound "m − |C| ≤ 2N_j" is too weak for the argument: the strict < 2N_j is needed (with equality the configuration would be j-proper, not j-low), and it does hold by the choice of j.

Proof gaps in true statements (4)Proposition 16 · Lemma 15 / Proposition 16 · Proposition 16 · Proposition 14

🔧 Proposition 16 (the initial value of OF must be false)

The construction lets the leader election give OF an arbitrary initial value v_OF, and with v_OF = true the protocol can output true on inputs x < i, where φ′(x) is false.

Impact. Statement true; fixing v_OF = false repairs the construction (proposition_16).

Details

With fewer than |F| agents the election can create an OF agent but never an IP agent. With v_OF = true, that agent would broadcast true.

🔧 Lemma 15 / Proposition 16 (the elected agents' initial states)

The proof says the agents are in their initial states X^v_none "at the moment this happens", which needs three new invariants of the election (prefix counts, empty levels, fresh agents).

Impact. Statement true; repaired (Machine.lemma_15).

Details

The fairness argument also needs the elected configuration to be reachable from every reachable configuration, not only from the initial one.

🔧 Proposition 16 (Appendix B.3, ⟨elect⟩ and Y = IP)

The wildcard in ⟨elect⟩ covers states of Q_X only, so map states have to count as agents of their pointer, and the transitions for Y = IP must be added, since the paper assumes Y ≠ IP "w.l.o.g.".

Impact. Statement true; a local addition to the transition list (proposition_16).

🔧 Proposition 14 (Appendix B.2, restart and V_y := V_□)

In Proposition 14, the restart helper must skip moves between equal registers, and V_y := V_□ needs a clamped map f.

Impact. Statement true; local fixes (proposition_14).

The formalizationmodel, Lean names of the results, trust

Model.

  • Population protocols (Section 3, Protocol.lean): states Q, transitions (q, r ↦ q', r'), input states I, accepting states O. Configurations are nonempty multisets. C → C' if C = C' or a transition fires. A protocol decides φ if every globally fair run (CSLib Run.GloballyFair) from an initial configuration stabilises to φ. The model is deterministic and fairness-based, with no probability and no leaders. Theorem 1's predicates are unary: φ(|C|) with one input state. Almost self-stabilisation (Def. 7) quantifies over runs from any configuration with at least |Q| agents in input states.

  • Population programs (Section 5, Program.lean): registers R → ℕ, flat code with a call stack, an output flag OF, and restart. A restart replaces the registers by any configuration with the same total and restarts Main, keeping OF. The paper's pseudocode is written in a structured syntax and compiled to flat code; the for loops are expanded. A program decides φ if every globally fair run from Main stabilises to φ(total). Well-formedness (acyclic calls, moves between distinct registers) is proved for the construction. Size is |Q| + #instructions + swap-size.

  • Population machines (Def. 6/13, Machine.lean): registers, pointers with finite domains, and instructions x ↦ y, detect x > 0, X := f(Y), with the paper's semantics. Nonempty pointer domains are a hypothesis of Proposition 16.

Trust. No sorry. theorem_1, theorem_3 and lemma_11c_false use only the axioms propext, Classical.choice and Quot.sound. Non-vacuity: Proposition 14 also shows that every register configuration is the register part of an initial machine configuration.
