import Papers.PODC2023.PPDoubleExpThresholds.Totals /-! # Lemma 11(c) is false Lemma 11(c) claims that `IncrPair(x, y)` is `j`-robust for all `j ≤ i`. For `j = i` this fails: with one level (`n = i = 1`, `N₁ = 1`) the configuration `x₁ = 0, x̄₁ = 1, y₁ = 1, ȳ₁ = 0` is `1`-high (and weakly `1`-proper), but `IncrPair(x̄₁, ȳ₁)` increments the counter `ctr_{x̄,ȳ} = 2` to `3`, i.e. returns `x̄₁ = ȳ₁ = 1, x₁ = y₁ = 0`, which is `1`-proper and hence not `1`-high. (In general: any weakly `i`-proper, not `i`-proper configuration whose counter is one step before the `i`-proper value.) The paper's proof of 11(c) overlooks that lines 3, 5–7 of `IncrPair` change level-`i` registers.
