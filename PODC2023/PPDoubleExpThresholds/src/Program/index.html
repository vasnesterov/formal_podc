import Papers.PODC2023.PPDoubleExpThresholds.Stable import Mathlib.Algebra.BigOperators.Group.Finset.Basic import Mathlib.Data.Fintype.Basic import Mathlib.Data.Fintype.Card /-! # Population programs (Section 4) A population program `P = (Q, Proc)` has a finite set of registers `Q` (values in `ℕ`) and a list of procedures built from while-loops, if-statements and the instructions * `x ↦ y` (move a unit from `x` to `y`; *hangs* if `x` is empty), * `detect x > 0` (nondeterministically returns `false`, or whether `x > 0`), * `swap x, y`, `OF := b`, `restart`, procedure calls and `return b`. Procedure calls are acyclic. A configuration is `(C, OF, σ)` with `C ∈ ℕ^Q`, the output flag `OF` and the call stack `σ ∈ (Proc × ℕ)*` (names and currently executed instructions). It is initial if `σ = ((Main, 1))`; `restart` moves to any initial configuration with the same total number of units. We keep the value of `OF` on a restart: this is how the paper implements `restart` in population machines (Appendix B.2), and the programs of Section 6 set `OF` before reading it anyway. ## Modelling We give the *instruction-level* semantics the paper describes: every procedure is a list of flat instructions (`Instr`), with the conditions of `if`/`while` compiled to conditional jumps. The structured syntax (`Stmt`, `BExp`) of the paper is compiled to flat code by `Stmt.compile` (standard, short-circuit evaluation of `∧`, `∨`); the configuration `(C, OF, σ)` is exactly the paper's, with `σ` storing the procedure and the index of its current flat instruction (0-based). * A procedure call `call p tT tF` stays on the caller's frame while `p` runs; when `p` executes `ret b`, the caller continues at `tT` if `b` and at `tF` otherwise. Calls used as statements have `tT = tF`. * `detect x tT tF` continues at `tF`, or at `tT` if `x > 0`. * If a configuration has no successor (a move from an empty register, a return of `Main`, a jump out of the code), the program hangs: `→` has a self-loop there (Section 3 requires `→` to be left-total). `P` decides `φ` if every fair run started at an initial configuration `(C, OF, ((Main, 0)))` stabilises to `φ(|C|)` (Section 3; the paper's text omits the word "fair" in Section 4). -/ namespace Podc.PPDoubleExpThresholds open Cslib.TransitionSystem /-! ### Flat instructions and programs -/
