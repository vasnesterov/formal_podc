Pointer values of all pointers live in one type `Val Q` (booleans, instruction addresses `ℕ`, registers `Q`), and `𝓕_X` is a `Finset (Val Q)`. There are special pointers: the output flag `OF`, the condition flag `CF`, the instruction pointer `IP`, and a register-map pointer `V x` for every `x ∈ Q ∪ {□}` (we write `V (some x)` for `V_x` and `V none` for `V_□`). Requirements (Definition 6): `𝓕_OF = 𝓕_CF = {false, true}`, `𝓕_IP = {1, …, L}`, `x ∈ 𝓕_{V_x} ⊆ Q` (and `𝓕_{V_□} ⊆ Q` nonempty). Instructions (`x ≠ y`, `f : 𝓕_Y → 𝓕_X`): `x ↦ y`, `detect x > 0`, `X := f(Y)`. Semantics (Definition 13): a configuration maps registers to `ℕ` and pointers to values; the instruction executed is `I_{C(IP)}`; registers are accessed through the register map, i.e. `x ↦ y` moves a unit from register `C(V_x)` to register `C(V_y)`. If no configuration `C' ≠ C` is a successor, `C → C` (so `→` is left-total; the machine *hangs*). Initial configurations: `C(IP) = 1` and `C(V_x) = x` for all `x ∈ Q`.
