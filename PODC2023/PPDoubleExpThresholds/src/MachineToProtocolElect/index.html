import Papers.PODC2023.PPDoubleExpThresholds.MachineToProtocolClean /-! # Leader election (Lemma 15) Counting agents per pointer level we define invariants of all configurations reachable from a configuration with at least `|F|` agents in the initial state `(X_1)^{v_1}_none` (plus arbitrary other agents): * `J`: for every `l ≤ |F|` at least `l` agents belong to the pointers of level `< l` (the prefix-sum invariant of the paper's proof of Lemma 15); * `K`: an empty level `l ∈ [1, |F| - 1)` has `≥ |F|` agents below it (levels `< |F| - 1` never become empty again once occupied); * `Fr`: if there is no `IP` agent, then the agents of every *settled* level `l` (exactly `l + 1` agents at levels `≤ l`) are *fresh*: `X^{v_X}_none` (for `CF`: any value). They are preserved by all transitions (`inv_step`). The key consequence (`elected_of_step`): the first configuration in which every pointer has exactly one agent is `π(C)` for an *initial* configuration `C` of the machine. This is the precise form of the claim "at the moment this happens, these agents are in `X^v_none`, where `v` is the initial value" in the proof of Lemma 15. -/ set_option linter.unusedSectionVars
