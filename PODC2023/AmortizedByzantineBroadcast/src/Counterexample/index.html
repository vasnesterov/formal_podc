import Papers.PODC2023.AmortizedByzantineBroadcast.Consistency /-! # Lemma 3 and Validity of Algorithm 4 fail A concrete run of Algorithm 4 with `n = 6`, `f = 2`, `ε = 1/6` (so `f ≤ (1/2 - ε) n`) and `G_ε = K₆` (an `(n, 2ε, 1 - 2ε)`-expander, `isExpander_K6`), Byzantine nodes `F = {4, 5}` (indices; the paper's nodes 5 and 6), senders `S₁ = 4`, `S₂ = 0`. The flaw: in step (8) (Query-1) a node `u` without a commit-proof sends `query₁` to the smallest node `v` that "has not accused `L_i`" — but an honest `v` that also lacks the commit-proof accuses `L_i` *in the same round*, so `u` cannot know it. `v` then cannot answer in Respond-1 and `u` accuses the honest `v` in Query-2. With the help of the Byzantine nodes this yields a corrupt-proof `thsig(accuse, v)` of an honest node, after which every honest node skips the epochs led by `v` forever. The run (slot 1, epoch 0, leader `S₁ = 4`): the Byzantine leader behaves correctly up to the commit-proof, which it sends to node `3` only. Nodes `0, 1, 2` accuse `4` (only 3 accusations, `n - f = 4` are needed for a corrupt-proof) and query: `1` and `2` query node `0`, node `0` queries node `1` — nobody of them has the commit-proof. In Query-2, `1` and `2` accuse node `0`, and so do the Byzantine nodes `4, 5`: four accusations, a corrupt-proof of the honest node `0`. (Node `3` then answers the `query₂`s in Respond-2 and slot 1 completes.)
