import Papers.PODC2023.OptimalEBAOmission.Thm63 /-! # Safety condition (1): moving to a run where all preferences are `1` `allOnes`: in a sending-omission context where decided agents send nothing and the initial extra state does not depend on the preference, for a "0-biased" protocol (implementations of `P0`, `P_min`, `P_basic`) every run `c` has an all-`1` companion run `c'` with the same nonfaulty agents in which every agent that has not decided `0` by time `k` has the same local state at time `k` as in `c`. The companion run silences every faulty agent from the round in which it decides `0` on. The paper's proof of Proposition 6.4 keeps the failure pattern unchanged ("the adversary is the same as in `r`"); this works for `γ_min` but not for `γ_basic`, where an agent that decided `0` in `r`
