Optimal EBA with Omission Failures — PODC 2023

Kaya Alpturer, Joseph Y. Halpern, Ron van der Meyden. Optimal Eventual Byzantine Agreement Protocols with Omission Failures. PODC 2023. DOI 10.1145/3583668.3594573. Formalized version: arXiv 2305.06271 v1 (full version with appendix); numbering follows it. Targets: §6 (Prop. 6.1, Thm. 6.3, Prop. 6.4, Thms. 6.5–6.6, Cor. 6.7).

DOI · arXiv · PDF · All differences · Lean source · GitHub

Verdict: ⚠️ Weakened. Correctness of P0 (Prop. 6.1) and the concrete results hold for t ≤ n − 2: P^min and P^basic implement P0 (Thms. 6.5, 6.6), and P0 is safe (Prop. 6.4) once the definition of a 0-chain is repaired. The general "safe ⇒ optimal" (Thm. 6.3) is proved only with an extra hypothesis, which holds in the two concrete contexts, and against one-shot competitors, so both protocols are optimal in that sense (Cor. 6.7) and the general claim is neither proved nor refuted. The full-information protocol of Section 7, which settles the open problem of the abstract, was not checked.

Mistakes in the paper

⚠️ Theorem 6.3 (safe ⇒ optimal in every EBA context)

The proof takes the first round k in which P and a strictly dominating P' differ, for an agent i that "may be faulty", and has three gaps, so the general claim is neither proved nor refuted (Context.thm_6_3 proves it with an extra hypothesis).

Impact. Unestablished in general; our extra hypothesis NFConsistent holds in γ_min and γ_basic, so Cor. 6.7 (t ≤ n − 2) is fully established for one-shot competitors. Whether Thm. 6.3 holds in every safe EBA context is open. Agents that can detect their own faultiness are the risk.

Details

  • The agent i may be faulty. Safety (1) yields a run where all preferences are 1 and i has the same state. The contradiction ("P' decides 0 against Validity") needs i to be nonfaulty there. EBA imposes nothing on faulty agents.

  • A case is missing. The case "P decides at k, P' does not" is never treated.

  • Repeated decisions. "All agents have the same state up to time k − 1" fails if P' performs decide again after deciding. The spec allows this, and faulty agents may do it freely.

Repair

We prove Thm. 6.3 for one-shot competitors under one extra hypothesis, NFConsistent: an undecided agent's local state also occurs, with the same preferences, in a run where that agent is nonfaulty. The hypothesis holds in γ_min (trivially) and in γ_basic (by swapping the roles of i and a nonfaulty agent). (Context.thm_6_3, Context.thm_6_3_lit)

🔧 Proposition 6.4 (definition of 0-chain, condition (c))

With the paper's 0-chains, Prop. 6.4 is false already for n = 3, t = 0, no failures and preferences 0, 1, 1: at time 1 agent 2 knows that somebody just decided 0 but not who, so it has received no 0-chain, and safety condition (1) fails for P^min (Counterexamples.prop_6_4_lit_false; every n ≥ 3, t ≤ n − 2: prop_6_4_lit_false_gen).

Impact. A one-clause fix of a definition with evident intent: with "i_{m'} knows that some agent has just decided 0" Prop. 6.4 holds (prop_6_4_min, prop_6_4_basic), and Thm. 6.3 with the paper's definition still follows.

Details

Condition (c) of a 0-chain asks that i_{m'} knows that i_{m'−1} has just decided 0. In the minimal context an agent only learns that somebody just decided 0, not who. In the example, at time 1 agent 2 has jd = 0. In the run with preferences 1, 0, 1 it has the same local state, so it does not know that agent 0 decided. Hence it has received no 0-chain. Yet every run in which it has this local state contains a preference 0. This breaks safety condition (1) for P^min, the unique implementation of P0 there. The same failure-free example works for every n ≥ 3, t ≤ n − 2. It also refutes the main-text claim that "K_i(⋁_j jdecided_j = 0) holds iff i receives a 0-chain". The proof of Prop. 6.1 reaches the paper's definition by an invalid step: from K_i(⋁_j jdecided_j = 0) it concludes K_i(jdecided_j = 0) for some j.

✏️ Slips

  • Corollary 6.7 is stated for all of γ_min,n,t, i.e. for every t < n, but for t = n − 1 the protocol P^min_{n−1} implements P0, is an EBA protocol and strictly dominates P^min (Counterexamples.cor_6_7_min_false, cor_6_7_min_false'). A 0-chain reaching time n − 1 would need n agents besides the undecided agent, so P0 already decides 1 at time n − 1 = t, one round before P^min does; in the failure-free all-1 run the decisions are at n − 1 vs n. Cor. 6.7 is derived from Thms. 6.5/6.6, which assume t ≤ n − 2, and with that hypothesis it holds (cor_6_7_min, cor_6_7_basic).

  • Proposition 6.1 is stated for every EBA context, whose failure model may drop messages of nonfaulty agents, but Agreement and termination in t + 1 rounds need F ⊆ SO(t), the only model the paper uses (Context.prop_6_1 assumes it).

  • Section 5: the update rule of jd sets both jd = 0 and jd = 1 if a 0-message and a 1-message arrive in the same round. This never happens for implementations of P0; we set jd = 0.

Typos

  • Proof of Thm. 6.5: I should be the system of P^min, not of P0; jdecided should be deciding; "(Note that t′ = m.)".

The formalizationmodel, Lean names of the results, trust

Model.

  • Synchronous rounds, n agents Fin n, message passing.

  • Failures: sending omissions SO(t). A failure pattern (N, F) fixes the nonfaulty agents (|Agt \ N| ≤ t) and, for every round and pair, whether the message is delivered. Only faulty agents omit. Self-messages may be omitted too, as in the paper. The adversary is arbitrary.

  • No randomness; protocols are deterministic.

  • An EBA context (Context) is an information-exchange protocol plus a failure model. Local states are (⟨time, init, decided, jd⟩, x), and the core part is updated exactly as §5 prescribes. Messages have a tag 0/1/none (the sets M⁰, M¹, M²).

  • A run is determined by its initial global state (Config: pattern, preferences, initial extra state). Knowledge K_i quantifies over all admissible configurations and times; Knows is CSLib's System.K (knows_iff_K).

  • P0, "implements", the EBA spec, domination and optimality are the paper's definitions. Domination is literal, quantifying over all decision times.

  • Theorem 6.3 restricts competitors to one-shot protocols, which do nothing after deciding. Cor. 6.7 is proved in this sense; cor_6_7_min_false' refutes the paper's unrestricted sense.

Trust. No sorry; all listed theorems use only propext, Classical.choice, Quot.sound. Non-vacuity:

  • pmin_pbasic_eba: P^min and P^basic are EBA decision protocols.

  • The safety and NFConsistent hypotheses of thm_6_3 are discharged in both contexts.
