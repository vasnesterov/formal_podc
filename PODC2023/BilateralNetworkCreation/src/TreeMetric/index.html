import Papers.PODC2023.BilateralNetworkCreation.Model import Cslib.Foundations.Combinatorics.SimpleGraph.ShortestWalks import Cslib.Foundations.Combinatorics.SimpleGraph.BFSTree /-! # Rooted trees via the metric For a tree `G` rooted at `r`, the layer of `x` is `dist(r, x)` and the subtree `T_u` is `sub G r u = {x | dist(r,x) = dist(r,u) + dist(u,x)}` (the `x` whose path to `r` passes `u`). This metric description makes containment of subtrees and "ancestors" purely metric facts; the tree structure is used only for: * uniqueness of ancestors at a given layer (`anc_unique`), via uniqueness of paths; * the component description: for `u ≠ r` with parent `p`, `T_u` is the component of `u` in `G - up` (`mem_sub_iff_reachable`), and the rest is the component of `p`; * the bridge formula `dist(x, y) = dist(x, u) + 1 + dist(p, y)` for `x ∈ T_u`, `y ∉ T_u` (`dist_cross`), and its corollary, the "moving along an edge" formula `sum_move`; * `d_le_dist_of_reachable`: two vertices on the same side of the edge `up` keep (at most) their distance in any graph containing `G - up`.
