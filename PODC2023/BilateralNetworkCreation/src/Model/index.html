import Mathlib /-! # The Bilateral Network Creation Game (BNCG) Friedrich, Gawendowicz, Lenzner, Zahn. *The Impact of Cooperation in Bilateral Network Creation.* PODC 2023 (full version arXiv:2207.03798v2), Section 1.1. A state of the BNCG is identified with the created graph `G` on the agent set `V` (the paper does the same: in equilibrium no agent pays for an edge that is not built). Agent `u` pays `α` per incident edge and the sum of its hop distances to all agents; the distance between disconnected agents is a constant `M` (the paper takes `M ∈ ℕ`, `M > α n³`). We define * `d M G u v` — the distance with penalty `M`, `distCost M G u = ∑ v, d M G u v` (`dist(u)`), * `cost α M G u = α · deg u + dist(u)`, * the solution concepts `RE`, `BAE`, `PS`, `BSwE`, `BGE`, `KBSE k`, `BSE`, * the social cost, the optimum `optCost` (an infimum over *all* graphs on `V`), and the ratio `rho = cost(G) / cost(OPT)`. -/ namespace Podc.BilateralNetworkCreation open SimpleGraph V) (u v : V) : ℕ := if G.Reachable u v then G.dist u v else M /-- The total distance cost `dist_G(u) = ∑_v dist_G(u, v)`. -/ noncomputable def distCost (M : ℕ) (G : SimpleGraph V) (u : V) edges an agent pays for (its degree). -/ noncomputable def deg (G : SimpleGraph V) (u : V) : ℕ := (G.neighborSet u).ncard /-- The cost of agent `u`: buying cost `α · deg u` plus distance cost. -/ noncomputable def cost (α : ℝ) (M : ℕ) (G : SimpleGraph V) (u : V) : ℝ := α * deg G u + distCost M G u variable (α : ℝ) (M : ℕ) (G : SimpleGraph V) /-- Remove Equilibrium: no agent strictly improves `u, v, w` with `uv ∈ E`, `uw ∉ E` such that both `u` and `w` strictly improve when `u` replaces `uv` by `uw`. -/ def BSwE : Prop := ∀ u v w, G.Adj u v → u ≠ w → ¬ G.Adj u w → cost α M (swap G u v w) u < cost α M G u → cost α M G w ≤ cost α M (swap G u v w) w /-- Bilateral Greedy Equilibrium. -/ def BGE : Prop := PS α M G ∧ BSwE α M G /-- `G'` arises from `G` by a move of the coalition `Γ`: removed edges have an endpoint in `Γ`, added edges have both endpoints in `Γ`. -/ def IsCoalitionMove (G G' : SimpleGraph V) (Γ : Finset V) : Prop := (∀ x y, G.Adj x y → ¬ G'.Adj x y → x ∈ Γ ∨ y ∈ Γ) ∧ (∀ x y, G'.Adj x y → ¬ G.Adj x y → x ∈ Γ ∧ y ∈ Γ) /-- Bilateral `k`-Strong Equilibrium: no nonempty coalition of size `≤ k` has a move after which all its members strictly improve. (The paper does not say "nonempty"; for `Γ = ∅` the condition "all members improve" would be vacuous.) -/ def KBSE (k : ℕ) : Prop := ∀ Γ : Finset V, Γ.Nonempty → Γ.card ≤ k → ∀ G', IsCoalitionMove G G' Γ → ∃ x ∈ Γ, cost α M G x ≤ cost α M G' x /-- Bilateral Strong Equilibrium (`n`-BSE). -/ def BSE : Prop := KBSE α M G (Fintype.card V) /-- Social cost. -/ noncomputable def socialCost : ℝ := ∑ u, cost α M G u /-- Cost of a social optimum (infimum over all graphs on `V`). -/ noncomputable def optCost : ℝ := ⨅ H : SimpleGraph V, socialCost α M H /-- The social cost ratio `ρ(G) = cost(G) / cost(OPT)`. -/ noncomputable def rho : ℝ := socialCost α M G / optCost (V := V) α M end Defs /-! ### Basic facts about `d` -/ section Basic variable {M : ℕ} {G G' : SimpleGraph V} {u v w : V} @[simp] lemma d_self : d M G u u = 0 := by simp [d] lemma d_of_reachable (h : G.Reachable u v) : d M G u v = G.dist u v := by simp [d, h] lemma d_of_not_reachable (h : ¬ G.Reachable u v) : d M G u v = M := by simp [d, h] lemma d_comm : d M G u v = d M G v u := by unfold d by_cases h : G.Reachable u v · simp [h, h.symm, dist_comm] · have h' : ¬ G.Reachable v u := fun h' => h h'.symm simp [h, h'] lemma d_le_of_walk (p : G.Walk u v) : d M G u v ≤ p.length := by rw [d_of_reachable ⟨p⟩];
